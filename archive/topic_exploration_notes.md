## 1. 핵심 관점

이미 표준이 된 기술(LDPC, OFDM, Massive MIMO)은 연구할 여지가 상대적으로 적습니다.
연구 기회가 큰 쪽은 아래 조건을 갖춘 이론입니다.

> **이론적 이득은 증명됐는데, 구현이나 현실성 문제로 묻혀 있다가 최근 다시 주목받는 것**

각 항목의 **열린 질문**이 그대로 연구 주제 후보입니다.

## A. 이론은 완벽했지만 계산량과 구현에 막혔던 것

### A1. 나이퀴스트보다 빠른 전송 (Faster-than-Nyquist, FTN)

| 항목 | 내용 |
|---|---|
| 원조 | J. E. Mazo, 1975, *Bell System Technical Journal* |
| 핵심 | 나이퀴스트 속도보다 약 25% 빠르게 심볼을 보내도 최소 거리(오류 성능)가 줄지 않음. 이 한계를 '마조 한계'라고 부름 |
| 외면 이유 | 일부러 만든 심볼 간 간섭(ISI)을 풀어내는 수신기의 연산량이 너무 큼 |
| 부활 | 2000년대 Anderson, Rusek 등이 재연구. 6G에서 대역폭을 늘리지 않고 효율을 높이는 후보로 거론됨 |
| 열린 질문 | 연산량이 적은 FTN 검출기(딥러닝 포함), FTN과 OTFS·MIMO의 결합, 위성 링크 적용 |

### A2. 더러운 종이 위에 쓰기 (Dirty Paper Coding, DPC)

| 항목 | 내용 |
|---|---|
| 원조 | M. Costa, 1983, "Writing on Dirty Paper", *IEEE Trans. Inf. Theory* |
| 핵심 | 송신기가 간섭을 미리 알고 있으면, 그 간섭이 아무리 커도 **용량 손실이 0** |
| 외면 이유 | 실제로 구현하려면 무한히 긴 격자 부호가 필요해 약 20년간 순수 이론으로 남음 |
| 부활 | 2006년 다중 사용자 MIMO 방송 채널의 용량을 달성하는 방식이 DPC라는 것이 증명됨 (Weingarten, Steinberg, Shamai) |
| 열린 질문 | 실용적인 DPC 근사(벡터 섭동, 격자 프리코딩), 셀 프리 MIMO와 위성 다중 빔 간섭 사전 제거 |

### A3. 한-고바야시 기법 → 전송률 분할 다중 접속 (RSMA)

| 항목 | 내용 |
|---|---|
| 원조 | T. S. Han & K. Kobayashi, 1981. 간섭 채널에서 지금까지 알려진 가장 좋은 달성 기법 |
| 외면 이유 | 메시지를 공통 부분과 개인 부분으로 나누고 순차 간섭 제거(SIC)를 해야 해서 너무 복잡함 |
| 부활 | 2016년 이후 B. Clerckx 등이 RSMA로 재구성. 직교 다중 접속과 NOMA를 모두 특수한 경우로 포함하는 틀 |
| 열린 질문 | 채널 정보가 불완전할 때의 견고성, SIC 오류의 영향, 위성과 ISAC에 적용 |
| 주의 | NOMA는 5G NR 표준에서 빠졌음. "왜 실패했고, RSMA는 무엇이 다른가"부터 짚고 들어갈 것 |

### A4. 피드백 부호 (Schalkwijk–Kailath)

| 항목 | 내용 |
|---|---|
| 원조 | J. P. M. Schalkwijk & T. Kailath, 1966 |
| 핵심 | 피드백 채널을 쓰면 오류 확률이 이중 지수적으로 줄어듦 |
| 외면 이유 | 피드백에 잡음이 조금만 섞여도 이득이 무너져 실용성이 없다고 평가됨 |
| 부활 | 2018년 Deepcode, 2022년 GBAF처럼 **딥러닝으로 학습한 피드백 부호**가 잡음 있는 피드백에서도 기존 부호를 이김 |
| 열린 질문 | 학습된 부호의 해석 가능성과 이론적 보장, 짧은 블록 길이에서의 성능 |

### A5. 유한 블록 길이 정보이론

| 항목 | 내용 |
|---|---|
| 원조 | V. Strassen, 1962. 2차 점근 분석을 독일어 논문으로 발표 |
| 외면 이유 | 블록이 무한히 길다고 가정하는 샤논 이론이 주류여서 거의 잊힘 |
| 부활 | 2010년 Polyanskiy, Poor, Verdú, "Channel Coding Rate in the Finite Blocklength Regime" 이후 5G 초저지연 통신(URLLC)의 이론적 기반이 됨 |
| 열린 질문 | 페이딩, 다중 접속, 반송파 없는 IoT 환경의 유한 블록 길이 한계 |

## B. 주류 이론의 가정 때문에 묻혔던 것

### B1. 의미 통신 (Semantic Communication)

| 항목 | 내용 |
|---|---|
| 원조 | W. Weaver, 1949. 통신 문제를 기술(A), 의미(B), 효과(C)의 세 단계로 나눔. 1952년 Carnap & Bar-Hillel이 의미 정보 이론을 제안 |
| 외면 이유 | 샤논이 "의미는 공학과 무관하다"고 선을 그은 뒤 약 70년간 비주류 |
| 부활 | 2019년 DeepJSCC(Bourtsoulatze, Kurka, Gündüz) 이후 6G의 핵심 화두 |
| 열린 질문 | '의미 정보량'을 엄밀하게 정의하는 것, 성능 지표, 송수신 간 지식 불일치 |
| 메모 | 과장(hype)이 많은 분야라서 **엄밀한 이론으로 기여할 여지**가 큼 |

### B2. 소스·채널 결합 부호화 (Joint Source-Channel Coding, JSCC)

| 항목 | 내용 |
|---|---|
| 외면 이유 | 샤논의 분리 정리가 "소스 부호화와 채널 부호화는 따로 최적화해도 손해가 없다"고 보장함. 다만 이 보장은 블록이 무한히 길 때만 성립 |
| 부활 | 짧은 블록, 저지연, 방송 환경에서는 분리 방식이 손해라는 점이 드러났고, 딥러닝 기반 JSCC가 실험에서 기존 방식을 이기고 있음 |
| 열린 질문 | B1 의미 통신과 이어지는 주제. 채널이 바뀔 때의 적응성, 디지털 변조와의 호환 |

### B3. 공중 계산 (Over-the-Air Computation, AirComp)

| 항목 | 내용 |
|---|---|
| 원조 | B. Nazer & M. Gastpar, 2007, "Computation over Multiple-Access Channels" |
| 핵심 | 기존에는 피해야 할 간섭으로 보던 '신호가 공중에서 더해지는 현상'을 오히려 계산에 이용 |
| 부활 | 2019년 이후 **연합학습(Federated Learning)의 모델 집계**에 쓰이면서 급부상 |
| 열린 질문 | 동기화 오차, 프라이버시, 디지털 방식의 AirComp |

## C. 물리·하드웨어 한계로 묻혔던 것

### C1. 반사 전력 통신 → 후방산란 통신 (Backscatter)

| 항목 | 내용 |
|---|---|
| 원조 | H. Stockman, 1948, "Communication by Means of Reflected Power", *Proc. IRE* |
| 외면 이유 | 신호가 너무 약해서 RFID 정도의 틈새 용도에 머묾 |
| 부활 | 2013년 주변 전파를 반사해 통신하는 주변 후방산란(ambient backscatter)이 시연됨. 3GPP Rel-19에서 **배터리 없는 Ambient IoT** 연구 시작 |
| 열린 질문 | 수신 감도, 다중 태그 충돌, 셀룰러 신호를 이용한 후방산란 |

### C2. 반사배열 → 지능형 반사 표면 (RIS)

| 항목 | 내용 |
|---|---|
| 원조 | Berry, Malech, Kennedy, 1963 (reflectarray) |
| 부활 | 2019년 이후 대표적인 6G 화두 |
| 회의론 | 경로 손실이 두 번 곱해지는 문제(multiplicative path loss), 채널 추정 부담 때문에 "실제로 이득이 있느냐"는 논쟁이 진행 중 |
| 열린 질문 | 능동형 RIS와 수동형 RIS의 공정한 비교, 대규모 RIS의 채널 추정 |
| 메모 | **비판적으로 검증하는 연구**도 가치가 큼 |

### C3. 초지향성 안테나 (Superdirectivity)

| 항목 | 내용 |
|---|---|
| 원조 | A. I. Uzkov, 1946. 촘촘하게 배치한 안테나 배열이 N² 지향성을 낼 수 있음 |
| 외면 이유 | 손실과 오차에 극도로 민감해서 비실용적인 이론적 호기심으로 취급됨 |
| 부활 | 홀로그래픽 MIMO, 근거리장 XL-MIMO, 테라헤르츠 대역 연구에서 다시 거론됨 |
| 열린 질문 | 상호 결합을 활용한 배열 설계, 대역폭과 효율의 상충 관계 |

### C4. 자크 변환과 가보르 이론 → OTFS·AFDM

| 항목 | 내용 |
|---|---|
| 원조 | D. Gabor, 1946 (시간-주파수 표현). J. Zak, 1967 (자크 변환) |
| 외면 이유 | 순수 수학 도구로 머물렀고, 통신에는 OFDM이 더 단순했음 |
| 부활 | 2017년 OTFS(Hadani 등), 2021년 AFDM(Bemani 등). OFDM이 무너지는 **고속 이동 환경(저궤도 위성, 고속철도)** 의 대안 |
| 열린 질문 | 지연-도플러 영역 채널 추정, ISAC과의 결합, 실제 하드웨어 구현 |

## 연구 주제 선정 기준

| 기준 | 좋은 신호 | 주의할 신호 |
|---|---|---|
| 이론적 이득 | 상한이 수학적으로 증명됨 (DPC, FTN, 유한 블록 길이) | "무한대", "혁명적" 같은 표현만 있음 (초기 OAM) |
| 막혔던 원인 | 연산량이나 하드웨어 → 지금 바뀌는 중 (AI 가속기, 대규모 배열) | 물리 법칙 자체가 원인 |
| 분야 성숙도 | 서베이가 1~3편 정도 나옴 | 서베이가 수십 편이고 표준화까지 끝남 |
| 기여 방식 | 실용화 방법, 공정한 비교, 한계 분석 | 같은 시뮬레이션을 반복하는 수준 |

## 부록 A. 이미 표준이 된 고전 사례

이미 표준이 되어 연구 여지는 적지만, "외면당했다가 부활한" 흐름을 이해하는 데 좋은 사례입니다.

| 기술 | 원조 | 외면 이유 | 현재 |
|---|---|---|---|
| LDPC 부호 | R. Gallager, 1960~63 | 당시 컴퓨터로는 실시간 복호가 불가능 | 5G NR 데이터 채널, Wi-Fi, DVB-S2 |
| OFDM | R. W. Chang, 1966 | 아날로그 필터 수십 개가 필요. 1971년 FFT 구현법이 나온 뒤 DSP 발전으로 실용화 | Wi-Fi, LTE, 5G의 기반 |
| 터보 부호 | C. Berrou, 1993 | 샤논 한계에 0.5 dB까지 다가갔다는 결과를 청중이 측정 실수로 의심 | 3G/4G 표준. LDPC 재발견의 계기 |
| MIMO | G. Foschini, 1996 | "다중경로는 제거해야 할 적"이라는 통념 | 4G/5G 핵심 |
| 폴라 부호 | E. Arıkan, 2009 | 샤논 한계 달성이 증명된 최초의 부호 | 5G NR 제어 채널 |
| Massive MIMO | T. Marzetta, 2010 | 안테나가 너무 많아 비현실적이라는 평가 | 5G 기지국 |
| CDMA | 확산 스펙트럼(군사·GPS) → Qualcomm IS-95 | 원근 문제(near-far problem)로 민간 대용량 셀룰러는 불가능하다는 평가 | 2G/3G 기반 (LTE/5G는 OFDMA) |
| 전이중 통신 | 2010~2013 Stanford·Rice 시연 | 자기 간섭이 100 dB 이상 | 3GPP Rel-18/19의 SBFD |
| OAM 다중화 | 2010년대 | 빔 퍼짐, 정렬 문제, 실제로는 MIMO의 특수한 경우 | 단거리 무선·광통신 실험 단계 |

## 부록 B. 많이 퍼진 설명의 사실 확인

통신 역사 관련 글에서 자주 보이는 오류나 과장을 바로잡은 내용입니다.

### LDPC 부호: 대체로 정확함
- 갤러거의 MIT 박사논문은 1960년이고, 1962~63년에 논문과 단행본으로 나왔습니다.
- 완전히 잊힌 것은 아닙니다. 1981년 Tanner가 이 부호를 그래프로 표현했지만 거의 주목받지 못했습니다. 본격적으로 다시 발견된 것은 1993년 터보 부호가 나온 직후입니다. 1996년 MacKay와 Neal의 연구가 계기였습니다.
- "샤논 한계 99.9%"는 비유적인 표현입니다. 2001년 Chung 등이 매우 긴 부호로 샤논 한계에서 약 0.0045 dB 떨어진 결과를 보인 적은 있습니다.
- 스타링크는 사용하는 부호 방식이 공개되지 않았습니다. 위성통신의 예로는 DVB-S2를 드는 것이 정확합니다.
- 5G NR에서 데이터 채널은 LDPC, 제어 채널은 폴라 부호를 씁니다.

### CDMA: 가장 큰 오류가 있음
- ❌ **"3G/LTE/5G의 기초"는 틀렸습니다.** CDMA는 2G(IS-95)와 3G(WCDMA, cdma2000)의 기반이었고, **LTE와 5G는 OFDMA를 씁니다.**
- GPS는 "부활"한 사례가 아닙니다. 1970년대부터 군사용으로 CDMA 방식의 확산 스펙트럼을 써 왔습니다. 회의론은 "민간 셀룰러에서 대용량으로" 쓰는 것에 대한 것이었습니다.
- "한국 세계 최초": 홍콩 Hutchison이 1995년 9월에 먼저 상용 서비스를 시작했다는 기록이 있습니다. 한국(1996년 1월)은 보통 "세계 최초의 대규모 전국 상용화"로 소개됩니다.
- "1초에 800번 전력 제어"는 IS-95 폐루프 전력 제어(800 Hz)와 일치하므로 맞습니다.
- "용량 수십 배": 퀄컴이 내세운 수치는 아날로그 AMPS 대비 10~20배였습니다. 실제 현장 이득은 그보다 낮았고, GSM 같은 디지털 TDMA 방식과 비교하면 차이가 더 작았습니다.
- 1996년에는 스마트폰이 없었으므로 "휴대폰"이 맞는 표현입니다.

### 전이중 통신: 과장이 있음
- "100년간 물리적으로 불가능하다고 가르쳤다"는 과장입니다. 물리 법칙상 불가능한 것이 아니라 **공학적으로 비현실적**이라는 뜻이었습니다. 레이더는 오래전부터 서큘레이터 같은 부품으로 송수신을 분리해 왔습니다.
- 100 dB = 100억 배(전력 기준)는 맞습니다. 2010~2013년 Stanford와 Rice대 연구진이 약 110 dB의 자기 간섭 제거를 시연했습니다.
- 현실에서 먼저 표준이 된 것은 3GPP Rel-18/19의 **SBFD(Sub-Band Full Duplex)** 입니다. 완전히 같은 주파수에서 동시에 송수신하는 방식이 단말까지 상용화된 상태는 아닙니다.
- "효율 2배"는 이론상 상한이고, 실제로는 사용자 사이의 간섭 때문에 이득이 줄어듭니다.

### OAM: 핵심 비판이 빠져 있음
- ❌ **"이론적으로 무한대 채널"은 학계에서 대체로 반박된 주장입니다.** 2012년 Edfors 등의 분석 이후 정리된 결론은, 전파 OAM이 **MIMO 공간 모드의 특수한 경우**이고 안테나 크기와 거리로 정해지는 자유도를 넘어설 수 없다는 것입니다.
- 빔이 퍼지는 문제와 정렬이 까다로운 문제는 맞는 지적입니다. 다만 "1밀리미터 오차도 없이"는 과장입니다.
- 2018년 NTT가 28 GHz 대역에서 약 10 m 거리로 100 Gbps 전송을 시연했습니다. 현재 가능성이 더 큰 분야는 무선보다 광섬유와 광통신입니다.

### HBM 비유
- HBM은 "수십 년간 외면"받았다기보다, 2013년 표준화 이후 **비용과 수율 때문에 틈새 제품에 머물다가** AI 수요가 폭발하면서 주류가 된 경우입니다.
