# Max 1960 — 최소 왜곡 양자화 (Quantizing for Minimum Distortion)

## 1. 서지

- J. Max, "Quantizing for Minimum Distortion," *IRE Transactions on Information Theory*, vol. IT-6, no. 1, pp. 7–12, March 1960. (원고 접수 1959-09-25, MIT Lincoln Lab.)
- 원문 파일: `papers/classic/15_Max1960.pdf` (6쪽 중 1쪽은 앞 논문의 끝부분, 실제 본문은 원문 쪽번호 7–12).
- 원문에는 "정리(Theorem)" 번호가 없다. 결과는 식 번호 (1)–(8)과 표 I·II, 그림 1–6으로 제시된다. 아래에서는 식 번호로 인용한다.

## 2. 문제 설정 (원문 기호)

- 입력 신호 진폭의 확률밀도 p(x). 준위 수(number of output levels) N은 고정.
- 양자화기는 끝점(end points) x_1 < x_2 < … < x_{N+1} (x_1 = −∞, x_{N+1} = +∞)과 출력 준위(output levels) y_1, …, y_N으로 정해진다. 규약: x_j ≤ 입력 < x_{j+1} 이면 출력 y_j.
- 왜곡(distortion): 미분 가능한 함수 f에 대해 D = E[f(s_in − s_out)],

  D = Σ_{i=1}^{N} ∫_{x_i}^{x_{i+1}} f(x − y_i) p(x) dx.   [원문, 식 번호 없음]

- 목표: N 고정에서 D를 x_j, y_j에 대해 최소화. 전송은 오류 없다고 가정(고정율, 율 = log₂N 비트/표본).
- 이후 특수화: f(x) = x² (평균제곱오차, MSE), p(x) = (1/√(2π)) e^{−x²/2} (표준 가우시안).
- 두 번째 문제: 등간격 제약(입력 구간 길이 r 공통, 출력은 구간 중점)에서 r만 최적화. 짝수 2N개 출력의 대칭형에서 식 (7).

## 3. 주 결과 진술 (원문 대조함)

원문 2–3쪽(원문 쪽번호 8–9), 5–6쪽(표)의 이미지를 직접 보고 대조했다.

- 식 (1): ∂D/∂x_j = f(x_j − y_{j−1}) p(x_j) − f(x_j − y_j) p(x_j) = 0, j = 2, …, N.
- 식 (2): ∂D/∂y_j = −∫_{x_j}^{x_{j+1}} f′(x − y_j) p(x) dx = 0, j = 1, …, N.
- 식 (3): p(x_j) ≠ 0이면 f(x_j − y_{j−1}) = f(x_j − y_j), j = 2, …, N.
- 식 (4): ∫_{x_j}^{x_{j+1}} f′(x − y_j) p(x) dx = 0, j = 1, …, N.
- f가 f(0)=0, 우함수, 단조증가이면 (3)에서 |x_j − y_{j−1}| = |x_j − y_j|, 따라서 x_j = (y_j + y_{j−1})/2 (끝점 = 이웃 출력의 중점).
- f(x) = x²일 때
  - 식 (5): x_j = (y_j + y_{j−1})/2, 또는 y_j = 2x_j − y_{j−1}, j = 2, …, N. (중점 조건, midpoint condition)
  - 식 (6): ∫_{x_j}^{x_{j+1}} (x − y_j) p(x) dx = 0, j = 1, …, N. 즉 y_j는 [x_j, x_{j+1}] 위 p의 무게중심(centroid). (중심 조건, centroid condition)
- 충분조건: 2계 편미분 행렬 [∂²D/∂p_i∂p_j]이 임계점에서 양정치이면 극소. 아니면 모든 임계점에서 D를 비교 ("끝점"은 쉽게 배제된다고 서술).
- 수치 알고리즘: y_1을 고르고 (5)·(6)으로 x_2, y_2, x_3, … 을 차례로 생성, 마지막 y_N이 [x_N, ∞)의 무게중심이 되는지 확인하여 y_1을 다시 고른다(사격법, shooting).
- 등간격 문제 식 (7): 짝수 2N개 출력, 대칭일 때
  D = 2 Σ_{i=1}^{N−1} ∫_{(i−1)r}^{ir} f(x − [(2i−1)/2] r) p(x) dx + 2 ∫_{(N−1)r}^{∞} f(x − [(2N−1)/2] r) p(x) dx.
- 식 (8): dD/dr = −Σ_{i=1}^{N−1} (2i−1) ∫_{(i−1)r}^{ir} f′(x − [(2i−1)/2] r) p(x) dx − (2N−1) ∫_{(N−1)r}^{∞} f′(x − [(2N−1)/2] r) p(x) dx = 0.
- 표 I: 가우시안 MSE 최적 양자화기, N = 1…36의 x_j, y_j, 오차(MSE), 엔트로피. 표 II: 최적 등간격 양자화기의 간격, MSE, 엔트로피.
- 점근 서술: 로그-로그 그림의 접선이 N=4에서 D = 1.32 N^{−1.74}, N=36에서 D = 2.21 N^{−1.96}(최적), 등간격 최적은 N=36에서 D = 1.47 N^{−1.74}. 큰 N에서 D = kN^{−2}를 기대(k는 상수, 원문은 값을 주지 않음).
- 각주 1: 가우시안에서 해석해는 N=1 (y_1=0), N=2 (x_2=0, y = ±√(2/π)=±0.7980)뿐.
- 각주 2: 출력 엔트로피는 log₂N의 상당 부분이고 대부분 0.9 log₂N 근방.

## 4. 유도

### 4.1 왜곡 함수의 미분 (식 (1)–(4))

1. D(x_2,…,x_N, y_1,…,y_N) = Σ_i ∫_{x_i}^{x_{i+1}} f(x − y_i) p(x) dx. [원문]
2. x_j (2 ≤ j ≤ N)는 두 항에만 나타난다: i = j−1 항의 위끝, i = j 항의 아래끝. 라이프니츠 규칙(적분 끝점 미분)으로
   ∂D/∂x_j = f(x_j − y_{j−1}) p(x_j) − f(x_j − y_j) p(x_j). → 식 (1). [원문]
3. y_j는 i = j 항의 피적분함수에만 나타난다. 적분 기호 아래 미분(f가 미분 가능하고 f′(x−y)p(x)가 적분 가능하다는 가정, [재구성]: 원문은 정칙성 조건을 명시하지 않음)으로
   ∂D/∂y_j = −∫_{x_j}^{x_{j+1}} f′(x − y_j) p(x) dx. → 식 (2). [원문]
4. 내부 극소점이면 기울기가 0이어야 하므로 (1)=0, (2)=0. p(x_j) ≠ 0이면 (1)을 p(x_j)로 나누어 식 (3). [원문]

### 4.2 중점 조건 (식 (5))

5. f가 f(0)=0, f(x)=f(−x), x ≥ 0에서 순증가이면 f(a)=f(b) ⇔ |a|=|b|. 따라서 (3)에서 |x_j − y_{j−1}| = |x_j − y_j|. [원문]
6. 두 경우: x_j − y_{j−1} = x_j − y_j (곧 y_{j−1} = y_j, 출력이 겹침) 또는 x_j − y_{j−1} = −(x_j − y_j). 겹치는 출력은 준위 하나를 버리는 것과 같아 최적이 아니므로(원문: "should not coincide") 후자, 곧 x_j = (y_{j−1} + y_j)/2. [원문]
   - 해석 [재구성]: 이것은 최근접 이웃 조건(nearest neighbor condition)이다. 출력이 정해지면 각 입력을 가장 가까운 출력으로 보내는 분할이 최적이고, 1차원에서 그 경계는 이웃 출력의 중점이다. 원문은 미분으로만 얻었지만, 이 조건은 p(x_j) = 0인 경우에도 직접 논증으로 성립한다(분할을 바꿔도 D가 늘지 않음).

### 4.3 중심 조건 (식 (6))

7. f(x)=x²이면 f′(x−y) = 2(x−y). (4)는 ∫_{x_j}^{x_{j+1}} (x − y_j) p(x) dx = 0. [원문]
8. 풀면 y_j = ∫_{x_j}^{x_{j+1}} x p(x) dx / ∫_{x_j}^{x_{j+1}} p(x) dx = E[X | x_j ≤ X < x_{j+1}]. [원문(서술), 식 정리는 재구성]
   - 해석 [재구성]: 분할이 고정되면 구간 안에서 MSE를 최소화하는 상수는 조건부 평균이다(제곱 손실의 최적 추정량). 2계 도함수 ∂²D/∂y_j² = 2P(구간) > 0이므로 y_j에 대해서는 항상 유일한 극소.

### 4.4 충분조건과 대역 최적성

9. 원문: 헤세 행렬이 양정치이면 극소, 아니면 모든 임계점을 비교. [원문]
10. 보충 [재구성]: (5)·(6)은 필요조건일 뿐이다. p가 로그 오목(log-concave, 가우시안 포함)이면 MSE 임계점이 유일하여 (5)·(6)의 해가 대역 최적임이 뒤에 Fleischer(1964)·Trushkin(1982)에 의해 알려졌다. [미확인: 본 논문에는 없음, 2차 문헌 기억에 의존]

### 4.5 반복 알고리즘 (사격법)

11. (5)는 y_j = 2x_j − y_{j−1}, (6)은 x_{j+1}에 대한 음함수 방정식 ∫_{x_j}^{x_{j+1}} (x − y_j)p(x)dx = 0. 그러므로 y_1 하나를 정하면, (6)을 j=1에 적용해 x_2를 얻고(x_1 = −∞), (5)로 y_2, (6)으로 x_3, … 순서로 전부 결정된다. [원문]
12. 마지막에 y_N이 [x_N, ∞) 구간의 무게중심이어야 한다(j = N의 (6)). 맞지 않으면 y_1을 고쳐 반복. 원문은 이 탐색을 체계화해 IBM 709로 계산했다고만 쓴다. [원문]
13. 대칭 제약: 가우시안처럼 대칭 분포에서는 N 짝수이면 x_{N/2+1} = 0, N 홀수이면 y_{(N+1)/2} = 0을 강제하여 절반만 계산. [원문]
14. 보충 [재구성]: 오늘날 "Lloyd–Max 알고리즘"이라 부르는 것은 보통 (5)·(6)을 번갈아 적용하는 고정점 반복(Lloyd 1957/1982 방법 I)이다. Max의 원래 방법은 고정점 반복이 아니라 y_1에 대한 1차원 사격법이다. 이 차이를 혼동하지 않는다. y_1에 대한 마지막 조건 불일치가 y_1에 대해 단조라는 사실은 원문이 증명하지 않는다. [재구성/미확인]

### 4.6 등간격 양자화기 (식 (7)–(8))

15. 대칭 짝수 2N개 출력이면 구간 [(i−1)r, ir)의 출력은 중점 (2i−1)r/2, 마지막 구간은 [(N−1)r, ∞). 양쪽 대칭이므로 양의 쪽 적분의 2배 → 식 (7). [원문]
16. r에 대해 미분. 끝점 (i−1)r, ir에서 나오는 경계항은 이웃 구간끼리 f 값이 같으므로(경계가 이웃 출력의 중점이라 f(r/2)=f(−r/2)) 상쇄된다 [재구성: 원문은 이 상쇄를 말없이 생략]. 남는 것은 피적분함수의 r 미분 −((2i−1)/2) f′(·)에 앞의 2를 곱한 −(2i−1) f′(·). → 식 (8). [원문 식, 상쇄 논증은 재구성]
17. f=x², 가우시안, N=2…36 계산 결과가 표 II. [원문]

### 4.7 고해상도 거동 (원문 논증과 현대식 보충)

18. 원문 논증 [원문]: 균일분포 입력에서는 균등 간격이 최적이고, 각 구간을 반으로 나누면 D가 1/4이 된다(그림 2·3). 따라서 D = kN^{−2}. 가우시안 최적 양자화기도 N이 크면 각 구간 안에서 p가 거의 일정하므로 같은 반분 논리로 D ≈ kN^{−2}를 기대.
19. 보충 [재구성]: 상수 k는 Panter–Dite(1951)·Bennett(1948)의 점밀도(point density) 근사로 정해진다. 점밀도 λ(x)(∫λ=1)에서 구간 폭 ≈ 1/(Nλ(x)), 구간 내 오차 ≈ 균일 → D ≈ (1/(12N²)) ∫ p(x)/λ(x)² dx. 횔더 부등식으로 최적 λ ∝ p^{1/3}, 최소값
    D ≈ (1/(12N²)) (∫ p^{1/3} dx)³.
    가우시안 N(0,σ²): ∫p^{1/3} = (2πσ²)^{−1/6} · √(2π·3σ²) 이므로 (∫p^{1/3})³ = 6√3 πσ², D ≈ (√3 π/2) σ² N^{−2} ≈ 2.721 σ² N^{−2}.
20. 표 I과 대조: N²D = 1.880 (N=4), 2.211 (8), 2.431 (16), 2.559 (32), 2.573 (36). 2.721로 천천히 올라간다. 원문의 N=36 접선 기울기 −1.96이 −2에 가까워지는 것과 일치.

### 5.1 가우시안 (σ = 1), 원문 표 I에서

| N | MSE (최적) | 엔트로피 (bit) | log₂N | MSE (최적 등간격, 표 II) | 등간격 간격 |
|---|---|---|---|---|---|
| 1 | 1.000 | 0 | 0 | 1.000 | — |
| 2 | 0.3634 | 1.000 | 1 | 0.3634 | 1.596 |
| 3 | 0.1902 | 1.536 | 1.585 | 0.1902 | 1.224 |
| 4 | 0.1175 | 1.911 | 2 | 0.1188 | 0.9957 |
| 8 | 0.03454 | 2.825 | 3 | 0.03744 | 0.5860 |
| 16 | 0.009497 | 3.765 | 4 | 0.01154 | 0.3352 |
| 32 | 0.002499 | 4.730 | 5 | 0.003490 | 0.1881 |
| 36 | 0.001985 | 4.895 | 5.170 | 0.002843 | 0.1703 |

- 닫힌 식: N=2이면 y = ±√(2/π) = ±0.7979, D = 1 − 2/π = 0.3634 (중심 조건과 E[X²]−E[Y²]로 바로 나옴 [재구성: D 값은 원문 표와 일치]).
- 최적 양자화기에서 D = σ² − E[y²] (중심 조건의 결과로 오차가 출력과 직교, [재구성]). 예: N=2, E[y²] = 2/π.
- N ≤ 3에서는 최적 = 최적 등간격(대칭 3준위 이하에서는 자유도가 같음). N이 커지면 등간격 손해 비율이 커진다: N=36에서 0.002843/0.001985 = 1.43 (약 1.56 dB).

### 5.2 균일분포 입력

- p가 [−a, a] 균일이면 중심·중점 조건의 해는 정확히 균등 간격 Δ = 2a/N, D = Δ²/12 = a²/(3N²) = σ²/N² (σ² = a²/3). 원문의 "k는 분포의 분산" 서술과 일치. [원문 서술 + 재구성 식]

### 5.3 고정율 Max 양자화기와 디더 엔트로피 부호화의 비교 [재구성 수치]

같은 MSE D에서, Max 양자화기의 출력 엔트로피(표 I)와 감산 디더 균일 양자화기의 조건부 엔트로피 H(Q|Z) = h(X+N) − log₂Δ (Zamir–Feder 1992 Thm 1, Δ = √(12D))를 수치 적분으로 비교:

| N | D | log₂N (고정율) | Max 엔트로피 | 디더 ECSQ H(Q|Z) | R(D) = ½log₂(1/D) |
|---|---|---|---|---|---|
| 4 | 0.1175 | 2 | 1.911 | 1.879 | 1.545 |
| 8 | 0.03454 | 3 | 2.825 | 2.707 | 2.428 |
| 16 | 0.009497 | 4 | 3.765 | 3.621 | 3.359 |
| 36 | 0.001985 | 5.170 | 4.895 | 4.744 | 4.488 |

고해상도에서 디더 ECSQ − R(D) → 0.254 bit이고, Max 고정율은 log₂N − R(D) = ½log₂(N²D) → ½log₂(√3π/2) = ½log₂(2.721) = 0.722 bit. 즉 고정율 최적은 0.72 bit, 엔트로피 부호화 균일은 0.254 bit의 손실.

## 6. 원문과의 차이·빈틈

- 정리 번호 없음. 필요조건만 엄밀(미분 가능성, 내부점 가정 아래)하고, 충분조건·유일성은 "헤세 행렬이 양정치이면"으로만 언급.
- 식 (2)의 적분 기호 아래 미분 정당화 생략.
- 사격법의 수렴·단조성 증명 없음. "체계화할 수 있다"는 서술만 있음.
- D의 정의가 본문 앞에서는 E[f(s_in − s_out)], 식 (7) 앞에서는 E[f(s_out − s_in)]로 부호가 바뀐다. f가 우함수라 무해.
- 고해상도 D = kN^{−2}는 발견적 논증. 상수 k(= √3π/2 ≈ 2.72, 가우시안)는 원문에 없음.
- 엔트로피는 표에만 있고, 엔트로피 제약 하 최적화(ECSQ)는 다루지 않음. 고정율(준위 수) 문제다.

## 7. 본 연구와의 연결

- 본 연구 설정: K명 작업자 X_k ~ N(0,σ²) 독립, Q_k = f_k(X_k, W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만 계산, 복호기 Ŝ = g(Z, W), D̄ = E(S−Ŝ)²/(Kσ²).
- Max 양자화기는 비균등 간격이라 Q_k의 정수 덧셈이 "준위의 합"에 대응하지 않는다. 합 S를 ΣQ_k로 복원하려면 각 Q_k가 X_k에 대해 아핀(눈금 Δ의 정수 배)이어야 하므로, 합 호환 인코더는 사실상 균등 격자에 묶인다. 즉 Max 최적 비균등 양자화는 스위치 덧셈과 양립하지 않으며, 본 연구의 기준선으로는 "합 호환 제약 없음" 쪽(작업자별로 복호한 뒤 더하는 경우)의 고정율 벤치마크 역할만 한다. [재구성: 본 연구 해석]
- 정리 B와의 대비: 고정율 log₂M을 쓰면 Max식 최적도 고해상도에서 R(D) 대비 ½log₂(√3π/2) ≈ 0.72 bit 손실(가우시안), 균등 등간격은 넘침 여유 때문에 더 나쁘다(표 II, ln N 꼴 추가 손실 [미확인: 정확한 점근식은 Hui–Neuhoff 2001, 본 논문에 없음]). 정리 B의 0.254는 엔트로피 부호화를 전제한 상수이고 고정 레지스터 폭에는 적용되지 않는다는 주의가 이 표로 수치화된다.
- 보조정리 L과의 관계: 없음(디더 없음, 오차가 입력의 결정적 함수). Max의 중심 조건은 오차가 출력과 직교함(E[(X−y)y]=0)만 주고, 입력과의 독립은 주지 않는다.
- 상수 0.254의 출처: 본 논문 아님.
