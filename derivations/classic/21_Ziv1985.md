# Ziv 1985 — 보편 양자화 (On Universal Quantization)

## 1. 서지

- J. Ziv, "On Universal Quantization," *IEEE Transactions on Information Theory*, vol. IT-31, no. 3, pp. 344–347, May 1985. (원고 접수 1982-10-28, 수정 1984-01-12)
- 원문 파일: `papers/classic/21_Ziv1985.pdf` (4쪽). 2–4쪽(원문 345–347쪽)은 쪽 이미지로 식을 직접 대조했다.
- 번호 붙은 결과: Theorem 1, Lemma 1 (부록), Lemma 2 (부록, E. N. Gilbert에게 돌림). 식 (1)–(14).

## 2. 문제 설정 (원문 기호)

- 소스: Rⁿ 위 임의 확률측도를 갖는 n-벡터 X = (x_1, …, x_n). 정상성(stationarity)은 극한 진술에서만 가정.
- n차원 양자화기 Q: Rⁿ → Rⁿ, 부호점(code point) 집합 C, 유일 복호 가능(u.d., uniquely decipherable) 가변 길이 부호 B_n.
- 평균제곱오차 ε_Q = (1/n) E‖Q(X) − X‖² (식 (1)).
- H_n(ε): MSE ≤ ε를 만족하는 모든 n차원 양자화기에 대한 표본당 출력 엔트로피의 최솟값(최적 엔트로피 제약 벡터 양자화기, ECVQ). 식 (2)–(4b): 최소 평균 부호 길이와 H_n(ε)은 1/n 이내. 정상 소스에서 R(ε) = lim H_n(ε) (식 (5), 원문은 Gallager [1, (3.5.3-c)] 인용).
- 스칼라 균일 양자화기 Q_1: 부호점 C_1 = {0, ±2√(3ε), ±4√(3ε), …}, 곧 눈금 Δ = 2√(3ε) (ε = Δ²/12).
- 디더: Z ~ U[−√(3ε), √(3ε)] = U[−Δ/2, Δ/2], X와 독립. **Z = (Z, Z, …, Z)**, 곧 하나의 스칼라 확률변수를 n번 반복한다.
- 표현: X를 Q_1(X + Z) − Z로 나타낸다(감산 디더). 율 척도: H(Q_1(X + Z) | Z) (표본당, 복호기가 Z를 앎).
- 격자 확장: K-차원 격자 L_K, 보로노이 영역(Voronoi region), 정규화 2차 모멘트 G_K (식 (5) 근처, G_1 = 1/12).

## 3. 주 결과 진술 (원문 대조함)

- **Lemma 1** (부록): |X_i| ≤ B (유한 B)이면 임의의 X에 대해 (1/n)E(Q_1(X+Z) − X − Z) = 0, (1/n)E‖Q_1(X+Z) − X − Z‖² = ε. (기댓값은 Z에 대한 것.)
  - 원문은 Lemma 1의 진술을 "(1/n)E(Q_1(X+Z) − X − Z) = 0"으로 쓰는데, 문맥상 성분별 E(q_i − x_i − Z_i) = 0이다.
- **Lemma 2** (부록, 식 (13)): 이산 확률변수 K와 λ > 0에 대해
  −Σ_K P(K|a,t) log₂ P(K|a,t) ≤ log₂ β(a+t) + (λ/ln 2) Σ_K P(K|a,t)(K − a − t)², β(a+t) = Σ_K e^{−λ(K−a−t)²}.
- **Theorem 1**: 임의의 확률적 n-벡터 소스에 대해
  H(Q_1(X + Z) | Z) ≤ H_n(ε) + 0.754 bit/표본,
  그리고 정상 소스에 대해 lim_{n→∞} H(Q_1(X+Z) | Z) ≤ R(ε) + 0.754 bit/표본.
  - 식 (12): 상수는 ½log₂(2πe·(1/6)) = ½log₂(4πeG_1) = 0.754.
- 1절 서술 (정리 아님, 증명 없음):
  - Gish–Pierce를 일반화하면 "매끄러운" 무기억 밀도에서 K차원 (결정적) 격자 양자화기의 엔트로피 H^K(ε)가 R(ε) ≤ H^K(ε) ≤ R(ε) + μ_K(ε), lim_{ε→0} μ_K(ε) = ½log₂(2πeG_K). 특히 G_1 = 1/12에서 **lim μ_1(ε) = ½log₂(2πe/12) = 0.254 bit/표본**. ("it is easy to show"로만 언급.)
  - 복호기가 Z를 모르면 0.754가 1.55 bit/표본으로 바뀐다(이때 Z는 {−√ε, √ε}에 균등, C_1 = {0, ±2√ε, …}).
  - 무작위화 K차원 격자 양자화기: H(Q_K(X+Z) | Z) ≤ H_n(ε) + ½log₂(4πeG_K). G_K ≈ 1/(2πe)이면 + 0.5 bit.
  - 개별 수열(확률 모형 없음)에도 |X_i| ≤ B이면 비슷한 결과(Ziv–Lempel [2]).

## 4. 유도

### 4.1 Lemma 1 (오차의 1·2차 모멘트가 입력과 무관)

1. q_i = Q_1(x_i + Z). y = x_i + Z는 [x_i − Δ/2, x_i + Δ/2] 위 균일(Z가 균일이므로). [원문]
2. E(q_i − x_i − Z) = (1/Δ) ∫_{x_i−Δ/2}^{x_i+Δ/2} (q(y) − y) dy. 길이 Δ인 구간은 양자화 셀 하나의 길이와 같으므로, 구간을 "첫 셀의 끝까지"와 "다음 셀의 시작부터"로 나누고 뒤쪽을 Δ만큼 평행이동하면 하나의 완전한 셀 [q(y_min) − Δ/2, q(y_min) + Δ/2] 위 적분이 된다(q(y + Δ) = q(y) + Δ 이용). [원문: 위끝·아래끝 분할 계산]
3. 완전한 셀 위에서 (1/Δ)∫ (q − y) dy = 0, (1/Δ)∫ (q − y)² dy = Δ²/12 = ε. [원문]
4. 따라서 성분별 조건부 평균 0, 조건부 MSE ε, 임의의 x_i에 대해. [원문]
   - 보충 [재구성]: 이것은 Schuchman 1964 결과의 특수한 경우다(오차 q_i − x_i − Z 자체가 x_i와 독립인 U[−Δ/2, Δ/2]). Ziv는 1·2차 모멘트만 쓴다. |X_i| ≤ B 가정은 증명에 실제로 쓰이지 않는다 (무한 양자화기이므로).

### 4.2 Theorem 1의 증명 골격

5. Q_n^opt: MSE ≤ ε로 H_n(ε)를 달성하는 최적 n차원 양자화기. 엔트로피의 연쇄 법칙:
   H(Q_1(X+Z) | Z) ≤ H(Q_1(X+Z), Q_n^opt(X) | Z) = H(Q_n^opt(X)) + H(Q_1(X+Z) | Q_n^opt(X), Z) = H_n(ε) + H(Q_1(X+Z) | Q_n^opt(X), Z). [원문]
   (Q_n^opt(X)는 Z와 독립이므로 H(Q_n^opt(X)|Z) = H(Q_n^opt(X)).)
6. 오차 분해 (식 (6)): Q_1(X+Z) − Z − Q_n^opt(X) = [Q_1(X+Z) − Z − X] − [Q_n^opt(X) − X]. [원문]
7. 교차항 소거 (식 (7)): Lemma 1에서 X가 주어졌을 때 E[Q_1(X+Z) − Z − X | X] = 0이고 Q_n^opt(X) − X는 X의 함수이므로 교차항의 기댓값이 0. 따라서 E‖Q_1(X+Z) − Z − Q_n^opt(X)‖² = E‖Q_1(X+Z)−Z−X‖² + E‖Q_n^opt(X)−X‖². [원문]
8. 식 (8): (1/n)E‖…‖² ≤ ε + ε = 2ε. [원문]
9. 식 (9): 조건부 엔트로피의 부분가법성(subadditivity)과 "조건을 늘리면 엔트로피가 줄지 않음"의 반대 방향(조건을 줄이면 증가)을 써서
   H(Q_1(X+Z) | Q_n^opt(X), Z) ≤ (1/n) Σ_i H(q_i | b_i, Z) (표본당), Q_n^opt(X) = (b_1, …, b_n). [원문; 표본당 정규화 표기는 원문을 따름]
   - 보충 [재구성]: 정확히는 H(q_1…q_n | b_1…b_n, Z) ≤ Σ_i H(q_i | b_1…b_n, Z) ≤ Σ_i H(q_i | b_i, Z). 그리고 제약은 평균 (1/n)E Σ(q_i − Z − b_i)² ≤ 2ε뿐이다.
10. 정규화 (식 (10)): Z, q_i, b_i를 Δ = 2√(3ε)로 나눈다. K_i = q_i/Δ ∈ ℤ, t = Z/Δ ~ U[−½, ½], a_i = b_i/Δ (실수). 제약은 E (1/n)Σ (K_i − a_i − t)² ≤ 2ε/Δ² = 2ε/(12ε) = 1/6. [원문]
    - 주의 [재구성]: H(q_i | b_i, Z) = H(K_i | a_i, t)인데, 원문은 이것을 "a_i, t가 주어졌을 때 K_i의 조건부 엔트로피"로 쓰고 기댓값을 a_i·t에 대해 취한다.

### 4.3 Lemma 2 (가우시안형 비교 분포로 이산 엔트로피 상한)

11. q(K|a,t) := e^{−λ(K−a−t)²}/β(a+t)는 정수 K 위의 확률분포(합 1). [원문]
12. 깁스 부등식(Gibbs inequality, 로그 합 부등식): −Σ P log P ≤ −Σ P log q. 원문은 로그의 오목성으로 Σ P log(q/P) ≤ log Σ q = 0을 씀. [원문]
13. −Σ P log₂ q = log₂ β(a+t) + (λ/ln 2) Σ P (K − a − t)². → 식 (13)–(14). [원문]

### 4.4 상수 0.754의 계산 (식 (11)–(12))

14. 식 (13)을 각 i에 적용하고 a_i, t에 대해 평균, 그리고 로그의 오목성(옌센 부등식, Jensen)으로 평균을 log 안으로 넣는다:
    (1/n)Σ H(K_i | a_i, t) ≤ log₂ [(1/n) Σ E β(a_i + t)] + (λ/ln 2)·(1/6). [원문]
15. 핵심 계산: t ~ U[−½, ½]이면 a에 상관없이
    E_t β(a + t) = Σ_K ∫_{−½}^{½} e^{−λ(K − a − t)²} dt = ∫_{−∞}^{∞} e^{−λs²} ds = √(π/λ).
    (정수 평행이동의 합과 단위 구간 적분이 실수 전체 적분을 이룬다 — 디더가 하는 일의 본질.) [원문]
16. 식 (11): (1/n)Σ H(K_i|a_i,t) ≤ log₂ √(π/λ) + λ/(6 ln 2). [원문]
17. λ에 대해 최소화: d/dλ [½log₂(π/λ) + λ/(6 ln 2)] = −1/(2λ ln 2) + 1/(6 ln 2) = 0 ⇒ λ = 3. [원문 "for λ = 3", 미분은 재구성]
18. 값: ½log₂(π/3) + 3/(6 ln 2) = ½log₂(π/3) + ½log₂ e = ½log₂(πe/3) = ½log₂(2πe·(1/6)) = ½log₂(4πe/12) = ½log₂(4πeG_1). 수치 0.75461 bit. [원문 식 (12); 수치 재계산함]
19. 해석 [재구성]: 정수값 확률변수가 MSE ≤ 1/6로 실수 a + t를 근사하면, 그 엔트로피는 분산 1/6 가우시안의 미분 엔트로피 ½log₂(2πe/6)를 넘지 않는다는 이산판 최대 엔트로피 논법이다. 1/6 = 2 × 1/12에서 "2"는 식 (8)의 두 오차(디더 양자화 ε + 최적 양자화 ε)의 합에서 온다. 그래서 0.754 = ½log₂(2πe·2/12) = 0.254 + 0.5.

### 4.5 극한 진술

20. 정상 소스에서 H_n(ε) → R(ε)이므로 lim H(Q_1(X+Z)|Z) ≤ R(ε) + 0.754. [원문]
    - 빈틈 [재구성]: R(ε)는 MSE ε의 율-왜곡 함수이고 디더 양자화기의 MSE도 ε이므로 같은 왜곡에서 비교한다. 단 Ziv의 비교 대상은 1차적으로 H_n(ε)(최적 ECVQ)이고, R(ε)와의 비교는 극한을 통해서만 얻는다. 유한 n에서 R과 직접 비교하는 것은 Zamir–Feder 1992 Thm 2다.

### 4.6 원문이 증명 없이 언급한 수치

21. 0.254: 원문 345쪽 왼쪽 단, "Gish–Pierce [6]의 결과를 일반화하면 쉽게 보일 수 있다"며 **결정적** K차원 격자 양자화기, 매끄러운 무기억 밀도, ε → 0에서 lim μ_K(ε) = ½log₂(2πeG_K), K = 1에서 0.254. Ziv의 정리가 아니고 증명도 없다. [원문 서술 확인, 증명은 원문에 없음]
    - 현대식 유도 [재구성]: 고해상도에서 H(Q(X)) ≈ h(X) − log₂Δ (셀 안 밀도 ≈ 상수), MSE = Δ²/12 = ε. 섀넌 하한(Shannon lower bound) R(ε) ≥ h(X) − ½log₂(2πeε)이고 ε → 0에서 등호에 접근하므로 H − R → ½log₂(2πeε) − log₂Δ = ½log₂(2πeΔ²/12) − ½log₂Δ² = ½log₂(2πe/12).
22. 1.55 bit (복호기가 Z 모름): 증명·식 없음. 이때 Z는 이진 {±√ε}이고 눈금은 2√ε로 바뀐다는 서술뿐. [미확인: 값의 유도 경로를 원문에서 찾지 못함]
23. 격자판 ½log₂(4πeG_K): 같은 증명에서 1/6 대신 2G_K를 쓰면 나온다고 읽힌다 [재구성 추정, 원문은 증명 없음].

## 5. 예제

### 5.1 균일분포 소스 (Gish–Pierce 언급)

- X ~ U[0, A], Δ가 A를 나누고 디더 없는 결정적 양자화: H = log₂(A/Δ), MSE = Δ²/12, R(ε) ≥ h(X) − ½log₂(2πeε) = log₂A − ½log₂(2πeΔ²/12). 차이 ≤ ½log₂(2πe/12) = 0.254, 모든 해상도에서. (원문: "입력 밀도가 균일임을 알면 Gish–Pierce 한계가 모든 왜곡에서 성립") [원문 서술 + 재구성 식]

### 5.2 가우시안 소스 N(0, σ²)

- R(ε) = ½log₂(σ²/ε) (ε < σ²).
- Theorem 1의 상한: H(Q_1(X+Z)|Z) ≤ R(ε) + 0.754 (정상 i.i.d. 극한).
- 실제 값 (Zamir–Feder Thm 1로 계산, 수치 적분, σ = 1): ε = 0.01 → 3.584 bit, R = 3.322, 차이 0.262. ε = 0.1 → 1.984, R = 1.661, 차이 0.323. ε = 1 → 0.751, R = 0, 차이 0.751(최대). 즉 가우시안에서 Ziv 상한 0.754는 저해상도 ε ≈ σ²에서 거의 빡빡하고, 고해상도에서는 0.254로 내려간다. [재구성 수치]

## 6. 원문과의 차이·빈틈

- 디더 실현이 "하나의 Z를 n번 반복"이다. Zamir–Feder 1992는 성분별 독립 디더를 쓰고, 상수 상한·고해상도 표현은 두 실현에서 같다고 말한다.
- 식 (9)의 표본당 정규화와 조건 축소 단계가 압축되어 있다.
- 비교 기준이 H_n(ε)이다. R(ε)와의 차이(잉여율, redundancy)는 정상 소스 극한에서만.
- 0.254, 1.55, 격자판 상한은 서술만 있고 증명이 없다.
- Lemma 1의 |X_i| ≤ B 가정은 불필요해 보인다(무한 양자화기).
- 편집상: Lemma 1 증명 첫 줄에 "Q_1(X = Z)" 오식(X + Z).

## 7. 본 연구와의 연결

본 연구: X_k ~ N(0, σ²) 독립, Q_k = f_k(X_k, W) ∈ ℤ_M, Z = ΣQ_k mod M, Ŝ = g(Z, W), D̄ = E(S − Ŝ)²/(Kσ²). 정리 B: 감산 디더 균일 양자화, Δ² = 12D/K, H(Z) ≈ ½log₂(K/D̄) + ½log₂(2πe/12).

### 7.1 0.754와 0.254의 출처 확정

- **0.754**: 이 논문 Theorem 1이 원전이다(비교 대상: 최적 n차원 ECVQ H_n(ε), 정상 극한에서 R(ε)). Zamir–Feder 1992 Thm 2는 같은 수치를 R(ε) 대비 엄격한 부등식(< 0.754)으로 강화하고, 실제 최댓값을 제약 용량 C로 특성화한다.
- **0.254**: 이 논문에 수치가 **처음 등장**하지만, 지위는 "결정적 균일 양자화기, 매끄러운 밀도, ε → 0"에 대한 Gish–Pierce(1968) 결과의 인용·일반화이며 증명 없음. 디더 양자화기에 대해 증명된 정리로서의 출처는 **Zamir–Feder 1992 Theorem 3 (식 (36), 고해상도 극한 (13)·(44))**다. 정리 B의 상수는 Zamir–Feder Thm 1의 정확한 식 H(Q|Z) = h(X + N) − log₂Δ를 가우시안에 대입하고 R(D)를 빼서 얻으므로, 정리 B의 "+0.254"는 Zamir–Feder Thm 1 + Thm 3(가우시안에서는 섀넌 하한이 정확하여 Thm 3이 등식)의 논법을 K개 출력의 합 T = ΣQ_k로 확장해 얻는다고 인용해야 한다. Zamir–Feder는 합의 엔트로피를 직접 다루지 않으므로 확장 단계는 본 연구의 몫이다(Zamir–Feder 문서 7.2–7.3절).

### 7.2 Theorem 1의 논법이 본 연구에 주는 것

- 식 (15)의 계산 E_t β(a + t) = √(π/λ)는 "디더 t가 균일하면 정수 격자 위 합이 연속 적분으로 바뀐다"는 사실이다. 본 연구 보조정리 L의 정확값 계산(Schuchman 문서 7.3절, 어윈–홀 엔트로피)도 같은 장치를 쓴다.
- Lemma 2(가우시안형 비교 분포로 정수값 변수의 엔트로피 상한)는 H(Z|W) **상한** 쪽 도구로 바로 쓸 수 있다: 정수 T = ΣQ_k가 실수 (S + Σd_k)/Δ를 MSE m으로 근사하면 H(T | ·) ≤ ½log₂(2πe·m) + (Jensen 손실). 정리 B의 달성 쪽 상한 증명에 대안 경로가 된다 [재구성].
- 하한(정리 A, 보조정리 L) 쪽으로는 이 논문이 직접 주는 것이 없다. Theorem 1은 상한 정리다.

### 7.3 디더 실현의 차이

- Ziv의 디더는 n 좌표에 공통인 스칼라 하나다. 본 연구에서 K 작업자가 같은 스칼라 디더 d를 쓰면 e_k = e(X_k, d)들은 개별적으로는 균일·입력 독립이지만 서로 종속이다(모두 같은 d의 함수). [재구성]
  - 교차 모멘트: X_i, X_j가 d와 독립이고 서로 독립이므로 E[e_i e_j] = E_d[g(d)²], g(d) := E_X[e(X, d)]. 가우시안 X에서 g(d)는 Schuchman 문서 4.6절의 급수에서 Φ_d를 Φ_X로 바꾼 것이라 크기가 (Δ/π)e^{−2π²σ²/Δ²} 차수다. 따라서 Var(Σe_k) = KΔ²/12 + K(K−1)E[g²] ≈ KΔ²/12이고 Δ² = 12D/K는 근사적으로 유지된다.
  - 그러나 Σe_k의 분포는 어윈–홀이 아니며, 정확한 독립·분포 계산(보조정리 L의 정확값 포함)이 깨진다. 정리 B와 보조정리 L은 작업자별 독립 디더 성분 d_k를 쓰는 것이 깔끔하다.

### 7.4 고정 레지스터 폭 주의

- Theorem 1과 0.254는 모두 **엔트로피**(가변 길이 무잡음 부호)에 대한 진술이다. 스위치가 고정 폭 log₂M 레지스터로 mod 덧셈을 하면 엔트로피 부호화를 할 수 없고(합 호환을 깨므로), 율은 log₂M ≈ ½log₂(K/D̄) + log₂(2t/√12)로 넘침 여유 상수가 0.254 대신 붙는다(Schuchman 문서 7.2절). 0.254는 "Z를 엔트로피 부호화한다"는 가정에서만 정리 B의 상수다.
