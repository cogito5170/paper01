## 2. 문제 설정 (원문 기호)

대역 제한 가우시안 채널(band-limited AWGN channel)용 부호화 변조(coded modulation)를 하나의 틀로 묶어 분류하는 것이 목표다. 원문 §I.B, 그림 1의 부호기는 세 요소로 이루어진다.

1. **격자(lattice)** Λ: ℝ^N 안의 이산 덧셈군(additive group). 신호점은 Λ의 한 잉여류(coset, 평행 이동) Λ+c의 유한 부분집합에서 고른다.
2. **부분격자(sublattice)** Λ′ ⊂ Λ: Λ′도 N차원 격자. **격자 분할(lattice partition)** Λ/Λ′는 Λ를 |Λ/Λ′|개의 잉여류로 나눈다. |Λ/Λ′|를 **분할의 차수(order)**라 한다(수학에서는 지수 index). 이진 격자면 |Λ/Λ′| = 2^{k+r}.
3. **이진 부호기(binary encoder)** C, 율(rate) k/(k+r): N차원당 k 비트를 받아 k+r 개의 부호 비트를 내고, 이 비트가 Λ/Λ′의 잉여류 하나를 고른다. 중복도(redundancy) r(C)=r 비트/N차원, 2차원당 정규화 중복도 ρ(C)=2r(C)/N.

**잉여류 부호(coset code)** 𝐂(Λ/Λ′; C): C의 부호 비트열이 지정할 수 있는 Λ′ 잉여류 열 안에 놓인 모든 신호점 열의 집합(§I.B). C가 블록 부호면 **격자 부호(lattice code)**, 길쌈 부호(convolutional code)면 **트렐리스 부호(trellis code)**다.

일반형(§I.C): S가 거리가 주어진 군(group), T가 S의 부분군이고 몫군(quotient group) S/T의 차수가 유한하면, S/T의 잉여류 열을 고르는 부호 C로 𝐂(S/T; C)를 정의할 수 있다. 예: S가 이진 블록 부호이고 T가 부분부호, m-PSK의 단위근 군과 그 부분군.

**이 노트가 세는 양**: 비트 율이 아니다. 기하 모수(geometric parameter)인 최소 제곱 거리(minimum squared distance) d²_min, 기본 부피(fundamental volume) V, **기본 부호화 이득(fundamental coding gain)** γ, 오류 계수(error coefficient) N₀, 복호 복잡도 N_D, 성상 확장 인자(constellation expansion factor) 2^ρ를 센다.

## 4. 유도

### 4.1 잉여류 분해와 군 구조 [원문 §II.B + 재구성]

**정의.** Λ′ ⊂ Λ가 부분군이면, x ~ y ⇔ x−y ∈ Λ′는 동치 관계다. 동치류가 잉여류 Λ′+c다. [원문]

**몫군.** 잉여류끼리 (Λ′+a)+(Λ′+b) := Λ′+(a+b)로 더하면 잘 정의된다. a′ = a+λ₁, b′ = b+λ₂ (λᵢ∈Λ′)이면 a′+b′ = a+b+(λ₁+λ₂)이고 λ₁+λ₂ ∈ Λ′이기 때문이다. 원문은 "동치류는 Λ′를 법으로 더할 수 있고 몫군 Λ/Λ′를 이룬다"고만 쓴다. [원문 서술, 증명은 재구성]

**잉여류 대표계(system of coset representatives)** [Λ/Λ′]: 각 동치류에서 하나씩 고른 집합. 모든 λ∈Λ는 λ = λ′ + c (λ′∈Λ′, c∈[Λ/Λ′])로 **유일하게** 쓰인다. 이를 Λ = Λ′ + [Λ/Λ′]로 쓴다. [원문]

**예 (원문).** ℤ/mℤ: 대표계 {0,…,m−1}, n = am + c로 유일하게 쓰이고 [ℤ/mℤ]는 사실상 정수환 ℤ_m이다. ℤ^N/mℤ^N의 차수는 m^N, 대표계 [ℤ/mℤ]^N. ℤ²/Rℤ²는 차수 2이고 대표계는 {(0,0),(1,0)}이다. 여기서 R은 2×2 회전 행렬 [[1,1],[1,−1]]로, 45° 회전과 √2배 확대를 겸하며 R² = 2I이다.

**분할 사슬(partition chain).** Λ ⊇ Λ′ ⊇ Λ″ ⊇ …이면 Λ = Λ″ + [Λ′/Λ″] + [Λ/Λ′]이다. ℤ/2ℤ/4ℤ/…은 표준 이진 표현 m = a₀ + 2a₁ + 4a₂ + …을 준다. 여기서 a₀가 ℤ/2ℤ의 잉여류를, 2a₁이 2ℤ/4ℤ의 잉여류를 정한다(그림 5b). [원문]

**[재구성] 주의: 사슬 분해는 군 동형이 아니다.** ℤ/4ℤ = [2ℤ/4ℤ] + [ℤ/2ℤ]에서 라벨 (a₀,a₁)를 비트 XOR로 더하면 ℤ₄ 덧셈과 맞지 않는다. 1+1 = 2이면 라벨은 (1,0)⊕(1,0) = (0,0)이 되어야 하지만 실제로는 (0,1)이 된다(자리올림 carry). 원문 §IV.C도 같은 점을 말한다. ℤ/4ℤ의 2비트 표준 이진 라벨링은 "정규(regular)"이지만 "선형"이라고는 하지 않는다. 몫군 ℤ/4ℤ ≅ ℤ₄는 순환군이고 (ℤ₂)²가 아니다. mod-2 격자 분할(2Λ ⊂ Λ′)에서만 몫군의 모든 원소가 위수 2를 가지므로 Λ/Λ′ ≅ (ℤ₂)^K이고, 라벨 XOR = 잉여류 덧셈이 된다.

### 4.2 Lemma 1: 부피와 차수 [원문 §II.C]

**주장.** V(Λ′) = |Λ/Λ′|·V(Λ).

**증명.** [원문 스케치를 따름]
1. 기본 영역(fundamental region) R(Λ)는 ℝ^N/Λ의 각 동치류에서 정확히 한 점을 담는 영역이다. 그래서 ℝ^N = Λ + R(Λ)(공간의 쪽매맞춤 tessellation)이다. 모든 기본 영역은 Λ를 법으로 합동이므로 부피가 같고, 그 값이 V(Λ)다.
2. ℝ^N = Λ′ + [Λ/Λ′] + R(Λ). 따라서 ∪_{c∈[Λ/Λ′]} (R(Λ)+c)는 Λ′의 기본 영역이다.
3. 이 합집합은 서로 겹치지 않는 |Λ/Λ′|개 조각이므로 V(Λ′) = |Λ/Λ′|V(Λ). ∎

**따름정리.** Λ ⊂ ℤ^N이면 V(ℤ^N)=1이므로 V(Λ) = |ℤ^N/Λ|. 이진 격자에서는 V(Λ) = 2^{r(Λ)}이다. [원문]

원문의 덧붙임: Λ가 격자가 아니어도 Λ′ 잉여류 |Λ/Λ′|개의 합집합이기만 하면 점 밀도는 Λ′의 |Λ/Λ′|배다. 트렐리스 부호의 기본 부피(§4.6)는 이 사실을 쓴다. [원문]

### 4.3 기본 부호화 이득 γ와 그 해석 [원문 §II.C, §II.E]

**정의.** γ(Λ) = d²_min(Λ) / V(Λ)^{2/N}.

**불변성** [원문 b–d, 각 줄 검산은 재구성]
- 크기 조절: d²_min(rΛ) = r²d²_min, V(rΛ) = r^N V ⇒ V^{2/N}이 r²배 ⇒ γ 불변.
- 크기 조절된 직교 변환 T: d²_min(TΛ) = |det T|^{2/N} d²_min, V(TΛ) = |det T|V ⇒ 불변.
- 데카르트 곱 Λ^M: d²_min은 그대로이고 V(Λ^M) = V(Λ)^M ⇒ (V^M)^{2/(MN)} = V^{2/N} ⇒ 불변.
- 따라서 γ(ℤ^N)=1이다. "부호 없는 시스템(uncoded system)"은 ℤ^N 기반 성상(PAM, QAM)으로 정의된다.

**전력 이득 해석** [원문 f]. Λ에서 2^n개 점을 구 안에 고르면 그 구의 부피는 약 2^n V(Λ)이고, ℤ^N에서 고르면 약 2^n이다. 반지름 비는 V(Λ)^{1/N}이다. d²_min(Λ)=1로 맞추면 최소 거리는 ℤ^N과 같고, 평균 전력은 V(Λ)^{2/N} = 1/γ배로 줄어든다. 그래서 γ는 "같은 최소 거리에서 평균 전력 절감 비율"이고 dB로 표시한다.

**이진 격자 형태** [원문 1131쪽 ✓]. 실차원 2N, V(Λ)=2^{r(Λ)}, ρ(Λ)=r(Λ)/N(2차원당)이면
  V(Λ)^{2/(2N)} = 2^{r(Λ)/N} = 2^{ρ(Λ)} ⇒ **γ(Λ) = 2^{−ρ(Λ)} d²_min(Λ).**
해석: ℤ^{2N} 대비 거리 이득 d²_min을, 성상 확장으로 생기는 전력 비용 2^{ρ} (ρ·3.01 dB)가 일부 상쇄한다.

**깊이·중복도·정보도** [원문 §II.E ✓].
- 이진 격자: 정수 격자이면서 어떤 m에 대해 2^m ℤ^N ⊂ Λ인 것. 이런 최소 m을 2-깊이라 한다. 2-깊이 1이면 mod-2 격자, 2이면 mod-4 격자.
- 복소(가우스 정수 G = ℤ[i], φ = 1+i, |φ|²=2) 표기에서 φ^μ G^N ⊂ Λ인 최소 μ가 깊이다. 2-깊이 m인 실 2N차원 격자의 깊이는 2m 또는 2m−1이다.
- 사슬 G^N/Λ/φ^μG^N에서 |G^N/Λ| = 2^{r(Λ)}, |Λ/φ^μG^N| = 2^{Nμ−r(Λ)} = 2^{k(Λ)}. 정규화하면 μ = ρ + κ (ρ = r/N, κ = k/N)이다.
- 분할 Λ/Λ′에서는 깊이 μ(Λ/Λ′) := μ(Λ′), 중복도 ρ(Λ/Λ′) := ρ(Λ), 정보도 κ(Λ/Λ′) := κ(Λ′)로 정의한다. 그러면 |Λ/Λ′| = 2^{r(Λ′)−r(Λ)} = 2^{N(ρ(Λ′)−ρ(Λ))} = 2^{N(μ(Λ′)−κ(Λ′)−ρ(Λ))}이고, 마지막 꼴이 원문 식이다. [원문 식, 첫 두 등호는 재구성 검산]

### 4.4 Lemma 2: 2방향 사슬과 웅거보크 라벨링 [원문 §II.F; 일반론은 II부, 미확인]

**주장.** |Λ/Λ′| = 2^K이면 Λ = Λ₀ ⊇ Λ₁ ⊇ … ⊇ Λ_K = Λ′이 존재하고, 각 Λ_k/Λ_{k+1}은 2방향 분할이며, Λ = Λ′ + {Σ a_k g_k}, a_k∈{0,1}이다. 이때 {a_k g_k}는 [Λ_k/Λ_{k+1}]의 대표계다.

**증명 (k = K−1부터 0까지 귀납)** [원문 스케치]
1. Λ_{k+1}이 Λ/Λ_{k+1}/Λ′ 사슬을 이루는 이진 격자라 하자. Λ_{k+1} ≠ Λ이면 g_k ∈ Λ \ Λ_{k+1} 중 Λ_{k+1}을 법으로 위수 2인 원소, 즉 g_k+g_k ∈ Λ_{k+1}인 원소가 있다. 이 존재성은 II부에 있다. [미확인]
2. Λ_k := Λ_{k+1} ∪ (Λ_{k+1}+g_k)는 덧셈에 닫혀 있다. 2g_k ∈ Λ_{k+1}이기 때문이다. 그래서 Λ_k는 격자이고 Λ_k/Λ_{k+1}은 2방향 분할이다.
3. 귀납하면 2^{K−k}개의 이진 선형 결합 {Σ_{j≥k} a_j g_j}가 [Λ_k/Λ′]의 대표계가 된다. ∎

**결과: 웅거보크 거리 한계(Ungerboeck distance bound).** 앞 k 비트가 같은 라벨의 두 점은 같은 Λ_k 잉여류에 있으므로 거리² ≥ d²_min(Λ_k)이다. [원문]

**[재구성] 선형성에 관한 주의.** Σ a_k g_k는 정수 계수 결합이다. 라벨 a ⊕ a′(비트 XOR)와 Σ(a_k+a′_k)g_k가 Λ′를 법으로 같으려면 2g_k ∈ Λ′여야 한다. 2-depth 1인 mod-2 Λ′면 이 조건이 자동으로 성립한다. 일반적으로는 2g_k ∈ Λ_{k+1}만 보장되고 Λ′에 속한다는 보장은 없다. 그래서 원문은 "웅거보크 라벨링이면 Λ′를 법으로 선형"이라고 쓰지만(§IV.C 괄호), 엄밀히는 mod-2 분할에서만 XOR-선형이다. 원문 문장 "(recall that if c(a) is an Ungerboeck labeling, it is linear modulo Λ′)"는 Lemma 6 맥락, 즉 Λ′가 mod-2인 경우에 붙어 있다.

### 4.5 Lemma 3 (구성 A): mod-2 격자 ⇔ 선형 이진 부호 [원문 §II.G]

**주장.** Λ가 mod-2 이진 격자 ⇔ Λ = {x ∈ ℤ^N : x mod 2 ∈ C} = 2ℤ^N + C (C: 선형 (N,K) 이진 부호). r(Λ) = N−K, d²_min(Λ) = min[4, d_H(C)].

**증명** [원문]
(⇒) ℤ^N/Λ/2ℤ^N이 사슬이므로 |Λ/2ℤ^N| = 2^K, |ℤ^N/Λ| = 2^{N−K}, 따라서 r = N−K. 2ℤ^N의 잉여류마다 0/1 대표원이 있다. Lemma 2로 Λ = 2ℤ^N + {Σ a_k g_k}이고 g_k는 이진 N-튜플이며 덧셈은 mod 2로 해도 된다. 그러므로 대표계 {c(a) = Σ a_k g_k mod 2}는 선형 (N,K) 부호다.
(⇐) 부호어와 mod 2 합동인 정수 N-튜플 집합은 덧셈에 닫혀 있다. c+c′ mod 2 ∈ C이기 때문이다. 이 집합은 2ℤ^N을 부분격자로 갖는 격자다.
(거리) c ≠ 0이면 잉여류 2ℤ^N + c의 최소 노름(norm, 좌표 제곱합)은 c 자신의 노름, 곧 해밍 무게(Hamming weight)다. 성분 ±1이 최소이기 때문이다. c = 0이면 2ℤ^N의 최소 비영 노름은 4다. 둘 중 작은 값이 d²_min이다. ∎

**선형 라벨링** [원문 ✓]: c(a) = aG (mod 2)이면 c(a⊕a′) = c(a)⊕c(a′). 그래서 mod-2 격자는 "2ℤ^N 잉여류 2^K개를 선형 부호가 고르는 잉여류 부호" 𝐂(ℤ^N/2ℤ^N; C)다.

**예** [원문]: ℤ², Rℤ², 2ℤ² ↔ (2,2,1), (2,1,2), (2,0,∞) 부호. d² = 1, 2, 4. ℤ⁴, D₄, Rℤ⁴, RD₄, 2ℤ⁴ ↔ (4,4,1), (4,3,2), (4,2,2), (4,1,4), (4,0,∞). d² = 1, 2, 2, 4, 4. E₈ = 2ℤ⁸ + (8,4,4) 리드-뮬러(Reed–Muller) 부호: d²=4, r=4, ρ=1, γ = 2^{−1}·4 = 2 (3.01 dB).

### 4.6 트렐리스 부호의 기본 부피와 γ [원문 §IV.B, 이미지 1140쪽 ✓]

1. 𝐂_t: 시각 t 이후에 시작하는 부호열 집합. 시간 불변성 때문에 모두 동형이고 𝐂₁ ⊊ 𝐂₀이다. [원문]
2. 𝐂₀에서 "𝐂₁을 법으로 동치"는 첫 원소 c₀가 같다는 뜻이다. 첫 원소들의 집합 Λ₀ = {λ ∈ Λ′ + c(a₀)}에서 a₀는 영 상태에서 나올 수 있는 출력이고 2^k개다. 그래서 Λ₀는 Λ′ 잉여류 2^k개의 합집합(보통은 격자)이며 **시각 영 격자(time-zero lattice)**라 부른다.
3. Lemma 1(또는 그 덧붙임)로 V(Λ₀) = 2^{−k}V(Λ′)이다. V(Λ′) = 2^{k+r}V(Λ)이므로 V(Λ₀) = 2^r V(Λ)이다.
4. 𝐂₀ = 𝐂₀/𝐂₁ + 𝐂₁/𝐂₂ + … ≅ Λ₀ × Λ₀ × …이므로 V(𝐂) := V(Λ₀)로 정의한다.
5. γ(𝐂) := d²_min(𝐂)/V(𝐂)^{2/N}. V(𝐂) = 2^{−k}V(Λ′) = 2^{r}V(Λ)를 넣으면 γ(𝐂) = 2^{κ(C)} d²_min(𝐂)/V(Λ′)^{2/N} = 2^{−ρ(C)} d²_min(𝐂)/V(Λ)^{2/N}이다(κ(C) = 2k/N, ρ(C) = 2r/N). 원문은 같은 값을 다시 세 가지로 쓴다.
   - γ(𝐂) = 2^{κ(𝐂)}[d²_min(𝐂)/d²_min(Λ′)]·γ(Λ′) (κ(𝐂) = κ(C)+κ(Λ′))
   - γ(𝐂) = 2^{−ρ(𝐂)}[d²_min(𝐂)/d²_min(Λ)]·γ(Λ) (ρ(𝐂) = ρ(C)+ρ(Λ))
   - **γ(𝐂) = 2^{−ρ(𝐂)} d²_min(𝐂)** (이진 격자 기준). 계산에 필요한 것은 d²_min(𝐂)와 ρ(𝐂) 둘뿐이다.
6. d²_min(𝐂) = min[d²_s, d²_min(Λ′)]이다. d²_s는 트렐리스에서 갈라졌다 다시 만나는 두 경로 사이의 최소 거리이고, d²_min(Λ′)는 평행 전이(parallel transition)에서 온다. λ(D)가 부호열이면 λ(D) + λ′D^j (λ′∈Λ′)도 부호열이기 때문이다. [원문]

**예: 4상태 2차원 웅거보크 부호** [원문 §I.B, §IV.A]. Λ/Λ′ = ℤ²/2ℤ²(차수 4), C는 율 1/2 4상태 길쌈 부호이고 r = ρ = 1이다. 라벨 사슬 (2,2)/(2,1)/(2,0)에서 경로 차이의 해밍 거리는 5다(갈라질 때 2, 합칠 때 2, 중간에 1). 그러나 d²_min(2ℤ²) = 4이므로 d²_min(𝐂) = min(5, 4) = 4이고, γ = 2^{−1}·4 = 2 (3.01 dB)이다. 정사각 64점 성상이면 γ_s = 1이므로 γ_tot = γ다.

### 4.7 Lemma 5: 모든 이진 트렐리스 부호는 G^N/φ^μ G^N 위 부호 [원문 ✓]

Λ′의 깊이가 μ면 G^N/Λ/Λ′/φ^μG^N은 사슬이고, 각 차수는 2^{r(Λ)}, 2^{k+r}, 2^{k(Λ′)}, 2^{Nμ}이다. G^N의 φ^μG^N 잉여류는 Nμ 비트로 지정된다. 구성은 영 r(Λ)-튜플(Λ 자신 선택), (k+r)-튜플 a(원래 부호), k(Λ′) "부호 없는 비트"(Λ′ 안의 φ^μG^N 잉여류 선택)다. 이것을 증강 부호기 C′의 출력으로 보면 C′는 정보 비트 k+k(Λ′), 중복 r+r(Λ), 상태 수 2^ν(원래와 같음)인 부호다. 2-깊이 m 버전에서는 ℤ^N/2^mℤ^N 위 율 [Nm − r − r(Λ)]/Nm 부호가 된다. ∎

### 4.8 선형 트렐리스 부호와 Lemma 6 — **부호열의 합이 부호열이 되는 조건** [원문 §IV.C + 재구성]

원문 정의: 𝐂의 임의의 두 부호열 c₁, c₂에 대해 c₁+c₂와 c₁−c₂가 부호열이면 𝐂를 **선형**이라 한다. 원문은 "일반적으로 성립하지 않는다"고 명시한다(§IV.C 첫 문장). 또 §I.C에서는 "이 구성들은 군의 선형성에 거의 의존하지 않으며, 특히 트렐리스 부호는 흔히 선형이 아니다"라고 한다.

선형이면 𝐂는 (무한 차원) 격자이고 Λ^∞/𝐂/(Λ′)^∞이 분할 사슬이 된다. 깊이 μ면 (G^N)^∞/𝐂/(φ^μG^N)^∞도 사슬이다. [원문]

**Lemma 6.** Λ′가 mod-2이고, C가 2^ν상태 율 k/(k+r) 길쌈 부호이며, 라벨링 c(a)가 Λ′를 법으로 선형이면, 𝐂(Λ/Λ′;C) = {mod 2로 C′의 부호어와 합동인 정수 N-튜플 열}이다. 여기서 C′는 2^ν상태 율 [N−r(𝐂)]/N 길쌈 부호이고, r(𝐂) = r + r(Λ), d²_min(𝐂) = min[4, d_H(C′)]이다.

**증명 스케치** [원문]: Lemma 5의 2-깊이 판(m=1)으로 ℤ^N/2ℤ^N 위 증강 부호기 C′를 얻는다. c(a)가 Λ′를 법으로 선형이면 c′(a,a′)도 mod 2로 선형으로 잡을 수 있다. 거리는 Lemma 3과 같다. ∎

**[재구성] 군 덧셈 닫힘의 직접 증명.** 가정을 다음과 같이 둔다.
- (i) 라벨 부호 C는 군이다. 이진 선형 부호면 ⊕에 닫혀 있다.
- (ii) 라벨링은 군 준동형(group homomorphism)이다. c(a⊕b) ≡ c(a)+c(b) (mod Λ′).

x = λ′₁ + c(a), y = λ′₂ + c(b) (λ′ᵢ∈Λ′, a,b∈C)라 하자. 그러면
  x + y = (λ′₁+λ′₂) + c(a) + c(b) ≡ c(a⊕b) (mod Λ′)
이고 a⊕b ∈ C이므로 x+y ∈ 𝐂다. 열(sequence)에 대해서는 시각별로 같은 계산을 하면 된다. 길쌈 부호도 선형이므로 (a⊕b)(D) ∈ C이다. 역원도 같은 방식으로 다룬다. ∎

필요충분에 가까운 조건: (ii)는 "라벨 군 → Λ/Λ′"가 준동형이라는 뜻이다. 라벨 군이 (ℤ₂)^{k+r}인데 Λ/Λ′가 순환군 ℤ₄를 품으면(예: ℤ/4ℤ, 1차원 웅거보크) XOR 라벨로는 준동형을 만들 수 없다. 원문 §IV.C는 이런 경우를 "정규(regular)"로만 분류한다. 정규 라벨링은 거리 분포가 기준 부호열과 무관하다는 성질(거리 불변 distance-invariant)만 보장하고 합 닫힘은 보장하지 않는다.

**정규 라벨링 조건** [원문 §IV.C]: a) 선형(c(a)−c(a′) = c(a⊕a′) mod Λ′; Λ, Λ′가 mod-2이면 항상), b) 웅거보크 라벨링이고 거리 한계가 항상 등호(예: ℤ²/Rℤ²/2ℤ²/2Rℤ²), c) N겹 데카르트 곱의 정규 라벨링(예: G^N/φ³G^N, ℤ^N/4ℤ^N).

### 4.9 형상 이득과 부호화 이득의 분리 [원문 §I.A·I.B + 재구성]

원문 §I.A의 1)은 거리 성질(곧 γ)이 이진 부호기와 부분집합 분할로만 정해지고, 성상 경계 선택(형상)과는 거의 분리된다고 한다. §I.B는 γ_tot = γ(𝐂)·γ_s로 쓴다. γ_s는 "N-입방체의 정규화 2차 모멘트(normalized second moment)를 성상이 담긴 영역의 정규화 2차 모멘트로 나눈 비"와 근사적으로 같다.

**N-구 형상 이득 G_s 유도** [재구성; 원문은 결과만 인용, 출처 [1]].
- 영역 R의 정규화 2차 모멘트는 G(R) = (1/N)∫_R‖x‖²dx / V(R)^{1+2/N}이다.
- 입방체: G = 1/12.
- N-구(N=2n): 부피 V = π^n r^{2n}/n!, ∫‖x‖² = N V r²/(N+2). 따라서 G_sphere = [r²/(N+2)]/V^{2/N} = (n!)^{1/n}/[π(N+2)] = (n!)^{1/n}/[2π(n+1)].
- G_s = (1/12)/G_sphere = 2π(n+1)/[12(n!)^{1/n}] = π(n+1)/[6(n!)^{1/n}] — 원문 식과 일치. ✓
- n→∞: 스털링(Stirling) 근사로 (n!)^{1/n} ≈ n/e이므로 G_s → πe/6 ≈ 1.4233 (1.533 dB).

**[재구성] 양자화와의 쌍대성.** 같은 G(·)가 양자화 셀의 정규화 관성 모멘트(normalized moment of inertia)다(Gray–Neuhoff §IV.A의 M). 따라서 채널 쪽 "형상 이득 상한 πe/6"과 양자화 쪽 "공간 채움 손실 πe/6 = 0.2546 bit"은 같은 수(입방체 대 구의 2차 모멘트 비)다. Forney의 γ(에르미트 모수, 채움 packing 척도)는 **이것과 다른 척도**다. 예를 들어 E₈은 γ = 2 (3.01 dB)이지만 양자화 이득은 0.65 dB다(§5).

## 6. 원문과의 차이·빈틈

1. **정규화 차원의 이중 표기.** §I.B는 실차원을 N으로 두고 ρ = 2r/N을 쓴다. §II.E는 실차원을 2N(복소 N)으로 두고 ρ = r/N을 쓴다. 둘 다 "2차원당"이라는 같은 양이다. 깨진 텍스트에서 혼동하기 쉬우므로 이미지로 확인했다.
2. **Lemma 2의 위수 2 원소 존재성**과 "분할 거리 보조정리(partition distance lemma)"는 II부에 미룬다. [미확인]
3. **웅거보크 라벨링의 선형성.** 원문 §IV.C 괄호는 "웅거보크 라벨링이면 Λ′를 법으로 선형"이라고 쓴다. 이는 Lemma 6의 mod-2 Λ′ 맥락에서만 옳다. ℤ/4ℤ처럼 순환 몫군이면 XOR-선형이 아니다(§4.4, §4.8의 [재구성] 주의). 원문 자체도 ℤ/4ℤ 표준 라벨링을 "정규"로만 부른다.
4. **형상 이득 G_s의 유도**는 원문에 없다(결과만 [1]에서 인용). §4.9는 [재구성]이다.
5. **기본 부피의 정의(트렐리스).** 원문은 "합리적 정의"라는 직관 논증만 하고, 무한 차원 격자의 밀도를 엄밀하게 극한으로 정의하지 않는다. Λ₀가 격자가 아닐 수 있다는 점도 "보통은(ordinarily)" 격자라고만 한다.
6. **오류 계수 → 유효 이득 규칙**(N₀가 2배이면 약 0.2 dB 손해, 10⁻⁶ 근처)은 경험칙이다. 원문도 그렇게 밝힌다.
7. **SURVEY.md와의 대조.** SURVEY.md 5번 항목은 "형상 이득 ≤1.53 dB 규칙(원문 본 제목 밖) … 읽은 범위에서는 확인 못함"이라고 적었다. 실제로는 I부 §I.B 괄호 문단에 N-구 형상 이득 공식과 극한 πe/6 (1.53 dB)가 명시되어 있다(출처 [1] 인용). SURVEY.md의 해당 문장은 고쳐야 한다. 그 밖에 "센 것은 비트가 아니라 기하 모수" 같은 서술은 원문과 맞는다.

## 7. 본 연구와의 연결

본 연구 설정: K명 작업자, X_k ~ N(0,σ²) 독립, Q_k = f_k(X_k, W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만 계산, 복호기 Ŝ = g(Z, W), D̄ = E(S−Ŝ)²/(Kσ²).

### 7.1 스위치 덧셈 = 몫군 덧셈 [원문 §II.B 언어, 적용은 재구성]
- ℤ_M = ℤ/Mℤ는 Forney의 분할 ℤ/Mℤ의 몫군 그 자체다. 작업자 k가 정수 격자점 λ_k ∈ ℤ(눈금 Δ)를 정하고 그 잉여류 λ_k mod M을 보내면, 몫군 덧셈이 잘 정의되므로(§4.1) Σ(λ_k mod M) ≡ (Σλ_k) mod M이다. 스위치가 보는 Z는 **합의 잉여류**다. 복호기는 대표계 [ℤ/Mℤ] = {−M/2,…,M/2−1}에서 대표원을 골라 Σλ_k를 복원한다. Σλ_k가 그 대표 구간 안에 있으면 오류가 없다.
- d차원 블록 판: 중첩 격자(nested lattices) Λ_c ⊂ Λ_f, 작업자는 λ_k = Q_{Λ_f}(X_k + U_k)의 잉여류 λ_k mod Λ_c ∈ Λ_f/Λ_c를 보낸다. Lemma 1에 의해 |Λ_f/Λ_c| = V(Λ_c)/V(Λ_f)이므로 차원당 율은 R = (1/d)log₂(V(Λ_c)/V(Λ_f))다.
- **스위치가 ℤ_M 덧셈만 하는 경우의 호환성.** Λ_c = qΛ_f(자기닮음 중첩)이면 Λ_f = Gℤ^d에서 λ = Ga ↦ a mod q가 군 동형 Λ_f/qΛ_f ≅ (ℤ_q)^d를 준다. 이는 §II.B의 ℤ^N/mℤ^N ≅ [ℤ/mℤ]^N를 생성 행렬로 옮긴 것이다. 따라서 좌표별 mod-q 덧셈을 하는 스위치 d개(또는 한 스위치의 d개 슬롯)로 블록 부호를 그대로 쓸 수 있다. 일반 Λ_c ⊂ Λ_f면 몫군이 ℤ_{n₁}×…×ℤ_{n_d}(스미스 표준형 Smith normal form)이므로 스위치가 슬롯마다 다른 법을 지원해야 한다. [재구성]

### 7.2 선형 잉여류 부호만 스위치와 호환된다 [원문 §IV.C + 재구성]
- 스위치가 군 덧셈만 하므로, 작업자들의 부호어를 더한 결과가 다시 "복호 가능한 구조"에 있어야 한다. Forney의 말로 하면 **선형 잉여류 부호(=격자)**가 필요하다. 원문이 경고하듯 일반 트렐리스 부호, 비선형 웅거보크 라벨링, 정규이지만 비선형인 라벨링(ℤ/4ℤ 표준 이진)은 합에 닫혀 있지 않다(§4.8).
- 구성 A(Lemma 3)는 바로 쓸 수 있는 예다. E₈ = 2ℤ⁸ + (8,4,4)에서 잉여류 라벨 덧셈은 XOR이고(c(a⊕a′) = c(a)⊕c(a′)), 스위치가 (ℤ₂)^K 덧셈을 하면 된다. 그러나 ℤ_M (M = 2^b) 스위치는 자리올림이 있는 덧셈이므로 XOR 라벨과 맞지 않는다. ℤ/2^bℤ 사슬의 표준 이진 표현은 군 동형이 아니다(§4.1 주의). 스위치가 ℤ_{2^b}면 라벨 부호도 ℤ_{2^b} 위 선형 부호(ℤ_M-가군 module)여야 한다. Forney I부는 이진·삼진만 다룬다(§I.C, 삼진은 [16]). ℤ_M 위 부호는 이 논문 범위 밖이다. [재구성]

### 7.3 정리 B의 0.254와 격자 이득 [재구성; 양자화 수치는 Gray–Neuhoff·Conway–Sloane]
- **스칼라(d=1) 정리 B 재현.** 감산 디더(subtractive dither)를 쓰면 λ_k = X_k + U_k + E_k이고 E_k ~ Unif(−Δ/2, Δ/2)는 독립이다(Schuchman 조건, Gray–Neuhoff §V.E). 오차 합의 분산은 KΔ²/12, D̄ = Δ²/(12σ²)이다. M이 충분히 크면 H(Z) = H(Σλ_k | W) ≈ h(S) − log₂Δ = ½log₂(2πeKσ²/Δ²) = ½log₂(K/D̄) + ½log₂(2πe/12)이다. 0.254는 **입방체(구간) 셀의 공간 채움 손실** ½log₂(2πe·G(ℤ))다.
- **블록 부호로 상수 줄이기.** 미세 격자 Λ_f의 셀을 G(Λ_f)로 바꾸면 같은 계산에서 상수가 ½log₂(2πe·G(Λ_f))가 된다. §5.5 표에 따르면 E₈은 0.146, Λ₂₄는 0.084, d→∞ 양자화-좋은(quantization-good) 격자는 0이다. 1.53 dB = 0.2546 bit는 Forney의 형상 이득 상한 πe/6과 같은 수다(§4.9). 따라서 **0.254는 정리 A 가설의 하한 쪽이 아니라 스칼라 구조의 비용**이다. 블록 길이 d→∞에서 0으로 갈 수 있다(엔트로피 율 기준).
- **고정율(log₂M) 판과 굵은 격자의 역할.** 블록 부호에서 복호기는 [Z − ΣU_k] mod Λ_c = [S + ΣE_k] mod Λ_c를 계산하고, S + ΣE_k ∈ V(Λ_c)(굵은 격자의 보로노이 셀 Voronoi cell)이면 정확하다. 차원당 분산 K(σ² + G_fV_f^{2/d}) ≈ Kσ²인 가우시안 벡터를 담으려면 V(Λ_c)^{2/d} = μ_c·Kσ²가 필요하다. 그러면
  R = (1/d)log₂(V_c/V_f) = ½log₂(K/D̄) + ½log₂(2πe·G(Λ_f)) + ½log₂(μ_c/(2πe)).
  둘째 항은 미세 격자의 양자화 이득, 셋째 항은 굵은 격자의 "채널 부호화(덮기) 손실"이다. μ_c → 2πe는 AWGN-좋은(Poltyrev-good) 격자에서 d→∞로 달성된다(이 논문 밖의 결과). 유한 d에서 μ_c는 오류 확률 목표와 Λ_c의 패킹 성질로 정해진다. 높은 SNR에서는 이것이 Forney의 γ(Λ_c)와 N₀(Λ_c)가 재는 양이다. 같은 Pe에서 필요한 V_c^{2/d}는 대략 1/γ(Λ_c)에 비례해 줄어든다. **Forney의 γ는 굵은 격자 쪽, 양자화 G는 미세 격자 쪽**의 성능지수(figure of merit)다.
- 결론(추측): 중첩 격자 블록 부호로 log₂M/d → ½log₂(K/D̄) + o(1)이 가능해 보인다. 이것이 맞다면 정리 A 가설 log₂M ≥ ½log₂(K/D̄) − c는 c = 0 근방에서 빡빡할(tight) 수 있다. 다만 (a) 굵은 격자가 "합 S의 퍼짐"을 덮어야 해서 ½log₂K가 남는다는 점이 이 구조의 핵심이다. (b) 하한 증명은 Forney 논문의 도구(기하 모수)로는 나오지 않는다. 중앙집중 슈넌 하한은 ½log₂(1/D̄)만 주므로 ½log₂K 몫은 분산·합 제약에서 따로 끌어내야 한다(S2 노트 §7 참고). [재구성, 미검증]
