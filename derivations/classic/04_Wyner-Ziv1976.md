# 04. Wyner–Ziv — 복호기 측 부가 정보가 있는 율-왜곡 함수 (유도 노트)

## 1. 서지

- A. D. Wyner, J. Ziv, "The Rate-Distortion Function for Source Coding with Side Information at the Decoder," *IEEE Transactions on Information Theory*, vol. IT-22, no. 1, pp. 1–10, 1976년 1월.
- 원본 파일: `papers/classic/04_Wyner-Ziv1976.pdf` (10쪽). 원고 접수 1975.1.3, 수정 1975.7.3.
- 표기 규칙: [원문] = 원문 증명을 그대로 따라 단계를 풀어 씀, [재구성] = 원문이 생략했거나 낡은 기법이라 현대 표준 증명(El Gamal–Kim, *Network Information Theory*, 2011 식)으로 보충, [미확인] = 원문이나 다른 출처로 확인하지 못함.
- 모든 로그는 밑 2 (원문 I-B절 "All logarithms in this paper are taken to the base 2").

## 2. 문제 설정 (원문 기호)

**소스.** {(X_k, Y_k)}_{k≥1}은 유한 알파벳 𝒳×𝒴 위의 독립 동일 분포(i.i.d.) 쌍이며 분포는
Q(x,y) = Pr{X=x, Y=y} (식 (8)).
복원 알파벳(reproduction alphabet) 𝒳̂도 유한. 왜곡 척도(distortion measure) D: 𝒳×𝒳̂ → [0,∞).

**세 가지 경우 (Fig. 1의 스위치 A, B).**
- i) 부가 정보(side information) 없음: R_X(d) = min_{p∈𝓜₀(d)} I(X;X̂) (식 (2)).
- ii) 부호기(encoder)·복호기(decoder) 모두 Y를 앎: 조건부 율-왜곡 함수 R_{X|Y}(d) = min_{p∈𝓜₀(d)} I(X;X̂|Y) (식 (3)).
- iii) 복호기만 Y를 앎: R*(d) — 이 논문의 대상.
여기서 𝓜₀(d)는 (X,Y) 주변 분포가 Q이고 Σ D(x,x̂)p(x,y,x̂) ≤ d인 분포 p(x,y,x̂)의 집합 (식 (1)).

**부호(code) (n, M, Δ)** (식 (9a)–(9c)):
- 부호기 F_E: 𝒳ⁿ → I_M = {0,1,…,M−1},
- 복호기 F_D: 𝒴ⁿ × I_M → 𝒳̂ⁿ,
- X̂ⁿ = F_D(Yⁿ, F_E(Xⁿ)), Δ = E[(1/n) Σ_{k=1}^n D(X_k, X̂_k)].

**달성 가능성(achievability)** (식 (10); 인쇄본에는 "(01)"로 찍혀 있음): (R,d)가 달성 가능 ⇔ 임의의 ε>0에 대해 n이 충분히 크면 M ≤ 2^{n(R+ε)}, Δ ≤ d+ε인 부호 (n,M,Δ)가 존재. 달성 가능 쌍의 집합을 𝓡이라 하고
R*(d) = min_{(R,d)∈𝓡} R (식 (11)).
𝓡이 정의상 닫힌 집합이므로 최소가 존재하며, R*(d)는 d=0에서 연속이다(원문 I-B절 끝의 논증: 비증가성 + 닫힘).

**보조 확률변수(auxiliary random variable)와 단일 문자(single-letter) 식.** 임의의 유한 집합 𝒵 위의 Z로 p(x,y,z)를 만들되
- (12a) Σ_z p(x,y,z) = Q(x,y),
- (12b) Y와 Z는 X가 주어지면 조건부 독립, 즉 마르코프 사슬(Markov chain) Y − X − Z.
동치로 p(x,y,z) = Q(x,y) p_t(z|x) (식 (13)); p_t는 "시험 채널(test channel)"이다.
𝓜(d) = {(12)를 만족하고, 어떤 함수 f: 𝒴×𝒵 → 𝒳̂가 있어 E[D(X, f(Y,Z))] ≤ d인 p(x,y,z)} (식 (14)).
R̄(d) ≜ inf_{p∈𝓜(d)} [I(X;Z) − I(Y;Z)], d>0 (식 (15a)); R̄(0) ≜ lim_{d→0} R̄(d) (식 (15b)).

## 4. 유도

### 4.1 Remark 2: I(X;Z) − I(Y;Z) = I(X;Z|Y) [원문]

I(X;Z) − I(Y;Z) = [H(Z) − H(Z|X)] − [H(Z) − H(Z|Y)] = H(Z|Y) − H(Z|X).
(12b) Y−X−Z이므로 H(Z|X) = H(Z|X,Y). 따라서
= H(Z|Y) − H(Z|X,Y) = I(X;Z|Y). ∎

해석: Z를 보내는 데 원래 I(X;Z) 비트가 들지만, 복호기가 Y로 Z에 대해 I(Y;Z)만큼 이미 안다. 이 차이가 비닝(binning)으로 회수되는 양이다.

### 4.2 Remark 3: R̄(0) = H(X|Y) [원문]

(하계) δ ≜ min_{x≠x̂} D(x,x̂) > 0. p ∈ 𝓜(d)이면 λ ≜ Pr{X≠X̂} ≤ E D(X,X̂)/δ ≤ d/δ.
X̂ = f(Y,Z)는 (Y,Z)의 함수이므로 파노 부등식(Fano's inequality):
H(X|Z,Y) ≤ h(λ) + λ log|𝒳| ≜ ε(λ).
따라서 I(X;Z|Y) = H(X|Y) − H(X|Z,Y) ≥ H(X|Y) − ε(d/δ) → H(X|Y) (d→0).
(상계) Z = X, f(Y,Z) = Z로 두면 모든 d>0에서 𝓜(d)에 속하고 I(X;X|Y) = H(X|Y). ∎

### 4.3 Remark 5: R*(d) ≥ R_{X|Y}(d) [원문]

p ∈ 𝓜(d), X̂ = f(Y,Z). Y=y를 고정하면 X̂ = f(y,Z)는 Z의 함수이므로 X − Z − X̂ (Y=y 조건부). 자료 처리 부등식(data-processing inequality):
I(X;Z|Y=y) ≥ I(X;X̂|Y=y) → 평균하면 I(X;Z|Y) ≥ I(X;X̂|Y) (식 (17)).
(X,Y,X̂) 분포는 𝓜₀(d)에 속하므로 I(X;X̂|Y) ≥ R_{X|Y}(d). Remark 2와 Theorem 1로 R*(d) = R̄(d) ≥ R_{X|Y}(d). 등호 ⇔ I(X;Z|X̂,Y) = 0 (연쇄 법칙 I(X;Z|Y) = I(X;X̂|Y) + I(X;Z|X̂,Y), X̂가 (Y,Z)의 함수이므로). ∎

### 4.4 역정리 (Theorem 2) [원문]

**목표.** 임의의 부호 (n,M,Δ)에 대해 (1/n) log M ≥ R̄(Δ) (식 (46)). 이것이 되면 (R,d) ∈ 𝓡일 때 M ≤ 2^{n(R+ε)}, Δ ≤ d+ε인 부호가 있으므로 R+ε ≥ R̄(Δ) ≥ R̄(d+ε) (비증가성) (식 (47)), ε→0과 R̄의 연속성(Theorem A2)으로 R ≥ R̄(d).

**단계.** W = F_E(Xⁿ), X̂ⁿ = F_D(Yⁿ,W), Δ_k = E D(X_k,X̂_k), Δ = (1/n)ΣΔ_k (식 (48),(49)).

(50) log M ≥ H(W) ≥ I(Xⁿ;W) = H(Xⁿ) − H(Xⁿ|W).
 근거: (1) W ∈ I_M이므로 H(W) ≤ log M; (2) I ≤ H; (3) 정의.

(51) H(Xⁿ|W) = I(Xⁿ;Yⁿ|W) + H(Xⁿ|Yⁿ,W)
  = H(Yⁿ|W) − H(Yⁿ|Xⁿ,W) + H(Xⁿ|Yⁿ,W)
  ≤ H(Yⁿ) − H(Yⁿ|Xⁿ) + H(Xⁿ|Yⁿ,W)
  = I(Xⁿ;Yⁿ) + H(Xⁿ|Yⁿ,W).
 근거: 항등식; 부등호는 조건화가 엔트로피를 줄인다는 것(H(Yⁿ|W) ≤ H(Yⁿ))과 W가 Xⁿ의 함수라 H(Yⁿ|Xⁿ,W) = H(Yⁿ|Xⁿ).

(52) (51)을 (50)에 넣고, i.i.d.성으로 H(Xⁿ) = Σ H(X_k), I(Xⁿ;Yⁿ) = Σ I(X_k;Y_k), 연쇄 법칙(chain rule)으로 H(Xⁿ|Yⁿ,W) = Σ H(X_k | X^{k−1}, Yⁿ, W):
log M ≥ Σ_k [H(X_k) − H(X_k | X^{k−1} Yⁿ W) − I(X_k;Y_k)].

(53) 보조 변수 정의: Z_k ≜ (X^{k−1}, Y_1, …, Y_{k−1}, Y_{k+1}, …, Y_n, W). 그러면 (X^{k−1}, Yⁿ, W) = (Y_k, Z_k)이므로
(54) log M ≥ Σ_k [H(X_k) − H(X_k|Y_k,Z_k) − I(X_k;Y_k)].

Z_k의 두 성질:
- a) X̂_k는 F_D(Yⁿ,W)의 k번째 좌표이므로 (Y_k, Z_k)의 결정적 함수: X̂_k = f(Y_k,Z_k), E D(X_k,X̂_k) = Δ_k.
- b) Y_k와 Z_k는 X_k가 주어지면 조건부 독립. [근거 풀이] Z_k는 (X^{k−1}, Y^{k−1}, Y_{k+1}^n, X_{k+1}^n)과 X_k의 함수다(W = F_E(Xⁿ)). (X_j,Y_j)가 j에 대해 독립이므로 X_k를 조건으로 하면 Y_k는 다른 좌표들 전부와 독립. 따라서 Y_k − X_k − Z_k.

a), b)로 (X_k, Y_k, Z_k)의 분포는 𝓜(Δ_k)에 속한다 ⇒ I(X_k;Z_k) − I(Y_k;Z_k) ≥ R̄(Δ_k) (식 (55)).

(56) 합의 두 번째 항을 정리: b)로 H(Y_k|X_k,Z_k) = H(Y_k|X_k)이므로
H(X_k|Y_k,Z_k) = H(X_k,Y_k|Z_k) − H(Y_k|Z_k) = H(X_k|Z_k) + H(Y_k|X_k) − H(Y_k|Z_k).

(57) 대입하면
log M ≥ Σ_k [H(X_k) − H(X_k|Z_k) − H(Y_k|X_k) + H(Y_k|Z_k) − H(Y_k) + H(Y_k|X_k)]
 = Σ_k [I(X_k;Z_k) − I(Y_k;Z_k)]
 ≥ Σ_k R̄(Δ_k)  ((55))
 ≥ n R̄((1/n)ΣΔ_k)  (R̄의 볼록성 + 옌센 부등식(Jensen's inequality), Theorem A2)
 = n R̄(Δ). ∎

[재구성] 현대 판(El Gamal–Kim 11장): nR ≥ H(M) ≥ I(Xⁿ;M|Yⁿ) = Σ I(X_k; M | Yⁿ, X^{k−1}) = Σ [H(X_k|Y_k) − H(X_k|M,Yⁿ,X^{k−1})] ≥ Σ [H(X_k|Y_k) − H(X_k|U_k,Y_k)], U_k ≜ (M, Y^{k−1}, Y_{k+1}^n). 마지막 부등호는 조건 줄이기(X^{k−1} 제거). 원문의 Z_k에 들어 있는 X^{k−1}은 없어도 된다. 첫 부등호에서 I(Xⁿ;M|Yⁿ) ≤ H(M)을 쓰는 점이 원문 (50)–(51)보다 짧다.

### 4.5 직접 정리 (Theorem 4) — 원문 경로 [원문]

원문은 두 단계로 증명한다. (i) Lemma 5: 시험 채널 p_t(z|x)에 맞춘 보통의 율-왜곡 덮기 부호(covering code)를 만들되, 그 출력 W의 조건부 엔트로피 (1/n₀)H(W|Y^{n₀})가 I(X;Z) − I(Y;Z)에 가깝게 한다. (ii) Lemma 3: W를 블록 n₀짜리 "초소스(supersource)"로 보고 그 반복 열 {W_j}를 Slepian–Wolf로 (1/n₀)H(W|Y^{n₀}) 율에 부호화한다. 비닝은 (ii)에 숨어 있다.

**Lemma 3의 증명 [원문].** (W_j, Y^{n₀}_j)의 독립 반복을 초소스로 본다. Slepian–Wolf에 의해 n₁이 크면 (W₁,…,W_{n₁})을 2^{n₁(H(W|Y^{n₀})+δ)} = 2^{n₁(n₀R₀+δ)}개 이하 부호어로 부호화하고, Y를 아는 복호기가 (1/n₁)Σ Pr{Ŵ_j ≠ W_j} ≤ δ / max D 를 만족하도록 복원할 수 있다 (식 (61),(62)). 복호기는 Ŵ_j와 해당 블록의 Y로 F_D^{(0)}을 적용한다. 왜곡:
Δ = (1/n₁) Σ_j E[(1/n₀) Σ_{블록 j} D(X_k, X_k*)]
 ≤ (1/n₁) Σ_j [Δ₀ + max D · Pr{W_j ≠ Ŵ_j}] ≤ Δ₀ + δ (식 (63)).
 첫 부등호: 사건 𝓔 = {W_j ≠ Ŵ_j}로 나누면 E φ_j ≤ Pr{𝓔ᶜ}E[φ_j|𝓔ᶜ] + Pr{𝓔} max D이고, 𝓔ᶜ에서 φ_j는 원래 부호의 블록 왜곡이며 D ≥ 0이므로 Pr{𝓔ᶜ}E[φ_j|𝓔ᶜ] ≤ Δ₀.

**Lemma 5의 증명 [원문].** p(x,y,z) ∈ 𝓜(d), 확률은 모두 p⁽ⁿ⁾(n번 독립 반복) 기준.
- 전형 집합(typical set) T(n,α): |−(1/n)log Pr{Yⁿ=y,Zⁿ=z} − H(Y,Z)| ≤ α 그리고 |−(1/n)log Pr{Zⁿ=z} − H(Z)| ≤ α인 (y,z) (식 (67),(68)). 대수의 법칙으로 Pr{(Yⁿ,Zⁿ) ∉ T(n,α)} → 0 (식 (69)).
- 개수 보조정리 (식 (70),(71)): (y,z) ∈ T이면 Pr{Yⁿ=y|Zⁿ=z} = Pr{y,z}/Pr{z} ≥ 2^{−n(H(Y|Z)+2α)}. 이를 y에 대해 합하면 1 ≥ |{y:(y,z)∈T}| · 2^{−n(H(Y|Z)+2α)}, 즉 |{y:(y,z)∈T}| ≤ 2^{n(H(Y|Z)+2α)}.
- f_n(y,z) = (f(y₁,z₁),…,f(y_n,z_n)), D_n은 문자 평균 왜곡. 대수의 법칙: Pr{D_n(Xⁿ, f_n(Yⁿ,Zⁿ)) ≥ d+α} → 0 (식 (75)).
- 실패 지시 함수 ψ_n(x,y,z) = 1 ⇔ D_n(x,f_n(y,z)) ≥ d+α 또는 (y,z) ∉ T(n,α) (식 (76)); E ψ_n(Xⁿ,Yⁿ,Zⁿ) → 0 (식 (77)).
- Wyner 1975의 Lemma 4.3 (부록 A2에서 U=(X,Y), V=X, W=Z로 대응; U−V−W 조건은 (12b)): 임의의 ε>0에 대해 n₀이 크면 사상 F: 𝒳^{n₀} → {z_i}_{i=1}^{M₀}이 존재하여 M₀ ≤ 2^{n₀(I(X;Z)+ε)} (식 (78a)), E ψ_{n₀}(X^{n₀}, Y^{n₀}, F(X^{n₀})) ≤ ε (식 (78b)). — 이것이 사실상 덮기 보조정리(covering lemma)에 해당한다.
- 부호: F_E^{(0)}(x) = i ⇔ F(x) = z_i; F_D^{(0)}(y,i) = f_{n₀}(y,z_i). 왜곡 (식 (79)): Δ₀ ≤ (d+α) + max D · E ψ ≤ d + α + ε max D. α, ε가 작으면 Δ₀ ≤ d + ε₀.
- 조건부 엔트로피 (식 (80),(81)):
 (1/n₀)H(W|Y^{n₀}) = (1/n₀)[H(W) + H(Y^{n₀}|W)] − H(Y)
  ≤ I(X;Z) + ε − H(Y) + (1/n₀)H(Y^{n₀}|W)  (H(W) ≤ log M₀와 (78a)).
 ψ ≜ ψ_{n₀}(X^{n₀}, Y^{n₀}, F(X^{n₀}))로 두면
 H(Y^{n₀}|W) ≤ H(Y^{n₀}, ψ | W) ≤ H(ψ) + Pr{ψ=0}H(Y^{n₀}|W,ψ=0) + Pr{ψ=1}H(Y^{n₀}|W,ψ=1)
  ≤ h(ε) + n₀(H(Y|Z) + 2α) + ε n₀ log|𝒴|.
 근거: ψ=0이면 (Yⁿ, z_W) ∈ T이므로 Yⁿ은 많아야 2^{n₀(H(Y|Z)+2α)}개 값 ((70)); ψ=1이면 자명한 상한 n₀ log|𝒴|; Pr{ψ=1} ≤ ε ≤ ½이므로 H(ψ) ≤ h(ε).
 정리하면 (1/n₀)H(W|Y^{n₀}) ≤ I(X;Z) − [H(Y) − H(Y|Z)] + 2α + ε + ε log|𝒴| + h(ε)/n₀ ≤ R₀ + ε₀. ∎

**Theorem 4의 결론.** Lemma 5 + Lemma 3: 임의의 ε₀, δ에 대해 M ≤ 2^{n(R₀+ε₀+δ)}, Δ ≤ d+ε₀+δ인 부호 존재 ⇒ (R₀, d) ∈ 𝓡. p ∈ 𝓜(d)에 대해 inf를 취하면 R*(d) ≤ R̄(d) (d>0). d=0은 Remark 1의 연속성으로. ∎

원문의 Lemma 3 뒤 Remark: 최적 부호에서는 (1/n)H(W) ≈ (1/n)H(W|Yⁿ), 즉 (1/n)I(W;Yⁿ) ≈ 0 — 부호화된 정보와 부가 정보는 근사적으로 독립이다.

### 4.6 직접 정리 — 현대 단일 단계 증명 [재구성]

p(z|x)와 f(y,z)를 고정하고 E D(X, f(Y,Z)) ≤ d/(1+ε)라 하자. ε' < ε.
- 부호책 생성: 2^{n R̃}, R̃ = I(X;Z) + δ(ε'), 개의 zⁿ(l)을 ∏ p_Z(z_k)로 독립 생성. 지표 l ∈ [1:2^{nR̃}]를 2^{nR}개 통(bin) B(m)에 균등 분할.
- 부호기: (xⁿ, zⁿ(l)) ∈ 𝒯_{ε'}ⁿ인 l을 찾아 그 통 번호 m을 보냄.
- 복호기: 통 B(m) 안에서 (zⁿ(l̂), yⁿ) ∈ 𝒯_εⁿ인 유일한 l̂를 찾고 x̂_k = f(y_k, z_k(l̂)).
- 오류 사건과 근거:
 1. 그런 l이 없음: 덮기 보조정리(covering lemma)로 R̃ > I(X;Z) + δ(ε')이면 확률 → 0.
 2. (Xⁿ,Yⁿ,Zⁿ(L))이 결합 전형이 아님: Y−X−Z이고 (Xⁿ,Zⁿ(L))가 전형, Yⁿ ~ ∏ p(y|x)이므로 마르코프 보조정리(Markov lemma)로 → 0.
 3. 같은 통 안에 다른 l̃ ≠ L이 (zⁿ(l̃), Yⁿ) ∈ 𝒯ⁿ: 통 크기 2^{n(R̃−R)}, 각 잘못된 zⁿ(l̃)은 Yⁿ과 독립이므로 채움 보조정리(packing lemma)로 R̃ − R < I(Y;Z) − δ(ε)이면 → 0.
- 1과 3을 합치면 R > I(X;Z) − I(Y;Z) + δ(ε) + δ(ε')이면 충분. 오류가 없을 때 (Xⁿ, X̂ⁿ)는 전형이므로 전형 평균 보조정리(typical average lemma)로 왜곡 ≤ (1+ε) E D(X, f(Y,Z)) ≤ d. 오류 확률 → 0이고 D가 유계이므로 기대 왜곡 ≤ d + o(1). ∎

### 4.7 Theorem A2 (볼록성·기수 한계) [원문 + 재구성]

[원문] 𝒳 = {1,…,K}, t_{jk} = Pr{Y=j|X=k}. Z = z일 때 X의 조건부 분포 q(z) ∈ Δ_K와 가중치 λ_z로 분포를 다시 쓰면(제약 Σ_z λ_z q(z) = Q_X, 식 (A5)),
I(X;Z) − I(Y;Z) = Σ_z λ_z Γ(q(z)), Γ(q) ≜ H(X) − H(Y) + 𝓗(Tq) − 𝓗(q) (식 (A7)),
최적 f를 쓰면 E D = Σ_z λ_z A(q(z)), A(q) = Σ_j min_{x̂} Σ_k t_{jk} q_k D(k,x̂) (식 (A9)).
따라서 R̄(d)는 연속 상 S = {(q, Γ(q), A(q))}의 볼록 포(convex hull) 위의 최소화 (식 (A11)). 볼록 포 위의 선형 최소화이므로 R̄는 볼록. S가 연결된 콤팩트 집합이므로 Fenchel–Eggleston판 카라테오도리 정리로 점 K+1개면 충분 ⇒ |𝒵| ≤ |𝒳|+1, 콤팩트성으로 inf = min.

[재구성] 볼록성의 더 짧은 증명: (Z₁,f₁) ∈ 𝓜(d₁), (Z₂,f₂) ∈ 𝓜(d₂)와 X,Y와 독립인 시분할 변수 T ~ Bern(θ)에 대해 Z = (T, Z_T)로 두면 Y−X−Z가 유지되고 I(X;Z|Y) = θ I(X;Z₁|Y) + (1−θ) I(X;Z₂|Y), 왜곡도 선형 결합. 따라서 R̄(θd₁+(1−θ)d₂) ≤ θR̄(d₁) + (1−θ)R̄(d₂).

설정 (식 (20),(21)): 𝒳=𝒴=𝒳̂={0,1}, Q(x,y) = ((1−p₀)/2)δ_{xy} + (p₀/2)(1−δ_{xy}), 0 ≤ p₀ ≤ ½ (X는 균등, Y는 X를 교차 확률 p₀인 이진 대칭 채널(BSC)에 통과시킨 것). D = 해밍.

비교 기준 (식 (22)): R_{X|Y}(d) = h(p₀) − h(d) (0 ≤ d ≤ p₀), 0 (d ≥ p₀). h는 이진 엔트로피, u∗v ≜ u(1−v) + v(1−u).

결과 (식 (23)–(27)): g(d) = h(p₀∗d) − h(d) (0 ≤ d < p₀), g(p₀) = 0. g*(d)는 g의 아래 볼록 포:
g*(d) = inf_{θ,β} θ[h(p₀∗β) − h(β)], d = θβ + (1−θ)p₀, 0≤θ≤1, 0≤β<p₀ (식 (25)).
그리고 R*(d) = g*(d). g가 [0,p₀)에서 볼록이므로(Lemma A) g*는 d ≤ d_c에서 g와 같고, [d_c, p₀]에서는 (p₀,0)을 지나는 g의 접선. d_c는 g(d_c)/(d_c − p₀) = g′(d_c)의 해 (식 (26)).

**Lemma A (G(u) = h(p₀∗u) − h(u)의 볼록성) [원문].** a = 1−2p₀라 하면 p₀∗u = au + p₀. h″(u) = −(log e)/(u(1−u))이므로
G″(u) = a² h″(au+p₀) − h″(u) = (log e) / [(au+p₀)(1−au−p₀) u(1−u)] · [(au+p₀)(1−au−p₀) − a²u(1−u)].
괄호 안을 전개하면 p₀(1−p₀) ≥ 0 (u의 항이 상쇄됨: (au+p₀)(1−p₀−au) = p₀(1−p₀) + au(1−2p₀) − a²u² 이고 a(1−2p₀) = a² 이므로 = p₀(1−p₀) + a²u − a²u² ). 따라서 G″ ≥ 0. ∎

**상계 R*(d) ≤ g*(d) [원문].**

- b) Z = 상수, X̂ = Y: E D = p₀, 율 0 ⇒ R*(p₀) = 0 (식 (30)).
- R*의 볼록성으로 d = θβ + (1−θ)p₀에서 R*(d) ≤ θR*(β) + (1−θ)R*(p₀) ≤ θ[h(p₀∗β) − h(β)] (식 (32)). θ,β에 대해 최소화하면 ≤ g*(d). (물리적 의미: 시간의 θ 비율만 WZ 부호를 쓰고 나머지는 Y를 그대로 추정치로 씀.)

**하계 R*(d) ≥ g*(d) [원문].** p ∈ 𝓜(d), d < p₀.
- A = {z: f(0,z) = f(1,z)} (복원이 Y에 의존하지 않는 z), Aᶜ = {z: f(0,z) ≠ f(1,z)} (식 (34)).
- z ∈ Aᶜ이면 E[D|Z=z] ≥ p₀ (식 (36)): f(0,z)=0, f(1,z)=1이면 X̂ = Y이므로 E[D|Z=z] = Pr{X≠Y|Z=z} = Pr{X=1|z}Pr{Y=0|X=1} + Pr{X=0|z}Pr{Y=1|X=0} = p₀ ((12b) 사용, 식 (38a)); f(0,z)=1, f(1,z)=0이면 X̂ = 1−Y이고 E[D|z] = 1−p₀ ≥ p₀ (식 (38b)).

### 5.2 2차 가우시안(quadratic Gaussian) 경우: R_WZ(D) = ½ log(σ²_{X|Y}/D) [재구성]

원문 Remark 6은 결과만 진술하고 증명은 "다른 곳에서"로 미룬다(이후 Wyner 1978, *Inform. Control* 38:60–80 "…—II: General sources"; 이 서지는 07번 Yamamoto 논문 참고문헌 [4]에서 확인). 아래는 직접 유도.

**설정.** X ~ N(0,σ_X²), Y = X + U, U ~ N(0,σ_U²) ⟂ X. 왜곡 E(X−X̂)² ≤ D. 이때
σ²_{X|Y} ≜ Var(X|Y) = σ_X² − σ_X⁴/(σ_X²+σ_U²) = σ_X²σ_U²/(σ_X²+σ_U²).
일반적으로 (X,Y)가 결합 가우시안이면 σ²_{X|Y} = σ_X²(1−ρ²) (ρ = 상관 계수)이고 아래 유도는 그대로 성립한다. 주장:
R*(D) = R_{X|Y}(D) = ½ log(σ²_{X|Y}/D) (0 < D ≤ σ²_{X|Y}), 0 (D ≥ σ²_{X|Y}).
σ²_{X|Y}를 대입하면 원문 Remark 6의 식 ½ log[σ_U²σ_X²/((σ_X²+σ_U²)d)], 문턱 σ_U²σ_X²/(σ_X²+σ_U²)과 정확히 일치한다 [원문 대조 완료].

**역정리 (율 하계).** 연속 알파벳이라 Theorem 2를 그대로 인용하지 않고 다문자로 직접 보인다. 부호 (n, M), 메시지 W, X̂ⁿ = F_D(Yⁿ,W), D_k = E(X_k − X̂_k)², (1/n)ΣD_k ≤ D.
n R ≥ H(W) ≥ I(Xⁿ; W | Yⁿ)  (H(W) ≥ H(W|Yⁿ) ≥ I(Xⁿ;W|Yⁿ))
 = h(Xⁿ|Yⁿ) − h(Xⁿ|W,Yⁿ)
 = (n/2) log(2πe σ²_{X|Y}) − h(Xⁿ|W,Yⁿ)  ((X_k,Y_k) i.i.d. 가우시안, X_k|Y_k ~ N(·, σ²_{X|Y}))
 ≥ (n/2) log(2πe σ²_{X|Y}) − Σ_k h(X_k | X̂_k)  (연쇄 법칙 + 조건 줄이기: X̂_k는 (W,Yⁿ)의 함수)
 ≥ (n/2) log(2πe σ²_{X|Y}) − Σ_k h(X_k − X̂_k)  (h(X_k|X̂_k) = h(X_k − X̂_k | X̂_k) ≤ h(X_k − X̂_k))
 ≥ (n/2) log(2πe σ²_{X|Y}) − Σ_k ½ log(2πe D_k)  (주어진 2차 모멘트에서 가우시안이 미분 엔트로피 최대)
 ≥ (n/2) log(σ²_{X|Y}/D)  (log의 오목성 + 옌센: (1/n)Σ log D_k ≤ log D).
이 하계는 부호기가 Y를 알아도 성립하므로 R_{X|Y}(D) ≥ ½ log(σ²_{X|Y}/D)도 같은 논증으로 나온다.

**달성 (율 상계).** Theorem 1의 식에 가우시안 시험 채널을 넣는다(연속 경우로의 확장은 양자화 논증 또는 Wyner 1978에 의존 — 이 단계는 원문 범위 밖 [재구성]).
Z = X + V, V ~ N(0, σ_V²) ⟂ (X,U). Y − X − Z가 성립.
- 율: I(X;Z|Y) = h(Z|Y) − h(Z|X,Y) = h(Z|Y) − h(V).
 Z|Y는 가우시안, Var(Z|Y) = Var(X|Y) + σ_V² = σ²_{X|Y} + σ_V² (V ⟂ (X,Y)).
 ⇒ I(X;Z|Y) = ½ log[(σ²_{X|Y} + σ_V²)/σ_V²].
- 왜곡: X̂ = f(Y,Z) = E[X|Y,Z] (결합 가우시안이므로 선형). 정보 형태(정밀도 덧셈)로
 1/Var(X|Y,Z) = 1/σ²_{X|Y} + 1/σ_V²  ⇒  D = σ²_{X|Y}σ_V²/(σ²_{X|Y} + σ_V²).
 (근거: X|Y ~ N(μ, σ²_{X|Y})를 사전 분포로, Z = X + V를 독립 잡음 관측으로 보는 가우시안 베이즈 갱신. V가 Y와 독립이라 가능.)
- 소거: (σ²_{X|Y} + σ_V²)/σ_V² = σ²_{X|Y}/D 이므로 I(X;Z|Y) = ½ log(σ²_{X|Y}/D). σ_V²: 0 → ∞로 D는 (0, σ²_{X|Y})를 모두 덮는다. D ≥ σ²_{X|Y}이면 X̂ = E[X|Y]로 율 0.
- 하계와 일치 ⇒ R*(D) = R_{X|Y}(D) = ½ log(σ²_{X|Y}/D). ∎

**왜 가우시안에서는 율 손실이 없나 (Remark 5의 조건 확인).** R_{X|Y}의 최적 시험 채널은 "역방향" 형태 X = X̂ + E, E ~ N(0,D) ⟂ (X̂,Y). 위의 Z = X+V에서 X̂ = E[X|Y,Z]는 (Y,Z)의 선형 함수이고 X − X̂ ⟂ (Y,Z)이므로 I(X;Z|X̂,Y) = 0 — 식 (18)의 등호 조건이 성립한다. 이진 경우에는 이 조건이 성립하지 않는다(5.1의 표).

**동치 형태.** 등가 표현 D = σ²_{X|Y}·2^{−2R}: 부가 정보는 "분산을 σ_X²에서 σ²_{X|Y}로 낮춘 뒤의 보통 가우시안 율-왜곡"과 같다.

## 6. 원문과의 차이·빈틈

1. **가우시안 경우 무증명.** Remark 6은 결과만 있다. 연속 알파벳 확장은 Wyner 1978(*Inform. Control*)에서 다뤄졌다(서지는 Yamamoto 1982 참고문헌으로 확인, 내용은 [미확인]). 5.2절의 하계는 자족적이나, 달성은 유한 알파벳 정리를 연속 경우로 옮기는 표준 논증(양자화·약전형성)에 기대며 이 노트에서 엄밀히 하지 않았다.
2. **직접 정리의 외부 의존.** Lemma 5의 핵심(덮기 부호 존재, (78))은 Wyner 1975의 Lemma 4.3을 인용해 얻는다. 원문은 이 보조정리가 어떻게 증명되는지 싣지 않는다. 현대 증명(4.6절)은 덮기·채움·마르코프 보조정리로 단일 단계에 끝낸다.
3. **두 단계 구성의 실용성.** 원문의 구성은 "율-왜곡 부호 → 그 출력 블록을 다시 Slepian–Wolf"라 블록 길이가 n₀n₁로 커진다. 현대 표현은 같은 비닝을 한 블록에 한다. 율 자체는 같다.
4. **역정리의 보조 변수.** Z_k에 X^{k−1}을 넣은 것은 불필요(4.4 [재구성] 참조). 해롭지는 않다.
5. **연속성 논증.** Theorem 1을 d>0에서만 증명하고 d=0은 연속성(Remark 1)으로 처리. R̄의 d=0 연속성은 정의 (15b)로 강제한 것이고 R*의 연속성은 𝓡의 닫힘에서 나온다 — 정당하다.
6. **인쇄 오류.** 식 (10)이 "(01)"로 인쇄됨. 텍스트 추출본에는 기호가 깨지므로 이 노트의 식은 쪽 이미지로 대조했다.
7. **이후 문헌 (기억에 의존).** 율 손실 R*(d) − R_{X|Y}(d)는 2차 왜곡에서 일반 소스에 대해 ½ 비트 이하(Zamir 1996, "The rate loss in the Wyner–Ziv problem")로 알려져 있다. 가우시안 무손실의 구조적 구현은 중첩 격자(nested lattice) 부호(Zamir–Shamai–Erez 2002)다. 원문 서론은 Berger 1971 교과서의 Theorem 6.1.1이 R*(d)를 잘못 특성화했다고 밝힌다.

## 7. 본 연구와의 연결

본 연구 요약: K명의 작업자, X_k ~ N(0,σ²) 독립; 인코더 Q_k = f_k(X_k, W) ∈ ℤ_M; 스위치는 Z = ΣQ_k mod M만 계산; 복호기 Ŝ = g(Z,W)로 S = ΣX_k 추정. 정리 A(가설): R_down = log₂M ≥ ½ log₂(K/D̄) − c, D̄ = E(S−Ŝ)²/(Kσ²). 증명 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½ log₂K − c.

1. **기준선(제약 없는 부호)의 시간 부가 정보 판.** 이전 반복의 합 S′가 복호기에만 있을 때, 합 S 전체를 보는 가상의 단일 부호기에 대한 하한은 5.2절의 가우시안 WZ 하계다: R ≥ ½ log₂(σ²_{S|S′}/D). 정규화하면 ρ̄ ≜ σ²_{S|S′}/(Kσ²)로 R ≥ ½ log₂(ρ̄/D̄). 가우시안이라 율 손실이 없으므로 **S′가 부호기 쪽에 있든 복호기 쪽에만 있든 기준선은 같다** — 비교 기준을 하나로 고정할 수 있다. 정리 A의 시간 부가 정보 확장은 (가설) R_down ≥ ½ log₂(Kρ̄/D̄) − c 꼴이 되어, 합 호환 비용 ½ log₂K가 부가 정보 이득과 분리되는지가 질문이 된다.
2. **증명 사슬의 첫 항에 쓰이는 기법.** I(S;Z|W) ≥ ½ log₂(1/D̄)류 하계는 5.2절 역정리의 사슬(H(M) ≥ I(·;M|부가정보) → 미분 엔트로피 차 → 최대 엔트로피 → 옌센)을 그대로 옮긴 것이다. S′가 있으면 log₂M ≥ H(Z|W) ≥ H(Z|W,S′) = I(S;Z|W,S′) + H(Z|S,W,S′)로 쪼개고, 첫 항은 h(S|S′,W) − h(S|Z,W,S′) ≥ ½ log₂(σ²_{S|S′}/D)로 같은 단계를 밟는다(W가 S와 독립이면 h(S|S′,W) = h(S|S′)).
3. **보조정리 L의 조건부 판이 필요.** 위 분해에서 둘째 항은 H(Z|S,W,S′)이다. S′가 개별 X_k의 시간 상관을 통해 Z의 "분할 무작위성"(S가 같아도 X_k들의 배분에 따라 Z가 달라지는 성분)을 줄일 수 있으므로, 보조정리 L을 S′ 조건부로 다시 증명해야 한다(미해결, 가설).
4. **WZ 비닝과 H(Z|S,W)의 대비 (해석).** WZ에서 율 I(X;Z) − I(Y;Z)의 빼기 항은 "메시지가 부가 정보와 근사적으로 독립이 되도록"(Lemma 3 뒤 Remark) 비닝해서 얻는 이득이다. 본 연구 사슬의 H(Z|S,W)는 반대로 "메시지 중 목표 S와 무관한 성분"이며 비용이다. 합 호환 제약은 스위치가 복호·재부호화를 못 하게 막아, 이 무관 성분을 비닝처럼 제거할 수단을 없앤다는 것이 정리 A의 직관이다.
5. **공간 부가 정보(하행에서 작업자 k가 X_k를 앎).** 작업자 k가 복호기일 때 기준선은 Y = X_k, 목표 S인 가우시안 WZ: σ²_{S|X_k} = (K−1)σ²이므로 R ≥ ½ log₂((K−1)σ²/D). 부가 정보 없는 경우와의 차이는 ½ log₂(K/(K−1)) ≤ ½ 비트(K=2)이며 K→∞에서 0. 따라서 공간 부가 정보는 ½ log₂K 격차를 흡수하지 못한다(기준선 차원에서). 이 계산은 07번 Yamamoto의 "합 함수 + 부가 정보" 가우시안 언급과 같은 구조다.
6. **이진 예제의 교훈.** 이진(또는 ℤ_M 위 이산) 근사에서는 부가 정보 위치에 따라 율 손실이 생긴다(5.1절 표). 본 연구가 ℤ_M 위 양자화 값을 다룰 때, 저율 영역의 상수 c 추정에 이 손실이 섞일 수 있음을 주의.
