# Körner–Marton 1979 유도 노트

표기: [원문] = 원문 증명 경로를 그대로 따름, [재구성] = 원문이 생략했거나 낡은 기법이라 현대 표준 증명(El Gamal–Kim 식)으로 보충, [미확인] = 원문에서 확인하지 못함. 로그는 밑 2.

## 1. 서지

- 저자: János Körner, Katalin Marton
- 제목: How to Encode the Modulo-Two Sum of Binary Sources (Correspondence)
- 학술지: IEEE Transactions on Information Theory, vol. IT-25, no. 2, pp. 219–221, March 1979
- 비고: PDF 1쪽 앞부분은 무관한 논문(비중심 카이제곱 분포의 절단 적률)이며 본문은 219쪽 오른쪽 아래에서 시작한다. 텍스트 추출과 함께 220–221쪽 쪽 이미지를 직접 보고 식을 대조했다.

## 2. 문제 설정 (원문 기호)

**소스.** 3성분 이산 무기억 정상 소스(discrete memoryless stationary source) {(X_i, Y_i, Z_i)}_{i=1}^∞: 세 쌍이 서로 독립이고 분포가 같은(i.i.d.) 확률변수 열이며, 값의 범위는 유한 집합 𝒳, 𝒴, 𝒵이다. X^n = X_1⋯X_n 등. 일반 변수(generic variable) (X, Y, Z)는 (X_i, Y_i, Z_i)와 같은 분포를 갖는다.

**모듈로-2 가산기(modulo-two adder).** 𝒳 = 𝒴 = {0,1}이고 Z = X ⊕ Y (X = Y이면 0, 아니면 1).

**대칭 결합분포.** 어떤 0 ≤ p ≤ 1에 대해
 Pr{X=Y=1} = Pr{X=Y=0} = ½(1−p), Pr{X=0,Y=1} = Pr{X=1,Y=0} = ½p.
이것이 이중 대칭 이진 소스(doubly symmetric binary source, DSBS)다. 이때 X, Y는 각각 균등이고 Z ~ Bern(p), H(Z) = h(p)이며, Z는 X와도 독립이고 Y와도 독립이다(p(z|y) = p^z(1−p)^{1−z}가 y에 무관).

**(n, ε) 부호화 방식 (two-help-one 망).** 세 성분 소스를 각각 블록 길이 n으로 따로 부호화한다.
 f: 𝒳^n → 𝓜_f, g: 𝒴^n → 𝓜_g, h: 𝒵^n → 𝓜_h (치역은 임의 집합)
이 세 함수의 짝 (f, g, h)가 (n, ε) 부호화 방식이라는 것은 복호 함수 φ: 𝓜_f × 𝓜_g × 𝓜_h → 𝒵^n이 있어
 Ẑ^n ≜ φ(f(X^n), g(Y^n), h(Z^n)), Pr{Ẑ^n ≠ Z^n} < ε
를 만족한다는 뜻이다(그림 1: 인코더 X, Y, Z와 복호기 하나).

**율과 달성 가능성.** 율 삼중쌍(rate triple)은 (n⁻¹log‖f‖, n⁻¹log‖g‖, n⁻¹log‖h‖), ‖f‖ = |𝓜_f|. (R_X, R_Y, R_Z)가 ε-달성 가능하다는 것은 임의의 δ > 0과 충분히 큰 n에 대해 율 삼중쌍이 성분별로 δ보다 가까운 (n, ε) 부호화 방식이 존재한다는 뜻이다. 모든 ε > 0에 대해 ε-달성 가능하면 달성 가능하다. ℛ(ε), ℛ은 각각 ε-달성 가능, 달성 가능 삼중쌍 집합.

**두 인코더 문제와의 관계.** 흔히 말하는 "Körner–Marton 문제"(두 인코더가 X^n, Y^n을 따로 보내고 복호기가 Z^n만 복원)는 R_Z = 0 단면이다. 원문은 Z 인코더(도우미가 아니라 Z 자체를 보는 제3 인코더)를 둔 3성분 문제를 푼다. 이것은 Ahlswede–Körner–Wyner의 "one-helps-one"을 "two-help-one"으로 확장한 특수 경우다.

## 3. 주 정리 진술 (원문 대조함)

**정리 1 (Theorem 1).** 모듈로-2 가산기 소스 망에서, X와 Y의 결합분포가 대칭이면 모든 0 < ε < 1에 대해
 ℛ(ε) = ℛ = {(R_X, R_Y, R_Z): R_X + R_Z ≥ H(Z), R_Y + R_Z ≥ H(Z)}.
[원문 220쪽, 쪽 이미지로 대조함. 원문 식의 부등호는 ≥]

**R_Z = 0 단면 (따름 진술).** R_Z = 0이면 영역은 R_X ≥ H(Z), R_Y ≥ H(Z), 즉 R_X, R_Y ≥ h(p)이다. 원문에 별도 번호는 없고 정리 1에서 바로 나온다.

**명제 1 (Proposition 1).** 다음을 Ahlswede–Körner–Wyner 해에서 오는 two-help-one 망의 내부 한계(inner bound)로 정의한다.
 𝒢 ≜ {(R_X, R_Y, R_Z): R_X ≥ I(U∧X|V), R_Y ≥ I(V∧Y|U), R_X + R_Y ≥ I(UV∧XY), R_Z ≥ H(Z|UV)}의 볼록 폐포(convex closure),
 여기서 U, V는 유한 치역의 확률변수이고 UV − XY − Z와 U − X − Y − V가 마르코프 사슬.
대칭 결합분포이고 교차 확률 p ≜ Pr{X≠Y}가 0 < p < 1, p ≠ ½이면 𝒢 ≠ ℛ이다. [원문 221쪽, 대조함. 원문 표기 I(U∧X|V)는 상호정보 I(U;X|V)]

**비고 (원문).** 대칭 가정은 역정리(converse) 쪽에서만 쓰였다.

## 4. 유도

### 4.1 Elias 보조정리 (선형 무손실 소스 부호)

**보조정리 (Elias [원문 진술]).** i.i.d. 이진 열 {Z_i}에 대해, 임의의 ε > 0과 충분히 큰 n에 대해 m×n 0–1 행렬 A와 함수 ψ: {0,1}^m → {0,1}^n이 있어
 1) m < n(H(Z) + ε),
 2) A(z^n)을 A와 열벡터 z^n의 모듈로-2 곱이라 할 때 Pr{ψ(A(Z^n)) ≠ Z^n} < ε.

원문은 이 보조정리를 Elias의 "BSC 용량은 선형 부호로 달성된다"(Gallager 6.2절)의 재해석으로 인용만 하고 증명하지 않는다. 아래는 표준 무작위 선형 부호 논증이다. [재구성]

증명.
1. δ > 0을 고정하고 전형 집합(typical set) T = T_δ^{(n)}(Z)를 잡는다. AEP(점근적 등분배 성질)에 의해 Pr{Z^n ∉ T} → 0이고 |T| ≤ 2^{n(H(Z)+δ)}.
2. m = ⌈n(H(Z) + 2δ)⌉로 두고 A의 성분을 i.i.d. 균등 {0,1}에서 뽑는다.
3. 복호기 ψ(s): A z = s인 z ∈ T가 유일하면 그것을, 아니면 임의 값을 낸다.
4. 오류 사건 ⊂ {Z^n ∉ T} ∪ {∃ z' ∈ T, z' ≠ Z^n, A z' = A Z^n}.
5. z' ≠ z이면 w = z' ⊕ z ≠ 0이고, A w는 F_2^m 위의 균등 분포다(w의 1인 좌표 하나에 대응하는 A의 열이 균등하고 나머지와 독립이므로). 따라서 Pr_A{A z' = A z} = 2^{−m}. 이 쌍별 독립성(pairwise independence)이 선형 부호에서 쓰는 유일한 무작위성 성질이다.
6. 합집합 한계(union bound): E_A[Pr{오류}] ≤ Pr{Z^n ∉ T} + |T|·2^{−m} ≤ Pr{Z^n ∉ T} + 2^{−nδ} → 0.
7. 평균이 ε보다 작으면 그런 A가 하나 존재한다. ε 대신 δ를 작게 잡아 1) m < n(H(Z)+ε)도 만족시킨다. ∎

### 4.2 정리 1 직접부(달성성) [원문]

**(0, 0, H(Z))의 달성.** Z 인코더 혼자 Z^n을 무손실 소스 부호로 보내면 된다(점대점 소스 부호화 정리). 원문은 "자명하다"고만 쓴다.

**(H(Z), H(Z), 0)의 달성 (핵심 단계).**
1. 4.1의 보조정리를 Z_i = X_i ⊕ Y_i에 적용해 A, ψ를 얻는다.
2. 두 인코더가 같은 행렬을 쓴다: f(X^n) ≜ A(X^n), g(Y^n) ≜ A(Y^n). h_0은 상수 함수.
3. 복호기 φ: {0,1}^m × {0,1}^m → {0,1}^n를 φ(a^m, b^m) ≜ ψ(a^m ⊕ b^m)로 정의한다.
4. A가 F_2 위의 선형 사상이므로 A(X^n) ⊕ A(Y^n) = A(X^n ⊕ Y^n) = A(Z^n). 근거: 행렬 곱의 분배법칙(군 준동형(group homomorphism) 성질).
5. 따라서 Pr{φ(A(X^n), A(Y^n)) ≠ Z^n} = Pr{ψ(A(Z^n)) ≠ Z^n} < ε. 근거: 보조정리 2).
6. 율: 𝓜_A = {0,1}^m이므로 n⁻¹log‖A‖ = m/n < H(Z) + ε. 근거: 보조정리 1).
그러므로 (A, A, h_0)는 (n, ε) 부호화 방식이고 (H(Z), H(Z), 0)은 달성 가능하다.

주의: 이 단계는 대칭 가정을 쓰지 않는다. 임의의 결합분포에서 R_X = R_Y = H(X⊕Y)가 달성된다.

**시분할(time-sharing).** (0, 0, H(Z))와 (H(Z), H(Z), 0) 사이의 시분할로
 R_X = R_Y = (1−α)H(Z), R_Z = αH(Z), 0 ≤ α ≤ 1
이 달성된다. 원문은 여기서 멈춘다. 영역 전체로 확장하는 단계 [재구성]: ℛ 안의 임의 점 (R_X, R_Y, R_Z)에서 r = min(R_Z, H(Z))로 두면 R_X, R_Y ≥ H(Z) − r이므로, 이 점은 α = r/H(Z)인 시분할 점을 성분별로 지배한다. 율을 늘리는 것은 항상 허용되므로(사용하지 않는 비트를 덧붙임) 점 전체가 달성된다. 따라서 ℛ ⊆ 달성 가능 영역.

### 4.3 정리 1 역정리 [원문 경로 + 약한 역정리로 보충]

보일 것: 0 < ε < 1, δ > 0을 고정하면, 충분히 큰 n과 임의의 (n, ε) 부호화 방식에 대해
 n⁻¹log‖f‖ + n⁻¹log‖h‖ > H(Z) − δ.
(대칭성에 의해 R_Y + R_Z 쪽도 같다.)

**원문 경로.**
1. g(Y^n) ≜ Y^n(Y를 그대로 복호기에 준다)인 경우만 보이면 충분하다. 근거: Y^n을 그대로 주면 복호기의 정보가 늘기만 하므로 원래 방식이 (n, ε)이면 이것도 (n, ε)이다.
2. k(X^n, Z^n) ≜ (f(X^n), h(Z^n))로 둔다. X^n = Y^n ⊕ Z^n이므로 (g, k)는 "고전적" 부가정보(side information) 망의 (n, ε) 부호화 방식이 된다: 복원 대상 소스는 {(X_i, Z_i)}, 부가정보 소스는 {Y_i}(이것은 율 제한 없이 Y^n 전체를 보냄).
3. 대칭 경우 H(X, Z | Y) = H(Z | Y) = H(Z). 근거: X는 (Y, Z)의 함수이고, Z ⊥ Y.
4. 부가정보 소스 부호화 정리의 강한 역정리(strong converse; Ahlswede–Gács–Körner 1976)에 의해, 고정된 ε < 1에서도 충분히 큰 n에 대해
 n⁻¹log‖f‖ + n⁻¹log‖h‖ = n⁻¹log‖k‖ > H(Z) − δ.
강한 역정리를 쓰는 이유는 정리가 ℛ(ε) = ℛ를 모든 ε ∈ (0,1)에 대해 주장하기 때문이다.

**약한 역정리 형태 (ℛ에 대해서만) [재구성].** 오류 확률 ε_n → 0인 부호 열을 생각한다. M_X = f(X^n), M_Y = g(Y^n), M_Z = h(Z^n).
 n(R_X + R_Z) ≥ H(M_X, M_Z) (근거: 균등 분포가 엔트로피 최대, H(M) ≤ log|𝓜|)
  ≥ H(M_X, M_Z | Y^n) (조건화는 엔트로피를 줄인다)
  ≥ I(M_X, M_Z ; Z^n | Y^n) (H(·|Y^n) ≥ I(·;Z^n|Y^n))
  = H(Z^n | Y^n) − H(Z^n | M_X, M_Z, Y^n)
  ≥ H(Z^n | Y^n) − H(Z^n | M_X, M_Y, M_Z) (M_Y는 Y^n의 함수이므로 조건을 Y^n에서 M_Y로 바꾸면 엔트로피가 늘거나 같다)
  ≥ n H(Z|Y) − nε'_n (무기억성과 Fano 부등식, ε'_n = 1/n + ε_n log|𝒵| → 0)
  = n H(Z) − nε'_n (DSBS에서 Z ⊥ Y).
같은 방식으로 n(R_Y + R_Z) ≥ nH(Z|X) − nε'_n = nH(Z) − nε'_n. 이 유도는 컷셋(cut-set) 한계이며, 비대칭 분포에서는 H(Z|Y) < H(Z)일 수 있어 직접부와 맞지 않는다. 대칭성은 정확히 이 지점에서만 쓰인다(원문 비고와 일치).

**R_Z = 0 단면의 역정리.** 위에서 R_Z = 0을 넣으면 R_X ≥ H(Z|Y) = h(p), R_Y ≥ H(Z|X) = h(p). 이는 직접부와 일치하므로 두 인코더 KM 영역 {R_X ≥ h(p), R_Y ≥ h(p)}가 DSBS에서 정확한 영역이다.

### 4.4 무작위 비닝(Slepian–Wolf)이 더 필요한 이유

#### (a) Slepian–Wolf 영역과의 비교 (DSBS 닫힌 식)

Slepian–Wolf(SW) 영역(X^n, Y^n 둘 다 복원): R_X ≥ H(X|Y) = h(p), R_Y ≥ H(Y|X) = h(p), R_X + R_Y ≥ H(X,Y) = 1 + h(p).
KM 영역(Z^n만 복원): R_X ≥ h(p), R_Y ≥ h(p), 합 율 제약 없음, 최소 합 율 2h(p).
2h(p) < 1 + h(p) ⇔ h(p) < 1 ⇔ p ≠ ½. 따라서 0 < p < 1, p ≠ ½이면 KM 영역은 SW 영역을 진부분집합으로 포함한다. 합 율 절약량은 1 − h(p) 비트/심볼이다.

#### (b) 비구조적 무작위 비닝의 앙상블 분석 [재구성, 발견적]

인코더가 독립 균등 무작위 함수 B_X: {0,1}^n → [2^{nR_X}], B_Y: {0,1}^n → [2^{nR_Y}]로 비닝하고, 복호기가 (b_x, b_y)와 들어맞는 전형 쌍(x', y')으로부터 z' = x' ⊕ y'를 낸다고 하자.
1. 참 z와 다른 전형 z'(개수 ≈ 2^{nh(p)})에 대해, 같은 빈 쌍에 떨어지는 쌍 (x', x'⊕z')이 존재할 확률은, x' 후보가 2^n개이고 각 후보가 두 빈 조건을 만족할 확률이 2^{−n(R_X+R_Y)}이므로 ≈ min{1, 2^{n(1 − R_X − R_Y)}}.
2. 따라서 잘못된 z' 개수의 기댓값 ≈ 2^{nh(p)} · min{1, 2^{n(1−R_X−R_Y)}}. 이것이 0으로 가려면 R_X + R_Y > 1 + h(p) = H(X,Y).
3. 반면 선형 비닝에서는 빈이 같은 선형 부호의 잉여류(coset)이므로 B(x) ⊕ B(y) = B(x ⊕ y)가 되어, 빈 쌍이 z의 빈 하나로 "붕괴"한다. 잘못된 z' 개수 기댓값은 2^{nh(p)} · 2^{−m}이고 m > nh(p)이면 충분하다.
요점: 독립 비닝은 빈 쌍 (b_x, b_y)에 x, y 각각의 정보를 담아 두지만 z에 관한 정보를 따로 모아 두지 않는다. 그래서 z를 알기 위해 사실상 (x, y)를 모두 알아내야 한다. 이 분석은 특정 앙상블과 특정 복호기에 대한 것이므로 "모든 비구조 부호"에 대한 역정리는 아니다. 그 엄밀한 형태가 아래 명제 1이다.

#### (c) 명제 1의 증명: Berger–Tung/AKW형 내부 한계 𝒢는 (H(Z), H(Z), 0)을 포함하지 않는다

𝒢는 "각 인코더가 보조 변수 U(또는 V)로 양자화하고 무작위 비닝으로 보내는" 비구조 방식이 달성하는 영역이다. 증명 목표: 대칭 분포, 0 < p < 1, p ≠ ½에서 (H(Z), H(Z), 0) ∉ 𝒢.

**정확형 논증 (볼록 폐포를 무시한 단일 (U,V)) [재구성].** U − X − Y − V이고 H(Z|UV) = 0이라 하자.
1. H(X|U) > 0이라 가정하면 어떤 u에 대해 Pr{X=0, U=u} > 0, Pr{X=1, U=u} > 0.
2. 0 < p < 1이므로 p(x,y) > 0 (모든 x, y). U − X − Y에 의해 Pr{U=u, X=x, Y=y} = Pr{U=u, X=x}p(y|x) > 0 (x = 0, 1, 임의 y).
3. y를 하나 고르고 Pr{V=v|Y=y} > 0인 v를 고른다. X − Y − V(U − X − Y − V의 일부)와 (U,X) − Y − V에 의해 Pr{U=u, X=x, Y=y, V=v} = Pr{U=u, X=x, Y=y}·Pr{V=v|Y=y} > 0 (x = 0, 1).
4. 그러면 (U, V) = (u, v)에서 Z = x ⊕ y는 0과 1 둘 다 양의 확률로 나오므로 H(Z|U=u, V=v) > 0이고 H(Z|UV) > 0. 모순. 따라서 H(X|U) = 0, 같은 방식으로 H(Y|V) = 0.
5. 그러므로 I(UV; XY) = H(XY) − H(XY|UV) = H(XY) = 1 + h(p).
6. R_X + R_Y ≥ I(UV; XY) = 1 + h(p) > 2h(p) = 2H(Z). 근거: p ≠ ½이면 h(p) < 1. 따라서 (H(Z), H(Z), 0)은 이 (U,V)로 달성되지 않는다.

**볼록 폐포까지 포함한 강건형 [원문 부록].** 𝒢가 볼록 폐포이므로 혼합 지표 α(분포 μ를 갖는 집합 𝒜 위)로 (U_α, V_α)를 섞은 것을 다뤄야 하고, 또 극한점도 다뤄야 한다. 원문은 다음을 보인다: 모든 ε > 0에 대해 δ > 0이 있어
 (A.1) U_αV_α − XY − Z, U_α − X − Y − V_α,
 (A.2) ∫ H(Z|U_αV_α) μ(dα) < δ 이면
 (A.3) ∫ I(U_αV_α ∧ XY) μ(dα) > H(XY) − ε.
H(XY) > 2H(Z)이므로 이것으로 명제가 나온다. 핵심 단계는 (A.4) μ({α: H(X|U_α) > ε}) < ε를 보이는 것이다.
1. (A.1)에서 H(Z|U_αY) ≤ H(Z|U_αV_α) (V_α는 Y의 잡음 섞인 함수이므로 데이터 처리), 따라서 (A.2)에서 (A.5) ∫ H(Z|U_αY) μ(dα) < δ.
2. (A.4)가 거짓이면 μ(𝒜') ≥ ε, H(X|U_α) ≥ ε (α ∈ 𝒜')인 𝒜'가 있다.
3. ε와 p에만 의존하는 상수 ε_1, …, ε_5 > 0이 있어 α ∈ 𝒜'마다: 1) Pr{U_α ∈ 𝔅_α} > ε_1이고 u ∈ 𝔅_α에서 H(X|U_α=u) > ε_2인 집합 𝔅_α가 있고; 2) u ∈ 𝔅_α에서 Pr{X=x|U_α=u} > ε_3 (x = 0,1); 3) Pr{X=x, Y=y|U_α=u} = Pr{X=x|U_α=u}·Pr{Y=y|X=x} > ε_4이므로 Pr{X=x|U_α=u, Y=y} > ε_4; 4) H(Z|U_α=u, Y=y) > ε_5.
4. (A.6), 1), 4)를 합치면 ∫H(Z|U_αY)μ(dα) ≥ ε·ε_1·min_{x,y} p(y|x)·ε_5 (근거: Pr{Y=y|U_α=u} = Σ_x Pr{X=x|U_α=u}p(y|x) ≥ min p(y|x))이므로 δ가 충분히 작으면 (A.5)와 모순.
이로부터 대부분의 α에서 H(X|U_α)와 H(Y|V_α)가 작고, 따라서 I(U_αV_α ∧ XY)가 H(XY)에 가깝다. 원문은 (A.4)에서 (A.3)으로 가는 마지막 단계를 "충분하다"고만 적는다. 그 단계는 I(UV∧XY) ≥ H(XY) − H(X|U) − H(Y|V)와 H(X|U_α) ≤ 1을 써서 ∫ ≥ H(XY) − 2(ε + ε·1) 꼴로 마무리된다. [재구성]

**해석.** 명제 1은 "Berger–Tung형 비구조 방식으로는 합 율 2H(Z)에 도달할 수 없고, 이 문제에서 그 방식들의 합 율 하한은 H(XY)"라는 뜻이다. 즉 two-help-one 문제의 자연스러운 추측(𝒢 = ℛ)이 틀렸다는 반례다.

## 5. 예제 (이진, 닫힌 식)

**DSBS, p = 0.11.** h(0.11) ≈ 0.4999 ≈ ½.
- KM: R_X = R_Y = 0.5, 합 율 1.0.
- SW: 합 율 ≥ 1 + 0.5 = 1.5. 대칭점 R_X = R_Y = 0.75.
- 절약: 0.5 비트/심볼 (= 1 − h(p)).
- p → 0이면 KM 합 율 2h(p) → 0, SW 합 율 → 1. 비 (1+h(p))/(2h(p)) → ∞.
- p = ½이면 Z가 X, Y 각각과 독립이고 균등이라 h(p) = 1, 두 영역의 합 율이 2로 같다(명제 1에서 p ≠ ½를 제외한 이유).

**비대칭 분포 (정리 1 밖).** 대칭이 아닌 일반 분포에서 KM 달성 R_X = R_Y = H(X⊕Y)와 컷셋 하한 R_X ≥ H(Z|Y), R_Y ≥ H(Z|X)는 일반적으로 다르다. 예: X ~ Bern(q), Y ⊥ X ~ Bern(q), q 작음: H(Z) ≈ h(2q(1−q)) > h(q) = H(X) — 이때는 KM이 각자 X, Y를 보내는 것(R_X = H(X))보다 나쁘다. 즉 선형 부호는 H(X⊕Y) < min{H(X), H(Y)} 같은 구조에서만 이득이다 (후속 문헌의 Ahlswede–Han 1983 영역이 두 방식을 결합한다는 것은 기억에 의존).

## 6. 원문과의 차이·빈틈

1. **Elias 보조정리 무증명.** 원문은 인용만 한다(Gallager 6.2절, Wyner 1974 해석). 4.1에 쌍별 독립성 기반 증명을 보충했다. [재구성]
2. **영역 전체로의 확장.** 원문은 시분할 직선만 보이고 "율 증가는 자유"라는 단조성 단계를 생략했다. [재구성]
3. **강한 역정리 의존.** 역정리는 Ahlswede–Gács–Körner의 강한 역정리(blowing-up 보조정리 기반)를 블랙박스로 쓴다. ℛ에 대해서만 말하면 Fano 기반 약한 역정리로 충분하다(4.3). ℛ(ε) = ℛ (모든 ε)의 주장에는 강한 역정리가 필요하다.
4. **명제 1의 마지막 단계 생략.** (A.4) ⇒ (A.3)과, (A.4)를 Y 쪽(H(Y|V_α))에도 적용하는 대칭 단계를 원문이 생략한다. [재구성] 상수 ε_1…ε_5의 존재도 "정의할 수 있다"로만 적혀 있다.
5. **일반 분포.** 원문 IV절 말미대로 이 증명은 대칭 분포의 특수성에 크게 의존하고 일반 two-help-one 문제에는 통찰을 거의 주지 않는다. 이후 Ahlswede–Han(1983)이 비닝과 선형 부호를 결합한 내부 한계를, Han–Kobayashi(1987, 08번)가 "SW보다 작은 영역이 가능한 함수"의 분류를 주었다(기억에 의존한 연결이며 08번은 원문 확인함). 최근 Tsujino–Watanabe 2026(SURVEY에 정리됨)은 다문자 AH가 SW를 이기는 필요충분 조건을 준다.
6. **유한체 F_2 의존.** 선형 부호의 쌍별 독립성은 체(field) 구조에서 온다. ℤ_M (M 합성수) 같은 환(ring) 위에서는 A w가 균등이 아닐 수 있어(w의 성분이 영인자(zero divisor)이면 A w는 부분군에 갇힘) 같은 율이 나오지 않는다. 이것은 Krithivasan–Pradhan의 아벨 군 부호(Abelian group codes) 연구에서 다뤄졌다(기억에 의존).

## 7. 본 연구와의 연결

본 연구 모형: K명 작업자 X_k ~ N(0, σ²) 독립, Q_k = f_k(X_k, W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만 계산, 복호기 Ŝ = g(Z, W)로 S = ΣX_k 추정. 정리 A(가설): log₂M ≥ ½log₂(K/D̄) − c, D̄ = E(S−Ŝ)²/(Kσ²). 증명 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½log₂K − c.

1. **KM 방식은 스위치 제약을 정확히 만족한다.** KM 복호기의 첫 단계 φ(a, b) = ψ(a ⊕ b)는 메시지를 군 F_2^m에서 더하기만 하고, 이후 ψ는 합만 본다. 즉 "스위치 = 군 덧셈, 복호기 = 합 메시지의 함수"라는 본 연구의 구조와 동일하다. DSBS에서 KM은 최적이므로, **이진 무손실 + 함수 = 군 연산인 경우에는 스위치 제약의 대가가 0**이다.

2. **대가가 0인 이유를 본 연구 사슬로 쓰면.** KM에서 스위치 출력 Z_KM = A(X^n) ⊕ A(Y^n) = A(Z^n)은 목표 Z^n의 결정적 함수다. 따라서 H(Z_KM | 목표) = 0이고 log|메시지| ≥ H(Z_KM) = I(목표; Z_KM). 본 연구 사슬의 둘째 항 H(Z|S,W)가 KM에서는 정확히 0이다. 정리 A의 ½log₂K 대가는 전부 이 항에서 온다고 가설로 두고 있으므로, KM과 본 연구의 차이는 "**스위치 출력이 목표의 함수인가**"로 요약된다.

3. **실수 합에서 그것이 불가능한 대수적 이유 (단서).** KM에서 인코더 A는 소스 군 F_2^n에서 메시지 군 F_2^m으로 가는 준동형이고, 목표 함수 ⊕가 바로 그 군 연산이다. 본 연구에서 소스 군은 (ℝ, +), 메시지 군은 ℤ_M이다. ℝ은 나눗셈 가능 군(divisible group)이고 유한군의 나눗셈 가능 부분군은 자명하므로 **Hom(ℝ, ℤ_M) = {0}**: 0이 아닌 준동형 인코더가 존재하지 않는다. 그래서 인코더는 "양자화(준동형 아님) 후 축약"이 될 수밖에 없고, 양자화 결함(반올림 오차)이 K개 더해진다. ΣQ_k는 Σ(반올림된 X_k)이지 (ΣX_k)의 반올림이 아니며, 그 차이 Σε_k가 S를 알아도 남는 불확실성 H(Z|S,W)가 된다. 반올림 오차가 i.i.d. 연속(디더 사용 시 균등)이면 엔트로피 거듭제곱 부등식(EPI)으로 h(Σε_k) ≥ h(ε_1) + ½log₂K이므로, 격자 간격 단위로 잰 H(Z|S,W)가 ½log₂K − O(1)이 된다는 것이 보조정리 L의 자연스러운 증명 경로다(추정. mod M 감김과 비디더 인코더 처리가 남은 과제).

4. **KM 역정리 기법의 한계.** KM 역정리는 컷셋(Y^n을 복호기에 줌)이다. 본 연구에 그대로 적용하면 log₂M ≥ I(S;Z|W) ≥ R_S(D) = ½log₂(1/D̄)만 나오고 ½log₂K 항은 나오지 않는다. 컷셋/정보 주입(genie)형 하한은 비제약 문제에도 똑같이 성립하는 한계이므로 스위치 제약의 대가를 원리적으로 잡지 못한다. 정리 A를 위해서는 H(Z|S,W)를 직접 아래로 묶는, 제약에 특화된 논증이 필요하다.

5. **명제 1과의 유비.** 명제 1의 핵심은 "양의 확률(전체 지지) + 함수의 행이 서로 구별됨 ⇒ 인코더가 X를 전부 드러내야 함(H(X|U)=0)"이다. 본 연구의 연속 판본은 "가우시안의 전체 지지 + ℝ과 ℤ_M 덧셈의 불일치 ⇒ Z가 S의 함수일 수 없음(H(Z|S,W) > 0)"이고, 정량적 ½log₂K는 3의 EPI 경로로 얻어야 한다. 명제 1의 "작은 δ ⇒ 작은 ε" 강건형 논증 구조(상수 ε_i를 분포에만 의존하게 잡기)는 보조정리 L의 안정성 판본을 쓸 때 형식 틀로 참고할 만하다.

6. **이득/손해 판정.** 이진·상관(p ≠ ½) 소스에서 선형 부호는 SW 대비 이득(1 − h(p) 비트)이고 스위치 제약과 양립한다. 독립 소스(p = ½에 해당)에서는 이득이 0이다(두 영역의 합 율이 같다). 본 연구의 X_k는 독립이므로, KM형 "상관 이용 이득"은 원천적으로 없다. 남는 것은 군 덧셈 제약이 실수 합과 맞지 않아 생기는 손해뿐이라는 것이 이 논문이 주는 가장 직접적인 단서다.
