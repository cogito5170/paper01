# Zamir–Feder 1992 — 무작위화 균일·격자 양자화기에 의한 보편 양자화 (On Universal Quantization by Randomized Uniform/Lattice Quantizers)

## 1. 서지

- R. Zamir and M. Feder, "On Universal Quantization by Randomized Uniform/Lattice Quantizers," *IEEE Transactions on Information Theory*, vol. 38, no. 2, pp. 428–436, March 1992 (Correspondence). (원고 접수 1990-04-09, 수정 1991-05-30)
- 원문 파일: `papers/classic/23_Zamir-Feder1992.pdf` (9쪽; 1쪽 위쪽은 앞 논문, 9쪽 아래는 Feder의 다른 논문). 원문 429–433쪽을 쪽 이미지로 직접 대조했다.
- 번호 붙은 결과: Theorem 1, 2, 3, 부록 A (Theorem 1의 격자 일반화), 부록 B (용량 상·하한). 식 (1)–(58).

## 2. 문제 설정 (원문 기호)

- 균일 양자화기: 부호점 {0, ±Δ, ±2Δ, …}, Q(x) = iΔ (iΔ − Δ/2 ≤ x ≤ iΔ + Δ/2).
- 디더 Z ~ U[−Δ/2, Δ/2]. 무작위화(디더) 양자화기의 표현 (1): u = Q(x + z) − z (감산 디더, 복호기가 z를 앎).
- 차분 왜곡 측도(difference distortion measure) δ(x − u). (2): E_z{δ(Q(x+z) − z − x)} = (1/Δ)∫_{−Δ/2}^{Δ/2} δ(α) dα = ε, 모든 x에 대해.
- 격자: K차원 격자 L_K, 최근접 격자점 양자화 Q_K, 보로노이 셀 𝒱(l_i), 기본 셀 𝒱_0 = 𝒱(0). Z ~ U(𝒱_0). (3): u = Q_K(x + z) − z.
- 정규화 2차 모멘트 (6): G_K = (1/K) ∫_{𝒱_0}‖x − x̂‖²dx / (∫_{𝒱_0}dx)^{1+2/K}, G_1 = 1/12, min G_K → 1/(2πe).
- n차원 소스 벡터: 스칼라 경우 성분마다 **독립** 디더, 격자 경우 n/K개 부분벡터마다 독립 디더(Ziv 1985의 "한 Z를 n번 반복"과 다름).
- 보조 채널(auxiliary channel, 그림 1): Y = X + N, N은 X와 독립, f_N(n) = f_Z(−n) (기본 셀의 거울상 위 균일).
- 잉여율(redundancy) (8): ρ_{K,n}(ε) = (1/n)H(Q_K | Z) − R_n(ε), R_n(ε) = inf (1/n)I(X; U) s.t. (1/n)E δ(U − X) ≤ ε (식 (9)).
- 로그 밑 2, 엔트로피는 비트. H(·)는 이산·미분 엔트로피를 모두 뜻함. P(·)는 엔트로피 거듭제곱(entropy power) P(Y) = (1/(2πe))2^{(2/n)H(Y)}.

## 3. 주 정리 진술 (원문 대조함)

- **Theorem 1** (식 (14)): 눈금 Δ의 무작위화 균일 양자화기로 확률변수 X를 부호화할 때
  H(Q | Z) = I(X; Y) = H(X + N) − H(N) = H(Y) − log Δ,
  Y = X + N, N ~ U[−Δ/2, Δ/2]는 X와 독립.
  - 벡터·i.i.d. 디더 (18): (1/n)H(Q_1 | Z) = (1/n)I(X; Y) = (1/n)H(Y) − log Δ.
  - 격자 (20) (부록 A에서 증명): (1/n)H(Q_K | Z) = (1/n)I(X; Y) = (1/n)H(Y) − (1/K) log V, V = 보로노이 셀 부피. 부분벡터가 종속이어도 성립.
- **Theorem 2** (식 (22)–(23)): 스칼라 균일 무작위화 양자화기의 잉여율
  ρ_{1,1}(ε) = H(Q | Z) − R(ε) ≤ C,  C = sup_{f_X: E δ(X) ≤ ε} I(X; X + N).
  - 도달 가능 (29): 용량 달성 입력 X*에서 등호. 따라서 모든 왜곡 수준에 대해 성립하는 상수 상한으로는 개선 불가.
  - 제곱 오차에서 (30): ½log(1 + 2πe/12) ≤ C < ½log(4πe/12). (하한 0.638, 상한 0.754, 상한은 엄격)
  - 격자 (31)–(33): ρ_{K,n}(ε) ≤ C, ½log(1 + 2πeG_K) ≤ C < ½log(4πeG_K). K → ∞에서 둘 다 0.5로.
- **Theorem 3** (식 (36)): 제곱 오차에서 무작위화 격자 양자화기의 잉여율
  ρ_{K,n}(ε) = (1/n)H(Q_K | Z) − R_n(ε) ≤ ½ log (P(Y)/P(X)) + ½ log 2πeG_K.
  - 고해상도 (13)·(44): ρ_{K,n}(ε) ≤ ½log 2πeG_K (ε → 0, 매끄러운 밀도). 원문 (35) 뒤: "이 고해상도 한계는 보편 한계보다 0.5 bit/표본 낫다."
- 서론 (12)는 Theorem 3과 같은 식을 미리 적은 것이다.
- 원문은 0.254라는 **숫자**를 쓰지 않는다. K = 1, G_1 = 1/12를 넣으면 ½log₂(2πe/12) = 0.2546.

## 4. 유도

### 4.1 오차가 셀 위 균일이고 입력과 독립 [재구성 — 원문은 (2)의 평균 왜곡만 "easy to show"로 진술]

1. 격자 L_K의 기본 셀 𝒱_0는 Rᴷ를 L_K-평행이동으로 빈틈없이 덮는다. 사상 x ↦ x mod 𝒱_0 := x − Q_K(x)를 생각한다.
2. 임의의 고정 x에 대해 Z ~ U(𝒱_0)이면 (x + Z) mod 𝒱_0 ~ U(𝒱_0). 근거: 토러스 Rᴷ/L_K 위 균일측도는 평행이동 불변이고, 𝒱_0 위 균일분포는 그 토러스 위 균일측도와 같다. (스칼라에서는 Schuchman 조건 Φ_Z(2πm/Δ) = 0의 다변수판: U(𝒱_0)의 특성함수는 쌍대 격자의 0 아닌 점에서 0.)
3. 오차 E := Q_K(x + Z) − Z − x = Q_K(x+Z) − (x+Z) = −[(x + Z) mod 𝒱_0]. 따라서 E ~ U(−𝒱_0), 그리고 이 분포는 x에 무관하다.
4. 그러므로 X가 Z와 독립인 임의의 확률벡터이면 E는 X와 독립이고 U(−𝒱_0)를 따른다. 출력 U = X + E는 보조 채널 그림 1의 Y = X + N과 **같은 결합분포** (X, Y)를 갖는다. 원문의 f_N(n) = f_Z(−n)(거울상)이 정확히 이 부호에서 나온다.
5. 따름: 차분 왜곡 E δ(U − X) = E δ(E) = (1/V)∫_{𝒱_0} δ(−a)da (대칭 셀이면 (2)·(21)). [원문 (2), (21)과 일치]

### 4.2 Theorem 1: H(Q|Z) = I(X; X+N) — 원문의 직접 계산 [원문]

6. 디더 z가 주어지면 출력 q′_i = q_i − z, q_i = iΔ. 확률
   P(q′_i | z) = Prob{q_i − Δ/2 ≤ X + z ≤ q_i + Δ/2} = ∫_{q′_i − Δ/2}^{q′_i + Δ/2} f_X(x) dx. [원문]
7. Y = X + N의 밀도: f_Y(y) = (f_X ∗ f_N)(y) = (1/Δ)∫_{y−Δ/2}^{y+Δ/2} f_X(x)dx. 따라서 P(q′_i | z) = Δ·f_Y(q_i − z). [원문]
8. (15): H(Q | Z) = E_z{−Σ_i Δ f_Y(q_i − z) log(Δ f_Y(q_i − z))}. [원문]
9. (16): z ~ U[−Δ/2, Δ/2]로 평균하면 (1/Δ)∫_{−Δ/2}^{Δ/2} Σ_i (·)(iΔ − z) dz = (1/Δ)∫_ℝ (·)(y) dy (격자점 합과 한 셀 적분이 실수 전체 적분을 이룬다). 그리고 Σ_i Δ f_Y(q_i − z) = 1이 모든 z에서 성립하므로 −log Δ 항이 분리된다:
   H(Q | Z) = −∫ f_Y log f_Y dy − log Δ = H(Y) − log Δ. [원문]
10. H(N) = log Δ (균일 밀도), H(Y | X) = H(N)이므로 H(Y) − log Δ = H(Y) − H(Y|X) = I(X; Y). → (14). [원문]

### 4.3 Theorem 1의 정보이론적 별증 [재구성]

11. (Q, Z) ↔ (Y′, Z)는 일대일 (Y′ := Q − Z = 출력 u). 그리고 Z는 Y′의 함수다: Y′ + Z = Q ∈ ΔZ이므로 Z ≡ −Y′ (mod Δ)이고 Z ∈ [−Δ/2, Δ/2). 따라서 (Q, Z) ↔ Y′.
12. I(X; Q, Z) = I(X; Z) + I(X; Q | Z) = 0 + H(Q | Z) − H(Q | X, Z) = H(Q | Z) (Q는 (X, Z)의 함수).
13. I(X; Q, Z) = I(X; Y′) = I(X; X + N) (4.1에 의해 (X, Y′)의 결합분포가 (X, X + N)과 같음).
14. 따라서 H(Q|Z) = I(X; X+N). 이 증명은 격자·벡터·종속 부분벡터에 그대로 통한다 (부록 A의 결론 "부분벡터가 종속이어도 성립"과 일치).

### 4.4 격자 일반화 (20), 부록 A [원문]

15. P(q_i | z_K) = Prob{x_K + z_K ∈ q_i + 𝒱_0} = V·f_{Y_K}(q_i − z_K), Y_K = X_K + N_K, N_K ~ U(−𝒱_0) → (48). [원문]
16. z_K ~ U(𝒱_0) 평균, 격자점 합 + 셀 적분 = Rᴷ 적분 → H(Q_K | Z_K) = H(Y_K) − log V (45). n/K개 부분벡터로 확장하면 (20). [원문]
17. 왜곡과 부피의 관계 (21), (38): 제곱 오차에서 ε = (1/K)∫_{𝒱_0}(1/V)‖a‖²da = G_K V^{2/K}, 곧 (1/K) log V = ½ log(ε/G_K). [원문]

### 4.5 Theorem 2: ρ ≤ C [원문]

18. R(ε)를 달성하는 U는 f_{U|X}에 대한 최소화이므로 N과 독립으로 잡을 수 있다 (24). [원문]
19. (25): H(Q|Z) − I(X;U) = I(X;Y) − I(X;U). [원문, Thm 1]
20. (26): 항등식 I(X;Y) − I(X;U) = H(X|U) − H(X|Y) = I(X;Y|U) − I(X;U|Y) ≤ I(X;Y|U). [원문]
21. (27): I(X;Y|U) = H(Y|U) − H(Y|X,U) = H(Y|U) − H(N) (N이 (X,U)와 독립) = H(Y − U | U) − H(N) ≤ H(Y − U) − H(N) = I(X − U; X − U + N). 마지막 등호는 N이 X − U와 독립이므로. [원문]
22. (28): E δ(X − U) ≤ ε이므로 X − U는 용량 정의 (23)의 허용 입력 → I(X − U; X − U + N) ≤ C. [원문]
23. U를 R(ε) 달성 변수로 잡으면 H(Q|Z) − R(ε) ≤ C. □ [원문]
24. 도달 가능 (29): X*가 용량 달성 입력이면 E δ(X*) ≤ ε이므로 U ≡ 0이 허용되어 R(ε; X*) = 0, 그리고 H(Q(X* + Z)|Z) = I(X*; X* + N) = C. [원문]
    - 해석 [재구성]: 최악의 경우는 "소스 분산이 왜곡 이하"인 저해상도이다. 이때 R(ε) = 0인데 디더 양자화기는 여전히 양의 엔트로피를 쓴다.

### 4.6 제곱 오차에서 C의 상·하한 (부록 B, 식 (30), (51)–(52)) [원문]

25. 상한: E X² ≤ ε, E N² = Δ²/12 = ε ⇒ E Y² ≤ 2ε. 최대 엔트로피: H(Y) ≤ ½log(2πe·2ε). H(N) = log Δ = ½log(12ε). 따라서
    C ≤ ½log(2πe·2ε) − ½log(12ε) = ½log(4πe/12) = 0.7546. (51) [원문]
26. 엄격성: 등호는 Y가 가우시안이어야 하는데, 독립 합 X + N이 가우시안이려면 N이 가우시안이어야 한다(크라메르 정리, [재구성: 원문은 정리 이름 없이 서술]). N은 균일이므로 C < 0.754. [원문]
27. 하한: 엔트로피 거듭제곱 부등식 P(X + N) ≥ P(X) + P(N), X* = N(0, ε) (2차 모멘트 제약 하 최대 엔트로피), P(N) = Δ²/(2πe) = 12ε/(2πe):
    C ≥ ½log((2πeε + 12ε)/(12ε)) = ½log(1 + 2πe/12) = 0.6385. (52) [원문]
28. 격자: 1/12 → G_K로 바꾸면 (33). [원문]
29. |x|^r 왜곡에 대한 상·하한 (53)–(58): 하한 값 0.755, 0.638, 0.595, …, 0.5 (r = 1, 2, 3, …, ∞), 상한 C_r 1.44, 1.254, 1.180, …, 1, 짝수 r에서 개선 0.754, 0.888, …, 1 (r = 2, 4, …). [원문 수치, 식 (53)–(58)의 세부는 텍스트 추출이 일부 깨져 개별 식은 미확인]

### 4.7 Theorem 3 [원문]

30. (37): (20)에서 (1/n)H(Q_K | Z) = (1/n)H(Y) − (1/K) log V. [원문; 원문 (37)의 등호 우변에 −R_n(ε)가 인쇄에서 빠져 있음, 재구성으로 보완]
31. (38): (1/K) log V = ½ log(ε/G_K). [원문]
32. (39): 섀넌 하한 R_n(ε) ≥ R_n^L(ε) = (1/n)H(X) − ½ log 2πeε. [원문]
33. (40): 합치면 (1/n)H(Q_K|Z) − R_n(ε) ≤ (1/n)[H(Y) − H(X)] − ½log(ε/G_K) + ½log 2πeε = (1/n)[H(Y) − H(X)] + ½ log 2πeG_K. [원문]
34. 엔트로피 거듭제곱 정의로 (1/n)[H(Y) − H(X)] = ½ log(P(Y)/P(X)) → (36). □ [원문]
35. 고해상도 (41)–(44): 셀이 작고 밀도가 매끄러워 f_Y ≈ f_X (상대 오차 < ε_r)이면 |H(Y) − H(X)| < ε_r[H(X) + log M] (M = f_X의 상계), 따라서 (1/n)[H(Y) − H(X)] → 0, ρ → ½log 2πeG_K. 그리고 R_n^L → R_n이므로 이 한계는 보편적으로 달성된다. [원문; 부등식 |H(Y) − H(X)| < ε_r[…]는 "simple algebraic manipulations"로만 언급, 세부 미확인]

### 4.8 0.754와 0.254의 관계 [재구성]

36. 0.754 = ½log₂(4πe/12) = ½log₂(2πe·2·G_1): Y의 2차 모멘트가 최대 2ε (입력 ε + 잡음 ε)일 때 가우시안 엔트로피 − 균일 잡음 엔트로피. 저해상도(입력 분산 ≈ ε) 최악.
37. 0.254 = ½log₂(2πe/12) = ½log₂(2πeG_1): 고해상도에서 Y ≈ X이므로 P(Y)/P(X) → 1, 남는 것은 "분산 ε 가우시안 엔트로피 − 분산 ε 균일 엔트로피" = 입방체 셀의 공간 채움 손실(space-filling loss).
38. 둘의 차 0.5 bit = ½log₂2 = "Y의 분산이 ε에서 2ε로" 차이. 원문 (35) 뒤 "0.5 bit 낫다"와 일치.

## 5. 예제

### 5.1 가우시안 소스 X ~ N(0, σ²), 제곱 오차, 스칼라 (σ = 1, 수치 적분 [재구성 수치])

정확한 율: H(Q|Z) = H(X + N) − log₂Δ, Δ = √(12ε). ε < σ²이면 R(ε) = ½log₂(σ²/ε) = 섀넌 하한(가우시안에서 정확)이므로 Theorem 3이 **등식**:
ρ(ε) = ½log₂(P(Y)/σ²) + ½log₂(2πe/12). (원문 III절: "가우시안에서는 (14)와 (36)이 같다")
P(Y) ≤ Var Y = σ² + ε, P(Y) ≥ σ² + 12ε/(2πe) (EPI)이므로
½log₂(1 + 6ε/(πeσ²)) + 0.254 ≤ ρ(ε) ≤ ½log₂(1 + ε/σ²) + 0.254.

| ε/σ² | H(Q|Z) | R(ε) | ρ(ε) | ½log₂(1+ε)+0.2546 |
|---|---|---|---|---|
| 0.001 | 5.2382 | 4.9829 | 0.2553 | 0.2553 |
| 0.01 | 3.5837 | 3.3219 | 0.2618 | 0.2618 |
| 0.05 | 2.4508 | 2.1610 | 0.2898 | 0.2898 |
| 0.1 | 1.9843 | 1.6610 | 0.3234 | 0.3234 |
| 0.25 | 1.4155 | 1.0000 | 0.4155 | 0.4156 |
| 0.5 | 1.0465 | 0.5000 | 0.5465 | 0.5471 |
| 1 | 0.7508 | 0 | 0.7508 | 0.7546 |
| 2 | 0.5319 | 0 | 0.5319 | — |
| 10 | 0.2379 | 0 | 0.2379 | — |

- 최대 ρ = 0.7508 (ε = σ² 근처). 원문 그림 2의 "최대 0.75 bit, 0.754보다 약간 작다"와 일치. ε ≥ σ²에서는 R = 0이고 ρ = H(Q|Z)가 감소.
- 고해상도에서 0.254로 수렴.

### 5.2 균일 소스 X ~ U[0, A], A = LΔ (L 정수) [재구성]

- Y = X + N은 사다리꼴 밀도(가운데 1/A, 양끝 폭 Δ의 선형 경사). 계산: H(Y) = log₂A + (Δ/(2A))log₂e.
- 정확한 율: H(Q|Z) = log₂L + log₂e/(2L).
- Theorem 3: ρ ≤ (H(Y) − H(X)) + 0.254 = 0.7213/L + 0.254. L → ∞에서 0.254.
- 디더 없는 결정적 양자화(격자가 지지와 맞물림)는 H = log₂L로 log₂e/(2L)만큼 적다. 디더는 대가로 경계 번짐(edge spreading)만큼 율을 낸다.

### 5.3 고차원 격자

- G_K → 1/(2πe)이면 고해상도 잉여율 → 0, 보편 상한 → 0.5 bit. 원문 그림 3: G_K = 1/(2πe) 가정에서 가우시안 잉여율 = ½log₂(P(Y)/P(X)) → (K → ∞) ½log₂(1 + ε/σ²).

## 6. 원문과의 차이·빈틈

- "오차가 셀 위 균일이고 입력과 독립"은 원문에서 정리로 증명되지 않는다. (2)의 평균 왜곡 불변성과 그림 1의 "보조 채널"로 제시될 뿐이다. 4.1에서 보충.
- Theorem 1의 원문 증명은 직접 계산이고, 결합분포 동치 (X, U) =ᵈ (X, X+N)은 쓰지 않는다. 4.3의 별증이 더 일반적.
- 식 (37)의 우변에 −R_n(ε) 인쇄 누락.
- 고해상도 극한 (41)–(44)의 부등식 세부 생략, "simple algebraic manipulations".
- 0.254라는 숫자는 원문에 없다(식 ½log 2πeG_K만 있음). 0.754는 원문에 숫자로 있다.
- 디더를 한 번만 뽑는 Ziv 방식에서는 율이 약간 다를 수 있으나 상수 상한과 고해상도 표현은 그대로라고 결론부에서 서술 (증명은 석사 논문 [8]).

## 7. 본 연구와의 연결

본 연구: X_k ~ N(0, σ²) 독립(k = 1…K), Q_k = f_k(X_k, W) ∈ ℤ_M, Z = ΣQ_k mod M, Ŝ = g(Z, W), D̄ = E(S − Ŝ)²/(Kσ²). 정리 B: 감산 디더 균일 양자화 Q_k = round((X_k + d_k)/Δ) mod M, d_k ~ U[−Δ/2, Δ/2] 작업자별 독립, Δ² = 12D/K (D = D̄Kσ², 곧 Δ² = 12D̄σ²), H(Z) ≈ ½log₂(K/D̄) + ½log₂(2πe/12).
기호 충돌 주의: 원문의 Z는 디더, 본 연구의 Z는 스위치 출력이다. 이하 본 연구 기호를 쓰고 원문 디더는 W = (d_1, …, d_K)로 부른다. T := ΣQ_k ∈ ℤ (mod 전), N_k := 감산 디더 오차, Y_k := ΔQ_k − d_k = X_k + N_k.

### 7.1 이 논문이 정확히 주는 것

- (4.1) N_k ~ U[−Δ/2, Δ/2] 독립, (X_1, …, X_K)와 독립 — W에 대해 평균했을 때 정확. 넘침 조건: 인코더가 mod M으로 감기므로 인코더 쪽 포화는 없고 N_k는 무한 양자화기 오차와 같다. 넘침은 복호기가 T를 Z = T mod M에서 되찾는 단계의 문제다(Schuchman 문서 7.2절).
- Theorem 1 (작업자별): H(Q_k | d_k) = h(X_k + N_k) − log₂Δ. 작업자별로 따로 엔트로피 부호화하는 "합 호환 제약 없음" 기준선의 율.
- 4.3의 별증 논법(디더는 출력의 함수: d_k ≡ −Y_k mod Δ)은 본 연구의 합 설정으로 옮겨진다(7.2).

### 7.2 합 설정으로의 확장: 정확한 분해 [재구성, 이 논문에 없음]

1. T는 (X, W)의 함수이므로 H(T | W) = I(T; X | W) = I(T, W; X) (W ⊥ X).
2. 연쇄 법칙으로 H(T | W) = I(S; T, W) + H(T | S, W). (H(T|W) = I(T;S|W) + H(T|S,W), 그리고 I(T;S|W) = I(T,W;S).)
3. ΣY_k = ΔT − Σd_k는 (T, W)의 함수이므로 I(S; T, W) ≥ I(S; ΣY_k) = I(S; S + ΣN_k). 7.1에 의해 ΣN_k는 S와 독립인 어윈–홀 잡음(분산 KΔ²/12 = D).
4. 가우시안 입력에 대해 분산 D인 가법 잡음 중 상호정보량을 최소화하는 것은 가우시안 잡음이므로 I(S; S + ΣN_k) ≥ ½log₂(1 + Kσ²/D) = ½log₂(1 + 1/D̄).
5. 결론(정확한 부등식): **H(T | W) ≥ ½log₂(1 + 1/D̄) + H(T | S, W).** 첫 항은 합 S의 율-왜곡 함수 R_S(D)에 해당하고, 둘째 항이 보조정리 L이 다루는 "합 호환 대가"다.
6. 고해상도 값: H(T | S, W) → h(U_1 + … + U_K) (U_i ~ U[−½, ½], Schuchman 문서 7.3절), I(S; T, W) ≈ I(S; S + ΣN_k) = h(S + ΣN_k) − log₂Δ − h(ΣU_i). 더하면
   H(T | W) ≈ h(S + ΣN_k) − log₂Δ ≈ ½log₂(2πe(Kσ² + D)/Δ²) = ½log₂(K(1 + D̄)/D̄) + ½log₂(2πe/12).
   - 이것은 Theorem 1(율 = 출력 미분 엔트로피 − 셀 부피 로그)과 Theorem 3(가우시안에서 등식, P(Y)/P(X) = 1 + D̄ 근사)의 꼴을 합 변수에 적용한 것이다. T 자체는 S의 양자화가 아니므로 Theorem 1이 **직접** 적용되지는 않는다.
   - 몬테카를로 점검 (σ = 1, W 100개 × X 400000개): K = 1, D̄ = 0.05 → 2.4505 (예측 2.4508, Theorem 1 정확값과 같음), K = 4, D̄ = 0.05 → 3.4504 (3.4508), K = 4, D̄ = 0.01 → 4.5833 (4.5837), K = 16, D̄ = 0.05 → 4.4510 (4.4508). 과제의 근사 ½log₂(K/D̄) + 0.254는 (1 + D̄) 인자를 버린 것(D̄ = 0.05에서 0.035 bit 차이).
7. 0.254의 분배가 K에 따라 달라진다는 점에 주의: K = 1이면 H(T|S,W) = 0이고 0.254는 전부 I(S; T, W) − R 쪽(Theorem 3의 셀 손실)에 있다. K → ∞이면 ΣN_k가 가우시안에 가까워져 I(S; T, W) − R_S → 0이고, 0.254는 H(T|S,W) = h(ΣU_i) ≈ ½log₂K + ½log₂(2πe/12) 안으로 옮겨간다. 즉 "½log₂K + 0.254"의 두 항을 따로 어느 한 정리에 귀속시키면 안 되고, 합으로서만 의미가 있다.

### 7.3 정리 B 상수 0.254의 출처 확정

- 수치 ½log₂(2πe/12) = 0.254가 처음 **인쇄된** 곳: Ziv 1985 1절 (결정적 양자화기에 대한 Gish–Pierce 결과의 일반화, 증명 없음).
- 디더(무작위화) 양자화기에 대해 **증명된 정리**로서의 출처: 이 논문 **Theorem 3, 식 (36)** (K = 1, G_1 = 1/12), 고해상도 극한 (13)·(44). 비점근 형태: ρ ≤ ½log₂(P(Y)/P(X)) + ½log₂(2πe/12), 가우시안에서 등식.
- 정리 B의 "H ≈ ½log₂(K/D̄) + 0.254"를 인용할 때는: Theorem 1 (율 = h(출력) − log 셀 부피)과 Theorem 3 (G_1 = 1/12의 셀 손실)의 논법을 합 변수에 확장한 것(7.2, [재구성])이라고 적어야 한다. 이 논문은 K개 양자화기 출력의 **합**의 엔트로피를 다루지 않는다.
- 0.754의 원전은 Ziv 1985 Theorem 1 (최적 ECVQ 대비), R(ε) 대비 엄격 상한·도달 가능성은 이 논문 Theorem 2와 (30).

### 7.4 보조정리 L에 대한 함의

- 보조정리 L은 H(Z | S, W)를 W를 **조건으로** 다룬다. 이 논문의 Theorem 1–3과 4.1의 독립성은 모두 디더에 대한 평균(H(Q|Z)는 디더에 대한 조건부 엔트로피의 평균이지만, 독립·균일은 디더를 평균한 결합분포의 성질)이다. W를 고정하면 N_k는 X_k의 결정적 함수다.
- 그러므로 "e_k가 (S, W)가 주어졌을 때 독립 균등"이라는 이상화는 이 논문에서 나오지 않는다. 필요한 것은 (X | S)의 분수부가 "합 고정 부분 토러스" 위 거의 균일하다는 입력 쪽 조건이며, 이탈 크기는 exp(−π²(1 − 1/K)/(6D̄)) 차수다 (Schuchman 문서 7.3절).
- 이 논문이 보조정리 L에 실제로 주는 도구: (i) 4.2의 "격자점 합 + 셀 적분 = 연속 적분" 장치(오프셋이 균일할 때 조건부 이산 엔트로피의 평균 = 미분 엔트로피), (ii) 4.3의 "디더는 출력의 함수" 관찰(7.2의 분해 H(T|W) = I(S; T, W) + H(T|S,W)와 I(S; T,W) ≥ I(S; S + ΣN_k)를 정확하게 만든다).

### 7.5 H(Z)와 H(Z | W)

- 정리 B의 율은 공유 디더를 쓰는 엔트로피 부호화이므로 엄밀히는 H(Z | W) (이 논문의 H(Q|Z))이다. 무조건 엔트로피 H(Z)는 Σd_k의 분산 KΔ²/12가 더해져 고해상도에서 약 ½log₂((1 + 2D̄)/(1 + D̄))만큼 크다(H(T) ≈ h(S + ΣN_k + Σd_k) − log₂Δ, [재구성 근사]). D̄ → 0에서 차이는 사라진다.
- 고정 레지스터 폭 log₂M은 엔트로피가 아니며 넘침 여유 상수 log₂(2t/√12)가 붙는다(Schuchman 문서 7.2절). 0.254는 엔트로피 부호화를 전제할 때만의 상수다.
