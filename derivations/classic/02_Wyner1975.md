## 2. 문제 설정 (원문 기호, 2절)

- {(X_k, Y_k, V_k)}: 유한 알파벳 𝒳, 𝒴, 𝒱 위 삼중 (X,Y,V)의 i.i.d. 복사본, Q(x,y,v) = Pr{X=x, Y=y, V=v} (식 (2.2)). **로그는 밑 2** (원문 명시).
- 표기: I_k = {0, 1, …, k−1} (식 (2.1)).
- 부호 (n, M_0, M_1, M_2, Δ)는 다섯 사상 (f_0, f_1, f_2, g_1, g_2) (식 (2.3)):
  f_0: 𝒱ⁿ → I_{M_0},  f_1: 𝒳ⁿ → I_{M_1},  f_2: 𝒴ⁿ → I_{M_2},
  g_1: I_{M_0} × I_{M_1} → 𝒳ⁿ,  g_2: I_{M_0} × I_{M_2} → 𝒴ⁿ.
- 복원: X̂ⁿ = g_1(f_0(Vⁿ), f_1(Xⁿ)), Ŷⁿ = g_2(f_0(Vⁿ), f_2(Yⁿ)) (식 (2.4)).
- **오류 척도는 블록 오류가 아니라 문자당 평균 해밍 오류(bit error rate)**:
  Δ = (1/2n) [E d_H(Xⁿ, X̂ⁿ) + E d_H(Yⁿ, Ŷⁿ)]  (식 (2.5)), d_H는 해밍 거리.
- 달성 가능(achievable): 임의의 ε>0에 대해 (충분히 큰 n에서) M_i ≤ 2^{n(R_i+ε)} (i=0,1,2), Δ ≤ ε인 부호가 존재. ℛ = 달성 가능한 율 삼중쌍 집합.
- 그림 1의 해석: 인코더 0은 Vⁿ를, 인코더 1은 Xⁿ를, 인코더 2는 Yⁿ를 본다. 복호기 1은 (인코더 0, 1)의 출력으로 Xⁿ를, 복호기 2는 (인코더 0, 2)의 출력으로 Yⁿ를 복원한다. Vⁿ과 그 부호(인코더 0)는 **복호기만 쓰는 부가정보(side information)** 역할이다.

### 단일 문자 영역의 정의 (식 (2.6)–(2.7))

- 𝒫: 𝒳×𝒴×𝒱×𝒲 (𝒲는 임의의 유한 집합) 위 확률함수 p(x,y,v,w) 중
  (2.6a) Σ_w p(x,y,v,w) = Q(x,y,v)  (주변분포 일치),
  (2.6b) p(x,y,v,w) = Q(x,y,v) p_t(w|v)  ((X,Y)와 W가 V 주어졌을 때 조건부 독립, 즉 마르코프 사슬 (X,Y) − V − W).
  p_t(w|v)는 입력 V, 출력 W인 가상의 "시험 채널(test channel)".
- ℛ(p) = {(R_0,R_1,R_2): R_0 ≥ I(V;W), R_1 ≥ H(X|W), R_2 ≥ H(Y|W)}  (식 (2.7a))
- ℛ* = [∪_{p∈𝒫} ℛ(p)]의 폐포  (식 (2.7b))

## 3. 주 정리 진술 (원문 대조 완료: PDF 2–6쪽 이미지로 확인)

**Theorem 2.1**: ℛ = ℛ*.

(SURVEY.md는 이 기호를 𝒲 = 𝒲*로 적었으나 원문 기호는 ℛ = ℛ*이다. pdftotext가 ℛ을 W로 잘못 뽑은 데서 생긴 표기 차이로 보인다.)

부속 진술:
- **Remark a)** V = (X,Y)이면 (2.6b)는 자동으로 성립하고, ℛ은 R_0 ≥ I(X,Y;W), R_1 ≥ H(X|W), R_2 ≥ H(Y|W)의 폐포이며 Gray–Wyner 영역과 같다. 따라서 인코더 1이 Yⁿ를, 인코더 2가 Xⁿ를 볼 수 있어도 영역이 넓어지지 않는다.
- **Remark b)** Y ≡ 0(퇴화)이면 ℛ은 R_0 ≥ I(V;W), R_1 ≥ H(X|W)인 (R_0,R_1)의 폐포(𝒫는 X − V − W 마르코프). 동치 형식:
  Γ(C) = min H(X|W), 최소화는 H(V|W) ≥ H(V) − C (즉 I(V;W) ≤ C)인 p∈𝒫에 대해  (식 (2.9)).
- **Remark c)** ℛ은 위로 닫힘(각 좌표에 양수를 더해도 ℛ), 시분할로 볼록. 지지 평면 표현
  T(α_0,α_1,α_2) = inf [α_0 I(V;W) + α_1 H(X|W) + α_2 H(Y|W)]  (식 (2.12)).
- **Remark d)** card 𝒲 ≤ card 𝒱 + 2로 제한해도 ℛ*는 불변(증명 생략, [5, sec. A.2] 참조).

**Theorem 3.1** (역): 각 (R_0,R_1,R_2) ∈ ℛ에 대해 R_i ≥ R_i* (i=0,1,2)인 (R_0*,R_1*,R_2*) ∈ ℛ*가 있다.

**Theorem 4.1** (직접): p* ∈ 𝒫와 ε>0에 대해 충분히 큰 n에서
M_0 ≤ 2^{n[I(V;W)+ε]}, M_1 ≤ 2^{n[H(X|W)+ε]}, M_2 ≤ 2^{n[H(Y|W)+ε]}, Δ ≤ ε  (식 (4.1a–d))
인 부호가 존재.

**Lemma 4.2** (SW-부호, Slepian–Wolf에 귀속): 복호기가 Vⁿ의 부호 대신 Wⁿ 자체를 부가정보로 가질 때(그림 3), M_1 ≤ 2^{n[H(X|W)+ε]}, M_2 ≤ 2^{n[H(Y|W)+ε]}이고 EΦ_n(Xⁿ,Yⁿ,Wⁿ) → 0인 SW-부호가 존재. 여기서 Φ_n = (1/2n)[d_H(Xⁿ,X'ⁿ) + d_H(Yⁿ,Y'ⁿ)], X'ⁿ = g̃_1(Wⁿ, f̃_1(Xⁿ)), Y'ⁿ = g̃_2(Wⁿ, f̃_2(Yⁿ)) (식 (4.2)).

**Lemma 4.3** (PB-부호, "업어 가기(piggy-back)"): U = (X,Y), p*(u,v,w) = p*(w) p*(v|w) p*(u|v) (식 (4.4), U − V − W 마르코프). ψ_n: 𝒰ⁿ × 𝒲ⁿ → [0,1]이 lim E ψ_n(Uⁿ,Wⁿ) = 0 (식 (4.5))을 만족하면, 충분히 큰 n에서
M_0 ≤ 2^{n[I(V;W)+ε]}, E ψ_n(Uⁿ, F(Vⁿ)) ≤ ε
인 사상 F: 𝒱ⁿ → {w_j}_{j=1}^{M_0} ⊆ 𝒲ⁿ (PB-부호)가 존재.

**Lemma 5.1**: S_n = {(v,w): η(v,w) ≤ δ_n^{1/2}}이면 Pr{(Vⁿ,Wⁿ) ∉ S_n} ≤ δ_n^{1/2}.

## 4. 유도

### 4.1 역정리 (Theorem 3.1) [원문]

임의의 부호 (n, M_0, M_1, M_2, Δ)를 잡고 S_0 = f_0(Vⁿ), S_1 = f_1(Xⁿ), S_2 = f_2(Yⁿ) (식 (3.1)).

**(가) R_0 단계 (식 (3.2)–(3.4))**
(1/n) log M_0 ≥ (1/n) H(S_0)                      (S_0 ∈ I_{M_0}: 엔트로피 ≤ log 개수)
≥ (1/n) I(Vⁿ; S_0)                                  (H(S_0) = I(Vⁿ;S_0) + H(S_0|Vⁿ) ≥ I)
= (1/n) H(Vⁿ) − (1/n) H(Vⁿ|S_0).
- H(Vⁿ) = Σ_k H(V_k)  (V_k 독립, 식 (3.3a))
- H(Vⁿ|S_0) = Σ_k H(V_k | V^{k−1}, S_0) = Σ_k H(V_k|W_k)  (연쇄 법칙, 식 (3.3b))
  여기서 **W_k ≡ (V^{k−1}, S_0)** (보조 확률변수 식별).
따라서 (1/n) log M_0 ≥ (1/n) Σ_k I(V_k; W_k)  (식 (3.4)).

**(나) 파노 단계 (식 (3.5)–(3.7))**
S_0 = j로 조건화한 문자당 오류 Δ_j^{(X)} = (1/n)E[d_H(Xⁿ,X̂ⁿ)|S_0=j], Δ_j^{(Y)}도 같은 방식. Σ_j Pr{S_0=j} ½[Δ_j^{(X)} + Δ_j^{(Y)}] = Δ (식 (3.5c)).
문자당 파노 부등식(Gallager 정리 4.3.2):
(1/n) H(Xⁿ | X̂ⁿ, S_0 = j) ≤ Δ_j^{(X)} log card 𝒳 + h(Δ_j^{(X)})  (식 (3.6a))
[근거: H(Xⁿ|X̂ⁿ) ≤ Σ_k H(X_k|X̂_k) ≤ Σ_k [P_k log(card𝒳 − 1) + h(P_k)], P_k = Pr{X_k ≠ X̂_k}, 그리고 h의 오목성으로 평균을 안으로.]
j에 대해 평균하고 h의 오목성·단조성을 쓰면, Σ_j Pr{S_0=j}Δ_j^{(X)} ≤ 2Δ이므로(Δ ≤ ¼이면 2Δ ≤ ½라 h가 증가 구간)
(1/n) H(Xⁿ | X̂ⁿ, S_0) ≤ 2Δ log card 𝒳 + h(2Δ)  (식 (3.7a)), Y도 같음 (식 (3.7b)).

**(다) R_1, R_2 단계 (식 (3.8)–(3.10))**
S_0 = j가 주어지면 g_1(S_0,S_1)은 많아야 M_1개 값을 가지므로
(1/n) log M_1 ≥ (1/n) H(X̂ⁿ|S_0) ≥ (1/n) I(Xⁿ; X̂ⁿ | S_0)
= (1/n) H(Xⁿ|S_0) − (1/n) H(Xⁿ|X̂ⁿ,S_0)
≥ (1/n) H(Xⁿ|S_0) − 2Δ log card 𝒳 − h(2Δ)  (식 (3.8a)).
이제
(1/n) H(Xⁿ|S_0) = (1/n) Σ_k H(X_k | X^{k−1}, S_0)                (연쇄 법칙)
≥ (1/n) Σ_k H(X_k | X^{k−1}, V^{k−1}, S_0)                         (조건화는 엔트로피를 줄임)
= (1/n) Σ_k H(X_k | V^{k−1}, S_0)                                   (*)
= (1/n) Σ_k H(X_k | W_k)  (식 (3.9a)).
(*)의 근거: X_k와 X^{k−1}은 (V^{k−1}, S_0)가 주어지면 조건부 독립. [보충 검증] 결합분포가 ∏_i Q(x_i,v_i)이고 S_0 = f_0(vⁿ)이므로, p(x^{k−1}, x_k | v^{k−1}, s_0) = p(x^{k−1}|v^{k−1})·p(x_k | v^{k−1}, s_0)로 인수분해된다(X^{k−1}은 V^{k−1}을 통해서만 나머지와 연결).
같은 방식으로 (1/n) H(Yⁿ|S_0) ≥ (1/n) Σ_k H(Y_k|W_k) (식 (3.9b)). 대입하면 (Δ ≤ ¼)
(1/n) log M_1 ≥ (1/n) Σ_k H(X_k|W_k) − 2Δ log card 𝒳 − h(2Δ)  (식 (3.10a)),
(1/n) log M_2 ≥ (1/n) Σ_k H(Y_k|W_k) − 2Δ log card 𝒴 − h(2Δ)  (식 (3.10b)).

**(라) 단일 문자화**
(X_k, Y_k, V_k, W_k)의 분포 p_k는 𝒫에 속한다: W_k = (V^{k−1}, f_0(Vⁿ))는 V_k와 나머지 V들의 함수이고, V_k가 주어지면 (X_k,Y_k)는 다른 모든 V_i (i≠k)와 독립이므로 (X_k,Y_k) − V_k − W_k. 따라서 (I(V_k;W_k), H(X_k|W_k), H(Y_k|W_k)) ∈ ℛ(p_k) ⊆ ℛ*.
ℛ*가 볼록(부록 A.1)하므로 평균도 ℛ*에 속한다:
(1/n) log M_i ≥ R_i* − ν(Δ), i = 0,1,2, (R_0*,R_1*,R_2*) ∈ ℛ*, ν(Δ) = h(2Δ) + 2Δ max(log card 𝒳, log card 𝒴)  (식 (3.11)).
[원문 (3.11)은 "2Δ max(card 𝒳, card 𝒴)"로 인쇄되어 log가 빠져 보인다. (3.10)에서 오는 항은 2Δ log card이다. 상수라 결론에는 영향 없음.]

**(마) 극한**: 달성 가능한 (R_0,R_1,R_2)와 ε ≤ ¼에 대해 (1/n)log M_i ≤ R_i + ε, Δ ≤ ε인 부호에 (3.11)을 적용하면 R_i ≥ R_i* − (ν(ε) + ε). ε → 0과 ℛ*의 닫힘으로 Theorem 3.1. ∎

**부록 A.1 (ℛ*의 볼록성) [원문]**: ℛ*의 내부 점 R^{(1)} ∈ ℛ(p_1), R^{(2)} ∈ ℛ(p_2), 𝒲_1 ∩ 𝒲_2 = ∅. 𝒲 = 𝒲_1 ∪ 𝒲_2 위에 p = θp_1 (w ∈ 𝒲_1), (1−θ)p_2 (w ∈ 𝒲_2)로 정의(혼합). W의 값이 어느 성분인지를 알려 주므로(시분할 변수가 W에 내장)
I(V;W) = θI(V;W_1) + (1−θ)I(V;W_2), H(X|W) = θH(X|W_1) + (1−θ)H(X|W_2), H(Y|W)도 같음.
[보충: I(V;W)의 분해는 H(V)가 공통이고 H(V|W)가 성분별 가중합이 되기 때문에 성립.] 따라서 θR^{(1)} + (1−θ)R^{(2)} ∈ ℛ(p) ⊆ ℛ*.

### 4.2 직접 정리 (Theorem 4.1) [원문]

구조: (i) 복호기가 진짜 Wⁿ을 부가정보로 가지면 SW 부호(Lemma 4.2)로 율 H(X|W), H(Y|W)가 된다. (ii) 진짜 Wⁿ 대신 인코더 0이 Vⁿ을 율 I(V;W)로 "Wⁿ처럼 보이는" 부호어 F(Vⁿ)로 양자화해 보낸다(Lemma 4.3). (iii) 핵심은 (ii)로 바꿔도 SW 부호의 오류가 커지지 않는다는 것이고, 이를 U − V − W 마르코프 성질이 보장한다.

**Lemma 4.2 (SW-부호)** [원문은 Slepian–Wolf에 귀속, 증명 없음]
(Xⁿ, Wⁿ)은 i.i.d. 쌍이므로 Slepian–Wolf Theorem 2(복호기가 상대 소스를 알 때 율 H(X|W)+ε)를 그대로 적용. 블록 오류 → 0이면 해밍 오류 Φ_n도 → 0. [보충, 재구성: 비닝 증명은 01번 노트 4.2에서 Y 대신 W를 복호기가 직접 아는 경우. 율 H(X|W)+δ에서 오류 사건 {∃ x̃≠Xⁿ: 같은 bin, (x̃,Wⁿ) 결합 전형}의 확률 ≤ 2^{n(H(X|W)+δ−R_1)} → 0.]

**Lemma 4.3 (PB-부호)의 증명 (5절)** [원문]
1. δ_n ≡ E ψ_n(Uⁿ,Wⁿ) → 0 (식 (5.2)).
2. η(v,w) ≡ E[ψ_n(Uⁿ,Wⁿ) | Vⁿ=v, Wⁿ=w] = Σ_u ψ_n(u,w) p*(u|v,w) (식 (5.3)).
   마르코프 U − V − W로 p*(u|v,w) = p*(u|v)이므로
   η(v,w) = Σ_u ψ_n(u,w) p*(u|v)  (식 (5.4)).
   **요점: η는 (v,w)만의 함수이며, w가 어떻게 만들어졌는지(진짜 채널 출력인지 부호어인지)와 무관하다.** Uⁿ은 Vⁿ만 통해 w와 연결되기 때문이다.
3. S_n = {(v,w): η(v,w) ≤ δ_n^{1/2}} (식 (5.5)). Lemma 5.1: η ≥ 0과 마르코프(Markov) 부등식으로
   Pr{(Vⁿ,Wⁿ) ∉ S_n} = Pr{η ≥ δ_n^{1/2}} ≤ Eη/δ_n^{1/2} = δ_n/δ_n^{1/2} = δ_n^{1/2}.
4. 임의의 PB-부호 F에 대해, 0 ≤ ψ_n ≤ 1이므로
   E ψ_n(Uⁿ, F(Vⁿ)) ≤ Pr{(Vⁿ, F(Vⁿ)) ∉ S_n} + Σ_j Σ_{v: F(v)=w_j, (v,w_j)∈S_n} [Σ_u ψ_n(u,w_j) p*(u|v)] p*(v)  (식 (5.6))
   [근거: Z ≤ 1인 확률변수와 집합 S_0에 대해 EZ ≤ Pr{Z∉S_0} + Σ_{z∈S_0} z p(z).]
   대괄호는 η(v,w_j) ≤ δ_n^{1/2}이므로 둘째 항 ≤ δ_n^{1/2}. 따라서
   E ψ_n(Uⁿ, F(Vⁿ)) ≤ Pr{(Vⁿ,F(Vⁿ)) ∉ S_n} + δ_n^{1/2}  (식 (5.7)).
5. 피복(covering) 보조정리 (식 (5.8)): 임의의 S_n, M_0, ρ > 0에 대해
   Pr{(Vⁿ, F(Vⁿ)) ∉ S_n} ≤ Pr{(Vⁿ,Wⁿ) ∉ S_n} + Pr{i*(Vⁿ,Wⁿ) > nρ} + exp{−M_0 2^{−ρn}}
   인 F가 존재. i*(v,w) = log[p*(w|v)/p*(w)] = Σ_k log[p*(w_k|v_k)/p*(w_k)] (식 (5.9), 정보 밀도(information density)).
   원문은 Gallager 보조정리 9.3.1에서 이를 끌어낸다(부록 A.2: D(u,v) = 0 (집합 안), 1 (밖)으로 놓고 "앙상블 평균 이상의 부호가 존재"). 직접 증명 [재구성]:
   - 부호어 w_1,…,w_{M_0}를 p*(w)ⁿ에서 i.i.d. 추출. 각 v에 대해 G_v = {w: (v,w) ∈ S_n, i*(v,w) ≤ nρ}. F(v) = G_v 안의 부호어(있으면 아무거나), 없으면 w_1.
   - w ∈ G_v이면 p*(w) ≥ p*(w|v) 2^{−nρ}이므로 P_W(G_v) ≥ 2^{−nρ} q_v, q_v ≡ P_{W|V}(G_v|v).
   - Pr{G_v에 부호어 없음} = (1 − P_W(G_v))^{M_0} ≤ exp(−M_0 2^{−nρ} q_v) ≤ 1 − q_v + exp(−M_0 2^{−nρ}).
     마지막 부등식: q ↦ e^{−aq}는 볼록이므로 [0,1]에서 현(chord) 아래에 있다: e^{−aq} ≤ (1−q) + q e^{−a} ≤ 1 − q + e^{−a}.
   - v에 대해 평균: E_codebook Pr{실패} ≤ Pr{(Vⁿ,Wⁿ) ∉ G} + exp(−M_0 2^{−nρ}) ≤ Pr{∉S_n} + Pr{i* > nρ} + exp(−M_0 2^{−nρ}). 평균 이하의 부호가 존재.
6. 조립 (식 (5.10)): Pr{(Vⁿ,Wⁿ)∉S_n} ≤ δ_n^{1/2} → 0. ρ = I(V;W) + ε/2, M_0 = ⌊2^{n(I(V;W)+ε)}⌋이면

### 4.3 현대 표준 증명과의 대응 [재구성]

- 직접부: El Gamal–Kim의 "도우미가 있는 무손실 부호화(lossless source coding with a helper)"와 같은 구조. 인코더 0: 피복 보조정리(covering lemma)로 Vⁿ을 Wⁿ(m_0) ~ ∏p(w)에서 뽑은 2^{n(I(V;W)+δ)}개 부호어 중 결합 전형인 것으로 양자화. 인코더 1, 2: 랜덤 비닝 율 H(X|W)+δ, H(Y|W)+δ. 복호: (Xⁿ, Wⁿ(m_0))가 결합 전형인 bin 안의 유일한 x̂ⁿ. 마르코프 보조정리(Markov lemma)로 (Xⁿ, Vⁿ, Wⁿ(m_0))가 결합 전형일 확률 → 1. Wyner의 "η는 (v,w)만의 함수" 논법은 마르코프 보조정리 대신 쓴, 더 단순하고 오류 척도에 무관한 장치다(블록 오류 대신 임의의 유계 손실 ψ_n에 적용 가능).
- 역: 4.1과 같은 식별 W_k = (S_0, V^{k−1}). 블록 오류 기준이면 파노 부등식을 블록 단위로 쓰면 되고 경로는 같다. 현대 교과서는 시분할 변수 Q를 도입해 W = (W_Q, Q)로 볼록성 논증을 대신한다.
- 크기 제한 card 𝒲 ≤ card 𝒱 + 2: 지지 보조정리(support lemma, Fenchel–Eggleston–Carathéodory). 원문은 생략([5] 참조). 보존할 함수: p(v)의 card𝒱 − 1개 성분 + I(V;W)(=H(V|W)) + H(X|W) + H(Y|W) → card𝒱 + 2개. [재구성]

X ~ Bern(½), V = X ⊕ N, N ~ Bern(p) 독립 (대칭이므로 X = V ⊕ N, N ⊥ V로도 쓸 수 있음).

  **Γ(C) = h(p ∗ h^{−1}(1 − C)), 0 ≤ C ≤ 1.**
- 원문은 이 식을 쓰지 않고 "[4, sec. II]에 주어져 있다"고만 한다(원문 296쪽 Remark b). 위 닫힌 식은 기억에 의존한 재구성이다.
- 수치: p = 0.11, C = 0.5 → h(β) = 0.5 → β ≈ 0.110 → p ∗ β ≈ 0.196 → Γ ≈ h(0.196) ≈ 0.713 비트. (C = 0이면 1, C = 1이면 h(p) ≈ 0.5로 SW 꼭짓점.)

## 6. 원문과의 차이·빈틈

1. **오류 척도**: 원문은 문자당 평균 해밍 오류 Δ를 쓴다. 블록 오류보다 약한 기준이라 역정리가 더 강하고(약한 기준에서도 같은 영역), 직접부는 SW 부호(블록 오류 → 0)로 충분하다. 현대 교과서는 블록 오류로 서술한다.
2. **Lemma 4.2는 SW 1973 결과로 인용만** 하며, 부가정보 Wⁿ이 복호기에 "있는" 형태로 쓴다. SW 원문은 Y를 율 H(Y)로 보내서 복호기가 아는 형태이므로, 한 단계 환원(복호기가 Wⁿ을 직접 안다)이 암묵적이다.
3. **(5.8)의 근거**: Gallager 보조정리 9.3.1(율-왜곡 랜덤 부호화 보조정리)을 유계 왜곡 0/1로 특수화. 원문 부록 A.2의 D(u,v) 정의는 인쇄가 흐려 정확한 값을 확인하지 못함 [미확인]. 위 4.2-5의 직접 증명으로 대체 가능.
4. **식 (3.11)의 ν(Δ)**: 인쇄상 log가 빠진 것으로 보인다(4.1 (라) 주석).
5. **크기 제한(Remark d)**: 증명 생략.
6. **역정리의 독립 발견**: 각주 3에 따르면 Ahlswede–Körner가 독립적으로 역정리(의 한 형태)를 증명. Y ≡ 0 경우(Remark b)는 정확히 Ahlswede–Körner(1975, 03번 노트)의 문제와 같다(역할: Wyner의 V ↔ AK의 도우미 X, Wyner의 X ↔ AK의 Y).

## 7. 본 연구와의 연결

본 연구 모델: K명의 작업자, X_k ~ N(0,σ²) 독립, 인코더 Q_k = f_k(X_k,W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만 계산, 복호기 Ŝ = g(Z,W)로 S = ΣX_k 추정. 정리 A(가설): log₂M ≥ ½log₂(K/D̄) − c. 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½log₂K − c.

1. **사슬의 첫 두 단계는 Wyner 역정리 (3.2)와 같은 모양이다.** Wyner: (1/n)log M_0 ≥ (1/n)H(S_0) ≥ (1/n)I(Vⁿ;S_0). 본 연구: log₂M ≥ H(Z|W) ≥ I(S;Z|W). 결정적 차이는 Wyner가 버린 항이다. Wyner에서 S_0 = f_0(Vⁿ)는 **관측 Vⁿ의 결정적 함수**라 H(S_0|Vⁿ) = 0이고, 그래서 H(S_0) = I(Vⁿ;S_0)로 손실이 없다. 본 연구에서 Z는 (X_1,…,X_K,W)의 함수이지만 **(S,W)의 함수가 아니다**(스위치가 S를 계산하지 못하고 Q_k의 합만 낸다). 그래서 H(Z|S,W) > 0인 잉여가 남고, 보조정리 L은 이 잉여가 ½log₂K 이상임을 보이는 것이다. 즉 본 연구의 새 내용은 정확히 Wyner식 사슬이 0으로 버리는 항에 있다.

2. **기준선(제약 없는 부호)의 구성 = PB-부호(Lemma 4.3).** 스위치가 복호·재부호화를 할 수 있다면, 스위치(Wyner의 인코더 0 위치)는 자기가 아는 것(V ↔ 각 Q_k로부터의 Ŝ)을 율 I(V;W)로 시험 채널 출력처럼 양자화해 보내면 된다. 가우시안이면 W = S + 잡음 시험 채널로 I(S;W) = ½log₂(Kσ²/D), 즉 ½log₂(1/D̄)이 기준선이다. 이 논문의 피복 보조정리 (5.8)이 그 달성성의 정보이론적 핵심이다(가우시안 확장은 이 논문 밖).

3. **"η는 (v,w)만의 함수" 논법.** 마르코프 U − V − W 아래에서 진짜 시험 채널 출력 대신 부호어를 써도 하류 손실이 그대로라는 장치. 본 연구의 달성 쪽(합 호환 부호의 상한)에서, 스위치 출력 Z를 "S의 잡음 섞인 관측"으로 보고 복호기 성능을 S − Z 결합분포만으로 분석할 때 같은 형태로 쓸 수 있다. 단 본 연구에서는 Z가 S만의 함수가 아니어서(U − V − W에 해당하는 마르코프가 S − (Q_1..Q_K) − Z 형태로 바뀜) 그대로 대입되지는 않는다.

4. **보조변수 식별 W_k = (S_0, V^{k−1})와 단일 문자화.** 본 연구에서 d차원 벡터(좌표 n=d개)로 확장할 때 log₂M ≥ (1/d)H(Zᵈ|W) ≥ (1/d)Σ_k I(S_k; Zᵈ, S^{k−1}|W) 같은 단일 문자화가 필요하면 (3.3b)·(3.9a)의 조건부 독립 논법((*) 단계)이 그대로 쓰인다. 반면 잉여 항 H(Zᵈ|Sᵈ,W)의 단일 문자화는 Wyner에 없는 새 단계다.

5. **공통/개별 분해(Gray–Wyner, Remark a).** 상관 가우시안 확장(작업자 간 공통 성분)에서 "공통 성분을 한 번, 개별 잔차를 따로"라는 율 분해의 원형이지만, 기본 모델(X_k 독립)에서는 직접 쓰이지 않는다.
