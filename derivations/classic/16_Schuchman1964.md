# Schuchman 1964 — 디더 신호와 양자화 잡음 (Dither Signals and Their Effect on Quantization Noise)

## 1. 서지

- L. Schuchman, "Dither Signals and Their Effect on Quantization Noise," *IEEE Transactions on Communication Technology*, vol. COM-12, no. 4, pp. 162–165, December 1964. (원고 접수 1964-10-22, Philco WDL)
- 원문 파일: `papers/classic/16_Schuchman1964.pdf` (4쪽, 마지막 쪽 아래는 다른 논문).
- 원문에 "정리" 번호는 없다. 결과는 식 (1)–(12)로 제시된다. 아래에서는 식 번호로 인용한다.

## 2. 문제 설정 (원문 기호)

- 입력 신호 x(t), 디더 신호(dither, 보조 무작위 신호) d(t), 양자화 간격 q, 균일 계단 양자화기 Q (그림 2: 준위 −kq, …, 0, q, …, (M−k−1)q, 문턱은 준위 사이 중점).
- 그림 3의 구성 [원문 그림 3 직접 확인]: x와 d를 더해 양자화하고 ȳ(t) = x(t) + d(t) + n(t)를 얻은 뒤, **d를 다시 빼서** 출력 y(t) = ȳ(t) − d(t)를 낸다. 원문 1쪽 본문도 디더를 "양자화기 입력에 더한 다음 양자화 후에 빼는 두 번째 신호"로 정의하고, 통신계에서는 수신기가 같은 디더 파형을 알아야(동기) 한다고 쓴다.
  - 따라서 원문의 모형은 **감산 디더(subtractive dither)** 다.
- 양자화 잡음(quantization noise): n = n(x + d) = −(x + d) + bq, 여기서 b는 bq − q/2 ≤ x + d ≤ bq + q/2를 만족하는 정수 (그림 4의 톱니 모양). 즉 n = Q(x+d) − (x+d) ∈ [−q/2, q/2]. 감산 후 출력은 y = x + n이므로 n은 감산 디더 계의 전체 오차다.
- 목표 (1): n(t, x) = n(t), 곧 잡음이 신호와 독립. 독립의 의미는 p(n | x) = p(n) (원문 표기 p(n/x)).
- 디더 특성함수(characteristic function) W_d(·). 원문은 디더 밀도를 p_d(·)로 쓴다.
- 비교 대상 Widrow 조건 (2): 무한 준위 양자화기에서 입력 자체가 W_x(u) = 0 (u > 2π/q)을 만족하면 잡음이 신호와 독립인 것처럼 다룰 수 있다.

## 3. 주 결과 진술 (원문 대조함)

원문 4쪽 전부를 쪽 이미지로 확인했다.

- 식 (4): p(n | x = X) = Σ_b p_d(bq − n − X), 그리고 |n| > q/2이면 p(n | x = X) = 0.
- 식 (5): W_{n/x}(u) = Σ_b W_d(b/q) e^{(x에 대한 위상, 지수 −jπ(b/q)x 꼴로 인쇄)} sinc q(u − b/q).
- 식 (6): W_d(b/q) = 0, b = ±1, ±2, … 이면 W_{n/x}(u)가 x와 무관하여 p(n/x) = p(n). 원문은 (6)이 필요충분조건이라고 주장한다.
- 비고 1): 조건 (2)를 만족하는 밀도는 (6)도 만족한다.
- 식 (7): 대역 제한이 아니면서 (6)을 만족하는 무한 부류
  p_d(t) = (1/(kq)) [v(t + kq/2) − v(t − kq/2)] ∗ f_a(t), k = 1, 2, 3, …, f_a는 임의의 밀도, v는 단위 계단함수.
  곧 폭 kq인 균일분포와 임의 분포의 합성곱.
- B절 (유한 M준위): 포화(saturation, 끝 효과)가 일어날 수 있으면 잡음을 독립으로 만들 방법이 없다. 그러나 (7)의 디더가 다음 제약을 만족하면 독립이 된다:
  x_max + d_max ≤ (M − k − 1)q + q/2,  x_min + d_min ≥ −kq − q/2. (곧 넘침 없음)
- 표본화 계에서는 표본마다 독립이고 각각 균일(식 (7)에서 k = 1)인 디더가 최적이라는 언급.
- III절: Roberts의 "D 인자(D factor)" (8): D = ∫ (x − ȳ_x)² p(x) dx, ȳ_x = ∫ p(y/x) y dy. 가정 p(d|x) = p(d), E[d] = 0 아래 (9) E(ȳ|x) = E(y|x), (10) E(y|x) = x + ∫ n(x+d) p(d) dd, (11) D = ∫ [E(n|x)]² p(x) dx, (12) E(n|x)를 W_d(b/q)의 급수로. 결론: D = 0 ⇔ p(n|x) = p(n) (p(x) > 0 가정, 각주 7).

## 4. 유도

아래에서 현대식 규약 Φ_d(ω) = E[e^{jωd}] (각주파수)를 쓴다. 원문 (6)의 W_d(b/q)는 주파수 단위 규약 W_d(u) = ∫ p_d(t) e^{−j2πut} dt에 해당하며, 이 경우 W_d(b/q) = Φ_d(−2πb/q)이므로 조건 "모든 b ≠ 0에서 0"은 두 규약에서 같다. 원문은 (2)에서는 2π/q (각주파수), (6)에서는 b/q (주파수)를 써서 규약이 섞여 있다 [재구성: 규약 정리].

### 4.1 조건부 잡음 밀도 (식 (4))

1. x = X 고정. n = bq − X − d이고 b는 d에 따라 정해진다. 각 b에 대해 d ∈ [bq − X − q/2, bq − X + q/2]가 n ∈ [−q/2, q/2]에 일대일 대응(야코비안 1). [원문 "each value of d is uniquely specified by d = −x − n + bq"]
2. 모든 b의 기여를 더하면 p(n | X) = Σ_b p_d(bq − n − X), |n| ≤ q/2. → 식 (4). [원문]
3. 핵심 관찰 [재구성]: 주기 q의 함수 P(t) := Σ_b p_d(bq − t) (디더 밀도의 주기화, periodization)를 두면 p(n | X) = P(n + X). 조건부 잡음 밀도는 **하나의 주기 함수 P를 X만큼 평행이동한 것**이다.

### 4.2 푸아송 합 공식으로 푸리에 급수 전개 (원문 식 (5)의 현대식 유도)

4. P의 푸리에 계수: c_m = (1/q) ∫_0^q P(t) e^{−j2πmt/q} dt. 주기화를 펼치고 s = bq − t로 바꾸면 e^{−j2πmt/q} = e^{j2πms/q}, 따라서 c_m = (1/q) ∫_ℝ p_d(s) e^{j2πms/q} ds = (1/q) Φ_d(2πm/q). [재구성: 원문은 단위계단 함수와 합성곱 정리로 같은 계산을 함]
5. 그러므로 (P가 L¹ 주기 함수이므로 푸리에 급수가 L¹ 의미로 P를 결정한다)
   p(n | X) = (1/q) [1 + Σ_{m ≠ 0} Φ_d(2πm/q) e^{j2πm(n + X)/q}],  |n| ≤ q/2.   (★)
   m = 0 항은 Φ_d(0) = 1. [재구성]
6. (★)의 특성함수: ∫_{−q/2}^{q/2} e^{−j2πun} (1/q) e^{j2πmn/q} dn = sinc(q(u − m/q)) (sinc z = sin πz/(πz)). 따라서
   W_{n|X}(u) = Σ_m Φ_d(2πm/q) e^{j2πmX/q} sinc(q(u − m/q)).
   이것이 원문 식 (5)의 구조와 같다(원문 인쇄의 위상 지수 부호·계수는 규약 차이로 다르게 보인다). [원문 식 대조, 위상 표기는 미확인: 인쇄가 흐려 "−jπ(b/q)x"인지 "−j2π(b/q)x"인지 판독 불확실]

### 4.3 필요충분조건 (식 (6))

7. 충분성: Φ_d(2πm/q) = 0 (모든 m ≠ 0)이면 (★)에서 p(n | X) = 1/q (|n| ≤ q/2). X와 무관하고, **잡음은 [−q/2, q/2] 균일**이다. [원문: 충분성은 (5)에서 바로 나온다고 씀. 균일성 명시는 재구성]
8. 필요성 원문 논증 [원문]: 어떤 b에서 W_d(b/q) ≠ 0이면 (5)가 x의 주기함수가 되고, 그 변환이 x에 의존하므로 p(n/x) ≠ p(n).
9. 필요성 엄밀화 [재구성]: p(n | X)가 X에 무관하다고 하자(모든 X에 대해, 또는 거의 모든 X). 고정된 n에서 (★)을 X의 주기 q 함수로 보면 X에 대한 m번째 푸리에 계수가 (1/q) Φ_d(2πm/q) e^{j2πmn/q}이다. 상수 함수의 m ≠ 0 계수는 0이므로 Φ_d(2πm/q) = 0. (푸리에 계수의 유일성.) 더 간단히: p(n | X) = P(n + X)가 X에 무관하면 P가 상수이고, ∫_0^q P = 1이므로 P ≡ 1/q, 그 푸리에 계수 c_m(m≠0) = 0.
10. 결론 (정리 형태로 재진술, [재구성]):
    > 감산 디더, 무한 균일 양자화기, d가 x와 독립일 때 다음은 동치이다.
    > (a) 잡음 n = Q(x+d) − (x+d)의 조건부 분포가 x에 무관하다.
    > (b) n이 x와 독립이고 U[−q/2, q/2]를 따른다.
    > (c) Φ_d(2πm/q) = 0, m = ±1, ±2, ….
    "독립"만 요구해도 자동으로 "균일"이 따라온다는 점(9의 두 번째 논증)이 원문에는 명시되지 않았다.

### 4.4 조건을 만족하는 디더 (비고 1, 식 (7))

11. 비고 1) [원문]: Φ_d가 대역 제한(|ω| ≥ 2π/q에서 0)이면 (c) 성립. 그러나 대역 제한 특성함수는 유계 지지 밀도와 양립하지 않으므로(페일리–위너, [재구성 근거]) 유한 준위에는 쓸 수 없다고 원문 B절이 말한다.
12. 식 (7) [원문 식, 검증은 재구성]: 폭 kq 균일분포의 특성함수는 sin(ωkq/2)/(ωkq/2). ω = 2πm/q에서 sin(πkm)/(πkm) = 0 (m ≠ 0). 합성곱은 특성함수의 곱이므로 임의의 f_a와 합성곱해도 0이 유지된다.
13. 역은 성립하지 않는다(조건 (c)를 만족하지만 (7) 꼴이 아닌 디더도 있다. 예: 특성함수가 2πm/q에서만 0이고 다른 곳에서 0이 아닌 밀도) [재구성]. 원문은 (7)을 "무한 부류"라고만 하고 전부라고 하지 않는다.
14. 사인파 디더 d = A sin θ (θ 균일): Φ_d(ω) = J_0(Aω). J_0의 영점은 등간격이 아니므로 모든 2πm/q에서 동시에 0일 수 없다 → 조건 불충족. 원문은 "사인파 디더는 이 부류에 속하지 않는다"고만 쓰고 이유는 생략 [재구성: 베셀 함수 논증].

### 4.5 유한 M준위 양자화기 (B절)

15. 유한 양자화기는 [−kq − q/2, (M−k−1)q + q/2] 밖에서 포화한다. 입력 x + d가 이 범위 안에 머물면 유한 양자화기와 무한 양자화기의 출력이 같으므로 4.1–4.3이 그대로 성립. 이것이 원문의 두 부등식이다. [원문 조건, "같은 출력이므로" 논증은 재구성]
16. 포화가 확률 > 0으로 일어나면 그 사건에서 n은 무한히 커질 수 있고 x에 의존하므로 독립이 깨진다(원문: 포화 가능하면 불가능, 근거는 저자의 석사 논문 [4] 인용) [원문 서술, 증명은 원문에 없음 → 미확인].
17. 가우시안 입력은 지지가 무한이므로 넘침 없음 조건을 엄밀히는 만족할 수 없다. 넘침 확률만큼의 오차가 남는다 [재구성].

### 4.6 D 인자 (III절, 식 (8)–(12))

18. D = ∫ (x − E[y|x])² p(x) dx. y = ȳ − d = x + n, E[d|x] = E[d] = 0이므로 E[y|x] = x + E[n|x] → (10), 대입하면 (11) D = ∫ (E[n|x])² p(x) dx. [원문]
19. (★)에서 1차 모멘트를 직접 계산 [재구성: 원문 (12)는 W_{n/x}의 u-미분으로 얻음]: m ≠ 0에 대해 (1/q)∫_{−q/2}^{q/2} n e^{j2πmn/q} dn = q(−1)^m / (j2πm). 따라서
    E[n | x] = Σ_{m≠0} Φ_d(2πm/q) e^{j2πmx/q} · q(−1)^m/(j2πm) = Σ_{m≥1} (q(−1)^m/(πm)) Im[Φ_d(2πm/q) e^{j2πmx/q}].
    점검: 디더 없음(Φ_d ≡ 1)이면 Σ_{m≥1} (q(−1)^m/(πm)) sin(2πmx/q) = −x (|x| < q/2), 곧 톱니 오차. ✓
20. 원문 (12)의 인쇄본에는 j 인자 하나와 W_d(b/d) 같은 오식(d ↔ q)이 보인다. 위 식이 올바른 형태다. [재구성]
21. D = 0 ⇔ (p(x) > 0이면) E[n|x] = 0 거의 모든 x ⇔ 위 급수의 모든 푸리에 계수가 0 ⇔ Φ_d(2πm/q) = 0 (m≠0, 계수 앞 인자 q(−1)^m/(j2πm) ≠ 0이므로) ⇔ (c) ⇔ 독립. [원문 결론, 동치 사슬의 엄밀화는 재구성]
22. 주목할 점 [재구성]: 일반적으로 조건부 평균 0은 독립보다 훨씬 약하다. 여기서는 p(n|x)와 E[n|x]가 같은 계수 집합 {Φ_d(2πm/q)}에 의해 지배되므로 둘이 동치가 된다. 이 동치는 감산 디더 오차 n에 대해서만 성립한다.

### 4.7 감산·비감산 구분 (원문 기준)

23. 원문의 모형은 감산이다(그림 3, 1쪽 정의). n은 양자화기 자체 오차이자 감산 계의 전체 오차 y − x다. [원문]
24. 원문 III절 첫머리의 "y = n + x + d"는 바로 아래의 "ȳ − d = y"와 식 (10) E(y|x) = x + ∫n p(d)dd와 모순되며, ȳ = n + x + d의 오식으로 읽어야 한다. [재구성: 원문 내부 대조]
25. 비감산 디더(non-subtractive dither)에서는 전체 오차가 ε = Q(x+d) − x = n + d다. 원문은 이 경우를 다루지 않는다. ε는 x와 독립으로 만들 수 없고, 모멘트 E[ε^r | x]만 x와 무관하게 만들 수 있다(조건은 Φ_d·sinc 곱의 고계 도함수가 2πm/q에서 0 — Wright 1979, Lipshitz–Wannamaker–Vanderkooy 1992, Gray–Stockham 1993). [미확인: 해당 문헌은 이 저장소에서 대조하지 않음]
    - papers/SURVEY.md는 Schuchman을 "비감산(nonsubtractive) 디더"라고 적었으나, 원문 그림 3과 정의는 감산이다. 이 판정이 원문과 어긋난다.

## 5. 예제

### 5.1 균일 디더 (k = 1)

- d ~ U[−q/2, q/2]: Φ_d(ω) = sin(ωq/2)/(ωq/2), ω = 2πm/q에서 0. 잡음 n ~ U[−q/2, q/2] 독립, E[n] = 0, E[n²] = q²/12. 감산 계 출력 y = x + n의 MSE = q²/12 (입력 분포와 무관).
- 디더 분산 q²/12. 같은 조건을 만족하는 디더 중 분산 최소인지는 원문이 주장하지 않는다 [미확인]. 감산 계에서는 오차가 디더 분산과 무관하게 q²/12이므로, k = 1이 "가장 쓸모 있다"는 원문 판단은 구현의 단순성·진폭 여유(넘침 조건에서 d_max − d_min = q로 최소) 관점에서 타당하다 [재구성].

### 5.2 삼각 디더, 가우시안 디더

- 삼각 디더 = 두 U[−q/2, q/2]의 합 (식 (7), k=1, f_a = 균일): 조건 만족. 감산 계에서는 균일 디더와 같은 오차 분포이고 진폭만 두 배 → 넘침 여유가 q만큼 더 든다.
- 가우시안 디더 N(0, σ_d²): Φ_d(2πm/q) = e^{−2π²σ_d²m²/q²} ≠ 0 → 조건 불충족. 잡음 밀도의 균일 이탈 크기 ≈ (2/q)e^{−2π²σ_d²/q²}·cos(2π(n+x)/q). σ_d = q이면 e^{−19.7} ≈ 2.7×10⁻⁹로 실질적으로 균일.

### 5.3 디더 없음, 가우시안 입력 (Widrow 조건과의 대비)

- d = 0이면 x가 주어졌을 때 n은 결정적이다(독립 불가). 입력이 무작위 X ~ N(0, σ²)이면 n의 **주변** 밀도는 (★)에서 d를 X로 바꾼 것: p(n) = (1/q)[1 + 2Σ_{m≥1} e^{−2π²σ²m²/q²} cos(2πmn/q)].
- 첫 계수 e^{−2π²σ²/q²}: q = σ → 2.7×10⁻⁹, q = 2σ → 7.2×10⁻³, q = 4σ → 0.29. 원문의 "평균 0 가우시안은 (2)를 근사적으로 만족한다"는 서술의 정량화. [재구성 수치]
- 주의: 이것은 주변 균일성이고, n과 X의 독립은 아니다(n은 X의 함수).

## 6. 원문과의 차이·빈틈

- 필요성 증명이 느슨하다("주기 함수이면 변환이 x에 의존"). 푸리에 계수 유일성으로 보강 (4.3의 9).
- 독립 ⇒ 균일을 명시하지 않음.
- 특성함수 규약이 (2)와 (6)에서 다르다(각주파수/주파수).
- 식 (5)·(12)의 인쇄본에 위상 지수와 첨자 오식 의심(W_d(b/d), j 누락). 판독 불확실한 부분은 [미확인]으로 둔다.
- III절 "y = n + x + d" 오식 (4.7의 24).
- 유한 준위에서 "포화 가능하면 독립 불가"는 석사 논문 인용만 있고 증명 없음.
- 다변수(여러 표본, 여러 양자화기) 결합 독립은 "표본마다 독립인 균일 디더가 최적"이라는 한 문장뿐. 결합 독립의 증명 없음.
- 비감산 디더는 다루지 않음.

## 7. 본 연구와의 연결

본 연구: X_k ~ N(0, σ²) 독립(k = 1…K), Q_k = f_k(X_k, W) ∈ ℤ_M, Z = ΣQ_k mod M, Ŝ = g(Z, W), D̄ = E(S − Ŝ)²/(Kσ²). 정리 B의 인코더는 Q_k = round((X_k + d_k)/Δ) mod M, W = (d_1, …, d_K), d_k ~ U[−Δ/2, Δ/2] 독립.

### 7.1 Schuchman이 정확히 보장하는 것

- **단일 작업자**: d_k가 X_k와 독립이고 Φ_{d_k}(2πm/Δ) = 0 (m ≠ 0)이면, 무한(또는 넘침 없는) 양자화기의 오차 e_k = Δ·round((X_k+d_k)/Δ) − X_k − d_k는 X_k와 독립이고 U[−Δ/2, Δ/2]. (4.3의 정리)
- **K 작업자 결합** [재구성, 원문에 없음]: d_1, …, d_K가 서로 독립이고 (X_1…X_K)와 독립이며 각각 조건 (c)를 만족하면, X = x를 고정했을 때 e_k는 서로 다른 독립 변수 d_k만의 함수이므로 조건부 결합 분포는 Π_k U[−Δ/2, Δ/2]이고 x와 무관. 따라서 (e_1, …, e_K)는 i.i.d. 균일이고 (X_1, …, X_K)와, 특히 S와 독립. 그러므로 S + Σe_k의 Σe_k는 S와 독립인 어윈–홀(Irwin–Hall) 잡음이고, E(S − Ŝ)² = KΔ²/12 (Ŝ = ΔΣQ_k − Σd_k, 넘침 없을 때). 이것이 정리 B의 눈금 Δ² = 12D/K (D = 절대 왜곡 = D̄Kσ²), 곧 Δ² = 12D̄σ²의 정확한 근거다.
- 주의: Ziv 1985처럼 **하나의 스칼라 디더를 모든 좌표에 반복**하면 각 e_k는 개별적으로 균일·입력 독립이지만 결합 독립은 아니다(모두 같은 d의 함수). 정리 B는 작업자별 독립 디더 성분을 써야 한다.

### 7.2 넘침 없음 조건과 mod M

- Schuchman의 유한 준위 조건은 **인코더 포화**를 막는 조건이다. 본 연구의 인코더는 포화 대신 mod M으로 감기므로(ℤ_M 값), 각 e_k는 무한 양자화기의 오차와 정확히 같다. 즉 인코더 쪽 넘침 조건은 필요 없다 [재구성].
- 넘침 문제는 **복호기 쪽 감기 풀기(unwrapping)** 로 옮겨간다: 복호기는 Z와 Σd_k를 알고 T = ΣQ_k ∈ Z + Mℤ 중 하나를 골라야 한다. 정확 복원 조건은 |S + Σe_k| < MΔ/2 (원점 중심 선택 규칙에서). S + Σe_k의 표준편차 √(Kσ² + KΔ²/12) ≈ σ√K이므로, 넘침 확률을 2Q(t) 이하로 두려면 MΔ ≥ 2tσ√K, 곧
  log₂M ≥ log₂(2tσ√K/Δ) = ½log₂(K/D̄) + log₂(2t/√12).
  이것이 과제의 "고정 레지스터 폭에 붙는 log₂(2t/√12) 상수"다. 엔트로피 H(Z|W) ≈ ½log₂(K/D̄) + ½log₂(2πe/12)와의 차이는 log₂(2t/√12) − 0.254 (t = 4이면 1.21 − 0.25 = 0.95 bit). [재구성]
- 가우시안은 지지가 무한이라 넘침 확률을 0으로 만들 수 없다. Schuchman 조건의 "x_max"는 존재하지 않으므로, 본 연구의 이상화 "넘침 없음"은 확률 2Q(t)의 사건을 무시한 근사다.

### 7.3 보조정리 L (H(Z|S,W) ≥ ½log₂K − c)에 대한 함의 — 핵심 주의

- Schuchman의 독립·균일 결론은 **디더에 대해 평균했을 때**의 진술이다. 보조정리 L은 W를 **조건으로** 둔다. W = w가 고정되면 e_k = Δ·round((X_k + w_k)/Δ) − X_k − w_k는 X_k의 결정적 함수이므로 "e_k가 (S, W)가 주어졌을 때 독립 균등"은 Schuchman 조건으로는 나오지 않는다.
- 조건부 진술에 필요한 것은 디더 조건이 아니라 **입력 쪽 조건**, 곧 Widrow 조건 (2)의 근사형을 (X_1, …, X_K | S)에 적용한 것이다 [재구성, 이 논문들에 없음]:
  - S = s가 주어지면 X는 초평면 Σx_k = s 위의 가우시안, 공분산 σ²(I − 11ᵀ/K).
  - 분수부 벡터 u_k = frac((X_k + w_k)/Δ)의 결합 밀도를 (★)의 다변수판으로 전개하면 정수 벡터 m에 대한 계수가 Φ_{X|S}(2πm/Δ)이고 |Φ_{X|S}(2πm/Δ)| = exp(−2π²(σ²/Δ²) Σ_k (m_k − m̄)²).
  - m이 1 = (1,…,1)의 정수배이면 지수가 0이다. Σu_k mod 1은 (s + Σw_k)/Δ mod 1로 **결정된다**. 따라서 (S, W)가 주어졌을 때 분수부는 "합이 고정된 부분 토러스" 위에서만 균일할 수 있다.
  - 그 밖의 m에서 Σ(m_k − m̄)² ≥ 1 − 1/K이므로 균일 이탈은 exp(−2π²(1 − 1/K)σ²/Δ²) 차수이고, Δ² = 12D̄σ²를 넣으면 exp(−π²(1 − 1/K)/(6D̄)). D̄ = 0.1, K 큼 → e^{−16.4} ≈ 7×10⁻⁸.
- 이 이상화 아래에서 정확한 값 [재구성]: 분수부가 부분 토러스 위 균일이면, 정수 T = ΣQ_k의 조건부 분포는 어윈–홀 밀도 f_K(합/Δ)를 격자 c + ℤ에서 표집한 것이 되고(어윈–홀 특성함수 sinc^K가 2πm에서 0이므로 정규화가 자동), 오프셋 c가 균일이므로 Zamir–Feder Thm 1과 같은 "격자 합 + 셀 적분 = 연속 적분" 논법으로
  E_{S,W}[H(T | S = s, W = w)] = h(U_1 + … + U_K) (bit, U_i ~ U[−½, ½] i.i.d.).
  - 수치: K = 1: 0, K = 2: 0.721, K = 4: 1.250, K = 8: 1.754, K = 64: 3.255 bit. ½log₂(2πeK/12)로 수렴.
  - 엔트로피 거듭제곱 부등식(EPI)으로 h(ΣU_i) ≥ ½log₂(K · 2^{2·0}) = ½log₂K. 즉 이상화 아래에서는 **c = 0**으로 보조정리 L이 성립하고, 상한은 ½log₂(2πeK/12).
  - mod M: 조건부 지지가 길이 K 미만의 정수 구간이므로 M ≥ K이면 H(Z|S,W) = H(T|S,W).
  - 몬테카를로 점검(σ = 1, 표본 200×200000): K = 4, D̄ = 0.05 → 1.2502 (이론 1.2504), K = 8, D̄ = 0.05 → 1.7536 (1.7538), K = 4, D̄ = 1.0 → 1.207 (저해상도에서 이상화 붕괴 시작).
- 요약: 보조정리 L이 쓰는 "e_k가 S와 독립 균등"은 (i) W에 대해 평균한 진술로는 Schuchman 조건(균일 디더, 작업자별 독립)과 넘침 없음으로 **정확히** 성립하고, (ii) W를 조건으로 둔 진술로는 Schuchman이 아무것도 보장하지 않으며 입력 분포의 매끄러움(σ²/Δ² = 1/(12D̄)이 큼)으로부터 오는 **근사**이고, 그때도 합 Σe_k mod Δ는 결정적이므로 "부분 토러스 위 균일"로 정정해야 한다.

### 7.4 상수 0.254

- 본 논문에는 율·엔트로피 결과가 없으므로 0.254의 출처가 아니다. 이 논문이 주는 것은 0.254 계산의 전제(감산 디더 오차가 입력과 독립인 U[−Δ/2, Δ/2])뿐이다.
