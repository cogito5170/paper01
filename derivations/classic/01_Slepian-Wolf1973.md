## 2. 문제 설정 (원문 기호)

### 2.1 단일 소스 [원문, 472쪽]

- X: 유한 알파벳 𝒜 = {1,…,A} 위의 이산 확률변수(discrete random variable), 분포 p_X(x).
- **X** = (X_1,…,X_n): 독립 동일 분포(i.i.d.) 블록, P_X(**x**) = ∏ p_X(x_i).
- 부호기(encoder) 𝒞(n,M): 단일값 함수 i = f(**x**), 𝒜ⁿ → {1,…,M}.
- 복호기(decoder) 𝒟(n,M): 단일값 함수 **x** = g(i), {1,…,M} → 𝒜ⁿ.
- 율(rate) R = (1/n) log M. **원문은 자연로그(nats)를 쓴다**(exp, log가 모두 자연 밑).
- 허용 율(admissible rate): 모든 ε>0에 대해 어떤 n=n(ε)와 𝒞(n,⌊exp(nR)⌋), 𝒟(n,⌊exp(nR)⌋)가 있어 Pr[**X*** ≠ **X**] < ε.

### 2.2 상관 소스 쌍과 16가지 경우 [원문, 472–473쪽]

- (X,Y): 𝒜_X × 𝒜_Y 위 결합분포 p_XY(x,y), n개 i.i.d. 쌍 (**X**,**Y**), P_XY(**x**,**y**) = ∏ p_XY(x_i,y_i).
- 스위치 S1,S2,S3,S4 (상태변수 s_i ∈ {0,1}, 닫힘=1)가 누가 무엇을 보는지를 정한다(Fig. 3).
  - X-부호기: i_X = f_X(**x**, s2·**y**) → {1,…,M_X}  (S2가 닫히면 X 부호기가 **y**도 본다)
  - Y-부호기: i_Y = f_Y(s1·**x**, **y**) → {1,…,M_Y}  (S1이 닫히면 Y 부호기가 **x**도 본다)
  - X-복호기: **x*** = g_X(i_X, s4·i_Y), Y-복호기: **y*** = g_Y(s3·i_X, i_Y)
- R_X = (1/n) log M_X, R_Y = (1/n) log M_Y.
- **허용 율 점(admissible rate point)**: 모든 ε>0에 대해 어떤 n=n(ε)와 M_X=⌊exp(nR_X)⌋, M_Y=⌊exp(nR_Y)⌋인 부호기·복호기가 있어
  Pr[{**X*** ≠ **X**} ∪ {**Y*** ≠ **Y**}] < ε.
  ℛ = 허용 율 점 집합의 폐포(closure).
- 핵심 경우 **0011** (Fig. 1, Fig. 8): 두 부호기는 서로의 소스를 모르고(S1=S2=0), 두 복호기는 두 메시지를 모두 본다(S3=S4=1). 즉 "분리 부호화, 공동 복호".

## 3. 주 정리 진술 (원문 대조 완료: PDF 4·5·8쪽 이미지로 확인)

**Theorem 1** (단일 소스, 472쪽, 원문은 기존 결과로 인용): R > H(X)이면 R은 허용, R < H(X)이면 허용 불가. 후자에서는 n과 무관한 δ>0가 있어 모든 부호기·복호기 쌍 𝒞(n,⌊exp(nR)⌋), 𝒟(n,⌊exp(nR)⌋)에 대해 Pr[**X*** ≠ **X**] > δ > 0 (강한 역정리 형태).

**Theorem 2** (경우 0011의 꼭짓점, 474쪽, 식 (5)):
R_X = H(X|Y) + ε_X, ε_X > 0;  R_Y = H(Y) + ε_Y, ε_Y > 0
는 경우 0011의 허용 율 점이다.

**Theorem 3** (전형 수열, 475쪽, 기존 결과 인용): 𝒯(ε,n) = {**y**: |f_i(**y**) − n p_Y(i)| < k√(n p_Y(i)[1−p_Y(i)]), i=1,…,A_Y}, k = √(A_Y/ε)보다 큰 최소 정수(식 (9)). 그러면 1) Pr[**Y** ∈ 𝒯(ε,n)] > 1−ε, 2) n, ε와 무관한 A>0가 있어 **y** ∈ 𝒯에 대해 exp[−nH(Y) − A√(n/ε)] < P_Y(**y**) < exp[−nH(Y) + A√(n/ε)], 3) |𝒯(ε,n)| = exp{n[H(Y)+δ_n(ε)]}, lim_{n→∞} δ_n(ε) = 0.

## 4. 유도

### 4.0 준비: 정보량 [원문, 식 (4), (7)]

I(X,Y) ≡ H(X) + H(Y) − H(X,Y) = H(X) − H(X|Y) = H(Y) − H(Y|X).
원문은 I(X;Y)를 I(X,Y)로 쓴다.

### 4.1 Theorem 2 달성성: 원문 증명 (랜덤 "초부호(supercode)") [원문]

**아이디어 (474–475쪽)**: Y는 율 H(Y)+ε_Y로 따로 보내므로 복호기가 **Y**를 안다고 보자. p_XY = p_{Y|X} p_X이므로 **Y**를 "**X**를 입력으로 하는 이산 무기억 채널 p_{Y|X}의 출력"으로 볼 수 있다. 이 채널에는 크기 M ≈ exp[n(I(X,Y) − ε)]의 좋은 채널 부호가 있고, 같은 크기의 좋은 부호를 여러 개 (𝒳_1, 𝒳_2, …) 만들 수 있다. X-부호기는 "**X**를 포함하는 첫 번째 부호의 번호"를 보낸다. 복호기는 그 부호 안에서 **Y**를 출력으로 보고 채널 복호를 한다. 전형 **X**는 약 exp{n[H(X)+η]}개이므로 부호들이 서로소라면
M' = exp{n[H(X)+η]} / exp{n[I(X,Y) − ε]} = exp{n[H(X|Y) + ε_X]}
개면 충분하다. 실제로는 서로소가 아니지만 이 개수만 쓴다. 이것이 오늘날 "비닝(binning)"과 같은 역할이다. 단 원문은 비닝을 "부호 목록의 첫 포함 번호"로 구현한다.

**구성 (475쪽, 식 (8)–(15))**

1. M_X = ⌊exp(nR_X)⌋, M_Y = ⌊exp(nR_Y)⌋, R_X, R_Y는 식 (5)를 따른다.
2. Y-부호기: 𝒯(ε,n)의 원소를 **y**_1,…,**y**_N으로 번호 붙이고 임의의 벡터를 덧붙여 목록 ℒ = (**y**_1,…,**y**_{M_Y})를 만든다. f_Y(**y**) = **y** = **y**_i인 최소 i (**y** ∈ ℒ), 아니면 1 (식 (11)). n이 커서 δ_n(ε) < ε_Y이면 N ≤ M_Y (식 (10)).
3. X-부호(X-code) 𝒳_i = {**x**_{i1},…,**x**_{iM}} (중복 허용), i=1,…,M_X. 이 모음 𝒳를 X-초부호(X-supercode)라 한다.
   f_X(**x**) = **x** ∈ 𝒳_i인 최소 i (**x** ∈ 𝒳 = ∪𝒳_i), 아니면 1 (식 (12)).
4. 복호: g_Y(i_X,i_Y) = **y**_{i_Y} (식 (13)).
   j(i_X,i_Y) = p_{Y|X}(**y**_{i_Y}|**x**_{i_X j}) ≥ p_{Y|X}(**y**_{i_Y}|**x**_{i_X k}) (k=1,…,M)를 만족하는 최소 j (식 (14)), 즉 부호 𝒳_{i_X} 안에서의 최대우도(maximum likelihood) 복호.
   g_X(i_X,i_Y) = **x**_{i_X, j(i_X,i_Y)} (식 (15)).
5. 부호 크기: M = ⌊exp{n[I(X,Y) − ½ε_X]}⌋ (식 (22)), I − ½ε_X > 0 가정.

**랜덤 부호 앙상블 (식 (17)–(18))**: M_X·M개 벡터 **X**_{ij}를 성분별로 p_X에서 i.i.d. 추출. 앙상블 평균 오류확률 P̄_e(𝒳)를 "초부호와 (**X**,**Y**)를 독립으로 뽑는 결합 실험"의 오류확률로 해석한다.

**오류 분해 (식 (19)–(20))**
P_1 = Pr[**Y** ∉ ℒ], P_2 = Pr[**X** ∉ 𝒳], P_3 = Pr[**Y** ∈ ℒ, **X** ∈ 𝒳, **X*** ≠ **X**],
P̄_e ≤ P_1 + P_2 + P_3  (합집합 한계(union bound)).

**(i) P_1 < ε** (식 (21)): ℒ ⊇ 𝒯(ε,n)이고 Theorem 3의 1).

**(ii) P_2 < 2ε** (식 (23)–(26)): **X**의 각 실현 **x**에 대해 M·M_X개의 독립 부호어 중 어느 것도 **x**와 같지 않을 확률은 [1 − P_X(**x**)]^{M M_X}이다. 따라서
P_2 = Σ_x P_X(**x**)[1 − P_X(**x**)]^{M M_X}  (식 (24)).
Theorem 3을 X에 적용하면 확률 < ε인 비전형 부분 𝒯_X^c와, exp{−n[H(X) + A'/√(nε)]} ≤ P_X(**x**)인 전형 부분 𝒯_X로 나뉜다(식 (25); 원문 지수의 √ 위치는 Theorem 3의 A√(n/ε)와 같은 꼴). 그러면
P_2 ≤ [1 − exp{−n[H(X) + A'/√(nε)]}]^{M M_X} + ε ≡ Z + ε.
log(1−t) ≤ −t를 쓰면
log Z ≤ −M M_X exp{−n[H(X) + A'/√(nε)]}.
M M_X ≈ exp{n[I(X,Y) − ½ε_X]}·exp{n[H(X|Y) + ε_X]} = exp{n[H(X) + ½ε_X]}이므로(식 (5), (7), (8), (22))
log Z ≲ −exp{n[½ε_X − A'/√(nε)]} → −∞.
(바닥 함수 ⌊·⌋에 따른 상수배 손실은 지수에 영향 없음.) 따라서 n이 크면 Z < ε, P_2 < 2ε.

**(iii) P_3 → 0** (식 (27)–(36)): Gallager 식 한계.
P_3 ≤ Pr[**X** ∈ 𝒳, **X*** ≠ **X**] = Σ_{x,y} P_XY(**x**,**y**) A(**x**,**y**),
A(**x**,**y**) = Σ_{i=1}^{M_X} Pr[**x**가 𝒳_1,…,𝒳_{i−1}에 없음, **x** ∈ 𝒳_i, 오복호 | **X**=**x**, **Y**=**y**].
**x**가 처음 나타나는 위치 (i,j)로 쪼개면(식 (28)–(29)), a ≡ 1 − P_X(**x**) (식 (33))로
A(**x**,**y**) = Σ_i a^{(i−1)M} Σ_j a^{j−1} P_X(**x**) C_ij(**x**,**y**),
C_ij ≤ Pr[∪_{α≠j} {p_{Y|X}(**y**|**X**_{iα}) ≥ p_{Y|X}(**y**|**x**)} | 𝒟],
여기서 𝒟 = {**X**_{i1}≠**x**,…,**X**_{i,j−1}≠**x**, **X**_{ij}=**x**, **X**=**x**, **Y**=**y**}. (오류가 나려면 같은 부호 안 다른 부호어의 우도가 정답 이상이어야 한다. 동률 처리 규칙 때문에 "≥"이다.)

- 단계 1 (Gallager의 ρ-합집합 한계, 0≤ρ≤1): Pr[∪A_i] ≤ [Σ Pr(A_i)]^ρ (식 (30)). 확률이 1 이하이므로 ρ 제곱이 합집합 한계를 약하게 만들지 않는 쪽으로만 작용한다.
- 단계 2 (조건부 확률 계산, 식 (31)–(32)): α > j이면 **X**_{iα}는 𝒟와 독립이라 조건이 사라진다. α < j이면 조건 "**X**_{iα} ≠ **x**"가 붙는데, Pr[B | **X**_{iα}≠**x**] ≤ Pr[B]/Pr[**X**_{iα}≠**x**] = a^{−1} Pr[B]이다. 따라서
  C_ij ≤ {[(j−1)a^{−1} + M − j] · Pr[p(**y**|**X**') ≥ p(**y**|**x**)]}^ρ, **X**' ~ P_X.
- 단계 3 (체르노프(Chernoff)형 한계, 임의의 s ≥ 0): 지시함수 1{p(**y**|**x**')/p(**y**|**x**) ≥ 1} ≤ [p(**y**|**x**')/p(**y**|**x**)]^s 이므로
  Pr[p(**y**|**X**') ≥ p(**y**|**x**)] ≤ Σ_{x'} P_X(**x**')[p(**y**|**x**')/p(**y**|**x**)]^s.
- 단계 4 (부록의 합 한계, 식 (35)):
  Σ_{i=1}^{M_X} a^{(i−1)M} Σ_{j=1}^{M} a^{j−1}[(j−1)a^{−1} + M − j]^ρ ≤ M^ρ / P_X(**x**).
  증명 [원문 부록 + 계산 보충]:
  · Σ_i a^{(i−1)M} = (1 − a^{M M_X})/(1 − a^M) ≤ 1/(1 − a^M).
  · 가중치 p_j = a^{j−1}(1−a)/(1−a^M) (Σp_j = 1)와 x_j = (j−1)a^{−1} + M − j에 대해, x^ρ가 오목(0≤ρ≤1)이므로 젠센(Jensen) 부등식으로 Σ_j a^{j−1}x_j^ρ = [(1−a^M)/(1−a)] Σ p_j x_j^ρ ≤ [(1−a^M)/(1−a)] (Σ p_j x_j)^ρ.
  · x_j = M − 1 + (j−1)(1−a)/a 이고, 절단 기하분포의 평균 Σ p_j (j−1) ≤ a/(1−a)이므로 Σ p_j x_j ≤ M.
  · 곱하면 ≤ [1/(1−a^M)]·[(1−a^M)/(1−a)]·M^ρ = M^ρ/(1−a) = M^ρ/P_X(**x**).
- 단계 5 (조립, 식 (34)–(36)): P_X(**x**)가 약분되어
  P_3 ≤ Σ_{x,y} P_X(**x**) p(**y**|**x**)^{1−sρ} M^ρ [Σ_{x'} P_X(**x**') p(**y**|**x**')^s]^ρ.
  s = 1/(1+ρ)로 두면
  P_3 ≤ T ≡ M^ρ Σ_y [Σ_x P_X(**x**) p_{Y|X}(**y**|**x**)^{1/(1+ρ)}]^{1+ρ}  (식 (36)).
  이것은 정확히 크기 M인 랜덤 채널 부호에 대한 Gallager 한계이다. 즉 "**X**를 포함하는 부호 찾기"의 비용이 사라지고 채널 부호 하나의 오류만 남는다.
- 단계 6 (단일 문자화와 지수): 곱 구조로 Σ_y[…]^{1+ρ} = exp[−nV(ρ)],
  V(ρ) = −log Σ_y [Σ_x p_X(x) p_{Y|X}(y|x)^{1/(1+ρ)}]^{1+ρ}
  (현대 표기로 Gallager의 E_0(ρ, p_X)). M ≤ exp{n[I − ½ε_X]}이므로
  T ≤ exp{−nρ[V(ρ)/ρ − I(X,Y) + ½ε_X]}.
  V(0)=0, E(ρ) ≡ V(ρ)/ρ는 0 근처에서 해석적이고 E(0) = V'(0) = I(X,Y) (로피탈). 따라서 |E(ρ_0) − I| < ε_X/4인 ρ_0>0가 있어
  P_3 ≤ exp(−nρ_0 ε_X/4) → 0.
- 결론: P̄_e ≤ ε + 2ε + ε = 4ε. ε = ε'/4로 두면 P̄_e < ε'이므로 앙상블 안에 오류 < ε'인 초부호가 존재한다. ∎

### 4.2 Theorem 2 달성성: 현대 표준 증명 (랜덤 비닝 + 결합 전형성) [재구성]

El Gamal–Kim, *Network Information Theory* 10장 식의 증명(비트 단위, log₂).

- 비닝(binning): 각 **x** ∈ 𝒳ⁿ에 bin 번호 B_X(**x**) ~ Unif{1,…,2^{nR_X}}를 독립 부여. 같은 방식으로 B_Y(**y**).
- 복호: (b_X,b_Y)를 받으면 B_X(**x̂**)=b_X, B_Y(**ŷ**)=b_Y이면서 (**x̂**,**ŷ**) ∈ 𝒯_ε^{(n)}(X,Y)인 쌍이 유일하면 그것을 출력.
- 오류 사건: ℰ_1 = {(**X**,**Y**) ∉ 𝒯_ε}, ℰ_2 = {∃ **x̃**≠**X**: B_X(**x̃**)=B_X(**X**), (**x̃**,**Y**)∈𝒯_ε}, ℰ_3 (Y 쪽 대칭), ℰ_4 = {∃ **x̃**≠**X**, **ỹ**≠**Y**: 두 bin 일치, (**x̃**,**ỹ**)∈𝒯_ε}.
  · P(ℰ_1) → 0: 대수의 법칙(LLN).
  · P(ℰ_2) ≤ Σ_{**x̃** ∈ 𝒯_ε(X|**Y**)} 2^{−nR_X} ≤ 2^{n(H(X|Y)+δ(ε))}·2^{−nR_X} → 0, R_X > H(X|Y)+δ(ε)이면. 근거: 조건부 전형 집합의 크기 |𝒯_ε(X|**y**)| ≤ 2^{n(H(X|Y)+δ(ε))}, 그리고 bin 독립성.
  · P(ℰ_3) → 0 ⇐ R_Y > H(Y|X)+δ(ε).
  · P(ℰ_4) ≤ |𝒯_ε(X,Y)|·2^{−n(R_X+R_Y)} ≤ 2^{n(H(X,Y)+δ(ε)−R_X−R_Y)} → 0 ⇐ R_X+R_Y > H(X,Y)+δ(ε).
- 따라서 영역 내부 전체를 직접 달성(시분할 불필요). 원문의 "꼭짓점 + 시분할(g) + 비트 채우기(f)" 경로와 같은 결론.

### 4.3 역정리 (원문 경로) [원문]

**Theorem E (R_X + R_Y ≥ H(X,Y), 모든 스위치)**: (X,Y)를 A_X·A_Y 값을 갖는 단일 변수 Z로 본다. H(Z) = H(X,Y). Fig. 3의 어떤 부호도 (I_X,I_Y) 쌍의 번호를 I_Z로 삼으면 Z의 부호가 된다. 만약 R_X+R_Y = H(X,Y) − δ가 허용이면
M_Z = M_X M_Y = ⌊exp(nR_X)⌋⌊exp(nR_Y)⌋ ≤ ⌊exp[n(H(X,Y) − δ)]⌋
개 값으로 오류 < ε인 Z 부호가 존재하게 되어 Theorem 1(역)과 모순. ∎
근거: "메시지 쌍의 개수 = 곱"이라는 계수(counting) 논법 + 단일 소스 강한 역정리.

**Theorem A (S1 열림 ⇒ R_X ≥ H(X|Y))**: (R_X,R_Y) = (H(X|Y) − δ, R_2)가 허용이고 오류 < ε인 부호 (𝒞_X, 𝒞_Y, 𝒟_X, 𝒟_Y)가 있다고 하자. S1이 열려 있으므로 I_Y = f_Y(**Y**)는 **Y**만의 함수다. 𝒞_Y를 율 H(Y)+δ/2의 전형 목록 부호 𝒞_Y'로 바꾸고(Theorem 1), 복호기 𝒟_Y'' = "𝒟_Y'로 **Y** 복원 → 𝒞_Y로 I_Y 재계산 → 원래 𝒟_X, 𝒟_Y"로 둔다. 그러면 (𝒞_X, 𝒞_Y', 𝒟_X, 𝒟_Y'')는 율 (H(X|Y) − δ, H(Y) + δ/2), 오류 ≲ 2ε이다. 합율 = H(X,Y) − δ/2 < H(X,Y)이므로 Theorem E와 모순. ∎
(원문은 "error probability < ε"라고만 쓰지만 실제로는 두 오류의 합이므로 ≤ 2ε 수준이다. 결론에는 영향 없음.)

**Theorem B**: A에서 X↔Y. **C, D**: Theorem 1에서 바로(복호기가 다른 메시지를 못 보면 단일 소스 문제).

**채우기**: Theorem f(율을 올려도 안 쓰는 번호만 생김), Theorem g(두 강허용 점의 블록 교대 사용, 유리수 λ 후 폐포), Theorem h(볼록성; Fig. 4–9 검사로 확인했다고 원문이 서술).

### 4.4 역정리 (현대 약한 역정리, Fano) [재구성]

부호 (n, 2^{nR_X}, 2^{nR_Y}), P_e^{(n)} → 0, M_X = f_X(Xⁿ), M_Y = f_Y(Yⁿ)라 하자. 파노(Fano) 부등식: H(Xⁿ,Yⁿ | M_X,M_Y) ≤ nε_n, ε_n → 0.

- R_X ≥ H(X|Y):
  nR_X ≥ H(M_X) ≥ H(M_X|Yⁿ)                    (조건화는 엔트로피를 줄임)
  = H(M_X|Yⁿ) + H(Xⁿ|M_X,Yⁿ) − H(Xⁿ|M_X,Yⁿ)
  = H(Xⁿ,M_X|Yⁿ) − H(Xⁿ|M_X,Yⁿ)              (연쇄 법칙)
  = H(Xⁿ|Yⁿ) − H(Xⁿ|M_X,Yⁿ)                   (M_X는 Xⁿ의 함수)
  ≥ nH(X|Y) − H(Xⁿ|M_X,M_Y)                   (i.i.d.로 H(Xⁿ|Yⁿ)=nH(X|Y); M_Y는 Yⁿ의 함수이므로 H(Xⁿ|M_X,Yⁿ) = H(Xⁿ|M_X,M_Y,Yⁿ) ≤ H(Xⁿ|M_X,M_Y))
  ≥ n[H(X|Y) − ε_n]                            (Fano)
- R_Y ≥ H(Y|X): 대칭.
- R_X+R_Y ≥ H(X,Y): n(R_X+R_Y) ≥ H(M_X,M_Y) ≥ I(Xⁿ,Yⁿ; M_X,M_Y) = nH(X,Y) − H(Xⁿ,Yⁿ|M_X,M_Y) ≥ n[H(X,Y) − ε_n].

원문 역정리는 단일 소스의 **강한** 역정리를 환원으로 옮겨서 "율이 경계 아래면 오류가 0으로 가지 않는다"는 형태이지만, 환원 단계에서 오류 상한을 ε으로 잡으므로 실제로 증명된 것은 "ε→0에서 허용 불가"(약한 형태)와 같다. 강한 역정리(고정 ε<1에서도)는 이후 Ahlswede–Gács–Körner(1976)의 블로우업(blowing-up) 보조정리로 일반화됨 [기억].

## 5. 예제

### 5.1 이중 대칭 이진 소스(DSBS) [재구성 계산]

X ~ Bern(½), Y = X ⊕ N, N ~ Bern(p) 독립, h(p) = −p log₂p − (1−p)log₂(1−p).
- H(X) = H(Y) = 1, H(X|Y) = H(Y|X) = h(p), H(X,Y) = 1 + h(p).
- 0011 영역: R_X ≥ h(p), R_Y ≥ h(p), R_X + R_Y ≥ 1 + h(p).
- 예: p = 0.11 → h(p) ≈ 0.4999. 꼭짓점 (0.5, 1): 따로 무손실 압축하면 (1,1)이 필요하므로 합율 약 0.5비트/문자 절약.
- 선형(신드롬) 구현 [기억, Wyner 1974]: 패리티 검사 행렬 H ∈ 𝔽₂^{(n−k)×n}로 신드롬 H**X**를 보낸다(율 (n−k)/n ≈ h(p)). 복호기는 H**X** ⊕ H**Y** = H**N**에서 **N**을 추정(BSC 채널 복호와 동일)하고 **X** = **Y** ⊕ **N̂**. **선형 비닝은 합에 대해 닫혀 있다**: H(**X** ⊕ **Y**) = H**X** ⊕ H**Y**. 원문의 초부호(첫 포함 번호)는 이 성질이 없다. 이 차이가 Körner–Marton(1979)과 본 연구의 출발점이다(7절).

### 5.2 가우시안 경우

원문은 이산·무손실이므로 가우시안에 직접 적용 불가. 원문 V절도 연속값 확장을 "율-왜곡 이론이 필요한 미해결 과제"로 남긴다. 손실 확장은 Wyner–Ziv(1976), Berger–Tung 내부 경계 [기억]로 이어진다.

## 6. 원문과의 차이·빈틈

1. **비닝이 아니라 초부호 + ML 복호 + Gallager 한계**: 원문 달성성은 오늘날 교과서의 "랜덤 비닝 + 결합 전형성 복호"가 아니다. 무작위로 만든 M_X개의 채널 부호 목록에서 **X**가 처음 나타나는 부호 번호를 보내고, 부호 안에서는 최대우도로 복호한다. 오류 분석은 Gallager의 ρ-한계와 E_0 함수의 미분(E(0)=I)을 쓴다. 결과적으로 오류 지수(error exponent)까지 얻는 장점이 있다(P_3 ≤ exp(−nρ_0 ε_X/4)). 현대식 비닝 증명은 Cover(1975, 에르고드 소스로 확장) 이후 표준이 됨 [기억; Wyner 1975 각주 2에 Cover 1975 인용 확인].
2. **단위**: 원문은 nats(자연로그). 비트로 바꾸려면 log₂로 바꿔 읽으면 된다.
3. **꼭짓점만 직접 증명**: 내부·경계는 비트 채우기(f)와 시분할(g)로 채운다. 시분할은 "강허용"(충분히 큰 모든 n에서 성립) 점에 대해서만 증명하며 유리수 λ 후 폐포를 쓴다. 비닝 증명은 내부를 직접 달성한다.
4. **Theorem A의 오류 회계**: 환원 후 오류를 ε으로 적었으나 실제로는 두 오류의 합. 결론에는 영향 없음.
5. **Theorem h(볼록성)**: 일반 증명 없이 "Fig. 4–9를 보면 모두 볼록"이라는 검사로 주장.
6. **Table I의 c/d 표기**: 표 식과 본문 서술의 X·Y 역할이 엇갈린다(3절 주석). 결과에는 영향 없음.
7. **N개 소스, 율-왜곡, 가변 길이, 메모리 소스**: 원문 V절이 미해결로 남긴 과제. 이후 Cover(1975)의 N-소스·에르고드 확장, Wyner–Ziv(1976)·Berger–Tung의 손실 확장, Körner–Marton(1979)의 함수(모듈로 합) 복원이 이어짐 [기억].

## 7. 본 연구와의 연결

본 연구 모델: K명의 작업자, X_k ~ N(0,σ²) 독립, 인코더 Q_k = f_k(X_k,W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만 계산(복호·재부호화 없음), 복호기 Ŝ = g(Z,W)로 S = ΣX_k 추정. 정리 A(가설): R_down = log₂M ≥ ½log₂(K/D̄) − c, D̄ = E(S−Ŝ)²/(Kσ²). 증명 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½log₂K − c.

1. **사슬 첫 단계 log₂M ≥ H(Z|W)의 원형 = Theorem E의 계수 논법.** Theorem E는 "메시지가 가질 수 있는 값의 수 ≥ exp(복원해야 할 것의 엔트로피)"를 메시지 쌍의 번호로 묶어 쓴다. 본 연구에서 Z ∈ ℤ_M이므로 H(Z|W) ≤ log₂M은 같은 계수 논법의 한 줄짜리 판이다. 차이: SW는 복원 대상(X,Y)의 엔트로피 전체를 하한으로 쓰지만, 본 연구는 복원 대상 S의 정보 I(S;Z|W)와 **복원에 쓸모없지만 피할 수 없는 잉여** H(Z|S,W)를 분리해 둘 다 센다.

2. **기준선(제약 없는 부호)에서의 역할.** 독립 소스(X_k 독립)에서는 SW 영역이 각자 압축하는 것과 같아 비닝 이득이 없다(H(X_k | 나머지) = H(X_k)). 따라서 "스위치가 각 Q_k를 복호할 수 있는" 기준선의 상향 링크 쪽 비용은 개별 부호화로 충분하고, 하향 링크 기준선은 스위치가 Ŝ를 만든 뒤 다시 양자화하는 율 ½log₂(Kσ²/E(S−Ŝ)²) = ½log₂(1/D̄)이다(가우시안 율-왜곡; 이 논문 밖 결과). 정리 A와의 격차 ½log₂K가 "합 호환 제약의 비용"이라는 해석에서, SW는 "복호·재부호화가 허용되면 상관이 없을 때 추가 이득도 손실도 없다"는 쪽 기준점을 준다.

3. **비닝의 대수 구조와 합 호환성.** 원문의 초부호 비닝(첫 포함 번호)은 덧셈과 무관한 임의 분할이라, bin 번호의 모듈로 합이 합의 bin 번호가 되지 않는다. 5.1의 선형 신드롬 비닝은 H(**x**⊕**y**) = H**x**⊕H**y**를 만족한다. 본 연구의 Q_k = f_k(X_k,W) ∈ ℤ_M과 Z = ΣQ_k mod M은 정확히 "**선형(군 준동형) 비닝만 스위치를 통과한다**"는 제약이다. 즉 SW의 임의 비닝은 본 연구의 허용 부호 집합 밖이고, 허용 부호는 Körner–Marton형 선형 구조로 좁혀진다.

4. **보조정리 L에 대한 직관(본 연구 측 계산, 원문 내용 아님).** 원문 Theorem 2의 꼭짓점에서 X 메시지는 "Y가 주어졌을 때 X의 잔여 불확실성" H(X|Y)만 운반한다. 본 연구에서 스위치 출력 Z는 S가 주어져도 잔여 불확실성 H(Z|S,W)를 운반한다. 예: Q_k = ⌊X_k/Δ⌋ mod M(디더 없음, Δ ≪ σ, 랩어라운드 무시)이면 ΣQ_k = S/Δ − Σ frac(X_k/Δ)이고, S가 주어져도 Σ frac(·)는 대략 분산 K/12인 정수 격자 위 분포라 H(Z|S) ≈ ½log₂(2πeK/12) = ½log₂K + ½log₂(πe/6). 즉 ½log₂K 항은 "각자 양자화한 오차의 합이 S로 결정되지 않는다"에서 나온다. [근사; 엄밀화는 보조정리 L의 과제]

5. **증명 기법 측면.** 원문의 오류 분석(초부호 + ρ-합집합 한계)은 본 연구 사슬에 직접 쓰이지 않는다. 본 연구 하한에는 4.4의 Fano형 약한 역정리 구조(엔트로피 연쇄 법칙 + 함수 관계에 의한 소거)가 더 가깝다.
