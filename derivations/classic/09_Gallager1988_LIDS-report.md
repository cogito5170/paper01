# 09. Gallager — 잡음 방송망에서 패리티 구하기 (유도 노트)

## 1. 서지

- R. G. Gallager, "Finding Parity in a Simple Broadcast Network," MIT LIDS 보고서 LIDS-P-1490, 1985년 8월 작성, 1987년 3월 개정. (파일명은 1988; 같은 내용이 IEEE Trans. Inform. Theory 34(2), 1988에 실렸다고 알려져 있으나 이 노트는 보고서판만 대조했다 [미확인: 학술지판과의 차이].)
- 원본 파일: `papers/classic/09_Gallager1988_LIDS-report.pdf` (본문 15쪽 + 표지).
- 보고서 형식이라 정리(theorem) 번호가 없다. 아래에서 "식 (n)"은 보고서의 식 번호다.
- 문제의 출처: A. El Gamal이 1984년 Bellcore 워크숍에서 낸 미해결 문제 (보고서 참고문헌 [1]).

## 2. 문제 설정 (원문 기호)

- 노드 N+1개. 그중 하나가 수신 노드(receiver), 나머지 N개가 일반 노드다. (초록은 "N nodes"라 쓰고 본문은 N+1로 쓴다. 본문을 따른다.)
- 각 노드는 1비트 상태(state)를 가진다.
- 한 노드가 보낸 이진 숫자 하나는 다른 모든 노드에 각각 이진 대칭 채널(binary symmetric channel, BSC, 교차 확률 ε<1/2)을 거쳐 도착한다. 잡음은 송신자·수신자·시간에 대해 모두 독립이다. 즉 같은 전송이라도 수신 노드마다 독립적으로 뒤집힌다.
- 경합(contention)은 없다. 모든 노드가 알고리즘을 알고, 누가 언제 보내는지 안다.
- 목표: 수신 노드가 전체 상태의 패리티(parity, 모듈로-2 합)를 오류 확률 P* 이하로 구하는 것. 비용은 **노드당 전송 비트 수 m** 이다.
- 관련 문제(3절): 수신 노드가 모든 노드의 상태를 각각 알아내는 것(identity 문제).
- 기호: ε_j = 한 비트를 j번 반복 수신해 다수결로 판정했을 때의 오류 확률, α = [4ε(1−ε)]^(−1/2) (>1), Z = 1 − (1−2ε)²/4 (<1), k = 부분집합 크기, j = 반복 횟수.

보고서가 강조하는 문제의 특이점 [원문]: 각 노드는 1비트만 가지므로 블록 부호화를 전제로 한 통상의 부호화 정리(coding theorem)를 쓸 수 없다. 또 한 번의 전송을 N개 노드가 독립 잡음으로 받으므로 "집단적으로는" 그 비트를 잘 알지만, 집단이 행동하려면 각자의 (역시 잡음 섞인) 전송을 써야 한다.

주 결과를 한 문장으로: **오류 확률 P*를 고정하면, 수신 노드가 패리티(나아가 모든 상태)를 얻는 데 노드당 O(ln ln N) 비트면 충분하다.** 전체 전송량은 O(N ln ln N)이다. 이것은 상계(달성)만이고, 보고서는 하계를 증명하지 않는다.

## 4. 유도

### 4.1 단순 반복의 한계: 식 (1) [원문 + 재구성]

노드가 자기 상태를 j번 보내고 수신 노드가 다수결로 판정한다고 하자. 오류는 j번 중 j/2번 이상 뒤집힐 때 일어난다 (동률은 오류로 셈).

[재구성] 체르노프(Chernoff)식 한계:
P(오류) = Σ_{i≥j/2} C(j,i) ε^i (1−ε)^(j−i).
i ≥ j/2이고 ε < 1/2이면 ε^i (1−ε)^(j−i) ≤ [ε(1−ε)]^(j/2) 이므로
P(오류) ≤ [ε(1−ε)]^(j/2) Σ_i C(j,i) = [4ε(1−ε)]^(j/2) = α^(−j).
이것이 식 (1) ε_j ≤ α^(−j)이다. 보고서는 [2](Gallager 1968, 5.3절)를 근거로 들고 "꽤 정확한(closely)" 상계라고 한다.

같은 논법을 "독립 오류 확률이 각각 β 이하인 n개 추정의 다수결"에 쓰면 오류 ≤ [4β(1−β)]^(n/2) 이다. 이것을 아래 식 (3)과 (17)에서 재사용한다.

모든 노드 상태를 이렇게 받아 패리티를 계산하면 한 노드라도 틀리면 패리티가 틀릴 수 있으므로 합집합 한계(union bound)로 P ≤ Nα^(−j). Nα^(−j)가 작을 때 이 한계는 거의 정확하므로 P를 상수로 두려면 j ≥ ln(N/P)/ln α, 즉 **j ~ ln N** 이 필요하다 [원문].

### 4.2 부분집합 분할 방식 [원문]

1. N개 노드(수신 노드 제외)를 크기 k 또는 k−1인 부분집합으로 나눈다. (k−1)² ≤ N이면 항상 가능하다.
   - [재구성] 근거: q = ⌈N/k⌉개의 집합을 만들고 r = qk − N (0 ≤ r ≤ k−1)개 집합에서 하나씩 뺀다. r ≤ q 이면 된다. N ≥ (k−1)²이면 q ≥ ⌈(k−1)²/k⌉ = ⌈k − 2 + 1/k⌉ = k−1 ≥ r (k ≥ 2).
2. 모든 노드가 자기 상태를 j번 방송한다. (j ∝ ln ln N로 고를 것.)
3. 각 노드는 **자기 부분집합 안의** 다른 노드들의 상태를 j번 수신으로 판정하고, 그 판정들과 자기 상태를 모듈로 2로 더해 "자기 부분집합 패리티의 추정"을 만든다.
4. 각 노드는 이 추정을 **정확히 한 번** 방송한다. 노드당 비트 수 m = j + 1.
5. 수신 노드는 각 부분집합에 대해 k개(또는 k−1개)의 추정을 받고, 자기도 2단계의 j번 수신으로 예비 추정을 하나 만든다. 이들의 다수결로 부분집합 패리티를 정한다.
6. 부분집합 패리티들과 자기 상태를 모듈로 2로 더해 전체 패리티를 낸다.

핵심 아이디어: 반복 j는 "부분집합 안에서 k−1개 판정이 모두 맞을 정도"로만 크면 되고(로그 k), 전체 신뢰도는 k개의 독립 추정에 대한 다수결이 맡는다(k ~ ln N). 그래서 j ~ ln k ~ ln ln N.

### 4.3 한 추정이 틀릴 확률: 식 (2) [원문]

크기 k인 부분집합의 한 노드가 보낸 패리티 추정을 수신 노드가 받는다. 이 추정이 틀리는 원인은 (a) 송신 노드의 k−1개 판정 오류, (b) 패리티 비트 전송 오류. I = (판정 오류 수) + (전송 오류면 1)로 두면 추정은 I가 홀수일 때 틀린다.

z-변환(생성함수) f(z) = E[z^I]. 오류들은 독립이므로
f(z) = [(1−ε_j) + ε_j z]^(k−1) · [(1−ε) + εz].

P(I 홀수) = [f(1) − f(−1)]/2. f(1) = 1, f(−1) = (1−2ε_j)^(k−1)(1−2ε). 따라서

β = [1 − (1−2ε_j)^(k−1)(1−2ε)]/2.  … 식 (2)

크기 k−1인 부분집합에서는 지수가 k−2가 되어 β보다 작다. 수신 노드 자신의 예비 추정은 k(또는 k−1)개 판정의 모듈로 합이고 전송 오류 항이 없으므로 [재구성: 오류 확률 = [1 − (1−2ε_j)^k]/2 ≤ β; 보고서는 "역시 β로 상계된다"고만 씀. ε_j ≤ ε이면 성립하며, j ≥ 1이면 다수결이 단일 수신보다 나쁘지 않으므로 ε_j ≤ ε로 볼 수 있다].

**독립성** [원문, 재구성으로 보충]: 같은 부분집합의 서로 다른 송신 노드가 같은 노드 u의 j번 전송을 판정하더라도, BSC 잡음이 수신자마다 독립이므로 판정 오류는 서로 독립이다. 패리티 전송 오류도 독립. 그래서 수신 노드가 보는 k+1개(또는 k개) 추정의 오류는 서로 독립이다. 이 "수신자별 독립 잡음"이 방식 전체의 근거다.

### 4.4 다수결과 부분집합 오류: 식 (3), (4) [원문]

추정 수는 k+1(또는 k)개 ≥ k이고, 4.1의 다수결 한계에서 지수는 추정 수/2이므로 보수적으로 k/2를 쓴다:

P_subset ≤ [4β(1−β)]^(k/2).  … 식 (3)

x = (1−2ε_j)^(k−1)(1−2ε)로 두면 β = (1−x)/2, 1−β = (1+x)/2, 4β(1−β) = 1 − x². 따라서

P_subset ≤ [1 − (1−2ε_j)^(2(k−1))(1−2ε)²]^(k/2).  … 식 (4)

### 4.5 전체 오류: 식 (5)–(7) [원문]

부분집합 수는 최대 N이므로 합집합 한계로 P ≤ N·P_subset. 식 (1)로 ε_j ≤ α^(−j)를 대입하면 (1−2ε_j) ≥ (1−2α^(−j)) 이므로 [재구성: α^(−j) ≤ 1/2가 필요]

P ≤ N[1 − (1−2α^(−j))^(2(k−1))(1−2ε)²]^(k/2).  … 식 (5)

우변은 k에 대해 감소하다 증가한다(지수 k/2는 커지지만 대괄호 안이 1로 다가감). 최적 k는 복잡하므로 다음 제약을 둔다:

(1−2α^(−j))^(2(k−1)) ≥ 1/4.  … 식 (6)

그러면 대괄호 ≤ 1 − (1−2ε)²/4 = Z 이므로

P ≤ N·Z^(k/2),  Z = 1 − (1−2ε)²/4.  … 식 (7)

해석: (7)을 P* 이하로 하려면 k ≥ 2 ln(N/P*)/ln(1/Z), 즉 k는 ln N에 비례. (6)을 만족시키려면 2(k−1)·(−ln(1−2α^(−j))) ≤ ln 4, 대략 4kα^(−j) ≲ ln 4이므로 j ≳ ln k/ln α, 즉 j는 ln k ~ ln ln N에 비례.

### 4.6 정수 맞추기: 식 (8)–(11) [원문]

실수 근사값

k* = 2 ln(N/P*)/ln(1/Z),  j* = [ln 2 − ln(1 − 2^(−1/k*))]/ln α,  … 식 (8)

k = ⌈k*⌉, j = ⌈j*⌉.

- j*의 정의를 정리하면 α^(−j*) = (1 − 2^(−1/k*))/2, 곧 1 − 2α^(−j*) = 2^(−1/k*), 따라서
  (1 − 2α^(−j*))^(2k*) = 1/4.  … 식 (9)
- k* > k−1, j* ≤ j 이므로 (1−2α^(−j))^(2(k−1)) ≥ (1−2α^(−j*))^(2k*) = 1/4, 즉 (6) 성립 [원문; 단조성은 재구성으로 보충: 1−2α^(−j)는 j에 증가, 밑이 [0,1]이면 지수에 감소].
- 따라서 (7)이 성립하고, k* ≤ k, Z<1이므로
  P ≤ N Z^(k/2) ≤ N Z^(k*/2) = P*.  … 식 (10)
  (마지막 등호는 k* 정의를 다시 쓴 것: Z^(k*/2) = exp(−ln(N/P*)) = P*/N.)
- k* ≥ 1이면 1 − 2^(−1/k*) ≥ 1/(2k*) [재구성: t = 1/k* ∈ (0,1]에서 1 − 2^(−t) ≥ t/2. 1 − 2^(−t)는 오목이고 t=0에서 0, t=1에서 1/2이므로 현(chord) t/2 위에 있다]. 이를 j*에 대입하면
  j* ≤ [ln 2 + ln(2k*)]/ln α = ln(4k*)/ln α.  … 식 (11)

### 4.7 최종 한계: 식 (12)–(14) [원문]

m = j + 1 ≤ j* + 2. (11)에 k* = 2 ln(N/P*)/ln(1/Z)를 넣으면
ln(4k*) = ln 8 + ln ln(N/P*) − ln ln(1/Z). 따라서

m ≤ [ln ln(N/P*) + A]/ln α + 2,  A = ln 8 − ln ln(1/Z).  … 식 (12), (13)

사용한 제약 두 가지:
- N ≥ (k−1)²: N ≥ k*²이면 충분 (k−1 < k*).
- k* ≥ 1.
이를 k* 정의로 풀면

N ≥ [2 ln(N/P*)/ln(1/Z)]²,  N ≥ P*/√Z.  … 식 (14)

[재구성] 두 번째: k* ≥ 1 ⇔ 2 ln(N/P*) ≥ ln(1/Z) ⇔ N/P* ≥ Z^(−1/2).

보고서의 해석 [원문]:
- 고정된 P*, ε에서 (14)는 충분히 큰 N에서 항상 성립하므로 **m은 점근적으로 많아야 ln ln N으로 자란다.**
- 반대로 고정된 N, ε에서 P*를 줄이면 (14)가 깨지므로, (12)가 m ~ ln ln(1/P*)를 뜻하지는 않는다. 실제로 수신 노드 외 모든 노드가 패리티를 안다 해도 오류 확률은 대략 ε^(Nm)보다 빨리 줄 수 없다 (보고서 원문은 "ε^(−Nm)"으로 인쇄됨. 부호 오식으로 보인다 [재구성]).
- 크기 1~k인 부분집합 하나를 허용하면 N ≥ (k−1)² 제약을 N ≥ k로 완화할 수 있으나 일부 노드가 한 비트를 더 보내야 하고 점근은 같다(세부 생략).
- ε이 클 때 각 노드가 여러 부분집합의 패리티를 보내 A를 줄일 수 있다(세부 생략).
- 다층(multi-tier) 부분집합 방식: 이 N+1 노드 전체를 더 큰 집합의 한 부분집합으로 보고 같은 기법을 반복하는 것. 상위 계층의 추정들은 서로 독립이 아니라서 분석이 깨지며, 보고서는 **점근을 개선하지 못할 것이라고 추측(conjecture)** 한다.

### 4.8 전체 상태 복원: 식 (15)–(23) [원문]

구조를 바꾼다. 분할 대신 **N개의 부분집합**을 만들되
- 각 부분집합의 크기는 k 또는 k−1,
- 각 노드는 k 또는 k−1개의 부분집합에 속하고,
- 어떤 두 노드도 둘 이상의 부분집합에 함께 속하지 않는다 (두 부분집합의 공통 노드 ≤ 1).
이런 구성은 N ≥ 2k(k−1)²이면 존재한다(식 (15), 부록). 각 노드를 자기가 속한 서로 다른 부분집합 하나에 일대일로 배정한다. (그림 1: N=7, k=3 예. 사실상 파노 평면(Fano plane)의 결합 행렬이다 [재구성].)

절차: 각 노드가 상태를 j번 방송 → 각 노드가 배정된 부분집합의 패리티를 추정해 한 번 방송 (m = j+1). 수신 노드는 노드 i를 복원할 때 i를 포함하는 각 부분집합 S_{i,ℓ}에 대해 "받은 패리티 추정 + (S_{i,ℓ} − {i})에 대한 자기 예비 판정들"을 모듈로 2로 더한다. 모두 맞으면 다른 노드들이 두 번 더해져 사라지고 i의 상태만 남는다.

이 추정의 오류 = 패리티 전송 1개 + 수신 노드 판정 k−1개 + 송신 노드 판정 k−1개 중 홀수 개 오류. 4.3과 같은 생성함수 계산으로

β′ = [1 − (1−2ε_j)^(2(k−1))(1−2ε)]/2.  … 식 (16)

부분집합들이 i 외에는 서로 겹치지 않으므로(S_{i,ℓ} − {i}가 서로소) 추정들의 오류가 독립이다. [재구성 보충: 송신 노드의 판정은 그 송신 노드 고유의 수신 잡음에 의존하고, 수신 노드의 판정은 노드별로 서로 다른 전송을 쓰므로 서로소이면 독립.] 예비 판정 + k−1 또는 k개 추정, 총 k 또는 k+1개 [원문은 "k or k+1"로 씀]의 다수결:

P_i ≤ [4β′(1−β′)]^(k/2).  … 식 (17)

4β′(1−β′) = 1 − (1−2ε_j)^(4(k−1))(1−2ε)², ε_j ≤ α^(−j) 대입:

P_i ≤ [1 − (1−2α^(−j))^(4(k−1))(1−2ε)²]^(k/2).  … 식 (18)

P ≤ N P_i, 제약 (1−2α^(−j))^(4(k−1)) ≥ 1/4 (식 (19)) 아래에서 P ≤ N Z^(k/2) (식 (20)). 같은 k*와 j* = [ln 2 − ln(1 − 2^(−1/(2k*)))]/ln α (식 (21))를 쓰고, 2k* ≥ 1이면 j* ≤ ln(8k*)/ln α이므로

m ≤ [ln ln(N/P*) + A′]/ln α + 2,  A′ = ln(16/ln(1/Z)).  … 식 (22), (23)

A′ − A = ln 2, 즉 패리티보다 ln 2/ln α 비트만 더 든다 [원문]. 조건 N ≥ 2k(k−1)²는 N ≥ 2k*²(k*+1)이면 충분하다.

### 4.9 부록: 부분집합 행렬 구성 [원문 요약]

N×N 0/1 행렬(행 = 부분집합, 열 = 노드)에서 각 행·열에 1이 k개, 두 행의 공통 열 ≤ 1개가 목표. L = ⌈N/k⌉, N′ = Lk로 두고 N′×N′ 행렬을 k²개의 L×L 순열 행렬(permutation matrix) 블록으로 채운다(행·열 무게 k가 자동 보장). 새 블록을 채울 때 한 행에 금지되는 위치는 최대 (k−1)²개; N ≥ 2k(k−1)²이면 L ≥ 2(k−1)²이므로 각 행·열에 L/2 이상 허용 위치가 남는다. 허용 위치만 써서 순열 행렬을 만드는 데 탐욕적 배치 + 한 번의 교환(그림 3) 논법을 쓴다 (Gallager 1963 LDPC 부록 C, Hall 1967의 특수한 경우). 마지막으로 N′−N개 행·열을 지우면(각 행·열에서 1이 최대 하나 빠짐) 무게 k 또는 k−1이 된다. 대각 블록의 1로 노드–부분집합 일대일 배정을 얻는다. L이 소수이고 L = k이면 블록 (m,n)에 순환 이동 P_{(m−1)(n−1)}를 쓰는 대수적 구성도 있다.

[재구성] 이 행렬은 둘레(girth) 6 이상인 정규 LDPC 부호의 패리티 검사 행렬과 같은 조건이고, 4.8의 복호는 한 단계 다수결 논리 복호(majority-logic decoding)와 같다.

### 4.10 하계에 대해 알려진 것 [미확인: 기억/후속 문헌]

보고서 자체에는 하계 증명이 없다. 아래는 원문에서 확인한 것이 아니라 후속 문헌에 대한 기억이다.

- 자명한 하계: 각 노드의 상태가 결과에 영향을 주므로 노드마다 최소 1비트, 총 Ω(N). (보고서의 "ε^(Nm)" 논평은 P* 쪽 하계 직관이다.)
- Kushilevitz–Mansour(1998 전후, "Computation in noisy radio networks")는 OR·문턱(threshold) 함수류는 총 O(N) 전송으로 가능함을 보였다고 기억한다 [미확인].
- **Goyal–Kindler–Saks** ("Lower bounds for the noisy broadcast problem", FOCS 2005, SIAM J. Comput. 2008)는 이 잡음 방송 모형에서 **총 Ω(N log log N) 전송이 필요함**을 보여, Gallager의 O(N log log N) 방식이 차수상 최적임을 확인했다고 알려져 있다. 기억으로는 전체 상태 복원(identity) 문제에 대한 하계가 주 결과이고, 패리티에도 같은 차수의 하계가 따른다고 서술되어 있다. 증명은 "일반화된 잡음 결정 트리(generalized noisy decision tree)" 모형으로 환원한 뒤 하계를 보이는 방식이다. 정확한 정리 진술, 패리티 적용 여부, 비적응/적응 프로토콜 가정은 원문으로 확인해야 한다 [미확인].
- 따라서 "N개 1비트 값의 모듈로-2 합을 잡음 방송으로 계산하는 통신량"은 Θ(N log log N), 노드당 Θ(log log N)으로 정리되어 있다 [미확인, 후속 문헌 기준].

## 7. 본 연구와의 연결

본 연구 모형: K명의 작업자가 X_k ~ N(0,σ²)를 가지고 인코더 Q_k ∈ ℤ_M를 보내며, 스위치는 Z = ΣQ_k mod M (군 덧셈)만 계산해 내려보내고, 목표는 S = ΣX_k 추정. 하행 비트 log₂M ≥ ½log₂(K/D̄) − c (가설).

### 7.1 같은 점: 계산 대상이 군 합

Gallager의 패리티는 ℤ₂ 위의 합이고, 본 연구의 Z는 ℤ_M 위의 합이다. 둘 다 "개별 값이 아니라 합만 원할 때 통신량이 얼마나 줄어드는가"라는 함수 계산(function computation) 문제다. Gallager의 방식에서 부분집합 패리티 → 전체 패리티의 2단 구조는 본 연구의 트리 확장(랙 스위치 → 상위 스위치에서 부분합을 다시 더함)과 같은 모양이다.

### 7.2 다른 점: 무엇이 N(=K)에 따라 자라게 만드는가

| | Gallager (잡음 방송) | 본 연구 (무잡음 군 합 스위치) |
|---|---|---|
| 채널 | 수신자별 독립 BSC, 망 내부 계산 없음 | 상행 무잡음(현재 가정), 스위치가 군 합을 정확히 계산 |
| 원천 | 1비트 이산 상태, 무손실 목표 | 연속 가우시안, 평균제곱오차 왜곡 D̄ |
| 자라는 이유 | 잡음에 맞서 신뢰도를 유지하는 비용 | 합 S의 동적 범위(분산 Kσ²)가 커지는 비용 |
| 노드당 비트 | Θ(log log N) (후속 하계 포함, 4.10 [미확인]) | 가설: ½log₂(K/D̄) − c |

- 본 연구에서 정확한 ℤ_M 합 자체의 "계산 통신량"은 스위치가 공짜로 해 주므로 K에 무관하게 작업자당 log₂M 비트다. 즉 Gallager가 log log N을 낸 원인(잡음 + 망 내부 계산 부재)은 본 연구에 없다. 본 연구의 K 의존은 **원천 부호화(양자화) 쪽**에서 온다. 그러므로 두 결과는 "합 계산의 통신량이 N에 따라 자란다"는 같은 문장으로 묶이지만 성장 원인과 차수가 다르다(log log N 대 log K). 논문에서 이 둘을 같은 척도로 비교하지 않도록 주의한다.
- 오히려 Gallager는 "합만 계산하면 개별 복원(단순 반복의 ln N)보다 훨씬 싸다"는 고전적 선례로 인용하기 좋다. 본 연구에서 이에 대응하는 비교는 "개별 X_k 복원에 드는 율(작업자당 ½log(σ²/D_k))"과 "합만 복원할 때의 율"의 차이다.

### 7.3 상행 링크가 잡음일 때의 확장 (Gallager 기법의 직접 이식)

상행 작업자 → 스위치 링크가 잡음이면(예: 무선 공중 계산(over-the-air) 또는 비트 오류가 있는 링크) Gallager의 식 (2) 구조가 그대로 나타난다 [재구성].
- ℤ₂에서: K개 비트가 각각 확률 ε로 뒤집혀 합쳐지면 Z가 틀릴 확률은 [1 − (1−2ε)^K]/2 → 1/2 (K→∞). 즉 **망 내 합산은 잡음 오류를 누적**하므로 링크당 신뢰도는 K에 따라 올라가야 한다.
- ℤ_M 일반화: 링크 오류 e_k가 독립이고 특성함수가 φ_k(t) = E[e^(2πi t e_k/M)]이면 P(Σe_k ≡ 0 mod M) = (1/M) Σ_{t=0}^{M−1} Π_k φ_k(t). 대칭 오류(e_k가 0이 아닌 값에 균등, 확률 ε)라면 φ_k(t) = 1 − εM/(M−1) (t≠0)이므로 P(Z 정확) = 1/M + (1−1/M)(1 − εM/(M−1))^K. 식 (2)의 ℤ_M판이다.
- 단순 반복으로 막으면 링크당 반복 ~ ln K, Gallager식 부분집합 검사(여러 노드가 같은 부분합을 중복 추정)로 막으면 ~ ln ln K까지 줄일 여지가 있다. 단 본 연구의 스위치는 "더하기만" 하므로 Gallager의 다수결 단계(비선형)를 스위치가 할 수 없다. 다수결은 하행 이후 수신 측에서 해야 하고, 그러려면 같은 부분합을 서로 다른 군 원소 슬롯으로 여러 번 보내야 한다. 이 제약 하의 차수는 열린 문제로 둘 수 있다 [재구성, 제안].

### 7.4 다중 라운드·링·트리

- 다중 라운드: Gallager의 방식은 사실상 2라운드(상태 j번 → 부분집합 패리티 1번)다. 본 연구의 다중 라운드 확장에서 "첫 라운드 결과를 일부 노드가 재가공해 다시 보낸다"는 구조가 통신량 차수를 바꿀 수 있다는 예다.
- 트리: 부분집합 분할 = 2층 트리. Gallager가 추측한 "다층으로 쌓아도 점근이 좋아지지 않는다"(4.7)는, 본 연구의 트리 확장에서 계층을 늘려도 비트 하한 차수가 그대로일 것이라는 가설과 같은 방향의 고전적 언급으로 인용할 수 있다(단 추측임을 밝힌다). 상위 계층 추정들이 독립이 아니게 되는 문제는 본 연구에서도 트리 상위 스위치의 양자화 오차가 하위에서 상관된 형태로 들어오는 문제와 대응한다.
- 링: 방송 모형이 아니므로 직접 대응은 없다.

### 7.5 인용 방식 제안

서론/관련연구에서 "합(패리티) 계산의 통신 복잡도가 노드 수에 따라 어떻게 자라는가"의 고전 결과로: Gallager(상계 O(N log log N)) + Goyal–Kindler–Saks(하계 Ω(N log log N), 원문 확인 후). 본 연구는 잡음이 아니라 왜곡·동적 범위가 성장의 원인이며, 스위치가 정확한 군 합을 제공하는 모형이라는 차이를 한 문장으로 명시한다.
