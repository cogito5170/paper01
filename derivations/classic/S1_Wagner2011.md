## 2. 문제 설정 (원문 기호)

**소스.** (Y_1, Y_2)는 평균 0, 공분산
 K_y = [[1, ρ],[ρ, 1]], 0 ≤ ρ < 1
인 결합 가우시안. 시간축으로 i.i.d. 블록 Y_1^n, Y_2^n. (일반 가우시안은 이동·축척으로 이 경우로 환원; 한 성분이 다른 성분의 아핀 함수이면 자명.)

**부호.** 인코더 f_j^{(n)}: ℝ^n → {1, …, M_j}, j = 1, 2 (그림 1의 fork network: 인코더 간 통신 없음). 복호기는 선형 함수 a_1Y_1^n + a_2Y_2^n을 추정한다. a_1a_2 ≠ 0이면 정규화로
 Y_3^n := Y_1^n − cY_2^n, c ≠ 0
을 추정하는 문제가 된다. 복호기는 최적 추정기 E[Y_3^n | f_1^{(n)}(Y_1^n), f_2^{(n)}(Y_2^n)]를 쓴다고 가정해도 일반성을 잃지 않는다.

**정의 1 (달성 가능성).** (R_1, R_2, Δ)가 강한 의미로 달성 가능(strict-sense achievable)하다는 것은 어떤 n과 인코더 쌍이 있어
 (1/n)log M_j ≤ R_j (j=1,2), (1/n)Σ_{i=1}^n E[(Y_3^n(i) − E[Y_3^n(i) | f_1^{(n)}(Y_1^n), f_2^{(n)}(Y_2^n)])²] ≤ Δ
를 만족하는 것. 그 폐포가 율-왜곡 영역(rate-distortion region) 𝓡𝓓_⋆.

**범위 축소.**
- c ≤ 0 (즉 E[Y_1Y_2]·a_1a_2 ≥ 0, 원문 식 (2): 선형 결합의 부호가 상관의 부호와 맞음)이면 quantize-and-bin(양자화 후 비닝, 비구조 방식)의 영역 𝓡𝓓_QB가 최적: 𝓡𝓓_QB = 𝓡𝓓_⋆ (선행 연구 [13],[16],[17]).
- 따라서 c > 0만 남는다. Y_1 − cY_2를 추정하는 것은 Y_2 − Y_1/c를 추정하는 것과 같고(비례), 인코더 역할을 바꾸면 되므로 0 < c ≤ 1로 가정한다.
- σ_3² := Var(Y_3) = 1 + c² − 2ρc.

**정의 2 (비구조 영역).** 𝓡𝓓_QB := {(R_1,R_2,Δ): 결합 가우시안 (U_1,U_2)가 있어 U_1 ↔ Y_1 ↔ Y_2 ↔ U_2, I(Y_1;U_1|U_2) ≤ R_1, I(Y_2;U_2|U_1) ≤ R_2, I(Y_1,Y_2;U_1,U_2) ≤ R_1+R_2, E[(Y_3 − E[Y_3|U_1,U_2])²] ≤ Δ}.

**명제 1 (Berger–Tung 한계).** 𝓡𝓓_QB ⊆ 𝓡𝓓_⋆.

**최적 합 율.** 정리 2의 R(Δ)는 문맥상 R(Δ) = min{R_1+R_2 : (R_1,R_2,Δ) ∈ 𝓡𝓓_⋆}이다. 원문에서 이 기호의 명시적 정의 문장은 찾지 못했다. [미확인] R_QB(Δ), R_NL(Δ)는 각각 quantize-and-bin, 중첩 격자(cardinality-based) 방식의 합 율이다.

## 3. 주 정리 진술 (원문 대조함)

**격자 기초 상수 (II-C절).**
 σ_i² := ½ · Δσ_3²/(σ_3² − Δ), σ_o² := σ_3² + 2σ_i² + ε,
 V(Λ_o) = (2πeσ_o²)^{n/2} (5), (1/n)log(V(Λ_o)/V(Λ_i)) → ½log(σ_o²/σ_i²),
 두 격자는 Rogers good, 외부 격자는 잡음 분산 σ_3² + 2σ_i² + ε/2 (6)에 대해 지수적으로 좋은 채널 부호.

**명제 2 ([20] Krithivasan–Pradhan, cardinality-based scheme).**
 𝓡𝓓_NL = {(R_1, R_2, Δ): 2^{−2R_1} + 2^{−2R_2} ≤ Δ/(1 + c² − 2ρc)} (11)
은 중첩 격자로 달성 가능하다. [원문 82쪽 대조]

**보조정리 1.** 𝒳가 위수 p인 갈루아 체이고 X^k가 벡터 공간 𝒳^k의 확률 벡터이면, 모든 ε > 0에 대해 ℓ, m ∈ ℕ, A ∈ 𝒳^{ℓ×mk}, f: 𝒳^ℓ → 𝒳^{mk}가 있어
 Pr(f(A ·_p X^{mk}) ≠ X^{mk}) ≤ ε, ℓ/m ≤ H(X^k)/log p + ε.
(X^{mk}는 X^k의 m개 i.i.d. 복사본.) [원문 84쪽 대조]

**정리 1 (entropy-based scheme).** (G_{Λ_o}, p, G, u_1^n, u_2^n)를 왜곡 Δ를 달성하는 중첩 격자로서 G_{Λ_o}와 G가 최대 계수(full rank)인 것이라 하자. 그러면 (R, R, Δ)가 달성 가능하다. 여기서
 R = (1/n) H( Q_i(Y_1^n + u_1^n) − Q_i(cY_2^n + u_2^n) mod Λ_o ).
(각주: 이 율은 디더 실현값 u_1, u_2에 의존한다.) [원문 84쪽 대조]

**정리 2 (합 율 하한).** 모든 Δ에 대해
 R(Δ) ≥ max_K log⁺ (c²|K|/Δ²) (17) [원문 인쇄 그대로. 증명이 주는 것은 ½log⁺ — 6절 1번 참조]
최대화는 0 ⪯ K ⪯ K_y, μᵀKμ ≥ min(K(1,1), c²K(2,2)), μᵀ = [1 −c]인 모든 K에 대해. 특히
 Var(Y_3) ≥ c² (18)
이면
 R(Δ) ≥ ½ log⁺ (c²(1−ρ²)/Δ²) (19)
이고 quantize-and-bin의 합 율은 최적에서 1비트 이내:
 R_QB(Δ) − R(Δ) ≤ 1 (20), 모든 왜곡 Δ에 대해.
[원문 86쪽, 300 dpi 확대본으로 대조]

**정리 3 (외부 경계).** ρ ≤ α ≤ 1/ρ에 대해
 θ(α) = (1 − αρ) / (1 − αρ + c²(1 − ρ/α))
로 정의하고, 𝓡𝓓_o(α)를
 θ(α)·2^{−2R_1} + (1 − θ(α))·2^{−2R_2} ≤ Δ / (1 − αρ + c²(1 − ρ/α))
를 만족하는 (R_1, R_2, Δ)의 집합이라 하자. 그러면 𝓡𝓓_o := ∩_{ρ≤α≤1/ρ} 𝓡𝓓_o(α)는 외부 경계: 𝓡𝓓_⋆ ⊆ 𝓡𝓓_o. [원문 86–87쪽 대조]

**"1비트 이내" 진술의 정확한 형태 (원문 그대로의 범위).**
- (정리 2) 조건 (18) Var(Y_3) ≥ c² 아래에서, 합 율 기준으로 R_QB(Δ) − R(Δ) ≤ 1, 모든 Δ. 원문 해설: c ≤ 1/2이면 (18)이 항상 성립(가중치가 2배 이상 차이). (18) ⇔ 1 − 2ρc ≥ 0 ⇔ ρc ≤ ½이므로 c ≤ ½은 충분조건일 뿐이다.
- (V-A절, 정리 3의 따름) c = 1이고 α = 1로 두면 외부 경계는 {2^{−2(R_1+1/2)} + 2^{−2(R_2+1/2)} ≤ Δ/(2(1−ρ))}. (R_1,R_2,Δ)가 외부 경계 안이면 (R_1+½, R_2+½, Δ)는 𝓡𝓓_NL 안. 즉 **c = 1 (양의 상관 두 소스의 차)에서 중첩 격자 방식은 모든 왜곡에서 인코더당 ½비트, 합 1비트 이내**. 원문 표현: "within one bit of optimal at all distortion levels", III절 말미에 "half-bit-per-encoder penalty". 다른 매개변수에서는 알려진 내부·외부 경계의 격차가 무한일 수 있다고 원문이 명시한다(Maddah-Ali–Tse가 유계 격차 내부 경계를 얻었다고 언급).

**명제 3.** 고정 Δ에서 ℛ_o(Δ) = {(R_1,R_2): (R_1,R_2,Δ) ∈ 𝓡𝓓_o}, ℛ_CS(Δ)(컷셋)에 대해, 고정 ρ, c에서 충분히 작은 Δ면 ℛ_o(Δ)가 ℛ_CS(Δ)에 진부분집합으로 포함된다.

## 4. 유도

### 4.1 명제 2: cardinality-based 중첩 격자 방식 (Krithivasan–Pradhan) [원문 개요 + 재구성]

**부호화.** 인코더 1: Ỹ_1^n := Q_i(Y_1^n + u_1^n), 인코더 2: Ỹ_2^n := Q_i(cY_2^n + u_2^n) (Q_i는 내부 격자 Λ_i 최근접 양자화, u_j는 디더). 전송: S_j^n := Ỹ_j^n mod Λ_o. 율 R_1 = R_2 = (1/n)log(V(Λ_o)/V(Λ_i)) → ½log(σ_o²/σ_i²).

**복호.** Ŷ_3^n := ((σ_3²−Δ)/σ_3²)·[((S_1^n − S_2^n) − (u_1^n − u_2^n)) mod Λ_o] (8).

**분석 단계.**
1. mod의 분배 성질 (x mod Λ + y) mod Λ = (x + y) mod Λ로 Ŷ_3^n = ((σ_3²−Δ)/σ_3²)·[((Ỹ_1 − Ỹ_2) − (u_1 − u_2)) mod Λ_o] (9). 이것이 **스위치가 군 Λ_i/Λ_o에서 빼기만 하는 구조**다.
2. 디더 양자화 오차 E_j := (Y_j′ + u_j) mod Λ_i (Y_1′ = Y_1, Y_2′ = cY_2)로 쓰면 Ỹ_j − u_j = Y_j′ − E_j. 디더가 기본 보로노이 셀(Voronoi cell)에서 균등이면 E_j는 균등, 소스와 독립(crypto lemma). 따라서 (Ỹ_1 − Ỹ_2) − (u_1 − u_2) = Y_3^n + Z^n, Z^n = E_2 − E_1, 성분 분산 2σ_i² (σ_i² = 내부 격자 2차 모멘트). Rogers good이면 Z^n은 근사적으로 i.i.d. 가우시안 (10).
3. Y_3 + Z의 분산 σ_3² + 2σ_i². 외부 격자가 분산 σ_3² + 2σ_i² + ε/2 잡음에 좋은 채널 부호이므로 높은 확률로 [(Y_3 + Z) mod Λ_o] = Y_3 + Z.
4. LLSE 계수 σ_3²/(σ_3² + 2σ_i²). 2σ_i² = Δσ_3²/(σ_3²−Δ)를 넣으면 σ_3² + 2σ_i² = σ_3⁴/(σ_3²−Δ)이고 계수 = (σ_3²−Δ)/σ_3², MSE = σ_3²·2σ_i²/(σ_3²+2σ_i²) = Δ. [계산 재구성]
5. 율: σ_o²/σ_i² = σ_3²/σ_i² + 2 = 2(σ_3²−Δ)/Δ + 2 = 2σ_3²/Δ. 그래서 R = ½log(2σ_3²/Δ) (7). 무작위 디더로 평균 왜곡 Δ를 얻으므로 이를 달성하는 고정 디더가 존재.
6. **비대칭 일반화 → (11).** [재구성] 내부 격자를 Λ_{i1}, Λ_{i2} (2차 모멘트 σ_{i1}², σ_{i2}²), 공통 외부 격자 Λ_o ⊂ Λ_{i1} ∩ Λ_{i2}로 두면 잡음 N = σ_{i1}² + σ_{i2}², 왜곡 Δ 조건은 N = Δσ_3²/(σ_3²−Δ), σ_o² ≈ σ_3² + N = σ_3⁴/(σ_3²−Δ), R_j = ½log(σ_o²/σ_{ij}²). 그러면
 2^{−2R_1} + 2^{−2R_2} = (σ_{i1}² + σ_{i2}²)/σ_o² = N/σ_o² = Δ/σ_3².
 σ_{i1}², σ_{i2}² ≥ 0의 모든 분할을 훑으면 (11)의 경계 전체.
7. **K 인코더 일반화 (본 연구용).** [재구성] 같은 계산으로 Σ_{k=1}^K 2^{−2R_k} ≤ Δ/σ_S² (σ_S² = 목표의 분산). 원문은 "정리 1을 둘보다 많은 인코더로 일반화할 수 있다"고만 쓴다.

**약점.** Δ → σ_3²에서 합 율이 0이 아니라 1로 간다(각 R → ½). 원문은 이것을 저율 "간극(gap)"이라 부르고 정리 1이 이 간극을 닫는다고 주장한다.

### 4.2 보조정리 1 (유한 벡터 공간 소스의 선형 압축) [원문 부록 B]

1. δ > 0과 유리수 r을 H(X^k) + δ < r log p ≤ H(X^k) + ε log p가 되게 잡는다.
2. ℓ/m = r이고 2^{−m(r log p − H(X^k) − δ)} + Pr(−(1/m)log p(X^{mk}) ≥ H(X^k) + δ) ≤ ε (21)이 되는 ℓ, m을 잡는다(약한 AEP로 둘째 항 → 0).
3. A의 성분을 i.i.d. 균등 𝒳에서 뽑고, f는 x^ℓ에 대해 A로 x^ℓ에 사상되는 최대우도(maximum-likelihood) 소스열을 낸다.
4. Pr(f(A X^{mk}) ≠ X^{mk}) ≤ Σ_{x: p(x) ≥ 2^{−m(H+δ)}} p(x)·Pr(f(Ax) ≠ x) + Pr(−(1/m)log p(X^{mk}) ≥ H + δ).
5. ML 정의와 합집합 한계: Pr(f(Ax) ≠ x) ≤ Σ_{x̃: p(x̃) ≥ 2^{−m(H+δ)}} Pr(Ax = Ax̃). (ML이 x를 놓치려면 확률이 x 이상인, 따라서 2^{−m(H+δ)} 이상인 x̃가 같은 신드롬을 가져야 함.)
6. 성분 i.i.d. 균등이므로 x ≠ x̃에서 Pr(A(x −_p x̃) = 0) = 1/p^ℓ (체 구조).
7. |{x̃: p(x̃) ≥ 2^{−m(H+δ)}}| ≤ 2^{m(H+δ)}이므로 Pr ≤ p^{−ℓ}2^{m(H+δ)} + Pr(…) = 2^{−m(r log p − H − δ)} + Pr(…) ≤ ε. (21)로 결론. ∎

### 4.3 정리 1: 격자 + 선형 비닝 (entropy-based scheme)

**(가) 동기 [원문 III절].** 중앙 인코더라면 Ỹ_1^n − Ỹ_2^n mod Λ_o를 율 (1/n)H(Ỹ_1 − Ỹ_2 mod Λ_o) (12)로 보낼 수 있다. cardinality-based 방식은 중첩비의 로그(log of nesting ratio)를 쓰는데, 기수 한계에 의해 (12)는 그 이하이고 엄격히 작을 수 있다. 고왜곡 영역(σ_i² 큼)에서 중첩비 로그 ≈ ½log((1+c²−2ρc+2σ_i²)/σ_i²) → ½인 반면 (13)–(14)에 의해
 (1/n)H(Ỹ_1 − Ỹ_2 mod Λ_o) ≤ (1/n)H(Ỹ_1) + (1/n)H(Ỹ_2), (1/n)H(Ỹ_j) ≈ ½log((1+σ_i²)/σ_i²) → 0
(ECDQ 분석, Zamir–Feder). 즉 양자화가 Ỹ_1 − Ỹ_2 mod Λ_o를 균등하게 만들지 않으므로 엔트로피 부호화로 아낄 여지가 있다.

**(나) 중첩 격자 앙상블의 대수 구조 [원문].**
- G_{Λ_o}: 부피 (5), Rogers good, (6)에 대해 지수적으로 좋은 채널 부호, 가역. Λ_o = G_{Λ_o}·ℤ^n.
- k = ⌈(log n)²⌉, p는 (σ_o²/σ_i²)^{n/(2k)}에 가장 가까운 소수. n×k 생성 행렬 G의 성분 i.i.d. 균등 ℤ_p.
- Λ_i = {λ ∈ ℝ^n: λ = G_{Λ_o}(p^{−1}(G ·_p x^k) + z^n), x^k ∈ ℤ_p^k, z^n ∈ ℤ^n}.
- G_{Λ_o}, G가 최대 계수이면 Λ_i의 각 점 λ에 유일한 (x^k(λ), z^n(λ))가 대응.

**(다) 핵심 보조 사실: λ ↦ x^k(λ)는 Λ_i → ℤ_p^k 군 준동형이고 핵(kernel)이 Λ_o다.** [원문은 "x^k(λ) = x^k(λ̂)이면 λ − λ̂ ∈ Λ_o"만 적음 → 준동형 부분 재구성]
 λ_1 − λ_2 = G_{Λ_o}(p^{−1}(G ·_p x_1 − G ·_p x_2) + z_1 − z_2). 정수 벡터로 G ·_p x_1 − G ·_p x_2 = G ·_p (x_1 −_p x_2) + p·w (w ∈ ℤ^n). 따라서 λ_1 − λ_2 = G_{Λ_o}(p^{−1}(G ·_p (x_1 −_p x_2)) + (z_1 − z_2 + w)). 유일성에서 x^k(λ_1 − λ_2) = x_1 −_p x_2. 핵: x^k(λ) = 0 ⇔ λ = G_{Λ_o}z ∈ Λ_o. 그러므로 Λ_i/Λ_o ≅ ℤ_p^k이고, λ mod Λ_o는 x^k(λ)로 계산된다.

**(라) 정리 1 증명 [원문 부록 C].**
1. X_j^k := x^k(Ỹ_j^n), j = 1,2, X_−^k := x^k(Ỹ_1^n − Ỹ_2^n) = X_1^k −_p X_2^k ((다)).
2. 외부 블록 m개(블록당 n 샘플)에 걸쳐 보조정리 1의 A를 X_−^{mk}에 대해 고른다. 인코더 j는 A ·_p X_j^{mk}를 보낸다.
3. 복호기: A ·_p X_1^{mk} −_p A ·_p X_2^{mk} = A ·_p (X_1^{mk} −_p X_2^{mk}) = A ·_p X_−^{mk} (선형성). X̂_−^{mk} = f(A ·_p X_−^{mk}). (스위치의 군 연산 = ℤ_p^ℓ에서의 뺄셈.)
4. 율: 인코더당 ℓ log p/(mn) ≤ (1/n)H(X_−^k) + (ε/n)log p ≤ R + (ε/n)log p. 그리고 x^k(·)는 Λ_i/Λ_o의 동형이므로 H(X_−^k) = H(Ỹ_1 − Ỹ_2 mod Λ_o) = nR.
5. 왜곡: 오류 사건 E = {f(A ·_p X_−^{mk}) ≠ X_−^{mk}}, Pr(E) ≤ ε. E^c에서 Ŷ_3^n = ((σ_3²−Δ)/σ_3²)·([G_{Λ_o}p^{−1}(G ·_p X_−^k) − (u_1−u_2)] mod Λ_o) = ((σ_3²−Δ)/σ_3²)·([Ỹ_1 − Ỹ_2 − (u_1−u_2)] mod Λ_o), 즉 [20]의 추정기 (9)와 동일. 따라서
 (1/n)E‖Y_3^n − Ŷ_3^n‖² = (1/n)E[‖·‖²1_E] + (1/n)E[‖·‖²1_{E^c}] ≤ (1/n)√(E‖Y_3^n − Ŷ_3^n‖⁴)·√ε + Δ (슈바르츠 부등식, 둘째 항은 Def. 3에 의해 ≤ Δ).
 Y_3^n은 i.i.d. 가우시안이고 Ŷ_3^n은 유계(mod Λ_o의 값)이므로 4차 모멘트는 ε에 무관한 상수로 유계. ε → 0. ∎

**(마) 원문이 밝힌 한계.** 정리 1의 R은 해석적으로 계산하기 어렵고(ECDQ 분석에 맞지 않음, 각주 5), 정리 1이 cardinality-based와 QB의 시분할 바깥의 점을 달성한다는 것은 증명되지 않았다("그럴 것 같다"). 개선이 없는 경우: Ỹ_1 − cỸ_2가 Ỹ_1과 독립일 때(σ_i² ≈ 0, c ≈ 1, ρ ≈ 1). 이 영역에서 (15)–(16)의 ECDQ 계산으로 Δ = θσ_3² = 2θ(1−ρ)이면 (1/n)H ≈ ½log(((1+ρ) − 2ρθ)/(θ(1−ρθ))) → ½log(2/θ) (ρ→1), 중첩비 로그도 → ½log(2/θ)이므로 Ỹ_1 − Ỹ_2 mod Λ_o는 균등하고 개선 없음. 원문 해석: 이것이 "Y_1 ⊕ Y_2가 Y_1, Y_2 각각과 독립"인 원래 KM 설정의 가우시안 유비라서 순진한 KM 적용이 잘 통한다.

### 4.4 정리 2: 합 율 하한 [원문 부록 D, 단계별 근거]

(R_1, R_2, Δ)가 강한 의미로 달성 가능하고 (f_1, f_2)가 그 부호라 하자. C_j = f_j^{(n)}(Y_j^n).

**경우 I: μᵀKμ ≥ c²K(2,2).**

0. 0 ⪯ K ⪯ K_y이므로 Cov(Y_1,Y_2|X) = K인 결합 가우시안 X가 있다. [근거 보충: Y = X′ + N, N ~ 𝒩(0,K), X′ ~ 𝒩(0, K_y − K) 독립, X = X′.] 각 샘플마다 X의 i.i.d. 복사본을 붙여 X^n을 만든다(정보 주입 변수(genie)).

1. (22)–(23): E[Y_3^n | X^n, C_1, C_2]는 (X^n, C_1, Y_2^n)의 함수(C_2 = f_2(Y_2^n))이므로
 h(Y_3^n|X^n,C_1,Y_2^n) = h(Y_3^n|X^n,C_1,Y_2^n, E[Y_3^n|X^n,C_1,C_2]) (조건에 있는 변수들의 함수를 추가해도 엔트로피 불변)
  ≤ h(Y_3^n | E[Y_3^n|X^n,C_1,C_2]) (조건을 줄이면 엔트로피가 늘거나 같음)
  ≤ Σ_i h(Y_3^n(i) | E[Y_3^n(i)|X^n,C_1,C_2]) (연쇄 법칙 후 각 항에서 조건 축소)
  ≤ Σ_i ½log(2πeε_i), ε_i := E[(Y_3^n(i) − E[Y_3^n(i)|X^n,C_1,C_2])²] (주어진 MSE에서 가우시안이 엔트로피 최대, Cover–Thomas Thm 8.6.5)
  ≤ (n/2)log(2πe·(1/n)Σε_i) (log의 오목성, 옌센)
  ≤ (n/2)log(2πeΔ) (X^n을 더 주면 MSE가 줄 뿐: (1/n)Σε_i ≤ Δ).
 Y_3 = Y_1 − cY_2이고 Y_2^n이 조건에 있으므로 평행 이동 불변성으로 h(Y_1^n|X^n,C_1,Y_2^n) ≤ (n/2)log(2πeΔ) (24).

2. (25): nR_1 ≥ H(C_1) ≥ H(C_1|X^n) ≥ I(Y_1^n;C_1|X^n) ≥ I(Y_1^n;C_1|X^n) + h(Y_1^n|X^n,C_1,Y_2^n) − (n/2)log(2πeΔ). (마지막은 (24)를 더하고 뺌.)

3. (26): Y_2^n ↔ (Y_1^n, X^n) ↔ C_1이므로 연쇄 법칙으로 I(Y_1^n;C_1|X^n) = I(Y_1^n,Y_2^n;C_1|X^n) = I(Y_2^n;C_1|X^n) + I(Y_1^n;C_1|X^n,Y_2^n). 따라서 h(Y_1^n|X^n,Y_2^n) − h(Y_1^n|X^n,C_1,Y_2^n) = I(Y_1^n;C_1|X^n) − I(Y_2^n;C_1|X^n).

4. (27): (26)을 (25)에 넣으면 nR_1 ≥ I(Y_2^n;C_1|X^n) + h(Y_1^n|X^n,Y_2^n) − (n/2)log(2πeΔ) = h(Y_1^n,Y_2^n|X^n) − h(Y_2^n|X^n,C_1) − (n/2)log(2πeΔ).

5. (28): nR_2 ≥ H(C_2) ≥ H(C_2|X^n,C_1) ≥ I(Y_3^n;C_2|X^n,C_1) ≥ h(Y_3^n|X^n,C_1) − h(Y_3^n|X^n,C_1,C_2).

6. (29): 1과 같은 계산으로 h(Y_3^n|X^n,C_1,C_2) ≤ (n/2)log(2πeΔ).

7. (30): μᵀKμ ≥ c²K(2,2)는 Var(Y_3|X) ≥ Var(cY_2|X), 즉 h(Y_3|X) ≥ h(cY_2|X). h(Y_3|Y_1,X) = h(cY_2|Y_1,X)이므로 I(Y_1;Y_3|X) ≥ I(Y_1;cY_2|X) = I(Y_1;Y_2|X).

8. **열화(degradedness) 단계.** X의 각 실현값에서 (Y_1,Y_2,Y_3)는 가우시안이므로, (30)은 조건부 채널 Y_1 → Y_2가 Y_1 → Y_3에 대해 확률적으로 열화(stochastically degraded)되어 있음을 뜻한다(스칼라 가우시안 채널은 SNR로 완전 순서화). Y_3^n ↔ (Y_1^n,X^n) ↔ C_1, Y_2^n ↔ (Y_1^n,X^n) ↔ C_1이므로 C_1을 조건으로 주면 이 "채널"들의 입력 분포만 바뀐다. 무기억 열화 채널에서는 임의 입력 분포에서 상호정보 순서가 유지되므로
 I(Y_1^n;Y_3^n|X^n,C_1) ≥ I(Y_1^n;Y_2^n|X^n,C_1).
 양변에서 h(Y_3^n|Y_1^n,X^n,C_1) = h(cY_2^n|Y_1^n,X^n)를 이용해 정리하면 h(Y_3^n|X^n,C_1) ≥ h(cY_2^n|X^n,C_1).

9. 8과 (29)를 (28)에 넣으면 nR_2 ≥ h(cY_2^n|X^n,C_1) − (n/2)log(2πeΔ) = h(Y_2^n|X^n,C_1) − (n/2)log(2πeΔ/c²) (축척 h(cY) = h(Y) + n log c).

10. (27)과 더하면 h(Y_2^n|X^n,C_1)이 소거되어
 n(R_1+R_2) ≥ h(Y_1^n,Y_2^n|X^n) − n log(2πeΔ/c) = (n/2)log((2πe)²|K|) − (n/2)log((2πeΔ)²/c²) = (n/2)log(c²|K|/Δ²).

**경우 II: μᵀKμ ≥ K(1,1).** 인코더 역할을 바꿔 같은 단계: h(cY_2^n|X^n,C_2,Y_1^n) ≤ (n/2)log(2πeΔ); nR_2 ≥ h(Y_1^n,cY_2^n|X^n) − h(Y_1^n|X^n,C_2) − (n/2)log(2πeΔ) (32); nR_1 ≥ h(Y_3^n|X^n,C_2) − (n/2)log(2πeΔ) (33); μᵀKμ ≥ K(1,1)이면 h(Y_3|X) ≥ h(Y_1|X), 채널 Y_2 → Y_1이 Y_2 → Y_3에 대해 열화, h(Y_3^n|X^n,C_2) ≥ h(Y_1^n|X^n,C_2). 합치면 R_1 + R_2 ≥ ½log(c²|K|/Δ²) (h(Y_1,cY_2|X) = h(Y_1,Y_2|X) + n log c 사용).

**결론과 연속성.** 두 경우를 합치면 강한 의미로 달성 가능한 점에서 R_1+R_2 ≥ ½log(c²|K|/Δ²), 율은 음이 아니므로 ½log⁺. 연속성 논증으로 폐포 𝓡𝓓_⋆로 확장. K에 대해 최대화.

**(19).** (18) Var(Y_3) = μᵀK_yμ ≥ c² ≥ min(1, c²) = min(K_y(1,1), c²K_y(2,2))이므로 K = K_y가 허용되고 |K_y| = 1 − ρ²: R(Δ) ≥ ½log⁺(c²(1−ρ²)/Δ²).

**(20) R_QB − R ≤ 1.** [원문] [33, App. A]의 QB 합 율
 R_QB(Δ) = ½log(4c((1−ρ²)c − ρΔ)/Δ²) (Δ ≤ 2(1−ρ²)c²/(1+ρc)), ½log((1−ρc)²/(Δ − (1−ρ²)c²)) (그 밖).
(이 QB 합 율 식 자체는 원문에서 유도하지 않고 인용한다. [미확인])
- 첫 구간: R_QB − R ≤ ½log(4c((1−ρ²)c−ρΔ)/Δ²) − ½log(c²(1−ρ²)/Δ²) = ½log(4((1−ρ²)c − ρΔ)/(c(1−ρ²))) ≤ ½log 4 = 1 (ρΔ ≥ 0).
- 둘째 구간: 협력 하한 R(Δ) ≥ ½log((1−2ρc+c²)/Δ)를 쓴다. 보일 것 ½log((1−ρc)²/(Δ−(1−ρ²)c²)) − ½log((1−2ρc+c²)/Δ) ≤ 1, 직접 계산으로 동치인
 4(1−ρ²)c²(1−2ρc+c²) ≤ Δ[4(1−2ρc+c²) − (1−ρc)²] (34).
 우변 괄호 ≥ 0 ⇔ 3 + 4c² ≥ 6ρc + ρ²c² (35); (18)에서 ρc ≤ ½이므로 6ρc + ρ²c² ≤ 3 + c² ≤ 3 + 4c². 우변이 Δ에 대해 증가하므로 구간 경계 Δ = 2(1−ρ²)c²/(1+ρc)에서만 확인하면 되고, 대입·정리하면 2ρc(1−2ρc+c²) ≤ (1−2ρc+c²) + c²(1−ρ²)와 동치. cρ ≤ ½이면 2ρc(1−2ρc+c²) ≤ 1−2ρc+c²로 성립. ∎

### 4.5 정리 3: 외부 경계 [원문 부록 E]

ρ ≤ α ≤ 1/ρ를 고정.

0. **조건부 독립을 만드는 정보 주입 변수.** Y_1 = √(αρ)·X + Z_1, Y_2 = √(ρ/α)·X + Z_2, X, Z_1, Z_2 독립 가우시안, σ_X² = 1, σ_1² = 1 − αρ, σ_2² = 1 − ρ/α. [검산: Var Y_1 = αρ + 1 − αρ = 1, Var Y_2 = 1, Cov = √(αρ)√(ρ/α) = ρ. σ_1², σ_2² ≥ 0 ⇔ ρ ≤ α ≤ 1/ρ.] X^n을 붙인다. 이제 Y_1 ⊥ Y_2 | X.

1. **개별 율.**
 nR_1 ≥ H(C_1) ≥ H(C_1|X^n) = I(Y_1^n;C_1|X^n) = I(Z_1^n;C_1|X^n) (X^n이 주어지면 Y_1^n ↔ Z_1^n 일대일)
  = Σ_i I(Z_1(i);C_1|X^n,Z_1^{i−1}) = Σ_i [h(Z_1(i)) − h(Z_1(i)|C_1,X^n,Z_1^{i−1})] (Z_1(i) ⊥ (X^n, Z_1^{i−1}))
  ≥ Σ_i [h(Z_1(i)) − h(Z_1(i)|C_1,X^n)] = Σ_i I(Z_1(i);C_1,X^n)
  ≥ Σ_i ½log(σ_1²/Δ_1(i)) (점대점 가우시안 율-왜곡; 가우시안 최대 엔트로피),
 Δ_1(i) := E[(Z_1(i) − E[Z_1(i)|C_1,X^n])²] = E[(Y_1(i) − E[Y_1(i)|C_1,X^n])²]. Δ_1 = (1/n)ΣΔ_1(i), 오목성으로
 R_1 ≥ ½log(σ_1²/Δ_1) (36), R_2 ≥ ½log(σ_2²/Δ_2) (37) (Δ_2는 Y_2(i)를 (C_2,X^n)로 추정한 MSE).

2. **왜곡 분해.** 마르코프 조건 C_1 ↔ Y_1^n ↔ X^n ↔ Y_2^n ↔ C_2 (38). X^n이 주어지면 (Y_1^n,C_1) ⊥ (Y_2^n,C_2)이므로 교차항
 2c·E[(Y_1(i) − E[Y_1(i)|X^n,C_1])(Y_2(i) − E[Y_2(i)|X^n,C_2])|X^n] = 2c·E[Y_1(i) − E[Y_1(i)|X^n,C_1]|X^n]·E[…|X^n] = 0
(반복 기댓값으로 첫 인수 = 0). 따라서 평균하면
 (1/n)ΣE[(Y_3(i) − E[Y_1(i)|X^n,C_1] + cE[Y_2(i)|X^n,C_2])²] = Δ_1 + c²Δ_2 (39).

3. (38)에서 E[Y_1(i)|X^n,C_1,C_2] = E[Y_1(i)|X^n,C_1], E[Y_2(i)|X^n,C_1,C_2] = E[Y_2(i)|X^n,C_2]. 그래서 (39)의 추정기는 E[Y_3(i)|X^n,C_1,C_2]이고
 Δ_1 + c²Δ_2 = (1/n)ΣE[(Y_3(i) − E[Y_3(i)|X^n,C_1,C_2])²] ≤ (1/n)ΣE[(Y_3(i) − E[Y_3(i)|C_1,C_2])²] ≤ Δ
 (조건부 기댓값이 MSE 최소; X^n을 빼면 MSE 증가).

4. (36), (37)을 넣으면 σ_1²·2^{−2R_1} + c²σ_2²·2^{−2R_2} ≤ Δ. 양변을 σ_1² + c²σ_2² = 1 − αρ + c²(1 − ρ/α)로 나누면 σ_1²/(…) = θ(α), c²σ_2²/(…) = 1 − θ(α):
 θ(α)2^{−2R_1} + (1−θ(α))2^{−2R_2} ≤ Δ/(1 − αρ + c²(1 − ρ/α)).
 연속성으로 폐포에 확장, α가 임의이므로 교집합. ∎

### 4.6 명제 3 [원문 부록 F]

α = ρ: θ = 1이므로 R_1 ≥ ½log((1−ρ²)/Δ). α = 1/ρ: θ = 0이므로 R_2 ≥ ½log(c²(1−ρ²)/Δ). α = 1: θ(1) = 1/(1+c²), 경계는 2^{−2R_1} + c²2^{−2R_2} ≤ Δ/(1−ρ), 산술–기하 평균으로 2c·2^{−(R_1+R_2)} ≤ Δ/(1−ρ), 즉 R_1 + R_2 ≥ log(2c(1−ρ)/Δ). 이것은 작은 Δ에서 ½log((1−2ρc+c²)/Δ)를 넘으므로 ℛ_o(Δ) ⊆ ℛ_CS(Δ), 그리고 작은 Δ에서 log(2c(1−ρ)/Δ) > max(½log((1−2ρc+c²)/Δ), ½log((1−ρ²)/Δ) + ½log(c²(1−ρ²)/Δ))이므로 엄격 포함. (괄호 안 둘째 항은 log(1/Δ)급이라 "모든 작은 Δ"에서의 엄격 부등식은 상수 비교 2c(1−ρ) > c(1−ρ²) ⇔ 2 > 1+ρ로 성립. [재구성 검산])

## 5. 예제 (가우시안 닫힌 식)

**(가) c = 1, ρ = 0 (독립 소스의 차 = 합과 동치).** σ_3² = 2.
- 참 최적: 정리 3에서 α = 1이면 θ = ½, 경계 ½2^{−2R_1} + ½2^{−2R_2} ≤ Δ/2, 즉 2^{−2R_1} + 2^{−2R_2} ≤ Δ. 각자 독립 부호화(Δ = Δ_1 + Δ_2, R_j = ½log(1/Δ_j))가 이를 달성하므로 **ρ = 0에서는 정리 3이 정확한 영역**이다. 이것은 c ≤ 0 경우가 아니지만 ρ = 0이면 조건 (2) E[Y_1Y_2]a_1a_2 = 0 ≥ 0이 성립하므로 QB 최적과도 일치.
- 격자(명제 2): 2^{−2R_1} + 2^{−2R_2} ≤ Δ/2.
- 대칭 율: 최적 R = ½log(2/Δ), 격자 R = ½log(4/Δ). **격차 정확히 인코더당 ½비트, 합 1비트.** V-A절의 "1비트 이내"가 ρ = 0에서 등호로 달성(즉 그 상수는 개선 불가)된다는 것을 보여 준다.
- 정리 2: Var(Y_3) = 2 ≥ 1 = c²이므로 (19): R(Δ) ≥ ½log(1/Δ²) = log(1/Δ). 참 최적 합 율 log(2/Δ)와 1비트 차.
- R_QB 검산: Δ ≤ 2이면 R_QB = ½log(4·1·1/Δ²) = log(2/Δ) = 참 최적.

**(나) c = 1, ρ → 1 (KM 유비).** Δ = 2θ(1−ρ)로 두면 격자 R_NL 합 = 2·½log(2σ_3²/Δ) = log(2/θ), QB 합 = ½log(4/(1−ρ))급으로 발산(원문: Δ = 1−ρ, c = 1에서 R_NL = log 4 = 2, R_QB = ½log(4/(1−ρ)) → ∞). 외부 경계 합 율 ≥ log(2(1−ρ)/Δ) = log(1/θ). 격자는 외부 경계와 1비트 차, QB는 무한히 나쁨.

**(다) c = 1, ρ = Δ = 0.1 (원문 그림 6).** 외부 경계: 2^{−2R_1} + 2^{−2R_2} ≤ 0.1/0.9 = 1/9; 격자: ≤ 1/18. 대칭 외부 경계 R ≥ ½log 18 ≈ 2.08, 격자 R = ½log 36 ≈ 2.58.

## 6. 원문과의 차이·빈틈

1. **(17)의 ½ 누락 (인쇄 오류로 판단).** 정리 2 본문 (17)은 R(Δ) ≥ max_K log⁺(c²|K|/Δ²)로 인쇄되어 있으나(300 dpi 확대로 확인), 부록 D의 결론은 R_1 + R_2 ≥ ½log(c²|K|/Δ²)이고 특수형 (19)도 ½을 갖는다. 증명된 것은 ½log⁺ 쪽이다. 인용 시 ½을 붙여야 한다.
2. **R(Δ)의 정의 문장 부재.** 문맥상 최적 합 율. [미확인]
3. **명제 2의 근사 논증.** "Z^n이 근사적으로 가우시안"(10)과 "외부 격자가 그 잡음에 좋은 채널 부호" 단계는 원문에서 근사(≈)로만 서술된다. 엄밀한 처리는 Krithivasan–Pradhan [33]과 Erez–Zamir의 혼합 잡음(가우시안 + 균등 디더) 논증에 맡긴다. [미확인: [33]의 해당 증명을 직접 대조하지 않음]
4. **정리 1의 율은 계산 불가.** 원문 스스로 entropy-based 방식이 시분할 영역 밖의 점을 달성하는지 해석적으로 보이지 못한다. 그림 4는 스칼라 양자화 수치 계산.
5. **열화 단계 (정리 2, 단계 8).** "조건부 채널이 열화되어 있으면 C_1을 조건으로 주어도 n-문자 상호정보 순서가 보존된다"는 원문에서 한 문장. 엄밀하게는 X^n의 각 실현값에서 Y_2^n = (열화 채널)(Y_3^n)이 되는 결합(coupling)을 만들고, C_1이 (Y_1^n, X^n)만의 함수라는 사실로 데이터 처리 부등식을 쓰는 단계다. 결합을 만들 때 Y_2를 Y_3의 잡음판으로 실제 표현하는 것이 아니라 h(Y_3^n|X^n,C_1)과 h(cY_2^n|X^n,C_1)만 비교하므로 확률적 열화로 충분하다. [재구성 설명]
6. **R_QB 식 미유도.** [33, App. A] 인용. [미확인]
7. **정리 2·3의 상수.** 둘 다 "인코더당 ½비트" 규모 상수의 격차이고, 5(가)에서 보였듯 ρ = 0에서 격자 대비 격차는 정확히 ½비트/인코더로 등호. 반면 정리 2의 하한(19)도 ρ = 0에서 1비트 느슨하다. 후속 문헌(Maddah-Ali–Tse의 interference nulling, 원문 [44])은 유계 격차 내부 경계를 준다고 원문이 언급한다. 그 이후 정확한 영역이 풀렸는지는 확인하지 않았다. [미확인]
8. **다인코더 확장.** 원문은 "둘보다 많은 인코더로 일반화할 수 있다"고만 쓰고 진술·증명이 없다. 4.1의 7번 K 인코더 식은 [재구성].

## 7. 본 연구와의 연결

본 연구 모형: K명 작업자 X_k ~ N(0, σ²) 독립, Q_k = f_k(X_k, W) ∈ ℤ_M, 스위치 Z = ΣQ_k mod M, 복호기 Ŝ = g(Z, W)로 S = ΣX_k 추정. 정리 A(가설): log₂M ≥ ½log₂(K/D̄) − c, D̄ = E(S−Ŝ)²/(Kσ²). 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½log₂K − c. K=2 달성: Krithivasan–Pradhan 2^{−2R_1} + 2^{−2R_2} ≤ D/σ_S².

1. **본 연구의 설정은 Wagner 문제의 "쉬운 쪽"이다 — 비제약 최적은 구조 없이 달성된다.** 본 연구는 ρ = 0, c = 1(합과 차가 동치)에 해당한다. ρ = 0이면 조건 (2)가 성립해 QB(비구조)가 최적이고, 5(가)에서 보였듯 정리 3이 정확한 영역 2^{−2R_1} + 2^{−2R_2} ≤ Δ를 준다. 따라서 **본 연구 설정에서 선형/격자 부호의 "이득"은 0이다.** SURVEY가 S1을 "가우시안 합 함수 + 구조적 부호 이득"으로 묶은 것은 본 연구 설정에 대해서는 맞지 않는다. Wagner의 격자 이득은 차를 원하고 상관이 강한(ρ → 1) 경우의 것이다.

2. **스위치 제약을 만족하는 방식은 정확히 ½log₂K만큼 진다 (K=2에서 원문 식으로 확인).** cardinality-based(명제 2)와 entropy-based(정리 1) 방식은 둘 다 스위치가 군(Λ_i/Λ_o ≅ ℤ_p^k, 또는 ℤ_p^ℓ)에서 빼기만 한다. 반면 QB는 개별 양자화값을 결합 복호해야 하므로 제약 밖이다. ρ = 0, c = 1에서 격자 R = ½log(4/Δ), 최적 R = ½log(2/Δ). 본 연구 정규화(σ² = 1, K = 2, D̄ = Δ/2)로 옮기면 격자 = ½log₂(K/D̄), 비제약 최적 = ½log₂(1/D̄). 격차 = ½log₂K. **정리 A의 c = 0 판이 K = 2 격자로 정확히 달성되고, 제약 없는 하한과의 차이가 정확히 가설의 ½log₂K다.** 4.1의 7번 K 인코더 식으로 대칭이면 K·2^{−2R} = D/(Kσ²), R = ½log₂(K²σ²/D) = ½log₂(K/D̄)로 일반 K에서도 같다. 비교: 업링크만 보는 비제약 하한은 독립 소스에서 MMSE가 분해되어(E[X_k|C_1..C_K] = E[X_k|C_k]) D ≥ ΣD_k, R_k ≥ ½log(σ²/D_k)이므로 대칭에서 ½log₂(1/D̄)다. [재구성]

3. **½log₂K는 H(Z|S,W)에서 온다 — 격자 방식에서의 계산 (보조정리 L이 격자에서 등호).** [재구성, 발견적 근사] 정리 1의 율은 정확히 (1/n)H(Z), Z = Ỹ_1 − Ỹ_2 mod Λ_o (본 연구의 스위치 출력). 원문 (10)의 근사(Z ≈ Y_3 + N, N 분산 2σ_i² 가우시안, 고해상도)로 분해하면
 - I(Y_3; Z)/n ≈ ½log((σ_3² + 2σ_i²)/(2σ_i²)) (복호기에 실제로 쓸모 있는 정보, ≈ R_S(D)),
 - H(Z|Y_3)/n ≈ h(N)/n − (1/n)log V(Λ_i) ≈ ½log(2πe·2σ_i²) − ½log(2πeσ_i²) = ½log 2 (Rogers good: V(Λ_i)^{2/n} ≈ 2πeσ_i²),
 - 합 = ½log((σ_3²+2σ_i²)/σ_i²) = 중첩비 로그.
 즉 H(Z|S)/n ≈ ½log₂K (K = 2)이고 이것이 정확히 원문 4.3(마)의 "균등, 개선 없음" 상황이다. 일반 K에서 디더 오차 E_k가 i.i.d.이면 h(ΣE_k) − h(E_1) ≥ ½log K (엔트로피 거듭제곱 부등식(EPI), 가우시안에서 등호)이므로 **보조정리 L의 증명 경로 후보: H(Z|S,W) ≈ h(ΣE_k) − log(셀 부피) ≥ h(E_1) + ½log K − log(셀 부피)**. 남은 과제: (i) 비디더·비격자 일반 인코더 f_k, (ii) mod M 감김, (iii) h(E_1) − log(셀 부피)의 하한(양자화 셀이 작다는 것과 왜곡 D의 연결). (추정)

4. **왜 실수 가우시안 합에서는 KM처럼 대가를 피하지 못하는가 (원문이 주는 단서).** 원문 4.3(마)는 Ỹ_1 − Ỹ_2 mod Λ_o가 균등(엔트로피 부호화 이득 없음)이 되는 조건이 "Ỹ_1 − cỸ_2가 Ỹ_1과 독립"이고, 이것이 KM의 "Y_1 ⊕ Y_2가 Y_1과 독립"의 유비라고 한다. 그런데 KM에서는 그 상황에서도 손해가 없다(H(Z_KM|목표) = 0). 가우시안에서는 같은 상황에서 정리 3과 격자가 정확히 ½비트/인코더 차이 난다(5(가)). 차이의 원천은 **목표(실수 합)와 스위치 출력(양자화값의 군 합)의 불일치**: 양자화 Q_i는 준동형이 아니므로 ΣQ_i(X_k) ≠ Q(ΣX_k)이고, 오차 합이 S와 무관한 엔트로피 ½log K를 남긴다. 대수적으로 Hom(ℝ, ℤ_M) = {0}(ℝ은 나눗셈 가능 군)이라 KM식 "인코더 = 준동형" 구조가 원천적으로 불가능하다. Wagner의 중첩 격자는 Λ_i → Λ_i/Λ_o라는 준동형을 "양자화 뒤에" 쓰는 최선의 우회지만, 양자화 결함은 남는다. 이것이 본 연구 가설의 구조적 근거다.

5. **피할 수 있는가? 원문에서 읽히는 경우들.**
 - 상관이 강하고(ρ → 1) 차를 원할 때: 비제약 최적 자체가 격자와 같은 차수이고(외부 경계 대비 1비트), QB는 무한히 나쁘다. 이 영역에서는 스위치 제약이 거의 공짜이고 오히려 구조가 이득이다. 본 연구 설정(독립)과는 반대 극단.
 - 독립(ρ = 0): 비제약 최적은 개별 부호화이고, 제약 방식은 ½log K를 낸다. 원문 어디에도 제약 방식이 이를 피하는 구성은 없다.
 - 결론적 단서: "구조 부호가 이득"인 것은 소스 상관이 목표 함수의 엔트로피를 줄일 때(H(Y_3) ≪ H(Y_1,Y_2))이고, 그 이득이 제약 비용 ½log K를 상쇄한다. 독립 소스에서는 상쇄할 이득이 없으므로 순손해. 본 연구 정리 A는 "상쇄할 상관이 없을 때의 순손해 = ½log₂K"라는 진술로 읽을 수 있다.

6. **원문 하한 기법의 한계와 재사용 가능성.**
 - 정리 2, 3의 하한은 모두 정보 주입(genie X) + 컷셋형이고 비제약 문제에 대한 것이다. 그러므로 원리적으로 ½log₂K 대가를 잡지 못한다(ρ = 0에서 정리 3은 비제약 최적과 정확히 같다).
 - 재사용할 부분: 정리 3의 "X^n을 주어 조건부 독립을 만들고, MSE를 교차항 0으로 분해" 기법은 본 연구에서 W(공통 무작위성)를 조건으로 두고 Q_k들이 조건부 독립이 되는 구조와 같다. 왜곡 분해 D = ΣD_k (독립 작업자)는 정확히 부록 E의 (39) 꼴이다.
 - 재사용할 부분 2: 정리 2의 "h(Y_3^n|…) ≤ (n/2)log(2πeΔ)"로 왜곡을 미분 엔트로피 상한으로 바꾸는 단계는 보조정리 L에서 I(S;Z|W)를 다룰 때 그대로 쓴다.
 - 새로 필요한 것: H(Z|S,W)를 아래로 묶는 단계(3번의 EPI 경로). 이것은 Wagner에 없다.

7. **K=2 달성 식 대조.** 과제 설명의 Krithivasan–Pradhan Thm 3.1 "2^{−2R_1} + 2^{−2R_2} ≤ D/σ_S²"는 원문 명제 2의 (11)과 같다(σ_S² = σ_3² = 1 + c² − 2ρc). 원문은 이를 [20](LNCS 4851, 2007) 인용으로 적는다. KP 원논문의 정리 번호 "3.1"은 이 논문에서 확인할 수 없다. [미확인]
