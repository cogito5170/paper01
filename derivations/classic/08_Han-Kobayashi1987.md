# Han–Kobayashi 1987 유도 노트

표기: [원문] = 원문 증명 경로를 그대로 따름, [재구성] = 원문이 생략했거나 낡은 기법이라 현대 표준 증명(El Gamal–Kim 식)으로 보충, [미확인] = 원문에서 확인하지 못함. 원문은 log 밑을 정하지 않는다(식 (3.25)에서 log_q와 구분). 아래 예시 수치는 밑 2.

## 1. 서지

- 저자: Te Sun Han, Kingo Kobayashi
- 제목: A Dichotomy of Functions F(X, Y) of Correlated Sources (X, Y) from the Viewpoint of the Achievable Rate Region
- 학술지: IEEE Transactions on Information Theory, vol. IT-33, no. 1, pp. 69–76, January 1987
- 비고: 텍스트 추출은 대체로 정상. 조건 (3.1), (3.11), (3.13), 보조정리 1–5, 정리 1과 그 증명은 70–73쪽 쪽 이미지로 대조했다.

## 2. 문제 설정 (원문 기호)

**소스.** X, Y는 유한 집합 𝒳, 𝒴에 값을 갖는 상관 확률변수, |𝒳| = a ≥ 2, |𝒴| = b ≥ 2, 확률
 p(k, h) = Pr{X=k, Y=h} > 0, 모든 k ∈ 𝒳, h ∈ 𝒴. (2.1)
F(X, Y)는 임의 함수, Z = F(X, Y), 치역 𝒵 (유한). (X_i, Y_i)는 (X, Y)의 독립 복사본, Z_i = F(X_i, Y_i).

**부호.** 인코더 φ_1: 𝒳^n → 𝓜_1 = {1, …, M_1}, φ_2: 𝒴^n → 𝓜_2 = {1, …, M_2}, 복호기 ψ: 𝓜_1 × 𝓜_2 → 𝒵^n. 율 R_1 = (1/n)log M_1, R_2 = (1/n)log M_2. 오류 확률 P_e = Pr{Z^n ≠ Ẑ^n}, Ẑ^n = ψ(φ_1(X^n), φ_2(Y^n)).

**달성 가능성.** 음이 아닌 (R_1, R_2)가 Z = F(X,Y)에 대해 달성 가능하다는 것은 임의의 λ > 0, η > 0에 대해 충분히 큰 n에서 (1/n)log|𝓜_1| < R_1 + η, (1/n)log|𝓜_2| < R_2 + η, P_e < λ인 φ_1, φ_2, ψ가 존재한다는 뜻이다. 달성 가능 율 전체를 ℛ(Z)라 쓴다.

**함수 행렬(function matrix).** F(k, h)를 (k, h) 성분으로 갖는 a×b 행렬 F. 행은 k, 열은 h.

**집합 𝒫.** (X, Y) ∈ 𝒫 ⇔ 모든 (k, h)에서 p(k, h) > 0. 확률값은 양수인 한 자유롭게 바뀌고 𝒳, 𝒴는 고정.

**예 1 (SW 영역).** Z = (X, Y)이면 ℛ은 R_1 ≥ H(X|Y) (2.2), R_2 ≥ H(Y|X) (2.3), R_1 + R_2 ≥ H(X,Y) (2.4)로 주어진다(Slepian–Wolf). 이 집합을 SW 영역 ℛ((X,Y))라 부른다.

**예 2 (KM 영역).** 𝒳 = 𝒴 = {0,1}, Z = X ⊕ Y이면 R_1 ≥ H(Z) (2.5), R_2 ≥ H(Z) (2.6)인 율은 달성 가능하다(Körner–Marton). 이 집합을 KM 영역이라 부른다. (X,Y)가 이진 대칭 상관 소스이면 KM 영역 = ℛ(X⊕Y)이고, 이때 (2.5), (2.6)은 (2.2), (2.3)과 같아져 ℛ(X⊕Y)가 ℛ((X,Y))를 진부분집합으로 포함한다.

**분류.** 클래스 𝒞_1: 모든 (X,Y) ∈ 𝒫에서 ℛ(F(X,Y)) = ℛ((X,Y))인 함수. 𝒞_2: 그 여집합.

## 3. 주 정리 진술 (원문 대조함)

**조건 (3.1).** "함수 행렬 F의 서로 다른 두 행은 다르다(any two distinct rows of the function matrix F are different)." 즉 k_1 ≠ k_2이면 F(k_1, h_0) ≠ F(k_2, h_0)인 h_0가 있다.

**조건 (3.11).** "함수 행렬 F의 서로 다른 두 열은 다르다." 즉 h_1 ≠ h_2이면 F(k_0, h_1) ≠ F(k_0, h_2)인 k_0가 있다.

**조건 (3.13).** F(k_1, h_1) ≠ F(k_2, h_2), k_1 ≠ k_2, h_1 ≠ h_2인 모든 (k_1, h_1), (k_2, h_2)에 대해. (두 좌표가 모두 다른 두 칸은 값이 다르다.)

[세 조건 모두 원문 70–71쪽 쪽 이미지로 대조함]

**보조정리 1.** (X,Y) ∈ 𝒫이고 (3.1)이 성립하면 F의 모든 달성 가능 율은 R_1 ≥ H(X|Y) (3.2)를 만족한다.

**보조정리 2.** (X,Y) ∈ 𝒫이고 (3.11)이 성립하면 R_2 ≥ H(Y|X) (3.12).

**보조정리 3.** (X,Y) ∈ 𝒫이고 (3.1), (3.11)에 더해 (3.13)이 성립하면 R_1 + R_2 ≥ H(X, Y) (3.14).

**보조정리 4.** Z가 갈루아 체(Galois field) GF(q)에 값을 갖고 Z^n이 n개 독립 복사본이면, 임의의 ε > 0, λ > 0과 충분히 큰 n에 대해 GF(q) 성분의 m×n 행렬 A와 ψ: GF(q)^m → GF(q)^n이 있어
 m < n(H_q(Z) + ε) (3.23), Pr{Z^n ≠ ψ(AZ^n)} < λ (3.24),
 H_q(Z) = −Σ_z Pr{Z=z} log_q Pr{Z=z} = (1/log q)H(Z) (3.25).

**보조정리 5.** 𝒳, 𝒴가 GF(q)의 임의 부분집합이고 Z = X + Y (GF(q) 덧셈)이면 R_1 ≥ H(Z), R_2 ≥ H(Z) (3.26)인 모든 율이 Z = X + Y에 대해 달성 가능하다.

**정리 1.** Z = F(X,Y)가 𝒳 × 𝒴 (|𝒳| = a ≥ 2, |𝒴| = b ≥ 2) 위의 함수일 때, 모든 (X,Y) ∈ 𝒫에서 전체 달성 가능 영역 ℛ(Z)가 SW 영역 ℛ((X,Y))와 일치하기 위한 필요충분조건은 함수 행렬 F(k,h)가 조건 (3.1), (3.11), (3.13)을 만족하는 것이다. [원문 72쪽, 대조함]

(정리 2, 3은 다변수 일반화로, 정리 2는 필요조건 (4.5), 정리 3은 충분조건 1′), 2′)를 준다. s = 2이면 둘을 합친 것이 정리 1과 같다. 원문 스스로 s ≥ 3에서는 결론적이지 않다고 적는다. 본 노트는 정리 1에 집중한다.)

## 4. 유도

정리 1의 논리 구조: "조건 ⇒ ℛ(Z) = SW"(원문은 이것을 충분성(sufficiency)이라 부른다)는 SW ⊆ ℛ(Z)(SW로 (X,Y)를 복원하면 Z도 계산됨, 자명)와 ℛ(Z) ⊆ SW(보조정리 1–3, 역정리)로 이뤄진다. "ℛ(Z) = SW (모든 분포) ⇒ 조건"(필요성)은 조건이 깨질 때 ℛ(Z) ⊋ SW인 분포를 만드는 것이다.

### 4.1 보조정리 1의 증명 [원문, 일부 단계 근거 보충]

W_1 = φ_1(X^n), W_2 = φ_2(Y^n), X^{i−1} = (X_1,…,X_{i−1}), Y^{[i+1]} = (Y_{i+1},…,Y_n).

**(가) 율 부등식.**
 nR_1 ≥ H(W_1) ≥ H(W_1|Y^n) (율 정의와 조건화)
  = I(X^n; W_1|Y^n) (W_1은 X^n의 함수)
  = H(X^n|Y^n) − H(X^n|Y^nW_1)
  = Σ_i H(X_i|Y_i) − Σ_i H(X_i|Y^n W_1 X^{i−1}) (무기억성, 연쇄 법칙)
  ≥ Σ_i H(X_i|Y_i) − Σ_i H(X_i|Y_i Y^{[i+1]} W_1 X^{i−1}) (Y^{i−1}을 조건에서 뺌, 조건화 감소의 역)
  = Σ_i I(X_i; U_i|Y_i) = nI(X; U|Y),
U_i = Y^{[i+1]}W_1X^{i−1}. 시간 공유 변수(time-sharing variable) Q ~ Unif{1..n}, U = (W_1, Y^{[Q+1]}, X^{Q−1}, Q), X = X_Q, Y = Y_Q로 두면 R_1 ≥ I(X;U|Y) (3.3).

**(나) 마르코프 사슬 U → X → Y (3.4).** X_i가 주어지면 U_i는 (X^{i−1}, X_{i+1}^n, Y_{i+1}^n)의 함수이고 이들은 (X_i, Y_i)와 독립이다. 따라서 U_i − X_i − Y_i. Q를 섞어도 유지된다. [근거 보충, 원문은 "쉽게 확인된다"]

**(다) Fano 단계.** 충분히 큰 n에서
 nε ≥ H(Z^n|W_2W_1) (Fano, ε는 λ→0과 함께 0으로)
  ≥ H(Z^n|Y^nW_2W_1) = H(Z^n|Y^nW_1) (W_2는 Y^n의 함수)
  = Σ_i H(Z_i|W_1Y^nZ^{i−1})
  ≥ Σ_i H(Z_i|W_1Y^nZ^{i−1}X^{i−1})
  = Σ_i H(Z_i|W_1Y^nX^{i−1}) (Z^{i−1}은 (X^{i−1},Y^{i−1})의 함수)
  = Σ_i H(Z_i|W_1Y_iY^{[i+1]}X^{i−1}) (X^{i−1}이 주어지면 Y^{i−1}은 (W_1, X_i^n, Y_i^n)과 독립이므로 등호 [근거 보충])
  = Σ_i H(Z_i|U_iY_i) = nH(Z|UY).
따라서 ε ≥ H(Z|UY) (3.5).

**(라) 극한.** Eggleston–Carathéodory 정리로 ‖U‖ ≤ |𝒳| + 1 (3.6). 그러면 (U,X,Y)의 치역이 유한 고정이므로 ε → 0에서 컴팩트성으로 극한 분포가 존재하고
 R_1 ≥ I(X;U|Y) (3.7), H(Z|UY) = 0 (3.8), U → X → Y (3.9).

**(마) H(X|U) = 0.** H(X|U) > 0이라 가정하면 어떤 u, k_1 ≠ k_2에서 Pr{X=k_1, U=u} > 0, Pr{X=k_2, U=u} > 0. (X,Y) ∈ 𝒫와 U → X → Y에서 임의 h에 대해 Pr{X=k_j, U=u, Y=h} = Pr{X=k_j, U=u}p(h|k_j) > 0 (3.10). (3.1)에 의해 F(k_1,h_0) ≠ F(k_2,h_0)인 h_0가 있으므로, (U,Y) = (u,h_0)에서 Z는 두 값을 양의 확률로 가져 H(Z|UY) > 0. (3.8)과 모순. 따라서 H(X|U) = 0이고
 I(X;U|Y) = H(X|Y) − H(X|UY) = H(X|Y) ⇒ R_1 ≥ H(X|Y). ∎

보조정리 2는 역할을 바꾼 같은 증명이다. [원문]

### 4.2 보조정리 3의 증명 [원문, 일부 근거 보충]

**(가) 합 율.**
 n(R_1+R_2) ≥ H(W_1) + H(W_2) ≥ H(W_1W_2) ≥ I(X^nY^n; W_1W_2)
  = H(X^nY^n) − H(X^nY^n|W_1W_2)
  = H(X^nY^n) − H(X^nY^nZ^n|W_1W_2) (Z^n은 (X^n,Y^n)의 함수)
  = H(X^nY^n) − H(Z^n|W_1W_2) − H(X^nY^n|Z^nW_1W_2).
Fano(H(Z^n|W_1W_2) ≤ nε)로
 n(R_1+R_2) ≥ Σ_i H(X_iY_i) − Σ_i H(X_iY_i|Z^nW_1W_2X^{i−1}Y^{i−1}) − nε
  ≥ Σ_i H(X_iY_i) − Σ_i H(X_iY_i|Z_{[i]}W_1W_2X^{i−1}Y^{i−1}) − nε (Z_i를 조건에서 뺌)
  = Σ_i H(X_iY_i|Z_{[i]}) − Σ_i H(X_iY_i|Z_{[i]}W_1W_2X^{i−1}Y^{i−1}) − nε
  = Σ_i I(X_iY_i; U_iV_i|Z_{[i]}) − nε (3.15),
Z_{[i]} = (Z_1,…,Z_{i−1},Z_{i+1},…,Z_n) (Z_i만 뺀 열), U_i = X^{i−1}W_1, V_i = Y^{i−1}W_2. 셋째 줄 등호는 Z_{[i]} ⊥ (X_i,Y_i) (3.16)′ (다른 시점의 함수이므로).

**(나) 핵심 관찰: (3.13) ⇒ Z가 주어지면 X와 Y가 독립.** 원문은 이 함의를 한 줄로 적는다. 근거 [재구성]: (3.13)은 F^{−1}(z) 안의 어떤 두 칸도 두 좌표가 모두 다르지 않다는 뜻이다. 세 칸 (k_1,h_1), (k_1,h_2), (k_2,h_1) (k_1≠k_2, h_1≠h_2)이 모두 F^{−1}(z)에 있으면 (k_1,h_2)와 (k_2,h_1)이 (3.13)에 위배되므로, F^{−1}(z)는 한 행 안에 있거나 한 열 안에 있다. 따라서 Z = z가 주어지면 X나 Y 중 하나가 결정적이고, 결정적인 변수는 무엇과도 조건부 독립이다.

**(다) 마르코프 사슬 U_i → X_i → Y_i → V_i | Z_{[i]} (3.16).** Z_{[i]}가 주어지면 j ≠ i인 (X_j, Y_j)들은 (나)에 의해 X_j ⊥ Y_j | Z_j이고 서로 다른 시점끼리 독립이므로, (X_j)_{j≠i}와 (Y_j)_{j≠i}는 조건부 독립이며 둘 다 (X_i,Y_i)와 독립이다. U_i는 (X_j)_{j≠i}와 X_i의 함수, V_i는 (Y_j)_{j≠i}와 Y_i의 함수이므로 사슬이 성립한다. [근거 보충]

**(라) 단일 문자화.** Q ~ Unif, J = Z_{[Q]}, X = X_Q, Y = Y_Q, U = U_Q, V = V_Q로
 R_1 + R_2 ≥ I(XY; UV|JQ) − ε (3.17), U → X → Y → V | JQ (3.18), JQ ⊥ (X,Y) (3.18)′.
Fano로 nε ≥ H(Z^n|W_1W_2) = Σ_i H(Z_i|Z^{i−1}W_1W_2) ≥ Σ_i H(Z_i|X^{i−1}Y^{i−1}Z_{[i]}W_1W_2) = nH(Z|UVJQ), 즉 ε ≥ H(Z|UVJQ) (3.19).

**(마) 극한.** 원문은 보조정리 1과 비슷한 논증으로 ‖U‖ ≤ (|𝒳|−1)‖G‖ + 2, ‖V‖ ≤ (|𝒴|−1)‖G‖ + 2, ‖G‖ ≤ 2 (G ≡ JQ)로 제한할 수 있다고 쓰고 ε → 0으로 보내
 R_1 + R_2 ≥ I(XY; UV|G) (3.20), H(Z|UVG) = 0 (3.21), U → X → Y → V | G (3.22), G ⊥ (X,Y) (3.22)′
를 얻는다(Gelfand–Pinsker 참조). ‖G‖ ≤ 2라는 기수 한계의 유도는 원문에 없다. [미확인 — 6절 참조]

**(바) H(X|UG) = 0, H(Y|VG) = 0.** G = g를 고정. 어떤 u에서 k_1 ≠ k_2가 Pr{U=u, X=k_j|G=g} > 0 (j=1,2)라 하자. (3.1)에서 F(k_1,h_0) ≠ F(k_2,h_0)인 h_0. (3.22)′와 𝒫에서 Pr{X=k, Y=h|G=g} = p(k,h) > 0이고 U − X − Y | G이므로 Pr{U=u, X=k_j, Y=h_0|G=g} > 0. (3.22)에서 V는 (Y,G)를 통해서만 의존하므로 Pr{V=v|Y=h_0, G=g} > 0인 v를 잡으면 Pr{U=u, X=k_j, Y=h_0, V=v|G=g} > 0 (j=1,2). 그러면 H(Z|U=u,V=v,G=g) > 0, (3.21)과 모순. 따라서 H(X|UG) = 0. (3.11)로 같은 방식으로 H(Y|VG) = 0.

**(사) 결론.** I(XY;UV|G) = H(XY|G) − H(XY|UVG) = H(XY|G) = H(X,Y) (G ⊥ (X,Y)). (3.20)에서 R_1 + R_2 ≥ H(X,Y). ∎

### 4.3 보조정리 4, 5 (GF(q) 선형 부호) [원문은 증명 생략 → 재구성]

원문은 "단순한 세기 논증(Ahlswede–Han 1983, p. 411 참조)"이라고만 쓴다. [재구성]
1. 전형 집합 T, |T| ≤ q^{n(H_q(Z)+δ)}.
2. A의 성분을 i.i.d. 균등 GF(q)에서 뽑는다. z' ≠ z이면 w = z' − z ≠ 0이고, GF(q)가 체이므로 w의 0이 아닌 성분 w_j는 역원이 있어 A w는 GF(q)^m 위 균등. Pr{Az' = Az} = q^{−m}.
3. 전형 복호: E[P_e] ≤ Pr{Z^n ∉ T} + |T| q^{−m} → 0 (m = n(H_q(Z)+2δ)).
4. 율: (1/n)log q^m = (m/n)log q ≈ H_q(Z) log q = H(Z). (3.25)의 단위 환산.

보조정리 5: 두 인코더가 같은 A로 AX^n, AY^n을 보내면 AX^n + AY^n = A(X^n + Y^n) = AZ^n이므로 ψ(AX^n + AY^n) = Ẑ^n. 율은 각각 H(Z). KM(05번)의 GF(q) 일반화. [원문]

**주의.** 2의 "A w가 균등"은 체 구조를 쓴다. ℤ_M (M 합성수)에서는 w가 영인자 성분만 가지면 A w가 진부분군 (M/d)ℤ_M^m 안에 갇혀 충돌 확률이 커진다. 따라서 보조정리 4, 5는 ℤ_M 덧셈에 그대로 적용되지 않는다. [재구성 관찰]

### 4.4 정리 1 필요성 [원문]

**a) (3.1)이 깨질 때.** k_1번째 행 = k_2번째 행 (k_1 ≠ k_2)이라 하자. 𝒳′ = 𝒳 − {k_2}로 두고 X′를 두 행을 합친 변수로 정의:
 Pr{X′=k, Y=h} = Pr{X=k, Y=h} (k ≠ k_1), Pr{X′=k_1, Y=h} = Pr{X=k_1,Y=h} + Pr{X=k_2,Y=h}.
F(X,Y) = F(X′,Y)이므로 인코더 1은 X′만 보내도 된다. ℛ(Z) ⊇ ℛ((X′,Y)) ∪ ℛ((X,Y)). 양수성 때문에 H(X′|Y) < H(X|Y)이고 H(X′,Y) < H(X,Y)이므로 ℛ((X′,Y)) ⊄ ℛ((X,Y)), 따라서 ℛ(Z) ⊋ ℛ((X,Y)). 모순.

**b) (3.11)이 깨질 때.** a)와 대칭.

**c) (3.13)이 깨질 때.** F(k_1,h_1) = F(k_2,h_2), k_1 ≠ k_2, h_1 ≠ h_2인 칸이 있다. 그러면 F는 그림 2의 세 유형 중 하나의 2×2 부분행렬을 갖는다: (a) 네 칸이 모두 같음, (b) 세 칸이 같고 하나 다름, (c) 반대각선 두 칸만 같고 나머지 두 칸은 서로 다르며 그 값과도 다름.
1. (c)에 대해서만 모순을 보이면 된다. 근거: (a), (b)는 (c)의 값을 더 합친(조악하게 만든) 함수이므로, (c)에서 달성 가능한 율은 (a), (b)에서도 달성 가능하다. 같은 이유로 그 부분행렬 밖의 값은 모두 서로 다르고 ○, △, ×와도 다르다고 가정해도 된다(가장 세밀한 함수).
2. 그런 함수의 구체적 표현: 𝒳 = {0, 1, …, a−1}, 𝒴 = {0, a−1, 2a−1, …, (b−1)a−1}, F(x,y) = x + y (정수 덧셈).
 - y = 0이면 값 0..a−1, y = ja−1 (j ≥ 1)이면 값 ja−1..(j+1)a−2. 이 구간들은 a−1에서만 겹친다(y=0의 최댓값 = y=a−1의 최솟값). 따라서 충돌은 (x_1,y_1) = (0, a−1), (x_2,y_2) = (a−1, 0) 하나뿐이고 [근거 보충], d_0 = min F = 0, d_1 = max F = ab − 2이며 0..ab−2의 모든 정수가 a−1을 빼고 한 번씩 나타난다.
3. q를 d_1보다 큰 가장 작은 소수로 잡으면 정수 덧셈 x + y는 GF(q) 덧셈으로 볼 수 있다(값이 q보다 작아 감김(wrap)이 없음).
4. 분포: Pr{X=x, Y=y} = (1−ε)/2 ((x,y) = (0,a−1) 또는 (a−1,0)), ε/(ab−2) (그 밖, 칸 수가 ab−2). 이것은 𝒫에 속한다.
 - H(X,Y) = (1−ε)log 2 + h(ε) + ε log(ab−2).
 - H(Z) = h(ε) + ε log(ab−2) (Z = a−1의 확률 1−ε, 나머지 ab−2개 값은 각각 ε/(ab−2)).
5. 보조정리 5로 (R_1^0, R_2^0) = (H(Z), H(Z))가 달성 가능하고 R_1^0 + R_2^0 = 2(h(ε) + ε log(ab−2)) → 0 (ε → 0).
6. 반면 SW 영역의 점은 R_1 + R_2 ≥ (1−ε)log 2 + h(ε) + ε log(ab−2) ≥ log 2 (ab−2 ≥ 2이므로 ε log(ab−2) ≥ ε log 2).
7. 충분히 작은 ε에서 (R_1^0, R_2^0)은 SW 영역 밖. ℛ(Z) ≠ ℛ((X,Y)). 모순. ∎

### 4.5 모듈로 합이 조건을 만족하는가

**이진 모듈로-2 합.** F = [[0,1],[1,0]].
- (3.1): 두 행 (0,1), (1,0)은 다르다. 만족.
- (3.11): 두 열도 다르다. 만족.
- (3.13): F(0,0) = 0 = F(1,1), 0≠1, 0≠1. **위배.**
따라서 X ⊕ Y ∈ 𝒞_2. 원문 예 2와 일치(이진 대칭 상관 소스에서 ℛ(X⊕Y) ⊋ SW).

**일반 유한 아벨 군 ℤ_M의 덧셈 (M ≥ 2), 𝒳 = 𝒴 = ℤ_M.** [재구성, 원문 밖 일반화]
- (3.1): 행 k는 h ↦ k + h, 즉 순열을 k만큼 민 것. k_1 ≠ k_2이면 모든 h에서 k_1 + h ≠ k_2 + h. 만족(사실 모든 열에서 다름).
- (3.11): 같은 이유로 만족.
- (3.13): 임의의 k_1 ≠ k_2, h_1에 대해 h_2 = h_1 + k_1 − k_2 ≠ h_1로 두면 F(k_1,h_1) = F(k_2,h_2). **항상 위배.** (각 값 z의 역상이 M개의 "반대각선" 칸이므로 한 행이나 한 열에 들어가지 않는다.)
- 결론: 모든 군 덧셈(그리고 |𝒳|,|𝒴| ≥ 2인 모든 라틴 방진형 함수)은 𝒞_2에 속한다. 즉 "SW보다 작은 율이 가능한 분포가 적어도 하나 있다."

**주의: 𝒞_2는 "이득이 가능한 분포가 존재"일 뿐이다.** 정리 1은 모든 분포에서 같은지를 묻는다. 특정 분포(예: 독립 균등)에서는 ℤ_M 합도 SW와 같은 영역을 가질 수 있다. 예: X, Y 독립 균등 ℤ_M이면 Z도 균등이고 Z ⊥ X, Z ⊥ Y이므로 컷셋으로 R_1 ≥ H(Z|Y) = log M = H(X|Y), R_2 ≥ log M, 즉 이득 없음. 이득의 크기는 결정 함수의 구조가 아니라 상관에 달려 있다.

## 5. 예제

**(가) 정리 1 필요성 구성의 수치 (a = b = 2).** 𝒳 = {0,1}, 𝒴 = {0,1} (= {0, a−1}), F(x,y) = x + y ∈ {0,1,2}, 충돌 (0,1),(1,0). q = 3 (d_1 = 2보다 큰 최소 소수), 곧 GF(3)에서 감김 없는 덧셈. ε = 0.01 (밑 2):
- H(X,Y) = 0.99 + h(0.01) + 0.01·log 2 ≈ 0.99 + 0.0808 + 0.01 = 1.0808.
- H(Z) = h(0.01) + 0.01 ≈ 0.0908. KM형 합 율 2H(Z) ≈ 0.18, SW 합 율 ≥ 1.08.
이것은 "Z가 거의 결정적인데 (X,Y)에는 1비트의 불확실성이 남는" 구조가 선형 부호 이득의 원천임을 보여 준다: 이득 = H(X,Y) − 2H(Z) ≈ H(X,Y|Z) − H(Z).

**(나) 이진 DSBS 모듈로 합 (원문 예 2).** p = 0.11: SW 합 율 ≈ 1.5, KM 합 율 ≈ 1.0.

**(다) 원문 주석 1 (양수성 가정의 필요).** 𝒳 = 𝒴 = {0,1}, Pr{X=0,Y=y} = ½ − ε, Pr{X=1,Y=y} = ε (y=0,1), F(0,y) = 0, F(1,0) = 1, F(1,1) = 2. 이 F는 (3.1), (3.11), (3.13)을 모두 만족한다. ε → 0 극한에서 SW 영역은 R_1 ≥ 0, R_2 ≥ log 2인데, ε = 0 정확히에서는 ℛ(F) = {R_1 ≥ 0, R_2 ≥ 0} (율 0으로 충분). 즉 ℛ(F)는 확률에 대해 불연속이고 SW 영역은 연속이다. 이것이 (2.1)을 가정한 이유다.

## 6. 원문과의 차이·빈틈

1. **보조정리 3의 기수 한계 ‖G‖ ≤ 2.** G = JQ는 고차원 열 Z_{[Q]}를 포함하므로, 기수를 2로 줄이는 근거가 원문에 없다. "보조정리 1과 비슷한 논증"이라고만 한다. [미확인] 대안 [재구성 제안]: G의 기수를 줄이지 않고도, 각 g에서 점별로 (바) 논증이 성립하고 ε → 0 극한은 "H(Z|UV,G=g) ≤ ε/Pr{g}"의 g별 처리와 U, V의 기수 한계(지지 보조정리(support lemma)를 G 조건부로 적용)만으로 할 수 있을 것으로 보이나, 엄밀한 확인은 하지 않았다.
2. **(3.13) ⇒ 조건부 독립의 근거 생략.** 4.2(나)에 보충했다. [재구성]
3. **보조정리 4 증명 생략.** 4.3에 보충했다. [재구성]
4. **보조정리 1의 Y^{i−1} 제거 등호.** 원문은 근거 없이 등호로 쓴다. 4.1(다)에 근거를 적었다.
5. **필요성 c)의 "가장 세밀한 함수로 환원" 단계.** 원문 논리는 맞지만, 정수 덧셈 구성이 "한 쌍만 충돌하는 임의의 a×b 함수"와 행·열 재명명으로 동형이라는 점을 명시하지 않는다. 충돌 쌍과 나머지 값이 모두 구별되는 a×b 함수는 재명명으로 유일하므로 성립한다. [재구성]
6. **다변수 (s ≥ 3) 미결.** 원문 4절 스스로 정리 2(필요)와 정리 3(충분) 사이 간극을 열어 둔다. 이후 문헌의 해결 여부는 확인하지 않았다. [미확인]
7. **결과의 성격.** 정리 1은 "구조적 이분법"이고 이득의 크기를 주지 않는다. 일반 함수의 정확한 영역은 여전히 열려 있다(Ahlswede–Han 1983 내부 한계가 알려진 최선의 하나라는 것은 기억에 의존).

## 7. 본 연구와의 연결

본 연구 모형: K명 작업자 X_k ~ N(0, σ²) 독립, Q_k = f_k(X_k, W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만 계산, 복호기 Ŝ = g(Z, W). 정리 A(가설): log₂M ≥ ½log₂(K/D̄) − c. 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½log₂K − c.

1. **스위치 함수는 𝒞_2이지만, 본 연구의 분포에서는 이득이 없다.** 스위치가 계산하는 F(q_1, …, q_K) = Σq_k mod M은 4.5에 의해 (3.13)을 항상 위배하므로 𝒞_2(이득 가능 클래스)다. 그러나 Q_k = f_k(X_k, W)는 W가 주어지면 서로 독립이다. 4.5의 "주의"에서 보였듯 독립 소스에서는 컷셋이 SW와 같아져 구조적 이득이 사라진다. 이분법이 말하는 이득은 HK 4.4 c)의 구성처럼 "H(Q|Z)가 크고 H(Z)가 작은" 상관 구조에서 나온다. 본 연구에서는 상관이 없으므로 HK식 이득은 0이고, 남는 것은 제약의 손해뿐이다.

2. **HK의 이득 항과 본 연구의 손해 항은 방향이 반대다.** HK에서 선형 부호가 아끼는 양은 H(X,Y|Z)(함수가 지우는 정보). 본 연구에서 문제가 되는 양은 H(Z|S,W)(스위치 출력에 남는, 목표 S와 무관한 정보). 이산 무손실에서는 목표 = Z이므로 H(Z|목표) = 0이 자동이다. 본 연구에서 목표 S는 실수 합이고 Z는 ℤ_M 합이라 목표와 Z가 다르며, 이 불일치가 H(Z|S,W) > 0을 만든다. 따라서 HK 이분법은 "어떤 함수가 SW보다 싼가"에 답하지만, "스위치가 계산하는 함수 ≠ 원하는 함수"일 때의 비용에는 답하지 않는다.

3. **보조정리 1·3의 증명 기법이 보조정리 L의 틀이 될 수 있다.** HK 역정리의 핵심 구조는 "(i) 오류 0 극한에서 H(Z|UY) = 0, (ii) 양수성(전체 지지) + 마르코프, (iii) 함수의 구별 가능성 ⇒ H(X|U) = 0(인코더가 전부 드러냄)"이다. 본 연구의 연속 판본으로 옮기면: (i) Ŝ = g(Z,W)가 S를 D 이내로 맞힘, (ii) 가우시안 전체 지지와 Q_k ⊥ Q_j | W, (iii) ℝ 덧셈과 ℤ_M 덧셈의 불일치(Hom(ℝ, ℤ_M) = {0}) ⇒ Z가 S의 함수일 수 없음, 정량적으로 H(Z|S,W) ≥ ½log₂K − c. HK의 (iii)이 정성적(0 vs 양수)이라면 본 연구는 크기(½log₂K)가 필요하므로, (iii)을 EPI류 부등식(합의 엔트로피 증가)으로 바꾸는 것이 할 일이다(추정).

4. **보조정리 3의 (3.13) ⇒ "Z가 주어지면 X ⊥ Y" 구조.** 본 연구에서 스위치 출력 Z가 주어졌을 때 (Q_1, …, Q_K)의 조건부 구조는 반대로 강한 의존(합이 고정된 초평면)이다. HK 보조정리 3의 경로(조건부 독립이면 합 율 ≥ H(X,Y))가 깨지는 지점이 정확히 군 덧셈의 반대각선 구조라는 것은, 본 연구에서 H(Q_1…Q_K|Z,W)가 큰 것이 이득(KM)이 아니라 손해로 바뀌는 조건을 찾을 때 참고점이 된다: 이득은 "목표가 Z의 함수"일 때만 이득이다.

5. **ℤ_M 합성수 주의.** 보조정리 4, 5는 체 GF(q) 위의 선형 부호다. 본 연구의 레지스터 ℤ_M (예: M = 2^b)은 체가 아니므로, KM/HK 달성 기법을 ℤ_M에 그대로 옮길 수 없다(4.3 주의). 격자 달성(Krithivasan–Pradhan, Wagner)도 내부적으로 소수 p의 ℤ_p 구성을 쓴다. ℤ_{2^b}에서 같은 율이 나오는지는 별도 확인이 필요하다(기억에 의존: 아벨 군 부호는 부분군 구조 때문에 율 손실이 생길 수 있음).

6. **이득/손해 판정.** HK는 "군 덧셈 = 구조적 이득이 가능한 함수"를 보장하지만, 그 이득은 상관에서 나온다. 독립 가우시안 작업자 + 실수 합 목표에서는 HK의 이득 메커니즘이 작동할 여지가 없고, 스위치 제약은 순손해 쪽으로만 작용한다는 것이 이 논문에서 얻는 판정이다.
