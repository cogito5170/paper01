## 2. 문제 설정 (원문 기호)

**역할 주의.** 원문 Fig. 1과 II절에 따르면 **부호기는 Y₂ⁿ을 보고, 복호기는 Y₁ⁿ을 부가 정보로 가진다.** (papers/SURVEY.md의 요약은 이 역할을 반대로 적었다 — 6절 참조.)

- 𝒴₁, 𝒴₂, 𝒳, 𝒳̂: 유한 집합. {(Y₁ₖ, Y₂ₖ)}ₖ: 𝒴₁×𝒴₂ 위 i.i.d. 쌍.
- 함수 G: 𝒴₁×𝒴₂ → 𝒳, 왜곡 D: 𝒳×𝒳̂ → [0,∞). 복호기는 X = G(Y₁,Y₂)를 왜곡 허용치 안에서 복원하려 한다.
- 부호 (F_E, F_D) (식 (1),(2)): F_E: 𝒴₂ⁿ → I_M = {0,…,M−1}, F_D: 𝒴₁ⁿ × I_M → 𝒳̂ⁿ.
- 평균 왜곡 (식 (3)): Δ = E[(1/n) Σₖ D(Xₖ, X̂ₖ)], Xₖ = G(Y₁ₖ, Y₂ₖ), X̂ⁿ = F_D(Y₁ⁿ, F_E(Y₂ⁿ)).
- 달성 가능성 (식 (4),(5)): (R,d)가 G에 대해 달성 가능 ⇔ 임의의 ε>0과 충분히 큰 n에 대해 M ≤ 2^{n(R+ε)}, Δ ≤ d+ε인 부호 존재.
- 율-왜곡 함수 (식 (6)): R(d) ≜ min_{(R,d)∈𝓡} R.

G(y₁,y₂) = y₂이면 Wyner–Ziv 문제(04번)와 같다. 서론은 이 문제가 Yamamoto–Itoh(1980)의 원격 소스(remote source) Wyner–Ziv 계의 **특수한 경우**라고 밝힌다: 잡음 채널의 입력 X가 두 출력 (Y₁,Y₂)로 유일하게 정해지는 경우.

## 4. 유도

### 4.1 Theorem 1의 핵심 관찰 [재구성]

원문은 증명을 생략하고 Wyner–Ziv Theorem 1과 같다고만 한다. 핵심은 **함수 복원 = 부가 정보에 의존하는 왜곡 척도**라는 점이다:
d̃(y₁, y₂, x̂) ≜ D(G(y₁,y₂), x̂).
그러면 문제는 "부호기는 Y₂, 복호기는 Y₁, 왜곡 d̃(Y₁,Y₂,X̂)"인 WZ 문제다. WZ 원 논문은 D가 소스 X에만 의존한다고 가정하지만, 아래 두 증명은 왜곡이 부가 정보에도 의존해도 한 줄도 바뀌지 않는다. (El Gamal–Kim 11.3절의 WZ 정리는 처음부터 d(x,y,x̂) 형태를 허용한다고 기억함 [미확인: 정확한 절 번호].)

또 Remark 2(04번 4.1절)와 같이 Y₁ − Y₂ − Ŷ₂이면 I(Y₂;Ŷ₂|Y₁) = I(Y₂;Ŷ₂) − I(Y₁;Ŷ₂).

### 4.2 Theorem 1 역정리 (R(d) ≥ inf I(Y₂;Ŷ₂|Y₁)) [재구성]

부호 (F_E,F_D), M = F_E(Y₂ⁿ), Δₖ = E D(Xₖ,X̂ₖ), (1/n)ΣΔₖ = Δ.
n(R+ε) ≥ log M ≥ H(M) ≥ H(M|Y₁ⁿ) ≥ I(Y₂ⁿ; M | Y₁ⁿ)  (메시지 집합 크기; 조건 줄이기; I ≤ H)
 = Σₖ I(Y₂ₖ; M | Y₁ⁿ, Y₂^{k−1})  (연쇄 법칙)
 = Σₖ [H(Y₂ₖ | Y₁ⁿ, Y₂^{k−1}) − H(Y₂ₖ | M, Y₁ⁿ, Y₂^{k−1})]
 = Σₖ [H(Y₂ₖ | Y₁ₖ) − H(Y₂ₖ | M, Y₁ⁿ, Y₂^{k−1})]  (i.i.d.: Y₂ₖ는 Y₁ₖ가 주어지면 다른 좌표와 독립)
 ≥ Σₖ [H(Y₂ₖ | Y₁ₖ) − H(Y₂ₖ | Uₖ, Y₁ₖ)]  (조건 줄이기: Y₂^{k−1} 제거)
 = Σₖ I(Y₂ₖ; Uₖ | Y₁ₖ),  Uₖ ≜ (M, Y₁^{k−1}, Y₁,ₖ₊₁ⁿ).
Uₖ의 성질:
- 마르코프 Y₁ₖ − Y₂ₖ − Uₖ: M은 Y₂ⁿ의 함수, Uₖ는 (Y₂ⁿ, Y₁ⁿ의 k 이외 좌표)의 함수. Y₂ₖ가 주어지면 Y₁ₖ는 (Y₂의 다른 좌표, Y₁의 다른 좌표)와 독립 (좌표 간 독립 + 같은 좌표 안에서는 Y₂ₖ만 Y₁ₖ와 연결).
- X̂ₖ는 (M, Y₁ⁿ) = (Uₖ, Y₁ₖ)의 함수: X̂ₖ = fₖ(Y₁ₖ, Uₖ), E D(G(Y₁ₖ,Y₂ₖ), fₖ(Y₁ₖ,Uₖ)) = Δₖ.
따라서 Uₖ ∈ 𝒫(Δₖ) (𝒴̂₂로 Uₖ의 값 집합을 쓰면 유한), I(Y₂ₖ;Uₖ|Y₁ₖ) ≥ R̄(Δₖ). R̄ ≜ 우변 함수의 볼록성(4.4절)과 옌센, 비증가성으로
R + ε ≥ (1/n) Σ R̄(Δₖ) ≥ R̄(Δ) ≥ R̄(d+ε). ε→0과 연속성으로 R ≥ R̄(d). ∎
(fₖ가 k에 의존하는 것은 문제없다: 𝒫(d)의 정의는 분포마다 함수 하나를 허용하고, 위 부등식은 좌표별로 적용한다.)

### 4.3 Theorem 1 달성 [재구성]

04번 4.6절의 비닝 증명에서 (X, Y, Z)를 (Y₂, Y₁, Ŷ₂)로 바꾼다.
- 부호책: 2^{n(I(Y₂;Ŷ₂)+δ)}개 ŷ₂ⁿ(l) ~ ∏ p_{Ŷ₂}, 2^{nR}개 통으로 분할.
- 부호기: (y₂ⁿ, ŷ₂ⁿ(l)) 결합 전형인 l(덮기 보조정리), 통 번호 전송.
- 복호기: 통 안에서 (ŷ₂ⁿ(l̂), y₁ⁿ) 결합 전형인 유일한 l̂(채움 보조정리: 통 크기 2^{n(I(Y₂;Ŷ₂) − R)} < 2^{n I(Y₁;Ŷ₂)}), x̂ₖ = f(y₁ₖ, ŷ₂ₖ(l̂)).
- 마르코프 보조정리: Y₁ − Y₂ − Ŷ₂이므로 (Y₁ⁿ, Y₂ⁿ, Ŷ₂ⁿ(L))이 결합 전형 ⇒ (Xⁿ = G(Y₁ⁿ,Y₂ⁿ), Y₁ⁿ, Ŷ₂ⁿ)도 전형(결정적 함수의 전형성 보존).
- 전형 평균 보조정리: (1/n) Σ D(G(y₁ₖ,y₂ₖ), f(y₁ₖ,ŷ₂ₖ)) ≤ (1+ε) E d̃.
- 율: R > I(Y₂;Ŷ₂) − I(Y₁;Ŷ₂) = I(Y₂;Ŷ₂|Y₁)이면 충분. ∎

### 4.4 볼록성·기수 한계 [재구성]

- 볼록성: 시분할 변수 T를 Ŷ₂에 포함(Ŷ₂ = (T, Ŷ₂^{(T)})). Y₁ − Y₂ − Ŷ₂ 유지, I(Y₂;Ŷ₂|Y₁)과 왜곡이 θ로 선형 결합 ⇒ R̄ 볼록, 따라서 내부에서 연속.
- 기수: 서포트 보조정리(support lemma, Csiszár–Körner)로 p(y₂|ŷ₂)들의 |𝒴₂|−1개 자유도(주변 분포 보존) + H(Y₂|Ŷ₂) − H(Y₁|Ŷ₂) 1개 + 최적 f 아래 왜곡 1개 = |𝒴₂|+1개 함수 보존 ⇒ |𝒴̂₂| ≤ |𝒴₂|+1. 원문 "Card 𝒴̂₂ ≤ Card 𝒴₂ + 1"과 일치.

(Y₁, Ȳ₂)는 교차 확률 1−p인 DSBS이고 (Ȳ₁, Ȳ₂)는 같은 p의 DSBS. 따라서 R₂(d; p) = R₁(d; 1−p), R₃(d;p) = R₁(d;1−p), R₄(d;p) = R₁(d;p). 마지막으로 R₁(d;p)가 p₀ = min(p,1−p)에만 의존함은 부록 I의 (A13) 치환(φ↔1−φ, β₀↔β₁)으로 원문이 보인다 [원문 부록 I 끝]. ∎

### 4.6 Theorem 5: R₁(d) = R*(d) [원문 부록 I + 재구성 보충]

X₁ = Y₁·Y₂. 우선 p ≤ ½ (p₀ = p).

**Lemma A1: R₁(d) ≤ R*(d) [원문].** 𝒴̂₂ = {0,1}, Fig. 3의 시험 채널: φ = Pr{Ŷ₂=0}, β₀ = Pr{Y₂=1|Ŷ₂=0}, β₁ = Pr{Y₂=0|Ŷ₂=1} (식 (A8),(A9)). Pr{Y₂=0} = ½이 되어야 하므로 ½ = φ(1−β₀) + (1−φ)β₁ (식 (A2)). 복원 함수 X̂₁ = f₁(Y₁,Ŷ₂) = Y₁·Ŷ₂ (식 (A10)).
- 왜곡 (식 (A11)): 오류 ⇔ Y₁ = 1이고 Y₂ ≠ Ŷ₂.
 Pr{Ŷ₂=0, Y₂=1, Y₁=1} = φβ₀(1−p₀),  Pr{Ŷ₂=1, Y₂=0, Y₁=1} = (1−φ)β₁p₀.
 ⇒ E D = φ(1−p₀)β₀ + (1−φ)p₀β₁ ≜ d.
- 율 (식 (A12)): I(Y₂;Ŷ₂|Y₁) = I(Y₂;Ŷ₂) − I(Y₁;Ŷ₂) = H(Y₁|Ŷ₂) − H(Y₂|Ŷ₂) (H(Y₁) = H(Y₂) = 1). Ŷ₂ = 0이면 Y₂ ~ Bern(β₀), Y₁ = Y₂ ⊕ Bern(p₀) (마르코프)이므로 H(Y₂|Ŷ₂=0) = h(β₀), H(Y₁|Ŷ₂=0) = h(p₀∗β₀); Ŷ₂=1도 같은 방식. ⇒
 I = φ[h(p₀∗β₀) − h(β₀)] + (1−φ)[h(p₀∗β₁) − h(β₁)].
- (A2)와 d 제약을 만족하는 모든 (φ,β₀,β₁)에 대해 성립하므로 inf를 취하면 R₁(d) ≤ R*(d). ∎

**Lemma A2: R₁(d) ≥ R*(d) [원문].** 임의의 Ŷ₂ ∈ 𝒫₁(d)와 f₁에 대해: Y₁ = 0이면 X₁ = 0이므로 f₁(0,·) = 0으로 두는 것이 최적. 남는 것은 f₁(1, ŷ₂) ∈ {0,1}뿐이므로 Ŷ₂의 값들을 f₁(1,·)의 값에 따라 두 부류로 합쳐도 된다(합치기는 Y₁−Y₂−Ŷ₂를 유지하고 I(Y₂;Ŷ₂|Y₁)을 줄이기만 함 — 자료 처리; 원문은 이 점을 "loss of generality 없이"라고만 씀 [재구성 보충]). 그러면 f₁(1,0)=0, f₁(1,1)=1, 즉 f₁ = Y₁·Ŷ₂로 둘 수 있다. (A8),(A9)로 φ, β₀, β₁을 정의하면 (A2)와 d ≥ φ(1−p₀)β₀ + (1−φ)p₀β₁ (식 (A15))이 성립하고
I(Y₂;Ŷ₂|Y₁) = φ[…] + (1−φ)[…] ≥ R*(φ(1−p₀)β₀ + (1−φ)p₀β₁) ≥ R*(d) (식 (A16)),
마지막은 R*의 비증가성(Lemma A3). ∎
[빈틈] R*의 정의 (22)는 0 ≤ φ < ½로 제한하지만 Lemma A2에서 합쳐 얻은 φ가 ½ 이하라는 보장은 원문에 없다. p₀ = 0.1, 0.3, 0.45와 여러 d에서 φ ∈ (0,1) 전체로 최소화해도 φ ≤ ½ 제한값과 같음을 수치로 확인했다(최적 φ는 0.2~0.49). 일반 증명은 [미확인].

**Lemma A3: R*(d)는 d에 대해 비증가 [원문].** d ≥ p₀/2에서는 R* = 0. 0 ≤ d < p₀/2에서 (23)의 피적분 g₁(d,θ)를 α ≜ 2p₀(1−p₀), β ≜ (1−2p₀)(p₀−2d), γ ≜ p₀, δ ≜ p₀−2d로 g₁ = h(αθ−β) + h((1−α)θ+β) − h(γθ−δ) − h((1−γ)θ+δ) (식 (A17),(A18))라 쓰면, dh/dx = (1/ln2)ln(1/x − 1)과 0 ≤ γθ−δ ≤ αθ−β ≤ (1−α)θ+β ≤ (1−γ)θ+δ ≤ 1 (식 (A21))에서 ∂g₁/∂d ≤ 0 (식 (A22)). 또 최소화 구간 1 − 2d/p₀ ≤ θ ≤ 1이 d와 함께 넓어지므로 R*는 비증가. ∎

**(22) ⇒ (23)의 환원 [원문 + 재구성].** (A2)에서 (1−φ)β₁ = ½ − φ + φβ₀. 이를 d 식에 넣으면
d = φ(1−p₀)β₀ + p₀(½ − φ + φβ₀) = φβ₀ + p₀/2 − p₀φ.
⇒ β₀ = [−(p₀−2d) + 2φp₀]/(2φ) (식 (A4)),

### 4.8 IV절 결론부의 언급들 [원문]

- 무손실 (R,0)은 G₁ = Y₁·Y₂에 대해서도 R ≥ H(Y₂|Y₁) (식 (30))일 때만 가능 (R₁(0) = H(Y₂|Y₁)이므로). G₆, G₇에 대해서는 이미 알려짐 ([3], Körner–Marton [14] 인용). 즉 AND 같은 "정보를 적게 쓰는" 함수라도 문자별(componentwise) 함수의 무손실 복원에는 Y₂ 전체의 조건부 엔트로피가 필요하다.
- Ahlswede–Csiszár(1981): 블록 함수 G*(Y₁ⁿ,Y₂ⁿ)에 대해서도 비슷한 현상("1비트를 얻는 것이 전부를 얻는 것만큼 어려울 수 있다").
- Slepian–Wolf형(양쪽 분리 부호기)으로의 일반화는 내·외부 경계만 가능하다고 언급.

## 5. 예제

### 5.1 이진 AND 함수 (원문 III절)
4.6–4.7절 참조. 요약: DSBS(p₀=0.3)에서 AND의 율 R*(d)는 Y₂ 자체를 2d로 복원하는 율 R_wz(2d)보다 엄격히 작고, 부호기·복호기 모두 Y₁을 아는 R_{X₁|Y₁}(d)보다 크다.

### 5.2 가우시안 합 함수: 원문 IV절 언급의 유도 [재구성]

**주장 (원문은 진술만):** (Y₁,Y₂) 결합 가우시안, 2차 왜곡, X = Y₁ + Y₂(또는 ±(Y₁ ± Y₂))이면 R(d) = R_{WZ, Y₂|Y₁}(d) = ½ log(σ²_{Y₂|Y₁}/d)⁺.
**유도.** 복호기가 Y₁을 알므로 임의의 추정 X̂에 대해 Ŷ₂ ≜ X̂ − Y₁(부호 ±는 적절히)로 두면 X − X̂ = ±(Y₂ − Ŷ₂). 거꾸로 Y₂의 추정 Ŷ₂로 X̂ = Y₁ + Ŷ₂를 만들 수 있다. 이 변환은 복호기에서 일대일이고 부호기는 그대로이므로, 두 문제의 달성 쌍 집합이 같다. 따라서 X = Y₂인 Wyner–Ziv 문제와 같고, 04번 5.2절의 가우시안 WZ 결과 R(d) = ½ log(σ²_{Y₂|Y₁}/d)가 그대로 나온다. 같은 논리로 Theorem 3(XOR)이 가우시안판의 이산 대응이다.
**단일 문자 식으로 검산.** Theorem 1에서 Ŷ₂ = Y₂ + V, f(Y₁,Ŷ₂) = Y₁ + E[Y₂|Y₁,Ŷ₂]: I(Y₂;Ŷ₂|Y₁) = ½ log((σ²_{Y₂|Y₁}+σ_V²)/σ_V²), 왜곡 = Var(Y₂|Y₁,Ŷ₂) = σ²_{Y₂|Y₁}σ_V²/(σ²_{Y₂|Y₁}+σ_V²) ⇒ 같은 식.
**예.** Y₁ = X_k, Y₂ = Σ_{j≠k} X_j (독립, 분산 σ²) ⇒ σ²_{Y₂|Y₁} = (K−1)σ², R(d) = ½ log((K−1)σ²/d).

## 7. 본 연구와의 연결

본 연구 요약: K명의 작업자, X_k ~ N(0,σ²) 독립, Q_k = f_k(X_k,W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M, 복호기 Ŝ = g(Z,W). 정리 A(가설): log₂M ≥ ½ log₂(K/D̄) − c. 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½ log₂K − c.

1. **공간 부가 정보의 정확한 기준선.** 하행에서 작업자 k가 X_k를 알고 S를 복원하는 것은 정확히 "G(Y₁,Y₂) = Y₁ + Y₂, Y₁ = X_k(복호기), Y₂ = S − X_k"인 이 논문의 설정이다. 5.2절에 의해 제약 없는 부호의 율은 ½ log₂((K−1)σ²/D) = ½ log₂((K−1)/(K D̄)) (D̄ = D/(Kσ²)). 부가 정보 없는 ½ log₂(1/D̄)와의 차이는 ½ log₂(K/(K−1))로 K가 크면 사라진다. **결론:** 공간 부가 정보는 정리 A의 ½ log₂K 항과 거의 무관하며, 공간 부가 정보 확장의 정리는 (가설) R_down ≥ ½ log₂((K−1)/D̄') − c 꼴로 상수만 바뀔 것으로 예상된다.
2. **증명 사슬에서의 역할.** 하행 복호기가 X_k를 가지면 사슬은 log₂M ≥ H(Z|W,X_k) = I(S;Z|W,X_k) + H(Z|S,W,X_k)가 된다. 첫 항은 4.2절 역정리(보조 변수 Uₖ = (M, 부가 정보의 다른 좌표))와 5.2절 가우시안 계산으로 ½ log₂((K−1)σ²/D) 하계를 준다. 둘째 항은 보조정리 L을 X_k 조건부로 써야 한다: 한 작업자를 고정해도 나머지 K−1명의 배분 무작위성이 남으므로 ½ log₂(K−1) − c가 자연스러운 가설이다.
3. **"함수 = 부가 정보 의존 왜곡" 환원.** 이 논문의 사실상 유일한 아이디어(4.1절)는 본 연구에서도 그대로 쓸 수 있다: 합 S를 복원하는 문제를 왜곡 d̃(x₁,…,x_K, ŝ) = (Σx_k − ŝ)²인 다단자 문제로 보고, 단일 문자 하계에서 보조 변수를 같은 방식(4.2절의 Uₖ 구성)으로 정의한다.
4. **AND 예의 교훈 — 함수의 "정보량"과 필요 율은 다르다.** 4.8절: 문자별 함수의 무손실 복원은 함수가 단순해도 H(Y₂|Y₁)를 요구할 수 있다. 합 호환 제약 아래에서 "Z가 합만 운반하면 싸다"는 직관이 성립하려면 Körner–Marton(05번)처럼 **군 구조**가 필요하고, 그렇지 않은 함수 계산은 일반적으로 이득이 없다는 대비로 인용할 수 있다.
5. **Theorem 6의 교훈 — 기존 부호의 재사용은 최적이 아니다.** 소스 복원 부호에 사후 연산(비트 곱)을 얹는 것은 함수 전용 부호보다 나쁘다. 본 연구에서 "개별 X_k를 양자화한 뒤 합"(합 호환 부호의 자연스러운 구성)이 함수 전용 최적 부호보다 손해를 볼 수 있다는 것의 이산 선례다. 다만 가우시안 합 + 한쪽 부가 정보(5.2절)에서는 손해가 없으므로, 손실은 **분산된 여러 부호기**에서 생긴다는 점을 구분해야 한다.
