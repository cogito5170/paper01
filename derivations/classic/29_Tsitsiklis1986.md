# 29. Tsitsiklis–Bertsekas–Athans 1986 — 비동기 분산 결정적·확률적 기울기 최적화 (유도 노트)

## 1. 서지

- J. N. Tsitsiklis, D. P. Bertsekas, M. Athans, "Distributed Asynchronous Deterministic and Stochastic Gradient Optimization Algorithms," *IEEE Trans. Automatic Control*, vol. AC-31, no. 9, pp. 803–812, Sept. 1986.
- 원본 파일: `papers/classic/29_Tsitsiklis1986.pdf` (10쪽). 2단 조판이라 pdftotext 결과의 수식이 깨져 있어, 진술과 식 번호는 쪽 이미지로 대조했다.

## 2. 문제 설정 (원문 기호)

### 2.1 계산 모형 (II절)

- 공간: H = H₁ × ⋯ × H_L (각 H_l은 유한차원 실벡터 공간, 유클리드 노름). x = (x₁,…,x_L), x_l ∈ H_l은 l번째 성분.
- 프로세서 {1,…,M}. 아래첨자 = 성분, 위첨자 = 프로세서, 괄호 = (전역) 이산 시간 n.
- 프로세서 i는 자기 사본 x^i(n) ∈ H를 가진다. 시간 n에 "스텝" s^i(n) ∈ H를 계산할 수 있다(자체 측정·계산).
- 메시지: 프로세서 j가 성분 x_l을 담은 메시지를 i에게 보내고 i가 시간 n에 받으면, 그 메시지의 송신 시각을 t^{ij}_l(n) (≤ n)으로 쓴다. 내용은 x^j_l(t^{ij}_l(n)). 관례로 t^{ii}_l(n) = n. T^{ij}_l = i가 j로부터 x_l 메시지를 받는 시각들의 집합.
- 갱신 규칙 (볼록 결합 + 스텝):

  x^i_l(n+1) = Σ_{j=1}^M a^{ij}_l(n) x^j_l(t^{ij}_l(n)) + γ^i(n) s^i_l(n),  n ≥ 1  … (2.1)

  계수 조건: a^{ij}_l(n) ≥ 0 (2.2), Σ_j a^{ij}_l(n) = 1 (2.3), n ∉ T^{ij}_l (i≠j)이면 a^{ij}_l(n) = 0 (2.4).
- T^i_l = 프로세서 i가 성분 l에 대해 "계산"(γ^i s^i_l 항을 더함)하는 시각들. n ∉ T^i_l이면 s^i_l(n) = 0. γ^i(n) ≥ 0은 스텝 크기(상수 γ₀ 또는 1/n 같은 감소형).
- 두 특수 형태: **특화(specialization)** — 성분 l은 한 프로세서만 갱신하고 나머지는 받은 값을 그대로 덮어씀(Bertsekas의 분산 비동기 반복); **중첩(overlap)** — 여러 프로세서가 같은 성분을 갱신하고 결합으로 의견을 맞춤.

### 2.2 통신·결합 가정

성분 l마다 방향 그래프 G_l = (V, E_l), V = {1,…,M}, (j,i) ∈ E_l ⇔ T^{ij}_l이 무한(j가 i에게 x_l을 무한히 자주 보냄).

- **Assumption 2.1** (각 l): a) 성분 l에 대한 계산 프로세서가 적어도 하나 있다. b) G_l에서 모든 계산 프로세서로부터 다른 모든 프로세서로 가는 방향 경로가 있다. c) 상수 α > 0이 있어 (i) i가 n에 j의 메시지를 받으면 a^{ij}_l(n) ≥ α, (ii) 계산 프로세서 i는 a^{ii}_l(n) ≥ α, (iii) 비계산 프로세서이고 G_l에서 진입차수 ≥ 2이면 a^{ii}_l(n) ≥ α.
- **Assumption 2.2**: 각 (j,i) ∈ E_l에 대해 j → i의 x_l 연속 전송 간격이 B₁ 이하.
- **Assumption 2.3**: 상수 B₁ > 0, β ≥ 1이 있어 모든 (j,i) ∈ E_l과 n에 대해 구간 [B₁n^β, B₁(n+1)^β]마다 적어도 한 메시지가 보내지고, 그 구간에서 주고받는 메시지 수는 유계. (2.2는 β=1인 특수형.) 간격이 n^(β−1) 속도로 **커지는 것을 허용**한다.
- **Assumption 2.4**: 통신 지연이 B₀ 이하: n ∈ T^{ij}_l이면 n − t^{ij}_l(n) ≤ B₀.

### 2.3 최적화 가정 (III절)

비음 비용 J: H → [0,∞). 초기값 x^i(1)과 스텝 s^i(n)은 확률변수, 계수 a와 송수신 시각은 결정적(사전에 프로세서가 알 필요는 없음). F_n = s^i(k) (k ≤ n−1)와 x^i(1)을 측정 가능하게 하는 σ-대수 열.

- **Assumption 3.1**: J는 연속 미분 가능, ‖∇J(x) − ∇J(x′)‖ ≤ K‖x − x′‖ (3.1).
- **Assumption 3.2** (조건부 하강 방향): E[(∂J/∂x_l)(x^i(n)) s^i_l(n) | F_n] ≤ 0, a.s., ∀i,l,n (3.2). (예: s = −∇J + 평균 0 잡음.)
- **Assumption 3.3** (잡음이 기울기와 함께 사라짐): K₀ ≥ 0이 있어 E[‖s^i_l(n)‖²] ≤ −K₀ E[(∂J/∂x_l)(x^i(n)) s^i_l(n)].
- **Assumption 3.4** (지속 잡음 허용): K₁, K₂ ≥ 0이 있어 E[‖s^i_l(n)‖²] ≤ −K₁ E[(∂J/∂x_l)(x^i(n)) s^i_l(n)] + K₂ (3.5).

## 3. 주 결과 진술 (원문 번호, 원문 대조)

### Lemma 2.1 (결합 계수의 성질; 증명은 [18]) [원문, 쪽 805–806 이미지 대조]

선형성으로, n ≥ k에 대해 스칼라 Φ^{ij}_l(n|k)가 있어

x^i_l(n) = Σ_j Φ^{ij}_l(n|0) x^j_l(1) + Σ_{k=1}^{n−1} Σ_j γ^j(k) Φ^{ij}_l(n|k) s^j_l(k).  … (2.6)

- i) 0 ≤ Φ^{ij}_l(n|k) (2.7), Σ_j Φ^{ij}_l(n|k) ≤ 1 (2.8).
- ii) 가정 2.1, 2.4와 2.2 또는 2.3 아래, lim_{n→∞} Φ^{ij}_l(n|k)가 존재하고 i에 무관(Φ^j_l(k)로 씀). 계산 프로세서 j에 대해 Φ^j_l(k) ≥ η > 0 (2.9). η는 B₀, B₁, β, α에만 의존.
- iii) 가정 2.1, 2.2, 2.4 아래, d ∈ [0,1), B ≥ 0이 있어 max_{i,j} |Φ^{ij}_l(n|k) − Φ^j_l(k)| ≤ B d^(n−k) (2.10).
- iv) 가정 2.1, 2.3, 2.4 아래, d ∈ [0,1), δ ∈ (0,1], B ≥ 0이 있어 같은 차이 ≤ B d^(n^δ − k^δ) (2.11).

보조 벡터: Φ^j(k)x := (Φ^j_1(k)x₁, …, Φ^j_L(k)x_L) (2.12),

y(n) = Σ_j Φ^j(0) x^j(1) + Σ_{k=1}^{n−1} Σ_j γ^j(k) Φ^j(k) s^j(k)  … (2.13),

y(n+1) = y(n) + Σ_j γ^j(n) Φ^j(n) s^j(n)  … (2.14).

y(n)은 "지금 계산을 멈추고 통신·결합만 계속하면 모든 프로세서가 합의할 점"이다.

### Theorem 3.1 (상수 스텝) [원문, 쪽 807 이미지 대조]

가정 2.1, 2.2, 2.4, 3.1, 3.2, 3.3 성립. γ^i(n) ≥ 0, sup_{i,n} γ^i(n) = γ₀ < ∞. 가정의 상수들에만 의존하는 γ* > 0이 있어 0 < γ₀ ≤ γ*이면:
- a) J(x^i(n)) (i = 1,…,M)와 J(y(n))이 거의 확실히(a.s.) 같은 극한으로 수렴.
- b) lim (x^i(n) − x^j(n)) = lim (x^i(n) − y(n)) = 0, a.s. 및 평균제곱.
- c) Σ_{n=1}^∞ Σ_i γ^i(n) ∇J(x^i(n)) E[s^i(n) | F_n]  … (3.4) 가 a.s. 유한, 기댓값도 유한.

원문 주의: 이 정리는 아직 최소점·정류점 수렴을 말하지 않는다(모든 i, n에서 s = 0도 허용되므로). 정류점 수렴은 Corollary 3.1.

### Theorem 3.2 (감소 스텝) [원문]

가정 2.1, **2.3**, 2.4, 3.1, 3.2, **3.4** 성립, 어떤 K₃ ≥ 0에 대해 γ^i(n) ≤ K₃/n. 그러면 Theorem 3.1의 a), b), c)가 그대로 성립. 또한 (3.5)를 더 약한

E[‖s^i(n)‖²] ≤ K₀E[J(x^i(n))] − K₁E[∇J(x^i(n))Φ^i(n)s^i(n)] + K₂  … (3.6)

로 바꿔도 성립(증명은 [18], "훨씬 복잡").

### Corollary 3.1 (정류점·최적 수렴) [원문]

어떤 K₄ > 0에 대해 γ^i(n) ≥ K₄/n, J의 준위 집합이 콤팩트, 연속 함수 g^i_l: H → [0,∞)가 있어

(∂J/∂x_l)(x^i(n)) E[s^i_l(n) | F_n] ≤ −g^i_l(x^i(n)),  ∀n ∈ T^i_l  … (3.7),

g = Σ_i Σ_l g^i_l의 영점은 모두 J의 정류점, T^i_l ≠ ∅인 (i,l)에 대해 T^i_l의 연속 원소 간격이 유계라고 하자. 그러면
- a) Theorem 3.1 또는 3.2의 가정 아래: liminf_n ‖∇J(x^i(n))‖ = 0, a.s. (3.8)
- b) Theorem 3.1의 가정 + γ^i(n) ≥ ε > 0: lim_n ‖∇J(x^i(n))‖ = 0 a.s. (3.9), {x^i(n)}의 모든 극한점은 정류점.
- c) 어느 정리의 가정이든, g = 0인 점이 모두 최소점이면 lim J(x^i(n)) = inf_x J(x) (3.10).

(상수 스텝 γ₀ ≥ ε을 쓰면서 동시에 γ^i(n) ≥ K₄/n은 자동이다. a)의 상수 스텝 경우는 K₄/n 조건이 필요 없을 것 같지만 원문은 Corollary 전체의 가정으로 둔다 [원문 그대로].)

## 4. 유도

표기 [원문 부록 관례]: A는 n, γ₀, γ^i(n), x^i(n), s^i(n)에 무관하고 가정의 상수(M, L, K, K₀, B₀, B₁, α 등)에만 의존하는 비음 상수이며, 식마다(심지어 양변에서) 다른 값을 가질 수 있다.

### 4.1 Theorem 3.1의 증명

**0단계: 정규화** [원문]. x^i(1) = 0으로 둘 수 있다(초기 불일치는 "시간 0에 0에서 출발해 s^i(0)이 x^i(1)로 옮겼다"로 환원). 또 s̃^i(n) = (γ^i(n)/γ₀)s^i(n)으로 바꾸면 스텝이 γ₀로 고정되고 3.2, 3.3이 s̃에도 성립하므로 γ^i(n) = γ₀로 둔다.

**1단계: 불일치 한계 (A.2)** [원문]. b(n) = Σ_i ‖s^i(n)‖ (A.1), b²(n) ≤ M Σ_i ‖s^i(n)‖² ≤ M b²(n) [코시–슈바르츠, 재구성]. (2.6)과 (2.13)을 빼고 Lemma 2.1 iii)을 쓰면

‖y(n) − x^i(n)‖ ≤ Σ_{k<n} Σ_j γ₀ ‖Φ^j(k) − Φ^{ij}(n|k)‖ ‖s^j(k)‖ ≤ Aγ₀ Σ_{k=1}^{n−1} d^(n−k) b(k).  … (A.2)

의미: 지연·통신 간격의 영향은 기하급수적으로 잊히는 과거 스텝들의 가중합으로 묶인다. d는 B₀, B₁, α에 의존하며 지연이 길수록 1에 가까워진다 [재구성: 원문은 d의 의존성만 명시].

**2단계: y에 대한 하강 (A.3)–(A.7)** [원문]. 립시츠 기울기의 테일러 상계(J(u+v) ≤ J(u) + ∇J(u)v + (K/2)‖v‖²)를 (2.14)에 적용:

J(y(n+1)) ≤ J(y(n)) + γ₀∇J(y(n)) Σ_i Φ^i(n)s^i(n) + Aγ₀² b²(n).  … (A.3)

가정 3.2는 ∇J(x^i(n))에 대한 것이므로 ∇J(y(n))을 ∇J(x^i(n))로 바꾸는 오차를 (3.1)과 (A.2)로 묶는다 (‖Φ^i(n)‖ ≤ 1):

‖∇J(y(n))ΣΦ^i s^i − Σ∇J(x^i(n))Φ^i s^i‖ ≤ A Σ_i ‖y(n) − x^i(n)‖‖s^i(n)‖ ≤ γ₀A Σ_{k<n} d^(n−k) b(k)b(n) ≤ γ₀A Σ_{k<n} d^(n−k)[b²(k) + b²(n)].  … (A.4)

(마지막은 2ab ≤ a² + b².) G^i(n) = −∇J(x^i(n))Φ^i(n)s^i(n) (A.5), G(n) = Σ_i G^i(n) (A.6). Φ^i_l(n) ≥ 0은 결정적이므로 가정 3.2에서 E[G(n) | F_n] ≥ 0, 따라서 E[G(n)] ≥ 0. Σ_k d^(n−k) ≤ 1/(1−d)로 b²(n) 항을 흡수하면

J(y(n+1)) ≤ J(y(n)) − γ₀G(n) + Aγ₀² Σ_{k=1}^{n} d^(n−k) b²(k).  … (A.7)

**3단계: 잡음–기울기 결합 (A.8)** [원문]. 가정 3.3을 성분별로 더하고 Lemma 2.1 ii)의 Φ^i_l ≥ η를 쓰면 (3.3)과 같이

E[‖s(n)‖²] ≤ (K₀/η) Σ_l E[−(∂J/∂x_l) Φ^i_l s^i_l] = K̄₀ E[−∇J(x^i(n))Φ^i(n)s^i(n)],

따라서 E[b²(k)] ≤ A E[G(k)].  … (A.8)

[재구성 보충] (3.3)의 "Φ^i_l ≥ η로 나눈다"는 계산 프로세서 성분에서만 의미가 있다. 비계산 성분은 s^i_l = 0이므로 양변 0이다.

**4단계: 합산과 γ* 선택 (A.9)–(A.12)** [원문]. (A.7)의 기댓값에 (A.8)을 대입하고 n에 대해 더하면 (이중합의 순서를 바꾸어 Σ_{m≥k} d^(m−k) ≤ 1/(1−d)):

0 ≤ E[J(y(n+1))] ≤ E[J(y(1))] + Σ_{k=1}^{n} [Aγ₀²/(1−d) − γ₀] E[G(k)].  … (A.10)

γ* = (1−d)/(2A)로 두고 0 < γ₀ ≤ γ*이면 Aγ₀²/(1−d) ≤ γ₀/2이므로

γ₀ Σ_{k=1}^n E[G(k)] ≤ 2E[J(y(1))]  … (A.11),  γ₀ Σ_{k=1}^∞ E[G(k)] < ∞.  … (A.12)

**γ*가 지연에 의존하는 방식**: γ* ∝ (1−d). 지연 B₀나 통신 간격 B₁이 크면 d → 1, 허용 스텝이 작아진다. 이것이 서론의 "통신 간격과 지연이 너무 크지 않다면"의 정량적 형태다 [원문 해석 + 재구성].

**5단계: c)** [원문]. E[G(k) | F_k] ≥ 0이므로 단조수렴정리로 E[Σ_k E[G(k)|F_k]] = Σ E[G(k)] < ∞ (A.13), 따라서 Σ_k E[G(k)|F_k] < ∞ a.s. (A.14). 이는 Σ_n ∇_l J(x^i(n)) Φ^i_l(n) E[s^i_l(n)|F_n] > −∞이고, 계산 프로세서에서 Φ^i_l ≥ η > 0이므로 Φ를 떼어 낼 수 있다. 이것이 (3.4)의 유한성이다.

**6단계: a)의 J(y(n)) 수렴 — 준마팅게일 보조정리** [원문].

Lemma A.1: X(n), Z(n) ≥ 0이 {F_n}에 적합(adapted)하고 E[X(n+1)|F_n] ≤ X(n) + Z(n) (A.15), Σ E[Z(n)] < ∞ (A.16)이면 X(n)은 a.s. 수렴. (증명: Σ Z(n) < ∞ a.s. → 준마팅게일 수렴 정리, Ljung–Söderström 4.C.1, Meyer.)

Z(n) = Aγ₀² E[Σ_{k≤n} d^(n−k) b²(k) | F_n] (A.17)로 두면 E[Z(n)] ≤ A Σ_k d^(n−k) E[G(k)] (A.18), Σ_n E[Z(n)] ≤ A/(1−d) Σ_k E[G(k)] < ∞ (A.19). (A.7)의 조건부 기댓값에서 J(y(n))은 F_n-가측이고 E[G(n)|F_n] ≥ 0이므로 E[J(y(n+1))|F_n] ≤ J(y(n)) + Z(n). Lemma A.1로 J(y(n))은 a.s. 수렴.

**7단계: b)** [원문]. 가정 3.3과 (A.12)로 E[Σ b²(k)] ≤ A Σ E[G(k)] < ∞ (A.20), 따라서 b(k) → 0 a.s.; (A.2)에서 y(n) − x^i(n) → 0 a.s. (기하 가중합은 0으로 가는 수열을 0으로 보냄 [재구성]). (A.2)를 제곱하고 기댓값을 취하면 E[b²(k)] → 0에서 평균제곱 수렴도 따른다.

**8단계: a)의 나머지** [원문]. J ≥ 0과 2차 전개: 임의 a에 대해 0 ≤ J(x − a∇J(x)) ≤ J(x) − aA₁‖∇J‖² + a²A₂‖∇J‖² (A.21). a를 작게 고정하면

‖∇J(x)‖² ≤ A J(x),  ∀x  … (A.22).

J(y(n))이 수렴하므로 유계, 따라서 ∇J(y(n))도 유계. y − x^i → 0과 J의 연속 미분 가능성(평균값 정리 [재구성])에서 J(x^i(n)) − J(y(n)) → 0. ∎

### 4.2 Theorem 3.2의 증명 개요 [원문 + 재구성]

정규화로 x^i(1) = 0, γ^i(n) = 1/n (s̃ = nγ^i(n)s^i). Lemma 2.1 iv)의 c(n|k) = d^(n^δ − k^δ)를 쓴다. 이 경우 기하 감쇠 대신 n^δ 척도의 감쇠라 계산이 길다.

1. 가중치 (A.27): φ(n|k) = 1/n² + Σ_{m<n} (1/(nm))c(n|m) (n=k), (1/(nk))c(n|k) (n>k), 0 (n<k).

## 7. 본 연구와의 연결

본 연구 모형: K명의 작업자가 그래디언트 좌표 X_k ~ N(0,σ²), 인코더 Q_k ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만 계산, 목표는 S = ΣX_k 추정. 하행 비트 log₂M ≥ ½log₂(K/D̄) − c (가설). 6장(과업 기준 한계)에서는 "SGD가 수렴하려면/특정 속도로 수렴하려면 통신량이 얼마나 필요한가"를 다룬다.

### 7.1 본 연구 시스템을 Tsitsiklis 모형에 대입 [재구성]

- 동기식 매개변수 서버/스위치형 SGD: 모든 작업자가 같은 하행 메시지 Z로 같은 추정 Ŝ를 얻어 같은 갱신을 하므로 x^i(n) = y(n), 지연 B₀ = 0, 간격 B₁ = 1. 이 경우 Lemma 2.1의 Φ는 자명하고 d = 0에 해당한다.
- 갱신 방향: s(n) = −(1/K)Ŝ(n) = −∇J(x(n)) − w(n), 여기서 w = (Ŝ − S)/K + (확률적 기울기 잡음). 양자화 오차는 **가정 3.2–3.4의 s에 들어가는 잡음 항**이다.
- 가정 3.2 ⇔ E[w | F_n] = 0. 즉 **ℤ_M 부호화 후 복호한 Ŝ가 조건부 불편(unbiased)이어야** 한다. 디더(dither) 양자화나 확률적 반올림으로 확보 가능. mod M 래핑(wrap-around) 오류(합이 범위를 넘어 접힘)는 큰 편향 오차를 낳으므로 3.2를 깬다. 래핑 확률을 충분히 작게 하는 조건이 log₂M ≳ ½log₂K의 한 원인이라는 점(합 S의 표준편차가 √K σ로 커짐)과 직접 연결된다.
- 가정 3.3 (상수 스텝): E‖s‖² ≤ K₀ × ‖∇J‖² 꼴. 양자화 오차 분산 D가 **기울기 크기에 비례해 줄어야** 한다(상대 정밀도 양자화). 기울기 노름에 맞춰 스케일을 조정하는 양자화라면 고정된 M(고정 비트)로도 D ∝ ‖∇J‖²/M²가 되어 3.3을 만족할 수 있다(확률적 기울기 잡음이 없다는 전제). 이 경우 **수렴만을 기준으로 하면 비트 수의 하한이 생기지 않는다**: 어떤 M ≥ 2라도 γ₀를 충분히 작게 하면 수렴. 다만 K₀가 M에 따라 커지고 γ*가 이에 반비례해 작아진다 — 비트가 줄면 허용 스텝이 줄고 속도가 느려진다 [재구성].
- 가정 3.4 (감소 스텝): E‖s‖² ≤ K₁‖∇J‖²-항 + K₂. 고정 해상도 양자화(왜곡 D̄ 고정)라면 K₂ ≈ σ_SGD² + D̄/K² 꼴의 상수. Theorem 3.2에 따라 **D̄ > 0이 고정되어도 1/n 스텝이면 정류점으로 수렴**한다. 즉 "수렴 여부" 기준으로는 하행 비트에 대한 하한이 없다.

### 7.2 6장 과업 기준 한계에 주는 함의

1. **수렴 여부만으로는 비트 하한이 나오지 않는다** (Theorem 3.2 + 7.1). 따라서 6장의 과업 기준 한계는 반드시 **수렴 속도**(예: n번 반복 후 E‖∇J‖² 또는 J − J*가 ε 이하) 형태로 정식화해야 의미가 있다. 이 논문은 그 점을 정당화하는 근거로 인용할 수 있다: "Tsitsiklis 등(1986)에 따르면 불편 잡음이 유계 분산이면 감소 스텝 SGD는 잡음 크기와 무관하게 수렴하므로, 통신량의 과업 기준 하한은 속도 기준이어야 한다."
2. 속도로 옮길 때의 연결고리: 이 논문의 (A.7)/(A.30) 구조에서 잡음 항이 Aγ²(E[G] + K₂) 꼴로 들어간다. 현대적 비볼록 SGD 분석(이 논문 밖, [재구성])에서는 이것이 min_n E‖∇J‖² ≲ (J(x₁) − J*)/(γN) + γK·(σ² + D̄/K²) 꼴로 바뀌고, 왜곡 D̄가 속도의 분산 항에 더해진다. 본 연구의 율–왜곡 관계 D̄(M)를 여기에 넣으면 "목표 정확도 ε을 N 라운드 안에 달성하는 데 필요한 log₂M"을 얻는 경로가 생긴다. 즉 ½log₂(K/D̄) 가설을 과업 기준으로 번역하는 다리다.
3. **편향 금지**: 가정 3.2가 요구하는 조건부 불편성은 본 연구의 추정기(Ŝ = E[S | Z] 같은 최소평균제곱오차(MMSE) 추정기)가 일반적으로 편향(축소, shrinkage)된다는 점과 충돌한다. MMSE 추정은 왜곡은 최소지만 3.2를 어길 수 있으므로, 6장에서는 (a) 불편 추정기 사용 시의 왜곡 손실, 또는 (b) 편향을 허용하는 분석(오차 피드백 등, 이 논문 밖)을 택해야 한다. 이 선택을 명시할 근거로 이 논문의 가정 3.2를 인용한다.

### 7.3 지연·다중 라운드·링·트리

- **링·트리 집계**: 링 올리듀스(all-reduce)는 K−1 단계 파이프라인이라 같은 라운드 안에서도 작업자마다 다른 시점의 부분합을 쓰게 설계할 수 있다(비동기/파이프라인 SGD). 이는 지연 B₀ ~ K인 Tsitsiklis 모형이고, Theorem 3.1의 γ* ∝ (1−d)에서 d가 K에 따라 1에 가까워지므로 허용 스텝이 K와 함께 줄어든다(5.2의 지연 1 예에서 한계가 2 → 1). 즉 링·트리에서 비트를 줄이려고 라운드를 파이프라인화하면 지연 비용이 수렴 속도로 돌아온다. 이 교환관계(비트 × 지연 × 스텝)를 6장의 확장 논의로 둘 수 있다.
- **트리의 부분합 공유(중첩)**: 서로 다른 스위치가 같은 좌표 블록의 부분 추정을 결합하는 구조는 원문의 "중첩(overlap)" + 볼록 결합 (2.1)에 해당하며, Assumption 2.1 b)(계산 노드에서 모두로 가는 경로)가 트리 연결성 조건이다. Lemma 2.1의 y(n)은 "모든 스위치가 합의할 집계값"으로 해석된다.
- **다중 라운드**: 원문 Theorem 3.2는 통신 간격이 B₁n^β로 커지는 것을 허용한다. 본 연구에 대입하면 "학습 후반에는 통신 라운드를 성기게 해도(그동안 국소 갱신) 수렴이 유지된다" — 지역 SGD(local SGD)의 고전적 근거다. 단, 이는 여전히 통신 횟수의 이야기이고 메시지당 비트(log₂M)는 다루지 않는다. 본 연구는 이 빈자리(메시지당 비트)를 채우는 쪽으로 위치시킬 수 있다.

### 7.4 인용 방식 제안

6장 도입에서: "분산 비동기 기울기법의 고전적 수렴 이론(Tsitsiklis–Bertsekas–Athans 1986, Thm 3.1–3.2, Cor 3.1)은 통신을 지연과 간격으로만 모형화하고 수렴의 점근적 성립만 보인다. 양자화 오차를 불편 유계 분산 잡음으로 보면 Thm 3.2에 의해 임의의 고정 왜곡에서도 수렴하므로, 메시지당 비트 수의 과업 기준 하한은 수렴 속도 기준으로만 의미가 있다." 편향 문제(가정 3.2)와 지연–스텝 교환(γ* ∝ 1−d)을 각주 수준으로 덧붙인다.
