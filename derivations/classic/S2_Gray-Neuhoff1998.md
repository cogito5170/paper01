## 2. 문제 설정 (원문 기호)

- **양자화기(quantizer)**(§I 식 (1), §III): k차원 입력 x를 손실 부호기(lossy encoder) α: x ↦ i ∈ 𝓘로 셀(cell) S_i = {x: α(x)=i}에 보낸다. 무손실 부호기(lossless encoder) γ: i ↦ 이진 부호어, 재생 복호기(reproduction decoder) β: i ↦ y_i가 뒤따른다. 양자화 규칙은 q(x) = β(α(x))다.
- **율(rate)**: 고정율(fixed-rate)이면 R = (1/k)log N(N = 셀 개수, 식 (3)). 가변율(variable-rate)이면 R = (1/k)E[ℓ(γ(α(X)))]이고, 흔히 출력 엔트로피 (1/k)H(q(X))로 바꿔 쓴다(§II.C).
- **왜곡(distortion)**: 제곱 오차 D = (1/k)E‖X − q(X)‖² (식 (2), §III).
- **운용 왜곡-율 함수(operational distortion-rate function)**: δ(R) = 율 R 이하인 스칼라 양자화기의 최소 왜곡(식 (4)). k차원은 δ_k(R)(§III), k차원 손실 부호기와 L차 엔트로피 부호화를 쓰면 δ_{k,L}(R)(§IV.C), 모든 차원의 하한은 δ̄(R) = inf_k δ_k(R)(식 (15), (22))이다.
- **슈넌 왜곡-율 함수(Shannon distortion-rate function)** D(R): I(X;Y) ≤ R인 시험 채널(test channel) 중 최소 E d(X,Y). 슈넌 부호화 정리에 의해 i.i.d.(독립 동일 분포) 소스에서 δ̄(R) = D(R)이다(§II.D).
- **고해상도(high resolution)**: 셀이 작아 각 셀 안에서 밀도 f가 거의 상수로 보이는 영역. 율 R이 큰 경우다(§IV).

## 4. 유도

### 4.1 Δ²/12 [원문 §IV.A ✓]
N준위 균일 양자화기 y_i = y_{i−1}+Δ, 과부하는 무시한다.
D = Σ_i ∫_{y_i−Δ/2}^{y_i+Δ/2} (x−y_i)² f(x)dx
 ≈ Σ_i f(y_i) ∫_{−Δ/2}^{Δ/2} u² du (셀 안에서 f ≈ 상수)
 = Σ_i f(y_i) Δ³/12 = (Δ²/12)Σ_i f(y_i)Δ ≈ (Δ²/12)∫f = Δ²/12.
서베이는 근사를 네 개 짚는다. (1) 과부하 무시, (2) 셀 안 밀도 상수, (3) 리만 합 ≈ 적분, (4) 다시 과부하 무시. 이 근사들은 "비가 1로 간다"는 뜻이다(엄밀판은 식 (51)).

### 4.2 베넷 적분 [원문 §IV.A ✓]
1. 셀 기여(식 (25)–(26)): D_i = (1/k)∫_{S_i}‖x−y_i‖²f ≈ f(y_i)·M(S_i,y_i)·vol(S_i)^{1+2/k}. 정규화 관성 모멘트 M은 크기와 무관하다. 크기 조절하면 분자 ∝ s^{k+2}, 분모 vol^{1+2/k} ∝ s^{k+2}이기 때문이다.
2. 점 밀도 λ(x) ≈ (N·vol(S_x))^{−1}이면 vol(S_i) ≈ 1/(Nλ(y_i))이다. 따라서 D_i ≈ N^{−2/k} f(y_i) M λ(y_i)^{−2/k} vol(S_i).
3. 합을 적분으로 바꾸면 D ≈ N^{−2/k}∫ m(x)λ(x)^{−2/k}f(x)dx이다(식 (27); m은 관성 분포 inertial profile).
4. 스칼라에서 셀 중앙에 점을 두면 m = 1/12이고, D ≈ (1/12N²)∫f/λ²이다(식 (28) = (7)). 압신기(compander) 형식 (5)는 g = dG/dx = λ, Δ = 1/N으로 둔 같은 식이다.

**적용 조건** [원문 i–iv]: 대부분 셀이 작아야 하고, 특정 점 밀도 ≈ λ, 특정 관성 분포 ≈ m, 이웃 셀 부피가 비슷해야 한다. 반례 [원문]: Δ, ½Δ, ½Δ가 번갈아 나오는 스칼라 양자화기는 실제 D = (5/96)Δ²인데 베넷 적분은 (1/27)Δ²을 준다. 베넷 적분은 점 밀도에 대해 선형이 아니기 때문이다.

### 4.3 판터-디테: 최적 점 밀도 λ ∝ f^{1/3} [원문은 결과 + "횔더 부등식(Hölder's inequality)으로도 가능"; 단계는 재구성]
제약 ∫λ = 1에서 J(λ) = ∫ f λ^{−2}를 최소화한다.
- 횔더(p=3, q=3/2): ∫ f^{1/3} = ∫ (fλ^{−2})^{1/3}·λ^{2/3} ≤ (∫fλ^{−2})^{1/3}(∫λ)^{2/3} = (∫fλ^{−2})^{1/3}.
- 따라서 J ≥ (∫f^{1/3})³이고, 등호 조건은 fλ^{−2} ∝ λ, 즉 λ* = f^{1/3}/∫f^{1/3}(식 (9))이다. 횔더를 쓰면 이것이 전역 최소임도 함께 나온다(서베이가 지적한 장점).
- N = 2^R을 넣으면 δ(R) ≈ (1/12)(∫f^{1/3})³2^{−2R} (식 (8)).

**부분 왜곡 정리** [재구성 검산]: D_i ≈ f(y_i)Δ_i³/12, Δ_i ≈ 1/(Nλ*(y_i)) ∝ f(y_i)^{−1/3}이므로 D_i ∝ f·f^{−1} = 상수.

**가우시안 값** [재구성 계산, 결과는 원문 (10) ✓]: f = (2πσ²)^{−1/2}e^{−x²/2σ²}이면
∫f^{1/3} = (2πσ²)^{−1/6}∫e^{−x²/6σ²}dx = (2πσ²)^{−1/6}(6πσ²)^{1/2}.
세제곱하면 (2πσ²)^{−1/2}(6πσ²)^{3/2} = 6πσ²·√3이다. 따라서 δ(R) ≈ (6√3π/12)σ²2^{−2R} = (√3π/2)σ²2^{−2R} ≈ 2.721σ²2^{−2R}이다.
D(R) = σ²2^{−2R} 대비 10log₁₀2.721 = 4.35 dB, 같은 D에서 율 차이는 ½log₂2.721 = 0.722 bit (서베이 "0.72 bits/sample" ✓).

### 4.4 엔트로피 근사 (11), (13) [원문 결과, 유도는 재구성]
P_i = Pr(X∈S_i) ≈ f(y_i)vol(S_i), vol(S_i) ≈ 1/Λ(y_i) (Λ = Nλ, 비정규화 점 밀도)라 하면
H(q(X)) = −ΣP_i log P_i ≈ −ΣP_i log f(y_i) + ΣP_i log Λ(y_i) ≈ h(X) + E[log Λ(X)]. (식 (13))
균일이면 Λ = 1/Δ이므로 H ≈ h(X) − log Δ (식 (11)). 벡터도 같은 꼴이고(§IV.C), k개 블록이면 식 (14)다.

### 4.5 엔트로피 제약 스칼라: 균일이 최적, 그리고 0.254 bit [원문 결과 (12), 유도는 재구성 = 서베이가 말하는 "젠센 부등식(Jensen's inequality)" 경로]
비정규화 점 밀도로 쓰면 D ≈ (1/12)E[Λ(X)^{−2}], R = H ≈ h(X) + E log Λ(X)이다.
- 젠센: E[Λ^{−2}] = E[2^{−2log Λ}] ≥ 2^{−2E log Λ} = 2^{−2(R−h(X))}.
- 따라서 D ≥ (1/12)2^{2h(X)}2^{−2R}이고, 등호는 Λ가 상수일 때, 즉 **균일 양자화기**일 때다. 이것이 식 (12)이고 δ_{1,1}(R) ≈ M₁γ₁σ²2^{−2R} (M₁ = 1/12, γ₁ = 2^{2h}/σ²)이다.

**슈넌 하한 대비 간극.** SLB는 D(R) ≥ D_SLB(R) = (1/(2πe))2^{2h(X)}2^{−2R}이다(§4.8). 비는
  δ_{1,1}/D_SLB = (1/12)/(1/(2πe)) = 2πe/12 = πe/6 ≈ 1.4233 → 1.533 dB.
같은 D에서 율 간극은 ½log₂(2πe/12) = **0.25461 bit/표본**이다. 서베이 표기 "0.255"는 반올림이고, 본 연구 표기 0.254는 버림이다. 같은 값이다.
가우시안이면 SLB = D(R)이므로(2^{2h} = 2πeσ²) 이 간극이 R(D)까지의 실제 간극이다. 가우시안에서 고정율 최적 스칼라(0.722 bit)와 비교하면 0.722 − 0.255 = 0.467 bit = 2.82 dB 이득이다(서베이 "2.82 dB or 0.47 bit" ✓).

### 4.6 로이드 조건 [원문 §III: "증명은 간단하며 미분 불필요", 단계는 재구성]
D = Σ_i ∫_{S_i}‖x−y_i‖²f(x)dx.
1. **중심 조건(centroid condition)** (분할 고정): 셀 i만 보면 E[‖X−y‖² | X∈S_i] = E[‖X−c_i‖² | S_i] + ‖c_i−y‖²이다(c_i = E[X|X∈S_i], 교차항은 E[X−c_i|S_i] = 0이라 사라짐). 최적은 y_i = c_i다.
2. **최근접 이웃 조건(nearest-neighbor condition)** (복호기 고정): D = E[‖X−β(α(X))‖²]를 점별로 최소화하면 α(x) = argmin_i‖x−y_i‖²이다(보로노이 분할 Voronoi partition). 가변율이면 라그랑주 승수 λ로 α(x) = argmin_i[d(x,y_i) + λℓ(γ(i))]이므로 최근접 부호기는 일반적으로 최적이 아니다(원문 ✓).
3. **무손실 부호** (α 고정): 이산 소스 α(X)에 대한 최적 무손실 부호(허프만 Huffman)다.
4. 세 단계를 번갈아 하는 것이 일반화 로이드 알고리즘(generalized Lloyd algorithm)이다. 매 단계 라그랑주 왜곡이 줄지 않으므로 수렴하지만, 국소 최적일 수 있다. 로그 오목(log-concave) 밀도에서는 국소 최적이 유일하다는 플라이셔(Fleischer) 결과를 서베이 §II.A가 언급한다.

**중심 양자화기 성질** [원문 결과, 검산 재구성]: q(X) = c_{α(X)}라 하면
- E q(X) = Σ P_i c_i = E X.
- E[q(X)ᵗ(q(X)−X)] = Σ P_i c_iᵗ(c_i − E[X|S_i]) = 0 (출력과 오차가 직교).
- E‖X‖² = E‖q + (X−q)‖² = E‖q‖² + E‖X−q‖² (교차항 0) ⇒ E‖q−X‖² = E‖X‖² − E‖q‖².
- E[Xᵗ(q−X)] = E[(q−(q−X))ᵗ(q−X)] = 0 − E‖q−X‖². 즉 **오차는 입력과 상관이 있다**(상관 = −MSE). "양자화 잡음은 입력과 무관"이라는 흔한 모형은 중심 양자화기에 대해 거짓이다. 이것이 디더가 필요한 이유 중 하나다(§4.10).

### 4.7 자도르·게르쇼 점근 [원문 (29)–(33), (38)–(40) ✓; 횔더 단계는 재구성]
**고정율.** 게르쇼 추측으로 m(x) ≡ M_k라 하면, ∫λ = 1에서 J = ∫fλ^{−2/k}를 최소화한다. a = k/(k+2)로 두고 횔더(p = 1/a, q = 1/(1−a))를 쓰면
∫f^a = ∫(fλ^{−2/k})^a·λ^{2/(k+2)} ≤ (∫fλ^{−2/k})^a(∫λ)^{1−a}
이다. ((λ^{2/(k+2)})^{1/(1−a)} = λ임을 확인했다.) 따라서 J ≥ (∫f^{k/(k+2)})^{(k+2)/k} = ‖f‖_{k/(k+2)}이고 λ*_k ∝ f^{k/(k+2)}이다. N = 2^{kR}이면 N^{−2/k} = 2^{−2R}이므로 δ_k(R) ≈ M_k‖f‖_{k/(k+2)}2^{−2R} = M_kβ_kσ²2^{−2R} (식 (30)).

**가우시안 i.i.d. β_k** [재구성 계산]: ∫f^a = (2πσ²)^{k(1−a)/2}a^{−k/2}. 1/a제곱 후 σ²로 나누면 β_k = 2π((k+2)/k)^{(k+2)/2}이다. k=1: 2π·3^{3/2} = 6√3π = 32.65 ✓(서베이 32.6). k→∞: 2πe = 17.08 ✓(서베이 17.1). 둘의 비 10log₁₀(32.65/17.08) = 2.81 dB가 "모양 손실(shape loss)"이다.

**가변율.** m ≡ M_k, R ≈ h_k + (1/k)E log Λ, D ≈ M_kE[Λ^{−2/k}]. 젠센으로 Λ = 상수(균일)가 최적이고 δ_{k,1} ≈ M_k2^{2h_k}2^{−2R} = M_kγ_kσ²2^{−2R}이다. L차 엔트로피 부호화면 h_{kL}로 바뀐다(식 (32)).

**차원 극한.** M_k → M̄ = 1/(2πe)(구의 정규화 모멘트 극한). i.i.d.에서 γ̄ = β̄ = 2^{2h}/σ²이다(게르쇼가 리겟 Liggett에게 공을 돌림). 그러면
- δ_{k,∞}(R) = M_kβ̄σ²2^{−2R} = (M_k/M̄)δ̄(R) (식 (39)): k차원 엔트로피 부호화 양자화는 **공간 채움 손실 M_k/M̄만** 겪는다.
- δ_{∞,L}(R) = δ̄(R) (식 (40)).
- k=1: M₁/M̄ = 2πe/12 = πe/6 → 1.53 dB = 0.2546 bit. §4.5와 같은 결론이다.

### 4.8 슈넌 하한 [서베이는 정의를 쓰지 않고 관계만 진술(§IV.I) → 유도 재구성]
**주장.** 제곱 오차에서 R(D) ≥ h(X) − ½log(2πeD), 동치로 D(R) ≥ D_SLB(R) = (1/(2πe))2^{2h(X)}2^{−2R}.
**증명.** E(X−Y)² ≤ D인 임의의 시험 채널에 대해
I(X;Y) = h(X) − h(X|Y) = h(X) − h(X−Y|Y) ≥ h(X) − h(X−Y) ≥ h(X) − ½log(2πe·E(X−Y)²) ≥ h(X) − ½log(2πeD).
(조건화는 엔트로피를 줄이고, 분산이 주어지면 가우시안이 미분 엔트로피를 최대화한다.) ∎
**k차 판**: R_k(D) ≥ h_k − ½log(2πeD), h_k = (1/k)h(X₁..X_k).
**서베이 관계 검산** [재구성]: Z̄(R) = M̄γ̄σ²2^{−2R} = (1/(2πe))2^{2h̄}2^{−2R} = D_SLB(R) ✓. D_SLB,k = (1/(2πe))2^{2h_k}2^{−2R} = Z_{k,1}(R)·M̄/M_k ✓. 가우시안이면 2^{2h} = 2πeσ²이므로 D_SLB = σ²2^{−2R} = D(R)로 등호다. 해석(원문): D_SLB,k는 "셀이 고차원 구 모양인 가상의 k차원 가변율 양자화기"의 왜곡이다.

### 4.9 구 하한 (58) [원문 결과, 검산 재구성]
반지름 r인 k-구는 V = π^{k/2}r^k/Γ(k/2+1), ∫‖x‖² = kVr²/(k+2)이다. 따라서 M_sphere = r²/((k+2)V^{2/k}) = Γ(k/2+1)^{2/k}/(π(k+2))이다. 같은 부피에서 구가 2차 모멘트를 최소화하므로 M_k ≥ M_sphere(k)이고, 이는 (58)과 같은 식이다(2π^{k/2}/(kΓ(k/2)) = π^{k/2}/Γ(k/2+1)). k=1: 1/12, k=2: 1/(4π) = 0.0796, k=24: 0.0648, k→∞: 1/(2πe).

### 4.10 디더 [원문 §V.E ✓ + 재구성]
- **정의** [원문]: U_n = X_n + W_n을 양자화한다(W: X와 독립인 i.i.d. 디더). 감산(subtractive)이면 X̂ = q(X+W) − W (로버츠 Roberts), 비감산(nonsubtractive)이면 X̂ = q(X+W)다.
- **슈크만 정리** [원문 진술]: e = X − q(X+W) + W가 (−Δ/2, Δ/2)에서 균일이고 X와 독립 ⇔ 과부하가 없고 디더 특성함수 M_W(ju) = E e^{juW}가 M_W(j2πl/Δ) = 0 (l ≠ 0)을 만족. 균일 디더 W ~ Unif(−Δ/2,Δ/2)는 M_W(ju) = sin(uΔ/2)/(uΔ/2)이므로 u = 2πl/Δ에서 sin(πl) = 0이 되어 조건을 만족한다. [검산 재구성] 또 슈크만 조건이면 오차열 {e_n}이 독립이다(Jayant–Rabiner, Sripad–Snyder, 원문).
- **충분성 스케치** [재구성]: x를 고정하면 e = (x+W) − q(x+W)를 Δ를 법으로 본 값이다. W ~ Unif이면 x+W mod Δ는 x와 무관하게 균일이다(평행 이동 불변). 따라서 e의 분포는 x와 무관한 Unif(−Δ/2,Δ/2)이고 e ⊥ X다.
- **비감산** [원문]: 오차를 입력과 독립으로 만들 수 없다. k차 모멘트를 조건부 독립으로 만드는 필요충분 조건은 알려져 있고, 충분조건은 "W가 균일 k개의 합"이다. 대가로 k=2이면 E[ε²|X] = E[ε²] = E[W²] + Δ²/12이다. 균일 디더 2개 합이면 E[W²] = Δ²/6이므로 총 MSE가 Δ²/4로 Δ²/12의 3배가 된다. [수치는 재구성]
- **지브** [원문 인용]: 고해상도 없이도 디더 균일 스칼라 + 무손실 벡터 부호화로 R(D)에서 0.75 bit/기호 이내다. 격자 확장은 자미르-페더 [565].

### 4.11 가우시안 고정율 균일의 점근 [원문 §IV.H ✓, 해석 재구성]
후이-노이호프: Δ_N/(4σ√(ln N)/N) → 1, D_N/((4/3)σ²(ln N)/N²) → 1, 그리고 과부하 왜곡은 점근적으로 무시된다. 그래서 SNR ≈ 6.02R − 10log₁₀R이고 "균일 스칼라 고정율은 점근적으로 나쁘다". [재구성] 율로 바꾸면 log N ≈ ½log₂(σ²/D_N) + ½log₂((4/3)ln N)이고, 둘째 항이 R과 함께 천천히(log log) 커진다.

## 6. 원문과의 차이·빈틈

1. **슈넌 하한 공식이 서베이에 명시되어 있지 않다.** "Z̄(R)는 슈넌 하한과 정확히 같다"는 관계만 있다(§IV.I). §4.8의 SLB 정의와 증명은 [재구성]이다.
2. **횔더·젠센 최적화 단계**는 서베이가 "가능하다/[193], [222]"라고만 하므로 §4.3, §4.5, §4.7은 [재구성]이다. 결과식은 원문과 일치한다.
3. **식 (14) 표기.** 이미지로는 "H(q(X₁),…,q(X_k)) ≅ h(X₁,…,X_k) − log Δ"로 보인다. 각 성분이 폭 Δ로 양자화되므로 일관된 식은 −k log Δ다(벡터 셀 부피가 Δ^k). 원문 오식이거나 정규화 표기 차이로 본다. [미확인: 지시-피어스 원 논문 대조 필요]
4. **슈크만 정리의 "비감산" 표기 혼선.** §V.E는 "비감산 디더의 주된 이론적 성질은 슈크만이 정립"이라고 쓰면서, 바로 다음 식으로 e_n = X_n − q(X_n+W_n) + W_n을 든다. 이것은 **감산 디더의 총 오차**(= 양자화기 자체 오차 q(U)−U의 부호 반전)다. 슈크만 1964가 다룬 것은 "양자화기 입력 X+W에 대한 양자화기 오차"가 X와 독립인 조건이다. 이것은 감산식으로 쓰면 총 오차가 되고, 비감산 출력 q(X+W)에서는 오차가 W를 포함하므로 독립이 아니다. 서베이 스스로 같은 절에서 "비감산 디더는 재구성 오차를 입력과 독립으로 만들 수 없다"고 쓴다. **SURVEY.md 6번(Schuchman) 항목의 "비감산 디더다(Gray-Neuhoff 설명)"는 서베이의 이 혼선을 그대로 옮긴 것이다.** 본 연구에서 쓸 사실(감산 디더 → 균일·독립 오차)은 슈크만 조건 자체에서 나온다. 슈크만 원문 대조가 필요하다.
5. **0.255 vs 0.254.** 정확한 값은 0.25461 bit. 서베이는 0.255(반올림), 본 연구와 SURVEY.md 218행은 0.254(버림)다. 모순은 아니지만 표기를 통일하는 편이 좋다.
6. **고해상도 근사의 엄밀성 공백**(원문 §IV.H 끝): 식 (11)의 유한 준위 판, 식 (13)의 일반 점 밀도 판, 3차원 이상 게르쇼 추측, DPCM은 엄밀 증명이 없다. 본 연구의 정리 B가 (11)/(13)형 근사를 쓰면 같은 공백을 물려받는다.
7. **SURVEY.md 7번 항목과의 대조**: "1.53 dB(0.255 bit/표본), 블록 엔트로피 부호화로 기억 있는 소스에서도 1.53 dB 이내, Ziv 1985 재발견"은 원문과 일치한다. "Schuchman의 비감산 디더는 독립 조건을 줌"은 위 4번의 혼선을 따른 서술이다.

## 7. 본 연구와의 연결

본 연구 설정: K명, X_k ~ N(0,σ²) 독립, Q_k = f_k(X_k,W) ∈ ℤ_M, 스위치 Z = ΣQ_k mod M, 복호기 Ŝ = g(Z,W), D̄ = E(S−Ŝ)²/(Kσ²).

### 7.1 정리 B는 서베이 식 (39)의 k=1 사례다 [재구성]
- 작업자 k가 감산 디더 균일 양자화를 한다고 하자. λ_k = Δ·round((X_k+U_k)/Δ), U_k ~ Unif(−Δ/2,Δ/2) 독립(W의 일부). 그러면 λ_k − U_k = X_k + E_k이고, E_k는 i.i.d. Unif(−Δ/2,Δ/2), X와 독립이다(§4.10 슈크만).
- 합: Σλ_k − ΣU_k = S + ΣE_k. 오차 분산은 KΔ²/12이므로 D̄ = (KΔ²/12)/(Kσ²) = Δ²/(12σ²)이다. (MMSE 축소 계수는 고해상도에서 무시한다.)
- M이 Σλ_k의 퍼짐을 덮을 만큼 크면 Z ↔ Σλ_k가 일대일이다. 고해상도 근사 (11)/(52)를 격자값 확률변수 Σλ_k ∈ Δℤ에 적용하면 H(Z|W) ≈ h(S + ΣE) − log₂Δ ≈ h(S) − log₂Δ = ½log₂(2πeKσ²/Δ²) = ½log₂(K/D̄) + ½log₂(2πe/12)이다. **0.254는 식 (39)의 M₁/M̄ = πe/6**, 즉 구간 셀의 공간 채움 손실이다. 판터-디테식 점 밀도 손실이나 직사각형 손실과는 무관하다.
- 이 유도는 h(S+ΣE) ≈ h(S)(고해상도)와 "H(Σλ|W) ≈ h − log Δ"(합 변수에 대한 (11)형 근사)를 쓴다. 후자는 서베이 범위 밖의 [재구성]이다.

### 7.2 스위치 합 제약이 균일(격자) 양자화를 강제한다 [재구성]
- 베넷의 압신기 형식(식 (5)) q = G^{−1}(q_u(G(x)))는 비선형 G 때문에 합과 호환되지 않는다. 작업자별 압신 출력의 합은 합의 압신 출력이 아니다. 판터-디테 최적 점 밀도 λ ∝ f^{1/3}(식 (9))는 개별 X_k에 대해서는 최적이지만, 스위치가 더한 결과 Z에서 Ŝ를 뽑을 구조를 주지 않는다.
- 군 덧셈과 호환되는 양자화는 사실상 **격자(균일) 양자화 + 잉여류 라벨**이다(Forney 노트 §7.1–7.2). 그런데 서베이에 따르면 엔트로피 부호화를 쓰면 고해상도에서 균일이 최적이다(식 (12), (39)). 따라서 엔트로피 율(H(Z)) 기준으로는 **합 호환 제약이 셀 모양 말고는 비용을 더하지 않는다**. 남는 손실은 공간 채움(0.254, d차원 격자면 ½log₂(2πeG_d))뿐이다.
- 고정율(log₂M) 기준에서 스칼라 ℤ_M은 후이-노이호프형 과부하(여기서는 mod-M 감김 wrap-around) 비용을 진다. 대략 log₂M ≈ ½log₂(K/D̄) + ½log₂(2πe/12) + ½log₂(c·ln M)꼴로, 상수가 아니라 log log로 커진다. 정확한 계수는 감김 오차 MSE의 계산이 필요하다. [재구성, 대략, 미검증]

### 7.3 0.254 상수는 블록 부호(d→∞)로 0까지 줄일 수 있다 [재구성]
- d차원 미세 격자 Λ_f로 바꾸면 §7.1과 같은 계산에서 상수가 ½log₂(2πe·G(Λ_f))가 된다. 서베이 식 (39): δ_{k,∞} = (M_k/M̄)δ̄. E₈ 0.146, Λ₂₄ 0.084, 구 하한 기준 k=24에서 0.073, d→∞이면 0 (M_k → 1/(2πe), 자미르-페더 [564]).
- 즉 블록 부호의 "공간 채움 이득 1.53 dB = 0.254 bit"는 정리 B 상수를 통째로 없앨 수 있는 양이다. 그렇다면 H(Z)/d → ½log₂(K/D̄)가 되고, 이는 정리 A 가설에서 c = 0인 경우와 맞물린다.
- 고정율(log₂M)로도 같은 극한을 얻으려면 굵은 격자 Λ_c가 S + ΣE(차원당 분산 ≈ Kσ²)를 높은 확률로 덮어야 한다. 서베이 §IV.F의 AEP(점근적 등분배 성질) 논증, 곧 고차원 가우시안이 얇은 구각(shell)에 몰린다는 사실이 이를 정당화한다. 고정율과 가변율이 고차원에서 같아지는 이유가 바로 이것이다(원문 2352쪽 ✓). 결과는 R ≈ ½log₂(K/D̄) + ½log₂(2πeG(Λ_f)) + (굵은 격자 덮기 손실)이다(Forney 노트 §7.3).

### 7.4 정리 A(하한)에 대해 이 서베이가 주는 것과 주지 않는 것 [재구성]
- **주는 것**: 중앙집중 SLB. S ~ N(0,Kσ²), 목표 MSE D̄Kσ²이므로 H(Z) ≥ I(Z;S|W) ≥ R_S(D̄Kσ²) ≥ h(S) − ½log₂(2πeD̄Kσ²) = ½log₂(1/D̄)이다. (W ⊥ S이므로 I(Z,W;S) = I(Z;S|W) 경로를 쓴다.)
- **주지 않는 것**: ½log₂K 몫. 정리 B의 ½log₂(K/D̄)와 SLB의 ½log₂(1/D̄)의 차이 ½log₂K는 "작업자 오차가 독립이라 분산이 K배로 쌓인다"는 데서 온다. 공유 난수 W로 작업자 오차를 음의 상관으로 만들어 상쇄할 수 없음을 보이는 것이 정리 A의 핵심 난점이다. 서베이의 단일 부호기 이론(고해상도, SLB, 로이드)으로는 이 몫을 얻을 수 없다. SURVEY.md 219행의 "단일 사용자 양자화 비용이므로 Δ_compat 비교에서 상쇄/분리 항일 가능성"이라는 추정과 같은 방향이다. 0.254는 분리 가능한 셀 모양 항이고, K 몫이 합 호환 비용이다.
- 정리 A의 상수 c에 대한 시사: 블록 부호가 c = 0 근방까지 갈 수 있으므로(§7.3), 가설이 참이라면 가장 빡빡한 형태는 c = 0일 것이다. 스칼라(d=1) 한정이면 c를 −0.254(엔트로피 기준)나 그보다 나쁜 값(고정율)으로 둘 수 있다. [추측]

### 7.5 디더 관련 실무 사실 [원문 §V.E + 재구성]
- 본 연구의 W는 복호기도 아는 공유 난수이므로 **감산 디더**를 쓸 수 있다. 서베이가 말하는 감산 디더의 실무 난점(복호기의 디더 사본, 동기)은 공유 난수 가정으로 사라진다.
- 비감산으로 하면 디더 전력이 MSE에 더해진다(E[ε²] = E[W²] + Δ²/12). 균일 디더 하나면 MSE가 2배, 곧 율 +0.5 bit다. 감산이 필수다.
- 작업자마다 독립 디더 U_k를 주면 E_k가 서로 독립이다(슈크만 + 독립성). 오차 합 ΣE_k는 어윈-홀(Irwin–Hall) 분포로, 균일이 아니다. 고차원 격자에서는 각 E_k가 백색에 가깝고 차원이 커지면 가우시안에 가까워진다(원문 §IV.I, 자미르-페더 [564]). 그러면 굵은 격자 설계에서 "S + ΣE를 가우시안으로 보고 덮기"가 정당화된다.
