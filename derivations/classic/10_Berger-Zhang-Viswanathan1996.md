# 10. Berger–Zhang–Viswanathan — CEO 문제 (유도 노트)

## 1. 서지

- T. Berger, Z. Zhang, H. Viswanathan, "The CEO Problem," *IEEE Transactions on Information Theory*, vol. 42, no. 3, pp. 887–902, 1996년 5월.
- 원본 파일: `papers/classic/10_Berger-Zhang-Viswanathan1996.pdf` (16쪽). 원고 접수 1994.12.12, 수정 1995.11.5.
- 텍스트 추출본은 수식이 대부분 깨지므로 모든 식을 쪽 이미지(887–902쪽)로 대조했다.
- 표기 규칙: [원문] = 원문 증명을 따름, [재구성] = 원문이 생략했거나 낡은 기법이라 현대 표준 증명으로 보충, [미확인] = 확인 못 함. 부록 A(가우시안 CEO)는 **이 논문이 아니라 이후 문헌**의 결과다.

## 2. 문제 설정 (원문 기호)

**소스와 관측** (식 (1)). 시간에 대해 무기억인 {X(t), Y₁(t), …, Y_L(t)}_{t≥1}, 순간 결합 분포
Pr(x, y₁, …, y_L) = p(x) ∏_{i=1}^L W(y_i|x).
X(t) ∈ 𝒳 (유한), Y_i(t) ∈ 𝒴 (공통 유한 알파벳), W는 𝒳×𝒴 위의 확률 행렬. 관측들은 X가 주어지면 조건부 독립이고, 모든 에이전트(agent)의 관측 품질이 같다(교환 가능, exchangeable).

**부호.** 에이전트 i는 자기 관측 블록 y_iⁿ = [y_i(1),…,y_i(n)]만 보고 부호 C_i^{(n)}의 부호어를 고른다. 율 R_i^{(n)} = (1/n) log₂|C_i^{(n)}|. 에이전트끼리 회의(convene)할 수 없다. CEO(Chief Executive / Central Estimation Officer)는 사상 Φ_L^{(n)}: C₁^{(n)}×…×C_L^{(n)} → 𝒳ⁿ (식 (3))으로 X̂ⁿ = Φ_L^{(n)}[C₁^{(n)},…,C_L^{(n)}] (식 (4))을 낸다.

**성능.**
- 기대 기호 오류 빈도 (식 (2)): P_e^{(n)} = (1/n) E d_H(Xⁿ, X̂ⁿ) (d_H: 해밍 거리).
- 총율(sum rate) R = Σ_{i=1}^L R_i^{(n)}.
- 주어진 부호에 대한 최소 오류 (식 (5)): P_e^{(n)}[C₁,…,C_L] = min_Φ (1/n) E d_H(Xⁿ, Φ(…)).
- P_e^{(n)}(L,R) = min_{Σ R_i^{(n)} ≤ R} P_e^{(n)}[C₁,…,C_L] (식 (6)), P_e(L,R) = lim_{n→∞} P_e^{(n)}(L,R) (식 (7)), P_e(R) = lim_{L→∞} P_e(L,R) (식 (8)).
- 감쇠율 (식 (9)): α(p,W) = lim_{R→∞} [−log₂ P_e(R)] / R.

**극한의 순서.** 먼저 n→∞, 다음 L→∞, 마지막으로 R→∞.

**Theorem 1 (원문 식).** X, Y는 p_{X,Y}(x,y) = p(x)W(y|x)인 확률변수, J는 (X,Y)와 독립인 보조 확률변수로 분포 P_J(j), 알파벳 크기 |𝒥| = C(|𝒳|,2) + 2. 𝒰는 크기 |𝒰| = [C(|𝒳|,2) + |𝒴|]|𝒥| + 1인 알파벳, Q(u|y, J=j)는 𝒰 위의 임의의 조건부 분포,
Q̃(u|x, J=j) = Σ_y W(y|x) Q(u|y, J=j).
그러면 (D(·‖·): 쿨백–라이블러 발산(Kullback–Leibler divergence))
α(p,W) = max_{Q, P_J} [ min_{x₁,x₂∈𝒳} E D[Q̃_{λ,J} ‖ Q̃(u|x₁,J)] ] / I(Y; U | X, J)   (식 (10))
여기서
- E D[Q̃_{λ,J}‖Q̃(u|x₁,J)] = Σ_j P_J(j) D[Q̃_{λ,j} ‖ Q̃(u|x₁,j)],
- 기울인 분포(tilted distribution) Q̃_{λ,j}(u) = Q̃^{1−λ}(u|x₁,j) Q̃^λ(u|x₂,j) / Δ_λ(x₁,x₂|j), Δ_λ(x₁,x₂|j) = Σ_u Q̃^{1−λ}(u|x₁,j) Q̃^λ(u|x₂,j),
- λ = λ(x₁,x₂)는 E D[Q̃_{λ,J}‖Q̃(u|x₁,J)] = E D[Q̃_{λ,J}‖Q̃(u|x₂,J)]가 되도록 고른다.
동치형 (식 (11)):
α(p,W) = max_{Q,P_J} [ min_{x₁,x₂} sup_λ E[−log Δ_λ(x₁,x₂|J)] ] / I(Y;U|X,J).
(min은 x₁ ≠ x₂인 쌍 위에서 — x₁ = x₂면 분자가 0이 되므로 의도상 서로 다른 쌍이다. 원문 (27)은 p(x₁),p(x₂) ≠ 0도 명시.)

## 4. 유도

### 4.0 미리 보기: 왜 "율당 지수"인가 [재구성 요약]

직접부의 구조는 다음 한 줄로 요약된다. 각 에이전트가 시험 채널 Q(u|y)로 자기 관측을 "잡음 섞인 양자화" U_i로 바꾸고 율 I(Y;U|X)로 보낸다. CEO는 U₁,…,U_L을 거의 정확히 복원하고, 이를 X에 대한 L개의 독립 관측(채널 Q̃(u|x))으로 보고 가설 검정을 한다. 그러면 오류 ≈ 2^{−L·β(Q)}, 총율 R ≈ L·I(Y;U|X)이므로 −log P_e/R ≈ β(Q)/I(Y;U|X). 역정리는 임의의 부호가 이보다 나을 수 없음을 보인다.

### 4.1 Proposition 1: 부호화 없는 L-표본 다중 가설 검정 [재구성 — 원문 생략]

n = 1, 각 에이전트가 Y_i를 그대로 보낸다. 결정 규칙은 𝒴^L의 분할 {𝒰_x}, 오류 P_e = Σ_x p(x) W^L(𝒰_xᶜ|x) (식 (12)), β(p,W) = lim_L max −(1/L) log P_e (식 (13)).

**두 가설 (원문 (14)–(21)의 내용).** W₁ = W(·|x₁), W₂ = W(·|x₂). 체르노프 정보(Chernoff information)
C(W₁,W₂) ≜ max_{0≤λ≤1} −log Δ_λ, Δ_λ = Σ_y W₁^{1−λ}(y) W₂^λ(y).
- d/dλ(−log Δ_λ) = D(W_λ‖W₂) − D(W_λ‖W₁) (W_λ ∝ W₁^{1−λ}W₂^λ, 식 (16)); 2차 도함수 = −Var_{W_λ}[log(W₁/W₂)] ≤ 0이므로 −log Δ_λ는 λ에 대해 오목. 최대점은 D(W_λ‖W₁) = D(W_λ‖W₂) (식 (19)) — 이때 C = D(W_λ‖W₁).
- 상계(달성): 우도비 검정 Σ_i log(W₁(Y_i)/W₂(Y_i)) ≷ 문턱. MAP 규칙의 베이즈 오류는 Σ_{y^L} min(p(x₁)W₁^L, p(x₂)W₂^L) ≤ p(x₁)^{1−λ}p(x₂)^λ Δ_λ^L (min(a,b) ≤ a^{1−λ}b^λ)이고, λ에 대해 최적화하면 지수 C.
- 하계: 임의의 규칙에서 두 오류 중 적어도 하나는 2^{−L·D(W_λ‖W_k) − o(L)} 이상 (원문 (17),(18): W_λ^L 아래에서 전형인 집합이 𝒰_{x₁} 또는 𝒰_{x₂}에 절반 이상 들어가야 함 + 발산의 변화 측도 논증).
- 따라서 베이즈 오류의 지수 = C(W₁,W₂). 사전 확률 p는 지수에 영향 없음 (p(x)>0이면).

**다중 가설.** P_e ≥ max_{x₁≠x₂} [p(x₁)+p(x₂)]·(쌍 {x₁,x₂}의 최소 베이즈 오류) (다른 가설을 고르는 경우를 오류에 넣으면 커질 뿐) ⇒ 지수 ≤ min 쌍 C. 거꾸로 최대 사후 확률(MAP) 규칙의 오류 ≤ Σ_{x₁≠x₂} (쌍별 오류) (합집합 한계, 항 수는 L과 무관) ⇒ 지수 ≥ min 쌍 C. ∴ β(p,W) = min_{x₁≠x₂} C(W(·|x₁), W(·|x₂)) — 원문 (22)와 일치. 원문 주석: β는 p에 의존하지 않지만 부호화가 있으면 총율이 p에 의존하므로 α는 p에 의존한다.

### 4.2 Lemma 1의 직접부 증명 [원문, 단계 풀이]

X → Y → U (조건부 분포 Q(u|y)), Q̃(u|x) = Σ_y W(y|x)Q(u|y) (식 (25)), I(W,Q|p) ≜ I(Y;U|X) (식 (26)), β(Q) = min_{x₁,x₂: p>0} D[Q̃_λ‖Q̃(·|x₁)] (식 (27)–(30)): Q̃(·|x)를 관측 채널로 하는 Proposition 1의 값.

**(a) 무작위 부호 구조 (식 (41)–(46)).** 각 에이전트 i에 대해 독립·동일하게:
- 부호책 C_i^{(n)} = {c_i(1),…,c_i(M)}, M = ⌈2^{nI(Y;U)+nδ}⌉, 각 부호어 ~ Qⁿ(uⁿ) (U의 주변 분포의 곱).
- 상자(bin) B_i = {b_i(1),…,b_i(N)}, N = ⌈2^{n[I(Y;U|X)+2δ]}⌉; 각 부호어를 독립·균등하게 상자에 배정.
- **에이전트당 율 = (1/n) log N ≈ I(Y;U|X)**, 총율 R = L·I(Y;U|X). 원문 주석: L이 크면 에이전트당 율은 작게 유지되며 은밀성(clandestine)에 유리.

**(b) 부호화 규칙 (식 (47)).** 관측 y_iⁿ의 형(type) t에 대해 조건부 전형 결합형 s(t)를 정하고, 조건부 형 클래스 Λ_{s[t(y_iⁿ)]}(U|y_iⁿ)와 부호책의 교집합에서 하나를 균등하게 골라 그 상자 번호를 보낸다. 교집합이 비면(Case 1) 0을 보낸다.

**(c) 복호 규칙 (식 (48)–(54)).** 받은 상자들의 곱 B = b₁×…×b_L에서 집합
𝒯(𝒰ⁿ) = {u^{nL} ∈ T_ε^{(nL)}(U) : ∃ x^{nL} ∈ 𝒮(𝒳ⁿ) s.t. (x^{nL}, u^{nL}) ∈ T_ε^{(nL)}(X,U)}
(𝒮(xⁿ) = (xⁿ,…,xⁿ): 같은 소스 단어를 L번 반복, 식 (49)–(51))
과의 교집합이 정확히 한 원소면 그것을 복원된 초부호어(super-codeword)로 선언, 아니면 오류.

**(d) 추정 규칙 (식 (55)–(58)).** 각 시각 t에서 u^L(t) = [u₁(t),…,u_L(t)]에 대해 p(x)∏_i Q̃(u_i(t)|x)를 최대화하는 x를 고른다 — 부호화 없는 문제의 MAP 규칙을 문자별로 적용.

**(e) 부호화 오류 (식 (59)–(65)).** 𝓔₁(i) = {Y_iⁿ 비전형}: Pr ≤ 2^{−nγ} (식 (62)). 𝓔₂(i) = {교집합이 빔}: 조건부 형 클래스의 Qⁿ 확률 ≥ 2^{−n[I(Y;U)+μ]} (식 (63)), 부호어 M개가 독립이므로
Pr[𝓔₂] ≤ (1 − 2^{−n[I(Y;U)+μ]})^M ≤ exp(−2^{n(δ−μ)}) (식 (64)) — δ > μ면 이중 지수적. 합집합 한계로 P_ee < 2L·2^{−nγ} (식 (65)).

**(f) 복호 오류 (식 (66)–(79)).**
- 𝓔₃ = {[𝒮(Xⁿ), Ũ^{nL}] 비전형}: (Y_iⁿ, Ũ_iⁿ)가 전형(부호화 규칙)이고 (Xⁿ, Y_iⁿ)가 확률 ≥ 1−2^{−nγ}로 전형 (식 (69)–(72)). **마르코프 보조정리 (Lemma 2)**: X → Y → U이므로 전형인 (𝒮(Xⁿ), Y^{nL})와 (Y^{nL}, Ũ^{nL})에서 (𝒮(Xⁿ), Ũ^{nL})이 확률 1−2^{−nLν}로 전형. ⇒ Pr(𝓔₃) ≤ L2^{−nγ} + 2^{−nLν} (식 (73)).
- 𝓔₄ − 𝓔₃ = {B 안에 𝒯(𝒰ⁿ)에 속하는 다른 초부호어가 있음}:
 |𝒯(𝒰ⁿ)| ≤ |T_ε(X)| · max |T_ε(U|x^{nL})| ≤ 2^{nH(X)+nε}·2^{nL[H(U|X)+2ε]} ≤ 2^{nL[H(U|X)+4ε]} (**L ≥ H(X)/ε일 때**, 식 (74)).
 한 원소가 초부호책의 원소일 확률 ≤ 2^{−nL[H(U)−ε]}M^L ≤ 2^{−nL[H(U|Y)−δ−ε]} = 2^{−nL[H(U|Y,X)−δ−ε]} (마르코프로 H(U|Y) = H(U|Y,X), 식 (75)).
 ⇒ 𝒯 안의 초부호어 수의 기대값 ≤ G = 2^{nL[I(Y;U|X)+δ+5ε]} (식 (76)). 각각이 받은 초상자 B에 들어갈 확률 N^{−L} = 2^{−nL[I(Y;U|X)+2δ]}.
 ⇒ E|(B − {Ũ^{nL}}) ∩ 𝒯| ≤ 2^{−nL(δ−5ε)} (식 (77)), ε < δ/6이면 지수 감소 (식 (78)).
- P_de ≤ L2^{−nγ} + 2^{−nLμ} + 2^{−nL(δ−5ε)} = 2^{−nσ} (식 (79)).

[재구성] **왜 상자 율이 I(Y;U|X)면 충분한가.** Berger–Tung식 분산 부호화의 총율 조건은 Σ R_i ≥ I(Y^L; U^L)이다. 관측의 조건부 독립과 U_i − Y_i − X로
I(Y^L;U^L) = I(X,Y^L; U^L) = I(X;U^L) + I(Y^L;U^L|X) = I(X;U^L) + Σ_i I(Y_i;U_i|X) ≤ H(X) + L·I(Y;U|X).
즉 에이전트당 I(Y;U|X) + H(X)/L이면 되고, 원문의 "L ≥ H(X)/ε" 조건이 정확히 H(X)/L 항을 여유분 δ 안에 넣는 역할을 한다. 공통 원인 X의 엔트로피를 L명이 나누어 내는 셈이다.

**(g) 오류 빈도 (식 (80)–(96)).** 사건 𝓔₅(t) = {X̂(t) ≠ X(t)}, 𝓔₆(상자 0 수신), 𝓔₇(복호 오류), 𝓔₈(비전형), 𝓔₉(결정 영역 밖)로 나누어
P_e^{(n)} ≤ 1 + P_de + P_ee + Pr[∪𝓔₈(i)] − Σ_x p(x) Q̂^{(L)}(𝒰_x^L|x) + O(L/n) (식 (95)).
핵심은 (89)–(94): 부호화 규칙이 조건부 형 클래스에서 **균등하게** 고르므로, 고정된 y_iⁿ에서 Ũ_iⁿ의 분포는 1/|Λ_s(U|y_iⁿ)| (상자 0 보정 제외)이고, 그 단일 좌표 주변 분포는 Q̂[u(1)=b|y(1)=a] = s_{ab}/t_a = Q(b|a) + O(1/n) (식 (94)). 따라서 (Xⁿ, Ũ^{nL})의 좌표별 분포가 p(x)∏Q̃(u_i|x) + O(1/n)에 수렴하고
lim_n min P_e^{(n)} ≤ 1 − Σ_x p(x) Q̃^{(L)}(𝒰_x^L|x) (식 (96)),
즉 **부호화 문제의 오류 = 관측 채널 Q̃를 쓰는 부호화 없는 L-표본 문제의 오류**. Proposition 1을 Q̃에 적용하면 오류 ≈ 2^{−Lβ(Q)}, 총율 R = L(I(Y;U|X)+2δ) ⇒ −log P_e/R → β(Q)/I(Y;U|X). Q에 대해 최대화하면 Lemma 1. ∎

**극한 순서에 대한 원문 주석 (894쪽).** 증명에서는 L과 R이 비율 I(Y;U|X)를 고정한 채 함께 커지지만, 정리는 L→∞ 후 R→∞다. 큰 L, R에서 고정 비율로 달성되는 오류는 L이 이미 발산한 상태에서도 달성되므로 γ는 lim_R −R⁻¹ lim_L log₂ P_e(R,L)의 하계다. [재구성 보충] 이것은 P_e(L,R)가 L에 대해 비증가(추가 에이전트는 율 0으로 아무것도 안 보내면 됨)이기 때문이다. 같은 이유로 (8)의 극한은 존재한다.

### 4.3 Lemma 3: 발산형 = 체르노프형 [원문]

Δ_λ = Σ_u Q̃^{1−λ}(u|x₁)Q̃^λ(u|x₂).
- d/dλ(−log Δ_λ) = −E_{Q̃_λ}[log(Q̃(u|x₂)/Q̃(u|x₁))] = D[Q̃_λ‖Q̃(u|x₂)] − D[Q̃_λ‖Q̃(u|x₁)].
- d²/dλ²(−log Δ_λ) = −E_{Q̃_λ}[log²(Q̃₁/Q̃₂)] + (E_{Q̃_λ}[log(Q̃₁/Q̃₂)])² ≤ 0 ⇒ 오목, 유일 최대점은 두 발산이 같은 곳 (식 (97)).
- 항등식: D[Q̃_λ‖Q̃(u|x₁)] = E_λ[log(Q̃₁^{1−λ}Q̃₂^λ/(Δ_λQ̃₁))] = λ{D[Q̃_λ‖Q̃₁] − D[Q̃_λ‖Q̃₂]} − log Δ_λ. 최대점에서 첫 항이 0 ⇒ D[Q̃_λ‖Q̃₁] = sup_{λ′} −log Δ_{λ′} (식 (98)). ∎
이로써 (10)과 (11)이 같다(J가 있으면 λ를 j들에 공통으로 두고 같은 계산을 Σ_j P_J(j)(·)에 적용).

### 4.4 보조 알파벳 기수 (II-E절) [원문 개요]

Δ_λ = p(x₁)^{−1+λ}p(x₂)^{−λ} Σ_u P(u) Q̃^{1−λ}(x₁|u) Q̃^λ(x₂|u)로 다시 쓰면 보존해야 할 양이 (1) Q(y) = Σ_u P(u)P(y|u)의 |𝒴|−1개 (이것이 H(Y)와 p(x) 보존을 함께 줌), (2) H(X|U) − H(Y|U) 1개, (3) 최적 λ*(x₁,x₂)에서의 Δ_{λ*} C(|𝒳|,2)개. 서포트 보조정리(support lemma, Csiszár–Körner [17])에 한 글자를 더해 |𝒰| ≤ C(|𝒳|,2) + |𝒴| + 1. 줄인 분포에서 λ*가 움직일 수 있으나 sup_λ ≥ (λ* 고정값)이므로 비율이 줄지 않는다 — γ_M ≤ γ_{M′}.
[불일치] Lemma 1 진술은 "C(|𝒳|,2) + |𝒴| − 1이면 충분"이라 쓰고, II-E절 본문과 (99) 앞 문장은 C(|𝒳|,2) + |𝒴| + 1을 유도한다. 본문 유도를 따르면 +1이 맞다.

### 4.5 Theorem 1 직접부: γ에서 α로 — 에이전트 전문화 (II-F절) [원문 개요]

α는 γ와 달리 보조 변수 J가 분자·분모 기대값 안에 있다. 구성: 𝒥 위 분포 P_J, 각 j에 시험 채널 Q_j(u|y). Σ L_j = L, |L_j − LP_J(j)| < 1인 정수로 에이전트를 S_j 집단에 배정하고 집단 j는 Q_j로 부호책을 만든다(율 I(Y;U_j|X)). 추정 규칙의 곱 ∏_i가 ∏_j∏_{i∈S_j}로 바뀌는 것 외에 II-C, II-D의 분석이 그대로 간다. 서로 다른 j의 관측이 섞인 L-표본 가설 검정의 체르노프 지수는 공통 λ에 대해 Σ_j L_j(−log Δ_λ(x₁,x₂|j))의 sup이므로 에이전트당 E[−log Δ_λ(·|J)], 에이전트당 율 E_J I(Y;U|X,J=j) = I(Y;U|X,J) ⇒ (11).

**원문의 중요한 관찰.** "공통 혼합 변수 U(각 에이전트가 무작위로 j를 고름)"로는 α에 도달하지 못한다: 무작위 배정의 통계적 요동 때문에 분자의 E[−log Δ_λ]가 −log E[Δ_λ]로 바뀌고 옌센에 의해 엄격히 작다. **결정적으로 배정된 전문가(dedicated specialists)** 가 필요하다. 각 쌍 (x₁,x₂)를 구별하는 데 특화된 집단을 두는 것 — 그래서 |𝒥| 한계에 C(|𝒳|,2)가 나온다(Tsitsiklis의 분산 검출 결과와 같은 수).

**J의 기수.** 서포트 보조정리로 (1) Σ_j P_J(j) log Δ_{λ*}(x₁,x₂|j) (C(|𝒳|,2)개), (2) I(Y;U|X,J) (1개)를 보존 + 1 ⇒ |𝒥| ≤ C(|𝒳|,2) + 2. 각 j당 |𝒰|에 C(|𝒳|,2) + |𝒴|개 + 1 ⇒ |𝒰| ≤ [C(|𝒳|,2) + |𝒴|]|𝒥| + 1 (Theorem 1의 크기). 원문 스스로 이 상한은 C(|𝒳|,2) + |𝒴| + 1로 좁힐 수 있을 것이라고 적는다.

[재구성] **|𝒳| = 2이면 α = γ.** 쌍이 하나뿐이므로 분자는 sup_λ Σ_j P_J(j) f_j(λ) ≤ Σ_j P_J(j) sup_λ f_j(λ), 그리고 Σ_j P_j a_j / Σ_j P_j b_j ≤ max_j a_j/b_j. 따라서 J를 결정적으로 두는 것이 최적. 전문화는 |𝒳| ≥ 3에서만 이득일 수 있다.

### 4.6 Theorem 1 역정리 (III절) [원문, 단계 풀이]

**지니(genie) 도움.** CEO를 n개의 추정기 O_t(t번째 기호 추정)로 보고, O_t에게 X̃_t ≜ [X(1),…,X(t−1),X(t+1),…,X(n)]과 함께, 참값이 x₁일 때 𝒳−{x₁}에서 균등하게 뽑은 x₂를 알려 "X(t) ∈ {x₁,x₂}"라고 말해 준다. 도움은 오류를 줄이기만 하므로 하계로 쓸 수 있다.

**율의 단일 문자화.**
R_i = (1/n) log|C_i| ≥ (1/n)H(C_i) ≥ (1/n)H(C_i|Xⁿ) = (1/n) I(C_i; Y_iⁿ | Xⁿ)  (C_i는 Y_iⁿ의 함수)
 = (1/n)[H(Y_iⁿ|Xⁿ) − H(Y_iⁿ|Xⁿ, C_i)]
 = (1/n) Σ_t {H[Y_i(t)|X(t), X̃_t, Y_i(1..t−1)] − H[Y_i(t)|C_i, X(t), X̃_t, Y_i(1..t−1)]}  (연쇄 법칙)
 ≥ (1/n) Σ_t {H[Y_i(t)|X(t), X̃_t] − H[Y_i(t)|C_i, X(t), X̃_t]}  (첫 항: 무기억성으로 등호; 둘째 항: 조건 줄이기)
 = (1/n) Σ_t E_{X̃_t} I[Y_i(t); U_i(t, X̃_t) | X(t)].
여기서 U_i(t, x̃_t)는 Pr[X(t)=x, Y_i(t)=y, U_i=c] = p(x)W(y|x)Pr[C_i=c | Y_i(t)=y, X̃_t=x̃_t]인 확률변수. 마지막 표현이 X(t)에 의존하지 않는 것은 C_i가 Y_iⁿ의 함수이고 Y_i의 다른 좌표는 X̃_t에만 의존하기 때문 ⇒ 고정된 x̃_t마다 **X(t) → Y_i(t) → U_i(t,x̃_t)** 마르코프. 또 X(t), X̃_t가 주어지면 C₁,…,C_L은 조건부 독립.

**검정 오류의 하계.** {x₁,x₂}가 주어진 O_t의 문제는 사전 p(x₁)/(p(x₁)+p(x₂)), p(x₂)/(…)인 이진 가설 검정이며 관측은 (C₁,…,C_L, X̃_t). 최적 규칙은 네이먼–피어슨(Neyman–Pearson)/우도비: Δ(C₁,…,C_L,X̃_t) = log(Pr[C|x₁,x̃]/Pr[C|x₂,x̃]) ≥ −log(p(x₁)/p(x₂))이면 x₁.
- 기울인 곱분포 Q_λ = ∏_i Q_λ^{(i)}, Q_λ^{(i)} ∝ Pr^{1−λ}[C_i|x₁,x̃]Pr^λ[C_i|x₂,x̃] (식 (100)–(102)). Q_λ 아래에서 Δ(C_i)는 독립.
- E_{Q_λ}Δ = Lε − log(p(x₁)/p(x₂))가 되게 λ를 고르고 체비쇼프 부등식(Chebyshev's inequality)으로 Q_λ(𝒰_{x₁}) ≥ 1 − Σσ²(i)/(L²ε²) (식 (104),(105)).
- **분산 유계 조건:** W(y|x₁) > 0 ⇔ W(y|x₂) > 0이면 C_i의 로그 우도비는 max_y |log(W(y|x₁)/W(y|x₂))|로 유계(C_i는 Y_i의 함수이므로 우도비가 Y_i 우도비의 볼록 결합) ⇒ σ²(i)도 n과 무관하게 유계 ⇒ Q_λ(𝒰_{x₁}) → 1 (식 (106)).
- 로그 합 부등식(log-sum inequality, Blahut [2] Thm 4.4.1)으로 Pr[𝒰_{x₁}|x₂, x̃] ≥ 2^{−D(Q_λ‖Pr[·|x₂,x̃]) + o(L)}, 대칭적으로 Pr[𝒰_{x₂}|x₁,x̃] ≥ 2^{−D(Q_λ‖Pr[·|x₁,x̃]) + o(L)}.
- λ를 두 발산이 같은 λ⁰로 옮겨도(식 (107)–(109)) L로 나눈 발산의 차이가 ε + O(ε²) + O(1/L)이므로 ε→0에서 같은 지수.
- 발산은 에이전트별로 더해진다: D(Q_{λ⁰}‖Pr[·|x_k,x̃]) = Σ_i D(Q_{λ⁰}^{(i)}‖Pr[C_i|x_k,x̃]) (곱분포, 식 (107),(108)).

**비율의 정리 (899–900쪽).** 옌센을 두 번 써서
R / (−log P_e^{(n)}) ≥ [Σ_t E_{X̃_t} Σ_i I(Y_i(t);U_i(t,X̃_t)|X(t))] / [Σ_t E_{X̃_t} min_{x₁,x₂} (Σ_i D(Q_{λ(i)}‖P_{C_i}(·|x₁, X̃_t)) − o(L))].
ΣA_i/ΣB_i ≤ max A_i/B_i (음이 아닌 A, B)로
−log P_e^{(n)}(R,L) / R ≤ max_{t, x̃_t} [min_{x₁,x₂} Σ_i D(Q_{λ(i)}‖P_{C_i}(·|x₁,x̃_t)) + o(L)] / Σ_i I(Y_i(t); U_i(t,x̃_t)|X(t)).
X(t) → Y_i(t) → U_i(t,x̃_t)이므로, L이 충분히 크면 임의의 부호화·추정에 대해
−log P_e^{(n)}(R,L)/R ≤ max_{U_i: X→Y_i→U_i} [min_{x₁,x₂} (1/L)Σ_i D(Q̃_{λ(i)}‖P(U_i|X=x₁))] / [(1/L)Σ_i I(Y_i;U_i|X)] + ε.
**혼합 변수로 단일화.** I를 {1,…,L} 위의 확률변수((X,Y)와 독립, X → (Y,I) → U), P(U=u|I=i,Y) = P(U_i=u|Y)로 두면
−log P_e^{(n)}(R,L)/R < max_{Q,P_I} min_{x₁,x₂} E D(Q̃_{λ,I}‖Q̃(u|x₁,I)) / I(Y;U|X,I) + ε.
L→∞에서 I의 알파벳이 가산 무한일 수 있으나, II-F절의 기수 논증으로 우변이 |𝒥| = C(|𝒳|,2)+2인 J로 바꿔도 같다 (식 (110)). ⇒ α ≤ (10)의 우변. Theorem 1 증명 끝. ∎

**퇴화 조건.** 어떤 쌍이 W(y|x₁) > 0 ⇔ W(y|x₂) > 0을 만족하지 않으면 그 쌍은 회의 없이도 확률 1로 구별되므로 (110)의 최소화 쌍은 반드시 이 조건을 만족한다. 이 조건을 만족하는 쌍이 하나도 없으면 문제는 퇴화(degenerate).

### 4.7 "R이 유한하면 L→∞여도 P_e(R) > 0" [재구성]

원문 초록·I-B절의 주장은 역정리에서 나온다. 비퇴화이고 α(p,W) < ∞라 하자. P_e(R)는 R에 대해 비증가(율을 늘려도 쓰지 않으면 됨). 만약 어떤 R₀에서 P_e(R₀) = 0이면 모든 R ≥ R₀에서 0이고 −log₂P_e(R)/R = ∞가 되어 α < ∞와 모순. 따라서 모든 유한 R에서 P_e(R) > 0이며, 큰 R에서 P_e(R) ≈ 2^{−αR}.
[미확인] α < ∞(즉 분자/분모 비가 모든 Q에서 유계)의 일반 증명은 원문에 명시되지 않는다. 국소 근사(Q(u|y)가 Q̃(u)에 가까운 경우)에서는 D(Q̃₁‖Q̃₂) ≤ χ²(W₂‖W₁)·(정보 항)/min_y(W₂/W₁) 꼴로 비가 유계임을 보일 수 있으나 전역 증명은 하지 않았다. 아래 5절 이진 예에서는 유한하다.

## 5. 예제: 이진 CEO (해밍 왜곡) [재구성: 계산]

X ~ Bern(½), W = BSC(ε): Y_i = X ⊕ N_i, N_i ~ Bern(ε). a ≜ 1−2ε.

**부호화 없음 (Proposition 1).** 쌍이 하나이고 대칭이므로 λ* = ½, Δ = 2√(ε(1−ε)) ⇒ β = −log₂(2√(ε(1−ε))) = −½log₂(1−a²) (에이전트당, 비트 단위 지수).

**부호화 있음 (Theorem 1).** |𝒳| = 2이므로 α = γ (4.5절). 시험 채널을 BSC(q)로 두면 U = Y ⊕ Bern(q), Q̃(·|x) = BSC(ε∗q), ε∗q = (1 − ab)/2, b ≜ 1−2q:
- 분자 = 체르노프 정보 = −½ log₂(1 − a²b²),
- 분모 = I(Y;U|X) = H(U|X) − H(U|Y) = h(ε∗q) − h(q).
- q = 0(관측을 그대로 보냄): 비 = −½log₂(1−a²)/h(ε).
- q → ½(각 에이전트가 거의 무작위인 1비트 미만의 정보를 보냄): 테일러 전개 h((1−x)/2) = 1 − x²/(2 ln2) + O(x⁴)로 분자 ≈ a²b²/(2 ln 2), 분모 ≈ b²(1−a²)/(2 ln 2) ⇒ 비 → a²/(1−a²).
- 수치 (BSC(q) 족 안에서 q 격자 최대화):

| ε | q=0 | q→½ 극한 a²/(1−a²) | BSC 족 최대 (최적 q) |
|---|---|---|---|
| 0.01 | 28.83 | 24.25 | ≈ 30.97 (q ≈ 0.01) |
| 0.05 | 4.18 | 4.26 | ≈ 4.62 (q ≈ 0.05) |
| 0.10 | 1.571 | 1.778 | ≈ 1.806 (q ≈ 0.145) |
| 0.20 | 0.446 | 0.5625 | → 0.5625 (q → ½) |
| 0.30 | 0.143 | 0.1905 | → 0.1905 (q → ½) |

(ε = 0.1에서 |𝒰| ≤ 3인 임의의 Q(u|y)에 대한 제한된 무작위 탐색도 1.806을 넘지 못했다. BSC 족이 전역 최적인지는 [미확인].)
해석: 관측이 꽤 잡음 섞이면(ε ≥ 0.2) 최적은 "각 에이전트가 아주 낮은 율로 거의 쓸모없어 보이는 정보를 보내고 에이전트 수로 보상"하는 극한이다. 관측이 깨끗하면 내부 최적 q가 생긴다. 어느 쪽이든 P_e(R) ≈ 2^{−αR}로 유한 R에서 0이 아니다.

## 6. 원문과의 차이·빈틈

1. **극한의 존재.** (7)의 lim_{n→∞}이 존재하는지 원문은 따지지 않는다(liminf/limsup로 읽으면 안전). (8)은 L에 대한 단조성으로 존재(4.2절 끝 [재구성]).
2. **기수 한계 불일치.** Lemma 1의 |𝒰| ≤ C(|𝒳|,2)+|𝒴|−1 vs II-E절 유도 C(|𝒳|,2)+|𝒴|+1 (4.4절).

4. **역정리의 분산 유계 가정.** 체비쇼프 단계에 W(·|x₁), W(·|x₂)의 서포트 일치가 필요하고, 원문은 서포트가 다른 쌍은 최소화에서 빠진다고 논증한다. 다만 "서포트가 다른 쌍이 회의 없이 확률 1로 구별된다"는 것이 **율 0으로** 가능한지에 대한 엄밀한 논증은 짧다 [미확인: 세부].

7. **유한 L, 유한 R의 율-왜곡 영역 미해결.** 원문 IV-A절: 조건부 독립 없이 일반화하면 "many-help-one" 문제가 되어 Körner–Marton 모듈로-2 합 문제를 포함한다고 언급.
8. **이후 문헌 (기억에 의존).** Viswanathan–Berger 1997 (IEEE Trans. IT 43(5)) 2차 가우시안 CEO; Oohama 1998 (IEEE Trans. IT 44(3):1057–1070) 대칭 가우시안 CEO의 총율-왜곡 함수 확정; Prabhakaran–Tse–Ramchandran (ISIT 2004)과 Oohama 2005가 전체 율 영역; Chen–Zhang–Berger–Wicker 2004 (IEEE JSAC 22(6)) 비대칭 잡음 분산의 총율 식과 율 배분; 이진 소거 CEO 등은 Wagner–Anantharam의 외부 한계로 다뤄짐 (서베이 B 항목 9–10 참조).

## 7. 본 연구와의 연결

본 연구 요약: K명의 작업자, X_k ~ N(0,σ²) 독립, Q_k = f_k(X_k,W) ∈ ℤ_M, 스위치 Z = ΣQ_k mod M(복호·재부호화 없음), Ŝ = g(Z,W). 정리 A(가설): log₂M ≥ ½ log₂(K/D̄) − c. 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½ log₂K − c. 확장: 공통 성분 X_k = U + N_k (CEO 구조).

1. **사슬의 구조적 선례 — 역정리의 첫 줄.** CEO 역정리(4.6절)와 가우시안 CEO 역정리(부록 A)는 모두
 Σ R_i ≥ (1/n) I(목표; 메시지들) + Σ_i (1/n) I(Y_iⁿ; C_i | 목표)
 로 출발한다. 둘째 항은 "목표와 무관한 관측 잡음을 기술하는 비용"이고 L(=K)에 비례해 커진다. 본 연구의 H(Z|S,W)는 같은 역할(목표 S와 무관한 메시지 성분)을 하는 항이다. **차이:** CEO에서는 이 항이 에이전트 수만큼 **더해지는 총율**에 나타나지만, 본 연구에서는 스위치가 합을 계산해 **하나의 Z**에 모두 실리므로 H(Z|S,W) ≈ ½ log₂K로 **로그로만** 커진다는 것이 보조정리 L의 내용이다. 원문 4.6절의 "조건부 독립 + 연쇄 법칙 + 조건 줄이기" 단일 문자화(R_i ≥ (1/n)Σ_t I(Y_i(t);U_i(t,X̃_t)|X(t)))는 공통 성분 확장에서 상행 율 하계를 세울 때 그대로 쓸 수 있다.
2. **공통 성분 확장 (X_k = U + N_k)의 기준선.** 목표가 U라면 부록 A의 가우시안 CEO 총율 식이 제약 없는 기준선이다. 목표가 S = KU + ΣN_k(본 연구)라면 CEO와 다르다: S는 관측들의 결정적 함수이므로 "원격 소스" 성격이 없고, 대신 합 함수 계산 문제(05 Körner–Marton, S1 Wagner)에 가깝다. 두 목표의 차이를 정량화하려면 Var(S|U) = Kσ_N² 이 S의 분산 K²σ_U² + Kσ_N² 중 어느 비중인지가 핵심 매개변수다(가설: 공통 성분이 지배적일수록 S ≈ KU가 되어 CEO 기준선에 접근).
3. **에이전트당 율 vs 링크당 율.** CEO 직접부(4.2절)에서 에이전트당 율은 I(Y;U|X) + H(X)/L로 L이 크면 0으로 갈 수 있고(가우시안에서도 부록 A의 식: 에이전트당 r → 0), 총율이 유한하게 남는다. 합 호환 구조에서는 모든 Q_k와 Z가 같은 ℤ_M에 있으므로 **에이전트당 상행 율도 log₂M ≥ ½ log₂(K/D̄) − c로 줄지 않는다**(정리 A가 참이면). 이것이 "합 호환 제약의 비용"을 CEO식 총율 척도와 비교할 때의 기준점이다: 제약 없는 총율 ~ ½ log₂(1/D̄) + O(1) 대비 제약 하 총율 ~ K·½ log₂(K/D̄).
4. **비닝 율 I(Y;U|X)의 해석 (4.2절 [재구성]).** 복호기가 공통 원인 X를 이용해 U_i들을 함께 복호하므로 에이전트가 각자 I(Y;U) 대신 I(Y;U|X)만 내면 된다. 본 연구의 스위치는 복호를 못 하므로 이런 결합 복호 이득을 스위치 단계에서 쓸 수 없다. 이 비교는 "스위치 내 복호 허용(기준선) vs 불허(합 호환)" 격차의 한 원천을 설명한다.
5. **전문화(specialization) 관찰 (4.5절).** 동일한 작업자라도 서로 다른 결정적 부호를 쓰는 것이 무작위 혼합보다 엄격히 낫다는 원문 결과는, 본 연구의 하계 증명에서 "모든 작업자가 같은 f_k를 쓴다"는 대칭 가정을 두면 안 되며 f_k가 k마다 다를 수 있음을 하계가 다뤄야 한다는 경고다(공유 난수 W로 무작위화해도 옌센 손실이 있을 수 있음).
6. **해밍/이산 결과의 직접 사용 한계.** 원문 본체는 유한 알파벳·해밍 오류의 지수 결과라 본 연구의 가우시안·MSE 설정에 수치로 대입할 수 없다. 쓰이는 것은 (i) 역정리의 단일 문자화 기법, (ii) 극한 순서(L→∞ 후 R→∞)와 단조성 논증, (iii) 1/R 대 2^{−2R}라는 질적 대비(IV-D절, 부록 A로 검증)다.

## 부록 A. 2차 가우시안 CEO의 총율-왜곡 함수 — **이후 문헌의 결과 (이 논문 아님)**

출처 (기억에 의존, 원문 대조 안 함): Y. Oohama, "The rate-distortion function for the quadratic Gaussian CEO problem," IEEE Trans. IT 44(3), 1998 (대칭 경우 확정); J. Chen, X. Zhang, T. Berger, S. B. Wicker, "An upper bound on the sum-rate distortion function and its corresponding rate allocation schemes for the CEO problem," IEEE JSAC 22(6), 2004 (비대칭 잡음으로 확장). 이 논문(1996)은 IV-D절에서 Viswanathan [19]의 질적 결론(MSE가 1/R보다 빨리 줄 수 없음)만 언급한다.

### A.1 설정과 식
X ~ N(0,σ_X²), Y_i = X + N_i, N_i ~ N(0,σ_N²) i.i.d. (i = 1,…,L), X와 독립. 2차 왜곡 E(X−X̂)² ≤ D. 총율-왜곡 함수 (비트):
R_sum(D) = ½ log₂(σ_X²/D) + (L/2) log₂[ Lσ_X²D / (Lσ_X²D − σ_N²(σ_X² − D)) ],  D_min < D ≤ σ_X²,
D_min = σ_X²σ_N² / (Lσ_X² + σ_N²).

### A.2 달성 (Berger–Tung + 가우시안 시험 채널) [재구성]
U_i = Y_i + V_i, V_i ~ N(0,σ_V²) i.i.d. 독립. U_i − Y_i − X − Y_j − U_j.
- 총율: I(Y^L;U^L) = I(X;U^L) + Σ_i I(Y_i;U_i|X)  (4.2절 [재구성]과 같은 분해: U^L − Y^L − X, X가 주어지면 (Y_i,U_i) 독립)
 = ½ log₂(σ_X²/D) + (L/2) log₂[(σ_N²+σ_V²)/σ_V²].
 근거: I(X;U^L) = h(X) − h(X|U^L) = ½log₂(σ_X²/D), D ≜ Var(X|U^L); I(Y_i;U_i|X) = h(U_i|X) − h(V_i) = ½log₂((σ_N²+σ_V²)/σ_V²).
- 왜곡: U_i = X + (N_i + V_i)는 X의 독립 잡음 관측 L개(잡음 분산 σ_N²+σ_V²)이므로 정밀도 덧셈
 1/D = 1/σ_X² + L/(σ_N² + σ_V²).
- 소거: σ_N² + σ_V² = Lσ_X²D/(σ_X² − D), σ_V² = [Lσ_X²D − σ_N²(σ_X² − D)]/(σ_X² − D) ⇒
 (σ_N²+σ_V²)/σ_V² = Lσ_X²D / (Lσ_X²D − σ_N²(σ_X² − D)).
 대입하면 A.1의 식과 **정확히 일치** [검증 완료]. Berger–Tung 내부 경계의 다른 부분집합 조건은 대칭 율 배분과 시분할로 만족(대칭 경우 총율 점이 달성 가능함은 문헌 결과로 받아들임 [미확인: 세부]).
- 수치 검산(σ_X² = 1, σ_N² = 0.5; L = 1, 2, 5, 50; σ_V² = 0.1, 1, 10): 매개변수 식과 닫힌 식이 소수 6자리까지 일치.

### A.3 역정리 (Oohama의 방법, 개략) [재구성 — 세부 미확인]
- 4.6절과 같은 첫 줄: Σ R_i ≥ (1/n) I(Xⁿ; C^L) + Σ_i r_i, r_i ≜ (1/n) I(Y_iⁿ; C_i | Xⁿ) (조건부 독립으로 I(Y^{L,n}; C^L | Xⁿ) = Σ_i I(Y_iⁿ;C_i|Xⁿ)).
- (1/n) I(Xⁿ; C^L) ≥ ½ log₂(σ_X²/D) (최대 엔트로피 + 옌센, 04번 5.2절과 같은 단계).
- **Oohama 보조정리** (엔트로피 거듭제곱 부등식(entropy power inequality, EPI)으로 증명): 1/D ≤ 1/σ_X² + Σ_i (1 − 2^{−2r_i})/σ_N². 직관: 에이전트 i가 잡음 N_iⁿ에 대해 r_i 비트를 쓰면 그 관측의 유효 잡음 분산이 σ_N²/(1 − 2^{−2r_i})로 남는다. (증명 세부는 이 노트에서 재현하지 않음 [미확인].)
- 최적화: 1 − 2^{−2r}가 r에 대해 오목하므로 Σr_i를 고정하면 Σ(1−2^{−2r_i})는 r_i가 모두 같을 때 최대(옌센) ⇒ 대칭 r이 최적. 등호 조건 1/D = 1/σ_X² + L(1 − 2^{−2r})/σ_N²에서
 2^{−2r} = 1 − σ_N²(σ_X² − D)/(Lσ_X²D) ⇒ r = ½ log₂[Lσ_X²D/(Lσ_X²D − σ_N²(σ_X² − D))].
 Σ R_i ≥ ½ log₂(σ_X²/D) + L·r = A.1의 식. 달성과 일치.

### A.4 극한 검증 [재구성: 직접 계산]
1. **D = σ_X²:** 첫 항 0, 둘째 항 log 안 = Lσ_X⁴/(Lσ_X⁴ − 0) = 1 ⇒ R_sum = 0. ✓ (평균값 추정)
2. **최소 D:** 로그 안 분모가 0이 되는 점 Lσ_X²D = σ_N²(σ_X² − D) ⇔ D = σ_X²σ_N²/(Lσ_X² + σ_N²) = D_min. 이는 모든 관측 Y^L을 가진 MMSE(1/D = 1/σ_X² + L/σ_N²)와 같다. D ↓ D_min이면 R_sum → ∞. ✓ (σ_V² = 0, 즉 무한 정밀 양자화에 해당)
3. **L = 1:** R_sum = ½ log₂[(σ_X² − D_min)/(D − D_min)] — 원격 소스 율-왜곡 함수(간접 율-왜곡: X의 MMSE 추정량 E[X|Y]를 분산 σ_X² − D_min인 가우시안 소스로 보고 D − D_min까지 압축)와 일치. 수치 검산(σ_X² = 1, σ_N² = 0.5, D = 0.5): 양쪽 모두 1.000 비트. ✓
4. **L → ∞ (D 고정, D > 0):** a ≜ σ_N²(σ_X² − D)/(σ_X²D)라 하면 둘째 항 = −(L/2) log₂(1 − a/L) → (a/2) log₂e. 따라서
 R_sum(D) → ½ log₂(σ_X²/D) + (σ_N²/(2D))(1 − D/σ_X²) log₂e.
 수치(σ_X² = 1, σ_N² = 0.5, D = 0.1): L = 10, 100, 1000, 10⁵에서 5.973, 4.982, 4.914, 4.9071 → 극한식 4.9070. ✓
 **의미:** 에이전트가 무한히 많아도 총율은 유한하게 남고(에이전트당 율 → 0), 이 원문 초록의 이산 결과와 같은 현상이다. 또 D → 0이면 R_sum ≈ σ_N² log₂e/(2D), 즉 **D ≈ σ_N² log₂e/(2R)** — 원문 IV-D절의 "MSE는 1/R보다 빨리 줄지 않는다"와 정확히 맞는다(회의 가능하면 D = σ_X²2^{−2R}).
5. **σ_N² → 0:** 둘째 항 → 0, R_sum → ½ log₂(σ_X²/D) (보통 가우시안 율-왜곡). ✓

결론: 과제에서 주어진 식은 Berger–Tung 가우시안 달성 계산과 정확히 일치하며, 모든 극한(D = σ_X², D_min, L = 1, L → ∞, 무잡음)에서 기대값과 맞는다. 역정리(최적성)는 Oohama 1998의 결과로 받아들이되 그 세부는 이 노트에서 재현하지 않았다.
