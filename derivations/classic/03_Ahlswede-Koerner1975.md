# 03. Ahlswede–Körner (1975) 유도 노트

표기 규칙: [원문] = 원문 증명 경로를 그대로 따름, [재구성] = 원문이 생략했거나 낡은 기법이라 현대 표준 증명(El Gamal–Kim 식)으로 보충, [미확인] = 원문에서 확인하지 못함, [기억] = 원문 밖 지식(문헌 기억)에 의존.

## 1. 서지

- 저자: Rudolf F. Ahlswede, János Körner
- 제목: Source Coding with Side Information and a Converse for Degraded Broadcast Channels
- 학술지: IEEE Transactions on Information Theory, vol. IT-21, no. 6, pp. 629–637, November 1975
- PDF: `papers/classic/03_Ahlswede-Koerner1975.pdf` (9쪽)

논문은 두 부분이다. II절: 부가정보가 있는 소스 부호화(도우미 문제). III절: 퇴화 방송 채널(degraded broadcast channel, DBC)의 약한 역정리.

## 2. 문제 설정 (원문 기호)

### 2.1 소스 부호화 (II-A절)

- {(X_i, Y_i)}: 유한 알파벳 𝒳, 𝒴 위 i.i.d. 쌍(이산 무기억 상관 소스, DMS), 결합분포 Q(x,y).
- 인코더 1은 Xⁿ만 보고 f_n(Xⁿ)을, 인코더 2는 Yⁿ만 보고 g_n(Yⁿ)을 만든다. 복호기는 두 부호를 받아 **Yⁿ만** 복원: V_n(f_n(Xⁿ), g_n(Yⁿ)).
- ‖Z‖: 함수 Z의 치역 크기(cardinality).
- **달성 가능한 율 쌍** (R_1,R_2): 임의의 δ>0, 0<λ≤1, 충분히 큰 n에 대해
  Pr{V_n(f_n(Xⁿ), g_n(Yⁿ)) = Yⁿ} ≥ 1 − λ  (식 (1.2)),
  ‖f_n(Xⁿ)‖ ≤ exp{(R_1+δ)n}, ‖g_n(Yⁿ)‖ ≤ exp{(R_2+δ)n}  (식 (1.3))
  인 f_n, g_n, V_n이 존재. ℛ = 달성 가능한 쌍의 집합.
- 로그·exp의 밑은 원문에 명시되지 않음(exp와 2^{…}가 섞여 나온다). 결과는 밑에 무관.

### 2.2 보조 함수 (Lemma 1, 2)

- T(c) = inf_{H(X|U) ≥ c} H(Y|U), 하한은 U − X − Y 마르코프 사슬인 모든 이산 U에 대해.
- T_n(c) = inf_{(1/n)H(Xⁿ|U) ≥ c} (1/n) H(Yⁿ|U), J_n(c) = sup_{(1/n)H(Yⁿ|U) ≤ c} (1/n) H(Xⁿ|U), U − Xⁿ − Yⁿ 마르코프.

### 2.3 퇴화 방송 채널 (III절)

- 채널 P_1(y|x) (𝒳→𝒴), P_2(z|y) (𝒴→𝒵), 합성 P_2∗P_1(z|x) = Σ_y P_2(z|y)P_1(y|x). n번 무기억 확장.
- 메시지 쌍 (i,j), 1 ≤ i ≤ M_1, 1 ≤ j ≤ M_2. i는 복호기 1(출력 Y 관측)에게, j는 복호기 2(출력 Z 관측)에게. 공통 부호기가 부호어 x_ij를 배정.
- 부호 {x_ij, 𝒜_i, ℬ_j}: 𝒜_i ⊆ 𝒴ⁿ, ℬ_j ⊆ 𝒵ⁿ 각각 서로소. 최대 오류(maximal error) 기준.
- 달성 가능 (R_1,R_2): 임의의 0 ≤ λ_1 < ½, 0 ≤ λ_2 < ½, δ>0, 큰 n에서
  M_1 ≥ exp[n(R_1−δ)], M_2 ≥ exp[n(R_2−δ)]  (식 (6.1a)),
  max_j max_i P_1ⁿ(𝒜_i^c | x_ij) ≤ λ_1 (6.1b), max_j max_i P_2ⁿ∗P_1ⁿ(ℬ_j^c | x_ij) ≤ λ_2 (6.1c).
- t(x) ≜ sup_{I(U∧Z) ≥ x} I(X∧Y|U), U,X,Y,Z 마르코프 사슬이고 전이확률이 P_1, P_2로 고정 (식 (5.2)).
  원문은 I(X∧Y)로 상호정보를 쓴다.

## 3. 주 정리 진술 (원문 대조 완료: PDF 2–5, 7–9쪽 이미지로 확인)

**Lemma 1** a) U − X − Y 마르코프일 때 T(c) = inf_{H(X|U)≥c} H(Y|U)는 c에 대해 볼록(∪). b) (비교용, 이 논문에서는 미사용) 고정 채널 Q(y|x)에 대한 G(c)도 볼록.

**Lemma 2** a) 모든 n, c ≥ 0에 대해 T_n(c) = T(c). b) J_n(c) = J_1(c). X, Y가 독립이 아니면 J(c) = T^{−1}(c).

**Lemma 3** (Carathéodory형): 확률 n-벡터 집합 𝒫_n 위 연속 함수 f_1,…,f_k와 𝒫_n 위 확률측도 μ에 대해, k+1개의 p_i ∈ 𝒫_n과 α_i ≥ 0 (Σα_i = 1)가 있어 ∫f_j dμ = Σ_i α_i f_j(p_i), j=1,…,k.

**Theorem (Slepian–Wolf)** (II-A, 식 (1.8)): 큰 n과 0<λ≤1, δ>0에 대해 Pr{V_n = (Xⁿ,Yⁿ)} ≥ 1 − λ, ‖f_n‖ ≤ exp{n(H(X)+δ)}, ‖g_n‖ ≤ exp{n(H(Y|X)+δ)}인 부호가 존재. (II-B에서 Feinstein 정리로 새로 증명.)

**Theorem 1** (II-C, 다문자 특성화): 
ℛ* = {((1/n) H(f_n(Xⁿ)), (1/n) H(Yⁿ | f_n(Xⁿ))) : n ∈ ℕ, f_n: 𝒳ⁿ → ℕ}
에 대해 ℛ = ℛ* (원문 표기 그대로. 문맥상 "이 점들이 지배하는 영역의 폐포"로 읽어야 한다. 3절 6항 참조).

**Theorem 2** (II-D, Coding Theorem and Converse):
ℛ = ℛ** = {(R_1,R_2) | R_1 ≥ I(X∧U), R_2 ≥ H(Y|U), U는 이산 확률변수이고 U, X, Y는 마르코프 사슬}.
또한 ‖U‖ ≤ ‖𝒳‖ + 2로 제한해도 같은 영역.

**Lemma 4** (III-A): t(x)는 x ≥ 0에서 오목(∩).
**Lemma 5**: U, Xⁿ, Yⁿ, Zⁿ 마르코프, 채널 무기억, U_i ≜ (U, Y_1,…,Y_{i−1})이면 I(U∧Zⁿ) ≤ Σ_i I(U_i∧Z_i).
**Lemma 6**: 같은 표기로 I(Xⁿ∧Yⁿ|U) ≤ Σ_i I(X_i∧Y_i|U_i). (증명은 사실상 등호를 준다. 4.6절.)
**Lemma 7**: t_n(x) ≜ sup{(1/n)I(Xⁿ∧Yⁿ|U) | (1/n)I(U∧Zⁿ) ≥ x}에 대해 t_n(x) ≤ t(x).
**Lemma 8**: t(x) = max{I(X∧Y|U) | I(U∧Z) ≥ x, ‖U‖ ≤ min(‖𝒳‖, ‖𝒴‖·‖𝒵‖)} (Gallager [12] Lemma 1의 변형, 개요만).

**Weak Converse Theorem** (III-B): (R_1,R_2)가 DBC {P_1,P_2}의 달성 가능한 율이면 R_1 ≤ t(R_2).

## 4. 유도

### 4.1 Lemma 1 a) T(c)의 볼록성 [원문]

"조건화 = 볼록 결합" 논법. (U_1,X_1,Y_1), (U_2,X_2,Y_2)가 조건을 만족하는 두 삼중쌍이고 0 ≤ α ≤ 1. 시분할 변수 I ∈ {1,2}, Pr{I=1} = α, 그리고 I=i이면 (Ũ,X̃,Ỹ) = (U_i,X_i,Y_i). 두 삼중쌍의 (X,Y) 주변분포가 모두 Q이므로 (X̃,Ỹ) ~ Q이고 I는 (X̃,Ỹ)와 독립.
H(X̃|Ũ,I) = αH(X_1|U_1) + (1−α)H(X_2|U_2)  (식 (1.4)),
H(Ỹ|Ũ,I) = αH(Y_1|U_1) + (1−α)H(Y_2|U_2)  (식 (1.5)).
((Ũ,I), X̃, Ỹ)도 마르코프 사슬이므로 (Ũ,I)는 T의 정의에서 허용되는 보조변수. H(X_i|U_i) ≥ c_i, H(Y_i|U_i) ≤ T(c_i)+ε로 고르면 H(X̃|Ũ,I) ≥ αc_1 + (1−α)c_2 이고
T(αc_1 + (1−α)c_2) ≤ H(Ỹ|Ũ,I) ≤ αT(c_1) + (1−α)T(c_2) + ε. ε → 0. ∎
[보충: 마르코프성 근거 — I=i에서 (U_i,X_i,Y_i)가 마르코프이고 X_i → Y_i 채널이 i에 무관하게 Q(y|x)이므로, p(ũ,i,x̃,ỹ) = p(i)p(ũ,x̃|i)Q(ỹ|x̃).]
또 T는 단조 비감소: c가 커지면 제약 집합이 줄어들기 때문.

### 4.2 Lemma 2 a) T_n = T (단일 문자화) [원문]

U − Xⁿ − Yⁿ 마르코프, (X_i,Y_i) i.i.d.
H(Yⁿ|U) = Σ_i H(Y_i | U, Y_1,…,Y_{i−1})                         (연쇄 법칙)
≥ Σ_i H(Y_i | U, Y_1,…,Y_{i−1}, X_1,…,X_{i−1})                    (조건화)
= Σ_i H(Y_i | U, X_1,…,X_{i−1})  (식 (1.6))
마지막 등호의 근거 [보충 검증]: p(u, x^{i−1}, y^{i−1}, y_i) = Σ_{x_i^n} p(xⁿ)p(u|xⁿ)∏_{j<i}Q(y_j|x_j)·Q(y_i|x_i) = ∏_{j<i}Q(y_j|x_j) · p(u, x^{i−1}, y_i)이므로 Y^{i−1}은 (U, X^{i−1})가 주어지면 Y_i와 조건부 독립.

각 i와 각 실현 X^{i−1} = x^{i−1}에 대해, (U, X^{i−1}=x^{i−1}) 조건부로 (U,X^{i−1}) − X_i − Y_i 마르코프이고 X_i → Y_i 채널이 Q(y|x)이다. 따라서 T의 정의로
H(Y_i | U, X^{i−1}=x^{i−1}) ≥ T(H(X_i | U, X^{i−1}=x^{i−1})).
[보충 검증: X_i는 X^{i−1}과 독립이므로 X^{i−1}=x^{i−1} 조건부에서도 (X_i,Y_i) ~ Q이고, U − Xⁿ − Yⁿ과 무기억성으로 U − X_i − Y_i (조건부). 따라서 실현별 적용이 정당하다. 같은 결론을 U' ≡ (U, X^{i−1})를 하나의 보조변수로 보고 H(Y_i|U') ≥ T(H(X_i|U'))로 한 번에 얻을 수도 있다(이 경우 젠센 단계가 i에 대한 평균 하나로 줄어든다). [재구성: 대안 경로]]
기대값을 취하고 T의 볼록성(젠센)으로
H(Yⁿ|U) ≥ Σ_i T(H(X_i | U X_1…X_{i−1}))  (식 (1.7))
≥ n T((1/n) Σ_i H(X_i | U X^{i−1}))  (젠센, T 볼록)
= n T((1/n) H(Xⁿ|U))  (연쇄 법칙).
T는 단조 증가이므로 (1/n)H(Xⁿ|U) ≥ c이면 (1/n)H(Yⁿ|U) ≥ T(c), 즉 T_n(c) ≥ T(c). 반대 방향 T_n ≤ T는 U = (U_1,…,U_n) i.i.d. 단일 문자 선택으로 자명. ∎
b): X, Y가 독립이 아니면 T는 상수가 아니고, 볼록·단조 증가 함수이므로 순증가. T_n = T이므로 J_n = T^{−1} = J_1.

### 4.3 Slepian–Wolf 정리의 새 증명 (Feinstein 반복) [원문]

**Feinstein 기본 정리** (원문 특수형): 쌍 {(𝒜_i, y_i)}가 s-부호(s-code)라 함은 𝒜_i ⊆ 𝒳ⁿ 서로소, y_i ∈ 𝒴ⁿ, Pr(Xⁿ ∈ 𝒜_i | Yⁿ = y_i) ≥ 1 − s. (**역할 주의: 여기서는 Yⁿ이 채널 입력, Xⁿ이 채널 출력.**) 부호어를 𝒴_0ⁿ ⊆ 𝒴ⁿ에서만 고른 극대(maximal) s-부호는
M ≥ exp{n[I(X∧Y) − δ]}·[s·Q(𝒴_0ⁿ) − Q(A_n(δ))],
A_n(δ) = {(xⁿ,yⁿ): |(1/n) log Q(xⁿ,yⁿ)/(Q(xⁿ)Q(yⁿ)) − I(X∧Y)| > δ}.
Q(A_n(δ)) → 0이므로 M ≥ exp{n[I − δ]}·(s/2)·Q(𝒴_0ⁿ) (큰 n).

**단계 1 (서로소 부호 쌓기)**: 𝒴_δⁿ(1) = {yⁿ: |(1/n) log Q(yⁿ) + H(Y)| < δ} (전형 집합), Q(𝒴_δⁿ(1)) > 1 − s (대수의 법칙). 크기 M(1) = (s/2)(1−s)exp{n(I−δ)}인 s-부호 C(1)을 만든다. 그 부호어들의 확률 합은 전형 집합 원소 확률 ≈ exp{−n(H(Y) ∓ δ)}로 상·하한되므로
(s/2)(1−s)exp[−n(H(Y|X) + 2δ)] ≤ Q(C(1)) ≤ (s/2)(1−s)exp[−nH(Y|X)].
𝒴_δⁿ(2) = 𝒴_δⁿ(1) − C(1)에 다시 Feinstein을 적용, 반복. L−1번 후 (식 (2.2))
(1−s)(1 − (s/2)e^{−nH(Y|X)})^{L−1} ≤ Q(𝒴_δⁿ(L)) ≤ (1−s)(1 − (s/2)e^{−n[H(Y|X)+2δ]})^{L−1}.
(1 − μx)^L ≤ exp(−μLx)로 L = ⌈exp(n(H(Y|X)+δ_1))⌉, δ_1 > 2δ이면 남은 확률 → 0. 반대로 L ≈ 2^{nH(Y|X)}이면 남은 확률이 0에서 떨어져 있음(식 (2.2) 좌변) — 즉 H(Y|X)는 필요한 부호 수의 정확한 지수.
결과: 큰 n에서 ⌈exp[n(H(Y|X) + δ_1)]⌉개 (0 < δ_1 < 3δ)의 서로소 s-부호, 각 부호는 > (s²/4)exp(n(I − δ))개 부호어, 합집합 확률 > 1 − s.
[보충, 재구성: 반복 중 남은 집합의 확률이 작아지면 Feinstein 하한 (s/2)Q(𝒴_0ⁿ)가 작아진다. 원문은 "각 부호 > (s²/4)exp(…)"라 하는데, 이는 남은 확률이 ≳ s/2 이상인 동안에만 보장된다. 남은 확률이 s 아래로 떨어지면 멈춰도 합집합 확률 > 1 − 2s 수준이 되어 결론은 같다.]

**단계 2 (부호기·복호기)**: s < (λ − δ)/2 (식 (2.3)).
- f_n: 𝒳_δⁿ(1)(X 전형 집합) 위에서 가역, 밖에서는 상수. 오류 < δ, (1/n) log‖f_n‖ ≤ H(X) + δ.
- g_n(Yⁿ) = J (Yⁿ ∈ C(J)), 0 (어느 부호에도 없음). (1/n) log‖g_n‖ ≤ H(Y|X) + 3δ.
- 복호: f_n으로 xⁿ 복원(확률 > 1−δ), g_n으로 부호 번호 J를 알면 C(J)의 복호 집합 중 xⁿ이 속한 것으로 yⁿ 결정(s-부호이므로 오류 ≤ s). 전체 Pr(Ŷⁿ = Yⁿ) ≥ 1 − 2s − δ > 1 − λ. ∎
이것은 SW 꼭짓점 (H(X), H(Y|X))이며, "전형 Yⁿ을 채널 Y→X의 부호들로 분할"하는 비닝이다(01번 노트의 초부호와 같은 발상, 결정적 분할이라는 점만 다름).

### 4.4 Theorem 1 (다문자 영역) [원문]

**직접 (ℛ ⊇ ℛ*)**: 고정 n과 f_n에 대해 초소스(supersource) {(U_t, Ỹ_t)}_t, (U_t, Ỹ_t) ~ (f_n(Xⁿ), Yⁿ) i.i.d.에 SW 정리를 적용: U를 율 H(U) = H(f_n(Xⁿ)), Ỹ를 율 H(Ỹ|U) = H(Yⁿ|f_n(Xⁿ))로 보내 둘 다 복원(Ỹ만 필요). n으로 나누면 ((1/n)H(f_n), (1/n)H(Yⁿ|f_n)) 달성.

**역 (ℛ ⊆ ℛ*)**: Pr(V_n = Yⁿ) = 1 − λ, ‖f_n‖ ≤ exp{R_1 n}, ‖g_n‖ ≤ exp{R_2 n} (식 (3.1)–(3.2)). U ≜ f_n(Xⁿ). R_1 ≥ (1/n)log‖f_n‖ ≥ (1/n)H(U)는 자명. R_2에 대해 u마다
R_2 ≥ (1/n) log‖g_n‖ ≥ (1/n) H(g_n(Yⁿ) | U=u)                (엔트로피 ≤ log 치역 크기)
≥ (1/n) H(V_n(f_n, g_n) | U=u)                                   (U=u에서 V_n은 g_n의 함수: 함수는 엔트로피를 늘리지 않음)
≥ (1/n) I(Yⁿ ∧ V_n | U=u)
= (1/n)[H(Yⁿ|U=u) − H(Yⁿ|U=u, V_n)]  (식 (3.4)).
파노: H(Yⁿ|U=u, V_n) ≤ h(λ(u)) + λ(u)·n·log‖𝒴‖, λ(u) = Pr{V_n ≠ Yⁿ | U=u}  (식 (3.5)).
따라서 R_2 ≥ (1/n)[H(Yⁿ|U=u) − h(λ(u)) − λ(u) n log‖𝒴‖] (식 (3.6)). u에 대해 평균하고 h의 오목성 E h(λ(U)) ≤ h(λ):
R_2 ≥ (1/n)[H(Yⁿ|f_n(Xⁿ)) − h(λ) − nλ log‖𝒴‖]  (식 (3.3)).
λ → 0, n 크게 하면 (R_1, R_2)는 ℛ*의 점에 의해 (근사적으로) 지배된다. ∎

### 4.5 Theorem 2 (단일 문자 영역) [원문]

**역 (ℛ* ⊆ ℛ**)**: R_1 = (1/n)H(Z), R_2 = (1/n)H(Yⁿ|Z), Z = f_n(Xⁿ)라 하자.
nR_1 = H(Z) ≥ I(Z∧Xⁿ) = H(Xⁿ) − H(Xⁿ|Z)  (식 (4.1))
⇒ (1/n)H(Xⁿ|Z) ≥ H(X) − R_1  (X_i 독립, 식 (4.2)).
Z − Xⁿ − Yⁿ 마르코프이므로 Lemma 2:
R_2 = (1/n)H(Yⁿ|Z) ≥ T((1/n)H(Xⁿ|Z)) ≥ T(H(X) − R_1)  (T 증가, 식 (4.3))
= inf_{H(X|U) ≥ H(X) − R_1} H(Y|U)  (식 (4.4))
= inf_{I(X∧U) ≤ R_1} H(Y|U)  (식 (4.5)).
따라서 (R_1,R_2)는 어떤 U − X − Y에 대해 R_1 ≥ I(X∧U), R_2 ≥ H(Y|U)를 (하한이 달성되거나 근사적으로) 만족. [보충: inf가 달성되지 않을 수 있으나 ‖U‖ 제한으로 컴팩트성 → min.]

**직접 (ℛ* ⊇ ℛ**)**: 임의의 U − X − Y와 ε > 0에 대해
(1/n)H(f_n(Xⁿ)) ≤ I(X∧U) + ε  (식 (4.6)), (1/n)H(Yⁿ | f_n(Xⁿ)) ≤ H(Y|U) + ε  (식 (4.7))
인 f_n을 만든다. H(U) − I(X∧U) > δ 가정 (식 (4.8); 아니면 H(U|X)=0, U가 X의 함수라 f_n = Uⁿ로 끝). ε < δ.
- 전형 수열 𝒯(𝒰ⁿ), 생성 수열(generated sequences) 𝒢(𝒳ⁿ,uⁿ), 𝒢(𝒴ⁿ,xⁿ,uⁿ) (√n 편차 상수).
  𝒢*(𝒴ⁿ,uⁿ) = ∪_{xⁿ∈𝒢(𝒳ⁿ,uⁿ)} 𝒢(𝒴ⁿ,xⁿ,uⁿ). 상수를 골라
  lim Pr(Yⁿ ∈ 𝒢*(𝒴ⁿ,uⁿ) | Xⁿ = xⁿ) = 1 (uⁿ 전형, xⁿ ∈ 𝒢(𝒳ⁿ,uⁿ))  (식 (4.9)),
  |(1/n) log‖𝒢*(𝒴ⁿ,uⁿ)‖ − H(Y|U)| ≤ c_1/√n  (식 (4.10)).
  [보충: 마르코프 U−X−Y이므로 Yⁿ은 Xⁿ을 통해서만 uⁿ과 연결; Xⁿ이 uⁿ과 결합 전형이면 Yⁿ도 uⁿ과 결합 전형(마르코프 보조정리의 원형). 𝒢*의 크기는 조건부 전형 집합 크기 2^{nH(Y|U)}.]
- **극대 부호 구성**(Wolfowitz): 채널 U → X에 대해, 임의의 0 < λ < 1로 다음을 만족하는 부호 {(v_j, D_j)}_{j=1}^N:
  a) v_j ∈ 𝒯(𝒰ⁿ), b) D_j ⊆ 𝒢(𝒳ⁿ,v_j) 서로소, c) Pr(Xⁿ ∈ D_j | Uⁿ = v_j) ≥ 1 − λ,
  d) Pr(Xⁿ ∈ D_0) ≤ (1−λ)Pr(Uⁿ ∉ {v_1..v_N}) + λ·Pr(Uⁿ ∈ {v_1..v_N}), D_0 = 𝒳ⁿ − ∪D_j (극대성).
  e) Wolfowitz 강한 역정리: (1/n) log(N+1) ≤ I(X∧U) + ε.
- f_n(Xⁿ) = j (Xⁿ ∈ D_j, j = 0,1,…,N) (식 (4.11)). (4.6)은 (1/n)H(f_n) ≤ (1/n)log(N+1)로 성립.
- (4.7): i ≥ 1이면 Xⁿ ∈ D_i ⊆ 𝒢(𝒳ⁿ,v_i)이므로 Yⁿ은 높은 확률로 𝒢*(𝒴ⁿ,v_i) 안. 파노형 추정
  H(Yⁿ | f_n = i) ≤ log‖𝒢*(𝒴ⁿ,v_i)‖ + log 2 + nδ_i^n log‖𝒴‖  (식 (4.12), 원문은 log 2 항을 "log 2/δ" 비슷하게 인쇄 [인쇄 흐림, 미확인]),
  δ_i^n = Pr(Yⁿ ∉ 𝒢*(𝒴ⁿ,v_i) | f_n = i) → 0 (4.9). (4.10)과 함께 (1/n)H(Yⁿ|f_n = i) ≤ H(Y|U) + ε/2 (식 (4.13)), 따라서
  (1/n)H(Yⁿ|f_n) ≤ H(Y|U) + ε/2 + log‖𝒴‖·Pr(f_n = 0)  (식 (4.14)).
- Pr(f_n = 0) → 0: e)와 ε < δ, (4.8)로 Pr(Uⁿ ∈ {v_1..v_N}) ≤ (N)·exp(−n(H(U) − o(1))) ≤ exp(n(I + ε − H(U) + o(1))) → 0. 그러면 d)에서 Pr(Xⁿ ∈ D_0) ≤ (1−λ) + o(1). **λ를 1에 가깝게 고를 수 있으므로** Pr(D_0)를 임의로 작게 만든다. (c)에서 λ가 1에 가까우면 각 D_j가 작아도 되지만, 그 대신 극대성 때문에 덮지 못한 부분 D_0가 작아진다는 점이 이 증명의 묘수다.)
- 따라서 (4.6), (4.7) 성립, Theorem 1의 직접부와 합쳐 ℛ** ⊆ ℛ. ∎

**크기 제한 ‖U‖ ≤ ‖𝒳‖ + 2** [원문]: Lemma 3을 𝒫_{‖𝒳‖} 위에서, 측도 μ = U의 분포, 점 p = Pr(X=·|U=u)로 적용. 보존할 연속 함수: f_j(p) = p(j) (주변분포 Pr(X=x) 보존, 실질적으로 ‖𝒳‖−1개), f_{n+1}(p) = −Σ_y(Σ_x p(y|x)p(x)) log(Σ_x p(y|x)p(x)) (→ H(Y|U)), f_{n+2}(p) = Σ_x p(x) log p(x) + H(X) (→ I(X∧U)). 함수 개수 k ≤ ‖𝒳‖ + 1 → 점 k+1 ≤ ‖𝒳‖ + 2개. [보충: 주변분포 제약이 ‖𝒳‖−1개면 ‖𝒳‖+1로 더 줄일 수 있다(현대 지지 보조정리). 원문은 j=1..n을 모두 세서 +2.]

### 4.6 현대 표준 증명 (El Gamal–Kim 식) [재구성]

**역 (블록 오류, 파노)**: M_1 = f_n(Xⁿ), M_2 = g_n(Yⁿ), H(Yⁿ|M_1,M_2) ≤ nε_n.
- nR_2 ≥ H(M_2) ≥ H(M_2|M_1) ≥ I(M_2;Yⁿ|M_1) = H(Yⁿ|M_1) − H(Yⁿ|M_1,M_2) ≥ Σ_i H(Y_i|M_1,Y^{i−1}) − nε_n.
- nR_1 ≥ H(M_1) ≥ I(M_1;Xⁿ) = Σ_i I(X_i; M_1 | X^{i−1}) = Σ_i I(X_i; M_1, X^{i−1}) (X_i 독립) ≥ Σ_i I(X_i; M_1, Y^{i−1}).
  마지막 부등식: I(X_i; M_1, X^{i−1}) = I(X_i; M_1, X^{i−1}, Y^{i−1}) ≥ I(X_i; M_1, Y^{i−1}). 첫 등호는 Y^{i−1} − (M_1, X^{i−1}) − X_i (Y^{i−1}은 X^{i−1}만 통해 연결).
- U_i ≜ (M_1, Y^{i−1}). U_i − X_i − Y_i: (M_1, Y^{i−1})은 (X^{i−1}, X_{i+1}^n, Y^{i−1})의 함수/잡음 출력이고, X_i가 주어지면 Y_i는 나머지와 독립. 시분할 변수 Q ~ Unif[1:n], U = (U_Q, Q) → R_1 ≥ I(X;U) − 0, R_2 ≥ H(Y|U) − ε_n. ∎
이 식별은 원문 III절 Lemma 5의 U_i = (U, Y_1,…,Y_{i−1})와 같은 형태다(원문은 소스 역정리에서는 Lemma 2의 볼록성 경로를, DBC에서는 이 식별 경로를 썼다).

**직접 (피복 + 비닝)**: Uⁿ(m_1), m_1 ∈ [1:2^{n(I(X;U)+δ)}] ~ ∏p_U. 인코더 1: Xⁿ과 결합 전형인 Uⁿ(m_1)를 찾음(피복 보조정리). 인코더 2: Yⁿ의 랜덤 bin, 율 H(Y|U) + δ. 복호: bin 안에서 Uⁿ(m_1)과 결합 전형인 유일한 ŷⁿ. 마르코프 보조정리로 (Uⁿ(M_1), Xⁿ, Yⁿ) 결합 전형. 오류 확률 ≤ 2^{n(H(Y|U)+δ' − R_2)} → 0.

### 4.7 DBC 약한 역정리 [원문]

**Lemma 4 (t 오목)**: x = αx_1 + (1−α)x_2, (U_i,X_i,Y_i,Z_i)가 t(x_i) − ε 이상을 주는 사슬. 시분할 T (Pr(T=1)=α), Ũ = U_T 등 (식 (5.3)). (T,Ũ), X̃, Ỹ, Z̃는 마르코프이고 채널 고정.
αt(x_1) + (1−α)t(x_2) − ε ≤ αI(X_1∧Y_1|U_1) + (1−α)I(X_2∧Y_2|U_2) = I(X̃∧Ỹ|Ũ,T)  (식 (5.4)).
αI(U_1∧Z_1) + (1−α)I(U_2∧Z_2) = I(Ũ∧Z̃|T) ≥ x  (식 (5.5)–(5.7)).
I((Ũ,T)∧Z̃) = I(Ũ∧Z̃|T) + I(T∧Z̃) ≥ I(Ũ∧Z̃|T) ≥ x이므로 (Ũ,T)는 t(x)의 허용 보조변수 → t(x) ≥ I(X̃∧Ỹ|Ũ,T) ≥ αt(x_1) + (1−α)t(x_2) − ε. ∎

**Lemma 5**: I(U∧Zⁿ) = H(Zⁿ) − H(Zⁿ|U).
H(Zⁿ|U) = Σ_i H(Z_i | U, Z^{i−1}) ≥ Σ_i H(Z_i | U, Z^{i−1}, Y^{i−1}) = Σ_i H(Z_i | U, Y^{i−1}) = Σ_i H(Z_i|U_i)  (식 (5.8); 등호: Y→Z 채널 무기억이라 Z^{i−1}은 Y^{i−1}을 통해서만 Z_i와 연결).
H(Zⁿ) ≤ Σ_i H(Z_i). 따라서 I(U∧Zⁿ) ≤ Σ_i [H(Z_i) − H(Z_i|U_i)] = Σ_i I(U_i∧Z_i). ∎

**Lemma 6**: I(Xⁿ∧Yⁿ|U) = H(Yⁿ|U) − H(Yⁿ|XⁿU) (식 (5.9)).
H(Yⁿ|U) = Σ_i H(Y_i|U,Y^{i−1}) = Σ_i H(Y_i|U_i)  (식 (5.10), 정의상 등호).
H(Yⁿ|XⁿU) = Σ_i H(Y_i|X_i,U) (채널 무기억, U − Xⁿ − Yⁿ) = Σ_i H(Y_i|X_i,U_i) (Y_i와 Y^{i−1}은 (X_i,U)가 주어지면 독립).
[보충 검증: 무기억 채널에서 Y_i는 X_i와 i번째 채널 잡음만의 함수이고, 그 잡음은 (U, Xⁿ, 앞선 잡음)과 독립이다. 따라서 p(y_i | x_i, u, y^{i−1}) = P_1(y_i|x_i)이고 원문의 조건부 독립 주장은 옳다. 같은 이유로 H(Y_i|X_i,U_i) = H(Y_i|X_i), 그리고 U_i − X_i − Y_i − Z_i 마르코프가 성립한다.]
따라서 실제로는 **등호** I(Xⁿ∧Yⁿ|U) = Σ_i I(X_i∧Y_i|U_i)이며, 원문의 "≤" 진술은 이를 약하게 쓴 것이다.

**Lemma 7 (t_n ≤ t)**: Lemma 5, 6으로
t_n(x) ≤ sup{(1/n)Σ I(X_i∧Y_i|U_i) | (1/n)Σ I(U_i∧Z_i) ≥ x}.
각 항을 sup으로 올리면 ≤ (1/n)Σ t(I(U_i∧Z_i)) ≤ t((1/n)Σ I(U_i∧Z_i)) (t 오목, 젠센) (식 (5.11)–(5.12)), t 감소와 (1/n)ΣI(U_i∧Z_i) ≥ x로 ≤ t(x). (원문은 ε 여유를 두고 t_n(x) − ε ≤ t(x).) [보충: 각 (U_i,X_i,Y_i,Z_i)가 t 정의의 마르코프 사슬이어야 한다. Lemma 6 보충에서 본 대로 채널 무기억성으로 U_i − X_i − Y_i − Z_i가 성립한다. 원문은 이 확인을 명시하지 않는다.]

**Lemma 8**: t는 오목이므로 상부 볼록 포락선과 같고, t(x) = inf_{λ≥0}[sup_{(U,X)}(λI(U∧Z) + I(X∧Y|U)) − λx]. sup은 Gallager [12] Lemma 1에 의해 ‖U‖ ≤ min(‖𝒳‖, ‖𝒴‖·‖𝒵‖)인 max로 대체 (식 (5.13)). [세부는 원문이 개요만 제시 — 미확인]

**Weak Converse의 증명 (6절)**:
- U: j(복호기 2용 메시지)를 균등 분포로, U=j가 주어지면 X는 T(j) = {x_ij: 1≤i≤M_1}에서 균등 선택. 그러면 U − Xⁿ − Yⁿ − Zⁿ 마르코프.
- nR_2 = H(U) = I(U∧Zⁿ) + H(U|Zⁿ) (식 (6.2)) ≤ I(U∧Zⁿ) + λ_2 log(M_2 − 1) + h(λ_2) (파노; 최대 오류 ≤ λ_2 ⇒ 평균 오류 ≤ λ_2) ⇒
  I(U∧Zⁿ) ≥ nR_2(1−λ_2) − h(λ_2)  (식 (6.3)).
- I(Xⁿ∧Yⁿ|U) = H(Xⁿ|U) − H(Xⁿ|U,Yⁿ) = nR_1 − H(Xⁿ|U,Yⁿ)  (식 (6.4); U 조건부로 Xⁿ 균등, 부호어 서로 다름 가정)
  ≥ nR_1 − λ_1 log(M_1 − 1) − h(λ_1) ≥ nR_1(1−λ_1) − h(λ_1)  (파노).
- Lemma 7: R_1 ≤ [h(λ_1) + I(Xⁿ∧Yⁿ|U)]/(n(1−λ_1)) ≤ h(λ_1)/(n(1−λ_1)) + t((1/n)I(U∧Zⁿ))/(1−λ_1)  (식 (6.5)).
- t 감소와 (6.3): R_1 ≤ h(λ_1)/(n(1−λ_1)) + t(R_2(1−λ_2) − h(λ_2)/n)/(1−λ_1)  (식 (6.6)).
- n → ∞: R_1 ≤ t(R_2(1−λ_2))/(1−λ_1). λ_1, λ_2 → 0: R_1 ≤ t(R_2). ∎
[보충: 마지막 극한은 t의 연속성이 필요. t는 [0, x_max)에서 오목이라 내부에서 연속이고, 감소 함수의 오른쪽 극한으로 처리 가능. 원문은 언급 없음. 또 원문은 (6.1a)의 M_1 ≥ exp[n(R_1−δ)]를 nR_1로 쓰며 δ를 생략.]

### 5.1 이진 도우미 [재구성 계산 + 기억]

(X,Y) DSBS: X ~ Bern(½), Y = X ⊕ N, N ~ Bern(p). 도우미 = X(율 R_1), 복원 대상 = Y.

  T(c) = h(p ∗ h^{−1}(c))이므로 Lemma 1(볼록성)과 일치(Mrs. Gerber 보조정리의 핵심이 바로 이 함수의 볼록성).

- 수치: p = 0.11, R_1 = 0.5 → R_2 ≈ 0.713 (02번 노트 5.2와 동일 — 같은 문제이기 때문).

## 6. 원문과의 차이·빈틈

1. **역정리는 약한 역정리이며 블로우업 기법을 쓰지 않는다.** 소스 쪽은 파노 + Lemma 1–2(T의 볼록성에 의한 단일 문자화), DBC 쪽은 파노 + Lemma 4–7(t의 오목성 + 보조변수 식별 U_i = (U, Y^{i−1})). 각주 1은 강한 역정리가 Ahlswede–Gács–Körner "Bounds on conditional probabilities with applications in multi-user communication"(당시 투고 중)에서 증명되었다고만 언급한다. 블로우업 보조정리는 그 후속 논문(1976)의 도구 [기억].
2. **Lemma 2의 단계**: 원문은 실현 x^{i−1}별로 T를 적용한다. X_i가 X^{i−1}과 독립이라 정당하지만 원문은 그 근거를 적지 않는다(4.2 보충).
3. **Lemma 6**: 진술은 "≤"이지만 증명은 실제로 등호를 준다(4.7 보충). 원문의 조건부 독립 주장은 무기억 채널에서 옳다.
4. **Lemma 7의 마르코프 성질** U_i − X_i − Y_i − Z_i는 명시적 확인 없음(성립은 함).
5. **Feinstein 반복 증명**에서 각 부호 크기 하한의 유지 조건이 느슨하게 서술됨(4.3 보충).
6. **Theorem 1의 ℛ*** 는 "점 집합"으로 적혀 있으나, 실제 의미는 그 점들이 위로 지배하는 영역의 폐포(율을 늘려도 달성 가능; 또한 ‖f_n‖과 H(f_n)의 차이를 흡수). 원문 표기 그대로는 영역이 아니다.
7. **Remark (II-E)**: 역정리는 Z = f_n(Xⁿ)라는 결정성을 쓰지 않고 Z − Xⁿ − Yⁿ 마르코프만 쓴다. 따라서 **Yⁿ과 독립인 무작위화(randomized encoding)는 영역을 넓히지 못한다.** 또 인코더 2가 f_n(Xⁿ)을 볼 수 있어도(Tusnády의 문제) 역정리가 그대로 적용되어 영역 불변.
8. **Wyner(1975)와의 관계**: 이 소스 문제는 Wyner 1975의 Remark b(Y ≡ 0)와 같은 문제이며 두 논문이 독립적으로 같은 영역을 얻었다(Wyner 각주 3).
9. 기호: 원문은 I(X∧Y)로 상호정보를 쓴다.

## 7. 본 연구와의 연결

본 연구 모델: K명의 작업자, X_k ~ N(0,σ²) 독립, Q_k = f_k(X_k,W) ∈ ℤ_M, 스위치는 Z = ΣQ_k mod M만, 복호기 Ŝ = g(Z,W). 정리 A(가설): log₂M ≥ ½log₂(K/D̄) − c. 사슬: log₂M ≥ H(Z|W) = I(S;Z|W) + H(Z|S,W), 보조정리 L: H(Z|S,W) ≥ ½log₂K − c.

1. **첫 단계 log₂M ≥ H(Z|W)는 Theorem 1 역 (3.4)의 첫 줄과 같은 계산.** 원문: R_2 ≥ (1/n)log‖g_n‖ ≥ (1/n)H(g_n | U=u). 본 연구: Z의 치역이 ℤ_M이므로 log₂M ≥ H(Z|W=w), w에 대해 평균. 원문이 공통 정보 U = f_n(Xⁿ)로 조건화하듯 본 연구는 공유 난수 W로 조건화한다.

2. **보조정리 L의 단일 문자화(차원 d로의 확장) 도구 = Lemma 1–2.** 보조정리 L을 스칼라(한 좌표)에서 먼저 증명하고 d차원 벡터 Zᵈ에 대해 (1/d)H(Zᵈ|Sᵈ,W) ≥ ½log₂K − c로 확장하려면, AK의 경로가 그대로 틀이 된다: (i) 단일 문자 하한 함수 T_L(·)을 정의하고(예: 잉여 엔트로피를 어떤 단일 문자 양의 함수로 하한), (ii) 그 함수의 볼록성·단조성을 보이고, (iii) 연쇄 법칙 + 조건부 독립(식 (1.6)의 Y^{i−1}을 X^{i−1}으로 바꾸는 단계) + 젠센으로 n-문자 → 단일 문자. 특히 본 연구의 하한은 "상수 ½log₂K − c"이므로 볼록성 없이 좌표별 합으로 끝날 수도 있으나, 율-왜곡 항 I(S;Z|W) ≥ ½log₂(1/D̄)류를 왜곡의 함수로 단일 문자화할 때는 Lemma 2와 같은 볼록 함수 논법(율-왜곡 함수의 볼록성)이 필요하다.

3. **무작위화가 도움이 안 된다는 Remark II-E와 공유 난수 W의 대비.** AK에서 무작위화가 무용한 이유는 역정리가 Z − Xⁿ − Yⁿ만 쓰기 때문이다. 본 연구의 W는 인코더·복호기가 **공유**하는 난수(디더)라 이 마르코프 구조가 아니고, 복호기가 W를 알기 때문에 조건화 H(·|W)가 붙는다. 사슬이 모든 항을 W 조건부로 쓰는 것이 이 차이를 처리하는 방법이며, 보조정리 L도 "각 w에서 성립 → W에 대해 평균" 구조로 증명해야 한다(원문 (3.6) → (3.3)의 "u별 부등식 → 평균 + 오목성"과 같은 패턴).

4. **보조변수 식별 U_i = (M_1, Y^{i−1}) / (U, Y^{i−1}).** 본 연구에서 I(S;Z|W)를 d개 좌표로 쪼갤 때 (W, Z, S^{i−1}) 같은 식별을 쓰게 되며, 마르코프 성질 확인(4.7 보충에서 지적한 빈틈)이 바로 본 연구에서도 검증해야 할 지점이다.

5. **기준선(제약 없는 부호)과 도우미 구조.** 도우미 문제의 직접부(4.5의 극대 부호 = 피복)는 "한 쪽이 상대의 복원을 돕기 위해 율 I(X;U)만큼 거칠게 양자화해 보낸다"는 구조다. 본 연구에서 스위치가 복호·재부호화를 할 수 있는 기준선은 스위치가 도우미처럼 Ŝ를 거칠게 양자화해 보내는 것이고, 그 율 ½log₂(1/D̄)은 가우시안 율-왜곡(이 논문 밖)이다. 합 호환 제약은 스위치가 도우미 역할(양자화·재부호화)을 하지 못하게 막는 것이고, 그 비용이 H(Z|S,W) 항으로 나타난다.

6. **DBC 역정리의 직접 관련성은 낮다.** 다만 "메시지를 균등 확률변수 U로 두고 I(U;Zⁿ)과 I(Xⁿ;Yⁿ|U)를 동시에 다루는" 중첩(superposition) 역정리 구조는, 하향 링크 Z를 여러 작업자가 각자 다른 목적으로 쓰는 확장(예: 작업자별 부분합 복원)에서 참고가 된다.
