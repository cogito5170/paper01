## 1. 한 문장 요약
부호 길이(blocklength) n이 유한하고 오류확률 ε이 0이 아닐 때, 압축·전송·결합 부호의 최적 전송률은
"1차 항(섀넌 극한) ± √(분산/n)·Q⁻¹(ε) + O(log n / n)" 꼴로 거의 정확히 잡히며, 그 분산은 항상
**정보 확률변수(information random variable)의 분산**이다.

## 2. 문제 설정 (그림 1)
- 원천 부호화: S^k → {1..M} → Z^k. 성능 = 초과 왜곡 확률(excess-distortion probability) P[d(S^k,Z^k) > d] ≤ ε.
  최소 부호책 크기 M*(k,d,ε), 율 R(k,d,ε) = (1/k) log M*.
- 채널 부호화: {1..M} → X^n → Y^n → {1..M}. 성능 = 평균/최대 오류확률 ≤ ε. 최대율 R*(n,ε) = sup{log M / n}.
- 결합 원천-채널 부호(JSCC, joint source-channel coding): S^k → X^n → Y^n → Z^k, 율 k/n.
- 세 종류의 결과: 달성 한계(achievability bound, 부호가 존재), 역 한계(converse bound, 부호가 존재하지 않음), 근사(approximation, 주된 항까지의 전개).

## 3. 통일 원리: 정보 확률변수
| 문제 | 정보 확률변수 | 평균 | 분산 |
|---|---|---|---|
| 무손실 압축 | ı_S(s) = log 1/P_S(s) (식 6) | H(S) | 바렌트로피(varentropy) V(S) |
| 손실 압축 | d-기울인 정보(d-tilted information) ȷ_S(s,d) = −log E[exp{λ*d − λ*d(s,Z*)}] (식 8), λ* = −R'(d) | R(d) | 원천 분산(source dispersion) V(d) |
| 채널 | 정보 밀도(information density) ı(x;y) = log dP_{Y\|X=x}/dP_Ȳ (y) | C | 채널 분산(channel dispersion) V |

i.i.d.이면 정보 확률변수는 k개 합이므로 중심극한정리(CLT) → 정규 근사. 베리–에센(Berry–Esseen)으로 오차를 O(1/√n) 확률 수준에서 통제하고, 이것이 O(log n / n) 율 항이 된다.

## 4. 주요 결과 (식 번호는 논문 기준)
**원천**
- 무손실 (7): R*(k,ε) = H + √(V/k) Q⁻¹(ε) − (1/2k) log k + O(1/k). (Kontoyiannis–Verdú)
- 손실 (10)–(11): R(k,d,ε) = R(d) + √(V(d)/k) Q⁻¹(ε) + θ(log k / k), 나머지 항: −½ log k / k ≤ θ ≤ (C₀+½) log k / k. (Kostina–Verdú 2012)
- 역 한계 (9), 가설 검정(hypothesis testing) 꼴: M ≥ sup_Q inf_z β_{1−ε}(P_S,Q) / Q[d(S,z) ≤ d].
  해석: (확률 1−ε 집합의 "부피") ÷ (왜곡 공 하나의 부피) = 필요한 공의 최소 개수. 공이 겹치면 느슨해진다.
- 달성 한계: 무작위 부호(random coding). 부호어 M개 중 하나도 s 주위 왜곡 공에 들어가지 않을 확률.
- 가우스–마르코프 (13)–(14): V_U(d) = (1/4π)∫ min{1, (S(w)/θ)²} dw. 역 물 채우기(reverse water-filling)가 분산에도 들어간다.
- 불일치(mismatch) (15): 2차 모멘트만 알 때 R = ½log(σ²/d) + √(V/k)Q⁻¹(ε), V = (E S⁴ − σ⁴)/(4σ⁴). 가우시안이면 V = ½.
- 다단자: 카스피(Kaspi) 문제 2차 율 L* = √V Q⁻¹(ε) (16), 점진 정밀화(successive refinement)는 2차원 가우시안으로 영역 결정.

**채널**
- 정규 근사 (26): R*(n,ε) = C − √(V/n) Q⁻¹(ε) + O(log n / n). (Polyanskiy–Poor–Verdú 2010)
- AWGN (27)–(28): C = ½log(1+P), V = P(2+P) / (2(1+P)²) · log²e.
- 달성 한계: 의존성 검정(DT) 한계, κβ 한계, 섀넌 구면 한계. 역 한계: 메타 역정리(meta-converse). 대부분의 역 한계가 여기서 나온다.
- 준정적 페이딩: 분산 0, R* = C_ε + O(log n / n) (29).
- 세 영역: CLT(ε 고정), 큰 편차(large deviations, R 고정, 오류 지수 E(R)), 중간 편차(moderate deviations) (32).
- 다중 접속 채널(MAC): 분산 행렬, 모서리가 아닌 경계점에서는 비대각 항이 무관 → 국소 2차 분석.
- 대규모 접속: 사용자 수가 n과 함께 커지는 다접속 채널(MnAC), 무출처 무작위 접속(URA, unsourced random access), 사용자별 오류확률(PUPE). 수신 안테나 L = Θ(n²)이면 K = O(n²) 사용자.

**JSCC**
- (34): nC − kR(d) = √(nV + kV(d)) Q⁻¹(ε) + θ(n).
- 분리 부호(SSCC) (36): 분산이 √(nV)Q⁻¹(η) + √(kV(d))Q⁻¹(ζ), η+ζ ≤ ε로 쪼개진다.
- 분리가 지는 이유(가장 좋은 직관): 결합은 {I > J}이면 성공, 분리는 {I > r} ∩ {J < r}이 필요. 후자가 전자의 진부분집합이다.
  두 분산 중 하나가 0이면 분리 손실이 사라진다.

## 5. 열린 문제 (5장)
1. 율-왜곡의 3차 근사(채널은 중간 편차로 n=100, ε=10⁻¹⁰까지 정확함이 알려짐).
2. 가우시안 다단자 손실 압축의 비점근 결과: 카스피 문제 달성 한계, 다중 기술(multiple descriptions) 2차 근사.
3. 셀프리(cell-free) MIMO, 상관 채널, 다원천 JSCC.
4. 실제 부호와 한계 사이의 간극.

## 6. 비판적 평가
- 강점: 원천·채널·JSCC를 "정보 확률변수의 평균과 분산"이라는 한 틀로 묶는다. 결과 표(표 1)와 참고문헌 지도로 유용하다.
- 약점: 증명이 없다. 대규모 접속(3.3절)은 저자 그룹 자신의 결과 비중이 크고, 다단자 원천 부호는 카스피·점진 정밀화 둘뿐이다.
  **부가 정보 부호(Wyner–Ziv), 분산 손실 부호(Berger–Tung), CEO 문제의 유한 길이 결과는 다루지 않는다.**
- 확인한 오탈자: 식 (20)의 ε*(n,R)은 sup이 아니라 inf여야 한다. 11쪽의 R(d) = sup_{k→∞} R(k,d,ε)는 극한으로 읽어야 한다. 3쪽 "probabilityeither" 등 조판 오류.

## 7. 내 연구(군 합 CEO)와의 연결
- **우리 W2–W5는 사실상 1회 전송(one-shot, n=1) 영역이다.** 이 서베이의 "단일 샷 표기"(S를 블록 전체로 보는 표기, 8쪽)와 같은 관점이다.
  우리의 점근은 n→∞가 아니라 **작업자 수 K→∞**다. 구조상 3.3절 대규모 접속(사용자 수가 커지는 영역)에 더 가깝다.
- 목표 사다리 A단(블록 부호, 열린 문제 O3)에서 블록 길이 n을 유한하게 두면, 이 서베이의 2차 항 틀이 그대로 질문이 된다:
  "군 합 제약이 1차 항 대가 ½log K 외에 분산 항에도 대가를 주는가?"
- 열린 문제 O2(일반 부호기, 보조정리 L)에 대한 후보 도구: 가설 검정 역 한계 (9)와 메타 역정리는 **임의의 부호**에 대해 성립한다.
  H(Z|X,W) 하한을 "Z의 분포 vs 보조 분포 Q"의 검정 문제로 바꾸는 경로를 검토할 가치가 있다. (아직 아이디어 단계)
- 추가로 읽을 것: Zhou–Motani 모노그래프 [13](다단자 유한 길이), Kostina–Verdú 2012 [10](d-기울인 정보의 원본),
  Polyanskiy–Poor–Verdú 2010 [11](메타 역정리). 부가 정보 쪽은 이 서베이 밖이다: Watanabe–Kuzuoka–Tan 2015
  ("Nonasymptotic and second-order achievability bounds for coding with side-information") 확인 필요.

## 8. 직접 할 것 (손 유도)
1. 무손실 (7)의 주된 두 항: ı_{S^k} = Σ ı_S(S_i)에 CLT를 적용해 √(V/k)Q⁻¹(ε)를 얻는다.
2. 가우시안 원천에서 ȷ_S(s,d) = ½log(σ²/d) + (s²/σ² − 1)/2 · log e 를 식 (8)에서 계산하고, V(d) = ½ log²e를 확인한다.
   (불일치 식 (15)에서 E S⁴ = 3σ⁴를 넣은 값과 일치해야 한다.)
3. AWGN 분산 (28)을 정보 밀도의 분산으로 계산한다.
4. JSCC 직관: (I, J) 평면에 {I>J}와 {I>r}∩{J<r}를 그린다.
