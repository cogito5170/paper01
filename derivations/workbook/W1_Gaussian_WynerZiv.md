## 0. 문제와 목표 정리

**설정.** X ~ N(0, P), Y = X + N, N ~ N(0, 𝒩)는 X와 독립. (Xᵢ, Yᵢ), i = 1, …, n은 i.i.d.

**부호.** 부호기 m: ℝⁿ → {1, …, 2^{nR}}는 Xⁿ만 본다. 복호기 x̂ⁿ(m, Yⁿ)는 메시지와 부가 정보 Yⁿ을 본다. 왜곡은 D(부호) = (1/n) Σᵢ E(Xᵢ − X̂ᵢ)².

**정리 W1.** 정의 σ² := Var(X | Y). 그러면

$$R_{\mathrm{WZ}}(D) = \tfrac12 \log^+ \frac{\sigma^2}{D}.$$

즉 (i) 모든 R > ½log(σ²/D)에서 왜곡 D + ε을 내는 부호가 있고 (달성), (ii) 왜곡 D 이하를 내는 모든 부호는 R ≥ ½log(σ²/D)를 만족한다 (역).

**연습 0.1** σ²를 P, 𝒩로 써라. □

<details><summary>답</summary>

σ² = P − Cov(X,Y)²/Var(Y) = P − P²/(P+𝒩) = P𝒩/(P+𝒩). 가우시안에서는 조건부 분산이 Y값에 무관하다.
</details>

**연습 0.2** P = 𝒩 = 1, D = 0.1일 때 정리 W1의 율을 계산하라. □

<details><summary>답</summary>

σ² = 0.5, R = ½log₂ 5 ≈ 1.161비트.
</details>

## 1부. 달성: 시험 채널을 고르고 정보량을 계산한다

일반 Wyner–Ziv 정리(교재 3.4절, [원문] 슬라이드 12–16)를 **그대로 쓴다.**

> R_WZ(D) = min I(X; U | Y), 최소는 p(u|x)와 x̂(u, y)에 대해, 조건 E(X − x̂(U,Y))² ≤ D.
> U – X – Y가 마르코프 사슬이므로 I(X;U|Y) = I(X;U) − I(Y;U).

연속 소스로의 확장은 교재 2.7절이다(그 노트에서 세부는 [미확인]). 이 작업장에서는 확장을 받아들인다.

따라서 달성은 **좋은 U 하나를 고르고 I(X;U|Y)를 계산**하면 끝난다.

**선택.** U = X + V, V ~ N(0, Q)는 (X, N)과 독립. 복원 x̂(U,Y) = E[X | U, Y].

| 단계 | 주장 | 근거 (채울 것) |
|---|---|---|
| 1.1 | U – X – Y는 마르코프 사슬이다 | □ |
| 1.2 | E(X − E[X\|U,Y])² = (1/P + 1/𝒩 + 1/Q)⁻¹ = (1/σ² + 1/Q)⁻¹ | □ |
| 1.3 | 왜곡을 정확히 D로 맞추는 Q는 1/Q = 1/D − 1/σ² (D < σ²일 때) | □ |
| 1.4 | I(X;U\|Y) = h(U\|Y) − h(U\|X,Y) | □ |
| 1.5 | h(U\|X,Y) = h(V) = ½log(2πeQ) | □ |
| 1.6 | h(U\|Y) = ½log(2πe(σ² + Q)) | □ |
| 1.7 | I(X;U\|Y) = ½log((σ²+Q)/Q) = ½log(σ²/D) | □ (대수) |
| 1.8 | D ≥ σ²이면 율 0으로 충분하다 | □ |

<details><summary>힌트</summary>

- 1.1: V는 (X, N)과 독립이다. U는 X와 V의 함수, Y는 X와 N의 함수.
- 1.2: 가우시안 사후 분포. 사전 정밀도(분산의 역수)는 1/P, 관측 Y = X + N과 U = X + V는 X가 주어지면 독립이고 각각 정밀도 1/𝒩, 1/Q를 더한다. 1/P + 1/𝒩 = 1/σ²임도 확인하라.
- 1.5: 조건 (X, Y)가 주어지면 U − X = V이고, 평행 이동은 미분 엔트로피를 바꾸지 않는다. V가 (X,Y)와 독립.
- 1.6: (U, Y)는 결합 가우시안이고 U = X + V, V ⊥ (X,Y)이므로 Var(U|Y) = Var(X|Y) + Q.
- 1.7: 1/D = 1/σ² + 1/Q를 써서 (σ² + Q)/Q = σ²(1/σ² + 1/Q) = σ²/D.
- 1.8: X̂ = E[X | Y]만으로 왜곡 σ².
</details>

**연습 1.9 (부호가 실제로 하는 일).** 교재 3.4절의 달성 부호는 덮개(covering) 율 R̃ > I(X;U)로 양자화하고, 비닝으로 R > I(X;U) − I(Y;U)만 보낸다. P = 𝒩 = 1, D = 0.1에서 Q, I(X;U), I(Y;U)를 계산하고 차이가 1.161인지 확인하라. □

<details><summary>답</summary>

Q = 1/(10 − 2) = 0.125. I(X;U) = ½log₂((P+Q)/Q) = ½log₂ 9 ≈ 1.585. I(Y;U) = ½log₂(Var U / Var(U|Y)) = ½log₂(1.125/0.625) = ½log₂ 1.8 ≈ 0.424. 차이 ≈ 1.161 = ½log₂ 5. 덮개는 1.585비트가 들지만, 서버가 Yⁿ으로 빈 안의 후보를 가려내므로 0.424비트를 아낀다.
</details>

**연습 1.10 (정리를 거치지 않는 직관 점검).** 같은 율을 부호기도 Y를 아는 경우(조건부 율-왜곡 R_{X|Y}(D))와 비교하라. 왜 같아도 이상하지 않은가? □

<details><summary>힌트</summary>

R_{X|Y}(D) = ½log(σ²/D)는 X − E[X|Y]를 부호화하는 점대점 문제다. 가우시안 Wyner–Ziv에서는 "부가 정보를 부호기가 몰라도 손해가 없다." 이것이 2부 역정리에서 바로 드러난다.
</details>

## 2부. 역: 어떤 부호도 ½log(σ²/D)보다 적게 쓸 수 없다

**보조 변수 없이 끝나는 직접 증명이다.** 일반 Wyner–Ziv 역(3부)보다 짧고, 이 연구의 역정리 1~3단계와 같은 모양이라 먼저 손에 익힌다.

임의의 부호 (m, x̂ⁿ)가 D(부호) ≤ D를 만족한다고 하자. M = m(Xⁿ), X̂ᵢ = x̂ᵢ(M, Yⁿ), Dᵢ = E(Xᵢ − X̂ᵢ)².

| 단계 | 식 | 근거 (채울 것) |
|---|---|---|
| (a) | nR ≥ H(M) | □ |
| (b) | H(M) ≥ H(M \| Yⁿ) | □ |
| (c) | H(M \| Yⁿ) ≥ I(Xⁿ; M \| Yⁿ) | □ **이 단계를 기억하라 (2.4)** |
| (d) | I(Xⁿ; M \| Yⁿ) = h(Xⁿ \| Yⁿ) − h(Xⁿ \| M, Yⁿ) | □ |
| (e) | h(Xⁿ \| Yⁿ) = (n/2) log(2πe σ²) | □ |
| (f) | h(Xⁿ \| M, Yⁿ) ≤ Σᵢ h(Xᵢ \| M, Yⁿ) | □ |
| (g) | h(Xᵢ \| M, Yⁿ) = h(Xᵢ − X̂ᵢ \| M, Yⁿ) | □ |
| (h) | h(Xᵢ − X̂ᵢ \| M, Yⁿ) ≤ h(Xᵢ − X̂ᵢ) | □ |
| (i) | h(Xᵢ − X̂ᵢ) ≤ ½ log(2πe Dᵢ) | □ |
| (j) | Σᵢ ½log(2πe Dᵢ) ≤ (n/2) log(2πe D) | □ |
| (k) | 위를 모으면 R ≥ ½log(σ²/D) | □ (대수) |

<details><summary>힌트</summary>

- (a) 이산 확률변수의 엔트로피는 값 개수의 로그 이하.
- (b) 조건을 걸면 엔트로피는 줄거나 같다.
- (c) I(Xⁿ;M|Yⁿ) = H(M|Yⁿ) − H(M|Xⁿ,Yⁿ)이고, 이산 M에 대해 H(M|Xⁿ,Yⁿ) ≥ 0. (사실 M = m(Xⁿ)이라 0이다.)
- (d) 상호 정보의 정의를 연속 변수 쪽에서 쓴 것.
- (e) (Xᵢ,Yᵢ)가 i.i.d.라 연쇄 법칙이 합으로 갈라지고, 가우시안 X|Y의 미분 엔트로피.
- (f) 연쇄 법칙 + 조건을 줄이면 엔트로피가 커진다(과거 X^{i−1} 조건을 버림).
- (g) X̂ᵢ는 (M, Yⁿ)의 함수. 조건이 주어지면 상수 이동.
- (h) 조건을 버리면 엔트로피는 커지거나 같다.
- (i) 2차 모멘트가 정해진 실수 확률변수 중 미분 엔트로피 최대는 가우시안. 평균이 0이 아니어도 분산 ≤ 2차 모멘트라 성립.
- (j) log의 오목성(옌센): (1/n)Σ log Dᵢ ≤ log((1/n)Σ Dᵢ) ≤ log D. 마지막은 log의 단조성.
</details>

<details><summary>답 (전체 연결)</summary>

nR ≥ I(Xⁿ;M|Yⁿ) = (n/2)log(2πeσ²) − h(Xⁿ|M,Yⁿ) ≥ (n/2)log(2πeσ²) − (n/2)log(2πeD) = (n/2)log(σ²/D). 양변을 n으로 나누면 끝. D ≥ σ²이면 우변이 음수라 R ≥ 0이 자명하므로 log⁺.
</details>

**연습 2.1** (c)에서 버린 항 H(M | Xⁿ, Yⁿ)는 이 문제에서 정확히 얼마인가? □

<details><summary>답</summary>

0. M = m(Xⁿ)은 Xⁿ의 결정적 함수다. 부호기가 무작위(공유 난수 W)를 쓰더라도 W를 조건에 넣으면 0이다.
</details>

**연습 2.2** 이 증명이 역정리로서 Wyner–Ziv 정리 전체(R = min I(X;U|Y))가 아니라 가우시안 경우만 증명하는 이유는 어느 단계 때문인가? □

<details><summary>답</summary>

(i)와 (e). 가우시안 최대 엔트로피와 X|Y가 가우시안이라는 사실을 썼다. 일반 소스에서는 3부처럼 보조 변수 Uᵢ를 만들어야 한다.
</details>

**연습 2.3** 1부의 결과와 2부의 결과가 일치함을 확인하고, "부호기가 Y를 몰라도 손해가 없다"는 말을 이 두 증명으로 정당화하라. □

**2.4 이 연구로 넘어가는 다리 (꼭 해 볼 것).** 이 연구의 군 합 CEO에서는 복호기가 M 대신 군 합 Z = Q₁ ⊕ ⋯ ⊕ Q_K를 본다. 2부와 같은 사슬을 Z로 쓰면

log|G| ≥ H(Z | W) = I(X; Z | W) + H(Z | X, W)

가 된다. 2부의 (c)는 둘째 항을 버리는 단계와 같다.

**연습 2.4** Wyner–Ziv에서 그 항은 0이었다(연습 2.1). 군 합에서는 왜 0이 아닌가? Z가 X의 함수가 되지 못하는 이유를 한 문장으로 쓰라. □

<details><summary>힌트</summary>

X와 W를 조건으로 두어도 각 Q_k = f_k(X + N_k, W)에는 작업자 잡음 N_k가 남는다. Z는 K개의 서로 독립인 흔들림을 더한 것이다. 이 항의 하한 ½log₂K − c가 이 연구의 핵심 보조정리 L이다(SPEC P.6, draft.md 정리 골격 v1).
</details>

## 3부 (선택). 일반 Wyner–Ziv 역: 보조 변수를 만드는 법

가우시안이 아닐 때 쓰는 증명이다. 교재 3.4절 "역 증명"을 옆에 두고 채운다. 핵심은 Uᵢ := (M, Y^{i−1}, Y_{i+1}^n)로 두는 것이다.

| 단계 | 식 | 근거 (채울 것) |
|---|---|---|
| 3.1 | nR ≥ H(M) ≥ H(M\|Yⁿ) ≥ I(Xⁿ;M\|Yⁿ) | 2부 (a)–(c) |
| 3.2 | I(Xⁿ;M\|Yⁿ) = Σᵢ I(Xᵢ; M \| Yⁿ, X^{i−1}) | □ |
| 3.3 | = Σᵢ [h(Xᵢ\|Yⁿ,X^{i−1}) − h(Xᵢ\|M,Yⁿ,X^{i−1})] ≥ Σᵢ [h(Xᵢ\|Yᵢ) − h(Xᵢ\|M,Yⁿ)] | □ (두 가지 사실) |
| 3.4 | = Σᵢ I(Xᵢ; Uᵢ \| Yᵢ) | □ |
| 3.5 | Uᵢ – Xᵢ – Yᵢ는 마르코프 사슬이다 | □ |
| 3.6 | X̂ᵢ는 (Uᵢ, Yᵢ)의 함수다 | □ |
| 3.7 | 시분할 변수 Q ~ 균일{1..n}을 넣어 R ≥ I(X;U\|Y), U = (U_Q, Q) | □ |

<details><summary>힌트</summary>

- 3.2: 연쇄 법칙.
- 3.3: (Xᵢ,Yᵢ)가 i.i.d.라 Xᵢ는 (Y^{i−1}, Y_{i+1}^n, X^{i−1})과 Yᵢ가 주어지면 독립이다(첫 항이 H(Xᵢ|Yᵢ)로 같아짐). 둘째 항은 조건 X^{i−1}을 버려 커짐.
- 3.5: M은 Xⁿ의 함수다. (M, Y^{i−1}, Y_{i+1}^n)은 (Xⁿ, Y^{i−1}, Y_{i+1}^n)의 함수이고, 이것은 Xᵢ가 주어지면 Yᵢ와 독립이다.
- 3.6: X̂ᵢ = x̂ᵢ(M, Yⁿ)이고 Yⁿ = (Y^{i−1}, Yᵢ, Y_{i+1}^n).
- 3.7: (1/n)Σᵢ I(Xᵢ;Uᵢ|Yᵢ) = I(X_Q; U_Q | Y_Q, Q) = I(X_Q; U_Q, Q | Y_Q) (Q가 (X_Q,Y_Q)와 독립). 왜곡 조건도 Q로 평균된다.
</details>
