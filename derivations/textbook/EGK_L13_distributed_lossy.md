### 2.1 전형열(typical sequence) [원문, 슬라이드 2–14~2–16, PDF 34–35쪽]

**유형(type, 경험 분포).** π(x|xⁿ) = |{i : xᵢ = x}|/n.

**ε-전형 집합.** T_ε^{(n)}(X) = {xⁿ : |π(x|xⁿ) − p(x)| ≤ ε·p(x) ∀x}. 쌍·삼중은 묶어서 하나의 확률변수로 본다. 허용 오차가 상대적(ε·p(x))이다.

**전형 평균 보조정리(typical average lemma).** xⁿ ∈ T_ε^{(n)}이면 g ≥ 0에 대해 (1−ε)E g(X) ≤ (1/n)Σᵢ g(xᵢ) ≤ (1+ε)E g(X).
증명: (1/n)Σ g(xᵢ) − E g(X) = Σₓ (π(x|xⁿ) − p(x)) g(x)의 절댓값 ≤ Σₓ εp(x)g(x). ∎ — **왜곡 분석의 마지막 단계는 항상 이것이다**: (xⁿ, x̂ⁿ)이 전형이면 (1/n)Σ d(xᵢ, x̂ᵢ) ≤ (1+ε)E d(X, X̂).

**성질.** (1) xⁿ ∈ T_ε^{(n)}이면 2^{−n(H(X)+δ(ε))} ≤ p(xⁿ) ≤ 2^{−n(H(X)−δ(ε))}, δ(ε) = εH(X) (g = −log p로 위 보조정리). (2) |T_ε^{(n)}| ≤ 2^{n(H(X)+δ(ε))}. (3) 대수의 법칙(LLN)으로 P{Xⁿ ∈ T_ε^{(n)}} → 1. (4) n이 크면 |T_ε^{(n)}| ≥ (1−ε)2^{n(H(X)−δ(ε))}. 조건부판: yⁿ ∈ T_ε^{(n)}(Y|xⁿ) := {yⁿ : (xⁿ,yⁿ) ∈ T_ε^{(n)}}이면 p(yⁿ|xⁿ) ≐ 2^{−nH(Y|X)}, |T_ε^{(n)}(Y|xⁿ)| ≤ 2^{n(H(Y|X)+δ(ε))}.

### 2.2 조건부 전형성 보조정리 [원문, 슬라이드 2–19, 2–23, PDF 37, 39쪽]

**진술.** xⁿ ∈ T_{ε′}^{(n)}(X), Yⁿ ~ ∏ p_{Y|X}(yᵢ|xᵢ)이면 ε > ε′일 때 P{(xⁿ, Yⁿ) ∈ T_ε^{(n)}(X,Y)} → 1.
증명 개요: 기호 x가 나타나는 nπ(x|xⁿ) ≈ np(x)개 자리에서 Yᵢ는 i.i.d. p(y|x)이므로, LLN으로 그 자리들 중 y의 비율 → p(y|x). 그러면 π(x,y) ≈ π(x)p(y|x)이고, π(x)가 이미 p(x)에서 ε′p(x)만큼 벗어나 있을 수 있으므로 여유 ε − ε′ > 0이 있어야 결합 편차를 ε 안에 넣을 수 있다. ∎

**마르코프판 (2–23).** X → Y → Z이고 (xⁿ,yⁿ) ∈ T_{ε′}^{(n)}, Zⁿ ~ ∏ p_{Z|Y}(zᵢ|yᵢ)이면 P{(xⁿ,yⁿ,Zⁿ) ∈ T_ε^{(n)}} → 1. 증명: 마르코프성으로 p_{Z|Y}(z|y) = p_{Z|X,Y}(z|x,y)이므로 (X,Y)를 하나로 보고 위 보조정리. ∎
**주의.** 이것은 Zⁿ이 **i.i.d. 조건부 분포**로 생성될 때만 쓸 수 있다. 버거–텅에서 U₂ⁿ(L₂)는 부호책에서 "골라진" 열이라 i.i.d.가 아니다 → 마르코프 보조정리(3.3절)가 필요하다.

### 2.3 결합 전형성 보조정리 [원문, 슬라이드 2–24, PDF 39쪽]

(X,Y,Z) ~ p, (xⁿ,yⁿ) ∈ T_ε^{(n)}, Z̃ⁿ ~ ∏ p_{Z|X}(z̃ᵢ|xᵢ) (Y를 무시하고 생성)이면
(a) P{(xⁿ,yⁿ,Z̃ⁿ) ∈ T_ε^{(n)}} ≤ 2^{−n(I(Y;Z|X)−δ(ε))}, (b) n이 크면 ≥ (1−ε)2^{−n(I(Y;Z|X)+δ(ε))}.
증명 개요 (a): 합 = Σ_{z̃ⁿ ∈ T(Z|xⁿ,yⁿ)} p(z̃ⁿ|xⁿ) ≤ 2^{n(H(Z|X,Y)+δ)}·2^{−n(H(Z|X)−δ)}. (b)는 집합 크기 하한을 쓴다. ∎
**한 줄 직관.** "엉뚱하게 만든 열이 우연히 맞아떨어질 확률 ≈ 2^{−n·(놓친 상호정보)}".

### 2.4 덮개 보조정리(covering lemma) [원문, 슬라이드 3–51~3–53, PDF 70–71쪽]

**진술.** (U,X,X̂) ~ p. (Uⁿ,Xⁿ)이 P{(Uⁿ,Xⁿ) ∈ T_ε^{(n)}} → 1을 만족하고, X̂ⁿ(m), m ∈ 𝒜, |𝒜| ≥ 2^{nR}가 Uⁿ이 주어지면 서로·Xⁿ과 조건부 독립이고 각각 ∏ p_{X̂|U}(x̂ᵢ|uᵢ)를 따르면, R > I(X;X̂|U) + δ(ε)일 때
P{(Uⁿ,Xⁿ,X̂ⁿ(m)) ∉ T_ε^{(n)} ∀m ∈ 𝒜} → 0.

**증명** [원문 3–53]. E₀ = {(Uⁿ,Xⁿ) ∉ T_ε^{(n)}}. P(E) ≤ P(E₀) + P(E ∩ E₀ᶜ), 첫 항 → 0. (uⁿ,xⁿ) ∈ T_ε^{(n)}로 고정하면 2.3(b)로 각 m에 대해 P{(uⁿ,xⁿ,X̂ⁿ(m)) ∈ T} ≥ 2^{−n(I(X;X̂|U)+δ)}. 독립이므로
P{전부 실패} ≤ (1 − 2^{−n(I+δ)})^{|𝒜|} ≤ exp(−|𝒜|·2^{−n(I+δ)}) ≤ exp(−2^{n(R−I−δ)}) → 0. (부등식 1 − x ≤ e^{−x}.) ∎
**직관.** 조건부 전형 공 하나가 차지하는 비율이 2^{−nI}이므로 2^{nI}개보다 많이 뿌리면 Xⁿ 주변에 하나는 떨어진다. 이것이 "양자화(quantization)"의 정보이론적 정의다: 율 I(X;U)로 Xⁿ을 Uⁿ 하나로 대표한다.

**벡터 양자화(vector quantization) 한 줄 설명** [재구성]. 스칼라 양자화는 각 Xᵢ를 따로 반올림한다. 벡터 양자화는 n개 묶음 Xⁿ 전체를 부호책의 열 하나 uⁿ(l)로 바꾼다. 덮개 보조정리에서 "Xⁿ과 결합 전형인 uⁿ(l)을 찾기"가 바로 벡터 양자화이고, 그 결과 (Xⁿ, Uⁿ)은 마치 시험 채널(test channel) p(u|x)를 통과한 것처럼 결합 전형이 된다. 버거–텅의 1단계는 이것을 각 부호기가 따로 한다.

### 2.5 채움 보조정리(packing lemma) [원문, 슬라이드 3–18~3–20, PDF 53–54쪽]

**진술.** (U,X,Y) ~ p. (Ũⁿ,Ỹⁿ)은 임의 분포. Xⁿ(m), m ∈ 𝒜, |𝒜| ≤ 2^{nR}, 각각 ∏ p_{X|U}(xᵢ|ũᵢ)를 따르고 Ũⁿ이 주어지면 Ỹⁿ과 (쌍별) 조건부 독립(서로 간에는 임의 의존 가능). 그러면 R < I(X;Y|U) − δ(ε)일 때 P{(Ũⁿ,Xⁿ(m),Ỹⁿ) ∈ T_ε^{(n)} for some m ∈ 𝒜} → 0.

**증명** [원문 3–20]. 합집합 한계(union bound)로 ≤ Σ_m P(E_m), 각 P(E_m) ≤ 2^{−n(I(X;Y|U)−δ)} (2.3(a), 전형인 (ũⁿ,ỹⁿ)에 대해 평균). 합 ≤ 2^{−n(I−R−δ)} → 0. ∎ — 합집합 한계만 쓰므로 **같은 부호책 안의 열끼리는 어떻게 의존해도 된다**. 이 점이 상호 채움 보조정리(3.4절)의 핵심이다.

### 2.6 와이너–지브 정리와 "상자 1로 줄이기" [원문, Lecture 12, 슬라이드 12–17, 12–21~12–24, 12–36~12–37, PDF 301–304, 310–311쪽]

**정리.** 복호기만 부가 정보 Y를 가질 때 R_{SI-D}(D) = min [I(X;U) − I(Y;U)] = min I(X;U|Y), 최소는 p(u|x)와 x̂(u,y)에 대해 (|𝒰| ≤ |𝒳|+1). 두 식이 같은 이유: U → X → Y이므로 I(X;U) − I(Y;U) = I(X,Y;U) − I(Y;U) = I(X;U|Y).

**달성 구조.** 2^{nR̃}개 uⁿ(l) ~ ∏p_U, 2^{nR}개 상자에 균등 분할. 부호기: 덮개(R̃ > I(X;U)); 상자 번호 전송. 복호기: 상자 안에서 yⁿ과 결합 전형인 유일한 l̂ (채움: R̃ − R < I(Y;U)). 오류 사건 E₁(덮개 실패), E₂(=(Uⁿ(L),Yⁿ) 비전형: 조건부 전형성 보조정리로 처리 — 여기서는 Yⁿ이 (Uⁿ(L),Xⁿ)이 주어지면 **i.i.d.** p(y|x)이므로 2.2로 충분), E₃(같은 상자의 다른 l̃이 전형).

**보조정리 1 (12장): P(E₃) ≤ P{(Uⁿ(l̃),Yⁿ) ∈ T for some l̃ ∈ B(1)}** [원문 증명 PDF 310–311쪽]. 문제: L은 Xⁿ에 의존해 골라지므로, L = l이 주어지면 나머지 부호어들은 더 이상 i.i.d. p_U가 아니다(예: 지표가 l보다 작은 부호어들은 "Xⁿ과 전형이 아니었다"는 조건을 받는다). 해결: L = l이 주어지면 l 이외의 부호어들 중 **아무 2^{n(R̃−R)} − 1개 묶음이나 분포가 같다**(부호어의 대칭성). 그래서 B(m) \ {l}을 B(1)의 같은 개수(또는 그 이상)로 바꿔도 확률이 작아지지 않고, M = m 조건을 평균하면 결론. 마지막으로 B(1)의 부호어들은 (m ≠ 1일 때) Yⁿ과 독립이고 ∏p_U를 따르므로 채움 보조정리를 적용한다. ∎ (m = 1인 경우는 자명하게 성립.)

**2차 가우시안 와이너–지브** (12–18): X ~ N(0,P), Y = X + Z, Z ~ N(0,N). P′ := Var(X|Y) = PN/(P+N). U = X + V, V ~ N(0,Q), Q = P′D/(P′−D)이면 I(X;U|Y) = R(P′/D) = R_{SI-ED}(D). 즉 가우시안에서는 부가 정보를 부호기가 몰라도 손해가 없다. 13장 정리 1에서 R₂ → ∞(U₂ = X₂)로 두면 이 결과가 나온다.

### 2.7 미분 엔트로피 도구 [원문, 슬라이드 2–7~2–9, PDF 31–32쪽]

- 평행 이동 h(Xⁿ + aⁿ) = h(Xⁿ), 축척 h(AXⁿ) = h(Xⁿ) + log|det A|. 가우시안 Xⁿ ~ N(μ, K): h = ½ log((2πe)ⁿ|K|).
- **최대 미분 엔트로피 보조정리.** K_{X|Y} = MMSE 오차 공분산이면 h(Xⁿ|Yᵏ) ≤ ½ log((2πe)ⁿ|K_{X|Y}|), 결합 가우시안일 때 등호. 특히 X̂ = g(Y)가 **아무** 추정기여도 h(X|Y) ≤ h(X − X̂) ≤ ½ log((2πe)ⁿ|K_{X−X̂}|) (평행 이동 불변 + 조건 축소 + 가우시안 최대).
- **스칼라 MSE판.** h(X|X̂) ≤ ½ log(2πe E(X−X̂)²).
- **log det의 오목성(concavity).** K ↦ log|K|는 양정치 행렬 위에서 오목 ⇒ (1/n)Σ log|Kᵢ| ≤ log|(1/n)ΣKᵢ| (옌센). 스칼라판: (1/n)Σ log Dᵢ ≤ log((1/n)ΣDᵢ). 역정리의 "단일 문자화 후 평균" 단계에 매번 쓰인다. [재구성: 오목성 자체는 표준 사실]
- **행렬 단조성.** 0 ≺ A ⪯ B이면 |A| ≤ |B|, B⁻¹ ⪯ A⁻¹. [재구성: 표준 사실]

### 2.8 엔트로피 거듭제곱 부등식(EPI) [원문, 슬라이드 2–8~2–9, PDF 31–32쪽]

- **스칼라.** X, Z 독립, Y = X + Z이면 2^{2h(Y)} ≥ 2^{2h(X)} + 2^{2h(Z)}, 둘 다 가우시안일 때 등호.
- **벡터.** Xⁿ, Zⁿ 독립 n-벡터이면 2^{2h(Yⁿ)/n} ≥ 2^{2h(Xⁿ)/n} + 2^{2h(Zⁿ)/n}, 등호는 공분산이 비례하는 가우시안.
- **조건부.** U가 주어지면 Xⁿ, Zⁿ이 조건부 독립이면 2^{2h(Yⁿ|U)/n} ≥ 2^{2h(Xⁿ|U)/n} + 2^{2h(Zⁿ|U)/n}. 증명 [재구성; 원문은 "follows from the above"]: a(u) := (2/n)h(Xⁿ|U=u), b(u) := (2/n)h(Zⁿ|U=u)라 하자. U = u마다 벡터 EPI로 (2/n)h(Yⁿ|U=u) ≥ log(2^{a(u)} + 2^{b(u)}). 양변을 U에 대해 평균하고, f(a,b) = log(2^a + 2^b)가 (a,b)에 대해 볼록(log-sum-exp)이므로 옌센 부등식 E f(a(U),b(U)) ≥ f(E a, E b)를 쓰면 (2/n)h(Yⁿ|U) ≥ log(2^{(2/n)h(Xⁿ|U)} + 2^{(2/n)h(Zⁿ|U)}). ∎
- **여러 항.** 조건부 독립인 항 K개의 합이면 2^{2h(ΣXₖ|U)/n} ≥ Σₖ 2^{2h(Xₖ|U)/n} (두 항짜리를 귀납).
- **"엔트로피 거듭제곱" 이름의 뜻.** N(X) := 2^{2h(X)/n}/(2πe)는 X와 엔트로피가 같은 i.i.d. 가우시안의 분산이다. EPI = "독립 합의 유효 분산 ≥ 유효 분산의 합" — 가우시안이 가장 덜 퍼진다. 역정리에서 EPI는 **"메시지를 알아도 남는 불확실성"을 잡음 쪽과 신호 쪽으로 쪼개는** 데 쓰인다.

### 2.9 MMSE, 선형 MMSE, 역행렬 보조정리 [원문, Appendix B, 슬라이드 B–9~B–10, PDF 624쪽]

- 선형 MMSE: X̂ = K_{XY}K_Y⁻¹(Y − EY) + EX, 오차 공분산 K_X − K_{XY}K_Y⁻¹K_{YX}. 일반 MMSE는 이보다 나쁘지 않다: E[Var(X|Y)] ⪯ K_X − K_{XY}K_Y⁻¹K_{YX}. 가우시안에서는 같다.
- **역행렬 보조정리(matrix inversion lemma).** (K₁₁ − K₁₂K₂₂⁻¹K₂₁)⁻¹ = K₁₁⁻¹ + K₁₁⁻¹K₁₂(K₂₂ − K₂₁K₁₁⁻¹K₁₂)⁻¹K₂₁K₁₁⁻¹.
- **정보 형식(information form)** [재구성]. Y = HX + Z, Z ~ (0, K_Z)가 X와 무상관이면 선형 MMSE 오차 공분산 = (K_X⁻¹ + HᵀK_Z⁻¹H)⁻¹. 증명: 역행렬 보조정리에 K₁₁ = K_X⁻¹, K₁₂ = −Hᵀ, K₂₁ = −H, K₂₂ = −K_Z를 넣으면 좌변 = (K_X⁻¹ + HᵀK_Z⁻¹H)⁻¹, 우변 = K_X − K_XHᵀ(HK_XHᵀ + K_Z)⁻¹HK_X (= 선형 MMSE 오차 공분산). 직관: **정밀도(precision, 역분산)는 독립 관측마다 더해진다.** 스칼라 예(B–10): Yᵢ = X + Zᵢ, i = 1..n이면 MSE = PN/(nP + N), 즉 1/MSE = 1/P + n/N. CEO 문제 전체가 이 한 줄 위에 서 있다.

### 2.10 가우시안 율-왜곡 [원문, 슬라이드 3–54, PDF 71쪽]

X ~ WGN(P), 제곱 오차: R(D) = R(P/D) = ½ log⁺(P/D). 역정리 한 줄: nR ≥ I(Xⁿ;X̂ⁿ) ≥ Σ[h(Xᵢ) − h(Xᵢ|X̂ᵢ)] ≥ Σ ½ log(P/Dᵢ) ≥ (n/2) log(P/D) (최대 엔트로피 + 옌센). 이 계산이 13장 모든 가우시안 역정리의 첫 줄이다.

## 3. 강의 본문 — 절 순서대로

### 3.1 문제 설정 [원문, 슬라이드 13–2~13–3, PDF 312–313쪽]

**소스.** 2-DMS (X₁, X₂): (X₁ᵢ, X₂ᵢ)가 i.i.d. ~ p(x₁, x₂). 왜곡 척도 d₁(x₁, x̂₁), d₂(x₂, x̂₂).

**부호 (2^{nR₁}, 2^{nR₂}, n).** 부호기 j = 1, 2가 xⱼⁿ만 보고 mⱼ(xⱼⁿ) ∈ [1 : 2^{nRⱼ})를 정한다. 복호기는 (m₁, m₂)에서 (x̂₁ⁿ, x̂₂ⁿ)을 만든다.

**달성 가능.** limsup_n E dⱼ(Xⱼⁿ, X̂ⱼⁿ) ≤ Dⱼ (j = 1, 2)인 부호열이 있으면 (R₁,R₂)는 (D₁,D₂)로 달성 가능. 여기서 d(xⁿ, x̂ⁿ) = (1/n)Σ d(xᵢ, x̂ᵢ). 율-왜곡 영역 ℛ(D₁,D₂) = 달성 가능한 (R₁,R₂)의 폐포. **일반적으로 모른다.**

**무엇이 어려운가 (직관)** [재구성]. 한 부호기 문제에서는 "Xⁿ을 양자화해서 Uⁿ을 보낸다"로 끝난다. 여기서는 (i) 각 부호기가 자기 소스만 보고 양자화해야 하고(협력 불가), (ii) 두 양자화 결과 U₁ⁿ, U₂ⁿ이 소스 상관 때문에 서로 상관되어 있으니 그 상관을 율 절약에 쓰고 싶다(슬레피안–울프식 비닝), (iii) 그런데 Uⁿ은 부호기가 고른 것이라 분포가 i.i.d.가 아니어서 상관을 분석하기 어렵다(마르코프 보조정리). 역정리 쪽은 보조 변수 Uⱼ에 장기 마르코프 사슬 U₁ – X₁ – X₂ – U₂를 강제할 방법이 없다는 것이 근본 난점이다.

### 3.2 버거–텅 내부 경계 (정리 1) [원문, 슬라이드 13–4~13–5, PDF 313–314쪽]

**정리 1 (Berger–Tung inner bound, Tung 1978).** (R₁,R₂)는 다음을 만족하면 (D₁,D₂)로 달성 가능하다:
- R₁ > I(X₁;U₁|U₂,Q),
- R₂ > I(X₂;U₂|U₁,Q),
- R₁ + R₂ > I(X₁,X₂;U₁,U₂|Q),

어떤 분포 p(q)p(u₁|x₁,q)p(u₂|x₂,q) (|U₁| ≤ |X₁| + 4, |U₂| ≤ |X₂| + 4)와 함수 x̂₁(u₁,u₂,q), x̂₂(u₁,u₂,q)에 대해 Dⱼ ≥ E dⱼ(Xⱼ, X̂ⱼ). Q는 시분할(time sharing) 변수.

**분포의 구조가 핵심.** p(q)p(x₁,x₂)p(u₁|x₁,q)p(u₂|x₂,q)이므로 Q가 주어지면 **장기 마르코프 사슬(long Markov chain)** U₁ – X₁ – X₂ – U₂가 성립한다. 이는 "각 부호기가 자기 소스만 보고 양자화한다"를 수식으로 쓴 것이다.

**세 부등식의 읽는 법** [재구성]. 장기 마르코프 사슬 때문에
I(X₁,X₂;U₁,U₂) = I(X₁;U₁) + I(X₂;U₂) − I(U₁;U₂) (3.4절 끝에서 증명).
즉 합 율 = (각자 양자화 율의 합) − (두 양자화 결과 사이의 상관 = 비닝으로 아끼는 양). 개별 조건 R₁ > I(X₁;U₁|U₂) = I(X₁;U₁) − I(U₁;U₂)는 "U₂ⁿ을 이미 안다고 치고 U₁ⁿ을 와이너–지브식으로 보내는 율"이다.

**특수 경우에서 꼭 맞음** [원문 13–5]:
1. **슬레피안–울프.** d₁, d₂가 해밍이고 D₁ = D₂ = 0: U₁ = X₁, U₂ = X₂로 두면 R₁ > H(X₁|X₂), R₂ > H(X₂|X₁), R₁+R₂ > H(X₁,X₂).
2. **와이너–지브.** R₂ ≥ H(X₂) (율 제한 없음): 활성 조건은 R₁ > I(X₁;U₁|U₂,Q)뿐이고 U₂ = X₂, Q = ∅가 이를 최소화한다 → R₁ > I(X₁;U₁|X₂) = R_{SI-D}.
3. **d₂가 해밍, D₂ = 0 (한쪽 무손실).** 영역은 R₁ ≥ I(X₁;U₁|X₂), R₂ ≥ H(X₂|U₁), R₁+R₂ ≥ I(X₁;U₁) + H(X₂|U₁), p(u₁|x₁), x̂₁(u₁,x₂). 이것이 율-왜곡 영역임이 알려져 있다(Berger–Yeung 1989). [원문 진술; 역정리는 노트에 없음]
   [재구성] U₂ = X₂를 넣으면 I(X₁;U₁|X₂), I(X₂;X₂|U₁) = H(X₂|U₁), I(X₁,X₂;U₁,X₂) = H(X₂) + I(X₁;U₁|X₂) = I(X₁;U₁) + H(X₂|U₁) (마지막 등식: H(X₂) + I(X₁;U₁|X₂) = H(X₂) + I(X₁,X₂;U₁) − I(X₂;U₁) = H(X₂|U₁) + I(X₁;U₁), U₁ – X₁ – X₂ 사용).
4. **2차 가우시안**(3.6절): 꼭 맞음(Wagner–Tavildar–Viswanath 2008).
5. **일반적으로는 꼭 맞지 않음**(3.8절 반례).

### 3.3 마르코프 보조정리 [원문 진술 13–6, 증명 13–45~13–48, PDF 314, 334–335쪽]

**왜 필요한가** [재구성]. 달성 증명에서 우리는 (U₁ⁿ(L₁), X₁ⁿ, X₂ⁿ, U₂ⁿ(L₂))가 **넷 다 함께** 결합 전형임을 보여야 한다(복호기가 (U₁ⁿ, U₂ⁿ)의 결합 전형성으로 찾고, 왜곡 분석이 (Xⱼ, X̂ⱼ(U₁,U₂))의 전형성을 쓰므로). (U₁ⁿ, X₁ⁿ, X₂ⁿ)이 전형인 것은 와이너–지브와 같다. 그러나 U₂ⁿ(L₂)는 부호기 2가 x₂ⁿ을 보고 **부호책에서 골라낸** 열이다. x₂ⁿ이 주어졌을 때 U₂ⁿ(L₂)의 조건부 분포 p(u₂ⁿ|x₂ⁿ)는 ∏p(u₂ᵢ|x₂ᵢ)가 아니다 — 그래서 2.2의 마르코프판을 쓸 수 없다. 마르코프 보조정리는 "i.i.d.는 아니지만 **조건부 전형 집합 위에서 거의 균등**하기만 하면 충분하다"고 말한다.

**마르코프 보조정리 (Markov lemma).** X → Y → Z가 마르코프 사슬이고 (xⁿ, yⁿ) ∈ T_{ε′}^{(n)}(X,Y), Zⁿ ~ p(zⁿ|yⁿ)가 다음 두 조건을 만족한다고 하자:
1. P{(yⁿ, Zⁿ) ∈ T_{ε′}^{(n)}(Y,Z)} → 1,
2. 모든 zⁿ ∈ T_{ε′}^{(n)}(Z|yⁿ)와 충분히 큰 n에 대해 2^{−n(H(Z|Y)+δ(ε′))} ≤ p(zⁿ|yⁿ) ≤ 2^{−n(H(Z|Y)−δ(ε′))}.

그러면 ε′이 ε에 비해 충분히 작을 때 P{(xⁿ, yⁿ, Zⁿ) ∈ T_ε^{(n)}(X,Y,Z)} → 1.

**직관** [재구성]. 조건 2는 "Zⁿ은 yⁿ의 조건부 전형 집합 위에 거의 균등하게 퍼져 있다"는 뜻이다. 조건부 전형 집합 T(Z|yⁿ) 중에서 xⁿ과도 전형이 **아닌** zⁿ의 비율은 지수적으로 작다(아래 초기하 분포 계산). 균등에 가까운 분포는 그 작은 부분에 확률을 몰아 줄 수 없으므로 결론이 따른다. Zⁿ이 i.i.d. p(z|y)이면 조건 1, 2가 자동으로 성립하므로 2.2의 마르코프판의 일반화다.

**증명** [원문 13–45~13–48, 단계 풀이].

(0) 합집합 한계로 P{(xⁿ,yⁿ,Zⁿ) ∉ T_ε} ≤ Σ_{(x,y,z)} P(E(x,y,z)), E(x,y,z) := {|π(x,y,z|xⁿ,yⁿ,Zⁿ) − p(x,y,z)| ≥ εp(x,y,z)}. 기호 삼중의 수는 유한하므로 각 (x,y,z)마다 P(E(x,y,z)) → 0만 보이면 된다.

(1) (x,y,z)를 고정하고 집합을 정의한다:
A(n_{yz}) := {zⁿ : π(y,z|yⁿ,zⁿ) = n_{yz}/n}, A₁ := {zⁿ : (yⁿ,zⁿ) ∈ T_{ε′}(Y,Z)}, A₂ := {zⁿ : |π(x,y,z|xⁿ,yⁿ,zⁿ) − p(x,y,z)| ≥ εp(x,y,z)}.
P(E) = P{Zⁿ ∈ A₂} ≤ P{Zⁿ ∈ A₁ᶜ} + P{Zⁿ ∈ A₁ ∩ A₂}. 첫 항 → 0 (조건 1).

(2) 둘째 항: 조건 2의 상한으로
P{Zⁿ ∈ A₁ ∩ A₂} = Σ_{zⁿ ∈ A₁∩A₂} p(zⁿ|yⁿ) ≤ Σ_{n_{yz}} |A(n_{yz}) ∩ A₂| · 2^{−n(H(Z|Y)−δ(ε′))},
합은 |n_{yz} − np(y,z)| ≤ ε′np(y,z)인 n_{yz}에 대해서 (A₁ 안이므로).

(3) **세기(counting).** n_{xy} := nπ(x,y|xⁿ,yⁿ), n_y := nπ(y|yⁿ). yⁿ에서 기호 y가 있는 n_y개 자리 중 n_{xy}개는 xⁿ에서 x와 짝지어져 있다("빨간 공"), 나머지 n_y − n_{xy}개는 아니다("파란 공"). zⁿ이 그 n_y개 자리 중 정확히 n_{yz}개에 z를 놓는 방법을 세면, 그중 빨간 자리에 k개가 떨어지는 방법의 수는 C(n_{xy},k)·C(n_y − n_{xy}, n_{yz} − k)이고, 이때 π(x,y,z) = k/n이다. (다른 기호 y′ ≠ y 자리의 배치는 이 (x,y,z) 사건과 무관하므로, 여기서는 "y 자리 안에서의 배치"만 세는 것으로 원문이 표현한다.) 그래서 K를 초기하(hypergeometric) 확률변수 — 빨간 공 n_{xy}개, 파란 공 n_y − n_{xy}개인 주머니에서 비복원으로 n_{yz}개 뽑을 때 빨간 공의 수 — 라 하면
|A(n_{yz}) ∩ A₂| = Σ_{k: |k − np(x,y,z)| ≥ εnp(x,y,z)} C(n_{xy},k)C(n_y−n_{xy},n_{yz}−k) = C(n_y, n_{yz}) · P{|K − np(x,y,z)| ≥ εnp(x,y,z)}.

(4) 크기 한계: (a) C(n_y, n_{yz}) ≤ 2^{n_y H(n_{yz}/n_y)} (이항계수의 엔트로피 한계), (b) n_y ≈ np(y), n_{yz}/n_y ≈ p(z|y)이므로 ≤ 2^{np(y)(H(p(z|y)) + δ(ε′))} (여기서 H(p(z|y))는 베르누이 엔트로피), (c) p(y)H(p(z|y)) ≤ Σ_{y} p(y)H(p(z|y)) = H(1{Z=z}|Y) ≤ H(Z|Y) (지시 함수는 Z의 함수이므로 엔트로피가 작다). 따라서
|A(n_{yz}) ∩ A₂| ≤ 2^{n(H(Z|Y)+δ(ε′))} · P{|K − np(x,y,z)| ≥ εnp(x,y,z)}.
→ (2)의 2^{−nH(Z|Y)}와 곱하면 지수 항이 2^{2nδ(ε′)} 정도로 상쇄된다. 남는 것은 초기하 꼬리 확률이다.

(5) **초기하 꼬리.** E K = n_{xy}n_{yz}/n_y. n_{xy} ≈ np(x,y), n_{yz} ≈ np(y,z), n_y ≈ np(y)이고 마르코프성 p(x,y,z) = p(x,y)p(z|y) = p(x,y)p(y,z)/p(y)이므로 (1 − δ(ε′))np(x,y,z) ≤ E K ≤ (1 + δ(ε′))np(x,y,z). **바로 여기서 마르코프 조건이 쓰인다**: "x 자리와 z 자리가 y 안에서 무작위로 겹친다"는 계산의 기댓값이 p(x,y,z)와 일치하려면 Z가 Y만을 통해 X와 연결되어야 한다. 같은 평균의 이항 확률변수 K′ ~ Binom(n_{xy}, n_{yz}/n_y)에 대해, 비복원 추출은 복원 추출보다 집중되어 있다(Uhlmann 1966; Orlitsky–El Gamal 1990 [원문 인용, 증명 생략]):
P{|K − np(x,y,z)| ≥ εnp(x,y,z)} ≤ P{|K′ − np(x,y,z)| ≥ εnp(x,y,z)} ≤ 2e^{−(ε−δ(ε′))²np(x,y,z)/4} (체르노프 한계).
[주: 원문 13–47은 지수에 n을 빠뜨리고 "(ε−δ(ε′))²p(x,y,z)/4"로 적었다. 체르노프 한계는 지수가 n에 비례해야 하고, 다음 줄의 "→ 0" 결론도 n에 비례하는 지수를 필요로 한다. 판단: 오식. [판단]]

(6) 모으면 P{Zⁿ ∈ A₁∩A₂} ≤ (n+1)·2^{2nδ(ε′)}·2e^{−(ε−δ(ε′))²np(x,y,z)/4} (n_{yz}의 가짓수 ≤ n+1). ε′을 충분히 작게 잡아 2δ(ε′) < (ε−δ(ε′))²p(x,y,z) log₂e/4가 되게 하면 → 0. ∎
[주: 원문은 지수 항을 2^{nδ(ε′)} 하나로 적는다. (2)의 −δ와 (4)의 +δ가 합쳐져 상수배 δ가 되는 것은 δ(·)의 재정의로 흡수된다.]

### 3.4 버거–텅 내부 경계의 달성 증명 [원문, 슬라이드 13–7~13–13, PDF 315–318쪽; 보조정리 2의 증명 13–49~13–50, PDF 336쪽]

|Q| = 1만 보인다(나머지는 시분할). 전체 그림은 세 단계다.

```
부호기 1:  x₁ⁿ ─(1) 양자화: x₁ⁿ과 전형인 u₁ⁿ(l₁) 찾기, 율 R̃₁ ≈ I(X₁;U₁)─▶ l₁ ─(2) 비닝: l₁ ∈ B₁(m₁)─▶ m₁ (율 R₁)
부호기 2:  x₂ⁿ ─(1) 양자화 ─▶ l₂ ─(2) 비닝 ─▶ m₂ (율 R₂)
복호기:   (m₁,m₂) ─(3) B₁(m₁)×B₂(m₂)에서 서로 결합 전형인 유일한 (l̂₁,l̂₂) ─▶ x̂ⱼᵢ = x̂ⱼ(u₁ᵢ(l̂₁), u₂ᵢ(l̂₂))
```

**부호책 생성.** ε > ε′ > ε″. p(u₁|x₁)p(u₂|x₂), x̂₁(u₁,u₂), x̂₂(u₁,u₂)를 고정. R̃ⱼ ≥ Rⱼ. j = 1, 2마다 uⱼⁿ(lⱼ), lⱼ ∈ [1 : 2^{nR̃ⱼ}), 독립 ~ ∏ p_{Uⱼ}(uⱼᵢ). 지표 [1 : 2^{nR̃ⱼ})를 2^{nRⱼ}개의 같은 크기 상자 Bⱼ(mⱼ)로 분할(결정적 분할로 충분 — 부호어가 이미 무작위이므로, 2.6과 같은 이유). 부호책과 상자는 모두에게 공개.

**(1)+(2) 부호화.** 부호기 j는 (xⱼⁿ, uⱼⁿ(lⱼ)) ∈ T_{ε′}^{(n)}인 lⱼ를 찾는다(여럿이면 가장 작은 것, 없으면 아무거나). lⱼ ∈ Bⱼ(mⱼ)인 mⱼ를 보낸다.

**(3) 복호.** B₁(m₁) × B₂(m₂)에서 (u₁ⁿ(l̂₁), u₂ⁿ(l̂₂)) ∈ T_ε^{(n)}인 **유일한** 쌍 (l̂₁, l̂₂)를 찾고 x̂ⱼᵢ = x̂ⱼ(u₁ᵢ(l̂₁), u₂ᵢ(l̂₂)). 없거나 여럿이면 임의 출력.

**오류 사건** [원문 13–10]. (L₁,L₂) = 실제로 고른 지표, (M₁,M₂) = 그 상자 번호.
- E₁ := {(U₁ⁿ(l₁), X₁ⁿ) ∉ T_{ε″}^{(n)} ∀l₁} (부호기 1의 양자화 실패),
- E₂ := {(U₁ⁿ(L₁), X₁ⁿ, X₂ⁿ) ∉ T_{ε′}^{(n)}},
- E₃ := {(U₁ⁿ(L₁), U₂ⁿ(L₂)) ∉ T_ε^{(n)}} — [판단] 원문은 쌍으로 적었지만 13–11의 분석은 넷 (U₁ⁿ(L₁), X₁ⁿ, X₂ⁿ, U₂ⁿ(L₂))의 전형성을 보이고, 왜곡 분석도 그것을 필요로 하므로 **넷의 비전형 사건**으로 읽어야 한다(넷이 전형이면 쌍도 전형이므로 더 강한 사건).
- E₄ := {(U₁ⁿ(l̃₁), U₂ⁿ(l̃₂)) ∈ T_ε^{(n)} for some (l̃₁,l̃₂) ∈ B₁(M₁)×B₂(M₂), (l̃₁,l̃₂) ≠ (L₁,L₂)} (다른 후보가 끼어듦).

E := 복호 결과가 (L₁,L₂)가 아니거나 넷이 비전형인 사건. P(E) ≤ P(E₁) + P(E₁ᶜ ∩ E₂) + P(E₂ᶜ ∩ E₃) + P(E₄). (E₁ᶜ∩E₂ᶜ∩E₃ᶜ∩E₄ᶜ 위에서는 정답 쌍이 전형이고 다른 후보가 없으므로 복호가 맞고 넷이 전형이다.)

**사건별 분석.**

*① P(E₁) → 0* [원문]: 덮개 보조정리(U = ∅, X̂ ← U₁), R̃₁ > I(U₁;X₁) + δ(ε″).

*② P(E₁ᶜ ∩ E₂) → 0* [원문]: E₁ᶜ에서 (U₁ⁿ(L₁), X₁ⁿ) ∈ T_{ε″}. U₁ⁿ(L₁)은 X₁ⁿ의 함수(와 부호책)일 뿐 X₂ⁿ을 보지 않았으므로
X₂ⁿ | {U₁ⁿ(L₁) = u₁ⁿ, X₁ⁿ = x₁ⁿ} ~ ∏ p_{X₂|U₁,X₁}(x₂ᵢ|u₁ᵢ,x₁ᵢ) = ∏ p_{X₂|X₁}(x₂ᵢ|x₁ᵢ)
— **i.i.d.**이다(소스가 무기억이고 X₂ⁿ은 부호기 1의 선택과 무관). ε′ > ε″이므로 조건부 전형성 보조정리(2.2)로 → 0.

*③ P(E₂ᶜ ∩ E₃) → 0* [원문 + 보조정리 2]: (u₁ⁿ, x₁ⁿ, x₂ⁿ) ∈ T_{ε′}^{(n)}을 고정. 부호기 2는 x₂ⁿ과 자기 부호책만 보므로
P{U₂ⁿ(L₂) = u₂ⁿ | X₂ⁿ = x₂ⁿ, X₁ⁿ = x₁ⁿ, U₁ⁿ(L₁) = u₁ⁿ} = P{U₂ⁿ(L₂) = u₂ⁿ | X₂ⁿ = x₂ⁿ} =: p(u₂ⁿ|x₂ⁿ).
(부호책 1, 2가 독립이고 부호기 2의 결정은 (X₂ⁿ, 부호책 2)의 함수이며, (X₁ⁿ, 부호책 1)은 X₂ⁿ이 주어지면 이것과 독립.) 이제 마르코프 보조정리를 Z ← U₂, Y ← X₂, X ← (U₁, X₁)로 적용한다. 필요한 마르코프 사슬 (U₁,X₁) → X₂ → U₂는 시험 채널 구조에서 성립한다. 조건 1: 덮개 보조정리로 P{U₂ⁿ(L₂) ∈ T_{ε′}(U₂|x₂ⁿ) | X₂ⁿ = x₂ⁿ} → 1 (R̃₂ > I(U₂;X₂) + δ(ε′)이면; 덮개 보조정리를 전형인 x₂ⁿ마다 적용). 조건 2: 보조정리 2.

**보조정리 2.** 모든 u₂ⁿ ∈ T_{ε′}^{(n)}(U₂|x₂ⁿ)와 충분히 큰 n에 대해 p(u₂ⁿ|x₂ⁿ) ≐ 2^{−nH(U₂|X₂)}, 정확히는
(1 − ε′)2^{−n(H(U₂|X₂)+δ(ε′))} ≤ p(u₂ⁿ|x₂ⁿ) ≤ 2^{−n(H(U₂|X₂)−δ(ε′))}.

*증명* [원문 13–49~13–50]. 상한: 고른 열이 u₂ⁿ인 사건은 "고른 열이 조건부 전형 집합 안"이라는 사건에 포함되므로
p(u₂ⁿ|x₂ⁿ) = P{U₂ⁿ(L₂) ∈ T(U₂|x₂ⁿ) | x₂ⁿ} · P{U₂ⁿ(L₂) = u₂ⁿ | x₂ⁿ, U₂ⁿ(L₂) ∈ T} ≤ P{U₂ⁿ(L₂) = u₂ⁿ | x₂ⁿ, U₂ⁿ(L₂) ∈ T}
= Σ_{l₂} P{L₂ = l₂ | x₂ⁿ, U₂ⁿ(L₂) ∈ T} · P{U₂ⁿ(l₂) = u₂ⁿ | x₂ⁿ, U₂ⁿ(l₂) ∈ T, L₂ = l₂}
=(a) Σ_{l₂} P{L₂ = l₂ | ·} · P{U₂ⁿ(l₂) = u₂ⁿ | U₂ⁿ(l₂) ∈ T(U₂|x₂ⁿ)}
≤(b) Σ_{l₂} P{L₂ = l₂ | ·} · 2^{−n(H(U₂|X₂)−δ(ε′))} = 2^{−n(H(U₂|X₂)−δ(ε′))}.
(a): L₂는 x₂ⁿ과 지시 변수들 {1[U₂ⁿ(l) ∈ T(U₂|x₂ⁿ)]}_l만의 함수이다(가장 작은 전형 지표를 고르므로). U₂ⁿ(l₂)는 다른 부호어와 독립이므로, "U₂ⁿ(l₂) ∈ T"라는 사실이 주어지면 U₂ⁿ(l₂)의 **집합 안에서의 정확한 위치**는 {L₂ = l₂}와 독립이다. (b): U₂ⁿ(l₂) ~ ∏p_{U₂}이고 전형 집합 안에서 p(u₂ⁿ) ≐ 2^{−nH(U₂)}이므로, 조건부 확률 = p(u₂ⁿ)/P{U₂ⁿ ∈ T(U₂|x₂ⁿ)} ≤ 2^{−n(H(U₂)−δ)}/2^{−n(I(U₂;X₂)+δ)} = 2^{−n(H(U₂|X₂)−2δ)} (분모는 2.3(b)). 하한도 같은 방식으로, P{U₂ⁿ(L₂) ∈ T | x₂ⁿ} ≥ 1 − ε′ (덮개)와 (b)의 반대 방향 한계를 쓴다. ∎

**직관** [재구성]. 부호기는 전형인 첫 부호어를 고른다. 각 부호어가 독립으로 같은 분포에서 나왔으므로 "선택된 것"은 조건부 전형 집합 위에서 (지수 정밀도로) 균등하다. 그래서 i.i.d. 시험 채널 출력과 "구별할 수 없을 만큼" 비슷하다 — 지수 수준에서.

마르코프 보조정리로 P{(u₁ⁿ, x₁ⁿ, x₂ⁿ, U₂ⁿ(L₂)) ∈ T_ε^{(n)} | ·} → 1 (ε′이 ε에 비해 충분히 작으면). 전형인 (u₁ⁿ,x₁ⁿ,x₂ⁿ) 위에서 평균하면 P(E₂ᶜ ∩ E₃) → 0.

*④ P(E₄) → 0* [원문 + 재구성]. 원문은 와이너–지브의 보조정리 1(2.6)과 같은 대칭 논증으로 P(E₄) ≤ P{(U₁ⁿ(l̃₁), U₂ⁿ(l̃₂)) ∈ T for some (l̃₁,l̃₂) ∈ B₁(1) × B₂(1)}로 줄이고, 다음 보조정리를 쓴다.

**상호 채움 보조정리 (mutual packing lemma)** [원문 13–12]. (U₁,U₂) ~ p(u₁,u₂). U₁ⁿ(l₁), l₁ ∈ [1:2^{nr₁}], 각각 ∏p_{U₁}을 따르되 서로 임의 의존; U₂ⁿ(l₂), l₂ ∈ [1:2^{nr₂}]도 마찬가지; 두 묶음은 서로 독립. 그러면 r₁ + r₂ < I(U₁;U₂) − δ(ε)일 때
P{(U₁ⁿ(l₁), U₂ⁿ(l₂)) ∈ T_ε^{(n)} for some (l₁,l₂)} → 0.
*증명* [재구성; 원문은 "채움 보조정리의 직접 일반화"라고만 함]. 합집합 한계로 ≤ Σ_{l₁,l₂} P{(U₁ⁿ(l₁),U₂ⁿ(l₂)) ∈ T}. 각 쌍에서 U₁ⁿ(l₁) ⟂ U₂ⁿ(l₂)이고 주변이 i.i.d.이므로 2.3(a)(X = ∅)로 각 항 ≤ 2^{−n(I(U₁;U₂)−δ(ε))}. 항의 수 2^{n(r₁+r₂)}. 합 ≤ 2^{−n(I(U₁;U₂)−r₁−r₂−δ)} → 0. ∎ (같은 묶음 안의 의존성은 합집합 한계에서 아무 영향이 없다.)

r₁ = R̃₁ − R₁, r₂ = R̃₂ − R₂(상자 크기)를 넣으면 (R̃₁ − R₁) + (R̃₂ − R₂) < I(U₁;U₂) − δ(ε)이면 P(E₄) → 0.

[판단/재구성: 부분 오류의 처리] 원문의 "상자 1로 줄이기"는 **두 지표가 모두 틀린** 후보에는 깔끔하게 적용되지만, l̃₁ = L₁이고 l̃₂만 틀린 후보(또는 그 반대)는 정답 부호어 U₁ⁿ(L₁)을 포함하므로 "독립인 두 묶음"이라는 상호 채움의 가정에 맞지 않는다. 엄밀하게는 E₄를 셋으로 나눈다:
- E₄₁: l̃₁ ≠ L₁, l̃₂ = L₂ → (U₂ⁿ(L₂)를 Ỹⁿ으로 둔) 채움 보조정리 + 상자 1 줄이기: R̃₁ − R₁ < I(U₁;U₂) − δ이면 → 0.
- E₄₂: 대칭으로 R̃₂ − R₂ < I(U₁;U₂) − δ.
- E₄₃: 둘 다 틀림 → 상호 채움: (R̃₁−R₁) + (R̃₂−R₂) < I(U₁;U₂) − δ.
Rⱼ ≤ R̃ⱼ이므로 E₄₃의 조건이 E₄₁, E₄₂의 조건을 함의한다. 그래서 **최종 영역은 원문과 같다.** (2011년 출판본의 해당 증명은 이렇게 나눈다는 기억이 있으나 이 노트에서 대조하지 않았다 [미확인].)

**R̃ 소거 (푸리에–모츠킨 소거, Fourier–Motzkin elimination)** [원문 13–13, 단계 재구성]. 조건:
(i) R̃₁ > I(U₁;X₁), (ii) R̃₂ > I(U₂;X₂), (iii) R̃ⱼ ≥ Rⱼ, (iv) (R̃₁−R₁) + (R̃₂−R₂) < I(U₁;U₂) (δ 생략).
(iv)와 R̃₂ − R₂ ≥ 0에서 R̃₁ − R₁ < I(U₁;U₂), 여기에 (i): R₁ > R̃₁ − I(U₁;U₂) > I(U₁;X₁) − I(U₁;U₂). 대칭으로 R₂ > I(U₂;X₂) − I(U₁;U₂). (iv)에 (i),(ii): R₁ + R₂ > R̃₁ + R̃₂ − I(U₁;U₂) > I(U₁;X₁) + I(U₂;X₂) − I(U₁;U₂). 반대로 이 세 조건을 만족하는 (R₁,R₂)면 (i)–(iv)를 만족하는 R̃를 고를 수 있다(R̃ⱼ = max(Rⱼ, I(Uⱼ;Xⱼ) + η)로 잡고 확인).

**정보량 정리** [재구성]. 장기 마르코프 사슬 U₁ – X₁ – X₂ – U₂를 쓴다.
- I(U₁;X₁) − I(U₁;U₂) = I(U₁;X₁,U₂) − I(U₁;U₂) (U₁ – X₁ – U₂이므로 I(U₁;X₁,U₂) = I(U₁;X₁)) = I(U₁;X₁|U₂). 대칭으로 I(U₂;X₂|U₁).
- I(U₁;X₁) + I(U₂;X₂) − I(U₁;U₂) = I(X₁,X₂;U₁,U₂): I(X₁,X₂;U₁,U₂) = H(U₁,U₂) − H(U₁,U₂|X₁,X₂) = H(U₁) + H(U₂) − I(U₁;U₂) − H(U₁|X₁) − H(U₂|X₂) (X₁,X₂가 주어지면 U₁, U₂가 독립이고 Uⱼ는 Xⱼ에만 의존) = I(U₁;X₁) + I(U₂;X₂) − I(U₁;U₂). ∎

**왜곡** [원문 "same arguments", 재구성]. Eᶜ 위에서 (U₁ⁿ(L₁), X₁ⁿ, X₂ⁿ, U₂ⁿ(L₂)) ∈ T_ε이고 복호가 정확하므로 (Xⱼⁿ, X̂ⱼⁿ)이 전형 → 전형 평균 보조정리로 dⱼ ≤ (1+ε)E dⱼ(Xⱼ,X̂ⱼ). limsup E dⱼ ≤ d_{max}·P(E) + (1+ε)E dⱼ → (1+ε)E dⱼ. 부등식이 엄격(>)이고 ε → 0, 영역이 왜곡에 대해 연속이므로 정리 1. (부호책 평균으로 보였으므로 좋은 부호책이 존재.) ∎

### 3.5 버거–텅 외부 경계 (정리 2) [원문, 슬라이드 13–14~13–15, PDF 318–319쪽]

**정리 2.** (R₁,R₂)가 (D₁,D₂)로 달성 가능하면
R₁ ≥ I(X₁,X₂;U₁|U₂), R₂ ≥ I(X₁,X₂;U₂|U₁), R₁+R₂ ≥ I(X₁,X₂;U₁,U₂)
를 만족하는 p(u₁,u₂|x₁,x₂)가 있다. 단 **U₁ – X₁ – X₂와 X₁ – X₂ – U₂**가 각각 마르코프 사슬이고, x̂ⱼ(u₁,u₂)로 Dⱼ ≥ E dⱼ.

**내부 경계와의 차이** [원문]. (i) 외부 경계는 시분할 없이도 볼록(보조 변수에 시분할 변수를 흡수할 수 있으므로). (ii) 마르코프 조건이 약하다: 내부는 U₁ – X₁ – X₂ – U₂(장기 사슬, 즉 (U₁,X₁) 쪽과 (U₂,X₂) 쪽이 X₁–X₂로만 연결) 전체를 요구하지만 외부는 두 짧은 사슬만. 장기 사슬에서는 U₁과 U₂가 X가 주어지면 독립이어야 하지만 외부 경계는 이를 요구하지 않는다. **간극의 근원**은 이것이다.

**증명** [원문은 "standard argument with identifying U₁ᵢ := (M₁, X₁^{i−1}, X₂^{i−1}), U₂ᵢ := (M₂, X₁^{i−1}, X₂^{i−1})"만 적음 → 재구성].
1. 합 율: n(R₁+R₂) ≥ H(M₁,M₂) ≥ I(X₁ⁿ,X₂ⁿ;M₁,M₂) = Σᵢ I(X₁ᵢ,X₂ᵢ;M₁,M₂|X₁^{i−1},X₂^{i−1}) = Σᵢ I(X₁ᵢ,X₂ᵢ;M₁,M₂,X₁^{i−1},X₂^{i−1}) (과거와 현재는 독립: 소스가 i.i.d.) ≥ Σᵢ I(X₁ᵢ,X₂ᵢ;U₁ᵢ,U₂ᵢ) (U₁ᵢ, U₂ᵢ를 합치면 (M₁,M₂,과거)이므로 사실 등호).
2. 개별 율: nR₁ ≥ H(M₁) ≥ H(M₁|M₂) ≥ I(X₁ⁿ,X₂ⁿ;M₁|M₂) = Σᵢ I(X₁ᵢ,X₂ᵢ;M₁|M₂,X₁^{i−1},X₂^{i−1}). 그리고 I(X₁ᵢ,X₂ᵢ;U₁ᵢ|U₂ᵢ) = I(X₁ᵢ,X₂ᵢ;M₁,M₂,과거|M₂,과거) = 같은 항. 대칭으로 R₂.
3. 마르코프 조건: U₁ᵢ = (M₁, X₁^{i−1}, X₂^{i−1})에서 M₁은 X₁ⁿ의 함수. X₂ᵢ가 주어진 X₁ᵢ에 대해 (M₁, X₁^{i−1}, X₂^{i−1})과 조건부 독립인가? (X₁ⁿ, X₂^{i−1}) 중 X₁ᵢ 이외의 부분은 (X₁ᵢ, X₂ᵢ)와 독립(시각이 다름)이므로 p(x₂ᵢ | x₁ᵢ, x₁^{n}\x₁ᵢ, x₂^{i−1}) = p(x₂ᵢ|x₁ᵢ). U₁ᵢ는 (X₁ⁿ, X₂^{i−1})의 함수이므로 U₁ᵢ – X₁ᵢ – X₂ᵢ. 대칭으로 X₁ᵢ – X₂ᵢ – U₂ᵢ. **그러나 U₁ᵢ와 U₂ᵢ는 공통 성분 (X₁^{i−1}, X₂^{i−1})를 공유**하므로 (X₁ᵢ,X₂ᵢ)가 주어져도 조건부 독립이 아니다 — 장기 사슬이 깨지는 정확한 이유.
4. 재구성: X̂ⱼᵢ는 (M₁,M₂)의 함수이므로 (U₁ᵢ,U₂ᵢ)의 함수.
5. 시분할 변수 T ~ Unif[1:n]를 두고 Uⱼ = (T, Uⱼ_T), Xⱼ = Xⱼ_T로 단일 문자화(정보량은 T로 조건을 걸어도 Xⱼ_T가 T와 독립이므로 그대로 옮겨진다). 왜곡은 (1/n)Σ E dⱼ(Xⱼᵢ,X̂ⱼᵢ) ≤ Dⱼ. ∎

**외부 경계가 꼭 맞는 경우** [원문 13–15]: 슬레피안–울프, 와이너–지브, d₂ 해밍·D₂ = 0, 그리고 X₂가 X₁의 함수인 경우(Kaspi–Berger 1982; 이때 **내부 경계는** 일반적으로 꼭 맞지 않음 — 3.8절). **꼭 맞지 않는 경우**: 2차 가우시안에서도 맞지 않는다(Tung 1978). 엄격히 개선된 외부 경계: Wagner–Anantharam 2008.

### 3.6 2차 가우시안 분산 소스 부호화 (정리 3) [원문, 슬라이드 13–16~13–31, PDF 319–327쪽; 보조정리 3·5의 증명 13–51~13–54, PDF 337–338쪽]

#### 3.6.1 진술

(X₁,X₂) ~ 2-WGN(1, ρ), dⱼ = (xⱼ − x̂ⱼ)². 일반성을 잃지 않고 ρ = E X₁X₂ ≥ 0 (부호를 바꾸려면 X₂ → −X₂).

**정리 3 (Wagner–Tavildar–Viswanath 2008).** ℛ(D₁,D₂) = ℛ₁(D₁) ∩ ℛ₂(D₂) ∩ ℛ₁₂(D₁,D₂):
- ℛ₁(D₁) = {R₁ ≥ R((1 − ρ² + ρ²2^{−2R₂})/D₁) =: g₁(R₂,D₁)},
- ℛ₂(D₂) = {R₂ ≥ R((1 − ρ² + ρ²2^{−2R₁})/D₂) =: g₂(R₁,D₂)},
- ℛ₁₂(D₁,D₂) = {R₁ + R₂ ≥ R((1−ρ²)φ(D₁,D₂)/(2D₁D₂))}, φ(D₁,D₂) := 1 + √(1 + 4ρ²D₁D₂/(1−ρ²)²).

**ℛ₁의 뜻** [재구성]. g₁(R₂,D₁)은 "부호기 2가 X₂를 율 R₂로 보내 주면 복호기의 X₁에 대한 남은 분산은 1 − ρ² + ρ²2^{−2R₂}이고, 그것을 D₁까지 줄이는 비용". 즉 부호기 2를 **도우미(helper)**로 쓰는 X₁ 문제의 율. R₂ = 0이면 ½log(1/D₁), R₂ → ∞이면 ½log((1−ρ²)/D₁) (와이너–지브, 부가 정보 X₂).

**주석** [원문 13–16]. 한 소스만 복원하면 되는 경우 ℛ(D₁,1) = ℛ₁(D₁), ℛ(1,D₂) = ℛ₂(D₂) (Oohama 1997, "한 도우미" 문제).

#### 3.6.2 달성: 분산 가우시안 시험 채널 [원문 13–18~13–19]

일반성을 잃지 않고 D₁ ≤ D₂. U₁ = X₁ + V₁, U₂ = X₂ + V₂, V₁ ~ N(0,N₁), V₂ ~ N(0,N₂), N₂ ≥ N₁, 서로·(X₁,X₂)와 독립. X̂ⱼ = E(Xⱼ|U₁,U₂). 이를 (N₁,N₂)로 정해지는 **분산 가우시안 시험 채널**이라 부른다. 장기 사슬 U₁ – X₁ – X₂ – U₂가 자동으로 성립한다.

**왜곡** [원문 진술, 계산 재구성].
D₁ = N₁(1 + N₂ − ρ²)/((1+N₁)(1+N₂) − ρ²), D₂ = N₂(1 + N₁ − ρ²)/((1+N₁)(1+N₂) − ρ²) ≥ D₁.
계산: 2.9의 정보 형식, H = I, K_Z = diag(N₁,N₂): K_{X|U}⁻¹ = K_X⁻¹ + diag(1/N₁,1/N₂). K_X⁻¹ = (1/(1−ρ²))[[1,−ρ],[−ρ,1]]. 그래서
K_{X|U}⁻¹ = [[1/(1−ρ²) + 1/N₁, −ρ/(1−ρ²)], [−ρ/(1−ρ²), 1/(1−ρ²) + 1/N₂]].
(1,1) 성분의 역 = (2,2) 성분/행렬식. 행렬식 = (1/(1−ρ²) + 1/N₁)(1/(1−ρ²) + 1/N₂) − ρ²/(1−ρ²)². 분자·분모에 N₁N₂(1−ρ²)²를 곱하면 행렬식·N₁N₂(1−ρ²)² = (N₁+1−ρ²)(N₂+1−ρ²) − ρ²N₁N₂ = (1−ρ²)[(1+N₁)(1+N₂) − ρ²] (전개해서 확인: 좌변 = N₁N₂(1−ρ²) + (N₁+N₂)(1−ρ²) + (1−ρ²)², 우변 = (1−ρ²)(1 + N₁ + N₂ + N₁N₂ − ρ²) — 같음). (2,2) 성분·N₁N₂(1−ρ²)² = N₁(1−ρ²)(N₂ + 1 − ρ²). 따라서 D₁ = N₁(1+N₂−ρ²)/((1+N₁)(1+N₂)−ρ²). D₂ − D₁의 분자 = N₂(1+N₁−ρ²) − N₁(1+N₂−ρ²) = (N₂ − N₁)(1−ρ²) ≥ 0. ∎

**율** [원문 13–19, 계산 재구성]. d := (1+N₁)(1+N₂) − ρ².
- I(X₁;U₁|U₂) = R(d/(N₁(1+N₂))): h(U₁|U₂) − h(U₁|X₁,U₂) = ½log Var(U₁|U₂) − ½log N₁, Var(U₁|U₂) = 1 + N₁ − ρ²/(1+N₂) = d/(1+N₂).
- I(X₂;U₂|U₁) = R(d/(N₂(1+N₁))) (대칭).
- I(X₁,X₂;U₁,U₂) = R(d/(N₁N₂)): h(U₁,U₂) − h(V₁,V₂) = ½log(|K_U|/(N₁N₂)), |K_U| = (1+N₁)(1+N₂) − ρ² = d.

**모서리 점** [원문 13–19]. 장기 사슬로 I(X₁,X₂;U₁,U₂) = I(X₁;U₁|U₂) + I(X₂;U₂) = I(X₁;U₁) + I(X₂;U₂|U₁). 왼쪽 모서리 (R₁ˡ, R₂ˡ) = (I(X₁;U₁|U₂), I(X₂;U₂)), R₂ˡ = R((1+N₂)/N₂), 그리고 **R₁ˡ = g₁(R₂ˡ, D₁)** [재구성 확인: 2^{−2R₂ˡ} = N₂/(1+N₂)이므로 1 − ρ² + ρ²N₂/(1+N₂) = (1 + N₂ − ρ²)/(1+N₂), 이를 D₁로 나누면 (1+N₂−ρ²)·d/((1+N₂)N₁(1+N₂−ρ²)) = d/(N₁(1+N₂)). ✓]. 즉 **왼쪽 모서리는 항상 ℛ₁(D₁)의 경계 위**에 있다 — "부호기 2를 먼저 복호하고 그것을 부가 정보로 X₁을 와이너–지브 부호화"하는 점이므로 당연하다.

#### 3.6.3 경우 1: (1 − D₂) ≤ ρ²(1 − D₁) [원문 13–20~13–21; 보조정리 3의 증명 13–51]

이 조건 ⇔ D₂ ≥ 1 − ρ² + ρ²D₁: "X₁을 D₁로 보내면 X₂는 공짜로 D₂ 이하가 된다".

**보조정리 3.** 이 경우 ℛ₁(D₁) ⊆ ℛ₂(D₂) ∩ ℛ₁₂(D₁,D₂). 따라서 ℛ = ℛ₁(D₁).
*증명* [원문 13–51, 단계 풀이].
(a) ℛ₁₂: φ와 ℛ₁₂는 D₂가 커질수록 느슨해지므로 ℛ₁₂(D₁,D₂) ⊇ ℛ₁₂(D₁, 1−ρ²+ρ²D₁) = {R₁+R₂ ≥ R(1/D₁)}. [재구성 확인: D₂ = 1−ρ²+ρ²D₁를 넣으면 (1−ρ²)φ/(2D₁D₂) = 1/D₁. a := 1−ρ², D₂ = a + ρ²D₁. √((1−ρ²)² + 4ρ²D₁D₂) = √(a² + 4ρ²D₁a + 4ρ⁴D₁²) = a + 2ρ²D₁. 그래서 (1−ρ²)φ = a + √(…) = 2a + 2ρ²D₁ = 2D₂, 즉 (1−ρ²)φ/(2D₁D₂) = 1/D₁. ✓] (R₁,R₂) ∈ ℛ₁이면 R₁ + R₂ ≥ g₁(R₂,D₁) + R₂ ≥ g₁(0,D₁) = R(1/D₁) — g₁(R₂,D₁) + R₂ = ½log((1−ρ²)2^{2R₂} + ρ²) − ½log D₁ (R이 양수인 영역에서)는 R₂에 대해 증가.
(b) ℛ₂: g₂를 R₁에 대해 풀면 ℛ₂(D₂) = {R₁ ≥ R(ρ²/(D₂2^{2R₂} − 1 + ρ²))}. D₂ ≥ 1−ρ²+ρ²D₁이면 ρ²/(D₂2^{2R₂} − 1 + ρ²) ≤ (1 − ρ² + ρ²2^{−2R₂})/D₁ [재구성 확인: 우변 분모·분자를 2^{2R₂}배 하고 t := 2^{2R₂} ≥ 1로 쓰면 필요한 것은 ρ²D₁ ≤ ((1−ρ²)t + ρ²)(D₂t − 1 + ρ²)/t. D₂ ≥ 1−ρ²+ρ²D₁ 대입 시 D₂t − 1 + ρ² ≥ (1−ρ²)(t−1) + ρ²D₁t ≥ ρ²D₁t, 그리고 (1−ρ²)t + ρ² ≥ 1이므로 우변 ≥ ρ²D₁. ✓]. 따라서 ℛ₁ ⊆ ℛ₂. ∎

**달성** [원문 13–20~13–21].
- 출발점: N₁ = D₁/(1−D₁), N₂ = ∞ (U₂ = ∅). 왼쪽 모서리 R₂ˡ = 0, R₁ˡ = I(X₁;U₁) = ½log((1+N₁)/N₁) = ½log(1/D₁) = g₁(0,D₁). 왜곡: E(X₁−X̂₁)² = 1 − 1/(1+N₁) = D₁, E(X₂−X̂₂)² = 1 − ρ²/(1+N₁) = 1 − ρ² + ρ²D₁ ≤ D₂. ✓
- ℛ₁의 경계 전체로 확장: Ñ₂ < ∞, Ñ₁ ≥ N₁을 Ñ₁(1+Ñ₂−ρ²)/((1+Ñ₁)(1+Ñ₂)−ρ²) = D₁이 되게 잡는다(D̃₁ = D₁ 유지). 그러면
D̃₂/D̃₁ = (1/Ñ₁ + 1/(1−ρ²))/(1/Ñ₂ + 1/(1−ρ²)) ≤ (1/N₁ + 1/(1−ρ²))/(1/(1−ρ²)) = (1−ρ²+ρ²D₁)/D₁ ≤ D₂/D₁.
[재구성: 첫 등식은 3.6.2의 D 공식을 N₁N₂(1−ρ²)로 나누면 나온다: D₂/D₁ = N₂(1+N₁−ρ²)/(N₁(1+N₂−ρ²)), 그리고 (1+N₁−ρ²)/(N₁(1−ρ²)) = 1/N₁ + 1/(1−ρ²). 부등식: Ñ₁ ≥ N₁이라 분자가 작고, 1/Ñ₂ > 0이라 분모가 크다. 가운데 등식: 1/N₁ = (1−D₁)/D₁를 넣고 정리.] 그래서 D̃₂ ≤ D₂. 왼쪽 모서리 R̃₂ = R((1+Ñ₂)/Ñ₂), R̃₁ = g₁(R̃₂, D₁). Ñ₂를 (0,∞)에서 움직이면 R̃₂가 (0,∞)를 다 덮으므로 ℛ₁(D₁)의 경계 전체가 달성된다. 경계 위쪽은 율을 늘리면 되므로 ℛ₁(D₁) 전체. ∎

#### 3.6.4 경우 2: (1 − D₂) > ρ²(1 − D₁) [원문 13–22~13–24]

두 왜곡 제약이 동시에 빡빡한(tight) 시험 채널이 존재함을 보인다.

**보조정리 4.** Uⱼ = Xⱼ + Vⱼ, X ~ N(0,K_X), V ~ N(0,K_V) 독립, K_X, K_V ≻ 0. K_{X|U} = K_X − K_{XU}K_U⁻¹K_{XU}ᵀ이면 K_{X|U}⁻¹ = K_X⁻¹ + K_V⁻¹. 따라서 **V₁, V₂가 독립 ⇔ K_{X|U}⁻¹ − K_X⁻¹가 대각.**
*증명* [재구성; 원문은 역행렬 공식의 쉬운 귀결이라고만 함]: 2.9의 정보 형식에서 H = I, K_Z = K_V. 가우시안 V에서 독립 ⇔ 무상관 ⇔ K_V 대각 ⇔ K_V⁻¹ 대각. ∎
**뜻.** 원하는 오차 공분산 K를 먼저 정하고, K⁻¹ − K_X⁻¹이 양의 대각이면 그것을 diag(1/N₁,1/N₂)로 실현하는 분산 시험 채널이 있다.

**K 고르기** [원문 13–22]. K = [[D₁, θ√(D₁D₂)], [θ√(D₁D₂), D₂]]로 두고 θ ∈ [0,1]를 K⁻¹ − K_X⁻¹ = diag(1/N₁, 1/N₂) (원문은 "diag(N₁,N₂)"로 적었지만 보조정리 4에 따라 역수가 맞다 [판단: 표기 오식])가 되게 고른다:
θ = (√((1−ρ²)² + 4ρ²D₁D₂) − (1−ρ²)) / (2ρ√(D₁D₂)).
*유도* [재구성]. 비대각 성분을 맞추면: K⁻¹의 비대각 = −θ√(D₁D₂)/(D₁D₂(1−θ²)) = −θ/(√(D₁D₂)(1−θ²)), K_X⁻¹의 비대각 = −ρ/(1−ρ²). 같게 놓으면 ρ√(D₁D₂)·θ² + (1−ρ²)θ − ρ√(D₁D₂) = 0, 즉
**θ² + Nθ − 1 = 0, N := (1−ρ²)/(ρ√(D₁D₂))**,
양의 근 θ = (−N + √(N²+4))/2 ∈ (0,1)이 위 식이다. (이 N은 역정리의 μ-합 하계에 나오는 N과 **같은 수**다 — 3.6.6.) 대각 성분이 양수(N₁, N₂ > 0)라는 것이 경우 2의 조건에서 나온다 [재구성 미완: 원문 "it can be shown by simple algebra"; 아래 수치 예에서 확인, 일반 증명은 이 노트에서 하지 않음 [미확인]].

**모서리 점** [원문 13–23, 수치로 재구성 확인]. 이 시험 채널의 왼쪽 모서리는 R₁ˡ + R₂ˡ = R((1−ρ²)φ/(2D₁D₂)), R₂ˡ = R((1+N₂)/N₂), R₁ˡ = g₁(R₂ˡ,D₁)를 만족 — ℛ₁₂와 ℛ₁의 경계가 만나는 점이다.
*수치 확인* (ρ = 0.8, D₁ = 0.3, D₂ = 0.4; 경우 2 조건 0.6 > 0.448 성립): θ = 0.54290, N₁ = 0.51318, N₂ = 1.30371, 시험 채널의 왜곡 = (0.3000, 0.4000) ✓, K⁻¹ − K_X⁻¹의 비대각 ≈ −9×10⁻¹⁶ ✓, R₁ˡ + R₂ˡ = ½log(d/(N₁N₂)) = 1.04437 = R((1−ρ²)φ/(2D₁D₂)) = 1.04437 ✓, R₂ˡ = 0.41067, R₁ˡ = 0.63370 = g₁(R₂ˡ,D₁) = 0.63370 ✓ (단위 비트).
**나머지** [원문 13–23~13–24]. 경우 1과 같이 D̃₁ = D₁을 유지하며 Ñ₂를 줄이면 R̃₁ = g₁(R̃₂,D₁), R̃₂ ≥ R₂ˡ인 ℛ₁ 경계 부분이 달성된다(원문 13–23은 "R̃₁ = g₂(R̃₂,D₁)"로 적었으나 문맥상 g₁ [판단: 오식]). 대칭으로 오른쪽 모서리 (R₁ʳ,R₂ʳ)는 ℛ₁₂와 ℛ₂의 경계에 있고 R̃₂ = g₂(R̃₁,D₂), R̃₁ ≥ R₁ʳ 부분이 달성된다. 두 모서리 사이의 합 율 직선은 시분할. ∎

#### 3.6.5 역정리 1: ℛ ⊆ ℛ₁(D₁) ∩ ℛ₂(D₂) [원문 13–25~13–26, Oohama 1997]

**직관.** 부호기 2가 아무리 잘해도 X₂에 대해 R₂ 비트만 준다. X₁ = ρX₂ + W에서 W는 아무도 공짜로 알려 주지 않는다. EPI가 "M₂를 알 때 X₁의 남은 불확실성 ≥ ρ²·(X₂의 남은 불확실성) + W의 불확실성"을 정확히 말한다.

**증명** [원문, 단계마다 근거].
1. nR₁ ≥ H(M₁) ≥ H(M₁|M₂) = I(M₁;X₁ⁿ|M₂) (M₁은 X₁ⁿ의 함수이므로 H(M₁|X₁ⁿ,M₂) = 0)
 = h(X₁ⁿ|M₂) − h(X₁ⁿ|M₁,M₂)
 ≥ h(X₁ⁿ|M₂) − h(X₁ⁿ|X̂₁ⁿ) (X̂₁ⁿ은 (M₁,M₂)의 함수: 조건을 함수로 바꾸면 조건이 줄어 엔트로피가 커짐)
 ≥ h(X₁ⁿ|M₂) − Σᵢ h(X₁ᵢ|X̂₁ᵢ) (연쇄 법칙 + 조건 축소)
 ≥ h(X₁ⁿ|M₂) − (n/2)log(2πeD₁) (2.7 스칼라 MSE판으로 h(X₁ᵢ|X̂₁ᵢ) ≤ ½log(2πeD₁ᵢ), D₁ᵢ := E(X₁ᵢ−X̂₁ᵢ)², 그다음 log의 오목성으로 (1/n)Σ½log(2πeD₁ᵢ) ≤ ½log(2πe·(1/n)ΣD₁ᵢ) ≤ ½log(2πeD₁)). [엄밀하게는 D₁ + ε로 하고 마지막에 ε → 0.]
2. nR₂ ≥ I(M₂;X₂ⁿ) = h(X₂ⁿ) − h(X₂ⁿ|M₂) = (n/2)log(2πe) − h(X₂ⁿ|M₂). 즉 2^{(2/n)h(X₂ⁿ|M₂)} ≥ 2πe·2^{−2R₂}.
3. 결합 가우시안이므로 X₁ᵢ = ρX₂ᵢ + Wᵢ, {Wᵢ} ~ WGN(1−ρ²), {X₂ᵢ}와 독립, 따라서 M₂(= X₂ⁿ의 함수)와도 독립. M₂가 주어지면 ρX₂ⁿ과 Wⁿ은 조건부 독립.
4. 조건부 EPI:
2^{(2/n)h(X₁ⁿ|M₂)} ≥ 2^{(2/n)h(ρX₂ⁿ|M₂)} + 2^{(2/n)h(Wⁿ|M₂)} = ρ²2^{(2/n)h(X₂ⁿ|M₂)} + 2πe(1−ρ²) (축척: h(ρX₂ⁿ) = h(X₂ⁿ) + n log ρ; Wⁿ ⟂ M₂이므로 h(Wⁿ|M₂) = h(Wⁿ) = (n/2)log(2πe(1−ρ²)))
 ≥ 2πe(ρ²2^{−2R₂} + 1 − ρ²) (2단계).
5. 1과 4를 합치면 nR₁ ≥ (n/2)log(2πe(1−ρ²+ρ²2^{−2R₂})) − (n/2)log(2πeD₁) = n·½log((1−ρ²+ρ²2^{−2R₂})/D₁). R₁ ≥ 0과 합쳐 R₁ ≥ g₁(R₂,D₁). 대칭으로 ℛ₂. ∎

#### 3.6.6 역정리 2: ℛ ⊆ ℛ₁₂(D₁,D₂) [원문 13–27~13–31, Wagner–Tavildar–Viswanath 2008, Wang–Chen–Wu 2009]

보조정리 3에 의해 일반성을 잃지 않고 (1−D₁) ≥ (1−D₂) ≥ ρ²(1−D₁) (경우 2, 합 율 제약이 활성). 두 하계 R₁(θ), R₂(θ)를 θ ∈ [−1,1]로 매개화해 세우고 **같은 θ에서 둘 다 성립**함을 보인 뒤 min_θ max{R₁(θ),R₂(θ)}를 계산한다.

**공통 준비** [재구성: 원문은 협력 하계에서 K̃ᵢ = K_{X(i)−X̂(i)}(복호기 출력의 오차), 보조정리 5에서 X̂(i) = E(X(i)|M₁,M₂)를 쓴다. 두 하계가 **같은 K̃**를 쓰도록 여기서는 처음부터 K̃ᵢ := K_{X(i)|M₁,M₂} (MMSE 오차 공분산)로 정의한다. MMSE가 복호기보다 나쁘지 않으므로 K̃(j,j) ≤ Dⱼ는 그대로 성립.] X(i) := (X₁ᵢ,X₂ᵢ)ᵀ, M := (M₁,M₂), K̃ := (1/n)Σᵢ K̃ᵢ, K_X = [[1,ρ],[ρ,1]], |K_X| = 1−ρ².

**θ의 존재** [재구성: 원문 "for some θ ∈ [−1,1]"]. K̃(j,j) ≤ Dⱼ이면 K̃ ⪯ K(θ) := [[D₁, θ√(D₁D₂)],[θ√(D₁D₂), D₂]]인 θ ∈ [−1,1]이 있다. 증명: aⱼ := Dⱼ − K̃(j,j) ≥ 0, θ√(D₁D₂) := K̃₁₂ + √(a₁a₂)로 두면 K(θ) − K̃ = [[a₁, √(a₁a₂)],[√(a₁a₂), a₂]] ⪰ 0 (행렬식 0, 대각 ≥ 0). |θ| ≤ 1: |K̃₁₂| ≤ √(K̃₁₁K̃₂₂)이고 코시–슈바르츠로 √(K̃₁₁K̃₂₂) + √(a₁a₂) ≤ √((K̃₁₁ + a₁)(K̃₂₂ + a₂)) = √(D₁D₂). ∎

**(가) 협력 하계 (cooperative lower bound).** 두 부호기가 합쳐진 부호기(율 R₁+R₂)보다 나을 수 없다.
n(R₁+R₂) ≥ H(M) = I(X₁ⁿ,X₂ⁿ;M) (M은 소스의 함수)
 = h(X₁ⁿ,X₂ⁿ) − h(X₁ⁿ,X₂ⁿ|M)
 ≥ (n/2)log((2πe)²|K_X|) − Σᵢ h(X(i)|M) (i.i.d. + 연쇄 법칙·조건 축소)
 ≥ (n/2)log((2πe)²|K_X|) − Σᵢ ½log((2πe)²|K̃ᵢ|) (최대 미분 엔트로피 보조정리)
 ≥ (n/2)log((2πe)²|K_X|) − (n/2)log((2πe)²|K̃|) (log det 오목성, 옌센)
 = (n/2)log(|K_X|/|K̃|) ≥ (n/2)log(|K_X|/|K(θ)|) (K̃ ⪯ K(θ) ⇒ |K̃| ≤ |K(θ)|).
∴ R₁+R₂ ≥ R₁(θ) := R(|K_X|/|K(θ)|) = R((1−ρ²)/(D₁D₂(1−θ²))).

**(나) μ-합 하계 (μ-sum lower bound).** *아이디어*: 가상의 관측 Yᵢ = μᵀX(i) + Zᵢ, Zᵢ ~ WGN(N) 독립을 도입한다. N과 μ를 잘 고르면 X₁ᵢ – Yᵢ – X₂ᵢ가 마르코프가 되어, Y가 "두 소스의 공통 정보"를 담는다. Y를 알면 두 부호기의 남은 불확실성이 분리(K̂ 대각)되므로, 분산 부호의 불이익을 정량화할 수 있다.
임의의 (μ,N)에 대해
n(R₁+R₂) ≥ H(M) = I(Xⁿ,Yⁿ;M) (M은 Xⁿ의 함수이고 Yⁿ은 M에 대해 Xⁿ 너머 정보가 없으므로 I(Xⁿ,Yⁿ;M) = H(M))
 = h(Xⁿ,Yⁿ) − h(Yⁿ|M) − h(Xⁿ|M,Yⁿ) (연쇄 법칙)
 ≥ Σᵢ [h(X(i),Yᵢ) − h(Yᵢ|M) − h(X(i)|M,Yⁿ)] (첫 항: i.i.d.로 등호; 나머지: 연쇄 법칙 + 조건 축소)
 ≥ Σᵢ ½log(|K_X|·N / (|K̂ᵢ|·(μᵀK̃ᵢμ + N))) [근거: h(X(i),Yᵢ) = h(X(i)) + h(Zᵢ) = ½log((2πe)³|K_X|N); Yᵢ − μᵀE(X(i)|M) = μᵀ(X(i) − E(X(i)|M)) + Zᵢ의 분산 = μᵀK̃ᵢμ + N이므로 h(Yᵢ|M) ≤ ½log(2πe(μᵀK̃ᵢμ + N)); K̂ᵢ := K_{X(i)|M,Yⁿ}이면 h(X(i)|M,Yⁿ) ≤ ½log((2πe)²|K̂ᵢ|). (2πe)³은 상쇄.]
 ≥ (n/2)log(|K_X|·N/(|K̂|·(μᵀK̃μ + N))) (−log det, −log(·)는 볼록이므로 옌센; K̂ := (1/n)ΣK̂ᵢ)
 ≥ (n/2)log(|K_X|·N/(|K̂|·(μᵀK(θ)μ + N))) (K̃ ⪯ K(θ)).
이제 **μ = (1/√D₁, 1/√D₂)ᵀ, N = (1−ρ²)/(ρ√(D₁D₂))**로 고른다. 그러면
- μᵀK(θ)μ = D₁/D₁ + D₂/D₂ + 2θ√(D₁D₂)/√(D₁D₂) = 2(1+θ).
- X₁ᵢ – Yᵢ – X₂ᵢ [재구성: 원문 "readily shown"]: 가우시안에서 Cov(X₁,X₂|Y) = 0을 보이면 된다. Cov(X₁,X₂) − Cov(X₁,Y)Cov(Y,X₂)/Var(Y) = 0 ⇔ ρ(μ₁² + μ₂² + 2ρμ₁μ₂ + N) = (μ₁ + ρμ₂)(ρμ₁ + μ₂) ⇔ ρN + 2ρ²μ₁μ₂ = (1+ρ²)μ₁μ₂ ⇔ N = μ₁μ₂(1−ρ²)/ρ = (1−ρ²)/(ρ√(D₁D₂)). ✓

**보조정리 5.** |K̂| ≤ D₁D₂N²(1+θ)²/(2(1+θ)+N)².

이를 넣으면 [재구성: 대수]
R₁+R₂ ≥ ½log(|K_X|·N·(2(1+θ)+N)² / (D₁D₂N²(1+θ)²·(2(1+θ)+N))) = ½log(|K_X|(2(1+θ)+N) / (N D₁D₂(1+θ)²)) =: R₂(θ).
**[정정]** 원문 13–30 (PDF 326쪽 이미지 확인)은 R₂(θ) := R(|K_X|(2(1+θ)+N)²/(N D₁D₂(1+θ)²))로 **제곱**을 붙였다. 위 대수에서 (2(1+θ)+N)이 분모에 한 번 남으므로 지수는 1이어야 하고, 13–31의 "R₁(θ*) = R₂(θ*)"와 최종 합 율도 지수 1일 때만 성립한다. 수치 확인(ρ = 0.8, D₁ = 0.3, D₂ = 0.4): θ* = 0.54290에서 R₁(θ*) = 1.04437, 지수 1인 R₂(θ*) = 1.04437 = 목표 합 율, 제곱판은 2.11064. 판단: 원문 오식. [판단, 수치 검증]

**(다) min-max 계산** [원문 13–31, 대수 재구성].
- R₁(θ) = ½log((1−ρ²)/(D₁D₂(1−θ²)))는 [0,1)에서 증가(θ² 증가).
- R₂(θ)는 (2(1+θ)+N)/(1+θ)² = 2/(1+θ) + N/(1+θ)²이 θ에 대해 감소하므로 (−1,1)에서 감소.
- 교점: R₁ = R₂ ⇔ (1+θ)²N = (1−θ²)(2(1+θ)+N) ⇔ (1+θ 약분) (1+θ)N = (1−θ)(2(1+θ)+N) ⇔ N + Nθ = 2(1−θ²) + N − Nθ ⇔ **θ² + Nθ − 1 = 0** ⇔ θ* = (√(N²+4) − N)/2 = (√((1−ρ²)² + 4ρ²D₁D₂) − (1−ρ²))/(2ρ√(D₁D₂)) — **달성에서 고른 θ와 정확히 같다**(3.6.4).
- θ* > 0. θ < θ*이면 max ≥ R₂(θ) > R₂(θ*); θ > θ*이면 max ≥ R₁(θ) > R₁(θ*). 그래서 min_θ max = R₁(θ*) = R₂(θ*).
- 값: 1 − θ*² = Nθ*이므로 R₁(θ*) = ½log((1−ρ²)/(D₁D₂Nθ*)). Nθ* = (1−ρ²)(√A − (1−ρ²))/(2ρ²D₁D₂), A := (1−ρ²)² + 4ρ²D₁D₂. 그러면 (1−ρ²)/(D₁D₂Nθ*) = 2ρ²/(√A − (1−ρ²)) = 2ρ²(√A + 1 − ρ²)/(A − (1−ρ²)²) = (√A + 1 − ρ²)/(2D₁D₂) = (1−ρ²)φ(D₁,D₂)/(2D₁D₂). ∎
- 증명이 실제로 주는 것: 모든 부호에 대해 "K̃ ⪯ K(θ)인 **어떤** θ에서 R₁+R₂ ≥ max{R₁(θ),R₂(θ)}" ⇒ R₁+R₂ ≥ min_θ max{…}. 두 하계가 같은 θ를 공유해야 한다는 점이 핵심이다(그래서 공통 준비에서 K̃를 통일했다).

**주석** [원문 13–32]. X₁ – Y – X₂가 되도록 Y를 고른 것은 두 확률변수의 **공통 정보(common information)**를 잡는 것으로 해석할 수 있다(14·15장에서 다시 나옴).

#### 3.6.7 보조정리 5의 증명 [원문 13–52~13–54, PDF 337–338쪽]

세 단계: (1) K̂는 대각, (2) 추정 이론으로 K̂ ⪯ (K̃⁻¹ + (1/N)μμᵀ)⁻¹ ⪯ (K(θ)⁻¹ + (1/N)μμᵀ)⁻¹, (3) 대각 행렬이 2×2 행렬 아래에 있을 때의 행렬식 한계.

**1단계: K̂ = diag(β₁,β₂).** M₁ – X₁ⁿ – Yⁿ – X₂ⁿ – M₂가 마르코프 사슬이다 [재구성: 시각마다 X₁ᵢ – Yᵢ – X₂ᵢ이고 시각 간 독립이므로 블록 단위로 X₁ⁿ – Yⁿ – X₂ⁿ; Mⱼ는 Xⱼⁿ의 함수]. 그러면 (Yⁿ,M₁,M₂)가 주어질 때 X₁ⁿ과 X₂ⁿ은 조건부 독립 [재구성: p(x₁ⁿ,x₂ⁿ|yⁿ) = p(x₁ⁿ|yⁿ)p(x₂ⁿ|yⁿ)에 m₁(x₁ⁿ), m₂(x₂ⁿ)의 지시 함수를 곱해도 곱 꼴 유지]. 그래서 모든 i, i′에 대해
E[(X₁ᵢ − E(X₁ᵢ|Yⁿ,M))(X₂ᵢ′ − E(X₂ᵢ′|Yⁿ,M))] = E[(X₁ᵢ − E(X₁ᵢ|Yⁿ,X₂ᵢ′,M))(X₂ᵢ′ − E(X₂ᵢ′|Yⁿ,M))] = 0
(첫 등식: 조건부 독립으로 E(X₁ᵢ|Yⁿ,M) = E(X₁ᵢ|Yⁿ,X₂ᵢ′,M); 둘째: 직교성 원리 — 추정 오차는 조건 변수 (Yⁿ,X₂ᵢ′,M)의 모든 함수와 직교하고, X₂ᵢ′ − E(X₂ᵢ′|Yⁿ,M)는 그런 함수). 그래서 각 K̂ᵢ가 대각이고 평균 K̂도 대각.

**2단계: 행렬 부등식.** Ỹ(i) := (Yᵢ, X̂(i)), X̂(i) := E(X(i)|M) (2차원). 모든 i에 **공통인** 행렬 A := ((1/n)Σ K_{X(i)Ỹ(i)})((1/n)Σ K_{Ỹ(i)})⁻¹.
(1/n)Σ K_{X(i)|Yⁿ,M}
 ⪯(a) (1/n)Σ K_{X(i) − AỸ(i)} (MMSE E(X(i)|Yⁿ,M)는 (Yⁿ,M)의 함수인 AỸ(i)보다 나쁘지 않음)
 =(b) (1/n)ΣK_{X(i)} − ((1/n)ΣK_{XỸ})((1/n)ΣK_Ỹ)⁻¹((1/n)ΣK_{ỸX}) [재구성: K_{X−AỸ} = K_X − AK_{ỸX} − K_{XỸ}Aᵀ + AK_ỸAᵀ는 공분산들에 대해 선형이므로 평균을 안으로 넣을 수 있고, 평균 공분산에 대해 A가 바로 "평균 선형 MMSE 계수"이므로 정리하면 이 꼴]
 =(c) K_X − [K_Xμ, K_X − K̃] · [[μᵀK_Xμ + N, μᵀ(K_X − K̃)],[(K_X − K̃)μ, K_X − K̃]]⁻¹ · [μᵀK_X ; K_X − K̃]
 [근거: Cov(X,Y) = K_Xμ, Var(Y) = μᵀK_Xμ + N, 직교성으로 Cov(X, X̂) = Cov(X̂) 이고 그 평균 (1/n)ΣK_{X̂(i)} = K_X − K̃, Cov(Y,X̂) = μᵀ(K_X − K̃) (Z는 모든 것과 독립)]
 =(d) (K̃⁻¹ + (1/N)μμᵀ)⁻¹ [재구성: X = X̂ + E, E의 평균 공분산 K̃, X̂와 무상관. (X̂, Y)로부터의 선형 추정은 "X̂를 빼고 남은 Y − μᵀX̂ = μᵀE + Z로 E를 추정"하는 것과 같다. 그 오차 공분산 = K̃ − K̃μ(μᵀK̃μ + N)⁻¹μᵀK̃ = (K̃⁻¹ + μμᵀ/N)⁻¹ (2.9의 정보 형식, H = μᵀ). (c)의 블록 역행렬을 직접 계산해도 같다.]
 ⪯(e) (K(θ)⁻¹ + (1/N)μμᵀ)⁻¹ (K̃ ⪯ K(θ) ⇒ K̃⁻¹ ⪰ K(θ)⁻¹ ⇒ 역을 취하면 순서 반전).
μ, N을 넣고 계산하면 [원문 13–54, 재구성: 2.9 정보 형식의 셔먼–모리슨(Sherman–Morrison) 판 (K⁻¹ + μμᵀ/N)⁻¹ = K − Kμμᵀ K/(N + μᵀKμ), Kμ = K(θ)μ = (1+θ)(√D₁, √D₂)ᵀ, μᵀKμ = 2(1+θ)]
(K(θ)⁻¹ + μμᵀ/N)⁻¹ = K(θ) − (1+θ)²/(N + 2(1+θ)) · [[D₁, √(D₁D₂)],[√(D₁D₂), D₂]] = [[(1−α)D₁, (θ−α)√(D₁D₂)],[(θ−α)√(D₁D₂), (1−α)D₂]], α := (1+θ)²/(2(1+θ)+N).
[K(θ)μ 확인: 첫 성분 D₁/√D₁ + θ√(D₁D₂)/√D₂ = √D₁(1+θ). ✓]

**3단계: 행렬식 한계.** 사실: b₁,b₂ ≥ 0이고 diag(b₁,b₂) ⪯ [[a,c],[c,a]]이면 b₁b₂ ≤ (a − c)². [재구성 증명: x := a − b₁ ≥ 0, y := a − b₂ ≥ 0, 차이 행렬이 ⪰ 0이므로 xy ≥ c². s := √(xy) ≥ |c|, x + y ≥ 2s, 그리고 bⱼ ≥ 0이라 x, y ≤ a, 따라서 s ≤ a. b₁b₂ = a² − a(x+y) + xy ≤ a² − 2as + s² = (a−s)² ≤ (a − |c|)² ≤ (a − c)² (a ≥ 0).] Λ := diag(1/√D₁, −1/√D₂)로 합동 변환(congruence; 순서 보존)하면
Λ diag(β₁,β₂) Λ = diag(β₁/D₁, β₂/D₂) ⪯ [[1−α, α−θ],[α−θ, 1−α]]
(음의 부호 때문에 비대각이 θ−α에서 α−θ로 바뀜). 사실을 a = 1−α, c = α−θ로 적용: β₁β₂/(D₁D₂) ≤ (1 − α − α + θ)² = (1 + θ − 2α)². 그리고 1 + θ − 2α = (1+θ)(1 − 2(1+θ)/(2(1+θ)+N)) = (1+θ)N/(2(1+θ)+N). ∴ |K̂| = β₁β₂ ≤ D₁D₂N²(1+θ)²/(2(1+θ)+N)². ∎

### 3.7 가우시안 CEO 문제 [원문, 슬라이드 13–33~13–38, PDF 328–330쪽]

#### 3.7.1 설정과 직관

X ~ WGN(P). 부호기 j = 1, 2는 잡음 섞인 관측 Yⱼᵢ = Xᵢ + Zⱼᵢ, {Zⱼᵢ} ~ WGN(Nⱼ) (서로·X와 독립)만 본다. 복호기는 (M₁,M₂)로 X̂ⁿ을 만들어 limsup E[(1/n)Σ(Xᵢ − X̂ᵢ)²] ≤ D. 율-왜곡 영역 ℛ_CEO(D). CEO(chief executive officer) 이름은 "직접 관찰하지 못하는 경영자가 부하들의 보고만으로 판단한다"는 비유(Berger–Zhang–Viswanathan 1996, `derivations/classic/10_…`).

**분산 소스 부호화와의 차이** [재구성]. 3.6에서는 복호기가 **각 부호기의 소스 자체**를 원했다. CEO에서는 아무도 직접 보지 못한 **원격(remote) 소스 X**를 원한다. 그래서 각 관측의 잡음 Zⱼ를 기술하는 데 쓰는 비트는 X 추정에 낭비다. 그런데 부호기는 X와 Zⱼ를 분리할 수 없으므로 어느 정도 낭비가 불가피하다 — 이 낭비가 아래 정리의 rⱼ 항이다.

**구조적 사실** [재구성]: X가 주어지면 Y₁, Y₂는 독립 ⇒ Mⱼ = mⱼ(Yⱼⁿ)이므로 **블록 수준의 장기 마르코프 사슬 M₁ – Y₁ⁿ – Xⁿ – Y₂ⁿ – M₂**가 임의의 부호에서 자동으로 성립한다. 일반 분산 문제(3.5)에서는 역정리가 이것을 얻지 못하는 반면 CEO에서는 공짜로 얻는다 — 그래서 꼭 맞는 역정리가 가능하다(5절 2번).

#### 3.7.2 정리 [원문 13–35, Oohama 2005; Prabhakaran–Tse–Ramchandran 2004]

ℛ_CEO(D)는 다음을 만족하는 r₁, r₂ ≥ 0이 있는 (R₁,R₂)의 집합이다:
- R₁ ≥ r₁ + ½log(1/D) − ½log(1/P + (1 − 2^{−2r₂})/N₂),
- R₂ ≥ r₂ + ½log(1/D) − ½log(1/P + (1 − 2^{−2r₁})/N₁),
- R₁ + R₂ ≥ r₁ + r₂ + ½log(P/D),
- 제약: 1/D ≤ 1/P + (1 − 2^{−2r₁})/N₁ + (1 − 2^{−2r₂})/N₂.

**rⱼ의 뜻** [재구성]. rⱼ = (1/n)I(Yⱼⁿ;Mⱼ|Xⁿ) = "X를 알아도 Mⱼ가 담고 있는 정보" = 관측 잡음을 기술하는 데 쓴 율. 제약식은 2.9의 정밀도 덧셈과 같은 꼴이다: 부호기 j는 X에 대해 정밀도 (1 − 2^{−2rⱼ})/Nⱼ, 즉 **유효 잡음 분산 Nⱼ/(1 − 2^{−2rⱼ})**의 관측을 준다. rⱼ → ∞면 원래 관측(정밀도 1/Nⱼ), rⱼ = 0이면 아무것도 주지 않는다.

**K개 부호기로의 일반화** [원문 13–41은 "확장 가능"이라고만 함; 증명은 아래와 똑같이 J ⊆ [1:K]로 하면 된다 — 재구성]: 모든 J ⊆ [1:K]에 대해
Σ_{j∈J} Rⱼ ≥ Σ_{j∈J} rⱼ + ½log(1/D) − ½log(1/P + Σ_{j∈Jᶜ}(1 − 2^{−2rⱼ})/Nⱼ),
J = ∅가 제약식이다.

#### 3.7.3 달성 [원문 13–35 "BT + 분산 가우시안 시험 채널", 계산 재구성]

Uⱼ = Yⱼ + Vⱼ, Vⱼ ~ N(0,Qⱼ) 독립. (K개 부호기 버거–텅 내부 경계: Σ_{J}Rⱼ > I(Y(J);U(J)|U(Jᶜ)) ∀J — 2부호기 정리 1의 직접 확장, 원문은 진술하지 않음 [재구성].)
- rⱼ := I(Yⱼ;Uⱼ|X) = h(Uⱼ|X) − h(Vⱼ) = ½log((Nⱼ+Qⱼ)/Qⱼ) ⇒ 1 − 2^{−2rⱼ} = Nⱼ/(Nⱼ+Qⱼ), 즉 (1 − 2^{−2rⱼ})/Nⱼ = 1/(Nⱼ+Qⱼ).
- Uⱼ = X + (Zⱼ + Vⱼ)는 잡음 분산 Nⱼ + Qⱼ인 X의 독립 관측이므로 정밀도 덧셈: 1/Var(X|U(S)) = 1/P + Σ_{j∈S} 1/(Nⱼ+Qⱼ) = 1/P + Σ_{j∈S}(1 − 2^{−2rⱼ})/Nⱼ.
- I(Y(J);U(J)|U(Jᶜ)) = I(X,Y(J);U(J)|U(Jᶜ)) (U(J)는 Y(J)를 통해서만 X에 의존) = I(X;U(J)|U(Jᶜ)) + I(Y(J);U(J)|X,U(Jᶜ)) = I(X;U(J)|U(Jᶜ)) + Σ_{j∈J} rⱼ (X가 주어지면 (Yⱼ,Uⱼ) 쌍들이 독립). 그리고 I(X;U(J)|U(Jᶜ)) = ½log(Var(X|U(Jᶜ))/Var(X|U)) = ½log(1/D) − ½log(1/P + Σ_{Jᶜ}(1 − 2^{−2rⱼ})/Nⱼ) (D := Var(X|U), 최종 추정 X̂ = E(X|U)).
→ 정리의 각 부등식이 등호로 정확히 나온다. 즉 **역정리의 매개변수 rⱼ는 시험 채널의 I(Yⱼ;Uⱼ|X)와 같은 것**이다.

#### 3.7.4 역정리 [원문 13–36~13–38; 깨진 식은 PDF 329–330쪽 이미지로 대조]

(2^{nR₁},2^{nR₂},n) 부호열이 limsup E(1/n)Σ(Xᵢ−X̂ᵢ)² ≤ D를 만족한다고 하자. J ⊆ {1,2}, M(J) := (Mⱼ : j ∈ J), Yⁿ(J) 마찬가지. rⱼ := (1/n)I(Yⱼⁿ;Mⱼ|Xⁿ).

**1단계: 율을 "X 정보 + 잡음 정보"로 쪼갠다.**
n Σ_{j∈J} Rⱼ ≥ H(M(J)) ≥ H(M(J)|M(Jᶜ))
 = I(Yⁿ(J);M(J)|M(Jᶜ)) (M(J)는 Yⁿ(J)의 함수)
 = I(Yⁿ(J),Xⁿ;M(J)|M(Jᶜ)) (Yⁿ(J)가 주어지면 M(J)는 결정되므로 Xⁿ을 추가해도 상호정보 불변)
 = I(Xⁿ;M(J)|M(Jᶜ)) + I(Yⁿ(J);M(J)|Xⁿ,M(Jᶜ)) (연쇄 법칙)
 = I(Xⁿ;M(J)|M(Jᶜ)) + I(Yⁿ(J);M(J)|Xⁿ) (Xⁿ이 주어지면 (Yⁿ(J),M(J))와 M(Jᶜ)는 독립 — 블록 장기 사슬)
 = [I(Xⁿ;M(J),M(Jᶜ)) − I(Xⁿ;M(Jᶜ))] + Σ_{j∈J} I(Yⱼⁿ;Mⱼ|Xⁿ) [재구성: Xⁿ이 주어지면 Mⱼ들이 독립이므로 I(Yⁿ(J);M(J)|Xⁿ) = H(M(J)|Xⁿ) = Σ H(Mⱼ|Xⁿ) = Σ I(Yⱼⁿ;Mⱼ|Xⁿ)]
 ≥ (n/2)log(P/D) − I(Xⁿ;M(Jᶜ)) + n Σ_{j∈J} rⱼ.
마지막: I(Xⁿ;M₁,M₂) ≥ (n/2)log(P/D)는 2.10과 같다(h(Xⁿ) − h(Xⁿ|M) ≥ (n/2)log(2πeP) − Σh(Xᵢ|X̂ᵢ) ≥ …). [엄밀하게는 D + ε.]

**2단계: I(Xⁿ;M(Jᶜ))의 상한 — EPI가 쓰이는 곳.** 목표: 2^{(2/n)I(Xⁿ;M(Jᶜ))} ≤ 1 + Σ_{j∈Jᶜ}(P/Nⱼ)(1 − 2^{−2rⱼ}).

(2-a) **분해.** X̃ᵢ := E(Xᵢ|Yᵢ(Jᶜ)) = Σ_{j∈Jᶜ}(Ñ/Nⱼ)Yⱼᵢ = Σ_{j∈Jᶜ}(Ñ/Nⱼ)(Xᵢ + Zⱼᵢ), Ñ := 1/(1/P + Σ_{j∈Jᶜ}1/Nⱼ). 그러면 Xᵢ = X̃ᵢ + Z̃ᵢ, {Z̃ᵢ} ~ WGN(Ñ)는 Yᵢ(Jᶜ)와 독립 (가우시안에서 MMSE 오차는 관측과 독립; 오차 분산 Ñ은 정밀도 덧셈). [재구성 확인: 2.9 예의 MMSE 계수 P/(nP+N)을 서로 다른 Nⱼ로 일반화하면 계수 Ñ/Nⱼ.]
따라서 Z̃ⁿ은 (X̃ⁿ, M(Jᶜ))와 독립(둘 다 Yⁿ(Jᶜ)의 함수)이고, M(Jᶜ)가 주어지면 X̃ⁿ과 Z̃ⁿ은 조건부 독립.

(2-b) **첫 EPI (신호 + 추정 오차).** 조건부 EPI:
2^{(2/n)h(Xⁿ|M(Jᶜ))} ≥ 2^{(2/n)h(X̃ⁿ|M(Jᶜ))} + 2^{(2/n)h(Z̃ⁿ|M(Jᶜ))} = 2^{(2/n)[h(X̃ⁿ|Xⁿ,M(Jᶜ)) + I(X̃ⁿ;Xⁿ|M(Jᶜ))]} + 2πeÑ.
(h(X̃|M) = h(X̃|X,M) + I(X̃;X|M)는 정의; h(Z̃ⁿ|M(Jᶜ)) = h(Z̃ⁿ) = (n/2)log(2πeÑ).)

(2-c) **둘째 EPI (잡음들의 합).** Xⁿ이 주어지면 X̃ⁿ = (상수) + Σ_{j∈Jᶜ}(Ñ/Nⱼ)Zⱼⁿ이고, (Xⁿ, M(Jᶜ))가 주어지면 항 (Ñ/Nⱼ)Yⱼⁿ들은 조건부 독립(각 Mⱼ는 자기 Yⱼⁿ만의 함수, Yⱼ들은 X가 주어지면 독립). 여러 항 조건부 EPI:
2^{(2/n)h(X̃ⁿ|Xⁿ,M(Jᶜ))} ≥ Σ_{j∈Jᶜ}(Ñ²/Nⱼ²)2^{(2/n)h(Yⱼⁿ|Xⁿ,M(Jᶜ))} = Σ_{j∈Jᶜ}(Ñ²/Nⱼ²)2^{(2/n)h(Yⱼⁿ|Xⁿ,Mⱼ)}
(축척 (Ñ/Nⱼ)ⁿ → 지수에서 (Ñ/Nⱼ)²; 다른 Mₖ는 (Xⁿ,Mⱼ)가 주어지면 Yⱼⁿ과 독립이라 조건에서 뺄 수 있음)
 = Σ (Ñ²/Nⱼ²)2^{(2/n)[h(Yⱼⁿ|Xⁿ) − I(Yⱼⁿ;Mⱼ|Xⁿ)]} = Σ (Ñ²/Nⱼ²)·2πeNⱼ·2^{−2rⱼ} = Σ_{j∈Jᶜ}(Ñ²/Nⱼ)2πe2^{−2rⱼ}.
(h(Yⱼⁿ|Xⁿ) = h(Zⱼⁿ) = (n/2)log(2πeNⱼ).)

(2-d) **상호정보 항.** 2^{(2/n)I(Xⁿ;X̃ⁿ|M(Jᶜ))} = 2^{(2/n)[h(Xⁿ|M(Jᶜ)) − h(Xⁿ|X̃ⁿ,M(Jᶜ))]} = (1/(2πeÑ))·2^{(2/n)h(Xⁿ|M(Jᶜ))}.
(h(Xⁿ|X̃ⁿ,M(Jᶜ)) = h(Z̃ⁿ|X̃ⁿ,M(Jᶜ)) = h(Z̃ⁿ) = (n/2)log(2πeÑ), 평행 이동 + 독립.)

(2-e) **자기 참조 부등식 풀기.** A := 2^{(2/n)h(Xⁿ|M(Jᶜ))}로 쓰면 (2-b),(2-c),(2-d)에서
A ≥ (Σ_{j∈Jᶜ}(Ñ²/Nⱼ)2πe2^{−2rⱼ})·(A/(2πeÑ)) + 2πeÑ = (Σ_{j∈Jᶜ}(Ñ/Nⱼ)2^{−2rⱼ})·A + 2πeÑ.
Σ_{Jᶜ}Ñ/Nⱼ < 1 (Ñ의 정의에서 Ñ(1/P + Σ1/Nⱼ) = 1)이므로 계수 c := Σ(Ñ/Nⱼ)2^{−2rⱼ} < 1이고 A ≥ 2πeÑ/(1 − c). 그러면
2^{(2/n)I(Xⁿ;M(Jᶜ))} = 2^{(2/n)(h(Xⁿ) − h(Xⁿ|M(Jᶜ)))} = 2πeP/A ≤ (P/Ñ)(1 − c) = P/Ñ − Σ_{Jᶜ}(P/Nⱼ)2^{−2rⱼ} = 1 + Σ_{Jᶜ}(P/Nⱼ)(1 − 2^{−2rⱼ})
(P/Ñ = 1 + Σ_{Jᶜ}P/Nⱼ 사용).

**3단계: 결합.**
Σ_{j∈J}Rⱼ ≥ ½log(P/D) − ½log(1 + Σ_{j∈Jᶜ}(P/Nⱼ)(1 − 2^{−2rⱼ})) + Σ_{j∈J}rⱼ = ½log(1/D) − ½log(1/P + Σ_{j∈Jᶜ}(1 − 2^{−2rⱼ})/Nⱼ) + Σ_{j∈J}rⱼ.
J = {1,2}: 합 율 부등식, J = {1}, {2}: 개별 부등식, J = ∅: 0 ≥ … 즉 제약식. rⱼ는 n에 의존하지만 [0, Rⱼ] 안에 있으므로(rⱼ ≤ (1/n)H(Mⱼ) ≤ Rⱼ) 수렴하는 부분열을 잡아 극한으로 넘기면 된다 [재구성: 원문 생략]. ∎

**EPI 등호 조건과 최적성** [재구성]. 두 EPI는 조건부 분포가 가우시안이고 공분산이 비례할 때 등호다. 가우시안 시험 채널 Uⱼ = Yⱼ + Vⱼ에서 (Yⱼ|X, Uⱼ)는 가우시안이므로 등호가 성립하고, 3.7.3에서 본 것처럼 각 부등식이 등호로 맞는다. 그래서 버거–텅이 최적이다.

#### 3.7.5 대칭 K-부호기 CEO 합 율의 닫힌 식 [재구성 — 원문에는 없음]

Nⱼ = N (모든 j), K개 부호기. 합 율 R_sum(D) := min Σ Rⱼ.

**유도.** J = [1:K]에서 Σ Rⱼ ≥ ½log(P/D) + Σⱼ rⱼ, 제약 1/D ≤ 1/P + Σⱼ(1 − 2^{−2rⱼ})/N. Σ rⱼ를 최소화한다. f(r) = 1 − 2^{−2r}은 오목이므로 Σ rⱼ를 고정하면 Σ f(rⱼ)는 모두 같을 때 최대(옌센) — 즉 임의의 실행 가능한 (rⱼ)를 평균 r̄로 바꿔도 여전히 실행 가능하고 합은 같다. 그래서 대칭 r로 충분하고, 최소 r은 제약을 등호로 만드는 값:
1/D = 1/P + K(1 − 2^{−2r})/N ⇔ 2^{−2r} = 1 − N(P − D)/(KPD) ⇔ r = ½log(KPD/(KPD − N(P−D))).
**R_sum(D) = ½log(P/D) + (K/2)log(KPD/(KPD − N(P − D))),  D_min < D ≤ P,  D_min := PN/(KP + N).**
달성 [재구성]: 대칭 시험 채널 Q = N·2^{−2r}/(1 − 2^{−2r}). 이때 BT 영역 {Σ_J Rⱼ ≥ f(J) ∀J}, f(J) := I(Y(J);U(J)|U(Jᶜ))에서 합 율 f([1:K]) = I(Y^K;U^K)가 실제로 달성된다: 순서 1,…,K로 "연속 복호" 꼭짓점 R_k := I(Y_k;U_k|U_{k+1},…,U_K)를 잡으면 Σ R_k = I(Y^K;U^K) (연쇄 법칙 + 장기 사슬), 그리고 임의의 J에 대해 Σ_{k∈J}R_k ≥ f(J) (각 항에서 조건 U_{k+1..K} 중 J에 속하지 않는 것만 남기면 상호정보가 줄어듦: I(Y_k;U_k|U_{>k}) = H(U_k|U_{>k}) − H(U_k|Y_k) ≥ H(U_k|U_{>k}, U(Jᶜ)) − H(U_k|Y_k)이고, 이 우변들을 J 안에서 합하면 f(J)). 그 결과 R_sum = I(Y^K;U^K) = ½log(P/D) + K·r (3.7.3, J = [1:K]).

**극한 점검.**
1. **D = P**: 둘째 항 로그 안 = KP²/KP² = 1 ⇒ R_sum = 0. ✓ (평균으로 추정)
2. **D ↓ D_min**: 로그 안 분모 KPD − N(P−D) → 0 ⇔ D = PN/(KP+N) = Var(X|Y₁,…,Y_K). R_sum → ∞. 발산 속도 ≈ (K/2)log(1/(D − D_min)) — 중앙 부호기(모든 Yⱼ를 한 곳에서 봄)의 ½log(1/(D − D_min))보다 **K배** 빠르다. 각 부호기가 자기 잡음까지 정밀하게 기술해야 하기 때문이다.
3. **K = 1**: R_sum = ½log((P − D_min)/(D − D_min)), D_min = PN/(P+N) — 원격 소스 율-왜곡 함수(E[X|Y]를 분산 P − D_min인 소스로 보고 D − D_min까지 압축). [재구성 확인: ½log(P/D) + ½log(PD/(PD − N(P−D))) = ½log(P²/((P+N)D − NP)) = ½log((P²/(P+N))/(D − PN/(P+N))), P²/(P+N) = P − D_min. ✓]
4. **K → ∞ (D 고정 > 0)**: a := N(P−D)/(PD)이면 둘째 항 = −(K/2)log(1 − a/K) → (a/2)log e. R_sum → ½log(P/D) + (N(P−D)/(2PD))log e — **유한**. 부호기당 율 → 0.
5. **N → 0**: R_sum → ½log(P/D) (보통 가우시안 율-왜곡).

**수치 예 (손으로 따라 할 것).** P = 1, N = 0.5, K = 4, D = 0.2.
- D_min = 0.5/(4 + 0.5) = 0.1111.
- KPD = 0.8, N(P−D) = 0.4 ⇒ r = ½log₂(0.8/0.4) = 0.5 비트. 대칭 시험 채널: 2^{−2r} = ½ = Q/(N+Q) ⇒ Q = 0.5. 검산: 1/D = 1 + 4/(0.5+0.5) = 5 ✓.
- R_sum = ½log₂5 + 4·0.5 = 1.161 + 2 = **3.161 비트** (부호기당 0.790).
- 비교: 중앙 부호기라면 ½log₂((1−0.1111)/(0.2−0.1111)) = ½log₂10 = 1.661 비트. 분산의 대가 = 1.5 비트.
- K를 늘릴 때 (D = 0.2): K = 10: 2.771, K = 100: 2.618, K = 1000: 2.605, K = 10⁵: 2.6037 → 극한 ½log₂5 + (0.5·0.8/(2·0.2))log₂e = 1.161 + 1.443 = 2.6037 ✓.
- D → D_min (K = 4): D = 0.12: 8.70, 0.112: 15.19, 0.1112: 21.82, 0.11112: 28.47 — D − D_min이 10배 줄 때마다 약 (K/2)log₂10 = 6.64 비트씩 증가 ✓.
- K = 1, D = 0.5: ½log₂2 + ½log₂(0.5/0.25) = 1.000 = ½log₂((1 − 1/3)/(0.5 − 1/3)) = ½log₂4 ✓.

### 3.8 반례: 이중 대칭 이진 소스 [원문, 슬라이드 13–39~13–40, PDF 331쪽; Wagner–Kelly–Altuğ 2009]

**설정.** (X̃,Ỹ) ~ DSBS(p), p ∈ (0, ½) (X̃ ~ Bern(½), Ỹ = X̃ ⊕ Bern(p)). X₁ = (X̃, Ỹ), X₂ = Ỹ. d₁ = X̃에 대한 해밍, d₂ ≡ 0 (X₂는 복원 불필요). 부호기 1이 **부호기 2의 소스 전체를 안다**는 점이 핵심.

**더 나은 방식** [원문 + 재구성]. 부호기 2가 Ỹ를 V로 기술(율 I(Ỹ;V))한다. 부호기 1도 Ỹ를 알고 부호책이 공개이므로 **부호기 2가 고른 Vⁿ을 똑같이 계산할 수 있다**(결정적 부호화). 그러면 부호기 1은 Vⁿ을 양쪽이 아는 부가 정보로 놓고 X̃를 조건부 율-왜곡으로 기술한다: R₁ > I(X̃;X̂₁|V), R₂ > I(Ỹ;V), p(v|ỹ)p(x̂₁|x̃,v). p(v|ỹ) = BSC(α)로 두면 X̃ = V ⊕ Bern(α∗p) (α∗p := α(1−p) + (1−α)p)이므로 [재구성: 조건부 해밍 율-왜곡 = H(α∗p) − H(D₁)]
R₁ > H(α∗p) − H(D₁), R₂ > 1 − H(α), α ∈ [0,½], H(α∗p) ≥ H(D₁).

**BT가 엄격히 못함** [원문 진술, 증명 개요만]. BT 내부 경계는 이 영역에 포함되고, R_{SI-ED}(D₁) < R_{SI-D}(D₁) (DSBS(α∗p)에서 부호기 쪽 부가 정보의 이득이 엄격)와 Mrs. Gerber의 보조정리로 위 영역의 어떤 경계점이 BT 영역 밖에 있음을 보일 수 있다고 원문은 말한다. 세부 계산은 원문에 없다 [미확인]. 원문의 "Theorem 5"는 문맥상 정리 1(BT 내부 경계)을 가리키는 것으로 보인다 [판단: 판(version) 간 번호 불일치].
**왜** [원문]: BT는 부호기들이 **상대 소스에 대한 지식으로 협력**하는 경우를 다루지 못한다. BT의 Uⱼ는 Xⱼ만의 독립 양자화라, 부호기 1이 U₂ⁿ을 재현할 수 있다는 사실을 쓰지 않는다.

**주석** [원문 13–40]. 위 영역이 율-왜곡 영역이다. 일반적으로 X₂가 X₁의 함수이고 d₂ ≡ 0이면 영역 = {R₁ ≥ I(X₁;X̂₁|V), R₂ ≥ I(X₂;V), D₁ ≥ E d₁} (p(v|x₂)p(x̂₁|x₁,v), |V| ≤ |X₂|+2; Kaspi–Berger 1982). 역정리는 BT 외부 경계에서, 달성은 위와 같은 방식. 이 방식은 BT와 "공통 부분(common part)" 기반 협력을 포함하도록 일반화된다(15장 참조).

### 3.9 소스가 셋 이상인 경우 [원문, 슬라이드 13–41, PDF 332쪽]

*답.* H(A⊕B) ≥ H(A⊕B|B) = H(A|B) = H(A) (B가 주어지면 a ↦ a⊕b는 전단사). 예: B가 G 위에서 균등이면 A⊕B도 균등, H(A⊕B) = log|G| = H(B) < H(A) + H(B) (H(A) > 0이면). 조건 (X,W)를 붙이고 귀납.

## 5. 자주 헷갈리는 점

**1. Σₖ I(Yₖ;Uₖ)와 I(Y^K;U^K)의 차이.** Σₖ I(Yₖ;Uₖ)는 **비닝 전** 각 부호기의 양자화 율의 합(Σ R̃ₖ, 덮개 보조정리가 요구하는 부호책 크기)이다. I(Y^K;U^K)는 **비닝 후** 실제로 보내는 합 율이다. 장기 사슬 아래에서 둘의 차이는 Σₖ h(Uₖ) − h(U^K) (총 상관, total correlation)이고, 이것이 상호 채움 보조정리가 허용하는 "상자 크기의 합" = 비닝으로 아끼는 양이다(K = 2이면 I(U₁;U₂)). 가우시안 CEO에서는 I(Y^K;U^K) = I(X;U^K) + Σₖ I(Yₖ;Uₖ|X): 첫 항은 X에 대한 유용한 정보, 둘째 항은 각 관측 잡음의 기술 비용(rₖ의 합). 반면 Σₖ I(Yₖ;Uₖ) = Σₖ[I(X;Uₖ) + I(Yₖ;Uₖ|X)]는 X 정보를 K번 중복해서 센다 — 비닝은 이 중복을 지운다.

**2. 왜 가우시안 CEO에서는 BT가 최적인가.** (i) CEO에서는 임의의 부호에서 M₁ – Y₁ⁿ – Xⁿ – Y₂ⁿ – M₂가 자동으로 성립한다(관측이 X가 주어지면 독립). 그래서 역정리의 첫 줄 I(Yⁿ(J);M(J)|Xⁿ) = Σⱼ n rⱼ가 **BT 내부 경계의 분해 I(Y(J);U(J)|X) = Σ I(Yⱼ;Uⱼ|X)와 같은 모양**이 된다. 일반 분산 문제에서는 외부 경계의 Uⱼᵢ가 과거를 공유해 장기 사슬이 깨진다(3.5의 3번). (ii) 남은 간극은 "Mⱼ가 가우시안 시험 채널보다 나을 수 있는가"인데, EPI가 정확히 "아니다"라고 말한다(가우시안이 EPI의 등호 경우). (iii) 확인: 3.7.3의 계산이 역정리의 각 부등식을 **등호로** 만든다.

**3. 장기 마르코프 사슬 Uₖ – Yₖ – X – Yⱼ – Uⱼ.** 내부 경계에서는 "각자 양자화"의 결과로 **강제**된다. 외부 경계에서는 짧은 사슬 Uₖ – Yₖ – (나머지)만 얻는다. 이 사슬이 하는 일: (a) I(Y(J);U(J)|X)를 항별 합으로 쪼갠다, (b) 복호기 쪽에서 (U₁,U₂)의 결합 분포를 p(u₁|x₁)p(u₂|x₂)로 결정해 마르코프 보조정리를 쓸 수 있게 한다, (c) 2차 가우시안 분산 문제에서 보조정리 5의 K̂ 대각성(1단계)도 같은 구조(M₁ – X₁ⁿ – Yⁿ – X₂ⁿ – M₂)에서 나온다 — 가상 관측 Y가 두 소스 사이의 "X" 역할을 하도록 만든 것이 μ-합 하계의 발상이다.

**4. 와이너–지브에서는 마르코프 보조정리가 필요 없었는데 왜 여기서는 필요한가.** 와이너–지브에서 부가 정보 Yⁿ은 자연이 만든 것이라 (Uⁿ(L), Xⁿ)이 주어지면 i.i.d. p(y|x)이다 → 조건부 전형성 보조정리로 충분. 버거–텅에서 "부가 정보" 역할을 하는 U₂ⁿ(L₂)는 **부호기가 고른 열**이라 i.i.d.가 아니다 → 보조정리 2(골라진 열의 분포가 조건부 전형 집합 위에서 거의 균등)와 마르코프 보조정리가 필요하다.

**5. ε″ < ε′ < ε의 순서.** 각 단계에서 이전 단계의 전형성을 조건으로 새 변수를 붙일 때 허용 오차가 조금씩 커져야 한다(2.2의 "ε > ε′가 결정적"). 덮개(ε″) → X₂ 추가(ε′) → U₂ 추가(ε, 마르코프 보조정리는 "ε′이 ε에 비해 충분히 작게"를 요구) → 복호(ε).

**6. 부분 오류 사건.** 원문의 E₄ 처리는 "두 지표 모두 틀린" 후보만 명시적으로 다룬다. 하나만 틀린 후보는 채움 보조정리로 따로 처리하며, 그 조건은 합 조건에 함의되므로 최종 영역은 같다(3.4 ④).

**7. 외부 경계로 가우시안 역정리를 하는 것이 아니다.** BT 외부 경계는 2차 가우시안에서도 꼭 맞지 않는다(3.5). 정리 3의 역정리는 외부 경계를 거치지 않고 EPI(ℛ₁, ℛ₂)와 추정 이론(ℛ₁₂)으로 직접 한다.

**8. Rⱼ와 rⱼ는 다르다.** CEO 정리의 rⱼ는 율이 아니라 "X를 알 때 메시지가 담는 정보"(잡음 기술 비용)다. Rⱼ ≥ rⱼ + (X에 관한 기여)이고, 대칭 합 율에서 X에 관한 기여 ½log(P/D)는 **한 번만** 지불된다.

**9. g₁/g₂, R(x)의 log⁺.** R(x)는 x < 1이면 0이다. 3.6의 부등식은 모두 log⁺로 읽어야 하며, 보조정리 3 (a)의 "g₁ + R₂ 증가" 같은 단조성 논증은 log가 양수인 영역에서 한 뒤 0으로 자르는 것이다.

### 5.10 쾨르너–마르톤(Körner–Marton) 반례: 구조 있는 부호가 BT를 이긴다 [재구성 — 13장 원문에는 없음; `derivations/classic/05_Koerner-Marton1979.md` 참조]

**설정.** (X,Y) ~ DSBS(p): X ~ Bern(½), Y = X ⊕ Z, Z ~ Bern(p) 독립, p < ½. 두 부호기가 X, Y를 따로 보고, 복호기는 **Z = X ⊕ Y만** 무손실로 원한다.

**비구조(BT/슬레피안–울프) 방식.** 무작위 부호책과 무작위 비닝은 대수 구조가 없어서 복호기가 할 수 있는 일은 결국 (Uₖ들을 개별 복원하는 것, 즉) 무손실 극한에서 (Xⁿ, Yⁿ)을 둘 다 복원하고 XOR하는 것이다. 그 합 율은 H(X,Y) = 1 + h(p) (h: 이진 엔트로피). [이 율이 BT형 방식 전체의 최소 합 율이라는 일반 진술은 이 노트에서 증명하지 않음 [미확인]; 쾨르너–마르톤 원 논문의 비교 기준은 슬레피안–울프 합 율.]

**선형 방식.** BSC(p)에 대한 좋은 선형 부호의 패리티 검사 행렬 H (크기 n(h(p)+δ) × n)를 두 부호기가 공유한다. 부호기 1은 Hxⁿ, 부호기 2는 Hyⁿ (신드롬)을 보낸다. 복호기는 Hxⁿ ⊕ Hyⁿ = H(xⁿ ⊕ yⁿ) = Hzⁿ (선형성!)을 계산하고, 신드롬에서 zⁿ을 (전형 잉여류 대표로) 복원한다 — zⁿ은 엔트로피 h(p)인 i.i.d.열이므로 신드롬 길이 n(h(p)+δ)면 충분. 각 율 h(p), **합 율 2h(p) < 1 + h(p)** (h(p) < 1이므로 항상).
수치: p = 0.11이면 h(p) ≈ 0.50, 선형 1.00 비트 대 비구조 1.50 비트.

**BT가 일반적으로 최적이 아닌 이유.** (i) BT의 무작위 부호책은 "부호어들의 함수"를 계산하는 구조가 없어서, 목표가 소스들의 **함수**(엔트로피가 작은)일 때도 개별 부호어를 다 복원해야 한다. 선형 부호에서는 비닝(신드롬)이 ⊕와 교환되므로 복호기가 합을 직접 받는다. (ii) 3.8의 반례는 다른 원인 — 부호기 간 협력(한 부호기가 상대의 부호어를 재현 가능) — 을 보인다. 두 반례 모두 "독립 무작위 양자화 + 무작위 비닝 + 개별 부호어 결합 복호"라는 BT의 구조 자체가 한계임을 보여 준다. (iii) 쾨르너–마르톤 방식의 "복호기가 신드롬들의 합만 받아도 된다"는 성질이 바로 본 연구의 스위치(합만 출력)와 같은 구조다(6절).

## 6. 본 연구와의 연결 — 군 합 CEO

설정: X ~ N(0,σ_X²), Yₖ = X + Nₖ, 작업자 k는 Qₖ = fₖ(Yₖⁿ, W) ∈ G (유한 아벨 군)를 보내고, 스위치는 Z = ⊕ₖQₖ만 내보내며, 복호기는 X̂ⁿ = g(Z, W). R_up = 작업자당 메시지 크기, R_down = log|G| (블록당 1/n).

1. **BT에서 개별 부호어가 필요한 단계** [판단]. 1단계(양자화)와 2단계(비닝)는 작업자 안에서 끝나므로 군 합 구조와 충돌하지 않는다. 충돌하는 것은 **3단계 결합 전형성 복호**: 복호기는 곱 상자 B₁(m₁)×…×B_K(m_K)를 탐색하므로 **개별 상자 번호 mₖ**가 필요하고, 상호 채움 분석(3.4 ④)도 후보 튜플마다 개별 부호어 uₖⁿ(lₖ)의 결합 전형성을 본다. 스위치 뒤에는 z = ⊕mₖ뿐이고 같은 z를 주는 튜플이 |G|^{K−1}개 있다.
2. **합만 보는 BT의 대가 (가설)** [판단, 미검증 스케치]. 상자 번호를 G에 무작위 배정하고 "합이 z인 모든 튜플"을 후보로 결합 전형성 복호를 하면, 틀린 지표 집합 S마다 후보 수가 |G|^{|S|−1}배 늘어 패킹 조건이 대략 R_down > I(Y(S);U(S)|U(Sᶜ))가 되고, S = [1:K]에서 R_down ≳ I(Y^K;U^K) = 제약 없는 CEO 합 율이 된다. Qₖ ∈ G이므로 작업자당 상행 율도 합 율 전체가 되어, 비닝 이득이 K배 상행 비용으로 바뀐다. 이 계산은 이 노트에서 엄밀히 하지 않았다.
3. **포함 관계** [재구성]. 군 합 부호가 있으면 복호기가 (Q₁,…,Q_K)를 받아 Z를 직접 계산할 수 있으므로 같은 왜곡의 CEO 부호가 된다(공유 난수 W는 평균 왜곡 ≤ D인 실현값 w를 고정해 제거). 따라서 (R_up,…,R_up) ∈ ℛ_CEO(D), 특히 K·R_up ≥ R_sum(D) (3.7.5). **군 합 영역 ⊆ 제약 없는 CEO 영역.**
4. **역정리에서 새 논증이 필요한 정확한 단계** [판단]. 3.7.4 1단계를 Z로 쓰면 nR_down ≥ H(Z|W) = I(Xⁿ;Z|W) + H(Z|Xⁿ,W). CEO에서는 둘째 항 자리에 I(Yⁿ(J);M(J)|Xⁿ) = Σⱼ n rⱼ (조건부 독립인 **개별** 메시지들의 엔트로피 합)가 오고, 이것이 rⱼ들을 EPI 제약(J = ∅)과 묶는다. Z는 하나의 합이라 이 분해가 없다. **H(Z|Xⁿ,W) ≥ 0으로 버리면** R_down ≥ ½log(σ_X²/D)만 남는다(중앙 부호기 하계보다도 약함).
5. 쉽게 얻는 것 [재구성]: Qₖ는 (Xⁿ,W)가 주어지면 독립이므로 연습 7로 H(Z|Xⁿ,W) ≥ maxₖ H(Qₖ|Xⁿ,W) ≥ n maxₖ rₖ, rₖ := (1/n)I(Yₖⁿ;Qₖ|Xⁿ,W). J = ∅ 제약(3.7.4 2단계)은 Z가 (Qₖ)의 함수이므로 그대로 성립. 대칭 잡음이면 max rₖ의 최소는 대칭 r이므로 R_down ≥ ½log(σ_X²/D) + r_sym(D) = ½log(σ_X²/D) + (R_sum − ½log(σ_X²/D))/K.
6. **간극** [판단]. CEO는 "Σₖ rₖ", 위 하계는 "maxₖ rₖ" — K배 차이. 조건부 독립인 K개 군 원소의 합의 엔트로피가 K에 따라 얼마나 커지는지(가우시안 연속판에서는 ½log K 정도라는 것이 기존 노트의 보조정리 L 가설)를 rₖ와 왜곡에 연결하는 부등식이 새로 필요한 논증이다. EPI의 이산 군 판(합 엔트로피 하계)이 후보 도구다.
7. **반대 방향의 가능성** [판단]. 5.10의 쾨르너–마르톤처럼 군 구조 부호는 합을 계산하는 데 BT보다 나을 수 있다. 그러나 CEO의 목표는 합 ⊕Yₖ가 아니라 원격 소스 X이므로, 군 합 제약이 2번의 K배 손실을 얼마나 되찾을 수 있는지는 열린 질문이다.
