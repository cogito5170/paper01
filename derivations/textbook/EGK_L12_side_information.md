### 이 장의 질문 한 줄 요약

부호기는 Xⁿ만 보고 2^{nR}개 중 하나의 지표 M을 보낸다. 복호기는 M과 상관된 부가 정보(side information) Yⁿ을 갖고 X̂ⁿ을 만든다. 평균 왜곡 E d(Xⁿ,X̂ⁿ) = (1/n)Σ E d(Xᵢ,X̂ᵢ) ≤ D를 지키는 최소 율 R은 얼마인가? 답은 "Y를 누가, 언제 보느냐"에 따라 다르다:

| 상황 | 율-왜곡 함수 | 슬라이드 |
|---|---|---|
| 부가 정보 없음 | R(D) = min_{p(x̂\|x)} I(X;X̂) | 12–3 |
| 부호기만 Y | R_{SI-E}(D) = R(D) | 12–3 |
| 부호기·복호기 모두 Y | R_{SI-ED}(D) = min_{p(x̂\|x,y)} I(X;X̂\|Y) | 12–3 |
| 복호기만, 인과적 Y^i | R_{CSI-D}(D) = min I(X;U), x̂(u,y) | 12–6 |
| 복호기만, 비인과적 Yⁿ | R_{SI-D}(D) = min [I(X;U) − I(Y;U)] = min I(X;U\|Y) | 12–17 |

그리고 항상 R_{SI-ED} ≤ R_{SI-D} ≤ R_{CSI-D} ≤ R (12–17). [원문]

## 2. 준비 (필요한 보조정리)

12장의 모든 달성 증명은 다음 네 도구로 끝난다: 전형 평균 보조정리, 조건부 전형성 보조정리, 덮개 보조정리, 채움 보조정리. (마르코프 보조정리(Markov lemma)는 12장에서는 필요 없다. 이유는 5절 "헷갈리는 점" 3번.)

### 2.1 전형열(typical sequence) [원문, Lecture 2, 슬라이드 2–14~2–18, PDF 35–36쪽]

**유형(type, 경험 분포).** π(x|xⁿ) = |{i : xᵢ = x}|/n. 쌍이면 π(x,y|xⁿ,yⁿ) = |{i : (xᵢ,yᵢ) = (x,y)}|/n.

**ε-전형 집합.** X ~ p(x), ε ∈ (0,1):
$$\mathcal T_\epsilon^{(n)}(X) = \{x^n : |\pi(x|x^n) - p(x)| \le \epsilon\, p(x)\ \ \forall x\}.$$
쌍·삼중은 (X,Y)를 하나의 큰 확률변수로 보고 같은 정의를 쓴다. 허용 오차가 **상대적**(ε·p(x))이라는 점이 중요하다: p(x)=0인 기호는 전형열에 한 번도 나타나지 않는다. (이 성질이 정리 2의 무손실 증명에 쓰인다.)

**전형 평균 보조정리(typical average lemma).** xⁿ ∈ T_ε^{(n)}(X)이면 모든 g ≥ 0에 대해
$$(1-\epsilon)\,E g(X) \le \frac1n\sum_{i=1}^n g(x_i) \le (1+\epsilon)\,E g(X).$$
증명: (1/n)Σᵢ g(xᵢ) = Σₓ π(x|xⁿ) g(x)이므로 |(1/n)Σ g(xᵢ) − E g(X)| = |Σₓ (π(x|xⁿ) − p(x)) g(x)| ≤ Σₓ ε p(x) g(x) = ε E g(X). (g ≥ 0이 필요한 곳은 마지막 등식.) ∎

**전형열의 성질.** p(xⁿ) = Πp(xᵢ)이고 xⁿ ∈ T_ε^{(n)}이면
1. 2^{−n(H(X)+δ(ε))} ≤ p(xⁿ) ≤ 2^{−n(H(X)−δ(ε))}, δ(ε) = εH(X). [증명: g(x) = −log p(x)에 전형 평균 보조정리.]
2. |T_ε^{(n)}| ≤ 2^{n(H(X)+δ(ε))}. [1의 하계를 집합 위에서 합하면 1 이상이 될 수 없으므로.]
3. 큰 수의 법칙(LLN)으로 P{Xⁿ ∈ T_ε^{(n)}} → 1. [각 x마다 π(x|Xⁿ) → p(x) 확률 수렴, 유한 개 x에 합집합 한계.]
4. n이 크면 |T_ε^{(n)}| ≥ (1−ε)2^{n(H(X)−δ(ε))}. [3과 1의 상계.]
쌍에 대해서도 같은 방식으로 p(xⁿ|yⁿ) ≐ 2^{−nH(X|Y)}, |T_ε^{(n)}(Y|xⁿ)| ≤ 2^{n(H(Y|X)+δ(ε))} (T_ε^{(n)}(Y|xⁿ) = {yⁿ : (xⁿ,yⁿ) ∈ T_ε^{(n)}}). 또 (xⁿ,yⁿ,zⁿ) ∈ T_ε^{(n)}(X,Y,Z)이면 각 부분쌍도 같은 ε로 전형이다(주변화하면 상대 오차가 유지됨).

**함수의 전형성 [재구성].** X̂ = x̂(U,Y)이고 (uⁿ,xⁿ,yⁿ) ∈ T_ε^{(n)}(U,X,Y), x̂ᵢ = x̂(uᵢ,yᵢ)이면 (xⁿ,x̂ⁿ) ∈ T_ε^{(n)}(X,X̂). 이유: π(x,x̂) = Σ_{(u,y): x̂(u,y)=x̂} π(u,x,y)이고 p(x,x̂)도 같은 합이므로 |π(x,x̂) − p(x,x̂)| ≤ Σ ε p(u,x,y) = ε p(x,x̂). 왜곡 계산에서는 더 간단히 g(u,x,y) = d(x, x̂(u,y))에 전형 평균 보조정리를 직접 쓴다.

### 2.2 조건부 전형성 보조정리(conditional typicality lemma) [원문, 슬라이드 2–19, PDF 37쪽]

**진술.** xⁿ ∈ T_{ε'}^{(n)}(X)이고 Yⁿ ~ Πᵢ p_{Y|X}(yᵢ|xᵢ)이면, 모든 ε > ε'에 대해 P{(xⁿ,Yⁿ) ∈ T_ε^{(n)}(X,Y)} → 1.

**증명 [재구성: 노트는 "LLN으로"만 씀].** 쌍 (x,y)를 하나 고정. xᵢ = x인 위치의 수는 n_x = nπ(x|xⁿ) ≥ n(1−ε')p(x) → ∞ (p(x)>0일 때; p(x)=0이면 n_x = 0이라 해당 항이 자명히 맞음). 그 위치들에서 Yᵢ는 i.i.d. p(y|x)이므로 LLN으로, 임의의 δ>0에 대해 그 위치 중 Yᵢ = y인 비율 f는 확률 → 1로 |f − p(y|x)| ≤ δ p(y|x). 그러면
π(x,y) = π(x)·f ∈ [(1−ε')(1−δ), (1+ε')(1+δ)]·p(x)p(y|x).
(1+ε')(1+δ) ≤ 1+ε, (1−ε')(1−δ) ≥ 1−ε가 되도록 δ를 고를 수 있는 것은 **ε > ε'일 때뿐**이다. 이것이 "ε > ε'이 결정적인 이유"(노트의 "why?")다: xⁿ 자체가 이미 ε' 만큼 어긋나 있을 수 있으므로, Yⁿ의 무작위 요동을 흡수할 여유 ε − ε' > 0이 있어야 한다. 유한 개 (x,y)에 합집합 한계. ∎

### 2.3 결합 전형성 보조정리(joint typicality lemma) [원문, 슬라이드 2–24~2–25, PDF 39쪽]

**진술(필요한 형태).** (U,X,Y) ~ p. 
- (상계) 어떤 고정된 (xⁿ,yⁿ)에 대해서든, Ũⁿ ~ Π p_U(ũᵢ)가 독립으로 뽑히면 P{(Ũⁿ,yⁿ) ∈ T_ε^{(n)}(U,Y)} ≤ 2^{−n(I(U;Y)−δ(ε))}.
- (하계) (xⁿ) ∈ T_{ε'}^{(n)}이고 ε' < ε, n이 크면 P{(Ũⁿ,xⁿ) ∈ T_ε^{(n)}(U,X)} ≥ 2^{−n(I(U;X)+δ(ε))}.

**증명.** 상계: yⁿ이 전형이 아니면 확률 0. 전형이면
P = Σ_{ũⁿ ∈ T_ε(U|yⁿ)} p(ũⁿ) ≤ |T_ε(U|yⁿ)| · 2^{−n(H(U)−δ)} ≤ 2^{n(H(U|Y)+δ)}·2^{−n(H(U)−δ)} = 2^{−n(I(U;Y)−2δ)}.
(두 번째: 각 ũⁿ ∈ T_ε(U|yⁿ)는 U-전형이므로 성질 1. 세 번째: 조건부 전형 집합 크기 상계.)
하계: 같은 식에서 p(ũⁿ) ≥ 2^{−n(H(U)+δ)}와 |T_ε(U|xⁿ)| ≥ (1−ε)2^{n(H(U|X)−δ)} (조건부 전형성 보조정리의 따름정리, 슬라이드 2–19)을 쓴다. ∎

직관: 독립으로 뽑은 Ũⁿ이 우연히 yⁿ과 "짝처럼 보일" 확률은 2^{−nI(U;Y)}이다. 상호정보량은 "우연한 일치가 얼마나 드문가"의 지수다.

### 2.4 덮개 보조정리(covering lemma) [원문, 슬라이드 3–51~3–53, PDF 70–71쪽]

**직관.** 소스 xⁿ 하나를 "덮으려면"(그와 결합 전형인 부호어를 적어도 하나 가지려면) 무작위 부호어가 몇 개 필요한가? 각 부호어가 성공할 확률이 ≈ 2^{−nI(X;U)}이므로 2^{nI(X;U)}개보다 조금 많으면 된다. 이것이 벡터 양자화(vector quantization)의 정보이론적 핵심이다: "양자화 = 소스 근처의 부호어를 찾는 것".

**진술(U-조건 없는 형태, 12장에서 쓰는 것).** (X,U) ~ p(x)p(u|x). Xⁿ이 P{Xⁿ ∈ T_{ε'}^{(n)}} → 1을 만족하고, Uⁿ(l), l ∈ [1:2^{nR̃}),이 서로 독립이며 Xⁿ과 독립, 각각 Π p_U(uᵢ)를 따르면 ε' 에 대해 δ(ε') → 0이 존재하여
$$P\{(U^n(l), X^n) \notin \mathcal T_{\epsilon'}^{(n)}\ \ \forall l\} \to 0 \quad \text{if } \tilde R > I(X;U) + \delta(\epsilon').$$
(노트의 일반형은 조건 변수 U를 하나 더 두고 X̂ⁿ(m) ~ Π p(x̂|uᵢ), 조건 R > I(X;X̂|U) + δ(ε).)

**증명 [원문].** E₀ = {Xⁿ ∉ T}라 두면 P(E) ≤ P(E₀) + P(E ∩ E₀ᶜ), 첫 항 → 0. 둘째 항: 전형 xⁿ을 고정하면 부호어들이 독립이므로
P{모든 l에서 실패 | Xⁿ = xⁿ} = Π_l P{(Uⁿ(l),xⁿ) ∉ T} ≤ (1 − 2^{−n(I(X;U)+δ)})^{2^{nR̃}} ≤ exp(−2^{nR̃}·2^{−n(I(X;U)+δ)}) = exp(−2^{n(R̃−I(X;U)−δ)}).
(첫 부등호: 결합 전형성 보조정리 하계. 둘째: (1−x)^k ≤ e^{−kx}.) R̃ > I(X;U)+δ면 이중 지수로 → 0. 전형 xⁿ에 대해 평균해도 → 0. ∎

(엄밀히는 노트의 결합 전형성 하계가 "같은 ε"로 쓰여 있다. 위에서는 xⁿ ∈ T_{ε''}, ε'' < ε'로 두고 하계를 적용한다고 읽으면 된다. [재구성])

### 2.5 채움 보조정리(packing lemma) [원문, 슬라이드 3–18~3–20, PDF 53–54쪽]

**직관.** 덮개와 반대 방향. 받은 열 ỹⁿ과 **무관하게** 만들어진 부호어가 |A| ≤ 2^{nR}개 있을 때, 그중 하나라도 우연히 ỹⁿ과 결합 전형일 확률은 ≤ 2^{nR}·2^{−nI(U;Y)}이다. 그러니 R < I(U;Y)이면 "가짜 일치"가 없다. 채널 부호화에서 "잘못된 부호어로 복호할 확률"이 이것이다.

**진술(12장에서 쓰는 형태).** Ỹⁿ은 임의 분포, Uⁿ(l), l ∈ A, |A| ≤ 2^{nR}, 각각 Π p_U(uᵢ)를 따르고 각 Uⁿ(l)은 Ỹⁿ과 독립(서로 간에는 임의 의존 허용)이면
$$P\{(U^n(l),\tilde Y^n) \in \mathcal T_\epsilon^{(n)} \text{ for some } l\in A\} \to 0 \quad\text{if } R < I(U;Y) - \delta(\epsilon).$$

**증명 [원문].** 합집합 한계로 ≤ Σ_{l∈A} P{(Uⁿ(l),Ỹⁿ) ∈ T}. 각 항: Ỹⁿ = ỹⁿ에 조건을 걸면(독립성 때문에 Uⁿ(l)의 분포는 그대로) 결합 전형성 상계로 ≤ 2^{−n(I(U;Y)−δ)}; ỹⁿ에 대해 평균해도 같다. 따라서 ≤ 2^{nR}·2^{−n(I(U;Y)−δ)} → 0. ∎

주의: 쌍별(pairwise) 독립만 쓰므로 "부호어들끼리 독립"은 필요 없다. 필요한 것은 **각 부호어와 Ỹⁿ 사이의 독립**뿐이다. 와이너–지브 증명의 보조정리 1이 하는 일이 바로 이 독립을 확보하는 것이다(3.4.4절).

### 2.6 점대점 손실 소스 부호화 정리 [원문, 슬라이드 3–40, 3–43~3–48, PDF 64–68쪽]

**진술.** R(D) = min_{p(x̂|x): E d(X,X̂) ≤ D} I(X;X̂). R(D)는 D에 대해 비증가·볼록·(따라서 내부에서) 연속.

**달성 요약.** p(x̂|x)를 R(D/(1+ε))를 달성하도록 고정. 2^{nR}개 x̂ⁿ(m) ~ Π p_{X̂}를 독립 생성. 부호기: (xⁿ,x̂ⁿ(m)) ∈ T_ε인 m을 보냄(여러 개면 가장 작은 것, 없으면 1). 복호기: x̂ⁿ(m) 출력. 덮개 보조정리로 R > I(X;X̂)+δ(ε)이면 실패 확률 P(E) → 0. 실패가 없으면 전형 평균 보조정리로 왜곡 ≤ (1+ε)E d(X,X̂) ≤ D, 실패하면 ≤ d_max. 따라서
$$\limsup E d(X^n,\hat X^n) \le \limsup [d_{\max} P(E) + (1+\epsilon) E d(X,\hat X)] \le D.$$
부호책에 대해 평균한 왜곡이 ≤ D이므로 그런 부호책이 하나는 존재. ε → 0과 R(D)의 연속성으로 R > R(D)이면 달성.

**역 요약.** nR ≥ H(M) ≥ H(X̂ⁿ) ≥ I(Xⁿ;X̂ⁿ) = Σ I(Xᵢ;X̂ⁿ|X^{i−1}) = Σ I(Xᵢ;X̂ⁿ,X^{i−1}) ≥ Σ I(Xᵢ;X̂ᵢ) ≥ Σ R(E d(Xᵢ,X̂ᵢ)) ≥ nR((1/n)Σ E d(Xᵢ,X̂ᵢ)) (볼록성+옌센), 비증가성으로 R ≥ R(D).

12장의 역 증명은 모두 이 틀을 따른다. 바뀌는 것은 "어떤 보조 변수 Uᵢ를 정의하느냐"뿐이다.

**무손실은 손실의 특수 경우 [원문, 슬라이드 3–49~3–50, PDF 69쪽].** X̂ = X, 해밍 왜곡, D = 0으로 두면 R(0) = H(X). 달성: 시험 채널 p(x̂|x) = 1{x̂ = x}이면 (xⁿ,x̂ⁿ) ∈ T_ε ⇒ xⁿ = x̂ⁿ (p(x,x̂) = 0인 쌍은 전형열에 나타날 수 없으므로). 덮개 보조정리로 블록 오류 → 0. 역: 블록 오류 → 0은 기호 평균 오류 → 0보다 강한 조건이다. 12장 정리 2가 정확히 이 방법을 쓴다.

### 2.7 연속 소스로의 확장 [원문, 슬라이드 3–55~3–57, PDF 71–72쪽]

가우시안처럼 연속 알파벳이면 위 이산 증명을 그대로 쓸 수 없다. 노트의 방법: (X,X̂)를 미세하게 양자화한 [X],[X̂]에 대해 이산 정리를 적용하고, 자료 처리 부등식 I([X];[X̂]) ≤ I(X;X̂)와 양자화 오차 → 0을 써서 원래 소스로 옮긴다. 12장의 가우시안 와이너–지브 예는 같은 방법으로 (X,Y,U)를 양자화하면 된다고 노트는 명시하지 않는다(그냥 "it is easy to show"). 이 확장이 성립한다는 것은 [재구성](표준 논증), 세부 검증은 이 노트에서 하지 않았다.

### 2.8 보조 변수 기수 한계와 볼록성 [원문 언급 + 재구성]

노트는 |𝒰| ≤ |𝒳|+1을 "Appendix C의 기법"(카라테오도리형 지지 보조정리)으로 미룬다. 이 노트에서는 증명하지 않는다 [원문: 언급만]. 역 증명에서 Uᵢ의 알파벳이 커도 상관없는 이유: 기수 한계는 "min을 유한 |𝒰|에서 해도 값이 같다"는 주장이므로, 역 증명은 기수 제한 없는 최소값에 대해 하고 나중에 한계를 붙이면 된다.

볼록성 [재구성]: (U₁,x̂₁)이 왜곡 D₁, (U₂,x̂₂)가 D₂를 달성할 때, (X,Y)와 독립인 시분할 변수 T ∈ {1,2}, P{T=1} = θ로 U = (T, U_T), x̂(u,y) = x̂_T(u_T,y)라 두면 U − X − Y가 유지되고 I(X;U) = I(X;T) + I(X;U_T|T) = 0 + θI(X;U₁) + (1−θ)I(X;U₂), I(Y;U)도 같은 식, 왜곡은 θD₁ + (1−θ)D₂. 따라서 R_{CSI-D}, R_{SI-D} 모두 볼록. 비증가성은 정의(제약 집합이 D에 대해 커짐)에서 바로. 볼록 함수는 열린 구간에서 연속이고, 비증가 볼록이면 오른쪽 끝점 처리만 남는데 노트는 "continuous"라고만 쓴다(12–6, 12–17) [원문].

## 3. 강의 본문 — 절 순서대로

### 3.1 문제 설정 [원문, 슬라이드 12–2, PDF 293쪽]

(X,Y)는 2-DMS, d(x,x̂) ≥ 0은 유계 왜곡 척도(d_max = max d < ∞). 부호기는 X의 설명(description)을 보내고, 복호기는 부가 정보 Y를 갖고 X를 왜곡 D로 복원한다(노트의 예: X = 모나리자, Y = 레오나르도 다 빈치). 부가 정보의 가용성 시나리오는 여러 가지다:
- 부호기에, 복호기에, 또는 양쪽에;
- 그대로(fully) 또는 부호화된 형태로;
- 복호기에서 비인과적(전체 Yⁿ을 보고 복원) 또는 인과적(i번째 복원 때 Y^i = (Y₁,…,Yᵢ)만 사용).
각 시나리오마다 (2^{nR},n) 부호, 달성 가능성, 율-왜곡 함수를 점대점 경우처럼 정의한다: R이 달성 가능 ⇔ lim sup_{n} E d(Xⁿ,X̂ⁿ) ≤ D인 (2^{nR},n) 부호열이 존재; 율-왜곡 함수 = 달성 가능한 R의 하한(infimum).

### 3.2 단순한 특수 경우 [원문, 슬라이드 12–3, PDF 294쪽]

**(a) 부가 정보 없음.** R(D) = min I(X;X̂) (2.6절). 무손실이면 R* = H(X).

**(b) 부호기만 Y를 앎: R_{SI-E}(D) = R(D).** 노트는 "(why?)"로 남긴다.
- 직관: 복호기가 Y를 모르면 X̂ⁿ은 M만의 함수다. 부호기가 Y를 알아도 "복호기가 만들 수 있는 X̂ⁿ의 목록"은 바뀌지 않는다. 그리고 왜곡은 X와 X̂만으로 정해지므로 Y는 쓸모가 없다.
- 증명 [재구성]: 달성은 Y를 무시하면 되므로 자명. 역: M = m(Xⁿ,Yⁿ), X̂ⁿ = x̂ⁿ(M).
 nR ≥ H(M) ≥ H(X̂ⁿ) ≥ I(X̂ⁿ;Xⁿ)
 이후는 2.6절의 역 증명과 글자 그대로 같다(그 증명은 X̂ⁿ이 어떻게 만들어졌는지 쓰지 않고 "X̂ⁿ의 엔트로피 ≤ nR"만 썼다). 무손실도 R* = H(X).

**(c) 양쪽 모두 Y: R_{SI-ED}(D) = min_{p(x̂|x,y): E d ≤ D} I(X;X̂|Y).** 노트는 "easy to show". [재구성]
- 직관: Y = y가 양쪽에 알려져 있으면 "Y=y인 시점들"만 모아서 조건부 분포 p(x|y)에 맞춘 율-왜곡 부호를 따로 쓸 수 있다. 율은 평균하여 Σ_y p(y)R_{X|Y=y}(D_y).
- 달성: 덮개 보조정리의 조건부형(2.4절 끝 괄호: 조건 변수 = Y)을 쓴다. yⁿ을 보고 2^{nR}개 x̂ⁿ(m) ~ Π p(x̂ᵢ|yᵢ)를 생성(부호책이 yⁿ에 의존해도 양쪽이 yⁿ을 알므로 괜찮다). (yⁿ,xⁿ,x̂ⁿ(m)) ∈ T_ε인 m을 보냄. 덮개 보조정리(P{(Yⁿ,Xⁿ) ∈ T} → 1 만족)로 R > I(X;X̂|Y) + δ(ε)이면 실패 → 0, 이후 왜곡 분석은 2.6절과 같음.
- 역: M = m(Xⁿ,Yⁿ), X̂ⁿ = x̂ⁿ(M,Yⁿ).
 nR ≥ H(M) ≥ H(M|Yⁿ) ≥ I(Xⁿ;M|Yⁿ) = Σᵢ I(Xᵢ;M|Yⁿ,X^{i−1})
 = Σᵢ I(Xᵢ; M, X^{i−1}, Y^{i−1}, Y_{i+1}^n | Yᵢ) (아래 3.4.5절 (a)와 같은 이유: (Xᵢ,Yᵢ)는 (X^{i−1},Y^{i−1},Y_{i+1}^n)과 독립)
 ≥ Σᵢ I(Xᵢ;X̂ᵢ|Yᵢ) (X̂ᵢ는 (M,Yⁿ)의 함수 — 자료 처리)
 ≥ Σᵢ R_{SI-ED}(E d(Xᵢ,X̂ᵢ)) ≥ nR_{SI-ED}((1/n)Σ E d(Xᵢ,X̂ᵢ)) (볼록성).
- 무손실이면 R*_{SI-ED} = H(X|Y) (조건부 무손실 부호화 정리) [원문].
- 보조 변수 형태 [재구성]: min_{p(u|x,y), x̂(u,y)} I(X;U|Y) (12–17)와 위 식은 같다. U = X̂로 두면 위 식 ≥ 보조형. 반대로 X̂ = x̂(U,Y)이면 자료 처리로 I(X;U|Y) ≥ I(X;X̂|Y).

### 3.3 복호기 측 인과적 부가 정보 [원문, 슬라이드 12–4~12–15, PDF 294–300쪽]

#### 3.3.1 왜 이 경우가 "가장 흥미로운가" [원문, 12–4]

복호기만 Y를 알 때, 율-왜곡 함수는 인과/비인과에 따라 다르다. 노트는 이것이 7장 "부호기만 상태(state)를 아는 채널"의 쌍대(dual)라고 말한다: R_{CSI-D} ↔ C_{CSI-E}, R_{SI-D} ↔ C_{SI-E}.

#### 3.3.2 정의 [원문, 12–5]

(2^{nR},n) 부호 = 부호기 m(xⁿ) ∈ [1:2^{nR}) + 복호기 x̂ᵢ(m, y^i), i ∈ [1:n]. 즉 i번째 복원은 지금까지 본 y₁,…,yᵢ만 쓸 수 있다. R_{CSI-D}(D) = lim sup E d ≤ D를 만족하는 율의 하한.

#### 3.3.3 정리 1 [원문, 12–6; Weissman–El Gamal 2006]

**직관.** 복호기는 미래의 Y를 못 보므로 Yⁿ 전체를 써서 "통(bin) 안에서 정답 부호어를 고르는" 일을 할 수 없다. 남는 방법은 하나: 보통의 양자화(덮개)로 Uⁿ을 그대로 보내고, 복원할 때 기호별로 x̂ᵢ = x̂(Uᵢ,Yᵢ)처럼 **현재의** Yᵢ를 섞어 쓰는 것. 그러면 율은 I(X;U) (비닝 이득 없음), 그러나 왜곡은 Y 덕분에 줄어든다.

**진술.**
$$R_{\text{CSI-D}}(D) = \min_{p(u|x),\ \hat x(u,y):\ E d(X,\hat X)\le D} I(X;U),\qquad |\mathcal U| \le |\mathcal X|+1.$$
여기서 결합 분포는 p(x,y)p(u|x) (U − X − Y 마르코프), X̂ = x̂(U,Y). R_{CSI-D}는 비증가·볼록·연속(2.8절).

#### 3.3.4 예: 이중 대칭 이진 소스(DSBS) [원문 진술, 12–7~12–8, PDF 296쪽; 증명은 재구성]

DSBS(p): X ~ Bern(1/2), Y = X ⊕ Z, Z ~ Bern(p) 독립, p ∈ [0,1/2], 해밍 왜곡. H(·)는 이진 엔트로피.
- 부가 정보 없음: R(D) = 1 − H(D) (0 ≤ D ≤ 1/2).
- 양쪽: R_{SI-ED}(D) = H(p) − H(D) (0 ≤ D ≤ p), D > p면 0.
- 복호기만, 인과적:
$$R_{\text{CSI-D}}(D) = \begin{cases} 1 - H(D), & 0 \le D \le D_c \\ (p - D) H'(D_c), & D_c < D \le p\end{cases}$$
 D_c는 (1 − H(D_c))/(p − D_c) = H'(D_c)의 해, H'(D) = log((1−D)/D). 즉 1 − H(D)의 그래프에 점 (p,0)에서 그은 접선. 의미: "Y를 무시하는 율-왜곡 부호"와 "율 0, X̂ = Y (왜곡 p)"를 시분할하는 것이 최적이다. 왜곡이 충분히 작으면 Y를 그냥 무시하는 것이 최적이다.

**달성 [재구성].** (i) U = X̂ = X ⊕ Bern(D), x̂(u,y) = u: 율 1 − H(D), 왜곡 D. (ii) U = 상수, x̂(u,y) = y: 율 0, 왜곡 P{X ≠ Y} = p. 볼록성(2.8절의 시분할)으로 두 점을 잇는 선분 위 모든 점 달성. 1−H(D)는 볼록이므로, (p,0)과 곡선의 점 (D_c, 1−H(D_c))을 잇는 선분 중 가장 낮은 것이 접선이다.

**역(하계) [재구성; 노트에 없음].** 임의의 p(u|x), x̂(u,y)를 잡는다. u를 두 부류로 나눈다:
- A = {u : x̂(u,0) = x̂(u,1)} (복원이 y를 안 씀), Aᶜ = 나머지.
- u ∈ Aᶜ: x̂(u,y) = y 또는 1⊕y. U − X − Y이므로 Z는 (X,U)와 독립이고 E[d|U=u] = P{Z=1} = p 또는 1−p ≥ p.
- u ∈ A: X̂ = c_u 상수, d_u ≜ P{X ≠ c_u | U=u}. X가 이진이므로 H(X|U=u) = H(d_u).
- θ = P{U ∈ A}, β = E[d_U | U ∈ A]. 왜곡: D ≥ E d = θβ + (1−θ)·(≥ p) ≥ θβ + (1−θ)p.
- 율: I(X;U) = 1 − Σ_u p(u)H(X|U=u) ≥ 1 − Σ_{u∈A} p(u)H(d_u) − (1−θ)·1 = Σ_{u∈A} p(u)(1 − H(d_u)) ≥ θ(1 − H(β)) (1−H 볼록 → 옌센).
- 따라서 I(X;U) ≥ min{θ(1−H(β)) : θβ + (1−θ)p ≤ D}, 이것이 정확히 "곡선 1−H와 점 (p,0)의 볼록 포(convex hull)"의 아래 경계 = 위 식. ∎

**수치 (p = 1/4) [재구성: 직접 계산].** H(1/4) = 0.8113, D_c ≈ 0.0804, 접선 기울기 H'(D_c) ≈ 3.517.

#### 3.3.5 정리 1 달성 증명 [원문, 12–9~12–10, PDF 297쪽]

**단계 0 (고정).** 원하는 왜곡 D, ε > ε' > 0. p(u|x), x̂(u,y)를 R_{CSI-D}(D/(1+ε))를 달성하도록 고정. 즉 E d(X, x̂(U,Y)) ≤ D/(1+ε), I(X;U) = R_{CSI-D}(D/(1+ε)).

**단계 1 (부호책).** 2^{nR}개 uⁿ(m) ~ Π p_U(uᵢ)를 서로 독립으로 생성. (p_U(u) = Σₓ p(x)p(u|x).) 부호책은 양쪽에 공개.

**단계 2 (부호기, 결합 전형성 부호화).** xⁿ을 받으면 (uⁿ(m),xⁿ) ∈ T_{ε'}^{(n)}인 m을 찾는다. 여러 개면 가장 작은 것, 없으면 m = 1. m을 보낸다.

**단계 3 (복호기).** x̂ᵢ = x̂(uᵢ(m), yᵢ). — i번째 기호에 yᵢ만 쓰므로 **인과적 제약을 지킨다**. 이것이 이 부호가 인과 경우에 허용되는 이유다.

**단계 4 (오류 사건).** M = 선택된 지표.
- E₁ = {모든 m에 대해 (Uⁿ(m),Xⁿ) ∉ T_{ε'}} (양자화 실패),
- E₂ = {(Uⁿ(M),Yⁿ) ∉ T_ε} (선택한 부호어가 Yⁿ과 어울리지 않음). 엄밀히는 삼중 (Uⁿ(M),Xⁿ,Yⁿ) ∉ T_ε로 읽는다 [재구성: 아래 단계 5가 삼중 전형성을 써야 하므로].
- P(E) = P(E₁) + P(E₁ᶜ ∩ E₂).

**단계 5 (각 항).**
1. 덮개 보조정리(2.4절): Xⁿ은 i.i.d.라 전형일 확률 → 1, 부호어들은 서로·Xⁿ과 독립. R > I(X;U) + δ(ε')이면 P(E₁) → 0.
2. E₁ᶜ에서 (Uⁿ(M),Xⁿ) ∈ T_{ε'}. 이제 Yⁿ의 조건부 분포: M은 (부호책, Xⁿ)의 함수이고 부호책은 (Xⁿ,Yⁿ)과 독립이므로
 P{Yⁿ = yⁿ | Uⁿ(M) = uⁿ, Xⁿ = xⁿ} = Πᵢ p_{Y|X}(yᵢ|xᵢ) = Πᵢ p_{Y|U,X}(yᵢ|uᵢ,xᵢ)
 (둘째 등호는 단일 문자 마르코프 U − X − Y). 즉 Yⁿ은 (uⁿ,xⁿ)이 주어졌을 때 "올바른" 조건부 분포를 따른다. (U,X)를 하나의 변수로 보고 조건부 전형성 보조정리(2.2절, ε > ε')를 쓰면 P{(uⁿ,xⁿ,Yⁿ) ∈ T_ε} → 1. 따라서 P(E₁ᶜ ∩ E₂) → 0.

**단계 6 (왜곡).** 오류가 없으면 (Uⁿ(M),Xⁿ,Yⁿ) ∈ T_ε. g(u,x,y) = d(x, x̂(u,y))에 전형 평균 보조정리:
(1/n)Σ d(Xᵢ,X̂ᵢ) ≤ (1+ε) E d(X,X̂) ≤ D. 오류면 ≤ d_max. 부호책과 (Xⁿ,Yⁿ)에 대해 평균하면
$$\limsup_{n} E d(X^n,\hat X^n) \le \limsup_n [d_{\max}P(E) + (1+\epsilon)E d(X,\hat X)P(E^c)] \le D,$$
조건은 R > I(X;U) + δ(ε') = R_{CSI-D}(D/(1+ε)) + δ(ε').

**단계 7 (마무리).** 평균이 ≤ D이면 그런 부호책이 존재한다. ε → 0 (ε' < ε이므로 ε' → 0도)과 R_{CSI-D}의 연속성으로, 모든 R > R_{CSI-D}(D)가 달성 가능. ∎

#### 3.3.6 정리 1 역 증명 [원문, 12–11~12–12, PDF 298쪽]

**핵심: Uᵢ를 무엇으로 두나.** 복원 X̂ᵢ = x̂ᵢ(M,Y^i) = x̂ᵢ((M,Y^{i−1}), Yᵢ). 그러므로 Uᵢ ≜ (M, Y^{i−1})로 두면 X̂ᵢ는 (Uᵢ,Yᵢ)의 함수다.

**Uᵢ − Xᵢ − Yᵢ의 확인 [재구성: 노트는 "Note that" 한 줄].** Uᵢ는 (Xⁿ, Y^{i−1})의 함수다. 소스가 i.i.d.이므로 Xᵢ가 주어지면 Yᵢ는 (X_{j≠i}, Y^{i−1})과 독립이다. 따라서 Yᵢ는 Xᵢ가 주어지면 Uᵢ와 독립.

**사슬.**
$$
\begin{aligned}
nR &\ge H(M) \ge I(X^n;M) &&\text{(M의 값은 } 2^{nR}\text{개; } I\le H)\\
&= \sum_{i=1}^n I(X_i; M \mid X^{i-1}) &&\text{(연쇄 법칙)}\\
&= \sum_{i=1}^n I(X_i; M, X^{i-1}) &&(X_i \perp X^{i-1}\text{이므로 } I(X_i;X^{i-1})=0)\\
&\overset{(a)}{=} \sum_{i=1}^n I(X_i; M, X^{i-1}, Y^{i-1}) \\
&\ge \sum_{i=1}^n I(X_i; U_i) &&(X^{i-1}\text{ 제거: 상호정보량은 변수를 빼면 줄어듦})\\
&\ge \sum_{i=1}^n R_{\text{CSI-D}}(E d(X_i,\hat X_i)) &&(U_i - X_i - Y_i,\ \hat X_i = \hat x_i(U_i,Y_i)\text{이므로 } (U_i,\hat x_i)\text{는 정의의 후보})\\
&\overset{(b)}{\ge} n R_{\text{CSI-D}}\Big(\tfrac1n\sum E d(X_i,\hat X_i)\Big) &&\text{(볼록성 + 옌센)}
\end{aligned}
$$
**(a)의 근거 [원문: "Xᵢ → (M,X^{i−1}) → Y^{i−1} 마르코프"; 풀이는 재구성].** I(Xᵢ; Y^{i−1} | M, X^{i−1}) = 0을 보이면 된다. X^{i−1}이 주어지면 Y^{i−1}은 X_i^n과 독립이다(Y^{i−1}은 X^{i−1}과 자기 잡음에만 의존). M = m(Xⁿ)이므로 X^{i−1}이 주어지면 (Xᵢ, M)은 X_i^n의 함수. 따라서 I(Xᵢ, M; Y^{i−1} | X^{i−1}) = 0이고, 연쇄 법칙으로 I(Xᵢ;Y^{i−1}|M,X^{i−1}) ≤ I(Xᵢ,M;Y^{i−1}|X^{i−1}) = 0.

**마무리.** lim sup (1/n)Σ E d(Xᵢ,X̂ᵢ) ≤ D이고 R_{CSI-D}는 비증가이므로 R ≥ R_{CSI-D}(D) (연속성으로 lim sup 처리). 기수 한계는 Appendix C [원문: 언급만]. ∎

주의(자주 빠뜨림): 후보 (Uᵢ, x̂ᵢ)에서 복원 함수 x̂ᵢ가 i마다 다른 것은 문제없다. R_{CSI-D}(·)는 각 i에 대해 "그 i의 분포"로 평가된 최소값의 하계이기 때문이다.

#### 3.3.7 인과적 부가 정보와 무손실 부호화: 정리 2 [원문, 12–13~12–15, PDF 299–300쪽]

**설정.** P{Xⁿ ≠ X̂ⁿ} → 0을 요구. 최적 율 R*_{CSI-D}. 자명하게 H(X|Y) ≤ R*_{CSI-D} ≤ H(X). 노트의 예:
1. X = Y: R* = H(X|Y) = 0.
2. X, Y 독립: R* = H(X|Y) = H(X).
3. X = (Y,Z), Y와 Z 독립: R* = H(X|Y) = H(Z). [재구성: Z만 무손실로 보내고 복호기가 i번째에 (Yᵢ, Zᵢ)를 결합. 인과성 위반 없음.]

**정리 2.** R*_{CSI-D} = min_{p(u|x)} I(X;U), 제약 H(X|U,Y) = 0, |𝒰| ≤ |𝒳|+1.

**증명 개요.** R*_{CSI-D} = R_{CSI-D}(0) (해밍 왜곡, X̂ = X)임을 보인다 — 2.6절 "무손실은 손실의 특수 경우"와 같은 방법.

**역 [원문].** 블록 오류 P{Xⁿ ≠ X̂ⁿ} → 0이면 기호 평균 오류 (1/n)Σ P{Xᵢ ≠ X̂ᵢ} ≤ P{Xⁿ ≠ X̂ⁿ} → 0 (각 P{Xᵢ ≠ X̂ᵢ} ≤ P{Xⁿ ≠ X̂ⁿ}). 즉 해밍 왜곡 E d → 0이므로 정리 1의 역으로 R* ≥ R_{CSI-D}(0) (연속성). 그리고 E d(X, x̂(U,Y)) = 0 ⇔ p(x,y,u) > 0인 모든 곳에서 x̂(u,y) = x ⇔ p(x|u,y) = 1 ⇔ H(X|U,Y) = 0.

**달성 [원문].** 정리 1의 달성 부호를 H(X|U,Y) = 0인 p(u|x)와 x̂(u,y) (= (u,y)로부터 유일하게 정해지는 x)로 쓴다. (xⁿ,yⁿ,uⁿ(l)) ∈ T_ε이면, 전형성의 상대 오차 정의(2.1절) 때문에 모든 i에서 p(xᵢ,yᵢ,uᵢ(l)) > 0이고, 따라서 x̂(uᵢ(l),yᵢ) = xᵢ가 모든 i에서 성립. 즉 "전형이면 오류 0":
P{X̂ⁿ = Xⁿ | 어떤 l에 대해 (Uⁿ(l),Xⁿ,Yⁿ) ∈ T_ε} = 1.
정리 1의 증명에서 이 사건의 여사건 확률 → 0 (R > I(X;U) + δ)이므로 P{X̂ⁿ ≠ Xⁿ} → 0. ∎

**따름: p(x,y) > 0 (모든 x,y)이면 R*_{CSI-D} = H(X)** [원문, 12–15]. 제약이 H(X|U) = 0으로 바뀐다는 것을 귀류법으로 보인다.
- H(X|U) > 0이라 하자. 그러면 어떤 u (p(u)>0)와 x에 대해 0 < p(x|u) < 1, 따라서 다른 x' ≠ x도 0 < p(x'|u).
- 임의의 y를 잡는다. p(u,x,y) = p(u)p(x|u)p(y|x) > 0, p(u,x',y) > 0 (p(y|x), p(y|x') > 0이므로; 여기서 마르코프 U−X−Y 사용).
- x̂(u,y)는 하나의 값이므로 d(x,x̂(u,y)) = 0과 d(x',x̂(u,y)) = 0이 동시에 될 수 없다 ⇒ E d > 0, 모순.
- 따라서 H(X|U) = 0이고 I(X;U) = H(X). ∎

**해석 [원문].** 슬레피안–울프(Slepian–Wolf)는 비인과 Yⁿ으로 H(X|Y)까지 내려간다. 인과성은 상관을 이용하는 능력을 심하게 제한한다. 이유 [재구성]: 슬레피안–울프 복호는 "통 안의 여러 후보 xⁿ 중 Yⁿ 전체와 결합 전형인 것"을 고르는 **블록 전체 판정**이다. Y^i만으로는 이 판정을 i번째 시점에 내릴 수 없다.

### 3.4 복호기 측 비인과적 부가 정보: 와이너–지브 [원문, 슬라이드 12–16~12–28, PDF 300–306쪽]

#### 3.4.1 설정과 질문 [원문, 12–16]

부호 = 부호기 m(xⁿ) + 복호기 x̂ⁿ(m, yⁿ). 무손실이면 슬레피안–울프로 R*_{SI-D} = H(X|Y) = R*_{SI-ED} — 부호기가 Y를 몰라도 손해가 없다. 질문: 손실 경우에도 R_{SI-D}(D) = R_{SI-ED}(D)인가?

#### 3.4.2 와이너–지브 정리 [원문, 12–17]

**직관 (세 단계 그림).**
1. 양자화: 정리 1처럼 xⁿ을 Uⁿ으로 덮는다. 부호어가 약 2^{nI(X;U)}개 필요.
2. 그런데 복호기의 Yⁿ도 Uⁿ과 상관되어 있다(U − X − Y이므로 I(Y;U) > 0). 복호기는 Yⁿ을 보고 "Uⁿ의 후보"를 2^{nI(X;U)}개에서 약 2^{nI(X;U)}/2^{nI(Y;U)}개 수준으로 좁힐 수 있다.
3. 그러므로 Uⁿ의 지표 전체를 보낼 필요 없이 **통 번호**만 보낸다. 부호어 2^{nI(X;U)}개를 2^{nR}개 통에 나누면 통마다 2^{n(I(X;U)−R)}개가 들어 있다. 복호기는 통 안에서 Yⁿ과 결합 전형인 것을 고른다. 통 안 가짜 후보가 Yⁿ과 우연히 맞을 확률은 채움 보조정리로 2^{n(I(X;U)−R)}·2^{−nI(Y;U)}, 이것이 → 0이려면 R > I(X;U) − I(Y;U).
"덮개 율 − 채움 율"이 답이다(12–29).

**진술.**
$$R_{\text{SI-D}}(D) = \min\big(I(X;U) - I(Y;U)\big) = \min I(X;U|Y),$$
최소는 p(u|x)와 x̂: 𝒴×𝒰 → 𝒳̂, |𝒰| ≤ |𝒳|+1, E d(X,X̂) ≤ D 위에서. 비증가·볼록·연속.

**두 식이 같은 이유 [재구성].** U − X − Y이면 I(Y;U|X) = 0. 연쇄 법칙으로 I(X,Y;U) = I(Y;U) + I(X;U|Y) = I(X;U) + I(Y;U|X) = I(X;U). 따라서 I(X;U|Y) = I(X;U) − I(Y;U).

**순서 관계 [원문, 12–17].** R_{SI-ED} ≤ R_{SI-D} ≤ R_{CSI-D} ≤ R.
- R_{SI-D} ≤ R_{CSI-D}: 같은 후보 집합에서 I(X;U) − I(Y;U) ≤ I(X;U).
- R_{CSI-D} ≤ R: U = X̂, x̂(u,y) = u.
- R_{SI-ED} ≤ R_{SI-D}: R_{SI-ED} = min_{p(u|x,y),x̂(u,y)} I(X;U|Y) (3.2(c))이고, 와이너–지브는 같은 목적함수를 **p(u|x)로 제한된** 더 작은 집합에서 최소화한다. 차이는 정확히 "U가 Y에 의존할 수 있느냐"다(12–17).

#### 3.4.3 2차 가우시안 예 — 끝까지 계산 [원문 진술, 12–18~12–19, PDF 301–302쪽; 계산은 재구성]

**설정.** X ~ N(0,P), Y = X + Z, Z ~ N(0,N) 독립, d(x,x̂) = (x−x̂)².

**"일반성을 잃지 않고"인 이유 [재구성, 노트의 "(why?)"].** (X,Y)가 평균 0인 임의의 결합 가우시안이고 Cov(X,Y) = c ≠ 0이면, Y를 X에 회귀시켜 Y = bX + W, b = c/P, W ⊥ X (가우시안이므로 비상관 = 독립). Y' = Y/b = X + W/b는 Y의 가역 함수이므로 복호기에게 같은 정보다. c = 0이면 Y는 쓸모없고 R(D) 문제다.

**양쪽이 Y를 알 때.** P' ≜ Var(X|Y) = PN/(P+N). (가우시안 사후 분산: 1/P' = 1/P + 1/N.) 2.6절의 가우시안 R(D)를 조건부로 적용하면
$$R_{\text{SI-ED}}(D) = \mathsf R(P'/D) = \tfrac12\log\frac{P'}{D}\quad (0 < D \le P'),\qquad 0\ (D \ge P').$$
하계 증명 [재구성]: I(X;X̂|Y) = h(X|Y) − h(X|X̂,Y) ≥ ½log(2πeP') − h(X−X̂|Y) ≥ ½log(2πeP') − h(X−X̂) ≥ ½log(2πeP') − ½log(2πeD). (조건 줄이면 엔트로피 증가; 분산 고정 시 가우시안이 미분 엔트로피 최대; E(X−X̂)² ≤ D.)

**와이너–지브 달성 (보조 변수 선택).** D ≥ P'이면 X̂ = E[X|Y]로 율 0. 0 < D < P'이면
$$U = X + V,\quad V \sim N(0,Q)\ \text{독립},\quad Q = \frac{P'D}{P'-D}.$$
U − X − Y는 V가 (X,Z)와 독립이므로 성립.

**율 계산.**
I(X;U|Y) = h(U|Y) − h(U|X,Y) = ½log(2πe·Var(U|Y)) − ½log(2πe·Q).
Var(U|Y) = Var(X|Y) + Q = P' + Q (V ⊥ (X,Y)). 따라서
$$I(X;U|Y) = \tfrac12\log\frac{P'+Q}{Q}.$$
Q = P'D/(P'−D)를 넣으면 P' + Q = P'[(P'−D) + D]/(P'−D) = P'²/(P'−D), 그러므로 (P'+Q)/Q = [P'²/(P'−D)]·[(P'−D)/(P'D)] = P'/D. 즉 I(X;U|Y) = ½log(P'/D) = R_{SI-ED}(D). ✓

**왜곡 계산.** X̂ = E[X|U,Y] (최소 평균제곱오차(MMSE) 추정). 가우시안에서는 정보(=역분산)가 더해진다:
$$\frac{1}{\operatorname{Var}(X|U,Y)} = \frac1P + \frac1N + \frac1Q = \frac{1}{P'} + \frac1Q.$$
Q의 정의를 다시 쓰면 1/Q = (P'−D)/(P'D) = 1/D − 1/P', 따라서 1/Var(X|U,Y) = 1/D, 즉 E(X−X̂)² = Var(X|U,Y) = D. ✓ (Q를 고르는 공식은 이 식 "1/P' + 1/Q = 1/D"를 거꾸로 푼 것이다 — 외울 필요가 없다.)
추정기 자체: X̂ = (U/Q + Y/N)/(1/P + 1/N + 1/Q) = D·(U/Q + Y/N).

**역.** R_{SI-D} ≥ R_{SI-ED} (3.4.2절)이므로 R_{SI-D}(D) = ½log(P'/D). **가우시안에서는 부호기가 Y를 몰라도 손해가 0이다** [원문, 12–19]. (연속 알파벳 확장은 2.7절 [재구성].)

**숫자 예 [재구성].** P = 1, N = 1 → P' = 0.5.
- D = 0.1: R_{SI-D} = ½log₂(0.5/0.1) = ½log₂5 ≈ 1.161 비트/기호. 부가 정보 없으면 R(D) = ½log₂(1/0.1) ≈ 1.661. 절약 = ½log₂(P/P') = 0.5 비트 (D와 무관).
 - Q = 0.5·0.1/0.4 = 0.125.
 - 덮개 율 I(X;U) = ½log₂((P+Q)/Q) = ½log₂(1.125/0.125) = ½log₂9 ≈ 1.585.
 - 채움 율 I(Y;U) = ½log₂(Var U / Var(U|Y)) = ½log₂(1.125/0.625) = ½log₂1.8 ≈ 0.424.
 - 차이 1.585 − 0.424 = 1.161 ✓. 해석: 부호어 2^{1.585n}개를 2^{1.161n}개 통에 넣으면 통마다 2^{0.424n}개, 복호기는 Yⁿ으로 그 0.424n 비트를 "공짜로" 알아낸다.
 - 검산: 1/P + 1/N + 1/Q = 1 + 1 + 8 = 10 → Var(X|U,Y) = 0.1 = D ✓. 추정기 X̂ = 0.1(8U + Y) = 0.8U + 0.1Y.
- D = 0.25: R = ½log₂2 = 0.5 비트, Q = 0.125/0.25 = 0.5, 1 + 1 + 2 = 4 → 0.25 ✓.

#### 3.4.4 예: DSBS에서는 손해가 있다 [원문, 12–19~12–20, PDF 302쪽]

DSBS(p), 해밍 왜곡. g(D) = H(p∗D) − H(D), a∗b = a(1−b) + b(1−a).
$$R_{\text{SI-D}}(D) = \begin{cases} g(D), & 0\le D\le D_c' \\ (p-D)\,(-g'(D_c')), & D_c' < D \le p\end{cases}$$
D'_c는 g(D'_c)/(p − D'_c) = −g'(D'_c)의 해. 즉 g의 그래프에 (p,0)에서 그은 접선.

**노트 표기의 두 오류 [재구성: 그림과 대조해 확인].**
1. 노트(12–19)는 (p−D)g'(D'_c), g(D'_c)/(p−D'_c) = g'(D'_c)로 쓰는데, g는 감소함수라 g' < 0이다. 기울기의 부호를 맞추려면 −g'이어야 한다(인과 경우의 H'(D_c)는 1−H(D)의 도함수가 −H'이므로 부호가 맞다).
2. 노트는 "R_{SI-D}(D) < R_{SI-ED}(D) = H(p) − H(D) for all D ∈ (0,p)"라고 쓰지만, 같은 쪽의 그림(12–20)과 순서 관계 R_{SI-ED} ≤ R_{SI-D}에 따르면 **R_{SI-D}(D) > R_{SI-ED}(D)**가 옳다. 결론 문장("부호기에 부가 정보가 없는 데 대한 0이 아닌 비용")은 이 올바른 방향과 일치한다. PDF 302쪽 이미지에서 원문 자체의 오타임을 확인했다.

**값.** p = 1/4: D'_c ≈ 0.0880, 접선 기울기 −g'(D'_c) ≈ 2.741 [재구성: 직접 계산]. 3.3.4절 표의 R_{SI-D} 열 참조. 예: D = 0.1에서 R_{SI-ED} = 0.342 < R_{SI-D} = 0.411 < R_{CSI-D} = 0.528 < R = 0.531.

**달성 직관 [재구성].** U = X ⊕ Bern(D), x̂ = u: (Y,U)는 BSC(p∗D)로 연결되므로 I(X;U) − I(Y;U) = (1−H(D)) − (1−H(p∗D)) = g(D). 시분할로 (p,0)과 연결. 하계는 Wyner–Ziv 1976 원 논문의 논증(`derivations/classic/04_Wyner-Ziv1976.md` 5.1절)이 3.3.4절의 인과 경우 논증과 같은 구조다(A/Aᶜ 분할, z ∈ A에서 H(Y|z) − H(X|z) = g(d_z), g의 볼록성).

#### 3.4.5 달성의 개요 [원문, 12–21, PDF 303쪽]

결합 전형성 부호화로 xⁿ을 uⁿ으로 기술한다. Uⁿ이 Yⁿ과 상관되어 있으므로 비닝으로 율을 줄인다. 2^{nI(X;U)}개 uⁿ(l)을 2^{nR}개 통으로 나누고, xⁿ과 결합 전형인 uⁿ을 찾아 **그 통 번호**를 보낸다. 복호기는 통 B(m) 안에서 yⁿ과 결합 전형인 유일한 uⁿ(l)을 찾고 x̂ᵢ = x̂(uᵢ,yᵢ).

#### 3.4.6 달성 증명 단계별 [원문, 12–22~12–24, PDF 303–304쪽]

**단계 0.** ε > ε' > 0. p(u|x), x̂(u,y)를 R_{SI-D}(D/(1+ε))를 달성하도록 고정.

**단계 1 (부호책).** 2^{nR̃}개 uⁿ(l) ~ Π p_U(uᵢ), l ∈ [1:2^{nR̃}), 서로 독립. 지표를 같은 크기의 통으로 **결정적으로** 나눈다:
B(m) = [(m−1)2^{n(R̃−R)} + 1 : m·2^{n(R̃−R)}], m ∈ [1:2^{nR}).
(연속한 지표 묶음. 부호어 자체가 무작위이므로 통을 무작위로 만들 필요가 없다 — 3.4.8절.)

**단계 2 (부호기).** (xⁿ,uⁿ(l)) ∈ T_{ε'}인 l을 찾는다(여러 개면 가장 작은 것, 없으면 l = 1). l ∈ B(m)인 m을 보낸다. 율 = R.

**단계 3 (복호기).** B(m) 안에서 (uⁿ(l̂),yⁿ) ∈ T_ε인 **유일한** l̂을 찾는다. 있으면 x̂ᵢ = x̂(uᵢ(l̂),yᵢ), 없거나 여러 개면 임의의 x̂ⁿ.

**단계 4 (오류 사건).** (L,M) = 선택된 지표.
- E₁ = {모든 l에 대해 (Uⁿ(l),Xⁿ) ∉ T_{ε'}} — 양자화 실패,
- E₂ = {(Uⁿ(L),Yⁿ) ∉ T_ε} — 정답 부호어가 Yⁿ과 안 맞음 (삼중 전형성으로 읽음, 3.3.5절과 같이),
- E₃ = {어떤 l̃ ∈ B(M), l̃ ≠ L에 대해 (Uⁿ(l̃),Yⁿ) ∈ T_ε} — 통 안 가짜 후보.
오류가 없으면 복호기는 정확히 l̂ = L을 고른다. P(E) ≤ P(E₁) + P(E₁ᶜ ∩ E₂) + P(E₃).

**단계 5 (각 항).**
1. 덮개 보조정리: R̃ > I(X;U) + δ(ε')이면 P(E₁) → 0. (정리 1과 동일.)
2. 정리 1의 단계 5-2와 동일: E₁ᶜ에서 Yⁿ | {Uⁿ(L)=uⁿ, Xⁿ=xⁿ} ~ Π p_{Y|X}(yᵢ|xᵢ) = Π p_{Y|U,X}(yᵢ|uᵢ,xᵢ), ε > ε'이므로 조건부 전형성 보조정리로 P(E₁ᶜ ∩ E₂) → 0.
3. **E₃가 미묘한 부분.** 통 B(M) 안 다른 부호어들은 Yⁿ과 독립이 아니다: M은 L로 정해지고, L은 Xⁿ(따라서 Yⁿ과 상관됨)과 부호어들에 의존한다. 그래서 채움 보조정리를 바로 쓸 수 없다. 보조정리 1이 이것을 해결한다:
 $$P(E_3) \le P\{(U^n(\tilde l),Y^n)\in\mathcal T_\epsilon^{(n)} \text{ for some } \tilde l \in B(1)\}.$$
 오른쪽은 **조건 없는** 확률이고, 부호책 전체는 (Xⁿ,Yⁿ)과 독립으로 생성되었으므로 B(1)의 각 Uⁿ(l̃) ~ Π p_U이고 Yⁿ과 독립이다. |B(1)| = 2^{n(R̃−R)}이므로 채움 보조정리(2.5절)로 R̃ − R < I(Y;U) − δ(ε)이면 → 0. (보조정리 1의 증명은 3.8절.)
4. 종합: R̃ > I(X;U) + δ(ε')와 R̃ − R < I(Y;U) − δ(ε)를 동시에 만족하는 R̃이 있으려면
 $$R > I(X;U) - I(Y;U) + \delta(\epsilon) + \delta(\epsilon').$$

**단계 6 (왜곡).** 오류가 없으면 (Uⁿ(L),Xⁿ,Yⁿ) ∈ T_ε이고 복원은 정확히 x̂(Uᵢ(L),Yᵢ). 전형 평균 보조정리로
$$\limsup E d(X^n,\hat X^n) \le \limsup[d_{\max}P(E) + (1+\epsilon)E d(X,\hat X)P(E^c)] \le D,$$
조건은 R > R_{SI-D}(D/(1+ε)) + δ(ε) + δ(ε').

**단계 7.** 연속성과 ε → 0으로 R > R_{SI-D}(D)이면 달성. ∎

#### 3.4.7 역 증명 단계별 [원문, 12–26~12–27, PDF 305–306쪽]

**핵심: Uᵢ ≜ (M, Y^{i−1}, Y_{i+1}^n).** X̂ᵢ는 (M,Yⁿ)의 함수 = ((M,Y^{i−1},Y_{i+1}^n), Yᵢ)의 함수 = (Uᵢ,Yᵢ)의 함수. Uᵢ − Xᵢ − Yᵢ: Uᵢ는 (Xⁿ, Y_{j≠i})의 함수이고, Xᵢ가 주어지면 Yᵢ는 (X_{j≠i},Y_{j≠i})와 독립. 기수 한계 없이 먼저 증명.

$$
\begin{aligned}
nR &\ge H(M) \ge H(M|Y^n) &&\text{(조건은 엔트로피를 줄임)}\\
&= I(X^n;M|Y^n) &&(H(M|X^n,Y^n)=0:\ M=m(X^n))\\
&= \sum_{i=1}^n I(X_i;M \mid Y^n, X^{i-1}) &&\text{(연쇄 법칙)}\\
&\overset{(a)}{=} \sum_{i=1}^n I(X_i; M, Y^{i-1}, Y_{i+1}^n, X^{i-1} \mid Y_i)\\
&\ge \sum_{i=1}^n I(X_i; U_i \mid Y_i) &&(X^{i-1}\text{ 제거})\\
&\ge \sum_{i=1}^n R_{\text{SI-D}}(E d(X_i,\hat X_i)) &&(U_i - X_i - Y_i,\ \hat X_i = \hat x_i(U_i,Y_i))\\
&\ge nR_{\text{SI-D}}\Big(\tfrac1n\sum E d(X_i,\hat X_i)\Big) &&\text{(볼록성)}
\end{aligned}
$$
**(a)의 근거 [원문: "(Xᵢ,Yᵢ)는 (Y^{i−1},Y_{i+1}^n,X^{i−1})과 독립"; 풀이는 재구성].** 연쇄 법칙으로
I(Xᵢ; M, Y_{j≠i}, X^{i−1} | Yᵢ) = I(Xᵢ; Y_{j≠i}, X^{i−1} | Yᵢ) + I(Xᵢ; M | Yⁿ, X^{i−1}).
첫 항: (Xᵢ,Yᵢ) ⊥ (Y_{j≠i}, X^{i−1})이므로 I(Xᵢ; Y_{j≠i},X^{i−1}|Yᵢ) = 0. 따라서 두 식이 같다.

lim sup 평균 왜곡 ≤ D와 비증가성으로 R ≥ R_{SI-D}(D). 기수 한계는 Appendix C [원문: 언급만]. ∎

비교: 인과 경우 Uᵢ = (M,Y^{i−1}), 비인과 경우 Uᵢ = (M,Y^{i−1},Y_{i+1}^n). 복원이 볼 수 있는 Y가 늘어난 만큼 Uᵢ에 미래 Y가 들어간다. 대신 H(M) ≥ H(M|Yⁿ)로 Yⁿ을 조건에 넣어 I(X;U|Y)가 나온다.

#### 3.4.8 결정적 비닝과 쌍대성에 관한 주석 [원문, 12–25, PDF 304쪽]

- **결정적 비닝(deterministic binning).** 슬레피안–울프에서는 고정된(무작위 아닌) 소스 열 xⁿ들을 통에 넣으므로 통 배정 자체를 무작위로 해야 했다. 여기서는 통에 들어가는 것이 이미 무작위로 생성된 부호어이므로 연속 지표로 통을 나눠도 같은 효과가 난다.
- **슬레피안–울프는 와이너–지브의 특수 경우.** 정리 2와 같은 논법(U = X, 해밍 왜곡, D = 0; 전형이면 오류 0)으로 R_{SI-D}(0) = min I(X;U|Y) s.t. H(X|U,Y)=0 = H(X|Y) [재구성: 제약 H(X|U,Y) = 0을 만족하는 모든 U에 대해 I(X;U|Y) = H(X|Y) − H(X|U,Y) = H(X|Y)이므로 최소값은 H(X|Y)이고, U = X가 그 예다. 달성은 정리 2와 같이 "전형이면 x̂(uᵢ,yᵢ) = xᵢ"로 블록 오류 → 0, 역은 블록 오류 ≥ 기호 평균 오류]. 따라서 무작위 비닝은 둘 다 필요 없다.
- **비닝은 다중 부호화(multicoding)의 쌍대.** 다중 부호화(겔판트–핀스커, 마턴(Marton) 내부 한계)는 채널 부호화 기법이다: 메시지마다 여러 부호어를 만들어 율을 늘리고, 원하는 성질을 갖는 하나를 보낸다. 비닝은 소스 부호화 기법이다: 많은 지표를 적은 통 번호로 묶어 율을 줄이고, 통 번호를 보낸다.

#### 3.4.9 와이너–지브 대 겔판트–핀스커 [원문, 12–28~12–29, PDF 306쪽]

- 점대점 쌍대성: R(D) = min_{p(x̂|x)} I(X̂;X) ↔ C = max_{p(x)} I(X;Y). 주어진 소스 p(x) ↔ 주어진 채널 p(y|x); 최적화하는 재생 p(x̂|x) ↔ 입력 p(x); min ↔ max.
- 부가 정보 쌍대성: R_{CSI-D} = min I(X;U), R_{SI-D} = min(I(X;U) − I(Y;U)) ↔ C_{CSI-E} = max I(U;Y), C_{SI-E} = max(I(U;Y) − I(U;S)). (노트 12–28에 "R_{SI-E} = max(...)"로 찍혀 있으나 문맥상 C_{SI-E}의 오타 [재구성].)
- 가장 흥미로운 쌍대: R_{SI-D} = 덮개 율 I(U;X) − 채움 율 I(U;Y), C_{SI-E} = 채움 율 I(U;Y) − 덮개 율 I(U;S). 슬레피안–울프 ↔ 결정적 방송 채널도 같은 유형. 수학적으로 정밀한 쌍대는 아니지만(라그랑주 쌍대나 MAC–BC 쌍대와 달리) 부호화 기법의 통일된 이해를 준다.

### 3.5 부가 정보가 없을 수도 있는 경우 [원문, 슬라이드 12–30~12–33, PDF 307–309쪽]

**설정.** 하나의 지표 M을 두 복호기가 받는다. 복호기 1은 부가 정보 없이 왜곡 D₁(척도 d₁), 복호기 2는 Y를 갖고 왜곡 D₂(척도 d₂). 부호기는 "부가 정보가 있을지 없을지 모르는" 상황에 견고한 기술을 보내야 한다(7장의 복합 채널에 대한 방송 채널 접근과 비슷).

**직관.** 먼저 복호기 1이 쓸 거친 기술 X̂₁을 보통 율-왜곡 부호로 보낸다. 그 다음 양쪽이 X̂₁을 알게 되었으므로, 이를 "공통 부가 정보"로 삼아 복호기 2에게만 의미 있는 와이너–지브 정제(refinement)를 보낸다.

#### 3.5.1 복호기 2에 비인과적 부가 정보 [원문, 12–31~12–32; Heegard–Berger 1985, Kaspi 1994]

$$R_{\text{SI-D2}}(D_1,D_2) = \min\big(I(X;\hat X_1) + I(X;U \mid \hat X_1, Y)\big),$$
최소는 p(u,x̂₁|x)와 x̂₂(u,x̂₁,y), |𝒰| ≤ |𝒳||𝒳̂₁| + 2, E dⱼ(X,X̂ⱼ) ≤ Dⱼ 위에서. (결합 분포 p(x,y)p(u,x̂₁|x).)

**달성 [원문 개요 + 재구성 세부].** (i) 율 I(X;X̂₁)의 손실 소스 부호로 x̂₁ⁿ을 만든다(덮개 보조정리). (ii) 부호기 측 부가 정보 X̂₁, 복호기 측 부가 정보 (X̂₁,Y)로 와이너–지브 부호화: uⁿ 부호어를 x̂₁ⁿ에 조건부로 Π p(uᵢ|x̂₁ᵢ)로 생성, 덮개 율 I(X;U|X̂₁), 채움 율 I(Y;U|X̂₁). 필요한 율은
I(X;U|X̂₁) − I(Y;U|X̂₁) = I(X;U|X̂₁,Y).
[이 등식: (U,X̂₁) − X − Y이므로 I(Y;U|X,X̂₁) = 0, 따라서 I(X,Y;U|X̂₁) = I(X;U|X̂₁) = I(Y;U|X̂₁) + I(X;U|X̂₁,Y).]
복호기 2는 x̂₂ᵢ = x̂₂(uᵢ,x̂₁ᵢ,yᵢ).

**역 [원문].** Uᵢ ≜ (M, Y^{i−1}, Y_{i+1}^n, X^{i−1}).
$$
\begin{aligned}
nR &\ge H(M) = I(M;X^n,Y^n) &&(M\text{은 }X^n\text{의 함수라 } H(M|X^n,Y^n)=0)\\
&= I(M;X^n|Y^n) + I(M;Y^n)\\
&= \sum_i \big(I(X_i;M|Y^n,X^{i-1}) + I(Y_i;M|Y^{i-1})\big) &&\text{(각각 연쇄 법칙)}\\
&= \sum_i \big(I(X_i;M,X^{i-1},Y^{i-1},Y_{i+1}^n|Y_i) + I(Y_i;M,Y^{i-1})\big) &&\text{(독립성: } Y_i\perp Y^{i-1},\ \text{앞 3.4.7 (a))}\\
&\ge \sum_i \big(I(X_i;U_i,\hat X_{1i}|Y_i) + I(Y_i;\hat X_{1i})\big) &&(\hat X_{1i}\text{는 } M\text{의 함수})\\
&\ge \sum_i \big(I(X_i;U_i|\hat X_{1i},Y_i) + I(X_i;\hat X_{1i})\big).
\end{aligned}
$$
마지막 줄 [재구성]: I(Xᵢ;Uᵢ,X̂₁ᵢ|Yᵢ) = I(Xᵢ;X̂₁ᵢ|Yᵢ) + I(Xᵢ;Uᵢ|X̂₁ᵢ,Yᵢ), 그리고 I(Xᵢ;X̂₁ᵢ|Yᵢ) + I(Yᵢ;X̂₁ᵢ) = I(Xᵢ,Yᵢ;X̂₁ᵢ) ≥ I(Xᵢ;X̂₁ᵢ). 넷째 줄의 I(Xᵢ;M|Yⁿ,X^{i−1}) 등식에서 X^{i−1}을 Uᵢ에 포함시켰으므로 "변수 제거" 없이 등호가 남는다(Uᵢ가 X^{i−1}을 포함하는 이유). (Uᵢ,X̂₁ᵢ) − Xᵢ − Yᵢ가 성립하고 X̂₂ᵢ는 (M,Yⁿ)의 함수 = (Uᵢ,Yᵢ)의 함수. 이후는 와이너–지브와 같다(시분할 볼록성, 비증가성) [원문: "similar steps"].

#### 3.5.2 복호기 2에 인과적 부가 정보 [원문 진술, 12–32; 증명은 재구성]

R_{CSI-D2} = min I(X;U), 최소는 p(u|x), x̂₁(u), x̂₂(u,x̂₁,y), |𝒰| ≤ |𝒳|+2.
[재구성] 달성: 정리 1의 부호를 그대로 쓰되 복호기 1은 x̂₁ᵢ = x̂₁(uᵢ). 역: Uᵢ = (M,Y^{i−1}); X̂₁ᵢ는 M의 함수이므로 Uᵢ의 함수, X̂₂ᵢ = x̂₂ᵢ(M,Y^i)는 (Uᵢ,Yᵢ)의 함수. 사슬은 3.3.6절과 동일.

#### 3.5.3 부호기와 복호기 2 모두 부가 정보 [원문, 12–32~12–33; Kaspi 1994]

인과/비인과 무관하게
$$R_{\text{SI-ED2}} = \min_{p(\hat x_1,\hat x_2|x,y)} \big(I(X,Y;\hat X_1) + I(X;\hat X_2 \mid \hat X_1, Y)\big).$$
- 달성 [원문]: (Xⁿ,Yⁿ)에 대한 율 I(X,Y;X̂₁)의 손실 부호 → 그 다음 (X̂₁ⁿ,Yⁿ)을 부호기·복호기 2 공통 부가 정보로 하는 조건부 율-왜곡 부호(3.2(c)), 율 I(X;X̂₂|X̂₁,Y).
- 역 [원문]: 먼저 항등식 I(X,Y;X̂₁) + I(X;X̂₂|X̂₁,Y) = I(X̂₁;Y) + I(X;X̂₁,X̂₂|Y) [재구성 확인: 좌변 첫 항 = I(Y;X̂₁) + I(X;X̂₁|Y), 그리고 I(X;X̂₁|Y) + I(X;X̂₂|X̂₁,Y) = I(X;X̂₁,X̂₂|Y)]. 3.5.1의 앞 단계와 같이 (이제 M = m(Xⁿ,Yⁿ)이어도 H(M) = I(M;Xⁿ,Yⁿ)은 성립)
 nR ≥ Σ (I(Xᵢ;M,X^{i−1},Y^{i−1},Y_{i+1}^n|Yᵢ) + I(Yᵢ;M,Y^{i−1})) ≥ Σ (I(Xᵢ;X̂₁ᵢ,X̂₂ᵢ|Yᵢ) + I(Yᵢ;X̂₁ᵢ)).
 (X̂₁ᵢ, X̂₂ᵢ는 (M,Yⁿ)의 함수, X̂₁ᵢ는 M의 함수.) 나머지는 같다.
 [재구성 주의] 넷째 줄 등식 I(Xᵢ;M|Yⁿ,X^{i−1}) = I(Xᵢ;M,X^{i−1},Y_{j≠i}|Yᵢ)는 M과 무관하게 (Xᵢ,Yᵢ)와 나머지 좌표의 독립성만 쓰므로 M이 Yⁿ에 의존해도 성립한다.

### 3.6 핵심 새 아이디어와 기법 [원문, 12–34, PDF 309쪽]

- p(x,y) > 0 (모든 x,y)이면 복호기의 인과적 부가 정보는 무손실 부호화 율을 줄이지 못한다.
- 결정적 비닝.
- 슬레피안–울프는 와이너–지브의 특수 경우.

### 3.8 부록: 보조정리 1의 증명 [원문, 12–36~12–37, PDF 310–311쪽]

**목표.** P(E₃) ≤ P{어떤 l̃ ∈ B(1)에 대해 (Uⁿ(l̃),Yⁿ) ∈ T_ε}.

**단계 1: M = m 조건부 부등식.** 
P{∃ l̃ ∈ B(m), l̃ ≠ L : (Uⁿ(l̃),Yⁿ) ∈ T | M = m} ≤ P{∃ l̃ ∈ B(1) : (Uⁿ(l̃),Yⁿ) ∈ T | M = m}.
- m = 1이면 자명(왼쪽 사건이 오른쪽 사건에 포함).
- m ≠ 1이면
$$
\begin{aligned}
&P\{\exists \tilde l\in B(m),\tilde l\ne L: \cdot \mid M=m\} = \sum_{l\in B(m)} p(l|m)\,P\{\exists \tilde l\in B(m),\tilde l\ne l:\cdot \mid L=l, M=m\}\\
&\overset{(a)}{=} \sum_{l\in B(m)} p(l|m)\,P\{\exists \tilde l\in B(m),\tilde l\ne l:\cdot \mid L=l\}\\
&\overset{(b)}{=} \sum_{l\in B(m)} p(l|m)\,P\{\exists \tilde l\in [1:2^{n(\tilde R-R)}-1]:\cdot \mid L=l\}\\
&\le \sum_{l\in B(m)} p(l|m)\,P\{\exists \tilde l\in B(1):\cdot \mid L=l\}\\
&\overset{(c)}{=} \sum_{l\in B(m)} p(l|m)\,P\{\exists \tilde l\in B(1):\cdot \mid L=l, M=m\} = P\{\exists\tilde l\in B(1):\cdot\mid M=m\}.
\end{aligned}
$$
 (a),(c): M은 L의 함수이므로 {L=l} ⊂ {M=m}이고 조건 M=m을 더하거나 빼도 같다. (b): L = l이 주어지면, l이 아닌 부호어 2^{n(R̃−R)} − 1개의 어떤 모음이든 (Yⁿ과의 결합) 분포가 같다. 부등호: B(1)은 l을 포함하지 않는(m ≠ 1) 2^{n(R̃−R)}개 지표이므로 크기 2^{n(R̃−R)}−1 모음을 포함하는 더 큰 사건.

**단계 2.** m에 대해 평균: P(E₃) = Σ_m p(m) P{… | M=m} ≤ Σ_m p(m) P{∃ l̃ ∈ B(1) … | M=m} = P{∃ l̃ ∈ B(1) : (Uⁿ(l̃),Yⁿ) ∈ T}. ∎

**(b)에 대한 주의 [재구성/미확인].** (b)의 "같은 분포" 주장은 부호기가 후보 중 **가장 작은 지표**를 고를 때 엄밀하지 않아 보인다. L = l이면 l보다 작은 지표의 부호어는 "xⁿ과 결합 전형이 아님"이라는 조건이 붙고, l보다 큰 지표의 부호어는 조건이 없어서 두 부류의 분포가 다르다. 표준적인 보완: 부호기가 결합 전형인 후보 중 **균등하게 무작위로** 하나를 고르게 하면, 사건 {L = l}이 l 이외 지표들의 순열에 대해 대칭이 되어 (b)가 성립한다. 율과 왜곡 분석은 그대로다. 출판된 교과서(2011)가 이 점을 어떻게 처리했는지는 이 노트에서 확인하지 않았다 [미확인]. 어느 쪽이든 결론 P(E₃) → 0은 바뀌지 않는다.

**왜 이 보조정리가 필요한가.** 마지막 확률은 조건 없는 사건이고, 부호책은 (Xⁿ,Yⁿ)과 독립으로 생성되었으므로 B(1)의 부호어들은 i.i.d. Π p_U이고 Yⁿ과 독립이다. 이렇게 "선택에 의해 생긴 의존성"을 지우는 것이 요점이다. 그러면 채움 보조정리(2.5절)를 그대로 쓸 수 있다.

## 4. 손으로 해 볼 연습문제

**문제 1 (가우시안 와이너–지브 수치).** P = 4, N = 1, D = 0.2.
(a) P', R_{SI-D}(D), R(D)를 구하라. (b) Q와 덮개 율 I(X;U), 채움 율 I(Y;U)를 구하고 차이가 (a)와 같은지 확인하라. (c) MMSE 추정기 X̂ = αU + βY의 계수를 구하라.
- 답: (a) P' = 4/5 = 0.8, R_{SI-D} = ½log₂(0.8/0.2) = 1 비트, R(D) = ½log₂20 ≈ 2.161 비트. (b) Q = 0.8·0.2/0.6 = 4/15 ≈ 0.2667. I(X;U) = ½log₂((4 + 4/15)/(4/15)) = ½log₂16 = 2. I(Y;U) = ½log₂((P+Q)/(P'+Q)) = ½log₂((64/15)/(16/15)) = ½log₂4 = 1. 차이 1 ✓. (c) 1/Var = 1/4 + 1 + 15/4 = 5 → D = 0.2 ✓. α = D/Q = 0.2·15/4 = 0.75, β = D/N = 0.2.

**문제 2 (부호기만의 부가 정보).** R_{SI-E}(D) = R(D)의 역을 처음부터 쓰라. 특히 "M이 Yⁿ에 의존해도 nR ≥ H(X̂ⁿ)"인 이유와, 어디에서 I(Xᵢ;X̂ⁿ|X^{i−1}) = I(Xᵢ;X̂ⁿ,X^{i−1})를 쓰는지 밝혀라.
- 힌트: X̂ⁿ = x̂ⁿ(M)이므로 H(X̂ⁿ) ≤ H(M) ≤ nR. I(X̂ⁿ;Xⁿ) ≤ H(X̂ⁿ). 둘째 등식은 Xᵢ ⊥ X^{i−1}에서만 나온다(Y는 어디에도 등장하지 않는다).

**문제 3 (인과 역 증명의 Uᵢ).** 인과 경우에 Uᵢ = (M, Y^{i−1}, Y_{i+1}^n)을 쓰면 무엇이 깨지는가? 반대로 비인과 경우에 Uᵢ = (M,Y^{i−1})을 쓰면 무엇이 깨지는가?
- 답: 인과 경우 사슬 nR ≥ I(Xⁿ;M) = Σ I(Xᵢ;M,X^{i−1},Y^{i−1})에서 Y_{i+1}^n을 추가하면 등식 (a)가 깨진다. Xᵢ와 Y_{i+1}^n은 M을 통해 의존할 수 있어서 I(Xᵢ;Y_{i+1}^n|M,X^{i−1}) ≠ 0일 수 있다. 그래서 하계가 성립하지 않는다. 비인과 경우 (M,Y^{i−1})만으로는 X̂ᵢ = x̂ᵢ(M,Yⁿ)이 (Uᵢ,Yᵢ)의 함수가 아니어서 R_{SI-D}의 후보가 되지 못한다.

**문제 4 (덮개 율 계산).** 덮개 보조정리에서 R̃ = I(X;U) − η (η > 0)이면 실패 확률이 → 1임을 보여라(전형 xⁿ에 대해, 기대 "적중 수" 상계로).
- 힌트: 적중 수 K = Σ_l 1{(Uⁿ(l),xⁿ) ∈ T}. 결합 전형성 상계(2.3절)로 E K ≤ 2^{nR̃}·2^{−n(I(X;U)−δ)} = 2^{−n(η−δ)} → 0 (δ < η). 마르코프 부등식으로 P{K ≥ 1} ≤ E K → 0.

**문제 5 (DSBS 와이너–지브 점).** p = 1/4, U = X ⊕ Bern(D), x̂(u,y) = u일 때 I(X;U) − I(Y;U) = H(p∗D) − H(D)임을 유도하고, D = 0.05에서 값을 계산하라. 같은 D에서 R_{SI-ED}와 비교하라.
- 답: U = X ⊕ W, W ~ Bern(D)이고 Y = X ⊕ Z이므로 U = Y ⊕ Z ⊕ W, Z ⊕ W ~ Bern(p∗D)이며 Y와 독립. X, Y, U 모두 균등이므로 I(X;U) = 1 − H(D), I(Y;U) = 1 − H(p∗D). p∗D = 0.25·0.95 + 0.05·0.75 = 0.275. H(0.275) ≈ 0.8485, H(0.05) ≈ 0.2864, 차이 ≈ 0.562. R_{SI-ED} = 0.8113 − 0.2864 ≈ 0.525 < 0.562 (D = 0.05 < D'_c이므로 이 값이 곧 R_{SI-D}이다; 3.3.4절 표).

**문제 6 (보조정리 1이 왜 필요한가).** 와이너–지브 증명에서 "통 B(M)의 다른 부호어는 Yⁿ과 독립"이라고 바로 말할 수 없는 이유를 구체적인 의존 경로로 적어라. 또한 정리 1(인과)의 증명에는 왜 E₃ 같은 사건이 없는가?
- 답: M은 L의 함수, L은 Xⁿ과 부호어 전체의 함수, Xⁿ은 Yⁿ과 상관 ⇒ M = m이라는 조건은 Yⁿ과 B(m) 부호어들 사이에 의존을 만든다. 예를 들어 "B(m)의 어떤 부호어가 xⁿ과 전형이었다"는 정보가 들어온다. 정리 1에서는 지표 전체를 보내므로 복호기가 부호어를 고를 필요가 없고, 따라서 가짜 후보 사건이 없다.

## 5. 자주 헷갈리는 점

1. **"I(X;U) − I(Y;U)"와 "I(X;U|Y)"는 마르코프 U − X − Y 아래에서만 같다.** 양쪽 부가 정보 R_{SI-ED}에서는 U가 Y에 의존할 수 있으므로 I(X;U|Y)만 맞는 식이다.
2. **복원 함수는 x̂(U,Y)이지 x̂(U)가 아니다.** 와이너–지브의 이득은 비닝(율 감소)과 복원 시 Y 결합(왜곡 감소) 두 곳에서 온다. 인과 경우는 후자만 남는다.
3. **12장 달성에는 마르코프 보조정리가 필요 없다.** E₂ 분석에서 Yⁿ | (Uⁿ(L),Xⁿ)는 정확히 Π p(yᵢ|xᵢ)이다(부호책 ⊥ 소스). 이러면 조건부 전형성 보조정리로 충분하다. 마르코프 보조정리는 13장(분산 손실 부호화)처럼 "다른 부호기의 선택 부호어"가 조건에 들어가 조건부 분포가 곱 꼴이 아닐 때 필요하다. (`derivations/classic/04_Wyner-Ziv1976.md` 4.6절은 같은 단계를 마르코프 보조정리로 쓰는데, 틀린 것은 아니지만 필요 이상으로 강한 도구다.)
4. **ε' < ε의 순서.** 부호기는 ε'로 판정하고 복호기는 더 느슨한 ε로 판정한다. 반대로 하면 조건부 전형성 보조정리를 쓸 수 없다(2.2절).
5. **덮개 조건은 R̃(부호어 수)에, 채움 조건은 R̃ − R(통 크기)에 걸린다.** 보내는 율 R은 둘의 차이로만 등장한다. "R > I(X;U)"를 요구하는 것이 아니다.
6. **가우시안에서 손해 0은 예외다.** DSBS에서는 R_{SI-D} > R_{SI-ED}이다. 노트 12–19의 부등호 "<"는 오타다(3.4.4절).
7. **D = 0에서 인과 율 = H(X)는 p(x,y) > 0 조건이 있을 때만이다.** 예 3(X = (Y,Z))처럼 결합 분포에 0이 있으면 인과적 부가 정보도 도움이 된다.
8. **역 증명의 Uᵢ는 "실제 부호에서 꺼낸" 변수다.** 단일 문자 식의 최소값 정의에 맞는지(마르코프 사슬, 복원 함수 꼴) 매번 확인해야 하고, 확인할 것은 그 두 가지뿐이다.
9. **결정적 비닝이 가능한 이유는 부호어가 이미 무작위이기 때문이다.** 슬레피안–울프처럼 고정된 xⁿ을 통에 넣을 때는 통 배정이 무작위여야 한다.

## 6. 본 연구와의 연결 (군 합 CEO) [판단]

설정: X ~ N(0,σ_X²), 작업자 k가 Y_k = X + N_k를 보고 유한 아벨 군 G의 원소 Q_k를 보낸다. 스위치는 Z = ⊕_k Q_k만 내보내고, 복호기는 Z(와 공유 난수 W)로 X를 추정한다. R_up = R_down = log|G|.
- **불가능해지는 단계 [판단].** 와이너–지브 복호의 핵심은 3.4.6절 단계 3, 즉 "통 B(m) 안에서 부가 정보와 결합 전형인 **개별** 부호어 uⁿ(l̂)을 고르는 것"이다. 이를 위해서는 각 작업자의 통 번호 m_k가 따로 보여야 한다. 그런데 Z = ⊕Q_k는 (m₁,…,m_K)를 군 합으로 뭉개므로 개별 m_k를 복원할 수 없다. 공동 전형성 복호(Berger–Tung형 순차/동시 복호)도 개별 지표 목록을 전제하므로 그대로는 쓸 수 없다.
- **부가 정보의 부재 [판단].** 복호기에는 Yⁿ 같은 별도 부가 정보가 없다. 다른 작업자의 기여가 서로에게 "부가 정보" 역할을 해야 하는데, 합만 보이면 각 기여를 분리해 꺼낼 수 없다.
- **살아남는 것 1: 부분군 잉여류 비닝 [판단].** 격자 와이너–지브(Zamir–Shamai–Erez; `23_Zamir-Feder1992.md`의 디더 양자화)에서 통 = 거친 격자 Λ_c에 대한 미세 격자 Λ_f의 잉여류(coset)이고, 통 번호 = Q_{Λ_f}(·) mod Λ_c이다. 이 사상은 **군 준동형**이므로 Σ(통 번호) = (Σ 양자화값) mod Λ_c가 된다. 즉 군 합 Z는 "개별 통 번호"는 잃어도 "합의 통 번호"는 정확히 준다. 합 Σ_k Q_{Λ_f}(Y_k) 자체가 X의 좋은 추정량이므로, 합 영역에서의 잉여류 비닝은 그대로 작동한다(Körner–Marton·계산 후 전달(compute-and-forward)과 같은 원리).
- **살아남는 것 2: 율 계산의 골격 [판단].** "덮개 율 − 채움 율" 회계는 남는다. 다만 채움 율은 개별 I(Y;U)가 아니라, 합 Σ U_k를 mod Λ_c에서 얼마나 정확히 되돌릴 수 있는지(= 합의 분산 대 거친 격자 부피)로 정해질 것이다.
- **살아남는 것 3: 공유 난수 W [판단].** 디더(dither)와 무작위 부호책의 역할을 한다. 3.8절 보조정리 1이 다루는 "선택으로 생긴 의존성"을 디더가 제거해 준다(크립토 보조정리(crypto lemma)).
- **깨지는 것 3: 비선형 복원 [판단].** 3.4.3절의 X̂ = αU + βY처럼 개별 Uₖ에 다른 가중치를 주는 선형 결합은 합만 보이면 불가능하다. 이질적 잡음 분산 σ_k²에 대한 최적 가중은 부호기 쪽 스케일링(Q_k에 들어가기 전 가중)으로 옮겨야 한다.
- **결론 [판단].** 12장의 비닝 = "지표의 몫 사상"이라는 관점만 군 구조(부분군 잉여류)로 바꾸면 계승되고, "개별 부호어 공동 복호"는 버려야 한다. 역(converse) 쪽 Uᵢ = (M, Y_{j≠i}) 식의 보조 변수 구성도 M 대신 Z를 쓰면 형식상 그대로 적용된다. 다만 Z가 X에 대해 갖는 정보를 각 작업자 단일 문자 항으로 분해하는 것은 CEO 역 증명(Oohama/Prabhakaran–Tse–Ramchandran) 수준의 추가 논증이 필요하다.
