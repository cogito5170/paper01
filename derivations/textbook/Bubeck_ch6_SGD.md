## 2. 준비 (앞 장에서 가져오는 도구)

전체에서 ‖·‖는 ℝⁿ 위의 임의의 노름, 쌍대 노름(dual norm)은 ‖g‖_* = sup_{‖x‖≤1} gᵀx [원문, 4장 297쪽]. 정의에서 바로 횔더 부등식(Hölder inequality) gᵀx ≤ ‖g‖_*‖x‖가 나온다. 유클리드 노름이면 ‖·‖_* = ‖·‖₂이고 이것은 코시–슈바르츠(Cauchy–Schwarz) 부등식이다.

### 2.1 정의

- **볼록(convex)**, **부분기울기(subgradient)**: g ∈ ∂f(x) ⇔ 모든 y에서 f(y) ≥ f(x) + gᵀ(y − x). 따라서 f(x) − f(y) ≤ gᵀ(x − y). 이 "부분기울기 부등식"이 모든 증명의 출발점이다.
- **L-립시츠(Lipschitz)** (볼록 f에 대해): 모든 g ∈ ∂f(x)에서 ‖g‖_* ≤ L [원문, 297쪽].
- **β-평활(β-smooth)**: ‖∇f(x) − ∇f(y)‖_* ≤ β‖x − y‖ [원문, 266쪽·297쪽]. 두 번 미분 가능하면 헤세 행렬(Hessian) 고윳값 ≤ β와 같다(유클리드).
- **α-강볼록(α-strongly convex)**: f(x) − f(y) ≤ gᵀ(x − y) − (α/2)‖x − y‖², g ∈ ∂f(x) [원문, (3.13)]. 즉 각 점에 아래로 받치는 2차 함수가 있다. f − (α/2)‖x‖²가 볼록인 것과 같다(유클리드).
- **조건수(condition number)** κ = β/α [원문, 278쪽].
- **브레그만 발산(Bregman divergence)**: D_f(x, y) = f(x) − f(y) − ∇f(y)ᵀ(x − y) [원문, 297쪽]. f가 볼록이면 D_f ≥ 0. Φ(x) = ½‖x‖₂²이면 D_Φ(x, y) = ½‖x − y‖₂².

### 2.2 보조정리 3.4 (평활 함수의 2차 상한) [원문, 267쪽]

**진술.** f가 β-평활이면 모든 x, y에서 |f(x) − f(y) − ∇f(y)ᵀ(x − y)| ≤ (β/2)‖x − y‖².

**증명.** h(t) = f(y + t(x − y))로 두면 미적분의 기본정리로 f(x) − f(y) = ∫₀¹ ∇f(y + t(x − y))ᵀ(x − y) dt. 여기서 ∇f(y)ᵀ(x − y) = ∫₀¹ ∇f(y)ᵀ(x − y) dt를 빼면

|f(x) − f(y) − ∇f(y)ᵀ(x − y)| = |∫₀¹ (∇f(y + t(x − y)) − ∇f(y))ᵀ(x − y) dt|
≤ ∫₀¹ ‖∇f(y + t(x − y)) − ∇f(y)‖_* ‖x − y‖ dt   (횔더)
≤ ∫₀¹ βt‖x − y‖² dt   (β-평활: 두 점 사이 거리가 t‖x − y‖)
= (β/2)‖x − y‖². ∎

원문은 유클리드로 적었지만 쌍대 노름으로 똑같이 성립한다 [재구성]. f가 볼록이면 왼쪽 절댓값 안이 0 이상이므로

0 ≤ f(x) − f(y) − ∇f(y)ᵀ(x − y) ≤ (β/2)‖x − y‖²   … (3.4) [원문]

**따름 (3.5)** [원문, 267쪽]: (3.4)에 x ← x − (1/β)∇f(x), y ← x를 넣으면 (유클리드)
f(x − ∇f(x)/β) − f(x) ≤ −(1/β)‖∇f(x)‖² + (β/2)(1/β²)‖∇f(x)‖² = −(1/(2β))‖∇f(x)‖².
의미: 기울기 하강 한 걸음(걸음 1/β)이 함숫값을 최소 ‖∇f‖²/(2β)만큼 줄인다.

**따름 (최솟값과 기울기 크기)** [재구성]: f ≥ f* 이면 f* ≤ f(x − ∇f(x)/β) ≤ f(x) − ‖∇f(x)‖²/(2β), 즉 ‖∇f(x)‖² ≤ 2β(f(x) − f*). 보조정리 6.4에서 이 꼴을 쓴다.

### 2.3 보조정리 3.5와 공강압성 (3.6) [원문, 268–269쪽]

**진술.** f가 (3.4)를 만족하면 (유클리드)
f(x) − f(y) ≤ ∇f(x)ᵀ(x − y) − (1/(2β))‖∇f(x) − ∇f(y)‖².

**증명.** z = y − (1/β)(∇f(y) − ∇f(x))로 두고 f(x) − f(y) = [f(x) − f(z)] + [f(z) − f(y)]로 쪼갠다.
- 첫 항: (3.4)의 왼쪽 부등식(볼록성)으로 f(x) − f(z) ≤ ∇f(x)ᵀ(x − z).
- 둘째 항: (3.4)의 오른쪽 부등식으로 f(z) − f(y) ≤ ∇f(y)ᵀ(z − y) + (β/2)‖z − y‖².
더하고 x − z = (x − y) + (y − z)로 쓰면
f(x) − f(y) ≤ ∇f(x)ᵀ(x − y) + (∇f(x) − ∇f(y))ᵀ(y − z) + (β/2)‖z − y‖².
y − z = (1/β)(∇f(y) − ∇f(x))를 넣으면 가운데 항 = −(1/β)‖∇f(x) − ∇f(y)‖², 마지막 항 = (1/(2β))‖∇f(x) − ∇f(y)‖². 합 = −(1/(2β))‖·‖². ∎

x와 y를 바꿔 쓴 식과 더하면 **(3.6)**: (∇f(x) − ∇f(y))ᵀ(x − y) ≥ (1/β)‖∇f(x) − ∇f(y)‖² [원문].

### 2.4 투영과 사영 경사 하강 (정리 3.2) [원문, 264–265쪽]

- 유클리드 투영 Π_X(y) = argmin_{x∈X} ‖x − y‖ (X는 닫힌 볼록 집합).
- **보조정리 3.1** [원문]: x ∈ X이면 (Π_X(y) − x)ᵀ(Π_X(y) − y) ≤ 0, 따라서 ‖Π_X(y) − x‖² + ‖y − Π_X(y)‖² ≤ ‖y − x‖². 특히 ‖Π_X(y) − x‖ ≤ ‖y − x‖ (투영은 X 안의 점에 가까워지게만 한다).
  - 증명 [재구성]: p = Π_X(y). 모든 x ∈ X, λ ∈ [0,1]에서 p + λ(x − p) ∈ X이므로 ‖y − p − λ(x − p)‖² ≥ ‖y − p‖². 전개하면 −2λ(y − p)ᵀ(x − p) + λ²‖x − p‖² ≥ 0; λ로 나누고 λ → 0이면 (y − p)ᵀ(x − p) ≤ 0, 즉 (p − x)ᵀ(p − y) ≤ 0. 그리고 ‖y − x‖² = ‖(y − p) + (p − x)‖² = ‖y − p‖² + ‖p − x‖² + 2(y − p)ᵀ(p − x)이며, 마지막 항은 −2(y − p)ᵀ(x − p) ≥ 0이므로 ‖y − x‖² ≥ ‖y − p‖² + ‖p − x‖². ∎
- **정리 3.2의 한 걸음 부등식** (사영 부분기울기 하강 y_{s+1} = x_s − ηg_s, x_{s+1} = Π_X(y_{s+1})): 2aᵀb = ‖a‖² + ‖b‖² − ‖a − b‖²를 쓰면
  gₛᵀ(xₛ − x*) = (1/η)(xₛ − y_{s+1})ᵀ(xₛ − x*) = (1/(2η))(‖xₛ − x*‖² + ‖xₛ − y_{s+1}‖² − ‖y_{s+1} − x*‖²)
  = (1/(2η))(‖xₛ − x*‖² − ‖y_{s+1} − x*‖²) + (η/2)‖gₛ‖²
  ≤ (1/(2η))(‖xₛ − x*‖² − ‖x_{s+1} − x*‖²) + (η/2)‖gₛ‖²   (보조정리 3.1).   … (★)
  (★)에는 함수에 관한 가정이 하나도 없다. gₛ가 아무 벡터여도 성립한다는 점이 6장 전체의 열쇠다 [판단].

### 2.5 미러 맵과 미러 하강 (4장) [원문, 298–301쪽, 307쪽]

**미러 맵(mirror map)** Φ: D → ℝ (D는 열린 볼록 집합, X ⊂ D̄): (i) 순볼록·미분 가능, (ii) ∇Φ(D) = ℝⁿ, (iii) 경계에서 ‖∇Φ‖ → ∞ [원문]. 여기서는 Φ가 X ∩ D에서 ‖·‖에 대해 ρ-강볼록이라고 가정하고, 6장은 ρ = 1을 쓴다. 이때 D_Φ(x, y) ≥ (ρ/2)‖x − y‖² (강볼록 정의 (3.13)을 ∇Φ(y)에서 쓴 것).

**삼점 항등식 (4.1)** [원문]: (∇Φ(x) − ∇Φ(y))ᵀ(x − z) = D_Φ(x, y) + D_Φ(z, x) − D_Φ(z, y).
증명 [재구성]: 오른쪽을 정의대로 펼치면 Φ(x) − Φ(y) − ∇Φ(y)ᵀ(x − y) + Φ(z) − Φ(x) − ∇Φ(x)ᵀ(z − x) − Φ(z) + Φ(y) + ∇Φ(y)ᵀ(z − y). Φ 값은 모두 상쇄되고 남는 것은 −∇Φ(y)ᵀ(x − z) + ∇Φ(x)ᵀ(x − z) = 왼쪽. ∎

**미러 하강(mirror descent, MD)의 근접 형태 (4.5)** [원문]: x₁ ∈ argmin_{X∩D} Φ, x_{t+1} = argmin_{x∈X∩D} ηgₜᵀx + D_Φ(x, xₜ).
Φ = ½‖x‖₂²이면 D_Φ = ½‖x − xₜ‖₂²이고, 이 argmin은 Π_X(xₜ − ηgₜ), 즉 사영 경사 하강과 정확히 같다 [원문, 301쪽 "Ball setup"].

**근접 단계의 핵심 부등식** [재구성; 원문 6.2절 증명이 "(4.9)와 같은 논법"이라고만 함]: x⁺ = argmin_{x∈X∩D} γgᵀx + D_Φ(x, xₛ)이면 모든 u ∈ X ∩ D에 대해

γgᵀ(x⁺ − u) ≤ D_Φ(u, xₛ) − D_Φ(u, x⁺) − D_Φ(x⁺, xₛ).   … (P)

증명: 목적 함수 x ↦ γgᵀx + D_Φ(x, xₛ)는 볼록이고 그 기울기는 γg + ∇Φ(x) − ∇Φ(xₛ). 볼록 집합 위 최소점의 1차 최적성 조건: (γg + ∇Φ(x⁺) − ∇Φ(xₛ))ᵀ(u − x⁺) ≥ 0. 즉 γgᵀ(x⁺ − u) ≤ (∇Φ(x⁺) − ∇Φ(xₛ))ᵀ(u − x⁺) = −(∇Φ(x⁺) − ∇Φ(xₛ))ᵀ(x⁺ − u). 삼점 항등식 (4.1)에 x ← x⁺, y ← xₛ, z ← u를 넣으면 (∇Φ(x⁺) − ∇Φ(xₛ))ᵀ(x⁺ − u) = D_Φ(x⁺, xₛ) + D_Φ(u, x⁺) − D_Φ(u, xₛ). 부호를 바꾸면 (P). ∎
유클리드에서 (P)는 γgᵀ(x⁺ − u) ≤ ½‖u − xₛ‖² − ½‖u − x⁺‖² − ½‖x⁺ − xₛ‖².

**R²의 뜻** [재구성]: R² := sup_{x∈X∩D} Φ(x) − Φ(x₁). x₁이 X ∩ D에서 Φ의 최소점이므로 1차 조건 ∇Φ(x₁)ᵀ(x − x₁) ≥ 0, 따라서 D_Φ(x, x₁) = Φ(x) − Φ(x₁) − ∇Φ(x₁)ᵀ(x − x₁) ≤ Φ(x) − Φ(x₁) ≤ R². 증명들은 R²을 **오직 D_Φ(x*, x₁) ≤ R²의 형태로만** 쓴다. 유클리드에서 이것은 ½‖x* − x₁‖² ≤ R²이다. 이 사실은 Zhang의 진술 대조(3.2.4)에서 중요하다.

**식 (4.10): 임의의 벡터열에 대한 미러 하강 부등식** [원문, 307쪽]: 임의의 벡터 g₁, …, gₜ에 대해 MD 반복은 모든 x ∈ X ∩ D에서
Σₛ gₛᵀ(xₛ − x) ≤ R²/η + (η/(2ρ)) Σₛ ‖gₛ‖²_*.
증명 [원문 정리 4.2 증명을 정리]: (P)를 γ = η, u = x, x⁺ = x_{s+1}로 쓰면
ηgₛᵀ(xₛ − x) = ηgₛᵀ(x_{s+1} − x) + ηgₛᵀ(xₛ − x_{s+1})
≤ D_Φ(x, xₛ) − D_Φ(x, x_{s+1}) − D_Φ(x_{s+1}, xₛ) + ηgₛᵀ(xₛ − x_{s+1}).
마지막 두 항: 횔더와 ρ-강볼록으로 ≤ η‖gₛ‖_*‖xₛ − x_{s+1}‖ − (ρ/2)‖xₛ − x_{s+1}‖² ≤ η²‖gₛ‖²_*/(2ρ) (az − bz² ≤ a²/(4b), 모든 z). s = 1..t로 더하면 D_Φ(x, ·)가 망원급수(telescoping)로 사라지고 D_Φ(x, x₁) − D_Φ(x, x_{t+1}) ≤ R². η로 나누면 (4.10). ∎ 유클리드·ρ = 1에서 이것은 (★)를 더한 것과 같다.

### 2.6 결정적 수렴률 세 개 (비교 기준)

- **정리 3.2** [원문]: 볼록 L-립시츠, 사영 부분기울기 하강, η = R/(L√t)(R ≥ ‖x₁ − x*‖) ⇒ f(평균 xₛ) − f* ≤ RL/√t. 증명: (★)를 더하면 Σ(f(xₛ) − f*) ≤ Σgₛᵀ(xₛ − x*) ≤ R²/(2η) + ηL²t/2; η 대입 후 젠센(Jensen) f(평균) ≤ 평균 f.
- **정리 3.3** [원문]: 볼록 β-평활, η = 1/β ⇒ f(xₜ) − f* ≤ 2β‖x₁ − x*‖²/(t − 1). 증명 골자: δₛ = f(xₛ) − f*. (3.5)로 δ_{s+1} ≤ δₛ − ‖∇f(xₛ)‖²/(2β). 볼록성·코시–슈바르츠로 δₛ ≤ ‖∇f(xₛ)‖‖xₛ − x*‖, (3.6)으로 ‖xₛ − x*‖가 감소하므로 ≤ ‖x₁ − x*‖. 합치면 δ_{s+1} ≤ δₛ − ωδₛ², ω = 1/(2β‖x₁ − x*‖²). 양변을 δₛδ_{s+1}로 나누고 δₛ/δ_{s+1} ≥ 1을 쓰면 1/δ_{s+1} − 1/δₛ ≥ ω, 더하면 1/δₜ ≥ ω(t − 1). (이 "δ_{s+1} ≤ δₛ − ωδₛ² ⇒ δₜ ≤ 1/(ω(t − 1))" 논법은 정리 6.7에서 다시 쓴다.)
- **정리 3.9** [원문, 277쪽]: α-강볼록 L-립시츠, ηₛ = 2/(α(s + 1)) ⇒ f(Σ 2s/(t(t + 1)) xₛ) − f* ≤ 2L²/(α(t + 1)). 증명은 확률판인 정리 6.2(3.1.3)에서 완전히 푼다.
- **정리 3.10** [원문, 278쪽]: α-강볼록 β-평활, η = 1/β ⇒ ‖x_{t+1} − x*‖² ≤ exp(−t/κ)‖x₁ − x*‖². 즉 ε 정확도에 κ log(1/ε)번 반복(선형 수렴, linear rate).

## 3. 6장 본문

### 3.0 도입: 확률적 오라클 [원문, 329–330쪽]

**직관.** 1차 방법은 작은 걸음을 많이 밟는다. 걸음마다 기울기가 "평균적으로만" 맞으면, 오차는 여러 걸음에 걸쳐 평균되어 사라진다(Robbins–Monro 1951) [원문]. 그러나 원문이 바로 경고하듯, 평활 최적화에서는 걸음이 크므로(η ~ 1/β) 이 그림이 미묘해진다.

**정의 (확률적 오라클, stochastic oracle)** [원문]: 볼록 f에 대해, 점 x를 넣으면 확률변수 g̃(x)를 내주며 E g̃(x) ∈ ∂f(x). 질의점 x 자체가 (이전 질의로 만들어진) 확률변수이면 E(g̃(x) | x) ∈ ∂f(x)를 가정한다.
- 불편성(unbiasedness)만으로는 수렴률이 안 나온다. 요동의 크기 가정이 필요하다 [원문]:
  - 비평활 경우: 2차 모멘트 E‖g̃(x)‖²_* ≤ B² (모든 x).
  - 평활 경우: 분산 E‖g̃(x) − ∇f(x)‖²_* ≤ σ² (모든 x).
- 편향된 오라클은 "상황이 꽤 다르다"며 d'Aspremont 2008, Schmidt et al. 2011을 가리키고 다루지 않는다 [원문]. 이 노트의 부록이 그 빈칸을 Ajalloeian–Stich로 채운다.

**두 가지 표준 예** [원문]:
1. 기대 손실 f(x) = E_ξ ℓ(x, ξ): 오라클이 새 표본 ξ를 뽑아 ∇ₓℓ(x, ξ)를 낸다. 미분과 기댓값 교환으로 E∇ₓℓ = ∇f. 표본 m개면 질의 m번(데이터 한 바퀴)까지만 조건부 불편성이 보장된다 — 같은 표본을 다시 쓰면 그 표본이 이미 xₛ에 영향을 줬으므로 E(·|xₛ)가 깨진다.
2. 유한합 f(x) = (1/m)Σᵢ fᵢ(x): I를 [m]에서 균등하게 뽑아 ∇f_I(x)를 낸다. E∇f_I(x) = (1/m)Σ∇fᵢ(x) = ∇f(x). 몇 바퀴든 돌 수 있다.

**확률 쪽에서 쓰는 단 하나의 도구 — 탑 성질(tower rule)** [재구성]: Fₛ를 xₛ까지의 과거 정보라 하면 xₛ는 Fₛ-가측이고, 임의의 Fₛ-가측 벡터 Y에 대해
E[g̃ₛᵀY] = E[E(g̃ₛ | Fₛ)ᵀY].
즉 "오라클이 지금 낸 잡음"과 "지금 이미 정해진 양"의 내적은 기댓값이 잡음 없는 것으로 바뀐다. **반대로 x_{s+1}처럼 g̃ₛ에 의존하는 양과의 내적에는 쓸 수 없다.** 6.2절 증명이 영 레마를 쓰지 않고 영의 부등식(Young's inequality)으로 우회하는 이유가 이것이다.

### 3.1 비평활 확률적 최적화 (6.1절, 330–331쪽)

**알고리즘 S-MD (확률적 미러 하강, stochastic mirror descent)** [원문]: x₁ ∈ argmin_{X∩D} Φ, x_{t+1} = argmin_{x∈X∩D} ηg̃(xₜ)ᵀx + D_Φ(x, xₜ). 즉 MD에서 부분기울기 자리에 오라클 출력을 넣은 것.

#### 3.1.1 정리 6.1 [원문, 331쪽]

**진술.** Φ는 X ∩ D에서 ‖·‖에 대해 1-강볼록인 미러 맵, R² = sup_{X∩D} Φ(x) − Φ(x₁). f는 볼록. 오라클이 E‖g̃(x)‖²_* ≤ B². 그러면 η = (R/B)√(2/t)인 S-MD는
E f((1/t)Σ_{s=1}^t xₛ) − min_{x∈X} f(x) ≤ RB√(2/t).

**증명.** 고정된(비무작위) x ∈ X ∩ D를 잡는다(마지막에 x → x*).

1단계 (경로별 부등식). (4.10)은 임의의 벡터열에 성립하므로 gₛ = g̃(xₛ)를 넣으면, 모든 실현값에서
Σₛ g̃(xₛ)ᵀ(xₛ − x) ≤ R²/η + (η/2)Σₛ‖g̃(xₛ)‖²_* [원문].

2단계 (젠센 + 탑 성질) [원문의 3줄 계산을 풀어 씀]:
E f((1/t)Σxₛ) − f(x) ≤ (1/t)Σₛ E[f(xₛ) − f(x)]   (f 볼록 ⇒ 젠센)
≤ (1/t)Σₛ E[E(g̃(xₛ) | xₛ)ᵀ(xₛ − x)]   (E(g̃(xₛ)|xₛ) ∈ ∂f(xₛ)이므로 부분기울기 부등식을 점별로)
= (1/t)Σₛ E[g̃(xₛ)ᵀ(xₛ − x)]   (탑 성질: xₛ − x는 xₛ의 함수).

3단계. 1단계의 기댓값을 잡고 E‖g̃(xₛ)‖²_* ≤ B²(이 가정은 "모든 x에서"이므로 무작위 xₛ에서도 조건부로 성립하고, 다시 기댓값을 잡아 무조건부로) 를 쓰면
E f(평균) − f(x) ≤ (1/t)(R²/η + ηtB²/2) = R²/(ηt) + ηB²/2.

4단계 (걸음 크기 최적화). φ(η) = R²/(ηt) + ηB²/2는 R²/(ηt) = ηB²/2, 즉 η = (R/B)√(2/t)에서 최소(산술–기하 평균). 대입: R²/(ηt) = RB/√(2t), ηB²/2 = RB/√(2t), 합 = 2RB/√(2t) = RB√(2/t). ∎

**읽는 법** [판단]: 결정적 정리 4.2(ρ = 1)의 RL√(2/t)에서 L(기울기 크기의 상한)이 B(오라클 출력의 2차 모멘트 제곱근)로 바뀌었을 뿐이다. 원문 6.2절 첫 문장 그대로, 비평활 최적화에서는 확률적 오라클을 쓰는 "비용이 사실상 없다". 이유: 비평활 경우 결정적 방법도 이미 ‖g‖²을 상한으로 다루므로, 잡음이 그 상한을 B² 이상으로 키우지만 않으면 차이가 없다.

**주의** [판단]: B²은 분산이 아니라 2차 모멘트다. E‖g̃‖² = ‖∇f‖² + E‖g̃ − ∇f‖²(불편일 때, 교차항의 기댓값 0)이므로 B² ≥ L²(신호) + σ²(잡음). 정리 6.1에서 잡음은 신호와 같은 자리에 더해진다.

#### 3.1.2 사영 SGD로 쓴 경우 [재구성]

Φ = ½‖x‖₂²이면 S-MD는 SGD: x_{t+1} = Π_X(xₜ − ηg̃(xₜ)) [원문, 331쪽]. 이때 (★)에 gₛ = g̃ₛ를 넣고 위와 똑같이 하면, R² 자리에 ½‖x₁ − x*‖²(또는 그 상한)을 쓸 수 있다.

#### 3.1.3 정리 6.2 (강볼록, 시간 가변 걸음) [원문, 331쪽]

**진술.** f는 α-강볼록, 오라클은 E‖g̃(x)‖²_* ≤ B² (유클리드). SGD x_{t+1} = Π_X(xₜ − ηₜg̃(xₜ)), ηₛ = 2/(α(s + 1))이면
f(Σ_{s=1}^t (2s/(t(t + 1))) xₛ) − f(x*) ≤ 2B²/(α(t + 1)).

원문 진술 왼쪽에 기댓값 E가 빠져 있다. 확률변수의 부등식이므로 E f(…)로 읽어야 한다 [판단: 오식].

**증명** [재구성; 원문은 "정리 3.9를 바로 일반화"라고만 함]. aₛ := E‖xₛ − x*‖².

1단계 (한 걸음). (★)에 gₛ = g̃ₛ, η = ηₛ를 넣으면 경로별로
g̃ₛᵀ(xₛ − x*) ≤ (‖xₛ − x*‖² − ‖x_{s+1} − x*‖²)/(2ηₛ) + (ηₛ/2)‖g̃ₛ‖².

2단계 (강볼록 + 탑 성질). 강볼록 정의를 gₛ := E(g̃ₛ | xₛ) ∈ ∂f(xₛ), y = x*로 쓰면 f(xₛ) − f(x*) ≤ gₛᵀ(xₛ − x*) − (α/2)‖xₛ − x*‖². 기댓값을 잡고 탑 성질로 E[gₛᵀ(xₛ − x*)] = E[g̃ₛᵀ(xₛ − x*)]. 1단계와 합치면
E[f(xₛ) − f*] ≤ (1/(2ηₛ) − α/2)aₛ − (1/(2ηₛ))a_{s+1} + ηₛB²/2.

3단계 (걸음 대입). 1/(2ηₛ) = α(s + 1)/4이므로 1/(2ηₛ) − α/2 = α(s − 1)/4, ηₛB²/2 = B²/(α(s + 1)):
E[f(xₛ) − f*] ≤ (α/4)[(s − 1)aₛ − (s + 1)a_{s+1}] + B²/(α(s + 1)).

4단계 (가중치 s를 곱해 망원급수 만들기). s를 곱하면 s(s − 1)aₛ − s(s + 1)a_{s+1} 꼴이 되고 이것은 bₛ := (s − 1)s aₛ로 두면 bₛ − b_{s+1}이다. 또 sB²/(α(s + 1)) ≤ B²/α. 따라서
s·E[f(xₛ) − f*] ≤ (α/4)(bₛ − b_{s+1}) + B²/α.
s = 1..t로 더하면 b₁ = 0, b_{t+1} ≥ 0이므로 Σₛ s·E[f(xₛ) − f*] ≤ tB²/α.

5단계 (젠센). Σₛ s = t(t + 1)/2이므로 가중치 wₛ = 2s/(t(t + 1))는 합이 1. f 볼록이므로 f(Σwₛxₛ) ≤ Σwₛf(xₛ), 따라서
E f(Σwₛxₛ) − f* ≤ (2/(t(t + 1)))·tB²/α = 2B²/(α(t + 1)). ∎

**왜 s배 가중인가** [판단]: 걸음 ηₛ ~ 1/s 덕분에 (1/(2ηₛ) − α/2) 계수가 s에 선형으로 자라는데, 가중치 s를 곱해야 앞 항의 계수 s(s − 1)과 뒤 항의 계수 s(s + 1)이 정확히 이어 붙는다. 균등 평균을 쓰면 log t 손실이 남는다(원문은 언급하지 않음; 문헌상 잘 알려진 사실 [미확인: 이 장에서 증명 안 됨]).

### 3.2 평활 확률적 최적화와 미니배치 SGD (6.2절, 332–334쪽)

#### 3.2.1 문제: 평활성은 확률적 오라클에서 얼마나 도움이 되는가

[원문] 일반 확률적 오라클에서는 평활성이 가속을 주지 못한다(하한, Tsybakov 2003 참조): 오라클 호출 t번으로 σ/√t보다 좋을 수 없다. 결정적이면 1/t(기울기 하강), 1/t²(네스테로프 가속)인 것과 대조적이다. 단, 이것은 최악의 경우 진술이고 제곱 손실·로지스틱 손실에서는 가속이 가능하다(Bach–Moulines 2013) [원문, 각주 2].

다음 정리는 두 극단을 **보간(interpolate)** 한다: 잡음 부분은 σ/√t, 잡음 없는 부분은 β/t. 증명은 Dekel et al. 2012에서 왔다 [원문].

#### 3.2.2 정리 6.3 [원문, 332쪽]

**진술.** Φ는 X ∩ D에서 ‖·‖에 대해 1-강볼록인 미러 맵, R² = sup_{X∩D} Φ(x) − Φ(x₁). f는 ‖·‖에 대해 볼록·β-평활. 오라클이 E‖∇f(x) − g̃(x)‖²_* ≤ σ². 그러면 걸음 크기 1/(β + 1/η), η = (R/σ)√(2/t)인 S-MD는

E f((1/t)Σ_{s=1}^t x_{s+1}) − f(x*) ≤ Rσ√(2/t) + βR²/t.

세 가지를 정확히 적어 둔다 [원문]:
1. S-MD의 "걸음"은 x_{s+1} = argmin γg̃(xₛ)ᵀx + D_Φ(x, xₛ)의 γ이며 γ = 1/(β + 1/η). η 자체가 걸음이 아니다.
2. 평균은 x₂, …, x_{t+1} (x_{s+1}, s = 1..t)의 평균이다. x₁은 들어가지 않는다.
3. 오라클 가정은 2차 모멘트가 아니라 **분산**이다.

**직관** [판단]. 걸음 γ = 1/(β + 1/η)는 두 걸음의 "조화 결합"이다: 잡음이 없으면(σ → 0, η → ∞) γ → 1/β, 즉 결정적 평활 하강의 긴 걸음. 잡음이 크면 1/η가 지배하여 γ ≈ η ~ (R/σ)/√t, 즉 비평활 SGD의 짧은 걸음. 1/η 항은 잡음과 걸음의 곱이 만드는 오차를 흡수하는 "추가 감쇠"다.

#### 3.2.3 정리 6.3의 증명 (한 줄씩) [원문 + 빈칸 재구성]

기호: g̃ₛ := g̃(xₛ), γ := 1/(β + 1/η), x* ∈ argmin_X f.

**1단계 (평활성으로 한 걸음의 증가를 위에서 누름).** 보조정리 3.4(쌍대 노름판)를 x ← x_{s+1}, y ← xₛ로:
f(x_{s+1}) − f(xₛ) ≤ ∇f(xₛ)ᵀ(x_{s+1} − xₛ) + (β/2)‖x_{s+1} − xₛ‖².

**2단계 (참 기울기를 오라클 출력 + 오차로 쪼갬).** ∇f(xₛ) = g̃ₛ + (∇f(xₛ) − g̃ₛ):
= g̃ₛᵀ(x_{s+1} − xₛ) + (∇f(xₛ) − g̃ₛ)ᵀ(x_{s+1} − xₛ) + (β/2)‖x_{s+1} − xₛ‖².

**3단계 (오차 항을 영의 부등식으로).** 오차 항은 x_{s+1}이 g̃ₛ에 의존하므로 기댓값이 0이 아니다. 횔더와 ab ≤ (η/2)a² + (1/(2η))b² (원문의 "2ab ≤ xa² + b²/x"에서 x = η):
(∇f(xₛ) − g̃ₛ)ᵀ(x_{s+1} − xₛ) ≤ ‖∇f(xₛ) − g̃ₛ‖_*‖x_{s+1} − xₛ‖ ≤ (η/2)‖∇f(xₛ) − g̃ₛ‖²_* + (1/(2η))‖x_{s+1} − xₛ‖².
따라서
f(x_{s+1}) − f(xₛ) ≤ g̃ₛᵀ(x_{s+1} − xₛ) + (η/2)‖∇f(xₛ) − g̃ₛ‖²_* + ½(β + 1/η)‖x_{s+1} − xₛ‖².

**4단계 (Φ의 1-강볼록성으로 노름을 브레그만 발산으로).** ½‖x_{s+1} − xₛ‖² ≤ D_Φ(x_{s+1}, xₛ):
f(x_{s+1}) − f(xₛ) ≤ g̃ₛᵀ(x_{s+1} − xₛ) + (η/2)‖∇f(xₛ) − g̃ₛ‖²_* + (β + 1/η)D_Φ(x_{s+1}, xₛ).   … (A)

**5단계 (근접 단계 부등식).** (P)를 g = g̃ₛ, 걸음 γ = 1/(β + 1/η), u = x*로 쓰고 양변에 (β + 1/η)를 곱하면
g̃ₛᵀ(x_{s+1} − x*) ≤ (β + 1/η)[D_Φ(x*, xₛ) − D_Φ(x*, x_{s+1}) − D_Φ(x_{s+1}, xₛ)].   … (B) [원문]

**6단계 (합치기: D_Φ(x_{s+1}, xₛ)가 상쇄된다).** (A)에서 g̃ₛᵀ(x_{s+1} − xₛ) = g̃ₛᵀ(x_{s+1} − x*) + g̃ₛᵀ(x* − xₛ)로 쪼개고 (B)를 넣으면 +(β + 1/η)D_Φ(x_{s+1}, xₛ)와 −(β + 1/η)D_Φ(x_{s+1}, xₛ)가 지워진다:
f(x_{s+1}) ≤ f(xₛ) + g̃ₛᵀ(x* − xₛ) + (β + 1/η)[D_Φ(x*, xₛ) − D_Φ(x*, x_{s+1})] + (η/2)‖∇f(xₛ) − g̃ₛ‖²_*.
**이 상쇄가 정리의 심장이다** [판단]: 걸음을 정확히 1/(β + 1/η)로 고른 이유는, 평활성(β)과 영의 부등식(1/η)이 만든 ‖x_{s+1} − xₛ‖² 비용을 근접 단계가 주는 −D_Φ(x_{s+1}, xₛ) 이득이 정확히 갚게 하려는 것이다.

**7단계 (볼록성).** g̃ₛᵀ(x* − xₛ) = ∇f(xₛ)ᵀ(x* − xₛ) + (g̃ₛ − ∇f(xₛ))ᵀ(x* − xₛ)이고 볼록성으로 f(xₛ) + ∇f(xₛ)ᵀ(x* − xₛ) ≤ f(x*):
f(x_{s+1}) ≤ f(x*) + (g̃ₛ − ∇f(xₛ))ᵀ(x* − xₛ) + (β + 1/η)[D_Φ(x*, xₛ) − D_Φ(x*, x_{s+1})] + (η/2)‖∇f(xₛ) − g̃ₛ‖²_*.

**8단계 (기댓값: 여기서만 불편성이 쓰인다).** (g̃ₛ − ∇f(xₛ))ᵀ(x* − xₛ)에서 x* − xₛ는 Fₛ-가측이므로 탑 성질로 기댓값 = E[(E(g̃ₛ|Fₛ) − ∇f(xₛ))ᵀ(x* − xₛ)] = 0. 분산 가정으로 E‖∇f(xₛ) − g̃ₛ‖²_* ≤ σ²:
E f(x_{s+1}) − f(x*) ≤ (β + 1/η)E[D_Φ(x*, xₛ) − D_Φ(x*, x_{s+1})] + ησ²/2. [원문]

**9단계 (더하기 — 원문의 "표준 논법")** [재구성]. s = 1..t로 더하면 망원급수:
Σₛ (E f(x_{s+1}) − f*) ≤ (β + 1/η)[D_Φ(x*, x₁) − E D_Φ(x*, x_{t+1})] + tησ²/2 ≤ (β + 1/η)R² + tησ²/2.
(2.5절: D_Φ(x*, x₁) ≤ R², D_Φ ≥ 0.) t로 나누고 젠센 f((1/t)Σx_{s+1}) ≤ (1/t)Σf(x_{s+1}):
E f(평균) − f* ≤ βR²/t + R²/(ηt) + ησ²/2.

**10단계 (η 대입).** η = (R/σ)√(2/t)이면 R²/(ηt) = Rσ/√(2t), ησ²/2 = Rσ/√(2t), 합 = Rσ√(2/t). 따라서
E f((1/t)Σ_{s=1}^t x_{s+1}) − f* ≤ Rσ√(2/t) + βR²/t. ∎

η = (R/σ)√(2/t)는 R²/(ηt) + ησ²/2를 최소화하는 값이다(정리 6.1의 4단계와 같은 산술–기하 평균 계산).

**불편성이 정확히 어디에 쓰였나** [판단]: 8단계 한 군데뿐이다. 편향 b가 있으면 그 자리에 E[bᵀ(x* − xₛ)]가 남고, 이것은 걸음이나 t로 줄어들지 않는다(부록 참조).

**분산이 정확히 어디에 쓰였나** [판단]: 3단계의 영의 부등식이 만든 (η/2)‖오차‖² 한 항뿐이다. 그래서 수렴률에서 σ²은 "ησ²/2를 η로 균형 잡은 결과" √(σ²) = σ로만 들어간다.

#### 3.2.4 Zhang et al. 2023의 Theorem 1과 대조

Zhang et al. 2023 (`papers/modern/Zhang2023_CEO_model_aggregation.pdf`, PDF 7쪽, 식 (4)) Theorem 1 ("[15], Theorem 6.3")의 진술 [원문(Zhang), 쪽 이미지 대조]:
ω ⊆ ℝᴾ 볼록, F: ω → ℝ 볼록·β-평활, w(0) 주어짐, A² = sup_{w∈ω}‖w − w(0)‖² < ∞, T 고정. 불편 추정량, E‖ĝ(t) − g(t)‖² ≤ D (t = 1..T), 상수 걸음 η(t) = γ/(β + 1), γ = A√(2/(DT))이면
E[F((1/T)Σ_{t=1}^T w(t))] − min_{w∈ℝᴾ} F(w) ≤ A√(2D/T) + βA²/T.

대응: R ↔ A, σ² ↔ D, t ↔ T, Bubeck의 η ↔ Zhang의 γ, Φ = ½‖·‖₂², x₁ = w(0), x_{s+1} = w(s).

| 항목 | Bubeck 정리 6.3 | Zhang Theorem 1 | 판정 |
|---|---|---|---|
| 결론 식 | Rσ√(2/t) + βR²/t | A√(2D/T) + βA²/T | 같음 (치환하면 일치) |
| 평균 범위 | x₂..x_{t+1} | w(1)..w(T), 시작점 w(0) | 같음 (w(0) = x₁이므로) |
| 걸음 크기 | **1/(β + 1/η)** = η/(βη + 1) | **γ/(β + 1)** | **불일치** |
| 분산 가정 | E‖∇f − g̃‖²_* ≤ σ², 모든 질의점에서 | E‖ĝ(t) − g(t)‖² ≤ D | 사실상 같음(증명엔 무조건부 기댓값만 필요) |
| 불편성 | E(g̃(x)|x) ∈ ∂f(x) (조건부) | E[ĝ(t)] = g(t) | 조건부로 읽어야 함 |
| 반경 | R² = sup Φ − Φ(x₁) (유클리드: sup ½‖x‖² − ½‖x₁‖²) | A² = sup‖w − w(0)‖² | 유효하나 상수가 느슨함 |
| 갱신 | 투영 포함 (X 위의 S-MD) | w(t+1) = w(t) − η(t)ĝ(t) (투영 없음) | 불일치 |
| 비교 대상 | f(x*), x* ∈ argmin_X f | min_{w∈ℝᴾ} F(w) | 불일치(ω 위의 최솟값이어야) |

세부 [판단]:
1. **걸음 크기 오식.** 원문 걸음은 1/(β + 1/γ) = γ/(1 + βγ)다. Zhang의 γ/(β + 1)은 β = 1이거나 γ = 1일 때만 일치하며, 차원도 맞지 않는다(β는 [기울기/거리], 1은 무차원). 증명 6단계의 상쇄는 걸음의 역수가 정확히 β + 1/γ일 것을 요구하므로, γ/(β + 1)로는 정리가 증명되지 않는다. 결론 식은 맞게 옮겼으므로, 걸음 크기 표기만 고치면 된다: η(t) = 1/(β + 1/γ) = γ/(1 + βγ).
2. **반경 A.** 증명이 쓰는 것은 D_Φ(x*, x₁) = ½‖x* − w(0)‖² ≤ R²뿐이다(2.5절). Zhang의 A²은 ‖x* − w(0)‖² 이상이므로 ½‖x* − w(0)‖² ≤ A²이 성립하고, R := A로 두면 정리가 그대로 맞다(걸음 η = (A/σ)√(2/T)도 A로 계산하면 된다). 다만 Φ(x) = ½‖x − w(0)‖²로 잡으면 R² = A²/2로 둘 수 있어, 원문을 정확히 쓰면 A√(D/T) + βA²/(2T)라는 더 작은 상한이 나온다. Zhang의 식은 틀리지 않았지만 상수 2배쯤 느슨하다.
3. **제약과 투영.** A < ∞ 이려면 ω가 유계여야 하는데, 유계 ω에서 투영 없는 갱신은 ω를 벗어날 수 있고, 정리 6.3은 투영(또는 근접) 단계를 증명 5단계 (P)에서 쓴다. ω = ℝᴾ이면 투영은 필요 없지만 A = ∞가 되어 Zhang의 A 정의가 무의미하다. 바르게 쓰려면 (a) w(t+1) = Π_ω(w(t) − η(t)ĝ(t))로 투영을 넣거나, (b) 무제약으로 두고 A를 sup이 아닌 ‖w(0) − w*‖ (또는 그 상한)로 정의해야 한다. (b)도 정리 6.3의 증명(유클리드, X = ℝᴾ)에서 그대로 성립한다 [재구성: 증명이 D_Φ(x*, x₁)만 쓰므로].
4. **min의 범위.** min_{w∈ℝᴾ}이 아니라 min_{w∈ω}여야 한다(F는 ω에서만 정의됨). 3번의 (b)로 읽으면 둘이 같다.
5. **조건부 불편성.** Zhang의 g(t) = ∇F(w(t))는 w(t)를 통해 무작위이므로, "E[ĝ(t)] = g(t)"는 E[ĝ(t) | w(t), 과거] = ∇F(w(t))로 읽어야 증명 8단계가 성립한다.

**결론**: 수렴률 식 A√(2D/T) + βA²/T 자체는 원문과 정확히 일치하고(R = A, σ² = D), 범위가 느슨할 뿐 틀리지 않다. 걸음 크기 γ/(β + 1)은 원문 1/(β + 1/γ)의 오식이고, 투영 생략과 min 범위는 제약 처리에서 생긴 부정확함이다 [판단].

#### 3.2.5 미니배치 SGD [원문, 333–334쪽]

**알고리즘**: x_{t+1} = Π_X(xₜ − (η/m)Σ_{i=1}^m g̃ᵢ(xₜ)), g̃ᵢ(xₜ)는 xₜ에 조건부로 독립인 오라클 출력.

**분산 계산** [원문 + 재구성]: 묶은 오라클 ḡ = (1/m)Σg̃ᵢ도 불편이다. 오차 eᵢ = g̃ᵢ − ∇f는 조건부로 독립·평균 0이므로 i ≠ j에서 E eᵢᵀeⱼ = (E eᵢ)ᵀ(E eⱼ) = 0, 따라서
E‖ḡ − ∇f‖₂² = (1/m²)Σᵢ E‖eᵢ‖² = (1/m)E‖g̃₁ − ∇f‖₂².
원문은 ‖g̃(x)‖₂ ≤ B(원문에는 "‖g̃(x)‖₂² ≤ B"로 찍혀 있는데 뒤의 2B²과 맞으려면 ‖g̃‖₂ ≤ B여야 한다 [판단: 오식]) 에서 E‖g̃₁ − ∇f‖² ≤ 2B²으로 잡는다(‖a − b‖² ≤ 2‖a‖² + 2‖b‖², ‖∇f‖ = ‖E g̃‖ ≤ B). 사실 분산 ≤ 2차 모멘트이므로 B²으로 충분하다 [재구성].

**호출 수로 센 수렴률** [원문]: 오라클 호출 t번 = 반복 t/m번. 정리 6.3에 σ² = 2B²/m, 반복 수 t/m을 넣으면
R√(2B²/m)·√(2/(t/m)) + βR²/(t/m) = 2RB/√t + mβR²/t.
m ≤ (B/(Rβ))√t이면 둘째 항 ≤ RB/√t이므로 전체 ≤ 3RB/√t. 즉 **배치를 √t 규모까지 키워도 호출 수 기준 수렴률은 손해가 없다** — 잡음 항은 배치가 분산을 1/m로 줄이는 효과와 반복 수가 1/m로 주는 효과가 정확히 상쇄되고, 평활 항 βR²/(t/m)만 커지는데 그것이 √t 규모까지는 지배적이지 않기 때문이다.

**쓸모** [원문]: (i) 한 반복의 m개 기울기를 여러 처리기에 분산(중앙 장치가 xₛ를 보내고 각자 추정해 돌려보냄 — 우리 연구의 분산 학습 설정과 같은 그림), (ii) 같은 점에서 여러 기울기를 계산할 때 계산 재사용.

### 3.3 평활 함수들의 합과 강볼록: 분산 감소 (6.3절, 334–338쪽)

#### 3.3.1 문제 설정 [원문]

무제약 최소화 f(x) = (1/m)Σᵢ fᵢ(x), 각 fᵢ는 볼록·β-평활, f는 α-강볼록. 기계학습에서 α는 1/m만큼 작고 β는 상수 규모라 κ = β/α가 Ω(m)일 수 있다.
- 전체 기울기 하강: 정리 3.10으로 O(mκ log(1/ε))번 기울기 계산(반복당 m번). 가속하면 O(m√κ log(1/ε)).
- SGD: 정리 6.2로 O(1/(αε))번. 낮은 정확도엔 빠르지만 높은 정확도엔 나쁘다.
- 둘의 장점을 합친 SAG, SDCA: O((m + κ)log(1/ε)). 원문은 이 착상을 가장 투명하게 보여 주는 SVRG(Johnson–Zhang 2013)를 다룬다. 가속판 O((m + √(mκ))log(1/ε))은 열린 질문이라 적는다(2015 기준) [원문].

**핵심 직관** [원문]: 선형 수렴에는 상수 크기 걸음이 필요한데, SGD는 오라클 분산 때문에 걸음을 1/√t로 줄여야 한다. 그래서 오라클 출력을 "중심화(center)"해 분산을 줄인다: ∇fᵢ(x) 대신
vᵢ(x) = ∇fᵢ(x) − ∇fᵢ(y) + ∇f(y)
를 쓴다(y는 중심 수열). E_i vᵢ(x) = ∇f(x) − ∇f(y) + ∇f(y) = ∇f(x)이므로 여전히 불편이고, x와 y가 둘 다 최적점 근처면 ∇fᵢ(x) − ∇fᵢ(y)도 작고 ∇f(y)도 작다. 반면 ∇fᵢ(x) 자체는 최적점에서도 작지 않다(∇f(x*) = 0이지만 각 ∇fᵢ(x*)는 0이 아님). **즉 일반 SGD의 분산은 최적점에서도 사라지지 않는 상수 σ²이고, SVRG의 분산은 최적성 간극에 비례해 0으로 간다** [판단]. 이것이 분산 감소의 전부다.

#### 3.3.2 보조정리 6.4 [원문, 336쪽]

**진술.** f₁, …, f_m이 ℝⁿ 위의 β-평활 볼록 함수이고 i가 [m]에서 균등이면
E‖∇fᵢ(x) − ∇fᵢ(x*)‖₂² ≤ 2β(f(x) − f(x*)).

**증명.** gᵢ(x) := fᵢ(x) − fᵢ(x*) − ∇fᵢ(x*)ᵀ(x − x*) (= D_{fᵢ}(x, x*)).
- gᵢ는 볼록·β-평활(선형 함수를 빼도 헤세/기울기 립시츠 상수가 안 변함), ∇gᵢ(x) = ∇fᵢ(x) − ∇fᵢ(x*).
- fᵢ 볼록 ⇒ gᵢ(x) ≥ 0, gᵢ(x*) = 0. 즉 x*에서 최솟값 0.
- 2.2절 "최솟값과 기울기 크기" 따름(즉 (3.5) + gᵢ ≥ 0): 0 ≤ gᵢ(x − ∇gᵢ(x)/β) ≤ gᵢ(x) − (1/(2β))‖∇gᵢ(x)‖². 따라서
‖∇fᵢ(x) − ∇fᵢ(x*)‖² ≤ 2β(fᵢ(x) − fᵢ(x*) − ∇fᵢ(x*)ᵀ(x − x*)).
- i에 대해 평균: 오른쪽은 2β(f(x) − f(x*) − ∇f(x*)ᵀ(x − x*)), 무제약 최소점이므로 ∇f(x*) = 0. ∎

#### 3.3.3 SVRG 알고리즘 [원문, 336쪽]

y⁽¹⁾ ∈ ℝⁿ 임의. 각 단계(epoch) s = 1, 2, …: x₁⁽ˢ⁾ = y⁽ˢ⁾, ∇f(y⁽ˢ⁾)를 한 번 계산(기울기 m번). t = 1..k에 대해
x_{t+1}⁽ˢ⁾ = xₜ⁽ˢ⁾ − η(∇f_{iₜ}(xₜ⁽ˢ⁾) − ∇f_{iₜ}(y⁽ˢ⁾) + ∇f(y⁽ˢ⁾)),  iₜ⁽ˢ⁾ ~ 균등[m] 독립,
y⁽ˢ⁺¹⁾ = (1/k)Σ_{t=1}^k xₜ⁽ˢ⁾ (x₁ = y는 포함, x_{k+1}은 제외).
∇f(y)는 비싸므로(m번) 중심점은 드물게(k걸음마다) 갱신한다.

#### 3.3.4 정리 6.5 [원문, 336쪽]

**진술.** f₁..f_m이 β-평활 볼록, f가 α-강볼록. η = 1/(10β), k = 20κ인 SVRG는
E f(y⁽ˢ⁺¹⁾) − f(x*) ≤ 0.9ˢ(f(y⁽¹⁾) − f(x*)).

**증명.** 한 단계에서 E f(y⁽ˢ⁺¹⁾) − f* ≤ 0.9(f(y⁽ˢ⁾) − f*)를 보이면 귀납(탑 성질로 단계마다 조건부 기댓값을 겹침)으로 끝난다. 단계 첨자를 떼고 y, x₁ = y, vₜ = ∇f_{iₜ}(xₜ) − ∇f_{iₜ}(y) + ∇f(y)로 쓴다. 보일 것:
E f((1/k)Σxₜ) − f* ≤ 0.9(f(y) − f*).   … (6.1)

1단계 (거리 전개) [원문 (6.2)]: ‖x_{t+1} − x*‖² = ‖xₜ − x*‖² − 2ηvₜᵀ(xₜ − x*) + η²‖vₜ‖².

2단계 (분산 상한) [원문 (6.3)]: vₜ = a + b, a = ∇f_{iₜ}(xₜ) − ∇f_{iₜ}(x*), b = ∇f_{iₜ}(x*) − ∇f_{iₜ}(y) + ∇f(y)로 쪼갠다(∇f_{iₜ}(x*)를 더하고 빼기). ‖a + b‖² ≤ 2‖a‖² + 2‖b‖².
- b = −(X − EX), X := ∇f_{iₜ}(y) − ∇f_{iₜ}(x*), EX = ∇f(y) − ∇f(x*) = ∇f(y). 분산 ≤ 2차 모멘트: E‖X − EX‖² = E‖X‖² − ‖EX‖² ≤ E‖X‖².
- 보조정리 6.4를 두 번(x = xₜ, x = y):
E_{iₜ}‖vₜ‖² ≤ 2E‖a‖² + 2E‖X‖² ≤ 4β(f(xₜ) − f* + f(y) − f*).

3단계 (내적 항): E_{iₜ}vₜ = ∇f(xₜ)(불편). xₜ는 iₜ와 무관하므로 E_{iₜ}vₜᵀ(xₜ − x*) = ∇f(xₜ)ᵀ(xₜ − x*) ≥ f(xₜ) − f*(볼록성).

4단계 (합치기): 1단계에 iₜ 조건부 기댓값을 잡고 2, 3단계를 넣으면
E_{iₜ}‖x_{t+1} − x*‖² ≤ ‖xₜ − x*‖² − 2η(f(xₜ) − f*) + 4βη²(f(xₜ) − f* + f(y) − f*)
= ‖xₜ − x*‖² − 2η(1 − 2βη)(f(xₜ) − f*) + 4βη²(f(y) − f*).

5단계 (t = 1..k로 더함; 탑 성질로 전체 기댓값):
E‖x_{k+1} − x*‖² ≤ ‖x₁ − x*‖² − 2η(1 − 2βη)Σₜ E(f(xₜ) − f*) + 4βη²k(f(y) − f*).

6단계 (정리) [재구성]: 왼쪽 ≥ 0. x₁ = y이고 강볼록성으로 f(y) − f* ≥ (α/2)‖y − x*‖², 즉 ‖x₁ − x*‖² ≤ (2/α)(f(y) − f*). 따라서
2η(1 − 2βη)Σₜ E(f(xₜ) − f*) ≤ [(2/α) + 4βη²k](f(y) − f*).
양변을 2η(1 − 2βη)k로 나누고 젠센 f((1/k)Σxₜ) ≤ (1/k)Σf(xₜ):
E f((1/k)Σxₜ) − f* ≤ [1/(αη(1 − 2βη)k) + 2βη/(1 − 2βη)](f(y) − f*).

7단계 (상수 계산) [재구성]: η = 1/(10β) ⇒ 2βη = 0.2, 1 − 2βη = 0.8. k = 20κ = 20β/α ⇒ αη(1 − 2βη)k = α·(1/(10β))·0.8·(20β/α) = 1.6. 괄호 = 1/1.6 + 0.2/0.8 = 0.625 + 0.25 = 0.875 ≤ 0.9. ∎

**복잡도** [재구성]: 단계당 기울기 계산 m + 2k = m + 40κ. ε 정확도까지 단계 수 log_{1/0.9}(1/ε) = O(log(1/ε)). 합계 O((m + κ)log(1/ε)). 원문 335쪽의 SAG/SDCA 수치와 같다.

**정리 6.3과의 대비** [판단]: 정리 6.3은 분산 σ²이 상수라 √(σ²/t)보다 빠를 수 없다. SVRG는 분산 자체가 최적성 간극에 비례하도록(2단계) 추정량을 설계해 그 바닥을 없앤다. 분산 상한이 "상수"인지 "간극에 비례"하는지가 1/√t와 선형 수렴을 가른다. 우리 연구에서 압축 왜곡 D가 상수로 고정되면 정리 6.3 영역에 머문다.

### 3.4 무작위 좌표 하강 (6.4절, 338–342쪽)

설정 [원문]: f는 ℝⁿ 위에서 볼록·미분 가능, 최소점 x* (유일성은 표기 편의). ∇ᵢf = ∂f/∂xᵢ. **RCD**: x_{s+1} = xₛ − η∇_{iₛ}f(xₛ)e_{iₛ}, iₛ ~ 균등[n] (원문은 "∇_{iₛ}f(x)"로 찍혀 있으나 xₛ의 오식 [판단]).

#### 3.4.1 정리 6.6 (립시츠 경우) [원문, 338쪽]

RCD를 오라클 g̃(x) = n∇_If(x)e_I인 SGD로 본다. E g̃ = Σᵢ(1/n)n∇ᵢf eᵢ = ∇f, E‖g̃‖² = (1/n)Σᵢ n²(∇ᵢf)² = n‖∇f‖² ≤ nL². 정리 6.1을 B² = nL²로 적용하면
**진술**: f 볼록 L-립시츠, η = (R/L)√(2/(nt))이면 E f((1/t)Σxₛ) − min f ≤ RL√(2n/t).
즉 정확한 기울기 하강보다 반복이 n배 필요하다(반복당 비용이 n배 싸므로 본전) [원문].
주의 [판단]: (a) 원문은 이 절에서 R을 정의하지 않는다. 정리 6.1의 유클리드판에서 R² ≥ ½‖x₁ − x*‖²로 읽어야 한다 [미확인: 원문 정의 없음]. (b) η = (R/L)√(2/(nt))는 정리 6.1의 SGD 걸음(오라클 g̃에 곱하는 걸음)이다. RCD 식의 η(∇ᵢf에 곱하는 걸음)로 환산하면 n배인 (R/L)√(2n/t)가 된다. 원문은 두 η를 구별하지 않는다.

#### 3.4.2 정리 6.7 (좌표별 평활) [원문, 339–340쪽]

**좌표별 평활성** [원문]: |∇ᵢf(x + ueᵢ) − ∇ᵢf(x)| ≤ βᵢ|u|. 두 번 미분 가능하면 (∇²f)ᵢᵢ ≤ βᵢ. 최대 고윳값 ≤ 대각합이므로 f는 β ≤ Σβᵢ인 β-평활.
**RCD(γ)** [원문, Nesterov 2012]: x_{s+1} = xₛ − (1/β_{iₛ})∇_{iₛ}f(xₛ)e_{iₛ}, iₛ ~ p_γ(i) = βᵢ^γ/Σⱼβⱼ^γ. 노름 ‖x‖_{[γ]} = √(Σβᵢ^γxᵢ²), 쌍대 ‖x‖*_{[γ]} = √(Σxᵢ²/βᵢ^γ). S_γ := Σβᵢ^γ.

**진술**: t ≥ 2에서 E f(xₜ) − f* ≤ 2R²_{1−γ}(x₁)S_γ/(t − 1), R_{1−γ}(x₁) = sup_{x: f(x)≤f(x₁)} ‖x − x*‖_{[1−γ]}.

**증명** [원문 + 재구성].
1. u ↦ f(x + ueᵢ)는 βᵢ-평활 1변수 함수이므로 (3.5): f(x − (1/βᵢ)∇ᵢf(x)eᵢ) − f(x) ≤ −(∇ᵢf(x))²/(2βᵢ).
2. iₛ에 대한 기댓값: E[f(x_{s+1}) − f(xₛ) | xₛ] ≤ −Σᵢ p_γ(i)(∇ᵢf)²/(2βᵢ) = −(1/(2S_γ))Σᵢ βᵢ^{γ−1}(∇ᵢf)² = −(1/(2S_γ))(‖∇f(xₛ)‖*_{[1−γ]})².
3. 1에서 매 걸음 f(x_{s+1}) ≤ f(xₛ)(확실히)이므로 모든 xₛ가 수준집합 {f ≤ f(x₁)}에 머문다. 볼록성과 횔더(‖·‖_{[1−γ]}와 ‖·‖*_{[1−γ]}는 쌍대 쌍): f(xₛ) − f* ≤ ∇f(xₛ)ᵀ(xₛ − x*) ≤ R_{1−γ}(x₁)‖∇f(xₛ)‖*_{[1−γ]}.
4. δₛ := E f(xₛ) − f*. 3을 제곱하고 기댓값 + 젠센(E Z² ≥ (EZ)²): E(‖∇f(xₛ)‖*)² ≥ δₛ²/R². (원문은 이 젠센 단계를 생략 [재구성].) 2에 넣으면 δ_{s+1} ≤ δₛ − δₛ²/(2R²S_γ).
5. 정리 3.3의 논법(2.6절)으로 1/δₜ ≥ (t − 1)/(2R²S_γ). ∎
**의미** [원문]: 기울기 하강은 β‖x₁ − x*‖²/t, β ≤ Σβᵢ. β가 Σβᵢ와 같은 규모인 함수에서는 RCD(1)이 같은 반복 수로 같은 정확도를 내면서 반복당 비용은 n배 싸다.

#### 3.4.3 정리 6.8 (좌표별 평활 + 강볼록) [원문, 341쪽]

**보조정리 6.9**: f가 ‖·‖에 대해 α-강볼록이면 f(x) − f* ≤ (1/(2α))‖∇f(x)‖²_*.
증명: 강볼록 정의와 횔더로 f(x) − f(y) ≤ ‖∇f(x)‖_*z − (α/2)z², z = ‖x − y‖ (원문의 ‖x − y‖₂²는 ‖x − y‖²의 오식 [판단]). z에 대한 2차식의 최댓값 ‖∇f‖²_*/(2α). y = x*. ∎
**진술**: f가 ‖·‖_{[1−γ]}에 대해 α-강볼록, 좌표별 βᵢ-평활, κ_γ = S_γ/α이면 E f(x_{t+1}) − f* ≤ (1 − 1/κ_γ)ᵗ(f(x₁) − f*).
증명: 3.4.2의 2단계에 보조정리 6.9(쌍대 노름 ‖·‖*_{[1−γ]})를 넣으면 (‖∇f(xₛ)‖*)² ≥ 2α(f(xₛ) − f*); 이번엔 선형이라 젠센 불필요. δ_{s+1} ≤ δₛ − 2αδₛ/(2S_γ) = (1 − 1/κ_γ)δₛ. 반복. ∎

### 3.5 안장점 문제의 무작위 가속 (6.5절, 342–343쪽)

설정 [원문, 5.2.1절]: X, Y 콤팩트 볼록, φ(·, y) 볼록·φ(x, ·) 오목. 목표 min_x max_y φ. 후보 (x̃, ỹ)의 질은 쌍대 간극(duality gap) max_y φ(x̃, y) − min_x φ(x, ỹ). 핵심: z = (x, y), g(z) = (g_X, g_Y), g_X ∈ ∂ₓφ, g_Y ∈ ∂_y(−φ)이면 간극 ≤ g(z̃)ᵀ(z̃ − z) (5.3)이라 Z 공간에서 미러 하강을 돌릴 수 있다. SP-MD는 미러 맵 Φ(z) = aΦ_X(x) + bΦ_Y(y)로 Z에서 MD를 한다.

**확률적 오라클** [원문]: g̃(z) = (g̃_X, g̃_Y), E(g̃_X | x, y) ∈ ∂ₓφ, E(g̃_Y | x, y) ∈ ∂_y(−φ). 이것으로 SP-MD를 돌린 것이 S-SP-MD.

**정리 6.10** [원문]: E(‖g̃_X‖*_X)² ≤ B_X², E(‖g̃_Y‖*_Y)² ≤ B_Y²이면 a = B_X/R_X, b = B_Y/R_Y, η = √(2/t)인 S-SP-MD는
E[max_y φ((1/t)Σxₛ, y) − min_x φ(x, (1/t)Σyₛ)] ≤ (R_XB_X + R_YB_Y)√(2/t).
증명 골자 [원문: "6.1절과 5.2.2절의 같은 추론"; 재구성]: ‖z‖_Z = √(a‖x‖²_X + b‖y‖²_Y)에 대해 Φ는 1-강볼록, ‖g‖*_Z² = (‖g_X‖*)²/a + (‖g_Y‖*)²/b이므로 E‖g̃‖*_Z² ≤ B_X²/a + B_Y²/b = B_XR_X + B_YR_Y. Z에서의 R² = aR_X² + bR_Y² = R_XB_X + R_YB_Y. 정리 6.1(쌍대 간극을 f(평균) − f* 자리에, (5.3)을 부분기울기 부등식 자리에)을 적용하면 √(R²·B²)√(2/t) = (R_XB_X + R_YB_Y)√(2/t). 주의: 쌍대 간극의 max_y가 기댓값 안에 있어, 6.1절의 "고정된 x" 논법을 그대로 쓰려면 경로별 부등식 (4.10)에서 sup을 먼저 잡아야 하는데 그때 잡음 항 Σ(g̃ₛ − gₛ)ᵀ(zₛ − z)의 sup은 기댓값이 0이 아니다. 원문은 이 점을 다루지 않는다 [미확인: 표준적으로는 "유령 반복(ghost iterate)" 논법으로 상수배 손실만 생긴다고 알려져 있으나 이 장에는 증명 없음].

**행렬 게임** [원문]: x ∈ Δₙ, y ∈ Δ_m, φ = xᵀAy, ∇ₓφ = Ay, ∇_yφ = Aᵀx. 오라클: g̃_X = A_I, I ~ y (E = Σyᵢ Aᵢ = Ay) (6.4); g̃_Y(i) = Aᵢ(J), J ~ x (E = Σⱼ xⱼAᵢ(j) = (Aᵀx)(i)) (6.5). ‖g̃‖_∞ ≤ ‖A‖_max (원문은 둘째도 g̃_X로 찍힘 — g̃_Y의 오식 [판단]). 음엔트로피 미러 맵으로 R² ~ log n이므로 O(‖A‖²_max log(n + m)/ε²)번 반복, 반복당 O(n + m). 전체 Õ((n + m)/ε²)로 행렬 크기 nm보다 작다(부선형) — Grigoriadis–Khachiyan 1995 [원문].
**선형 분류** [원문, 343쪽 이미지 대조]: x ∈ B_{2,n}, y ∈ Δ_m. x-오라클은 (6.4) 그대로, y-오라클은 g̃_Y(i) = (‖x‖₂²/x(J))Aᵢ(J), J ~ x²/‖x‖₂² ∈ Δₙ (x²(i) = x(i)²; 원문 분모의 소문자 j는 J의 오식 [판단]). 불편성: E = Σⱼ (x(j)²/‖x‖²)(‖x‖²/x(j))Aᵢ(j) = Σⱼ x(j)Aᵢ(j) = (Aᵀx)(i). 2차 모멘트: E‖g̃_Y‖²_∞ = Σⱼ (x(j)²/‖x‖²)maxᵢ(‖x‖²Aᵢ(j)/x(j))² = ‖x‖²Σⱼ maxᵢAᵢ(j)² ≤ Σⱼ maxᵢAᵢ(j)² (‖x‖ ≤ 1). 이 값은 O(n)일 수 있어, "국소 노름(local norm)" 분석으로 "국소 분산"이 차원 무관함을 보인다고 참고문헌(Bubeck–Cesa-Bianchi 2012, Clarkson et al. 2012)에 미룬다 [원문].

### 3.6 볼록 완화와 무작위 반올림 (6.6절, 343–347쪽)

**MAXCUT** [원문]: A ∈ ℝ₊^{n×n} 대칭 가중치. 목표 max_{x∈{−1,1}ⁿ} ½Σᵢⱼ Aᵢⱼ(xᵢ − xⱼ)² (6.6) = max xᵀLx (6.7), L = D − A (그래프 라플라시안). NP-난해. 확인 [재구성]: xᵢ² = 1이면 xᵀLx = ΣᵢDᵢᵢ − ΣAᵢⱼxᵢxⱼ = ΣᵢⱼAᵢⱼ(1 − xᵢxⱼ) = ½ΣAᵢⱼ(xᵢ − xⱼ)². (6.6)의 값은 잘린 가중치 합의 4배다(상수배는 무관).

**무작위 1/2 근사** [원문]: ζ ~ 균등{−1,1}ⁿ이면 Eζᵢζⱼ = 0 (i ≠ j), 1 (i = j)이라 EζᵀLζ = Σ_{i≠j}Aᵢⱼ ≥ ½max xᵀLx (최대값은 많아야 Σ_{i≠j}Aᵢⱼ·2). 또 Y := ζᵀLζ/OPT ∈ [0,1], EY ≥ ½이면 ½ ≤ EY ≤ P(Y ≥ ½ − ε) + (½ − ε) ⇒ P(Y ≥ ½ − ε) ≥ ε [재구성].

**고만스–윌리엄슨(Goemans–Williamson)** [원문]: max xᵀLx = max ⟨L, xxᵀ⟩ ≤ max_{X⪰0, Xᵢᵢ=1} ⟨L, X⟩ (SDP 완화, 내부점법으로 풂).
**정리 6.11**: Σ = SDP 해, ξ ~ N(0, Σ), ζ = sign(ξ) ⇒ EζᵀLζ ≥ 0.878·max xᵀLx.
**보조정리 6.12**: Σᵢᵢ = 1이면 Eζᵢζⱼ = (2/π)arcsin(Σᵢⱼ).
증명: Σ = VVᵀ, ‖Vᵢ‖ = 1, ξ = Vε, ε ~ N(0, I). ζᵢ = sign(Vᵢᵀε). Eζᵢζⱼ = P(같은 부호) − P(다른 부호) = 1 − 2P(다른 부호). ε의 방향은 구면 균등이므로 Vᵢ, Vⱼ를 가르는 무작위 초평면의 확률 = θ/π, θ = arccos(VᵢᵀVⱼ) = arccos Σᵢⱼ. 따라서 1 − 2θ/π = (2/π)(π/2 − arccos Σᵢⱼ) = (2/π)arcsin Σᵢⱼ. ∎ (원문은 조건부 확률 P(Vⱼᵀε < 0 | Vᵢᵀε ≥ 0) = θ/π로 같은 계산을 한다.)
정리 6.11 증명: Xᵢᵢ = 1이면 ⟨L, X⟩ = ΣAᵢⱼ(1 − Xᵢⱼ). 보조정리 6.12로 EζᵀLζ = ΣAᵢⱼ(1 − (2/π)arcsin Σᵢⱼ). 부등식 (6.8) 1 − (2/π)arcsin t ≥ 0.878(1 − t) (t ∈ [−1,1])와 Aᵢⱼ ≥ 0으로 ≥ 0.878ΣAᵢⱼ(1 − Σᵢⱼ) = 0.878·SDP ≥ 0.878·OPT. ∎
(6.8)의 근거 [재구성]: 1 − (2/π)arcsin t = (2/π)arccos t. t = cos θ로 두면 (6.8) ⇔ (2/π)θ/(1 − cos θ) ≥ 0.878, θ ∈ (0, π]. 수치로 최솟값 ≈ 0.87857 (θ ≈ 2.33)임을 확인했다.

**정리 6.13 (Nesterov 1997)** [원문]: 임의의 B ⪰ 0, max_{x∈{±1}ⁿ} xᵀBx (6.9). 같은 반올림으로 EζᵀBζ ≥ (2/π)max xᵀBx.
증명: EζᵀBζ = (2/π)⟨B, arcsin(Σ)⟩ (원문은 arcsin(X)로 찍힘 — Σ의 오식 [판단]; arcsin은 성분별). arcsin(Σ) − Σ = Σ_{k≥1} c_k Σ^{∘(2k+1)}, c_k = C(2k,k)/(4ᵏ(2k + 1)) > 0 (테일러 급수, |Σᵢⱼ| ≤ 1). 슈어 곱 정리(Schur product theorem): A, B ⪰ 0 ⇒ A∘B ⪰ 0 (A = VVᵀ, B = UUᵀ면 (A∘B)ᵢⱼ = ⟨VᵢUᵢᵀ, VⱼUⱼᵀ⟩인 그람 행렬). 따라서 Σ^{∘(2k+1)} ⪰ 0, arcsin(Σ) ⪰ Σ. B ⪰ 0, M ⪰ 0 ⇒ ⟨B, M⟩ ≥ 0이므로 ⟨B, arcsin Σ⟩ ≥ ⟨B, Σ⟩ = SDP ≥ OPT. ∎

### 3.7 무작위 보행 기반 방법 (6.7절, 347–349쪽)

[원문, 요약 수준] 무게중심법(center of gravity method, 2.1절)은 매 단계 현재 집합 Sₜ의 무게중심 cₜ에서 자르면 부피가 상수비로 준다. 정확한 cₜ 계산이 어려우므로 Bertsimas–Vempala 2004는 균등 표본 X₁..X_N의 평균 ĉₜ로 대체한다.
- **보조정리 6.14**: K가 등방 위치(isotropic position: EX = 0, EXXᵀ = Iₙ)이면 모든 w ≠ 0, z에서 Vol(K ∩ {(x − z)ᵀw ≥ 0}) ≥ (1/e − ‖z‖₂)Vol(K). 즉 무게중심에서 조금(‖z‖ 작게) 벗어나 잘라도 상수비 부피 감소가 유지된다. (증명은 이 장에 없음 [원문].)
- 표본 평균의 오차 [원문 + 재구성]: 등방이면 Cov X = I, E‖cₜ − ĉₜ‖² = tr(I)/N = n/N. 마르코프(원문 "체비쇼프") 부등식으로 P(‖cₜ − ĉₜ‖ > 0.1) ≤ 100n/N. N = O(n)이면 상수 비율의 단계에서 진전.
- 등방화: Σ̂ₜ = 표본 공분산, Ñ = Ω̃(n)이면 높은 확률로 Σ̂ₜ^{−1/2}(Sₜ − ĉₜ)가 근사 등방(½I ⪯ EXXᵀ ⪯ (3/2)I) — Rudelson 1999.
- 표본 추출: 히트-앤-런(hit-and-run) 보행. 균등분포에 "충분히 가까운" 시작점에서 O(n³)걸음 뒤 총변동 거리 ε 이내(Lovász 1998). 이전 단계 분포를 다음 단계 초기 분포로 재사용. S₁ = [−L, L]ⁿ에서 시작하고 ĉₜ ∉ X이면 분리 오라클 사용(타원체법처럼).
- 합계 [원문, 비형식적]: 반복 Õ(n), 반복당 표본 Õ(n), 표본당 보행 Õ(n³) ⇒ 분리/1차 오라클 Õ(n)번, 보행 Õ(n⁵)걸음.

## 4. 손으로 해 볼 연습문제

**연습 1 (분산 ≤ 2차 모멘트, 미니배치 분산).** (a) 확률벡터 X에 대해 E‖X − EX‖² = E‖X‖² − ‖EX‖²임을 보여라. (b) X에 조건부로 독립이고 E[eᵢ|x] = 0인 e₁..e_m에 대해 E‖(1/m)Σeᵢ‖² = (1/m²)ΣE‖eᵢ‖²임을 보여라.
*답*: (a) ‖X − EX‖² = ‖X‖² − 2XᵀEX + ‖EX‖², 기댓값을 잡으면 가운데가 −2‖EX‖². (b) 전개하면 교차항 E eᵢᵀeⱼ = E[E(eᵢ|x, eⱼ)ᵀeⱼ] = 0 (i ≠ j, 조건부 독립과 평균 0). 대각항만 남는다.

**연습 2 (정리 6.3의 일반 η판과 두 극한).** 증명 9단계까지 따라가 임의의 η > 0에 대해 E f(평균) − f* ≤ βR²/t + R²/(ηt) + ησ²/2를 유도하라. (a) σ = 0이면 η → ∞로 βR²/t(평균점에 대한 결정적 평활 하강률)가 됨을, (b) β = 0 꼴로 보면 정리 6.1과 같은 √(1/t) 구조임을 확인하라. (c) η를 최적화하라.
*답*: (a) 걸음 1/(β + 1/η) → 1/β, 잡음 항 0. (c) R²/(ηt) = ησ²/2 ⇒ η = (R/σ)√(2/t), 값 Rσ√(2/t). 교훈: σ²은 √로만 들어간다 — 분산을 4배 줄이면 잡음 항이 2배 준다.

**연습 3 (편향이 있으면 어디가 깨지나).** 정리 6.3의 가정에서 불편성만 E(g̃ₛ|Fₛ) = ∇f(xₛ) + bₛ, ‖bₛ‖_* ≤ ζ로 바꾸고, ‖x − x*‖ ≤ Δ (모든 x ∈ X)라 하자. 분산 가정은 E‖g̃ₛ − ∇f(xₛ)‖²_* ≤ σ²(편향 포함)로 둔다. 상한에 ζΔ가 더해짐을 보여라.
*답*: 증명 8단계에서 E[(g̃ₛ − ∇f(xₛ))ᵀ(x* − xₛ)] = E[bₛᵀ(x* − xₛ)] ≤ ζΔ (횔더). 나머지는 그대로이므로 Σ에 tζΔ, t로 나누면 +ζΔ. 이 항은 η·t를 어떻게 골라도 줄지 않는다 [재구성]. (부록의 "이웃으로 수렴" 현상의 볼록판.)

**연습 4 (1차원에서 잡음 바닥 vs 편향 바닥).** f(x) = x²/2 (β = α = 1, x* = 0), 상수 걸음 γ ∈ (0, 1).
(a) g̃ = x + n, E n = 0, E n² = σ² (독립)이면 aₜ := E xₜ²가 a_{t+1} = (1 − γ)²aₜ + γ²σ²를 만족하고 a_∞ = γσ²/(2 − γ)임을 보여라.
(b) g̃ = x + b (상수 b)이면 xₜ → −b임을 보여라.
*답*: (a) x_{t+1} = (1 − γ)xₜ − γn, 교차항 기댓값 0(n은 xₜ와 독립). 고정점 a = γ²σ²/(1 − (1 − γ)²) = γσ²/(2 − γ). γ → 0이면 0. (b) x_{t+1} + b = (1 − γ)(xₜ + b)이므로 xₜ + b → 0. **극한 −b는 γ와 무관**하다. 잡음은 γ²으로 들어가 γ를 줄이면 사라지고, 편향은 γ와 같은 차수로 들어가 고정점 자체를 옮긴다.

**연습 5 (보조정리 6.4의 등호 사례와 SGD 분산 바닥).** fᵢ(x) = ½‖x − aᵢ‖² (β = 1), ā = (1/m)Σaᵢ. (a) 보조정리 6.4의 양변을 계산해 등호임을 보여라. (b) 최적점에서 일반 SGD 오라클의 분산 E‖∇fᵢ(x*)‖²과 SVRG 오라클의 분산(y = x*일 때)을 비교하라.
*답*: (a) x* = ā, 왼쪽 E‖(x − aᵢ) − (ā − aᵢ)‖² = ‖x − ā‖², 오른쪽 2(f(x) − f(ā)) = ‖x − ā‖² (f(x) = f(ā) + ½‖x − ā‖²). (b) SGD: E‖ā − aᵢ‖² = aᵢ들의 산포(≠ 0). SVRG: vᵢ(x*) = (x* − aᵢ) − (x* − aᵢ) + 0 = 0, 분산 0.

**연습 6 (감산 디더 양자화의 불편성).** 스칼라 균일 양자화기 Q(v) = Δ·round(v/Δ), U ~ Unif[−Δ/2, Δ/2)를 X와 독립으로 뽑아 X̂ = Q(X + U) − U로 둔다. (a) E[X̂ | X = x] = x, (b) E[(X̂ − X)² | X = x] = Δ²/12임을 보여라.
*답*: (a) x = kΔ + r (0 ≤ r < Δ)로 쓰면 Q(x + U) = (k + 1)Δ ⇔ U ≥ Δ/2 − r, 확률 r/Δ; 아니면 kΔ. E Q(x + U) = kΔ + r = x, E U = 0. (b) X̂ − x = Q(V) − V, V = x + U는 길이 Δ인 구간 위 균등. 톱니 함수 Q(v) − v는 주기 Δ이고 한 주기에서 [−Δ/2, Δ/2)를 한 번씩 훑으므로 Q(V) − V ~ Unif[−Δ/2, Δ/2), 분산 Δ²/12 (x와 무관). 자세한 일반론은 `derivations/classic/16_Schuchman1964.md`.

## 5. 자주 헷갈리는 점

1. **B² 와 σ²**: 정리 6.1·6.2는 2차 모멘트 E‖g̃‖² ≤ B², 정리 6.3은 분산 E‖g̃ − ∇f‖² ≤ σ². 불편이면 E‖g̃‖² = ‖∇f‖² + 분산이라 B² ≥ σ². 압축 왜곡 D = E‖X̂ − X‖²는 (참 기울기 X 기준) 분산 쪽에 해당한다.
2. **정리 6.3의 η는 걸음이 아니다.** 걸음은 1/(β + 1/η). Zhang et al.은 이것을 γ/(β + 1)로 잘못 옮겼다(3.2.4).
3. **평균 범위**: 정리 6.3은 x₂..x_{t+1}, 정리 6.1은 x₁..xₜ의 평균. 마지막 반복점(last iterate)에 대한 보장이 아니다.
4. **R은 거리가 아니다.** R² = sup Φ − Φ(x₁)이고 증명이 쓰는 것은 D_Φ(x*, x₁) ≤ R². 유클리드에서 D_Φ = ½‖·‖²이므로 R ≥ ‖x₁ − x*‖/√2면 충분하다.
5. **불편성은 조건부여야 한다.** E g̃(xₛ) = E∇f(xₛ)(무조건부)로는 부족하고 E(g̃ₛ|과거) = ∇f(xₛ)가 필요하다. 데이터 재사용, 과거에 의존하는 압축 오차(예: 오차 피드백, error feedback)가 이것을 깨뜨린다.
6. **탑 성질을 쓸 수 있는 곳과 없는 곳**: (g̃ₛ − ∇f)ᵀ(x* − xₛ)는 기댓값 0, (g̃ₛ − ∇f)ᵀ(x_{s+1} − xₛ)는 아니다(x_{s+1}이 g̃ₛ에 의존). 후자를 영의 부등식으로 처리하는 대가가 ησ²/2 항이다.
7. **반복 수 vs 오라클 호출 수**: 미니배치 m은 반복당 분산을 1/m로 줄이지만 호출 t번 기준 반복은 t/m번. 호출 기준 잡음 항은 변하지 않는다(3.2.5).
8. **선형 수렴은 분산이 간극에 비례할 때만**: 분산 상한이 상수면(정리 6.3) σ/√t가 바닥이다. SVRG는 분산이 4β(간극)로 줄어들게 설계해서 선형 수렴한다. 압축 왜곡을 고정 D로 두는 한 선형 수렴은 기대할 수 없다.
9. **잡음과 편향의 차수**: 평균 0 잡음은 한 걸음 진전식에 γ²으로, 편향은 γ로 들어간다(부록, 연습 4). 그래서 걸음을 줄이면 잡음은 사라지지만 편향 바닥은 남는다.
10. **"정리 6.2"의 E 누락, 정리 6.6의 R 미정의, RCD 식의 x/xₛ** 등은 원문 오식이다(본문 해당 절).

## 6. 본 연구와의 연결

- [판단] 우리 압축 기울기 추정량 X̂가 E[X̂ | X, 과거] = X(조건부 불편)를 만족하고 왜곡 D = E‖X̂ − X‖²이면, 서버가 쓰는 ĝ = X̂는 참 기울기 ∇F(w)에 대해 분산 ≤ σ²_SGD/B + D인 불편 오라클이다(미니배치 잡음과 압축 오차가 서로 조건부 무상관이면 분산이 더해짐 — 연습 1의 논법). Zhang et al.처럼 X를 전역 기울기로 잡으면 σ² = D.
- [판단] 정리 6.3에 σ² = D를 넣으면 E F(평균 w) − F* ≤ A√(2D/T) + βA²/T (R = A, 걸음 1/(β + 1/γ)). D는 √D로만 들어가고, 평활 항 βA²/T는 D와 무관하다. 목표 ε에 필요한 T는 두 항을 각각 ε/2 이하로 두면 T ≥ max{8A²D/ε², 2βA²/ε}면 충분하다 — D가 작아질수록 T가 D에 선형으로 준다(Zhang 식 (23)과 같은 구조).
- [판단] 불편성이 사는 것: 증명 8단계의 교차항이 정확히 0이 되어, 압축 오차가 "분산"으로만 들어가고 걸음·T로 없앨 수 없는 바닥(연습 3의 ζΔ)이 생기지 않는다. 대가는 없다 — 단, D에 편향 성분이 섞이면 정리 6.3을 그대로 쓸 수 없다.
- [판단] 감산 디더 양자화 X̂ = Q(X + U) − U는 공유 난수 U만 있으면 Q의 형태와 무관하게(격자 양자화로도) E[X̂|X] = X, 오차가 X와 독립인 균등 잡음이 된다(연습 6, Schuchman 1964·Zamir–Feder 1992 노트). 따라서 정리 6.3의 가정을 정확히 충족하는 압축기의 표준 예다.
- [판단] 주의: 율–왜곡 최적(MMSE) 복원은 일반적으로 축소(shrinkage) 편향을 가진다. 가우스 시험 채널에서 E[X̂|X] = cX, c = 1 − D/σ²_X. 1/c로 다시 늘리면 불편해지지만 왜곡이 D_u = D/c = Dσ²_X/(σ²_X − D)로 커진다. 이 관계는 σ²_X/D_u = σ²_X/D − 1, 즉 ½log(1 + σ²_X/D_u) = ½log(σ²_X/D)와 같으며, Zhang et al.이 불편 제약 (10) E[X̂ⁿ|Xⁿ = xⁿ] = xⁿ을 명시하고 고전적 ½log(σ²_X/D)를 ½log(1 + σ²_X/D)로 조인 것(Zhang 14–15쪽, Remark 2)과 정확히 맞는다 [원문(Zhang) + 재구성]. 축소 편향 자체는 부록 A.5에서 보듯 "걸음을 줄이는 것"과 같아 바닥을 만들지 않으므로, 불편 제약이 율 측면에서 꼭 필요한지는 따져 볼 질문이다(재조정 1/c를 서버 걸음에 흡수하면 ½log(σ²_X/D) 율로 같은 경로를 얻는다 — 단 c가 알려진 상수일 때) [판단].

## 부록: 편향된 그래디언트 (Ajalloeian–Stich 2020)

### A.1 설정 [원문, 2–3쪽]

- 무제약 f* = min_{x∈ℝᵈ} f(x), 반복 x_{t+1} = xₜ − γₜgₜ, gₜ = ∇f(xₜ) + bₜ + nₜ (식 (2)).
- **정의 1 (편향된 기울기 오라클)**: g(x, ξ) = ∇f(x) + b(x) + n(x, ξ), E_ξ n(x, ξ) = 0. 편향 b(x)는 x의 결정적 함수.
- **가정 1 (L-평활)**: f(y) ≤ f(x) + ⟨∇f(x), y − x⟩ + (L/2)‖y − x‖² (3). 볼록성은 가정하지 않는다.
- **가정 2 (μ-PL, Polyak–Łojasiewicz)**: ‖∇f(x)‖² ≥ 2μ(f(x) − f*) (4). μ-강볼록이면 성립(보조정리 6.9와 같은 식).
- **가정 3 ((M, σ²)-유계 잡음)**: E_ξ‖n(x, ξ)‖² ≤ M‖∇f(x) + b(x)‖² + σ².
- **가정 4 ((m, ζ²)-유계 편향)**: ‖b(x)‖² ≤ m‖∇f(x)‖² + ζ², 0 ≤ m < 1, ζ² ≥ 0.
  - m: 기울기에 비례하는 "상대" 편향(기울기가 0이면 같이 0). ζ²: 기울기와 무관한 "절대" 편향.
- 주의 [판단]: Bubeck 6장과 달리 볼록·제약·함숫값 평균이 아니라 비볼록·무제약·기울기 노름(또는 PL 아래 함숫값)을 다룬다. 정리 6.3의 편향판을 직접 주지는 않는다.

### A.2 핵심 보조정리 2 (수정된 하강 보조정리) [원문, 3–4쪽; 증명 A.1절, 11쪽]

**진술.** γ ≤ 1/((M + 1)L)이면
E_ξ[f(x_{t+1}) − f(xₜ) | xₜ] ≤ (γ(m − 1)/2)‖∇f(xₜ)‖² + (γ/2)ζ² + (γ²L/2)σ².   … (5)

**증명** [원문, 단계 주석은 재구성]. g := gₜ, E g = ∇f + b.
1. 평활 (3)에 y = x − γg: f(x_{t+1}) ≤ f(xₜ) − γ⟨∇f, g⟩ + (γ²L/2)‖g‖². 기댓값: E⟨∇f, g⟩ = ⟨∇f, ∇f + b⟩ (잡음 평균 0), E‖g‖² = ‖∇f + b‖² + E‖n‖² (연습 1(a)).
2. 가정 3: E‖g‖² ≤ (M + 1)‖∇f + b‖² + σ².
3. γ ≤ 1/((M + 1)L) ⇒ (γ²L/2)(M + 1) ≤ γ/2:
E f(x_{t+1}) ≤ f(xₜ) + (γ/2)(−2⟨∇f, ∇f + b⟩ + ‖∇f + b‖²) + (γ²L/2)σ².
4. 괄호 = −2‖∇f‖² − 2⟨∇f, b⟩ + ‖∇f‖² + 2⟨∇f, b⟩ + ‖b‖² = −‖∇f‖² + ‖b‖².
5. 가정 4: ‖b‖² ≤ m‖∇f‖² + ζ². 대입하면 (5). ∎

### A.3 주정리들 [원문, 4쪽]

- **보조정리 3 (비볼록, 기울기 노름)**: γ ≤ 1/((M + 1)L)이면 Ψ_T := (1/T)Σ_{t=0}^{T−1}E‖∇f(xₜ)‖² ≤ 2F₀/(Tγ(1 − m)) + γLσ²/(1 − m) + ζ²/(1 − m), F₀ = f(x₀) − f*.
  증명: (5)를 Fₜ := E f(xₜ) − f*로 쓰면 ((1 − m)/2)E‖∇f(xₜ)‖² ≤ (Fₜ − F_{t+1})/γ + ζ²/2 + γLσ²/2. t에 대해 평균하면 망원급수, F_T ≥ 0. ∎
- **정리 4**: γ = min{1/((M + 1)L), (ε(1 − m) + ζ²)/(2Lσ²)}이면 T = O((M + 1)/(ε(1 − m) + ζ²) + σ²/(ε²(1 − m)² + ζ⁴))·LF₀번으로 Ψ_T = O(ε + ζ²/(1 − m)).
- **정리 6 (PL)**: (5)와 (4)로 F_{t+1} ≤ (1 − γμ(1 − m))Fₜ + γζ²/2 + γ²Lσ²/2 (6). 풀면
F_T ≤ (1 − γμ(1 − m))ᵀF₀ + ½Ξ, Ξ := ζ²/(μ(1 − m)) + γLσ²/(μ(1 − m)) (7).
  (기하급수 합 Σ(1 − a)ⁱ ≤ 1/a, a = γμ(1 − m).) 적절한 γ로 T = Õ(((M + 1)log(1/ε) + σ²/(εμ(1 − m) + ζ²))·κ/(1 − m))번이면 F_T = O(ε + ζ²/(μ(1 − m))).
- **Remark 5 (바닥의 엄밀성)**: g(x) = ∇f(x) + ρ(x)b, ‖b‖² = ζ², ρ(x)² = 1 + (m/ζ²)‖∇f(x)‖²는 (m, ζ²)-유계 편향이고, 이 오라클의 정지점(g = 0)에서 ‖∇f‖² = ζ²/(1 − m). 즉 보조정리 3의 바닥 ζ²/(1 − m)은 개선 불가.
- **Example 8 (볼록 함수에서 발산)**: 후버 손실 h(x) = |x| (|x| > 1), x²/2 + 1/2 (|x| ≤ 1), 오라클 h′(x) − 2 (ζ² ≤ 4). x₀ > 1이면 h′ = 1이라 g = −1, 매 걸음 x가 γ씩 커져 어떤 γ > 0에서도 발산. 기울기 노름은 1로 유계지만 함숫값은 무한대로. 볼록·비강볼록이면 편향이 "이웃"이 아니라 발산을 낳을 수 있다.

### A.4 왜 편향은 이웃으로, 평균 0 잡음은 최적점으로 가는가 [원문 논지 + 재구성]

(5)를 γ로 나눈 "단위 걸음당 진전"으로 보면:
- 평균 0 잡음은 1차 항에서 E⟨∇f, n⟩ = 0으로 사라지고, 2차 항 (γ²L/2)E‖n‖²로만 남는다. γ로 나누면 γLσ²/2 → 0 (γ → 0). 걸음을 줄이거나(또는 T에 맞춰 γ ~ 1/√T) 평균을 내면 없어진다. 여러 걸음에 걸친 잡음은 서로 상쇄된다(분산이 √ 속도로만 누적).
- 편향은 1차 항 −γ⟨∇f, b⟩에 남는다. 같은 방향으로 매 걸음 누적되므로 상쇄가 없다. γ로 나눠도 ζ²/2가 남아 **γ와 T에 무관한 바닥**이 된다. 기하학적으로는 기대 동역학의 고정점이 ∇f(x) + b(x) = 0인 점으로 옮겨지고, 거기서 ‖∇f‖² ≈ ‖b‖² ~ ζ²/(1 − m)이다(Remark 5, 연습 4(b)).
- 상대 편향(ζ² = 0, m < 1)은 바닥을 만들지 않는다: ‖b‖ ≤ √m‖∇f‖ < ‖∇f‖이므로 ⟨∇f, ∇f + b⟩ ≥ (1 − √m)‖∇f‖² > 0 — 기대 방향이 여전히 하강 방향이고, 기울기가 0으로 가면 편향도 0으로 간다. 대가는 반복 수가 1/(1 − m) (잡음 지배 시 1/(1 − m)²)배 [원문, 4쪽].
- Bubeck 정리 6.3 쪽에서 보면 연습 3의 +ζΔ가 같은 현상의 볼록판이다 [재구성].

### A.5 특수 경우: 곱셈 축소 편향 ĝ = c·g (0 < c < 1)

[재구성] g = ∇f(x) + n (불편, 가정 3을 (M′, σ′²)로 만족)이고 ĝ = c·g라 하자.
- **틀에 들어가는가**: ĝ = ∇f + b + ñ, b = (c − 1)∇f, ñ = c·n. ‖b‖² = (1 − c)²‖∇f‖²이므로 **m = (1 − c)² < 1, ζ² = 0** — 가정 4를 만족(c ∈ (0, 2)이면 모두). 잡음: E‖cn‖² ≤ c²(M′‖∇f‖² + σ′²) = M′‖∇f + b‖² + c²σ′² (∇f + b = c∇f), 즉 M = M′, σ² = c²σ′². 따라서 ζ² = 0이라 바닥 없이 정지점(PL이면 최적값)으로 수렴한다.
- **더 정확한 해석: 걸음이 줄어든 것일 뿐이다.** x − γ·cg = x − (cγ)g이므로 걸음 cγ인 불편 SGD와 **경로가 완전히 같다.** 틀이 말하는 감속 1/(1 − m) = 1/(c(2 − c))도 이것과 맞는다: 걸음 cγ, γ = 1/L인 결정적 하강의 정확한 한 걸음 감소량은 cγ(1 − cγL/2)‖∇f‖² = (γ/2)·c(2 − c)‖∇f‖²로, (5)의 계수 (γ/2)(1 − m)과 같다 [재구성]. 즉 이 경우 Ajalloeian–Stich의 상수는 느슨하지 않고, 바닥은 없다.
- **정리 6.3과 연결** [재구성]: 걸음 cγ_B (γ_B = 1/(β + 1/η))를 정리 6.3의 꼴 1/(β + 1/η′)로 다시 쓰면 1/η′ = (β + 1/η)/c − β = β(1/c − 1) + 1/(cη) > 0. 정리 6.3의 일반 η판(연습 2)이 η′로 그대로 성립하므로 E f(평균) − f* ≤ βR²/t + R²/(η′t) + η′σ²/2. η′ < η라 R²/(η′t) 항이 커져 수렴이 느려질 뿐, t → ∞에서 0으로 간다. 미리 c를 알면 걸음을 1/c배 키워 완전히 보정할 수 있다.
- 주의 [판단]: c가 x나 과거에 따라 변하면(예: 적응형 축소) ĝ = c(x)g는 일반적으로 c(x)∇f 방향이라 여전히 하강 방향(m = (1 − c_min)²)이지만 "걸음 축소"로의 정확한 환원은 c가 상수일 때만이다.
